# Longest Common Prefix

**Categories:** Array,String | **Tags:** array,string,prefix,horizontal-scanning | **Companies:** Amazon,Microsoft,Google,Adobe,Apple,Facebook

## Description
Write a function to find the longest common prefix string amongst an array of strings. If there is no common prefix, return an empty string.

**Time Complexity:** O(N × M)
**Space Complexity:** O(1)

### Input Format
An array of strings strs.

### Output Format
Return the longest common prefix string.

### Explanation
Compare characters of the first string with all other strings at the same position. Stop when a mismatch or end of any string is encountered.

### Sample Case 1
- **Input:** `strs = ["flower","flow","flight"]`
- **Output:** `"fl"`

### Sample Case 2
- **Input:** `strs = ["dog","racecar","car"]`
- **Output:** `""`

### Constraints
- 1 <= strs.length <= 200
- 0 <= strs[i].length <= 200
- strs[i] consists of only lowercase English letters.

### Hints
- Use the first string as the reference.
- Compare one character position at a time.
- Stop immediately when a mismatch occurs.
- The answer cannot be longer than the shortest string.
