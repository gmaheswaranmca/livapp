# Distinct Subsequences

**Categories:** Dynamic Programming,String | **Tags:** dynamic-programming,string,subsequence,dp | **Companies:** Amazon,Google,Microsoft,Adobe,Apple,Facebook,Bloomberg

## Description
Given two strings s and t, return the number of distinct subsequences of s which equals t. A subsequence is a new string generated from the original string by deleting some (possibly none) of the characters without disturbing the relative positions of the remaining characters.

**Time Complexity:** O(m × n)
**Space Complexity:** O(m × n)

### Input Format
The first line contains the string s. The second line contains the string t.

### Output Format
Print a single integer representing the number of distinct subsequences of s that equal t.

### Explanation
For each character in s, decide whether to use it or skip it. Dynamic Programming is used to count all valid ways to form t from s.

### Sample Case 1
- **Input:** `s = "rabbbit", t = "rabbit"`
- **Output:** `3`

### Sample Case 2
- **Input:** `s = "babgbag", t = "bag"`
- **Output:** `5`

### Constraints
- 1 <= s.length <= 1000
- 1 <= t.length <= 1000
- s and t consist of English letters.
- The answer fits in a 32-bit signed integer.

### Hints
- Think in terms of matching prefixes of the two strings.
- For every character in s, either use it or skip it.
- Define dp[i][j] as the number of ways to form the first j characters of t using the first i characters of s.
- The first column of the DP table is always 1 because an empty string can always be formed.
