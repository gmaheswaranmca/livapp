# Remove Duplicates from Sorted Array II

**Categories:** Array,Two Pointers | **Tags:** array,two-pointers,in-place,sorting | **Companies:** Amazon,Microsoft,Google,Adobe,Apple,Facebook,Bloomberg

## Description
Given an integer array nums sorted in non-decreasing order, remove some duplicates in-place such that each unique element appears at most twice. The relative order of the elements must be preserved. Return the new length of the modified array. The first k elements of nums should contain the final result.

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Input Format
The first line contains an integer n. The second line contains n sorted integers representing the array nums.

### Output Format
Print the new length k in the first line. Print the first k elements of the modified array in the second line separated by spaces.

### Explanation
Traverse the sorted array while maintaining a write index. Keep every element unless it would become the third occurrence of the same value.

### Sample Case 1
- **Input:** `nums = [1,1,1,2,2,3]`
- **Output:** `5
nums = [1,1,2,2,3]`

### Sample Case 2
- **Input:** `nums = [0,0,1,1,1,1,2,3,3]`
- **Output:** `7
nums = [0,0,1,1,2,3,3]`

### Constraints
- 1 <= nums.length <= 3 * 10^4
- -10^4 <= nums[i] <= 10^4
- nums is sorted in non-decreasing order.

### Hints
- The array is already sorted.
- Use two pointers: one for reading and one for writing.
- Always allow the first two occurrences of each value.
- Compare the current element with the element two positions before the write pointer.
