# Missing Number

**Categories:** Array,Math,Bit Manipulation | **Tags:** array,math,bit-manipulation,xor,gauss-sum | **Companies:** Amazon,Microsoft,Google,Adobe,Apple,Facebook,Oracle

## Description
Given an array nums containing n distinct numbers in the range [0, n], return the only number in the range that is missing from the array.

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Input Format
The first line contains an integer n representing the number of elements. The second line contains n distinct integers representing the array nums.

### Output Format
Return the missing number.

### Explanation
The array contains every number from 0 to n except one. Determine and return the missing value.

### Sample Case 1
- **Input:** `nums = [3,0,1]`
- **Output:** `2`

### Sample Case 2
- **Input:** `nums = [9,6,4,2,3,5,7,0,1]`
- **Output:** `8`

### Constraints
- 1 <= n <= 10^4
- nums.length == n
- 0 <= nums[i] <= n
- All numbers in nums are unique.

### Hints
- The numbers are from 0 to n with exactly one missing.
- Compare the expected sum with the actual sum.
- Alternatively, use XOR to eliminate matching numbers.
- Aim for O(n) time and O(1) extra space.
