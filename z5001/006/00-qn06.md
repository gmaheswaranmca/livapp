# Merge k Sorted Lists

**Categories:** Heap,Linked List,Divide and Conquer | **Tags:** heap,priority-queue,linked-list,merge,divide-and-conquer | **Companies:** Amazon,Google,Microsoft,Facebook,Apple,Adobe,Bloomberg

## Description
You are given an array of k sorted linked lists. Merge all the linked lists into one sorted linked list and return its head.

**Time Complexity:** O(N log k)
**Space Complexity:** O(k)

### Input Format
The first line contains an integer k. For each list, the first value is its length followed by the list elements in sorted order.

### Output Format
Print the merged sorted linked list as space-separated integers.

### Explanation
Maintain a min-heap containing the first node of every non-empty linked list. Repeatedly extract the smallest node and insert its next node until the heap becomes empty.

### Sample Case 1
- **Input:** `k = 3
1 4 5
1 3 4
2 6`
- **Output:** `1 1 2 3 4 4 5 6`

### Sample Case 2
- **Input:** `k = 0`
- **Output:** ``

### Constraints
- 0 <= k <= 10^4
- 0 <= Total number of nodes <= 10^4
- -10^4 <= Node.val <= 10^4
- Each linked list is sorted in ascending order.

### Hints
- Each individual list is already sorted.
- Only the smallest current node among the k lists is needed.
- A Min Heap (Priority Queue) efficiently finds the smallest node.
- Whenever a node is removed from the heap, insert its next node if it exists.
