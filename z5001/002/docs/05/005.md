# Rotting Oranges (LeetCode 994)

**Problem:**
Given a grid where:

* `0` = Empty cell
* `1` = Fresh orange
* `2` = Rotten orange

Every minute, any fresh orange adjacent (up, down, left, right) to a rotten orange becomes rotten.

Return the **minimum number of minutes** needed to rot all oranges. If impossible, return `-1`.

---

# Pattern Analysis

## Pattern 1: Brute Force Simulation

### Idea

* Every minute, scan the entire matrix.
* Find rotten oranges and rot adjacent fresh oranges.
* Repeat until no changes occur.

### Complexity

* Time: **O((m×n)²)**
* Space: **O(1)**

### Why Not Optimal?

* Matrix scanned repeatedly.
* Many unnecessary traversals.

---

## Pattern 2: Multi-Source BFS (Optimal)

### Key Observation

All rotten oranges start spreading **simultaneously**.

Instead of processing one rotten orange at a time:

* Put all rotten oranges into a queue initially.
* Perform BFS level by level.
* One BFS level = One minute.

This is called **Multi-Source BFS**.

---

# Why BFS Works?

Suppose:

```text
2 1 1
1 1 0
0 1 1
```

Minute 0:

```text
2 1 1
1 1 0
0 1 1
```

Minute 1:

```text
2 2 1
2 1 0
0 1 1
```

Minute 2:

```text
2 2 2
2 2 0
0 1 1
```

Minute 3:

```text
2 2 2
2 2 0
0 2 1
```

Minute 4:

```text
2 2 2
2 2 0
0 2 2
```

BFS naturally models this spreading process.

---

# Optimal Pattern: Multi-Source BFS

## Steps

### Step 1

Traverse grid

* Count fresh oranges
* Add all rotten oranges to queue

### Step 2

Run BFS

For each rotten orange:

* Visit 4 directions
* If fresh orange found:

  * Make it rotten
  * Decrease fresh count
  * Push into queue

### Step 3

Each BFS level represents one minute

Increment time after processing one level.

### Step 4

After BFS:

* If fresh oranges remain → return `-1`
* Else return minutes

---

# Python Code (Optimal)

```python
from collections import deque

class Solution:
    def orangesRotting(self, grid):
        rows = len(grid)
        cols = len(grid[0])

        queue = deque()
        fresh = 0

        # Collect all rotten oranges
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    queue.append((r, c))
                elif grid[r][c] == 1:
                    fresh += 1

        # No fresh oranges
        if fresh == 0:
            return 0

        directions = [
            (1, 0),
            (-1, 0),
            (0, 1),
            (0, -1)
        ]

        minutes = 0

        while queue and fresh > 0:

            size = len(queue)

            for _ in range(size):

                r, c = queue.popleft()

                for dr, dc in directions:

                    nr = r + dr
                    nc = c + dc

                    if (
                        0 <= nr < rows and
                        0 <= nc < cols and
                        grid[nr][nc] == 1
                    ):
                        grid[nr][nc] = 2
                        fresh -= 1
                        queue.append((nr, nc))

            minutes += 1

        return minutes if fresh == 0 else -1
```

# Pattern Recognition

Use **Multi-Source BFS** when:

| Problem                        | Pattern          |
| ------------------------------ | ---------------- |
| Rotting Oranges                | Multi-Source BFS |
| Walls and Gates                | Multi-Source BFS |
| 01 Matrix                      | Multi-Source BFS |
| Nearest Exit                   | BFS              |
| Shortest Path in Binary Matrix | BFS              |
| Word Ladder                    | BFS              |
| Fire Spread Problems           | Multi-Source BFS |
| Infection Spread Problems      | Multi-Source BFS |

# Pattern Comparison

| Pattern                | Time      | Space  | Recommended |
| ---------------------- | --------- | ------ | ----------- |
| Brute Force Simulation | O((m×n)²) | O(1)   | ❌ No        |
| DFS Spread Simulation  | O((m×n)²) | O(m×n) | ❌ No        |
| Multi-Source BFS       | O(m×n)    | O(m×n) | ✅ Best      |

# Interview Takeaway

Whenever you see:

* Multiple starting points
* Simultaneous spreading
* Minimum time/steps required
* Grid traversal

think:

> **Multi-Source BFS** → Put all sources into the queue initially and process level by level.

**Optimal Complexity**

```text
Time  : O(m × n)
Space : O(m × n)
```

This is the standard Amazon, Google, Meta, Microsoft, and Walmart interview solution.
