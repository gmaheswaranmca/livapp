# Design Hit Counter (LeetCode 362)

**Problem:**
Design a hit counter that counts the number of hits received in the past **5 minutes (300 seconds)**.

Operations:

```python
hit(timestamp)      # Record a hit
getHits(timestamp)  # Return hits in last 300 seconds
```

Example:

```text
hit(1)
hit(2)
hit(3)

getHits(4) -> 3

hit(300)

getHits(300) -> 4

getHits(301) -> 3
```

---

# Pattern Identification

This problem can be solved using multiple patterns:

| Pattern                   | Data Structure | Time Complexity | Space Complexity |
| ------------------------- | -------------- | --------------- | ---------------- |
| Brute Force               | List           | O(n) query      | O(n)             |
| Queue Sliding Window      | Queue/Deque    | O(1) amortized  | O(n)             |
| Fixed Size Circular Array | Array          | O(1)            | O(300)           |
| Circular Buffer + Counts  | Arrays         | O(1)            | O(300)           |

---

# Pattern 1: Brute Force List

## Idea

Store every hit timestamp.

For `getHits()`:

* Traverse all timestamps.
* Count timestamps within last 300 seconds.

---

## Code

```python
class HitCounter:

    def __init__(self):
        self.hits = []

    def hit(self, timestamp: int) -> None:
        self.hits.append(timestamp)

    def getHits(self, timestamp: int) -> int:
        count = 0

        for t in self.hits:
            if timestamp - t < 300:
                count += 1

        return count
```

---

## Complexity

### Hit

```text
O(1)
```

### GetHits

```text
O(n)
```

### Space

```text
O(n)
```

# Pattern 2: Queue Sliding Window

## Idea

Only keep hits from last 300 seconds.

When querying:

Remove expired hits.

```text
Current Time = T

Valid Range:

[T-299 , T]
```

Use queue front for oldest timestamp.

---

## Visualization

```text
Queue:

[1,2,3,300]

getHits(301)

301-1 = 300 → remove

Queue:

[2,3,300]

Answer = 3
```

---

## Code

```python
from collections import deque

class HitCounter:

    def __init__(self):
        self.q = deque()

    def hit(self, timestamp: int) -> None:
        self.q.append(timestamp)

    def getHits(self, timestamp: int) -> int:

        while self.q and timestamp - self.q[0] >= 300:
            self.q.popleft()

        return len(self.q)
```

---

## Complexity

### Hit

```text
O(1)
```

### GetHits

```text
O(1) amortized
```

### Space

```text
O(number of hits in 5 min)
```

# Pattern 3: Fixed 300 Buckets

## Idea

Since window size is fixed (300 seconds):

Store:

```python
times[300]
hits[300]
```

Each index represents one second.

```text
index = timestamp % 300
```

If timestamp changes:

```text
Overwrite old bucket
```

---

## Example

```text
timestamp = 301

index = 301 % 300 = 1

Bucket 1 previously stored second 1

Replace it.
```

---

## Code

```python
class HitCounter:

    def __init__(self):
        self.times = [0] * 300
        self.hits = [0] * 300

    def hit(self, timestamp: int) -> None:

        idx = timestamp % 300

        if self.times[idx] != timestamp:
            self.times[idx] = timestamp
            self.hits[idx] = 1
        else:
            self.hits[idx] += 1

    def getHits(self, timestamp: int) -> int:

        total = 0

        for i in range(300):

            if timestamp - self.times[i] < 300:
                total += self.hits[i]

        return total
```

---

## Complexity

### Hit

```text
O(1)
```

### GetHits

```text
O(300) = O(1)
```

### Space

```text
O(300)
```

# Pattern 4: Queue with Aggregated Counts

Useful when many hits arrive at the same timestamp.

Instead of storing every hit:

```text
(timestamp, count)
```

---

## Example

```text
hit(100)
hit(100)
hit(100)

Store:

[(100,3)]
```

---

## Code

```python
from collections import deque

class HitCounter:

    def __init__(self):
        self.q = deque()
        self.total = 0

    def hit(self, timestamp: int) -> None:

        if self.q and self.q[-1][0] == timestamp:
            self.q[-1][1] += 1
        else:
            self.q.append([timestamp, 1])

        self.total += 1

    def getHits(self, timestamp: int) -> int:

        while self.q and timestamp - self.q[0][0] >= 300:
            self.total -= self.q[0][1]
            self.q.popleft()

        return self.total
```

---

## Complexity

### Hit

```text
O(1)
```

### GetHits

```text
O(1) amortized
```

### Space

```text
O(unique timestamps)
```

# Optimized Solution

For interviews, the best progression is:

```text
Brute Force
    ↓
Queue Sliding Window
    ↓
300 Circular Buckets (Optimal)
```

### Why Circular Buckets Win

* Fixed 5-minute window
* Constant memory
* Constant-time updates
* Constant-time queries
* Handles millions of hits efficiently

```text
Time:
Hit      = O(1)
GetHits  = O(1)

Space:
O(300)
```

**Recommended Interview Pattern:**
✅ **Fixed Size Circular Array (300 Buckets)** — the most optimized and scalable solution for this problem.
