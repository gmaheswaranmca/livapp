# Sliding Window Maximum

**Problem:**
Given an array `nums` and an integer `k`, return the maximum value in every sliding window of size `k`.

### Example

```text
Input:
nums = [1,3,-1,-3,5,3,6,7]
k = 3

Output:
[3,3,5,5,6,7]
```

---

# Pattern 1: Brute Force

### Idea

For every window, scan all `k` elements and find the maximum.

### Algorithm

1. Iterate from `0` to `n-k`.
2. For each window, compute `max(nums[i:i+k])`.
3. Store the result.

### Complexity

* Time: `O(n*k)`
* Space: `O(1)`

### Code

```python
class Solution:
    def maxSlidingWindow(self, nums, k):
        result = []

        for i in range(len(nums) - k + 1):
            result.append(max(nums[i:i + k]))

        return result
```

---

# Pattern 2: Max Heap (Priority Queue)

### Idea

Maintain a max heap containing window elements.

Since Python provides a min heap, store negative values.

### Algorithm

1. Push `(−value, index)` into heap.
2. Remove elements whose index is outside the current window.
3. Heap top gives maximum.

### Complexity

* Time: `O(n log k)`
* Space: `O(k)`

### Code

```python
import heapq

class Solution:
    def maxSlidingWindow(self, nums, k):
        heap = []
        result = []

        for i, num in enumerate(nums):
            heapq.heappush(heap, (-num, i))

            while heap[0][1] <= i - k:
                heapq.heappop(heap)

            if i >= k - 1:
                result.append(-heap[0][0])

        return result
```

# Pattern 3: Monotonic Deque (Optimal)

### Idea

Maintain a deque of indices in decreasing order of values.

The front always contains the maximum element of the current window.

### Why It Works

When a larger element arrives:

* Smaller elements behind it can never become maximum.
* Remove them immediately.

### Example

```text
nums = [1,3,-1,-3,5]

Deque stores indices

1 → [1]
3 arrives
1 removed because 3 > 1

Deque:
[3]

Maximum = 3
```

---

### Algorithm

For each element:

#### Step 1: Remove Out-of-Window Indices

```python
while dq and dq[0] <= i-k:
    dq.popleft()
```

#### Step 2: Maintain Decreasing Order

```python
while dq and nums[dq[-1]] < nums[i]:
    dq.pop()
```

#### Step 3: Add Current Index

```python
dq.append(i)
```

#### Step 4: Record Maximum

Front of deque contains maximum.

```python
result.append(nums[dq[0]])
```

---

### Complexity

* Time: `O(n)`
* Space: `O(k)`

Each index is:

* inserted once
* removed once

Hence total operations are linear.

### Code

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        dq = deque()
        result = []

        for i in range(len(nums)):

            # Remove indices outside window
            while dq and dq[0] <= i - k:
                dq.popleft()

            # Maintain decreasing order
            while dq and nums[dq[-1]] < nums[i]:
                dq.pop()

            dq.append(i)

            # Window formed
            if i >= k - 1:
                result.append(nums[dq[0]])

        return result
```

# Pattern 4: Block Decomposition (DP)

### Idea

Precompute:

* `left[i]` = maximum from block start to `i`
* `right[i]` = maximum from `i` to block end

Window maximum:

```text
max(right[left boundary],
    left[right boundary])
```

### Complexity

* Time: `O(n)`
* Space: `O(n)`

### Code

```python
class Solution:
    def maxSlidingWindow(self, nums, k):
        n = len(nums)

        left = [0] * n
        right = [0] * n

        left[0] = nums[0]
        right[n - 1] = nums[n - 1]

        for i in range(1, n):
            if i % k == 0:
                left[i] = nums[i]
            else:
                left[i] = max(left[i - 1], nums[i])

        for i in range(n - 2, -1, -1):
            if (i + 1) % k == 0:
                right[i] = nums[i]
            else:
                right[i] = max(right[i + 1], nums[i])

        result = []

        for i in range(n - k + 1):
            result.append(max(right[i], left[i + k - 1]))

        return result
```

# Optimized Solution Pattern

## Monotonic Deque

This is the standard interview solution used by Amazon, Google, Meta, Microsoft, and Bloomberg.

### Key Insight

Keep indices in decreasing order of values.

```text
Front = Maximum of current window
Back  = Smaller candidates removed
```

### Complexity

* Time: `O(n)`
* Space: `O(k)`

### Optimized Code

```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums, k):
        dq = deque()
        ans = []

        for i, num in enumerate(nums):

            while dq and dq[0] <= i - k:
                dq.popleft()

            while dq and nums[dq[-1]] < num:
                dq.pop()

            dq.append(i)

            if i >= k - 1:
                ans.append(nums[dq[0]])

        return ans
```

### Pattern Recognition

Use the **Monotonic Deque Pattern** when you hear:

* Sliding Window Maximum
* Sliding Window Minimum
* Maximum of every subarray of size K
* First greater/smaller element in window
* Window-based min/max queries

This is the most efficient and most commonly expected interview solution.
