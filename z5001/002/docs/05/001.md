# Implement Queue using Stacks (LeetCode 232)

**Problem:**
Design a FIFO Queue using only Stack operations.

Operations:

* `push(x)` → Insert element to back
* `pop()` → Remove front element
* `peek()` → Return front element
* `empty()` → Check whether queue is empty

---

# Pattern 1: Brute Force (Push-Costly)

### Idea

Maintain one stack such that the front of queue always stays on top.

When pushing:

1. Move all elements from Stack1 → Stack2
2. Push new element into Stack1
3. Move everything back

### Visualization

Queue:

```
1 2 3
```

Stack1:

```
Top
1
2
3
```

Push 4:

```
Move all → Stack2
Push 4
Move back
```

Result:

```
Top
1
2
3
4
```

### Code

```python
class MyQueue:

    def __init__(self):
        self.s1 = []
        self.s2 = []

    def push(self, x: int) -> None:
        while self.s1:
            self.s2.append(self.s1.pop())

        self.s1.append(x)

        while self.s2:
            self.s1.append(self.s2.pop())

    def pop(self) -> int:
        return self.s1.pop()

    def peek(self) -> int:
        return self.s1[-1]

    def empty(self) -> bool:
        return len(self.s1) == 0
```

### Complexity

| Operation | Time |
| --------- | ---- |
| Push      | O(n) |
| Pop       | O(1) |
| Peek      | O(1) |
| Empty     | O(1) |

# Pattern 2: Brute Force (Pop-Costly)

### Idea

Keep elements in insertion order.

For pop:

1. Move n−1 elements to Stack2
2. Remove last element
3. Move elements back

### Code

```python
class MyQueue:

    def __init__(self):
        self.s1 = []
        self.s2 = []

    def push(self, x: int) -> None:
        self.s1.append(x)

    def pop(self) -> int:
        while len(self.s1) > 1:
            self.s2.append(self.s1.pop())

        ans = self.s1.pop()

        while self.s2:
            self.s1.append(self.s2.pop())

        return ans

    def peek(self) -> int:
        while len(self.s1) > 1:
            self.s2.append(self.s1.pop())

        ans = self.s1[-1]

        while self.s2:
            self.s1.append(self.s2.pop())

        return ans

    def empty(self) -> bool:
        return len(self.s1) == 0
```

### Complexity

| Operation | Time |
| --------- | ---- |
| Push      | O(1) |
| Pop       | O(n) |
| Peek      | O(n) |
| Empty     | O(1) |

# Pattern 3: Two Stacks with Lazy Transfer (Optimal)

### Idea

Use:

* `in_stack` → For incoming elements
* `out_stack` → For outgoing elements

### Push

Always push into `in_stack`.

### Pop / Peek

If `out_stack` is empty:

* Transfer all elements from `in_stack` to `out_stack`

This reverses order and exposes the oldest element.

### Example

Push:

```
1,2,3
```

in_stack:

```
Top
3
2
1
```

Need pop:

Transfer:

```
out_stack

Top
1
2
3
```

Now:

```
pop() => 1
peek() => 2
```

---

### Code

```python
class MyQueue:

    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x: int) -> None:
        self.in_stack.append(x)

    def _move(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(
                    self.in_stack.pop()
                )

    def pop(self) -> int:
        self._move()
        return self.out_stack.pop()

    def peek(self) -> int:
        self._move()
        return self.out_stack[-1]

    def empty(self) -> bool:
        return (
            len(self.in_stack) == 0 and
            len(self.out_stack) == 0
        )
```

# Optimized Solution Pattern

### Pattern: Two Stacks + Lazy Transfer

```python
class MyQueue:

    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def pop(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(
                    self.in_stack.pop()
                )
        return self.out_stack.pop()

    def peek(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(
                    self.in_stack.pop()
                )
        return self.out_stack[-1]

    def empty(self):
        return (
            not self.in_stack and
            not self.out_stack
        )
```

### Why this is optimal?

* Each element is:

  * Pushed once into `in_stack`
  * Moved once to `out_stack`
  * Popped once

Thus every element is processed a constant number of times.

**Time Complexity:** Amortized **O(1)** per operation
**Space Complexity:** **O(n)**
