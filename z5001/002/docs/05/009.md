# Moving Average from Data Stream (LeetCode 346)

**Difficulty:** Easy
**Companies:** Google, Amazon, Meta, Microsoft

## Problem

Design a data structure that calculates the **moving average** of the last `size` values in a data stream.

Implement:

```python
MovingAverage(size)
next(val)
```

* `next(val)` adds a new value and returns the moving average of the last `size` values.

### Example

```python
Input:
MovingAverage(3)

next(1)  -> 1.0
next(10) -> 5.5
next(3)  -> 4.66667
next(5)  -> 6.0
```

Explanation:

```text
Window = [1]          Average = 1
Window = [1,10]       Average = 11/2 = 5.5
Window = [1,10,3]     Average = 14/3 = 4.66667
Window = [10,3,5]     Average = 18/3 = 6
```

# Pattern 1: Brute Force Queue

## Idea

Store all window elements in a queue.

Whenever a new element arrives:

1. Push into queue.
2. Remove oldest if size exceeded.
3. Compute sum of queue every time.

---

## Code

```python
from collections import deque

class MovingAverage:

    def __init__(self, size: int):
        self.size = size
        self.q = deque()

    def next(self, val: int) -> float:
        self.q.append(val)

        if len(self.q) > self.size:
            self.q.popleft()

        return sum(self.q) / len(self.q)
```

---

## Complexity

```text
Time : O(k) per operation
Space: O(k)
```

where `k = window size`.

---

# Pattern 2: Queue + Running Sum

## Idea

Instead of recalculating sum every time:

Maintain:

```python
current_sum
```

When:

```python
add new value
current_sum += value
```

When window exceeds size:

```python
removed = popleft()
current_sum -= removed
```

Average:

```python
current_sum / len(queue)
```

---

## Code

```python
from collections import deque

class MovingAverage:

    def __init__(self, size: int):
        self.size = size
        self.q = deque()
        self.window_sum = 0

    def next(self, val: int) -> float:

        self.q.append(val)
        self.window_sum += val

        if len(self.q) > self.size:
            self.window_sum -= self.q.popleft()

        return self.window_sum / len(self.q)
```

---

## Complexity

```text
Time : O(1)
Space: O(k)
```

# Pattern 3: Circular Buffer (Array)

## Idea

Use fixed-size array.

Avoid deque overhead.

Track:

```python
head index
count
running_sum
```

Overwrite oldest element when window full.

---

## Code

```python
class MovingAverage:

    def __init__(self, size: int):
        self.size = size
        self.window = [0] * size
        self.count = 0
        self.head = 0
        self.window_sum = 0

    def next(self, val: int) -> float:

        if self.count < self.size:
            self.count += 1
        else:
            self.window_sum -= self.window[self.head]

        self.window[self.head] = val
        self.window_sum += val

        self.head = (self.head + 1) % self.size

        return self.window_sum / self.count
```

---

## Complexity

```text
Time : O(1)
Space: O(k)
```

# Optimized Solution Pattern

### Sliding Window + Queue + Running Sum

This is the standard interview solution because:

* Queue naturally maintains the window.
* Running sum avoids repeated summation.
* Each element is added once and removed once.
* Achieves **O(1)** time per stream update.

```text
Pattern:
Queue + Sliding Window + Running Sum

Time : O(1)
Space: O(k)

Recommended for interviews:
✅ Yes
✅ Most commonly expected solution
✅ Easy to explain
```
