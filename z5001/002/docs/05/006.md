# Number of Recent Calls (LeetCode 933)

**Difficulty:** Easy
**Companies:** Google, Amazon, Meta, Apple

## Problem Summary

Design a class `RecentCounter` that counts the number of requests received in the last **3000 milliseconds**.

For each call:

```python
ping(t)
```

Return the number of calls made in the inclusive range:

```text
[t - 3000, t]
```

where `t` is strictly increasing.

### Example

```python
recentCounter = RecentCounter()

recentCounter.ping(1)      # 1
recentCounter.ping(100)    # 2
recentCounter.ping(3001)   # 3
recentCounter.ping(3002)   # 3
```

# Solution Patterns

## Pattern 1: Brute Force (Store All Calls)

### Idea

* Store all timestamps.
* For every `ping(t)`, scan all previous timestamps.
* Count timestamps within:

```text
[t - 3000, t]
```

### Algorithm

1. Append current timestamp.
2. Traverse entire list.
3. Count valid timestamps.

### Code

```python
class RecentCounter:

    def __init__(self):
        self.calls = []

    def ping(self, t: int) -> int:
        self.calls.append(t)

        count = 0
        start = t - 3000

        for time in self.calls:
            if time >= start:
                count += 1

        return count
```

### Complexity

```text
Time  : O(n) per ping
Space : O(n)
```

# Pattern 2: Binary Search on Sorted Timestamps

### Idea

Since timestamps are strictly increasing:

```text
1 < 100 < 3001 < 3002 ...
```

Store all timestamps.

For each ping:

* Find first index ≥ (t - 3000)
* Count remaining elements

### Code

```python
from bisect import bisect_left

class RecentCounter:

    def __init__(self):
        self.calls = []

    def ping(self, t: int) -> int:
        self.calls.append(t)

        left = bisect_left(self.calls, t - 3000)

        return len(self.calls) - left
```

### Complexity

```text
Time  : O(log n)
Space : O(n)
```

# Pattern 3: Queue / Sliding Window

### Idea

Keep only timestamps that belong to the current window:

```text
[t - 3000, t]
```

Whenever a new request arrives:

1. Add it to queue.
2. Remove all timestamps older than:

```text
t - 3000
```

3. Queue size becomes answer.

### Visualization

```text
ping(1)

Queue:
[1]

Answer = 1
```

```text
ping(100)

Queue:
[1,100]

Answer = 2
```

```text
ping(3001)

Queue:
[1,100,3001]

Answer = 3
```

```text
ping(3002)

Valid range:
[2,3002]

Remove 1

Queue:
[100,3001,3002]

Answer = 3
```

---

### Code

```python
from collections import deque

class RecentCounter:

    def __init__(self):
        self.q = deque()

    def ping(self, t: int) -> int:

        self.q.append(t)

        while self.q[0] < t - 3000:
            self.q.popleft()

        return len(self.q)
```

### Complexity

```text
Time  : O(1) amortized
Space : O(n)
```

### Why O(1) Amortized?

Each timestamp:

```text
Added once
Removed once
```

Therefore:

```text
Total operations = 2n
```

Hence:

```text
O(n) over n calls
⇒ O(1) amortized per ping
```

# Optimal Interview Solution

```python
from collections import deque

class RecentCounter:

    def __init__(self):
        self.q = deque()

    def ping(self, t: int) -> int:

        self.q.append(t)

        while self.q and self.q[0] < t - 3000:
            self.q.popleft()

        return len(self.q)
```

```text
Queue
+
Sliding Window
+
Amortized Analysis
```
