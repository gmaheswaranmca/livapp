# Binary Search (Easy)

**Problem:** Find a target element in a sorted array.

**Companies:** Amazon, Google, Meta, Microsoft, Apple

---

# Pattern 1: Linear Search (Brute Force)

### Idea

Traverse the array from left to right and compare every element with the target.

### When to Use

* Array is not sorted.
* Small input size.

### Time Complexity

* **Time:** O(n)
* **Space:** O(1)

### Code

```python
def search(nums, target):
    for i in range(len(nums)):
        if nums[i] == target:
            return i
    return -1
```

---

# Pattern 2: Iterative Binary Search

### Idea

Since the array is sorted:

1. Find middle element.
2. If target equals middle → return index.
3. If target is smaller → search left half.
4. If target is larger → search right half.
5. Repeat until found or search space becomes empty.

### Visualization

```text
nums = [1,3,5,7,9,11]
target = 9

left=0 right=5

mid=2 → nums[2]=5

9 > 5

Search right side

left=3 right=5

mid=4 → nums[4]=9

Found
```

### Time Complexity

* **Time:** O(log n)
* **Space:** O(1)

### Code

```python
def search(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid

        elif nums[mid] < target:
            left = mid + 1

        else:
            right = mid - 1

    return -1
```

# Pattern 3: Recursive Binary Search

### Idea

Apply binary search recursively on the appropriate half.

### Time Complexity

* **Time:** O(log n)
* **Space:** O(log n) (recursion stack)

### Code

```python
def binary_search(nums, left, right, target):
    if left > right:
        return -1

    mid = left + (right - left) // 2

    if nums[mid] == target:
        return mid

    if nums[mid] < target:
        return binary_search(nums, mid + 1, right, target)

    return binary_search(nums, left, mid - 1, target)


def search(nums, target):
    return binary_search(nums, 0, len(nums) - 1, target)
```

# Pattern 4: Python Built-in Binary Search (bisect)

### Idea

Use Python's built-in binary search library.

### Time Complexity

* **Time:** O(log n)
* **Space:** O(1)

### Code

```python
from bisect import bisect_left

def search(nums, target):
    idx = bisect_left(nums, target)

    if idx < len(nums) and nums[idx] == target:
        return idx

    return -1
```

# Pattern Comparison

| Pattern                 | Time     | Space    | Interview Friendly |
| ----------------------- | -------- | -------- | ------------------ |
| Linear Search           | O(n)     | O(1)     | No                 |
| Iterative Binary Search | O(log n) | O(1)     | Yes                |
| Recursive Binary Search | O(log n) | O(log n) | Yes                |
| Bisect Library          | O(log n) | O(1)     | Usually No         |

# Optimized Pattern

### Recommended: Iterative Binary Search

Why?

✅ Best time complexity O(log n)

✅ Constant space O(1)

✅ No recursion overhead

✅ Most commonly expected by Amazon, Google, Meta, Microsoft, and Apple

### Core Template

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid

        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return -1
```

# Recognition Pattern for Interviews

If you see:

* **Sorted Array**
* **Find/Search Target**
* **Return Index**
* **O(log n) Expected**
* **Search Space Can Be Halved**

➡️ Think **Binary Search Pattern** immediately.

This pattern is the foundation for many medium/hard problems such as:

* Search Insert Position
* First Bad Version
* Guess Number Higher or Lower
* Find First and Last Position of Element
* Search in Rotated Sorted Array
* Peak Element
* Koko Eating Bananas
* Capacity To Ship Packages Within D Days
* Median of Two Sorted Arrays
