# Search in Rotated Sorted Array

**Problem:** Search a target value in a rotated sorted array and return its index. If not found, return `-1`.

Example:

```text
nums = [4,5,6,7,0,1,2], target = 0
Output: 4
```

---

# Pattern 1: Linear Search

### Idea

Traverse the array and compare each element with the target.

### Time Complexity

* Time: O(n)
* Space: O(1)

### Code

```python
class Solution:
    def search(self, nums, target):
        for i in range(len(nums)):
            if nums[i] == target:
                return i
        return -1
```

### When to Use

* Small arrays
* Brute-force baseline solution

---

# Pattern 2: Find Pivot + Binary Search

### Idea

1. Find rotation pivot (smallest element).
2. Decide which sorted half contains target.
3. Perform normal binary search.

### Time Complexity

* Time: O(log n)
* Space: O(1)

### Code

```python
class Solution:
    
    def binarySearch(self, nums, left, right, target):
        while left <= right:
            mid = (left + right) // 2

            if nums[mid] == target:
                return mid

            if nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1

        return -1

    def search(self, nums, target):
        n = len(nums)

        left, right = 0, n - 1

        while left < right:
            mid = (left + right) // 2

            if nums[mid] > nums[right]:
                left = mid + 1
            else:
                right = mid

        pivot = left

        if nums[pivot] <= target <= nums[n - 1]:
            return self.binarySearch(nums, pivot, n - 1, target)

        return self.binarySearch(nums, 0, pivot - 1, target)
```

### Interview Value

Good approach showing understanding of rotation and binary search.

# Pattern 3: Modified Binary Search (Single Pass)

### Idea

At every step:

* One half is always sorted.
* Check which half is sorted.
* Determine whether target lies inside that half.
* Eliminate half of the search space.

### Time Complexity

* Time: O(log n)
* Space: O(1)

### Code

```python
class Solution:
    def search(self, nums, target):

        left, right = 0, len(nums) - 1

        while left <= right:

            mid = (left + right) // 2

            if nums[mid] == target:
                return mid

            # Left half sorted
            if nums[left] <= nums[mid]:

                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1

            # Right half sorted
            else:

                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1

        return -1
```

### Dry Run

```text
nums = [4,5,6,7,0,1,2]
target = 0

mid=3 → value=7

Left half [4,5,6,7] sorted
Target not inside
Move right

mid=5 → value=1

Left half [0,1] sorted
Target inside
Move left

mid=4 → value=0

Found
```

# Pattern 4: Recursive Binary Search

### Idea

Same logic as Pattern 3 but implemented recursively.

### Time Complexity

* Time: O(log n)
* Space: O(log n) recursion stack

### Code

```python
class Solution:

    def helper(self, nums, left, right, target):

        if left > right:
            return -1

        mid = (left + right) // 2

        if nums[mid] == target:
            return mid

        if nums[left] <= nums[mid]:

            if nums[left] <= target < nums[mid]:
                return self.helper(nums, left, mid - 1, target)

            return self.helper(nums, mid + 1, right, target)

        else:

            if nums[mid] < target <= nums[right]:
                return self.helper(nums, mid + 1, right, target)

            return self.helper(nums, left, mid - 1, target)

    def search(self, nums, target):
        return self.helper(nums, 0, len(nums) - 1, target)
```

# Optimized Solution Pattern

## Modified Binary Search (Single Pass)

### Why It Is Best

✅ Single traversal

✅ No pivot calculation

✅ Constant extra memory

✅ Clean interview solution

✅ Most commonly expected by Amazon, Google, Meta, Microsoft, Bloomberg

### Complexity

```text
Time  : O(log n)
Space : O(1)
```

### Interview Pattern to Remember

```text
1. Calculate mid
2. Check target
3. Identify sorted half
4. Check if target belongs there
5. Discard one half
6. Repeat
```

### Final Recommended Code

```python
class Solution:

        while left <= right:

                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1

            else:

                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1

        return -1
```
