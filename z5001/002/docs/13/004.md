# Search a 2D Matrix (LeetCode 74)

**Problem:**
Given an `m x n` matrix where:

* Each row is sorted in ascending order.
* First element of each row is greater than the last element of the previous row.

Find whether a target exists in the matrix.

---

# Pattern 1: Brute Force Scan

### Idea

Check every element one by one.

### Time Complexity

* Time: **O(m × n)**
* Space: **O(1)**

### Code

```python
def searchMatrix(matrix, target):
    for row in matrix:
        for num in row:
            if num == target:
                return True
    return False
```

### When to Use

* Small matrix
* Interview warm-up approach

---

# Pattern 2: Row Selection + Binary Search

### Idea

1. Find the row that may contain target.
2. Perform binary search in that row.

Since rows are sorted and non-overlapping.

### Time Complexity

* Row search: O(m)
* Binary Search: O(log n)

Total:

**O(m + log n)**

### Code

```python
def searchMatrix(matrix, target):
    rows = len(matrix)
    cols = len(matrix[0])

    for r in range(rows):
        if matrix[r][0] <= target <= matrix[r][cols - 1]:

            left, right = 0, cols - 1

            while left <= right:
                mid = (left + right) // 2

                if matrix[r][mid] == target:
                    return True
                elif matrix[r][mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1

            return False

    return False
```

### Pattern Used

* Binary Search on Candidate Row

---

# Pattern 3: Binary Search on Rows + Binary Search on Columns

### Idea

First binary search to identify the correct row.

Second binary search inside that row.

### Time Complexity

* Row Binary Search = O(log m)
* Column Binary Search = O(log n)

Total:

**O(log m + log n)**

### Code

```python
def searchMatrix(matrix, target):
    rows = len(matrix)
    cols = len(matrix[0])

    top, bottom = 0, rows - 1

    while top <= bottom:
        row = (top + bottom) // 2

        if target > matrix[row][cols - 1]:
            top = row + 1
        elif target < matrix[row][0]:
            bottom = row - 1
        else:
            break

    if not (top <= bottom):
        return False

    row = (top + bottom) // 2

    left, right = 0, cols - 1

    while left <= right:
        mid = (left + right) // 2

        if matrix[row][mid] == target:
            return True
        elif matrix[row][mid] < target:
            left = mid + 1
        else:
            right = mid - 1

    return False
```

### Pattern Used

* Double Binary Search

# Pattern 4: Flattened Binary Search (Most Optimized)

### Idea

Treat matrix as a single sorted array.

Example:

```text
1  3  5  7
10 11 16 20
23 30 34 60
```

Virtual Array:

```text
[1,3,5,7,10,11,16,20,23,30,34,60]
```

Mapping:

```python
row = mid // cols
col = mid % cols
```

No actual flattening required.

---

### Visualization

For a matrix with:

```text
m rows
n cols
```

Indices:

```text
0 ... (m*n - 1)
```

Convert:

```python
row = index // n
col = index % n
```

---

### Time Complexity

Binary Search over all elements:

**O(log(m × n))**

Space:

**O(1)**

---

### Code

```python
def searchMatrix(matrix, target):
    rows = len(matrix)
    cols = len(matrix[0])

    left = 0
    right = rows * cols - 1

    while left <= right:

        mid = (left + right) // 2

        row = mid // cols
        col = mid % cols

        value = matrix[row][col]

        if value == target:
            return True

        elif value < target:
            left = mid + 1

        else:
            right = mid - 1

    return False
```

### Pattern Used

* Binary Search on Virtual Sorted Array
* Index Mapping

# Optimized Solution

### Recommended Pattern

**Flattened Binary Search**

Why?

* Uses matrix properties fully.
* Single binary search.
* Constant space.
* Most commonly expected by Amazon, Google, Meta, Microsoft, and Apple interviews.

```python
def searchMatrix(matrix, target):
    rows = len(matrix)
    cols = len(matrix[0])

    left, right = 0, rows * cols - 1

    while left <= right:
        mid = (left + right) // 2

        value = matrix[mid // cols][mid % cols]

        if value == target:
            return True
        elif value < target:
            left = mid + 1
        else:
            right = mid - 1

    return False
```

### Key Interview Pattern

**Binary Search on Answer Space / Virtual Array Mapping**

```text
2D Matrix
        ↓
Virtual Sorted Array
        ↓
Binary Search
        ↓
Index Mapping
```

This is the standard optimal solution expected in Tier-1 company interviews.
