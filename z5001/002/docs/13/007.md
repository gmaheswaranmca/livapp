# Median of Two Sorted Arrays (Hard)

**Problem:** Given two sorted arrays, find the median of the combined sorted array in **O(log(min(m,n)))** time.

Example:

```text
nums1 = [1,3]
nums2 = [2]

Output = 2.0
```

---

# Pattern Analysis

There are multiple ways to solve this problem.

| Pattern                    | Idea                            | Time             | Space  |
| -------------------------- | ------------------------------- | ---------------- | ------ |
| Merge Arrays               | Merge and find median           | O(m+n)           | O(m+n) |
| Two Pointers Without Merge | Traverse until median position  | O(m+n)           | O(1)   |
| Binary Search Partition    | Partition both arrays correctly | O(log(min(m,n))) | O(1)   |

---

# Pattern 1: Merge Arrays

### Idea

Merge both arrays into a new sorted array.

### Steps

1. Merge like Merge Sort.
2. Find middle element(s).
3. Return median.

### Code

```python
class Solution:
    def findMedianSortedArrays(self, nums1, nums2):
        merged = sorted(nums1 + nums2)

        n = len(merged)

        if n % 2:
            return merged[n // 2]

        return (merged[n//2 - 1] + merged[n//2]) / 2
```

### Complexity

```text
Time  : O((m+n) log(m+n))
Space : O(m+n)
```

---

# Pattern 2: Two Pointer Traversal

### Idea

No need to fully merge.

Only walk until median position.

### Steps

1. Use two pointers.
2. Simulate merge process.
3. Track previous and current elements.
4. Stop when median position reached.

### Code

```python
class Solution:
    def findMedianSortedArrays(self, nums1, nums2):

        m, n = len(nums1), len(nums2)

        total = m + n
        mid = total // 2

        i = j = 0
        prev = curr = 0

        for _ in range(mid + 1):

            prev = curr

            if i < m and (j >= n or nums1[i] <= nums2[j]):
                curr = nums1[i]
                i += 1
            else:
                curr = nums2[j]
                j += 1

        if total % 2:
            return curr

        return (prev + curr) / 2
```

### Complexity

```text
Time  : O(m+n)
Space : O(1)
```

# Pattern 3 (Optimal): Binary Search Partition

### Core Observation

Median splits the combined array into:

```text
Left Half  <= Right Half
```

We can binary search a partition in the smaller array.

Example:

```text
nums1 = [1,3]
nums2 = [2]

Combined:

[1 | 2,3]
```

Partition should satisfy:

```text
max(left side) <= min(right side)
```

---

## Visualization

Suppose:

```text
A = [1,3,8]
B = [7,9,10,11]
```

Partition:

```text
A : [1,3 | 8]
B : [7 | 9,10,11]
```

Left side:

```text
1,3,7
```

Right side:

```text
8,9,10,11
```

Check:

```text
max(left) = 7
min(right)= 8

7 <= 8 ✓
```

Valid partition found.

---

## Formula

Let:

```text
i = partition in nums1
j = partition in nums2
```

Then

```text
j = (m+n+1)//2 - i
```

Need:

```text
Aleft <= Bright
and
Bleft <= Aright
```

---

## Optimal Code

```python
class Solution:
    def findMedianSortedArrays(self, nums1, nums2):

        # Binary search on smaller array
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1

        m = len(nums1)
        n = len(nums2)

        left = 0
        right = m

        while left <= right:

            i = (left + right) // 2
            j = (m + n + 1) // 2 - i

            Aleft = float('-inf') if i == 0 else nums1[i - 1]
            Aright = float('inf') if i == m else nums1[i]

            Bleft = float('-inf') if j == 0 else nums2[j - 1]
            Bright = float('inf') if j == n else nums2[j]

            if Aleft <= Bright and Bleft <= Aright:

                if (m + n) % 2 == 0:
                    return (
                        max(Aleft, Bleft)
                        + min(Aright, Bright)
                    ) / 2

                return max(Aleft, Bleft)

            elif Aleft > Bright:
                right = i - 1

            else:
                left = i + 1
```

---

# Binary Search Partition Formula

The central formula is:

j = \frac{m+n+1}{2} - i

where:

```text
i = partition index in smaller array
j = partition index in larger array
```

---

# Why This Works

For a valid median partition:

```text
All left elements
      <=
All right elements
```

Thus:

```text
max(left side)
```

is the median for odd length.

For even length:

```text
(max(left) + min(right))/2
```

is the median.

Binary search helps us find this partition efficiently.
