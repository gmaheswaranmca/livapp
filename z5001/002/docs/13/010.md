# Find Minimum in Rotated Sorted Array

**Problem:** Find the minimum element in a rotated sorted array.

Example:

```text
Input: [4,5,6,7,0,1,2]
Output: 0

Input: [3,4,5,1,2]
Output: 1
```

---

# Pattern 1: Linear Scan

## Idea

Traverse the array and keep track of the minimum element.

## When to Use

* Brute force approach
* Small input sizes
* Interview warm-up

## Time Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def findMin(nums):
    minimum = nums[0]

    for num in nums:
        minimum = min(minimum, num)

    return minimum
```

---

# Pattern 2: Compare Adjacent Elements (Rotation Point Search)

## Idea

Minimum element is where:

```python
nums[i] < nums[i-1]
```

That index represents the rotation point.

Example:

```text
4 5 6 7 0 1 2
        ↑
      minimum
```

## Time Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def findMin(nums):
    n = len(nums)

    for i in range(1, n):
        if nums[i] < nums[i - 1]:
            return nums[i]

    return nums[0]
```

# Pattern 3: Binary Search on Sorted Half

## Key Observation

In a rotated sorted array:

* One side is always sorted.
* Minimum lies in the unsorted side.
* If the current range is already sorted, leftmost element is minimum.

Example:

```text
4 5 6 7 0 1 2
l       m     r

nums[m] > nums[r]
Minimum is on right side
```

Example:

```text
0 1 2 4 5 6 7
l     m       r

Already sorted
Answer = nums[l]
```

---

## Binary Search Logic

### Case 1

```python
nums[mid] > nums[right]
```

Minimum is in right half.

```python
left = mid + 1
```

### Case 2

```python
nums[mid] <= nums[right]
```

Minimum may be mid or left side.

```python
right = mid
```

---

## Time Complexity

* Time: O(log n)
* Space: O(1)

## Code

```python
def findMin(nums):
    left = 0
    right = len(nums) - 1

    while left < right:

        mid = left + (right - left) // 2

        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid

    return nums[left]
```

# Pattern 4: Binary Search with Early Sorted Check

## Idea

Before calculating mid:

If subarray is already sorted:

```python
nums[left] < nums[right]
```

then minimum is:

```python
nums[left]
```

This saves extra iterations.

---

## Code

```python
def findMin(nums):
    left = 0
    right = len(nums) - 1

    while left < right:

        if nums[left] < nums[right]:
            return nums[left]

        mid = left + (right - left) // 2

        if nums[mid] >= nums[left]:
            left = mid + 1
        else:
            right = mid

    return nums[left]
```

# Pattern Comparison

| Pattern                            | Idea                    | Time     | Space |
| ---------------------------------- | ----------------------- | -------- | ----- |
| Linear Scan                        | Check every element     | O(n)     | O(1)  |
| Rotation Point Scan                | Find drop point         | O(n)     | O(1)  |
| Binary Search on Right Boundary    | Search unsorted half    | O(log n) | O(1)  |
| Binary Search + Early Sorted Check | Optimized binary search | O(log n) | O(1)  |

---

# Optimized Solution

```python
def findMin(nums):
    left = 0
    right = len(nums) - 1

    while left < right:
        mid = left + (right - left) // 2

        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid

    return nums[left]
```

### Why this is optimal?

✅ Uses Binary Search Pattern
✅ Eliminates half search space every iteration
✅ O(log n) Time Complexity
✅ O(1) Space Complexity
✅ Most commonly expected in Amazon, Google, Microsoft, Meta, and Bloomberg interviews

### Pattern Name to Remember

**Binary Search on Rotation Pivot / Binary Search on Answer Region**.
