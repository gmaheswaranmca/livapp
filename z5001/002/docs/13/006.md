# Find Peak Element (LeetCode 162)

**Problem Statement:**
Given an array `nums`, find any peak element and return its index.

A peak element is an element that is strictly greater than its neighbors.

Example:

```text
Input: nums = [1,2,3,1]
Output: 2
Explanation: 3 is a peak element.
```

---

# Solution Patterns

## Pattern 1: Linear Scan (Brute Force)

### Idea

Check every element and verify whether it is greater than its neighbors.

### Algorithm

1. Traverse all elements.
2. Compare with left and right neighbors.
3. Return index when peak is found.

### Complexity

* Time: O(n)
* Space: O(1)

### Code

```python
def findPeakElement(nums):
    n = len(nums)

    for i in range(n):
        left = nums[i - 1] if i > 0 else float('-inf')
        right = nums[i + 1] if i < n - 1 else float('-inf')

        if nums[i] > left and nums[i] > right:
            return i

    return -1
```

---

## Pattern 2: Recursive Binary Search

### Idea

If middle element is smaller than right neighbor, peak exists on the right side.

Otherwise peak exists on the left side (including mid).

### Complexity

* Time: O(log n)
* Space: O(log n) (recursion stack)

### Code

```python
def findPeakElement(nums):

    def binary_search(left, right):
        if left == right:
            return left

        mid = (left + right) // 2

        if nums[mid] < nums[mid + 1]:
            return binary_search(mid + 1, right)
        else:
            return binary_search(left, mid)

    return binary_search(0, len(nums) - 1)
```

---

## Pattern 3: Binary Search on Answer (Optimal)

### Key Observation

If:

```text
nums[mid] < nums[mid+1]
```

then we are on an ascending slope.

```text
1 2 3 4 5
        ^
```

A peak must exist on the right.

---

If:

```text
nums[mid] > nums[mid+1]
```

then we are on a descending slope.

```text
5 4 3 2 1
^
```

A peak exists on the left including mid.

---

### Visualization

```text
Array:
1 2 3 1

L   M   R
    3 > 1

Peak is left side including M
```

```text
Array:
1 2 3 4 5

    M
3 < 4

Peak is on right side
```

---

### Algorithm

1. Initialize `left = 0`, `right = n-1`.
2. Find `mid`.
3. Compare `nums[mid]` and `nums[mid+1]`.
4. If ascending:

   * search right half.
5. Else:

   * search left half including mid.
6. Continue until `left == right`.

### Complexity

* Time: O(log n)
* Space: O(1)

### Code

```python
def findPeakElement(nums):
    left = 0
    right = len(nums) - 1

    while left < right:
        mid = (left + right) // 2

        if nums[mid] < nums[mid + 1]:
            left = mid + 1
        else:
            right = mid

    return left
```

# Optimized Solution

```python
def findPeakElement(nums):
    left = 0
    right = len(nums) - 1

    while left < right:
        mid = (left + right) // 2

        if nums[mid] < nums[mid + 1]:
            left = mid + 1
        else:
            right = mid

    return left
```

### Why this is optimal?

* Uses Binary Search.
* Eliminates half of the search space every iteration.
* O(log n) time.
* O(1) extra space.
* Most expected solution in Google, Amazon, Microsoft, Meta, and Apple interviews.

### Reusable Binary Search Template

```python
while left < right:
    mid = (left + right) // 2

    if condition(mid):
        left = mid + 1
    else:
        right = mid

return left
```

For Peak Element:

```python
condition(mid) = nums[mid] < nums[mid + 1]
```

* Koko Eating Bananas

* Split Array Largest Sum

Pattern Name:

**Binary Search on Answer / Monotonic Decision Binary Search**.
