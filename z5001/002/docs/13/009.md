# Single Element in a Sorted Array

**Problem:**
Given a sorted array where every element appears exactly twice except for one element that appears only once, find that single element.

**Example**

```text
Input:  [1,1,2,3,3,4,4,8,8]
Output: 2

Input:  [3,3,7,7,10,11,11]
Output: 10
```

---

# Pattern 1: Linear Scan (Pair Checking)

## Idea

Since duplicates occur in pairs, check elements two at a time.

## Algorithm

* Traverse with step size 2.
* If current element differs from next element, current element is the answer.
* If all pairs match, last element is the answer.

## Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def singleNonDuplicate(nums):
    n = len(nums)

    for i in range(0, n - 1, 2):
        if nums[i] != nums[i + 1]:
            return nums[i]

    return nums[-1]
```

---

# Pattern 2: XOR Pattern

## Idea

Same numbers cancel each other.

```text
a ^ a = 0
0 ^ b = b
```

Only the unique element remains.

## Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def singleNonDuplicate(nums):
    result = 0

    for num in nums:
        result ^= num

    return result
```

# Pattern 3: Binary Search on Pair Index (Most Interviewed)

## Observation

Before the unique element:

```text
Index: 0 1 2 3 4 5
Value: 1 1 2 2 3 3

Pairs start at EVEN indices.
```

After the unique element:

```text
Index: 0 1 2 3 4 5
Value: 1 1 2 3 3 4

Pair structure shifts.
```

We can use Binary Search.

---

## Key Logic

If `mid` is odd:

```python
mid -= 1
```

Now `mid` always points to first element of a pair.

Check:

```python
nums[mid] == nums[mid + 1]
```

### Case 1: Pair is Valid

```text
1 1 2 2 3 3 4 5 5

mid pair matched
=> single element lies right side
```

Move right.

### Case 2: Pair Broken

```text
1 1 2 3 3 4 4

mid pair broken
=> single element lies left side including mid
```

Move left.

---

## Complexity

* Time: O(log n)
* Space: O(1)

## Code

```python
def singleNonDuplicate(nums):
    left = 0
    right = len(nums) - 1

    while left < right:
        mid = left + (right - left) // 2

        if mid % 2 == 1:
            mid -= 1

        if nums[mid] == nums[mid + 1]:
            left = mid + 2
        else:
            right = mid

    return nums[left]
```

# Pattern 4: Binary Search Using Even/Odd Relationship

## Idea

Use parity directly.

* Even index should match next element.
* Odd index should match previous element.

If not, unique element is on the left side.

## Complexity

* Time: O(log n)
* Space: O(1)

## Code

```python
def singleNonDuplicate(nums):
    left = 0
    right = len(nums) - 1

    while left < right:
        mid = left + (right - left) // 2

        if (mid % 2 == 0 and nums[mid] == nums[mid + 1]) or \
           (mid % 2 == 1 and nums[mid] == nums[mid - 1]):
            left = mid + 1
        else:
            right = mid

    return nums[left]
```

# Pattern Comparison

| Pattern                  | Idea                | Time     | Space | Interview Value |
| ------------------------ | ------------------- | -------- | ----- | --------------- |
| Linear Scan              | Check pairs         | O(n)     | O(1)  | Low             |
| XOR                      | Cancel duplicates   | O(n)     | O(1)  | Medium          |
| Binary Search Pair Index | Pair alignment      | O(log n) | O(1)  | High            |
| Binary Search Even/Odd   | Parity-based search | O(log n) | O(1)  | High            |

# Optimized Solution

Use **Binary Search on Pair Index**.

Why?

* Exploits sorted property.
* O(log n) time.
* O(1) space.
* Expected solution in Google, Amazon, Meta, and Microsoft interviews.

```python
def singleNonDuplicate(nums):
    left = 0
    right = len(nums) - 1

    while left < right:
        mid = left + (right - left) // 2

        if mid % 2 == 1:
            mid -= 1

        if nums[mid] == nums[mid + 1]:
            left = mid + 2
        else:
            right = mid

    return nums[left]
```

### Pattern to Remember

> **Binary Search on Pair Structure**
> Whenever a **sorted array contains pairs with one abnormal element**, check whether the pair alignment is preserved. If alignment breaks, the answer lies on that side. This pattern also appears in several advanced binary-search interview problems.
