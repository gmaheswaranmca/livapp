# Palindrome Linked List

Check whether a singly linked list reads the same forward and backward.

Example:

```text
1 -> 2 -> 2 -> 1   => True
1 -> 2             => False
```

---

# Pattern 1 — Convert Linked List to Array

## Idea

* Traverse linked list
* Store values in array
* Use two pointers to check palindrome

---

## Steps

1. Traverse linked list
2. Store node values in list
3. Compare left and right values

---

## Code

```python
class Solution:
    def isPalindrome(self, head):
        arr = []

        curr = head

        while curr:
            arr.append(curr.val)
            curr = curr.next

        left = 0
        right = len(arr) - 1

        while left < right:
            if arr[left] != arr[right]:
                return False

            left += 1
            right -= 1

        return True
```

---

## Complexity

* Time: O(n)
* Space: O(n)

---

# Pattern 2 — Stack + Slow/Fast Pointer

## Idea

* Push first half into stack
* Move slow by 1, fast by 2
* Compare second half with stack

---

## Steps

1. Move slow and fast
2. Push slow values into stack
3. Skip middle node for odd length
4. Compare remaining nodes

---

## Code

```python
class Solution:
    def isPalindrome(self, head):
        stack = []

        slow = head
        fast = head

        while fast and fast.next:
            stack.append(slow.val)

            slow = slow.next
            fast = fast.next.next

        # odd length
        if fast:
            slow = slow.next

        while slow:
            top = stack.pop()

            if top != slow.val:
                return False

            slow = slow.next

        return True
```

---

## Complexity

* Time: O(n)
* Space: O(n/2)

---

# Pattern 3 — Reverse Second Half (Optimized)

## Idea

* Find middle
* Reverse second half
* Compare first and second halves

This is the most optimized interview solution.

---

## Steps

1. Find middle using slow/fast
2. Reverse second half
3. Compare both halves
4. Optional: restore linked list

---

## Visualization

### Original

```text
1 -> 2 -> 2 -> 1
```

### Find Middle

```text
1 -> 2 -> 2 -> 1
     slow
           fast
```

### Reverse Second Half

```text
First Half:   1 -> 2
Second Half:  1 -> 2
```

### Compare

```text
1 == 1
2 == 2
```

---

## Code

```python
class Solution:
    def isPalindrome(self, head):
        if not head or not head.next:
            return True

        # find middle
        slow = head
        fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # reverse second half
        prev = None

        while slow:
            nextNode = slow.next

            slow.next = prev
            prev = slow
            slow = nextNode

        # compare
        left = head
        right = prev

        while right:
            if left.val != right.val:
                return False

            left = left.next
            right = right.next

        return True
```

---

# Pattern 4 — Recursive Two Pointer

## Idea

* Go till end using recursion
* Compare while backtracking

---

## Code

```python
class Solution:
    def isPalindrome(self, head):
        self.left = head

        def dfs(right):
            if not right:
                return True

            if not dfs(right.next):
                return False

            if self.left.val != right.val:
                return False

            self.left = self.left.next

            return True

        return dfs(head)
```

---

## Complexity

* Time: O(n)
* Space: O(n) recursion stack

---

# Optimized Pattern Comparison

| Pattern             | Time | Space | Interview Value | Notes          |
| ------------------- | ---- | ----- | --------------- | -------------- |
| Array               | O(n) | O(n)  | Easy            | Simplest       |
| Stack               | O(n) | O(n)  | Medium          | Uses slow/fast |
| Reverse Second Half | O(n) | O(1)  | Very High       | Best solution  |
| Recursion           | O(n) | O(n)  | Medium          | Elegant        |

---

# Best Optimized Pattern

## Recommended

### Reverse Second Half Pattern

Why?

* O(1) extra space
* Uses important linked list concepts
* Most asked in interviews
* Clean and efficient

# Important Interview Concepts

## Slow/Fast Pointer

```python
slow = slow.next
fast = fast.next.next
```

---

## Reverse Linked List

```python
nextNode = curr.next
curr.next = prev
prev = curr
curr = nextNode
```
