# Merge Two Sorted Lists

Two sorted linked lists → merge into one sorted linked list.

Companies: Amazon, Microsoft, Adobe, Google, Oracle

---

# Pattern 1 — Iterative Merge (Dummy Node Pattern)

## Idea

* Use a dummy node.
* Compare nodes from both lists.
* Attach smaller node to result.
* Move pointer forward.

## Pattern

```text
dummy → temp

while l1 and l2:
    compare values
    attach smaller node
    move pointer

attach remaining nodes
```

## Code

```python
class Solution:
    def mergeTwoLists(self, list1, list2):
        dummy = ListNode(-1)
        tail = dummy

        while list1 and list2:

            if list1.val <= list2.val:
                tail.next = list1
                list1 = list1.next
            else:
                tail.next = list2
                list2 = list2.next

            tail = tail.next

        if list1:
            tail.next = list1
        else:
            tail.next = list2

        return dummy.next
```

## Complexity

* Time: O(n + m)
* Space: O(1)

# Pattern 2 — Recursive Merge

## Idea

* Smaller node becomes answer.
* Recursively merge remaining nodes.

## Pattern

```text
if one list empty:
    return other list

smaller node.next =
    recursive merge(...)
```

## Code

```python
class Solution:
    def mergeTwoLists(self, list1, list2):

        if not list1:
            return list2

        if not list2:
            return list1

        if list1.val <= list2.val:
            list1.next = self.mergeTwoLists(list1.next, list2)
            return list1
        else:
            list2.next = self.mergeTwoLists(list1, list2.next)
            return list2
```

## Complexity

* Time: O(n + m)
* Space: O(n + m) recursion stack

# Pattern 3 — Create New List

## Idea

* Create completely new nodes.
* Original lists remain unchanged.

## Code

```python
class Solution:
    def mergeTwoLists(self, list1, list2):

        dummy = ListNode(-1)
        tail = dummy

        while list1 and list2:

            if list1.val <= list2.val:
                tail.next = ListNode(list1.val)
                list1 = list1.next
            else:
                tail.next = ListNode(list2.val)
                list2 = list2.next

            tail = tail.next

        while list1:
            tail.next = ListNode(list1.val)
            list1 = list1.next
            tail = tail.next

        while list2:
            tail.next = ListNode(list2.val)
            list2 = list2.next
            tail = tail.next

        return dummy.next
```

## Complexity

* Time: O(n + m)
* Space: O(n + m)

# Optimized Solution Pattern Comparison

| Pattern              | Time   | Extra Space  | Best Use Case           |
| -------------------- | ------ | ------------ | ----------------------- |
| Iterative Dummy Node | O(n+m) | O(1)         | Best overall            |
| Recursive            | O(n+m) | O(n+m) stack | Elegant/simple          |
| Create New List      | O(n+m) | O(n+m)       | Preserve original lists |

# `ListNode` is the node structure used in a singly linked list.

Each node contains:

* `val` → data
* `next` → reference to next node

---

# Structure

```python
class ListNode:

    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

---

# Example Linked List

```text id="3yy3sh"
1 → 3 → 5 → None
```

Representation:

```python
node1 = ListNode(1)
node2 = ListNode(3)
node3 = ListNode(5)

node1.next = node2
node2.next = node3
```
