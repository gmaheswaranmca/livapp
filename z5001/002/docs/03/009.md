# Copy List with Random Pointer

Given a linked list where each node has:

* `next` pointer
* `random` pointer (can point to any node or `None`)

Create a **deep copy** of the list.

---

# Pattern 1 — HashMap / Dictionary Mapping

## Idea

* Create copy nodes first
* Store mapping:

```python
original_node -> copied_node
```

* Second pass:

  * connect `next`
  * connect `random`

---

## Flow

### Original

```text
A -> B -> C
|    |    |
v    v    v
C    A   None
```

### Mapping

```text
A -> A'
B -> B'
C -> C'
```

### Build links

```text
A'.next = B'
A'.random = C'
```

---

# Code

```python
class Node:
    def __init__(self, x, next=None, random=None):
        self.val = int(x)
        self.next = next
        self.random = random


class Solution:
    def copyRandomList(self, head):
        if not head:
            return None

        # old node -> new node
        copies = {}

        # pass 1: create copy nodes
        curr = head

        while curr:
            copies[curr] = Node(curr.val)
            curr = curr.next

        # pass 2: connect next/random
        curr = head

        while curr:
            copy_node = copies[curr]

            copy_node.next = copies.get(curr.next)
            copy_node.random = copies.get(curr.random)

            curr = curr.next

        return copies[head]
```

---

# Complexity

| Metric | Value |
| ------ | ----- |
| Time   | O(n)  |
| Space  | O(n)  |

# Pattern 2 — Interleaving Nodes (Optimal)

## Core Idea

Insert copied nodes inside original list.

---

## Step 1 — Insert copy nodes

### Before

```text
A -> B -> C
```

### After

```text
A -> A' -> B -> B' -> C -> C'
```

---

## Step 2 — Connect random pointers

If:

```text
A.random = C
```

Then:

```text
A'.random = C'
```

How?

```python
curr.next.random = curr.random.next
```

Because:

* `curr.next` = copied node
* `curr.random.next` = copied random node

---

## Step 3 — Separate lists

### Final

```text
Original: A -> B -> C

Copy:     A' -> B' -> C'
```

---

# Code

```python
class Node:
    def __init__(self, x, next=None, random=None):
        self.val = int(x)
        self.next = next
        self.random = random


class Solution:
    def copyRandomList(self, head):
        if not head:
            return None

        # STEP 1: insert copied nodes
        curr = head

        while curr:
            next_node = curr.next

            copy_node = Node(curr.val)

            curr.next = copy_node
            copy_node.next = next_node

            curr = next_node

        # STEP 2: connect random pointers
        curr = head

        while curr:
            if curr.random:
                curr.next.random = curr.random.next

            curr = curr.next.next

        # STEP 3: separate lists
        curr = head

        copy_head = head.next

        while curr:
            copy_node = curr.next
            next_original = copy_node.next

            curr.next = next_original

            if next_original:
                copy_node.next = next_original.next

            curr = next_original

        return copy_head
```

---

# Complexity

| Metric | Value      |
| ------ | ---------- |
| Time   | O(n)       |
| Space  | O(1) extra |

# Pattern Comparison

| Pattern      | Time | Space | Interview Preference |
| ------------ | ---- | ----- | -------------------- |
| HashMap      | O(n) | O(n)  | Easier               |
| Interleaving | O(n) | O(1)  | Most Preferred       |

# Optimized Solution

## Best Pattern

✅ Interleaving Nodes Pattern

Reason:

* O(1) extra space
* Elegant pointer manipulation
* Most commonly expected in interviews

---

# Key Interview Insight

Main trick:

```python
copy.random = original.random.next
```

because copied nodes are inserted immediately after originals.

# Important Pointer Pattern

## Traversing copied-interleaved list

```python
curr = curr.next.next
```

because structure is:

```text
original -> copy -> original -> copy
```

# Frequently Asked Interview Follow-up

## Why deep copy?

Because:

* copied nodes must be completely independent
* changing original list should NOT affect copied list

Example:

```python
original.val = 100
```

Copied list remains unchanged.
