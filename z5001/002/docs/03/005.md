# Linked List Cycle II

Detect the node where the cycle begins in a linked list.

---

# Pattern 1 — HashSet / Visited Nodes

## Idea

Store visited nodes in a set.

* Traverse the linked list.
* If a node is already visited → that node is the cycle start.
* Else add node to set.

---

## Visualization

```text
1 → 2 → 3 → 4 → 5
          ↑     ↓
          ← ← ←
```

Traversal:

```text
visit 1
visit 2
visit 3
visit 4
visit 5
visit 3 again → cycle starts at 3
```

---

## Complexity

* Time: O(N)
* Space: O(N)

---

## Code

```python
class Solution:
    def detectCycle(self, head):
        visited = set()

        current = head

        while current:
            if current in visited:
                return current

            visited.add(current)
            current = current.next

        return None
```

# Pattern 2 — Floyd’s Cycle Detection (Tortoise & Hare)

## Core Idea

Two phases:

### Phase 1 — Detect cycle

* slow moves 1 step
* fast moves 2 steps

If they meet → cycle exists.

---

### Phase 2 — Find cycle start

Move one pointer to head.

Now:

* one pointer starts from head
* another starts from meeting point
* both move 1 step

Where they meet again = cycle start.

---

# Why Does This Work?

Suppose:

```text
L = distance from head to cycle start
C = cycle length
x = distance from cycle start to meeting point
```

When slow and fast meet:

```text
2(L + x) = L + x + nC
```

Simplifies to:

```text
L + x = nC
```

So:

```text
L = nC - x
```

Meaning:

```text
distance from head to cycle start
=
distance from meeting point to cycle start
```

Hence both pointers meet at cycle start.

---

# Visualization

## Example

```text
1 → 2 → 3 → 4 → 5
          ↑     ↓
          ← ← ←
```

Cycle starts at `3`.

---

## Phase 1

```text
slow = 1
fast = 1

slow = 2
fast = 3

slow = 3
fast = 5

slow = 4
fast = 4
```

Meeting point = 4

---

## Phase 2

Move one pointer to head.

```text
ptr1 = 1
ptr2 = 4
```

Move both 1 step:

```text
ptr1 = 2
ptr2 = 5

ptr1 = 3
ptr2 = 3
```

Cycle starts at node `3`.

---

## Complexity

* Time: O(N)
* Space: O(1)

---

## Code

```python
class Solution:
    def detectCycle(self, head):
        slow = head
        fast = head

        # Phase 1: Detect cycle
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                break
        else:
            return None

        # Phase 2: Find cycle start
        ptr1 = head
        ptr2 = slow

        while ptr1 != ptr2:
            ptr1 = ptr1.next
            ptr2 = ptr2.next

        return ptr1
```

# Final Optimized Code

```python
class Solution:
    def detectCycle(self, head):
        slow = head
        fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                ptr = head

                while ptr != slow:
                    ptr = ptr.next
                    slow = slow.next

                return ptr

        return None
```
