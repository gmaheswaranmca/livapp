# Intersection of Two Linked Lists

Find the node where two singly linked lists intersect.

---

# Pattern 1 — Brute Force

## Idea

For every node in List A, traverse List B and compare nodes.

## Approach

* Pick one node from A
* Traverse all nodes in B
* If same node reference found → intersection

## Time Complexity

* Time: `O(M * N)`
* Space: `O(1)`

## Code

```python
class Solution:
    def getIntersectionNode(self, headA, headB):
        a = headA
        
        while a:
            b = headB
            
            while b:
                if a == b:
                    return a
                b = b.next
                
            a = a.next
            
        return None
```

---

# Pattern 2 — Hash Set

## Idea

Store all nodes of one linked list in a set.

## Approach

* Store all nodes from List A
* Traverse List B
* First matching node is intersection

## Time Complexity

* Time: `O(M + N)`
* Space: `O(M)`

## Code

```python
class Solution:
    def getIntersectionNode(self, headA, headB):
        visited = set()
        
        curr = headA
        
        while curr:
            visited.add(curr)
            curr = curr.next
            
        curr = headB
        
        while curr:
            if curr in visited:
                return curr
                
            curr = curr.next
            
        return None
```

# Pattern 3 — Length Difference Alignment

## Idea

Align both lists before traversal.

## Approach

* Find lengths of both lists
* Move longer list ahead by difference
* Traverse together
* First equal node is answer

## Time Complexity

* Time: `O(M + N)`
* Space: `O(1)`

## Code

```python
class Solution:
    
    def getLength(self, head):
        length = 0
        
        while head:
            length += 1
            head = head.next
            
        return length
    
    def getIntersectionNode(self, headA, headB):
        
        lenA = self.getLength(headA)
        lenB = self.getLength(headB)
        
        a = headA
        b = headB
        
        if lenA > lenB:
            diff = lenA - lenB
            
            while diff:
                a = a.next
                diff -= 1
                
        else:
            diff = lenB - lenA
            
            while diff:
                b = b.next
                diff -= 1
        
        while a and b:
            if a == b:
                return a
                
            a = a.next
            b = b.next
            
        return None
```

# Pattern 4 — Two Pointer Switching (Optimized)

## Idea

Both pointers traverse equal total distance.

## Core Trick

When a pointer reaches end:

* redirect it to other list head

Eventually:

* both pointers meet at intersection
* or both become `None`

---

## Visualization

```text
List A: 1 → 2 → 3 → 8 → 9
List B: 4 → 5 → 8 → 9

Pointer Flow:

a: 1 → 2 → 3 → 8 → 9 → None → 4 → 5 → 8
b: 4 → 5 → 8 → 9 → None → 1 → 2 → 3 → 8
```

Both travel:

```text
lenA + lenB
```

So alignment happens automatically.

---

## Time Complexity

* Time: `O(M + N)`
* Space: `O(1)`

---

## Optimized Code

```python
class Solution:
    def getIntersectionNode(self, headA, headB):
        
        a = headA
        b = headB
        
        while a != b:
            
            if a:
                a = a.next
            else:
                a = headB
                
            if b:
                b = b.next
            else:
                b = headA
                
        return a
```

---

# Most Optimized Pattern

## Best Choice

Pattern 4 — Two Pointer Switching

## Why?

* No extra space
* No length calculation
* Elegant logic
* Most asked in interviews
* Cleanest implementation

---

# Pattern Comparison

| Pattern               | Time   | Space | Interview Value |
| --------------------- | ------ | ----- | --------------- |
| Brute Force           | O(M×N) | O(1)  | Low             |
| Hash Set              | O(M+N) | O(M)  | Medium          |
| Length Alignment      | O(M+N) | O(1)  | High            |
| Two Pointer Switching | O(M+N) | O(1)  | Very High       |

---

# Interview Tip

Intersection means:

```python
a == b
```

NOT:

```python
a.val == b.val
```

Because:

* intersection is based on node reference
* not node value.
