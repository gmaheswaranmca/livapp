# Add Two Numbers

Two non-empty linked lists represent two non-negative integers.
Digits are stored in reverse order.
Each node contains a single digit.

Return the sum as a linked list.

Example:

```text
l1 = 2 -> 4 -> 3
l2 = 5 -> 6 -> 4

Result:
7 -> 0 -> 8

Explanation:
342 + 465 = 807
```

---

# Core Idea

Simulate elementary-school addition:

```text
digit1 + digit2 + carry
```

At every node:

```text
sum = x + y + carry
digit = sum % 10
carry = sum // 10
```

---

# Pattern 1 — Iterative Simulation (Most Common)

## Pattern

* Traverse both lists together
* Add digits + carry
* Create new node for result digit
* Move forward
* Finally handle leftover carry

---

## Visualization

```text
l1 : 2 -> 4 -> 3
l2 : 5 -> 6 -> 4

Step 1:
2 + 5 + 0 = 7
carry = 0

Result:
7

Step 2:
4 + 6 + 0 = 10
digit = 0
carry = 1

Result:
7 -> 0

Step 3:
3 + 4 + 1 = 8
carry = 0

Result:
7 -> 0 -> 8
```

---

## Code

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def addTwoNumbers(self, l1, l2):
        dummy = ListNode()
        current = dummy

        carry = 0

        while l1 or l2 or carry:

            x = l1.val if l1 else 0
            y = l2.val if l2 else 0

            total = x + y + carry

            carry = total // 10
            digit = total % 10

            current.next = ListNode(digit)

            current = current.next

            if l1:
                l1 = l1.next

            if l2:
                l2 = l2.next

        return dummy.next
```

---

## Complexity

| Metric | Value       |
| ------ | ----------- |
| Time   | O(max(m,n)) |
| Space  | O(max(m,n)) |

# Pattern 2 — Recursive Addition

## Pattern

Use recursion for:

* adding nodes
* forwarding carry

---

## Code

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:

    def add(self, l1, l2, carry):

        if not l1 and not l2 and carry == 0:
            return None

        x = l1.val if l1 else 0
        y = l2.val if l2 else 0

        total = x + y + carry

        carry = total // 10
        digit = total % 10

        node = ListNode(digit)

        next1 = l1.next if l1 else None
        next2 = l2.next if l2 else None

        node.next = self.add(next1, next2, carry)

        return node


    def addTwoNumbers(self, l1, l2):
        return self.add(l1, l2, 0)
```

---

## Complexity

| Metric | Value                       |
| ------ | --------------------------- |
| Time   | O(max(m,n))                 |
| Space  | O(max(m,n)) recursion stack |

# Pattern 3 — Convert to Integer (Not Preferred)

## Pattern

* Convert linked lists → integers
* Add numbers
* Convert back to linked list

---

## Why Avoid?

Problems:

* Integer overflow in some languages
* Extra conversions
* Not scalable
* Interviewers usually expect linked list simulation

---

## Code

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:

    def toNumber(self, node):

        num = 0
        place = 1

        while node:
            num += node.val * place
            place *= 10
            node = node.next

        return num


    def toList(self, num):

        if num == 0:
            return ListNode(0)

        dummy = ListNode()
        current = dummy

        while num > 0:

            digit = num % 10

            current.next = ListNode(digit)

            current = current.next

            num //= 10

        return dummy.next


    def addTwoNumbers(self, l1, l2):

        n1 = self.toNumber(l1)
        n2 = self.toNumber(l2)

        return self.toList(n1 + n2)
```

## Best Pattern

✅ Iterative Simulation

# Why Iterative is Optimal

| Feature               | Iterative | Recursive | Convert to Integer |
| --------------------- | --------- | --------- | ------------------ |
| Easy to understand    | ✅         | Medium    | ✅                  |
| Interview preferred   | ✅         | Medium    | ❌                  |
| Extra recursion stack | ❌         | ✅         | ❌                  |
| Handles huge inputs   | ✅         | Risky     | Risky              |
| Space efficient       | ✅         | ❌         | ❌                  |
| Production friendly   | ✅         | Medium    | ❌                  |

# Important Interview Observations

## 1. Use Dummy Node

Simplifies:

* head handling
* first insertion

```python
dummy = ListNode()
current = dummy
```

---

## 2. Loop Condition

Very important:

```python
while l1 or l2 or carry:
```

Handles:

* unequal lengths
* final carry

Example:

```text
9 -> 9
1

Result:
0 -> 0 -> 1
```

---

## 3. Missing Nodes Become Zero

```python
x = l1.val if l1 else 0
```

This avoids:

* null errors
* multiple edge cases

---

# Follow-Up Variant

Sometimes digits are stored in forward order:

```text
7 -> 2 -> 4 -> 3
5 -> 6 -> 4
```

That problem usually requires:

* stacks
  OR
* reversing linked lists

(LeetCode: Add Two Numbers II)

---

# Final Recommendation

For interviews:

1. Learn Iterative Pattern first
2. Then Recursive Pattern
3. Avoid Integer Conversion in interviews unless explicitly allowed
