# Reverse Linked List

Reverse a singly linked list iteratively or recursively.

Companies: Amazon, Google, Meta, Microsoft, Apple
Difficulty: Easy

---

# Pattern 1: Iterative Pointer Reversal (Most Optimized)

## Pattern

* Maintain:

  * `prev`
  * `curr`
  * `next_node`
* Reverse links one by one.

## Why Best

* O(1) extra space
* Simple
* Most asked in interviews
* No recursion stack overhead

---

## Code

```python
class Solution:
    def reverseList(self, head):
        prev = None
        curr = head

        while curr:
            next_node = curr.next
            curr.next = prev

            prev = curr
            curr = next_node

        return prev
```

---

## Dry Run

Original:

```text
1 -> 2 -> 3 -> None
```

Step 1:

```text
1 -> None
prev = 1
curr = 2
```

Step 2:

```text
2 -> 1 -> None
prev = 2
curr = 3
```

Step 3:

```text
3 -> 2 -> 1 -> None
```

Return `prev`.

---

## Complexity

Time:

```text
O(n)
```

Space:

```text
O(1)
```

# Pattern 2: Recursive Reversal

## Pattern

* Reverse remaining list recursively
* Attach current node at end

---

## Code

```python
class Solution:
    def reverseList(self, head):

        if not head or not head.next:
            return head

        new_head = self.reverseList(head.next)

        head.next.next = head
        head.next = None

        return new_head
```

---

## Key Logic

```python
head.next.next = head
```

Makes:

```text
2 -> 1
```

after recursive reversal.

---

## Complexity

Time:

```text
O(n)
```

Space:

```text
O(n)
```

(recursion stack)

---

# Pattern 3: Stack Based Reversal

## Pattern

* Push all nodes into stack
* Pop and reconnect

---

## Code

```python
class Solution:
    def reverseList(self, head):

        if not head:
            return None

        stack = []

        curr = head

        while curr:
            stack.append(curr)
            curr = curr.next

        new_head = stack.pop()
        curr = new_head

        while stack:
            curr.next = stack.pop()
            curr = curr.next

        curr.next = None

        return new_head
```

---

## Complexity

Time:

```text
O(n)
```

Space:

```text
O(n)
```

# Optimized Pattern Comparison

| Pattern                    | Time | Space | Interview Preference | Notes                  |
| -------------------------- | ---- | ----- | -------------------- | ---------------------- |
| Iterative Pointer Reversal | O(n) | O(1)  | Highest              | Best solution          |
| Recursive                  | O(n) | O(n)  | High                 | Elegant but stack used |
| Stack Based                | O(n) | O(n)  | Medium               | Extra memory           |

---

# Most Optimized Pattern

## Use:

```text
Iterative Pointer Reversal
```

## Why

* Constant space
* Fastest practical approach
* Standard interview expectation
* Simple pointer manipulation pattern

---

# Core Interview Pattern

```python
next_node = curr.next
curr.next = prev
prev = curr
curr = next_node
```

This is the main linked list reversal template used in:

* Reverse Between
* Reverse K Group
* Palindrome Linked List
* Reorder List
* Reverse Nodes in Even Length Groups
