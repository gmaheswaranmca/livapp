# Linked List Cycle

Detect whether a linked list contains a cycle using fast and slow pointers.

Companies: Amazon, Meta, Microsoft, Google, Bloomberg
Difficulty: Easy

---

# Solution Patterns

## 1. Hash Set Pattern

### Idea

Store visited nodes in a set.
If a node appears again → cycle exists.

---

### Pattern

* Traverse node by node
* Store node reference in set
* If node already exists in set → return True

---

### Code

```python
class Solution:
    def hasCycle(self, head):
        visited = set()

        current = head

        while current:
            if current in visited:
                return True

            visited.add(current)
            current = current.next

        return False
```

---

### Complexity

* Time: O(n)
* Space: O(n)

---

# 2. Fast & Slow Pointer Pattern (Floyd Cycle Detection)

### Idea

* slow moves 1 step
* fast moves 2 steps
* If cycle exists → they meet
* If fast reaches None → no cycle

---

### Pattern

* Initialize slow and fast
* Move until fast or fast.next becomes None
* If slow == fast → cycle detected

---

### Code

```python
class Solution:
    def hasCycle(self, head):
        slow = head
        fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                return True

        return False
```

---

### Complexity

* Time: O(n)
* Space: O(1)

---

# 3. Mark Visited Node Pattern (Modify Node)

### Idea

Modify node value/reference temporarily to mark visited.

Rarely used because it changes original linked list.

---

### Code

```python
class Solution:
    def hasCycle(self, head):
        current = head

        while current:
            if current.val == "visited":
                return True

            current.val = "visited"
            current = current.next

        return False
```

---

### Complexity

* Time: O(n)
* Space: O(1)

---

# Optimized Solution Pattern

## Best Pattern

✅ Floyd Fast & Slow Pointer

Why:

* O(1) space
* Most asked in interviews
* Elegant mathematical approach
* No modification to linked list

---

# Optimized Code

```python
class Solution:
    def hasCycle(self, head):
        slow = head
        fast = head

        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

            if slow == fast:
                return True

        return False
```

---

# Important Interview Note

If asked:

> "Find where cycle starts"

Then use Floyd Cycle Detection extension:

1. Detect meeting point
2. Move one pointer to head
3. Move both 1 step
4. Meeting point = cycle start
