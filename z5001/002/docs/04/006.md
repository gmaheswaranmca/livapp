# Next Greater Element I (LeetCode 496)

**Problem:**
Given two arrays `nums1` and `nums2`, for each element in `nums1`, find its next greater element in `nums2`.

The **next greater element** of an element `x` is the first element greater than `x` that appears to its right in `nums2`. If none exists, return `-1`.

### Example

```text
nums1 = [4,1,2]
nums2 = [1,3,4,2]

Output: [-1,3,-1]
```

---

# Solution Patterns

## Pattern 1: Brute Force Search

### Idea

For every element in `nums1`:

1. Find its position in `nums2`.
2. Scan right until a greater element is found.

### Time Complexity

* Finding position: O(n)
* Scanning right: O(n)
* Total: O(m × n)

### Space Complexity

* O(1)

### Code

```python
class Solution:
    def nextGreaterElement(self, nums1, nums2):
        result = []

        for num in nums1:
            idx = nums2.index(num)

            next_greater = -1
            for j in range(idx + 1, len(nums2)):
                if nums2[j] > num:
                    next_greater = nums2[j]
                    break

            result.append(next_greater)

        return result
```

# Pattern 2: Preprocessing with HashMap

### Idea

For every element in `nums2`:

* Scan right and find next greater.
* Store result in dictionary.

Then answer queries from `nums1`.

### Time Complexity

* O(n²)

### Space Complexity

* O(n)

### Code

```python
class Solution:
    def nextGreaterElement(self, nums1, nums2):
        nge = {}

        for i in range(len(nums2)):
            nge[nums2[i]] = -1

            for j in range(i + 1, len(nums2)):
                if nums2[j] > nums2[i]:
                    nge[nums2[i]] = nums2[j]
                    break

        return [nge[num] for num in nums1]
```

# Pattern 3: Monotonic Decreasing Stack (Optimal)

### Core Observation

When processing `nums2`:

If current element is greater than stack top:

```text
stack top --> found next greater element
```

Store the mapping immediately.

### Example

```text
nums2 = [1,3,4,2]

Stack = []

1 → push

Stack = [1]

3 > 1
NGE[1] = 3

Stack = [3]

4 > 3
NGE[3] = 4

Stack = [4]

2 < 4
push

Stack = [4,2]
```

Remaining stack elements:

```text
4 → -1
2 → -1
```

Result:

```text
{
 1:3,
 3:4,
 4:-1,
 2:-1
}
```

---

### Time Complexity

```text
O(n + m)
```

Each element enters and leaves stack once.

### Space Complexity

```text
O(n)
```

---

### Code

```python
class Solution:
    def nextGreaterElement(self, nums1, nums2):
        stack = []
        nge = {}

        for num in nums2:

            while stack and num > stack[-1]:
                smaller = stack.pop()
                nge[smaller] = num

            stack.append(num)

        while stack:
            nge[stack.pop()] = -1

        return [nge[num] for num in nums1]
```

# Pattern 4: Reverse Traversal + Monotonic Stack

### Idea

Traverse from right to left.

Maintain a decreasing stack.

For each element:

```text
Remove smaller elements.
Stack top becomes next greater element.
```

### Time Complexity

```text
O(n + m)
```

### Space Complexity

```text
O(n)
```

### Code

```python
class Solution:
    def nextGreaterElement(self, nums1, nums2):
        stack = []
        nge = {}

        for num in reversed(nums2):

            while stack and stack[-1] <= num:
                stack.pop()

            nge[num] = stack[-1] if stack else -1

            stack.append(num)

        return [nge[num] for num in nums1]
```
