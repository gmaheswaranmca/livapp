# Next Greater Element II (Circular Array)

**Problem:**
Given a circular integer array `nums`, return an array `answer` where `answer[i]` is the first greater number to the right of `nums[i]`. Since the array is circular, the search wraps around to the beginning.

**Example**

```text
Input:  nums = [1,2,1]
Output: [2,-1,2]
```

---

# Pattern 1: Brute Force Circular Traversal

## Idea

For every element, move forward up to `n-1` positions circularly and find the first greater element.

## Algorithm

1. For each index `i`
2. Check next elements circularly.
3. Stop when greater element is found.
4. Otherwise return `-1`.

## Code

```python
class Solution:
    def nextGreaterElements(self, nums):
        n = len(nums)
        result = [-1] * n

        for i in range(n):
            for j in range(1, n):
                idx = (i + j) % n
                if nums[idx] > nums[i]:
                    result[i] = nums[idx]
                    break

        return result
```

## Complexity

* Time: O(n²)
* Space: O(1) extra

---

# Pattern 2: Monotonic Stack + Simulate Circular Array

## Idea

Use a **decreasing monotonic stack** storing indices.

Since the array is circular:

* Traverse array twice (`2*n` iterations).
* Use `i % n` to simulate circular movement.
* During second traversal, unresolved elements can find greater values from beginning.

---

## Visualization

```text
nums = [1,2,1]

Traversal:

i=0 -> 1
stack=[0]

i=1 -> 2
2 > 1
answer[0]=2

stack=[1]

i=2 -> 1
stack=[1,2]

Second pass:

i=3 -> nums[0]=1

i=4 -> nums[1]=2
2 > nums[2]
answer[2]=2

Result:
[2,-1,2]
```

---

## Code

```python
class Solution:
    def nextGreaterElements(self, nums):
        n = len(nums)
        result = [-1] * n
        stack = []

        for i in range(2 * n):
            current = nums[i % n]

            while stack and nums[stack[-1]] < current:
                idx = stack.pop()
                result[idx] = current

            if i < n:
                stack.append(i)

        return result
```

---

## Complexity

* Time: O(n)
* Space: O(n)

---

# Pattern 3: Reverse Traversal Monotonic Stack

## Idea

Process from right to left twice.

Maintain stack of potential next greater elements.

For each element:

* Remove smaller/equal values.
* Top of stack becomes next greater.
* Push current value.

---

## Code

```python
class Solution:
    def nextGreaterElements(self, nums):
        n = len(nums)
        result = [-1] * n
        stack = []

        for i in range(2 * n - 1, -1, -1):
            current = nums[i % n]

            while stack and stack[-1] <= current:
                stack.pop()

            if i < n:
                result[i] = stack[-1] if stack else -1

            stack.append(current)

        return result
```

---

## Complexity

* Time: O(n)
* Space: O(n)

# Why Monotonic Stack Works

Maintain a stack where elements are in **decreasing order**.

```text
Stack:
[7,5,3]

Current = 6

Pop 3
Pop 5

Next greater for 5 and 3 is 6
```

Each element:

* Pushed once
* Popped once

Therefore:

```text
Total operations ≤ 2N
Time = O(N)
```

---

# Optimized Interview Pattern

Use **Forward Monotonic Stack with Double Traversal**.

```python
class Solution:
    def nextGreaterElements(self, nums):
        n = len(nums)
        result = [-1] * n
        stack = []

        for i in range(2 * n):
            while stack and nums[stack[-1]] < nums[i % n]:
                result[stack.pop()] = nums[i % n]

            if i < n:
                stack.append(i)

        return result
```

### Why this is optimal

* Handles circular array naturally.
* Single monotonic stack.
* O(n) time.
* Most commonly expected in Amazon, Google, Meta, Microsoft, and Bloomberg interviews.
* Standard template for circular next-greater-element problems.
