# Evaluate Reverse Polish Notation (RPN)

**LeetCode 150 – Medium**

Given an array of strings representing a postfix (Reverse Polish Notation) expression, evaluate its value.

Example:

```text
Input: ["2","1","+","3","*"]

Postfix:
(2 + 1) * 3

Output: 9
```

---

# Pattern 1: Stack Simulation (Standard Approach)

## Idea

* Numbers → push onto stack.
* Operator → pop top two operands.
* Apply operation.
* Push result back.
* Final stack element is the answer.

---

## Algorithm

```text
for token in tokens:
    if token is number:
        push(token)
    else:
        b = pop()
        a = pop()

        result = a op b

        push(result)

return stack[0]
```

---

## Example

```text
tokens = ["2","1","+","3","*"]

Stack:

2      -> [2]
1      -> [2,1]
+      -> [3]
3      -> [3,3]
*      -> [9]

Answer = 9
```

---

## Python Code

```python
class Solution:
    def evalRPN(self, tokens):
        stack = []

        for token in tokens:
            if token not in "+-*/":
                stack.append(int(token))
            else:
                b = stack.pop()
                a = stack.pop()

                if token == "+":
                    stack.append(a + b)

                elif token == "-":
                    stack.append(a - b)

                elif token == "*":
                    stack.append(a * b)

                else:
                    stack.append(int(a / b))

        return stack[-1]
```

---

## Complexity

| Metric | Value |
| ------ | ----- |
| Time   | O(n)  |
| Space  | O(n)  |

# Pattern 2: Stack + Operator Dictionary

## Idea

Use a lookup table for operators.

---

## Python Code

```python
class Solution:
    def evalRPN(self, tokens):
        stack = []

        ops = {
            "+": lambda a, b: a + b,
            "-": lambda a, b: a - b,
            "*": lambda a, b: a * b,
            "/": lambda a, b: int(a / b)
        }

        for token in tokens:
            if token in ops:
                b = stack.pop()
                a = stack.pop()
                stack.append(ops[token](a, b))
            else:
                stack.append(int(token))

        return stack[-1]
```

---

## Complexity

```text
Time  : O(n)
Space : O(n)
```

---

# Pattern 3: Recursive Evaluation

## Idea

Process tokens from the end.

When:

* Number → return it.
* Operator → recursively evaluate right operand.
* Recursively evaluate left operand.

---

## Python Code

```python
class Solution:
    def evalRPN(self, tokens):

        def solve():
            token = tokens.pop()

            if token not in "+-*/":
                return int(token)

            right = solve()
            left = solve()

            if token == "+":
                return left + right
            elif token == "-":
                return left - right
            elif token == "*":
                return left * right
            else:
                return int(left / right)

        return solve()
```

---

## Complexity

```text
Time  : O(n)
Space : O(n)
```

(Call stack contributes to space.)

# Optimized Solution Pattern

### Use: Stack Simulation

Reason:

1. Natural fit for postfix expressions.
2. Single pass.
3. No recursion overhead.
4. Easy to explain in interviews.
5. Industry-standard solution used by Amazon, Google, Microsoft, Apple, and LinkedIn.

## Recommended Code

```python
class Solution:
    def evalRPN(self, tokens):
        stack = []

        for token in tokens:
            if token not in "+-*/":
                stack.append(int(token))
            else:
                b = stack.pop()
                a = stack.pop()

                if token == "+":
                    stack.append(a + b)
                elif token == "-":
                    stack.append(a - b)
                elif token == "*":
                    stack.append(a * b)
                else:
                    # truncate toward zero
                    stack.append(int(a / b))

        return stack[-1]
```

