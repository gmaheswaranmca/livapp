# Daily Temperatures (LeetCode 739)

**Problem:**
Given an array `temperatures`, return an array `answer` such that `answer[i]` is the number of days you have to wait after the `i-th` day to get a warmer temperature. If there is no future warmer day, keep `0`.

### Example

```text
Input:  [73,74,75,71,69,72,76,73]
Output: [1,1,4,2,1,1,0,0]
```

---

# Pattern 1: Brute Force (Nested Loops)

## Idea

For each day, scan all future days until a warmer temperature is found.

## Algorithm

1. For each index `i`
2. Check every `j > i`
3. If `temperatures[j] > temperatures[i]`

   * Store `j - i`
   * Stop searching

## Code

```python
class Solution:
    def dailyTemperatures(self, temperatures):
        n = len(temperatures)
        ans = [0] * n

        for i in range(n):
            for j in range(i + 1, n):
                if temperatures[j] > temperatures[i]:
                    ans[i] = j - i
                    break

        return ans
```

## Complexity

* Time: O(n²)
* Space: O(1) extra

---

# Pattern 2: Reverse Traversal + Jumping DP

## Idea

Process from right to left.

Use previously computed answers to skip unnecessary comparisons.

## Algorithm

1. Traverse from right to left.
2. If current temperature is not less than next temperature:

   * Jump using previously computed distances.
3. Continue until warmer day found.

## Code

```python
class Solution:
    def dailyTemperatures(self, temperatures):
        n = len(temperatures)
        ans = [0] * n

        for i in range(n - 2, -1, -1):
            j = i + 1

            while j < n:
                if temperatures[j] > temperatures[i]:
                    ans[i] = j - i
                    break

                if ans[j] == 0:
                    break

                j += ans[j]

        return ans
```

## Complexity

* Time: O(n) average, can degrade
* Space: O(1) extra

# Pattern 3: Monotonic Decreasing Stack (Standard Solution)

## Pattern

**Next Greater Element**

A stack stores indices of temperatures in decreasing order.

## Idea

When a higher temperature arrives:

* Pop colder days from stack.
* Calculate waiting days.
* Push current index.

### Visualization

```text
Temps = [73,74,75,71,69,72,76,73]

Stack stores indices

73 -> push [0]

74 > 73
answer[0] = 1
push [1]

75 > 74
answer[1] = 1
push [2]

71 < 75
push [2,3]

69 < 71
push [2,3,4]

72 > 69
answer[4] = 1

72 > 71
answer[3] = 2

push [2,5]

76 > 72
answer[5] = 1

76 > 75
answer[2] = 4
```

---

## Algorithm

1. Initialize empty stack.
2. Traverse temperatures.
3. While stack not empty and current temperature is warmer:

   * Pop index.
   * Compute distance.
4. Push current index.
5. Remaining indices get answer `0`.

---

## Code

```python
class Solution:
    def dailyTemperatures(self, temperatures):
        n = len(temperatures)
        ans = [0] * n
        stack = []

        for i, temp in enumerate(temperatures):

            while stack and temp > temperatures[stack[-1]]:
                prev_index = stack.pop()
                ans[prev_index] = i - prev_index

            stack.append(i)

        return ans
```

## Complexity

* Time: O(n)
* Space: O(n)

# Pattern 4: Reverse Monotonic Stack

## Idea

Traverse from right to left.

Maintain stack of warmer candidates.

## Code

```python
class Solution:
    def dailyTemperatures(self, temperatures):
        n = len(temperatures)
        ans = [0] * n
        stack = []

        for i in range(n - 1, -1, -1):

            while stack and temperatures[stack[-1]] <= temperatures[i]:
                stack.pop()

            if stack:
                ans[i] = stack[-1] - i

            stack.append(i)

        return ans
```

## Complexity

* Time: O(n)
* Space: O(n)

# Optimized Solution

✅ **Monotonic Decreasing Stack (Forward Traversal)**

Reason:

* True O(n)
* Most intuitive
* Standard interview solution
* Direct application of Next Greater Element pattern
* Expected by Amazon, Google, Meta, Microsoft, Bloomberg

```python
class Solution:
    def dailyTemperatures(self, temperatures):
        ans = [0] * len(temperatures)
        stack = []

        for i, temp in enumerate(temperatures):
            while stack and temp > temperatures[stack[-1]]:
                idx = stack.pop()
                ans[idx] = i - idx

            stack.append(i)

        return ans
```

### Final Complexity

* **Time:** O(n)
* **Space:** O(n)

**Interview Pattern:** Monotonic Decreasing Stack → Next Greater Element.
