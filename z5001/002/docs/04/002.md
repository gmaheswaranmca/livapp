# Min Stack (LeetCode 155)

**Problem:**
Design a stack that supports:

* `push(x)`
* `pop()`
* `top()`
* `getMin()`

All operations must work in **O(1)** time.

---

# Pattern Analysis

## Pattern 1: Brute Force

### Idea

Store all elements in a stack.

Whenever `getMin()` is called, scan the entire stack.

### Operations

| Operation | Time |
| --------- | ---- |
| push      | O(1) |
| pop       | O(1) |
| top       | O(1) |
| getMin    | O(n) |

### Code

```python
class MinStack:

    def __init__(self):
        self.stack = []

    def push(self, val):
        self.stack.append(val)

    def pop(self):
        self.stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return min(self.stack)
```

### Drawback

`getMin()` violates O(1) requirement.

---

# Pattern 2: Two Stack Pattern

## Most Common Interview Solution

### Idea

Maintain:

1. Normal stack
2. Min stack

Min stack stores the minimum seen so far.

### Example

```text
push(5)

stack     = [5]
minStack  = [5]

push(3)

stack     = [5,3]
minStack  = [5,3]

push(7)

stack     = [5,3,7]
minStack  = [5,3,3]
```

### Operations

| Operation | Time |
| --------- | ---- |
| push      | O(1) |
| pop       | O(1) |
| top       | O(1) |
| getMin    | O(1) |

### Code

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.minStack = []

    def push(self, val):
        self.stack.append(val)

        if not self.minStack:
            self.minStack.append(val)
        else:
            self.minStack.append(
                min(val, self.minStack[-1])
            )

    def pop(self):
        self.stack.pop()
        self.minStack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.minStack[-1]
```

### Complexity

```text
Time  : O(1)
Space : O(n)
```

# Pattern 3: Pair Storage Pattern

### Idea

Store:

```python
(value, current_min)
```

at every position.

### Example

```text
push(5) -> (5,5)
push(3) -> (3,3)
push(7) -> (7,3)
```

### Stack

```text
[
 (5,5),
 (3,3),
 (7,3)
]
```

### Code

```python
class MinStack:

    def __init__(self):
        self.stack = []

    def push(self, val):

        if not self.stack:
            current_min = val
        else:
            current_min = min(
                val,
                self.stack[-1][1]
            )

        self.stack.append(
            (val, current_min)
        )

    def pop(self):
        self.stack.pop()

    def top(self):
        return self.stack[-1][0]

    def getMin(self):
        return self.stack[-1][1]
```

### Complexity

```text
Time  : O(1)
Space : O(n)
```

# Pattern 4: Encoded Minimum Trick

### Idea

Store modified values when a new minimum arrives.

Used to achieve:

```text
One stack only
O(1) getMin
```

### Formula

When new minimum comes:

```python
encoded = 2*val - minVal
```

Update:

```python
minVal = val
```

### Recovery

If popped value is encoded:

```python
oldMin = 2*minVal - encoded
```

### Code

```python
class MinStack:

    def __init__(self):
        self.stack = []
        self.minVal = None

    def push(self, val):

        if not self.stack:
            self.stack.append(val)
            self.minVal = val

        elif val < self.minVal:

            self.stack.append(
                2 * val - self.minVal
            )

            self.minVal = val

        else:
            self.stack.append(val)

    def pop(self):

        top = self.stack.pop()

        if top < self.minVal:
            self.minVal = (
                2 * self.minVal - top
            )

    def top(self):

        top = self.stack[-1]

        if top < self.minVal:
            return self.minVal

        return top

    def getMin(self):
        return self.minVal
```

### Complexity

```text
Time  : O(1)
Space : O(n)
```

### Drawback

Harder to understand and explain in interviews.

# Pattern Comparison

| Pattern       | Push | Pop  | Top  | GetMin | Extra Space | Interview Friendly |
| ------------- | ---- | ---- | ---- | ------ | ----------- | ------------------ |
| Brute Force   | O(1) | O(1) | O(1) | O(n)   | O(n)        | No                 |
| Two Stacks    | O(1) | O(1) | O(1) | O(1)   | O(n)        | Yes                |
| Pair Storage  | O(1) | O(1) | O(1) | O(1)   | O(n)        | Yes                |
| Encoded Trick | O(1) | O(1) | O(1) | O(1)   | O(n)        | Moderate           |

# Related Pattern Recognition

This problem teaches:

1. **Auxiliary Stack Pattern**

   * Min Stack
   * Max Stack
   * Special Stack

2. **State Tracking Pattern**

   * Store extra information with each element.

3. **Prefix Aggregate Pattern**

   * Keep minimum-so-far at every index.

# Optimized Interview Pattern

### Recommended: Two Stack Pattern

Why?

* Simple
* Easy to explain
* True O(1) operations
* Most expected by Amazon, Meta, Microsoft, Google interviews
