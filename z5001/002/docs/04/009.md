# Basic Calculator (LeetCode 224)

**Problem:**
Evaluate a string expression containing:

* Integers
* `+`, `-`
* Parentheses `(` `)`
* Spaces

Examples:

```text
Input: "1 + 1"
Output: 2

Input: " 2-1 + 2 "
Output: 3

Input: "(1+(4+5+2)-3)+(6+8)"
Output: 23
```

---

# Solution Pattern Analysis

| Pattern                        | Idea                                     | Time | Space | Suitable |
| ------------------------------ | ---------------------------------------- | ---- | ----- | -------- |
| Recursive Descent              | Parse expression recursively             | O(n) | O(n)  | Good     |
| Two Stack (Operators + Values) | Standard expression evaluation           | O(n) | O(n)  | Good     |
| BFS/Tree Construction          | Build expression tree                    | O(n) | O(n)  | Overkill |
| Stack with Sign Context        | Track result and sign across parentheses | O(n) | O(n)  | Optimal  |

---

# Pattern 1: Recursive Parsing

### Idea

When encountering:

* Number → add to current result
* `+` / `-` → update sign
* `(` → recursively evaluate sub-expression
* `)` → return result

---

### Code

```python
class Solution:
    def calculate(self, s: str) -> int:

        def helper():
            nonlocal i

            result = 0
            sign = 1
            num = 0

            while i < len(s):

                ch = s[i]

                if ch.isdigit():
                    num = num * 10 + int(ch)

                elif ch == '+':
                    result += sign * num
                    num = 0
                    sign = 1

                elif ch == '-':
                    result += sign * num
                    num = 0
                    sign = -1

                elif ch == '(':
                    i += 1
                    num = helper()

                elif ch == ')':
                    result += sign * num
                    return result

                i += 1

            result += sign * num
            return result

        i = 0
        return helper()
```

# Pattern 2: Two Stack Approach

### Idea

Maintain:

* Value stack
* Operator stack

Evaluate according to precedence.

Since only `+` and `-` exist, implementation is simpler.

---

### Code

```python
class Solution:
    def calculate(self, s: str) -> int:

        nums = []
        ops = []

        def apply():
            b = nums.pop()
            a = nums.pop()

            op = ops.pop()

            if op == '+':
                nums.append(a + b)
            else:
                nums.append(a - b)

        i = 0

        while i < len(s):

            ch = s[i]

            if ch == ' ':
                i += 1
                continue

            if ch.isdigit():
                num = 0

                while i < len(s) and s[i].isdigit():
                    num = num * 10 + int(s[i])
                    i += 1

                nums.append(num)
                continue

            elif ch == '(':
                ops.append(ch)

            elif ch == ')':

                while ops and ops[-1] != '(':
                    apply()

                ops.pop()

            elif ch in '+-':

                while ops and ops[-1] in '+-':
                    apply()

                ops.append(ch)

            i += 1

        while ops:
            apply()

        return nums[-1]
```

# Pattern 3: Stack with Sign Context (Most Popular)

### Key Observation

For expression:

```text
1-(2+3)
```

When entering `(`:

* Save current result
* Save current sign

When leaving `)`:

* Multiply sub-expression result by saved sign
* Add to saved result

---

### Example

```text
1-(2+3)

Stack:
[1, -1]

Sub-expression:
5

Final:
1 + (-1 * 5)
= -4
```

---

### Code

```python
class Solution:
    def calculate(self, s: str) -> int:

        result = 0
        number = 0
        sign = 1

        stack = []

        for ch in s:

            if ch.isdigit():
                number = number * 10 + int(ch)

            elif ch == '+':
                result += sign * number
                number = 0
                sign = 1

            elif ch == '-':
                result += sign * number
                number = 0
                sign = -1

            elif ch == '(':
                stack.append(result)
                stack.append(sign)

                result = 0
                sign = 1

            elif ch == ')':

                result += sign * number
                number = 0

                prev_sign = stack.pop()
                prev_result = stack.pop()

                result = prev_result + prev_sign * result

        result += sign * number

        return result
```

# Dry Run

Expression:

```text
(1+(4+5+2)-3)+(6+8)
```

### After evaluating first bracket

```text
1 + 11 - 3
= 11
```

### Second bracket

```text
6 + 8 = 14
```

### Final

```text
11 + 14 = 25
```

Wait:

Actual first bracket:

```text
1 + (4+5+2) - 3
= 1 + 11 - 3
= 9
```

Final:

```text
9 + 14
= 23
```

# Optimized Pattern Comparison

| Pattern            | Time | Space | Interview Rating |
| ------------------ | ---- | ----- | ---------------- |
| Recursive Parsing  | O(n) | O(n)  | ★★★★☆            |
| Two Stack          | O(n) | O(n)  | ★★★☆☆            |
| Sign Context Stack | O(n) | O(n)  | ★★★★★            |

### Recommended Pattern

✅ **Stack with Sign Context**

Reasons:

* Single pass.
* Simplest implementation.
* Most frequently expected in Google, Amazon, Meta, Microsoft, and Apple interviews.
* Naturally handles nested parentheses.
* No operator precedence handling required because only `+` and `-` exist.

**Final Interview Pattern:**
**Stack + Running Result + Sign Context (O(n) Time, O(n) Space)**.
