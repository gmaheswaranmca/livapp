# Decode String (LeetCode 394)

**Problem:**
Given an encoded string like `"3[a2[c]]"`, decode it.

### Examples

```text
Input:  "3[a]2[bc]"
Output: "aaabcbc"

Input:  "3[a2[c]]"
Output: "accaccacc"

Input:  "2[abc]3[cd]ef"
Output: "abcabccdcdcdef"
```

---

# Solution Patterns

## Pattern 1: Recursive DFS

### Idea

* When a digit is found, build the number.
* On `[`, recursively decode the inner substring.
* On `]`, return the decoded part to the caller.

### Algorithm

1. Traverse characters.
2. Build repeat count.
3. Recursively decode inside brackets.
4. Repeat decoded substring `k` times.
5. Return result when `]` is encountered.

### Time Complexity

* **O(n × k)** (due to string repetition)
* Usually considered **O(output length)**

### Space Complexity

* **O(depth)** recursion stack

### Python Code

```python
class Solution:
    def decodeString(self, s: str) -> str:
        index = 0

        def dfs():
            nonlocal index
            result = ""
            num = 0

            while index < len(s):
                ch = s[index]

                if ch.isdigit():
                    num = num * 10 + int(ch)

                elif ch == '[':
                    index += 1
                    decoded = dfs()
                    result += decoded * num
                    num = 0

                elif ch == ']':
                    return result

                else:
                    result += ch

                index += 1

            return result

        return dfs()
```

# Pattern 2: Two Stack Approach

### Idea

Maintain:

* Stack for numbers
* Stack for previous strings

When `]` is found:

* Pop repeat count
* Pop previous string
* Append repeated current string

### Algorithm

1. Push count when `[` appears.
2. Push current string.
3. Start building new substring.
4. On `]`, reconstruct.

### Time Complexity

* **O(output length)**

### Space Complexity

* **O(n)**

### Python Code

```python
class Solution:
    def decodeString(self, s: str) -> str:
        count_stack = []
        string_stack = []

        curr_num = 0
        curr_str = ""

        for ch in s:
            if ch.isdigit():
                curr_num = curr_num * 10 + int(ch)

            elif ch == '[':
                count_stack.append(curr_num)
                string_stack.append(curr_str)

                curr_num = 0
                curr_str = ""

            elif ch == ']':
                repeat = count_stack.pop()
                prev = string_stack.pop()

                curr_str = prev + curr_str * repeat

            else:
                curr_str += ch

        return curr_str
```

# Pattern 3: Single Stack (Character Stack)

### Idea

Push everything into one stack.

When `]` appears:

1. Extract string until `[`.
2. Extract number before `[`.
3. Repeat and push back.

### Time Complexity

* **O(output length)**

### Space Complexity

* **O(n)**

### Python Code

```python
class Solution:
    def decodeString(self, s: str) -> str:
        stack = []

        for ch in s:
            if ch != ']':
                stack.append(ch)

            else:
                substr = ""

                while stack and stack[-1] != '[':
                    substr = stack.pop() + substr

                stack.pop()  # remove '['

                num = ""

                while stack and stack[-1].isdigit():
                    num = stack.pop() + num

                stack.append(substr * int(num))

        return "".join(stack)
```

# Pattern 4: Iterative State Machine

### Idea

Treat decoding as state transitions:

* Reading digits
* Reading letters
* Entering nested block
* Exiting nested block

Internally behaves similar to the two-stack solution.

### Time Complexity

* **O(output length)**

### Space Complexity

* **O(n)**

# Optimized Solution

### Recommended Pattern: Two Stacks

Reasons:

✅ Most commonly expected in interviews
✅ Handles nested encodings naturally
✅ No recursion depth issues
✅ Easy to explain and implement
✅ Linear traversal

### Optimized Code

```python
class Solution:
    def decodeString(self, s: str) -> str:
        count_stack = []
        string_stack = []

        curr_num = 0
        curr_str = ""

        for ch in s:
            if ch.isdigit():
                curr_num = curr_num * 10 + int(ch)

            elif ch == '[':
                count_stack.append(curr_num)
                string_stack.append(curr_str)

                curr_num = 0
                curr_str = ""

            elif ch == ']':
                repeat = count_stack.pop()
                prev = string_stack.pop()

                curr_str = prev + curr_str * repeat

            else:
                curr_str += ch

        return curr_str
```

### Interview Pattern Recognition

Use the **Stack + Nested Expression Decoding** pattern when you see:

* Nested brackets `[]`
* Encoded expressions like `k[...]`
* Expression expansion
* Parentheses/bracket processing
* Recursive structure that can be simulated iteratively

This is the standard optimal solution for **Decode String**.
