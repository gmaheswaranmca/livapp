# Basic Calculator II (LeetCode 227)

**Problem:**
Given a string expression containing non-negative integers, `+`, `-`, `*`, `/`, and spaces, evaluate the expression.

**Constraints:**

* No parentheses.
* Division truncates toward zero.
* Valid expression.

Example:

```text
Input: "3+2*2"
Output: 7

Input: " 3/2 "
Output: 1

Input: " 3+5 / 2 "
Output: 5
```

---

# Pattern 1: Convert to Tokens + Two-Pass Evaluation

### Idea

1. Parse numbers and operators.
2. First pass: handle `*` and `/`.
3. Second pass: handle `+` and `-`.

### Steps

```text
3+2*2

Tokens:
[3,+,2,*,2]

Pass 1:
[3,+,4]

Pass 2:
7
```

### Complexity

* Time: O(n)
* Space: O(n)

### Code

```python
class Solution:
    def calculate(self, s: str) -> int:
        tokens = []
        num = 0

        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)
            elif ch in "+-*/":
                tokens.append(num)
                tokens.append(ch)
                num = 0

        tokens.append(num)

        stack = [tokens[0]]
        i = 1

        while i < len(tokens):
            op = tokens[i]
            val = tokens[i + 1]

            if op == '*':
                stack[-1] *= val
            elif op == '/':
                stack[-1] = int(stack[-1] / val)
            else:
                stack.append(op)
                stack.append(val)

            i += 2

        result = stack[0]
        i = 1

        while i < len(stack):
            op = stack[i]
            val = stack[i + 1]

            if op == '+':
                result += val
            else:
                result -= val

            i += 2

        return result
```

# Pattern 2: Stack-Based Operator Precedence

### Idea

Store numbers in a stack.

* `+` → push number
* `-` → push negative number
* `*` → multiply top
* `/` → divide top

Finally sum stack.

### Example

```text
3+2*2

Stack:
[3]

+
push 2
[3,2]

*
2*2 = 4

[3,4]

sum = 7
```

### Complexity

* Time: O(n)
* Space: O(n)

### Code

```python
class Solution:
    def calculate(self, s: str) -> int:
        stack = []
        num = 0
        sign = '+'

        s += '+'

        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)

            elif ch in "+-*/":

                if sign == '+':
                    stack.append(num)

                elif sign == '-':
                    stack.append(-num)

                elif sign == '*':
                    stack.append(stack.pop() * num)

                elif sign == '/':
                    stack.append(int(stack.pop() / num))

                sign = ch
                num = 0

        return sum(stack)
```

# Pattern 3: Constant Space Running Evaluation

### Idea

Avoid stack.

Maintain:

```text
result     -> completed terms
last_num   -> previous term
current    -> current number
```

When:

```text
+ or -
```

add previous term to result.

For:

```text
* or /
```

update last_num directly.

---

### Dry Run

Expression:

```text
3+2*2
```

```text
result = 0
last = 0

3
+:
last = 3

2
*:
result += 3
last = 2

2
end:
last = 4

result + last
= 3 + 4
= 7
```

---

### Complexity

* Time: O(n)
* Space: O(1)

### Code

```python
class Solution:
    def calculate(self, s: str) -> int:
        result = 0
        last_num = 0
        num = 0
        sign = '+'

        s += '+'

        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)

            elif ch in "+-*/":

                if sign == '+':
                    result += last_num
                    last_num = num

                elif sign == '-':
                    result += last_num
                    last_num = -num

                elif sign == '*':
                    last_num *= num

                elif sign == '/':
                    last_num = int(last_num / num)

                sign = ch
                num = 0

        return result + last_num
```

# Optimized Pattern (Recommended)

### Pattern: Constant Space Running Evaluation

Why?

✅ Single scan
✅ O(n) time
✅ O(1) space
✅ Handles precedence naturally
✅ Frequently expected by Amazon, Google, Microsoft, Meta, Uber interviews

### Pattern Recognition

Use this pattern when:

* Expression evaluation
* `+ - * /`
* No parentheses
* Need operator precedence
* Asked for O(1) extra space

**Pattern Name:** *Running Term Evaluation (Constant Space Expression Parsing)*.
