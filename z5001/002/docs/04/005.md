# Largest Rectangle in Histogram (Hard)

**Problem:**
Given an array `heights`, where each element represents the height of a histogram bar of width `1`, find the area of the largest rectangle that can be formed.

**Example**

```python
Input: heights = [2,1,5,6,2,3]
Output: 10

Explanation:
Rectangle formed by heights [5,6]
Width = 2
Area = 5 × 2 = 10
```

---

# Pattern 1: Brute Force Expansion

## Idea

For every bar:

* Expand left until a smaller bar is found.
* Expand right until a smaller bar is found.
* Calculate area using current bar as minimum height.

## Algorithm

```text
For each index i:
    Find left boundary
    Find right boundary
    width = right - left + 1
    area = heights[i] * width
Return maximum area
```

## Code

```python
def largestRectangleArea(heights):
    n = len(heights)
    max_area = 0

    for i in range(n):
        left = i
        while left > 0 and heights[left - 1] >= heights[i]:
            left -= 1

        right = i
        while right < n - 1 and heights[right + 1] >= heights[i]:
            right += 1

        area = heights[i] * (right - left + 1)
        max_area = max(max_area, area)

    return max_area
```

## Complexity

* Time: **O(n²)**
* Space: **O(1)**

---

# Pattern 2: Previous Smaller + Next Smaller Arrays

## Idea

For every bar:

* Find Previous Smaller Element (PSE)
* Find Next Smaller Element (NSE)

Then:

```text
width = NSE - PSE - 1
area = height * width
```

---

## Example

```python
heights = [2,1,5,6,2,3]
```

```text
PSE = [-1,-1,1,2,1,4]
NSE = [1,6,4,4,6,6]
```

For height 5:

```text
width = 4 - 1 - 1 = 2
area = 5 * 2 = 10
```

---

## Code

```python
def largestRectangleArea(heights):
    n = len(heights)

    prev_smaller = [-1] * n
    next_smaller = [n] * n

    stack = []

    for i in range(n):
        while stack and heights[stack[-1]] >= heights[i]:
            stack.pop()

        if stack:
            prev_smaller[i] = stack[-1]

        stack.append(i)

    stack = []

    for i in range(n - 1, -1, -1):
        while stack and heights[stack[-1]] >= heights[i]:
            stack.pop()

        if stack:
            next_smaller[i] = stack[-1]

        stack.append(i)

    max_area = 0

    for i in range(n):
        width = next_smaller[i] - prev_smaller[i] - 1
        max_area = max(max_area, heights[i] * width)

    return max_area
```

## Complexity

* Time: **O(n)**
* Space: **O(n)**

# Pattern 3: Monotonic Increasing Stack (Optimal)

## Idea

Maintain indices in increasing height order.

Whenever a smaller bar appears:

* Current bar becomes the right boundary.
* Stack top gives the left boundary.
* Compute area immediately.

This avoids storing PSE/NSE arrays.

---

## Visualization

```python
heights = [2,1,5,6,2,3]
```

Add sentinel:

```python
[2,1,5,6,2,3,0]
```

When processing `2`:

```text
Stack: [1,2,3]

Pop 6:
height = 6
width = 1
area = 6

Pop 5:
height = 5
width = 2
area = 10
```

Maximum becomes 10.

---

## Code

```python
def largestRectangleArea(heights):
    stack = []
    max_area = 0

    heights.append(0)

    for i in range(len(heights)):

        while stack and heights[stack[-1]] > heights[i]:

            height = heights[stack.pop()]

            if stack:
                width = i - stack[-1] - 1
            else:
                width = i

            max_area = max(max_area, height * width)

        stack.append(i)

    return max_area
```

---

## Complexity

* Time: **O(n)**
* Space: **O(n)**

# Pattern 4: Divide and Conquer

## Idea

Choose minimum height bar.

```text
Largest Area =
max(
    area using minimum bar,
    left subarray answer,
    right subarray answer
)
```

Similar to Quick Sort recursion.

---

## Code

```python
def largestRectangleArea(heights):

    def solve(left, right):
        if left > right:
            return 0

        min_index = left

        for i in range(left, right + 1):
            if heights[i] < heights[min_index]:
                min_index = i

        current = heights[min_index] * (right - left + 1)

        left_area = solve(left, min_index - 1)
        right_area = solve(min_index + 1, right)

        return max(current, left_area, right_area)

    return solve(0, len(heights) - 1)
```

## Complexity

Worst Case:

* Time: **O(n²)**
* Space: **O(n)**

Using Segment Tree:

* Time: **O(n log n)**

# Optimized Solution Pattern

## Monotonic Increasing Stack

### Why Best?

✅ Single pass

✅ Each element pushed once

✅ Each element popped once

✅ No extra PSE/NSE arrays

✅ Standard interview solution

### Core Template

```python
stack = []

for i in range(len(nums)):

    while stack and nums[stack[-1]] > nums[i]:
        idx = stack.pop()

        left = stack[-1] if stack else -1
        width = i - left - 1

        area = nums[idx] * width

    stack.append(i)
```

### Final Optimized Code

```python
def largestRectangleArea(heights):
    stack = []
    max_area = 0

    heights.append(0)

    for i, h in enumerate(heights):

        while stack and heights[stack[-1]] > h:

            height = heights[stack.pop()]

            left = stack[-1] if stack else -1
            width = i - left - 1

            max_area = max(max_area, height * width)

        stack.append(i)

    return max_area
```

### Complexity

* **Time:** O(n)
* **Space:** O(n)
