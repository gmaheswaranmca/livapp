# Valid Parentheses (LeetCode 20)

**Problem:**
Given a string containing only `'(' , ')' , '{' , '}' , '[' , ']'`, determine whether the parentheses are valid.

A string is valid if:

1. Every opening bracket has a corresponding closing bracket.
2. Brackets are closed in the correct order.

**Example**

```text
Input: "()[]{}"
Output: True

Input: "(]"
Output: False

Input: "([)]"
Output: False

Input: "{[]}"
Output: True
```

---

# Pattern 1: Brute Force (Repeated Replacement)

## Idea

Repeatedly remove:

* `()`
* `{}`
* `[]`

If the string becomes empty, it is valid.

## Pattern

```text
Keep removing valid pairs
Until no more pairs exist

If string becomes empty
    Valid
Else
    Invalid
```

## Code

```python
def isValid(s: str) -> bool:
    prev = ""

    while prev != s:
        prev = s
        s = s.replace("()", "")
        s = s.replace("{}", "")
        s = s.replace("[]", "")

    return s == ""
```

## Complexity

* Time: O(n²)
* Space: O(n)

---

# Pattern 2: Stack Simulation

## Idea

Push opening brackets.

When a closing bracket appears:

* Check top of stack.
* If matching opening bracket exists → pop.
* Otherwise → invalid.

## Pattern

```text
For each character

    If opening bracket
        Push

    Else
        Check stack top

After traversal
    Stack should be empty
```

## Code

```python
def isValid(s: str) -> bool:
    stack = []

    for ch in s:
        if ch == '(' or ch == '{' or ch == '[':
            stack.append(ch)

        else:
            if not stack:
                return False

            top = stack.pop()

            if ch == ')' and top != '(':
                return False

            if ch == '}' and top != '{':
                return False

            if ch == ']' and top != '[':
                return False

    return len(stack) == 0
```

## Complexity

* Time: O(n)
* Space: O(n)

# Pattern 3: Stack + HashMap

## Idea

Store matching pairs in a dictionary.

This avoids multiple if-else checks.

## Pattern

```text
Map closing -> opening

If opening
    Push

If closing
    Compare with stack top
```

## Code

```python
def isValid(s: str) -> bool:
    stack = []

    pairs = {
        ')': '(',
        '}': '{',
        ']': '['
    }

    for ch in s:

        if ch in "({[":
            stack.append(ch)

        else:
            if not stack:
                return False

            if stack.pop() != pairs[ch]:
                return False

    return len(stack) == 0
```

## Complexity

* Time: O(n)
* Space: O(n)

---

# Pattern 4: Stack with Expected Closing Brackets

## Idea

Instead of pushing opening brackets, push the expected closing bracket.

Example:

```text
(
Push )

[
Push ]
```

When a closing bracket arrives:

* It must match stack top.

This reduces lookups.

## Pattern

```text
Opening bracket
    Push expected closing bracket

Closing bracket
    Must equal stack.pop()
```

## Code

```python
def isValid(s: str) -> bool:
    stack = []

    for ch in s:

        if ch == '(':
            stack.append(')')

        elif ch == '{':
            stack.append('}')

        elif ch == '[':
            stack.append(']')

        else:
            if not stack or stack.pop() != ch:
                return False

    return not stack
```

## Complexity

* Time: O(n)
* Space: O(n)

---

# Pattern 5: Recursive Reduction

## Idea

Recursively remove valid pairs until no change.

## Code

```python
def isValid(s: str) -> bool:

    while True:
        new_s = s.replace("()", "") \
                 .replace("{}", "") \
                 .replace("[]", "")

        if new_s == s:
            break

        s = new_s

    return s == ""
```

## Complexity

* Time: O(n²)
* Space: O(n)

# Pattern Comparison

| Pattern                | Time  | Space | Interview Value |
| ---------------------- | ----- | ----- | --------------- |
| Repeated Replace       | O(n²) | O(n)  | Low             |
| Recursive Reduction    | O(n²) | O(n)  | Low             |
| Stack Simulation       | O(n)  | O(n)  | High            |
| Stack + HashMap        | O(n)  | O(n)  | Very High       |
| Expected Closing Stack | O(n)  | O(n)  | Highest         |

# Optimized Solution Pattern

## Expected Closing Bracket Stack

### Why Best?

* Single pass.
* No hashmap lookup.
* No nested conditions.
* Cleanest code.
* Standard interview solution.

## Optimized Code

```python
def isValid(s: str) -> bool:
    stack = []

    for ch in s:

        if ch == '(':
            stack.append(')')

        elif ch == '{':
            stack.append('}')

        elif ch == '[':
            stack.append(']')

        elif not stack or stack.pop() != ch:
            return False

    return not stack
```

## Complexity

* **Time:** O(n)
* **Space:** O(n)
