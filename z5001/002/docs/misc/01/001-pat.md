# Other Solution Patterns for "Two Sum Variant with Conditions"

---

# 1. Brute Force Pattern

---

# Pattern Name

```md id="wlq9eq"
Nested Loop / Brute Force Pattern
```

---

# Idea of Pattern

Check every possible pair manually.

For every element:

* Compare with every other element
* Check:

  * Sum condition
  * Even/Odd condition

This is the simplest approach.

---

# Visualization

```text
nums = [2, 4, 6, 8]

Check:
2 + 4
2 + 6
2 + 8
4 + 6
4 + 8
6 + 8
```

Every pair is checked.

---

# Code

```python id="t1y6js"
def two_sum_bruteforce(nums, target):

    for i in range(len(nums)):

        for j in range(i + 1, len(nums)):

            # Sum condition
            if nums[i] + nums[j] == target:

                # Same parity condition
                if nums[i] % 2 == nums[j] % 2:

                    return [i, j]

    return [-1, -1]


nums = [2, 4, 6, 8]
target = 10

print(two_sum_bruteforce(nums, target))
```

---

# Step-by-Step

---

## Outer Loop

```python id="0jjhdo"
for i in range(len(nums))
```

Pick first number.

---

## Inner Loop

```python id="r9gk6p"
for j in range(i + 1, len(nums))
```

Pick second number.

---

## Sum Check

```python id="gbmkq3"
nums[i] + nums[j] == target
```

Check target sum.

---

## Parity Check

```python id="9mhtg5"
nums[i] % 2 == nums[j] % 2
```

Check:

* both even
  OR
* both odd

---

# Complexity

| Type  | Complexity |
| ----- | ---------- |
| Time  | O(n²)      |
| Space | O(1)       |

---

# When Used

Used when:

* Simplicity is important
* Small input size
* Interview starts with basic approach

# 2. Hash Map Pattern

---

# Pattern Name

```md id="fcztx3"
Hash Map + Complement Search Pattern
```

---

# Idea of Pattern

Instead of checking all pairs:

* Store previously seen numbers
* Directly search complement

Very fast lookup.

---

# Visualization

```text
target = 10

Current number = 8

Need:
10 - 8 = 2

Check if 2 already exists.
```

---

# Code

```python id="qck7n7"
def two_sum_hashmap(nums, target):

    seen = {}

    for i in range(len(nums)):

        complement = target - nums[i]

        if complement in seen:

            prev_index = seen[complement]

            if nums[i] % 2 == nums[prev_index] % 2:

                return [prev_index, i]

        seen[nums[i]] = i

    return [-1, -1]


nums = [2, 4, 6, 8]
target = 10

print(two_sum_hashmap(nums, target))
```

---

# Why Faster?

Dictionary lookup:

```python id="j0z72p"
if complement in seen
```

takes:

```python id="qlwff0"
O(1)
```

average time.

---

# Complexity

| Type  | Complexity |
| ----- | ---------- |
| Time  | O(n)       |
| Space | O(n)       |

---

# When Used

Most common interview approach.

Used in:

* Two Sum
* Pair finding
* Frequency counting
* Fast searching problems

# 3. Sorting + Two Pointer Pattern

---

# Pattern Name

```md id="snhw0l"
Sorting + Two Pointer Pattern
```

---

# Idea of Pattern

Steps:

1. Sort array
2. Keep:

   * left pointer
   * right pointer
3. Move pointers based on sum

---

# Visualization

```text
Sorted:
[2, 4, 6, 8]

left = 2
right = 8

2 + 8 = 10
Found
```

---

# Important Note

Sorting changes original indices.

So we store:

```python id="d18sl7"
(value, original_index)
```

---

# Code

```python id="bn8xej"
def two_sum_twopointer(nums, target):

    arr = []

    for i in range(len(nums)):
        arr.append((nums[i], i))

    arr.sort()

    left = 0
    right = len(arr) - 1

    while left < right:

        current_sum = arr[left][0] + arr[right][0]

        if current_sum == target:

            num1 = arr[left][0]
            num2 = arr[right][0]

            if num1 % 2 == num2 % 2:

                return [arr[left][1], arr[right][1]]

            left += 1
            right -= 1

        elif current_sum < target:
            left += 1

        else:
            right -= 1

    return [-1, -1]


nums = [2, 4, 6, 8]
target = 10

print(two_sum_twopointer(nums, target))
```

---

# Pointer Movement Logic

---

## If Sum Small

```python id="2l0g7m"
current_sum < target
```

Move left forward.

Need bigger value.

---

## If Sum Large

```python id="e7zqmb"
current_sum > target
```

Move right backward.

Need smaller value.

---

# Complexity

| Type  | Complexity |
| ----- | ---------- |
| Time  | O(n log n) |
| Space | O(n)       |

---

# When Used

Very common in:

* Sorted arrays
* Pair sum problems
* Triplet problems
* Sliding window style questions

# 4. Even/Odd Separation Pattern

---

# Pattern Name

```md id="fthb97"
Partitioning / Grouping Pattern
```

---

# Idea

Since condition says:

* both even
  OR
* both odd

We can:

1. Separate even numbers
2. Separate odd numbers
3. Solve Two Sum independently

---

# Visualization

```text
nums = [2,4,1,3]

Even Group:
[2,4]

Odd Group:
[1,3]
```

---

# Code

```python id="3y0dcg"
def two_sum_partition(nums, target):

    even = []
    odd = []

    for i in range(len(nums)):

        if nums[i] % 2 == 0:
            even.append((nums[i], i))
        else:
            odd.append((nums[i], i))

    # Check even group
    seen = {}

    for num, idx in even:

        complement = target - num

        if complement in seen:
            return [seen[complement], idx]

        seen[num] = idx

    # Check odd group
    seen = {}

    for num, idx in odd:

        complement = target - num

        if complement in seen:
            return [seen[complement], idx]

        seen[num] = idx

    return [-1, -1]


nums = [2, 4, 6, 8]
target = 10

print(two_sum_partition(nums, target))
```

---

# Why This Works

Even + Even = Even

Odd + Odd = Even

So:

* If target is odd
  → impossible immediately

This optimization helps.
