
# Step-by-Step Explanation

---

## Step 1 — Create Hash Map

```python id="6bf4aq"
seen = {}
```

We create an empty dictionary called `seen`.

Purpose:

* Store numbers already visited
* Store their indices

Example:

```python id="j76trm"
{
   number : index
}
```

---

## Step 2 — Traverse the Array

```python id="l5i6v4"
for i in range(len(nums)):
```

We loop through every element in the array.

If:

```python id="ywjlwm"
nums = [2, 4, 6, 8]
```

Then:

* `i = 0`
* `i = 1`
* `i = 2`
* `i = 3`

---

## Step 3 — Find Complement

```python id="7d8m39"
complement = target - nums[i]
```

We calculate the number needed to make the target.

Example:

```python id="fcwz2z"
target = 10
nums[i] = 8
```

Then:

```python id="6n2i1c"
complement = 10 - 8
           = 2
```

We now check:

> "Have we already seen 2 before?"

---

## Step 4 — Check if Complement Exists

```python id="z4lm87"
if complement in seen:
```

If complement already exists in dictionary,
then we found a possible pair.

Example:

```python id="n5jlwm"
seen = {2:0, 4:1}
complement = 2
```

Condition becomes TRUE.

---

## Step 5 — Get Previous Index

```python id="7f11xt"
prev_index = seen[complement]
```

We retrieve the index of complement.

Example:

```python id="6whh7x"
seen = {2:0}
```

Then:

```python id="50oh9o"
prev_index = 0
```

---

## Step 6 — Check Conditional Rule

```python id="b9g5dr"
if (nums[i] % 2 == nums[prev_index] % 2):
```

This is the MOST IMPORTANT condition.

We must ensure:

* both numbers are even
  OR
* both numbers are odd

---

# Understanding `% 2`

---

## Even Number

```python id="mtn19h"
8 % 2 = 0
```

Even numbers always give remainder `0`.

---

## Odd Number

```python id="lfmcf5"
7 % 2 = 1
```

Odd numbers always give remainder `1`.

---

# Same Parity Check

```python id="31g6d8"
nums[i] % 2 == nums[prev_index] % 2
```

Means:

| Number 1 | Number 2 | Result |
| -------- | -------- | ------ |
| Even     | Even     | TRUE   |
| Odd      | Odd      | TRUE   |
| Even     | Odd      | FALSE  |

---

## Example Walkthrough

Input:

```python id="b4gy8g"
nums = [2, 4, 6, 8]
target = 10
```

---

### Iteration 1

```python id="jlwm2j"
i = 0
nums[i] = 2
complement = 8
```

`8` not in `seen`

Store:

```python id="9g5lqy"
seen = {2:0}
```

---

### Iteration 2

```python id="y2t2zv"
i = 1
nums[i] = 4
complement = 6
```

`6` not in `seen`

Store:

```python id="yutp55"
seen = {2:0, 4:1}
```

---

### Iteration 3

```python id="0ttvbo"
i = 2
nums[i] = 6
complement = 4
```

`4` exists in `seen`

```python id="6sh6a7"
prev_index = 1
```

Check parity:

```python id="pq2bks"
6 % 2 = 0
4 % 2 = 0
```

Both even → TRUE

Return:

```python id="e4mmvf"
[1, 2]
```

# Why Hash Map?

Without hash map:

* We need nested loops
* Time Complexity = `O(n²)`

With hash map:

* Lookup becomes fast
* Time Complexity = `O(n)`

---

# Time Complexity

## Loop

```python id="dcvht9"
for i in range(len(nums))
```

Runs `n` times.

---

## Dictionary Lookup

```python id="7jkrqa"
if complement in seen
```

Average Time:

```python id="p0mbsq"
O(1)
```

---

# Final Complexity

| Type  | Complexity |
| ----- | ---------- |
| Time  | O(n)       |
| Space | O(n)       |

# Pattern Used

```md id="18dnmi"
Hash Map + Conditional Checking
```

This pattern is commonly used in:

* Two Sum
* Pair problems
* Complement search
* Frequency counting
* Fast lookup problems
