# Title

```md
Two Sum Variant with Conditions
```

---

# Description

```md
Given an integer array nums and an integer target, find a pair of indices (i, j) such that:

1. nums[i] + nums[j] == target
2. i != j
3. Both numbers must be even OR both numbers must be odd

Return the indices of the valid pair.

If multiple answers exist, return any one of them.

If no valid pair exists, return [-1, -1].
```

```md
Sample Case 1

nums = [2, 4, 6, 8]
target = 10

Expected Output:

Explanation:

Both numbers are even.
```

# Solution Code in Python

```python id="77ayjv"
def two_sum_variant(nums, target):
    seen = {}

    for i in range(len(nums)):
        complement = target - nums[i]

        if complement in seen:
            prev_index = seen[complement]

            # Both even OR both odd
            if (nums[i] % 2 == nums[prev_index] % 2):
                return [prev_index, i]

        seen[nums[i]] = i

    return [-1, -1]


nums = list(map(int, input().split()))
target = int(input())

print(two_sum_variant(nums, target))
```
