# Contains Duplicate

**Problem:** Detect whether an array contains any duplicate element.

Example:

```text
Input: [1,2,3,1]
Output: True

Input: [1,2,3,4]
Output: False
```

---

# Pattern 1: Brute Force (Nested Loops)

## Idea

Compare every element with every other element.

## Algorithm

```text
for each i:
    for each j > i:
        if nums[i] == nums[j]:
            return True
return False
```

## Python Code

```python
def containsDuplicate(nums):
    n = len(nums)

    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] == nums[j]:
                return True

    return False
```

## Complexity

* Time: O(n²)
* Space: O(1)

## Pattern Used

* Exhaustive Search
* Nested Loop Comparison

---

# Pattern 2: Sorting Pattern

## Idea

If duplicates exist, they become adjacent after sorting.

## Algorithm

```text
sort array

for i from 1 to n-1:
    if nums[i] == nums[i-1]:
        return True

return False
```

## Python Code

```python
def containsDuplicate(nums):
    nums.sort()

    for i in range(1, len(nums)):
        if nums[i] == nums[i - 1]:
            return True

    return False
```

## Complexity

* Time: O(n log n)
* Space: O(1) (ignoring sort space)

## Pattern Used

* Sorting
* Adjacent Comparison

---

# Pattern 3: Hash Set Pattern

## Idea

Store elements in a hash set.

If element already exists in set → duplicate found.

## Algorithm

```text
create empty set

for each number:
    if number already in set:
        return True
    add number to set

return False
```

## Python Code

```python
def containsDuplicate(nums):
    seen = set()

    for num in nums:
        if num in seen:
            return True

        seen.add(num)

    return False
```

## Complexity

* Time: O(n)
* Space: O(n)

## Pattern Used

* Hashing
* Set Lookup

---

# Pattern 4: Hash Map Frequency Counting

## Idea

Count occurrences using dictionary.

Duplicate exists if frequency exceeds 1.

## Python Code

```python
def containsDuplicate(nums):
    freq = {}

    for num in nums:
        freq[num] = freq.get(num, 0) + 1

        if freq[num] > 1:
            return True

    return False
```

## Complexity

* Time: O(n)
* Space: O(n)

## Pattern Used

* Frequency Counting
* Hash Map

---

# Pattern 5: One-Liner Set Length Comparison

## Idea

Set removes duplicates automatically.

If lengths differ, duplicates exist.

## Python Code

```python
def containsDuplicate(nums):
    return len(nums) != len(set(nums))
```

## Complexity

* Time: O(n)
* Space: O(n)

## Pattern Used

* Hash Set
* Deduplication

# Optimized Solution

## Best Pattern: Hash Set

### Why?

* Single pass.
* O(n) average time.
* Immediate duplicate detection.
* Most commonly expected by Amazon, Google, Meta, Microsoft, and Apple interviewers.

### Python Code

```python
def containsDuplicate(nums):
    seen = set()

    for num in nums:
        if num in seen:
            return True

        seen.add(num)

    return False
```

### Complexity

* Time: O(n)
* Space: O(n)
