# Three Sum (LeetCode 15)

**Problem:** Find all unique triplets `(a, b, c)` such that:

[
a + b + c = 0
]

**Companies:** Amazon, Meta, Google, Microsoft, Bloomberg
**Difficulty:** Medium

---

# Pattern 1: Brute Force (Three Nested Loops)

### Idea

Check every possible triplet.

### Algorithm

1. Pick first element.
2. Pick second element.
3. Pick third element.
4. If sum is 0, add to result.
5. Use a set to avoid duplicates.

### Complexity

* Time: **O(n³)**
* Space: **O(k)**

### Python Code

```python
def threeSum(nums):
    n = len(nums)
    result = set()

    for i in range(n):
        for j in range(i + 1, n):
            for k in range(j + 1, n):
                if nums[i] + nums[j] + nums[k] == 0:
                    triplet = tuple(sorted([nums[i], nums[j], nums[k]]))
                    result.add(triplet)

    return [list(t) for t in result]
```

# Pattern 2: Hashing (Fix One Element + Two Sum)

### Idea

Convert Three Sum into Two Sum.

For each element:

* Fix `nums[i]`
* Find two numbers whose sum equals `-nums[i]`

### Algorithm

For each `i`:

1. Create hash set.
2. Target = `-nums[i]`
3. Traverse remaining elements.
4. Check if complement exists.
5. Store unique triplets.

### Complexity

* Time: **O(n²)**
* Space: **O(n)**

### Python Code

```python
def threeSum(nums):
    n = len(nums)
    result = set()

    for i in range(n):
        seen = set()

        for j in range(i + 1, n):
            complement = -nums[i] - nums[j]

            if complement in seen:
                triplet = tuple(sorted([nums[i], nums[j], complement]))
                result.add(triplet)

            seen.add(nums[j])

    return [list(t) for t in result]
```

# Pattern 3: Sorting + Two Pointers (Most Asked)

### Pattern Name

**Sort + Two Pointers**

This is the standard interview solution.

### Idea

After sorting:

* Fix first element.
* Use two pointers:

  * Left = i+1
  * Right = n-1

Move pointers based on current sum.

### Visualization

```text
[-4, -1, -1, 0, 1, 2]

 i

[-4, -1, -1, 0, 1, 2]
      L           R
```

---

### Algorithm

1. Sort array.
2. Fix first element.
3. Use left and right pointers.
4. Calculate sum.
5. If:

   * sum < 0 → left++
   * sum > 0 → right--
   * sum == 0 → store answer
6. Skip duplicates.

### Complexity

* Time: **O(n²)**
* Space: **O(1)** (excluding output)

---

### Python Code

```python
def threeSum(nums):
    nums.sort()
    result = []

    n = len(nums)

    for i in range(n - 2):

        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = n - 1

        while left < right:

            total = nums[i] + nums[left] + nums[right]

            if total < 0:
                left += 1

            elif total > 0:
                right -= 1

            else:
                result.append(
                    [nums[i], nums[left], nums[right]]
                )

                left += 1
                right -= 1

                while left < right and nums[left] == nums[left - 1]:
                    left += 1

                while left < right and nums[right] == nums[right + 1]:
                    right -= 1

    return result
```

# Pattern Comparison

| Pattern             | Technique              | Time  | Space | Interview Value |
| ------------------- | ---------------------- | ----- | ----- | --------------- |
| Brute Force         | 3 Loops                | O(n³) | O(1)  | Low             |
| Hashing             | Fix One + Two Sum      | O(n²) | O(n)  | Medium          |
| Sort + Two Pointers | Sorting + Two Pointers | O(n²) | O(1)  | Very High       |

# Optimized Solution

### Use: Sorting + Two Pointers

```text
Sort Array
      ↓
Fix First Element
      ↓
Apply Two Sum using Left & Right Pointers
      ↓
Skip Duplicates
      ↓
Collect Triplets
```

### Why It Is Optimal

✅ O(n²) time (best possible for general Three Sum)

✅ O(1) extra space

✅ Most commonly expected by Amazon, Meta, Google, Microsoft, Bloomberg interviews

### Interview Pattern

```text
Three Sum
    ↓
Sort + Two Pointers

Four Sum
    ↓
Sort + Nested Loop + Two Pointers

K Sum
    ↓
Recursion + Two Pointers Base Case
```

**Key Pattern:** Whenever you see *"find triplets/quadruplets with target sum"* in a sorted or sortable array, think **Two Pointers after Sorting**.
