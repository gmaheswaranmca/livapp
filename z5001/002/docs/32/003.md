# Four Sum

**Problem:** Find all unique quadruplets `[a, b, c, d]` such that:

[
a+b+c+d = target
]

Example:

```python
nums = [1,0,-1,0,-2,2]
target = 0

Output:
[
 [-2,-1,1,2],
 [-2,0,0,2],
 [-1,0,0,1]
]
```

---

# Pattern 1: Brute Force (4 Nested Loops)

### Idea

Generate every possible quadruplet and check its sum.

### Time Complexity

* O(n⁴)

### Space Complexity

* O(1)

### Code

```python
def fourSum(nums, target):
    n = len(nums)
    result = set()

    for i in range(n):
        for j in range(i + 1, n):
            for k in range(j + 1, n):
                for l in range(k + 1, n):
                    if nums[i] + nums[j] + nums[k] + nums[l] == target:
                        quad = tuple(sorted([nums[i], nums[j], nums[k], nums[l]]))
                        result.add(quad)

    return [list(x) for x in result]
```

# Pattern 2: Hashing Pair Sum

### Idea

Store pair sums in a hashmap.

```text
sum -> list of index pairs
```

For each pair:

```text
needed = target - current_pair_sum
```

Look for complementary pairs.

### Time Complexity

* O(n²) average

### Space Complexity

* O(n²)

### Code

```python
from collections import defaultdict

def fourSum(nums, target):
    n = len(nums)
    pair_sum = defaultdict(list)

    for i in range(n):
        for j in range(i + 1, n):
            pair_sum[nums[i] + nums[j]].append((i, j))

    result = set()

    for s in pair_sum:
        needed = target - s

        if needed not in pair_sum:
            continue

        for a, b in pair_sum[s]:
            for c, d in pair_sum[needed]:

                if len({a, b, c, d}) == 4:
                    quad = sorted([
                        nums[a],
                        nums[b],
                        nums[c],
                        nums[d]
                    ])
                    result.add(tuple(quad))

    return [list(x) for x in result]
```

# Pattern 3: Sorting + Two Nested Loops + Two Pointers

### Idea

This is the standard interview solution.

1. Sort array
2. Fix first number
3. Fix second number
4. Use Two Pointers for remaining two numbers

```text
i fixed
j fixed

left = j+1
right = n-1
```

Move pointers based on sum.

---

## Visualization

```text
[-2,-1,0,0,1,2]

 i
-2

    j
   -1

       L       R
       0       2
```

Check:

```text
-2 + -1 + 0 + 2 = -1
```

Move pointers accordingly.

---

### Time Complexity

```text
Sorting  = O(n log n)
Loops    = O(n²)
Pointers = O(n)

Total    = O(n³)
```

### Space Complexity

```text
O(1)
```

---

## Code

```python
def fourSum(nums, target):
    nums.sort()
    n = len(nums)

    result = []

    for i in range(n - 3):

        if i > 0 and nums[i] == nums[i - 1]:
            continue

        for j in range(i + 1, n - 2):

            if j > i + 1 and nums[j] == nums[j - 1]:
                continue

            left = j + 1
            right = n - 1

            while left < right:

                total = (
                    nums[i]
                    + nums[j]
                    + nums[left]
                    + nums[right]
                )

                if total == target:

                    result.append([
                        nums[i],
                        nums[j],
                        nums[left],
                        nums[right]
                    ])

                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1

                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1

                elif total < target:
                    left += 1
                else:
                    right -= 1

    return result
```

# Pattern 4: Generalized K-Sum Recursion

### Idea

Four Sum is a special case of K-Sum.

```text
4 Sum
 ↓
3 Sum
 ↓
2 Sum (Two Pointers)
```

Useful when interviewer asks:

```text
Can you solve K-Sum?
```

### Time Complexity

```text
O(n^(k-1))
```

For Four Sum:

```text
O(n³)
```

### Code

```python
def fourSum(nums, target):
    nums.sort()

    def ksum(start, k, target):

        res = []

        if k == 2:

            left = start
            right = len(nums) - 1

            while left < right:

                s = nums[left] + nums[right]

                if s == target:

                    res.append([nums[left], nums[right]])

                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1

                elif s < target:
                    left += 1
                else:
                    right -= 1

            return res

        for i in range(start, len(nums) - k + 1):

            if i > start and nums[i] == nums[i - 1]:
                continue

            for subset in ksum(i + 1, k - 1,
                               target - nums[i]):
                res.append([nums[i]] + subset)

        return res

    return ksum(0, 4, target)
```

# Pattern Comparison

| Pattern             | Time      | Space | Interview Value |
| ------------------- | --------- | ----- | --------------- |
| Brute Force         | O(n⁴)     | O(1)  | Low             |
| Pair Sum Hashing    | O(n²) avg | O(n²) | Medium          |
| Sort + Two Pointers | O(n³)     | O(1)  | Very High       |
| K-Sum Generic       | O(n³)     | O(k)  | High            |

---

# Optimized Solution

### Recommended Pattern

✅ **Sorting + Two Nested Loops + Two Pointers**

Reasons:

* Most asked in Amazon, Google, Meta, Microsoft interviews
* Handles duplicates naturally
* Constant extra space
* Easier to explain
* Extension of the famous Two Sum and Three Sum patterns

### Interview Pattern Flow

```text
Two Sum
   ↓
Sorting + Two Pointers

Three Sum
   ↓
Fix One + Two Pointers

Four Sum
   ↓
Fix Two + Two Pointers

K Sum
   ↓
Recursion + Two Pointers
```

**Final Choice for Interviews:**
⭐ **Pattern 3 — Sorting + Two Nested Loops + Two Pointers (O(n³), O(1))**.
