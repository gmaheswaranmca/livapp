# Intersection of Two Arrays (Easy)

**Problem:** Find the unique common elements present in both arrays.

Example:

```python
nums1 = [1,2,2,1]
nums2 = [2,2]

Output: [2]
```

---

# Pattern 1: Brute Force (Nested Loops)

## Idea

Compare every element of first array with every element of second array.

## Algorithm

1. Traverse nums1.
2. For each element, scan nums2.
3. Store common elements uniquely.

## Code

```python
def intersection(nums1, nums2):
    result = []

    for n1 in nums1:
        for n2 in nums2:
            if n1 == n2 and n1 not in result:
                result.append(n1)

    return result
```

## Complexity

* Time: O(n × m)
* Space: O(k)

---

# Pattern 2: Sorting + Two Pointers

## Idea

Sort both arrays and move pointers intelligently.

## Algorithm

1. Sort both arrays.
2. Compare current elements.
3. If equal, add to result.
4. Move smaller element pointer.

## Code

```python
def intersection(nums1, nums2):
    nums1.sort()
    nums2.sort()

    i = j = 0
    result = set()

    while i < len(nums1) and j < len(nums2):
        if nums1[i] == nums2[j]:
            result.add(nums1[i])
            i += 1
            j += 1
        elif nums1[i] < nums2[j]:
            i += 1
        else:
            j += 1

    return list(result)
```

## Complexity

* Time: O(n log n + m log m)
* Space: O(k)

---

# Pattern 3: Hash Set Lookup

## Idea

Store one array in a hash set and check membership from the other array.

## Algorithm

1. Convert nums1 into a set.
2. Traverse nums2.
3. If element exists in set, add to result set.

## Code

```python
def intersection(nums1, nums2):
    s1 = set(nums1)
    result = set()

    for num in nums2:
        if num in s1:
            result.add(num)

    return list(result)
```

## Complexity

* Time: O(n + m)
* Space: O(n)

---

# Pattern 4: Set Intersection Operator

## Idea

Python provides direct set intersection.

## Code

```python
def intersection(nums1, nums2):
    return list(set(nums1) & set(nums2))
```

## Complexity

* Time: O(n + m)
* Space: O(n + m)

---

# Pattern 5: Set Intersection Method

## Idea

Use built-in intersection().

## Code

```python
def intersection(nums1, nums2):
    return list(set(nums1).intersection(set(nums2)))
```

## Complexity

* Time: O(n + m)
* Space: O(n + m)

# Pattern Comparison

| Pattern                | Time                 | Space  | Interview Usage |
| ---------------------- | -------------------- | ------ | --------------- |
| Brute Force            | O(n×m)               | O(k)   | Rare            |
| Sorting + Two Pointers | O(n log n + m log m) | O(k)   | Common          |
| Hash Set Lookup        | O(n+m)               | O(n)   | Very Common     |

# Optimized Solution

## Best Interview Pattern: Hash Set Lookup

Why?

* Linear time.
* Demonstrates hashing knowledge.
* Works efficiently for large inputs.
* Frequently expected by Amazon, Google, Meta, and Microsoft.

```python
def intersection(nums1, nums2):
    s1 = set(nums1)
    result = set()

    for num in nums2:
        if num in s1:
            result.add(num)

    return list(result)
```

### Complexity

* Time: **O(n + m)**
* Space: **O(n)**

---

# Pattern Recognition

| Clue in Problem      | Pattern      |
| -------------------- | ------------ |
| Find common elements | Hash Set     |
| Membership checking  | Hash Set     |
| Unique common values | Set          |
| Two sorted arrays    | Two Pointers |
| Very small input     | Brute Force  |

**Recommended Interview Pattern:** **Hash Set Lookup (O(n + m))**.
