# Longest Consecutive Sequence (Medium)

**Problem:**
Given an unsorted array of integers `nums`, return the length of the longest consecutive elements sequence.

**Example**

```python
Input: nums = [100,4,200,1,3,2]
Output: 4

Explanation:
Sequence = [1,2,3,4]
Length = 4
```

---

# Pattern 1: Brute Force

### Idea

For every number, keep checking whether `num+1`, `num+2`, `num+3`... exist in the array.

### Algorithm

1. Iterate through each element.
2. Continuously search for next consecutive number.
3. Track maximum length.

### Complexity

* Time: **O(n²)**
* Space: **O(1)**

### Code

```python
class Solution:
    def longestConsecutive(self, nums):
        longest = 0

        for num in nums:
            length = 1
            current = num

            while current + 1 in nums:
                current += 1
                length += 1

            longest = max(longest, length)

        return longest
```

### Pattern

✅ Consecutive Sequence Detection
❌ Too slow for interviews

---

# Pattern 2: Sorting Pattern

### Idea

Sort the array first.

After sorting:

```python
[100,4,200,1,3,2]
↓
[1,2,3,4,100,200]
```

Now count consecutive elements.

### Algorithm

1. Sort array.
2. Skip duplicates.
3. Count consecutive streak.
4. Maintain maximum.

### Complexity

* Time: **O(n log n)**
* Space: **O(1)** or **O(n)** (depends on sorting)

### Code

```python
class Solution:
    def longestConsecutive(self, nums):
        if not nums:
            return 0

        nums.sort()

        longest = 1
        current = 1

        for i in range(1, len(nums)):

            if nums[i] == nums[i - 1]:
                continue

            elif nums[i] == nums[i - 1] + 1:
                current += 1

            else:
                longest = max(longest, current)
                current = 1

        return max(longest, current)
```

### Pattern

✅ Sorting + Streak Counting
❌ Doesn't satisfy O(n) requirement

# Pattern 3: Hash Set + Sequence Expansion

### Idea

Store all numbers in a set.

For every number:

* Expand left
* Expand right
* Count sequence length

### Example

```python
[100,4,200,1,3,2]

Start from 4:
4 ← 3 ← 2 ← 1

Length = 4
```

### Complexity

* Time: O(n²) worst case
* Space: O(n)

### Code

```python
class Solution:
    def longestConsecutive(self, nums):
        num_set = set(nums)
        longest = 0

        for num in nums:

            length = 1

            left = num - 1
            while left in num_set:
                length += 1
                left -= 1

            right = num + 1
            while right in num_set:
                length += 1
                right += 1

            longest = max(longest, length)

        return longest
```

### Pattern

✅ Hashing
❌ Repeated work

# Pattern 4: Optimal Hash Set (Interview Pattern)

### Idea

A number starts a sequence only if:

```python
num - 1 not in set
```

This means it is the first element of a sequence.

Then grow only forward.

### Example

```python
nums = [100,4,200,1,3,2]

Set:
{100,4,200,1,3,2}

1 → Start
2 → Continue
3 → Continue
4 → Continue

Length = 4
```

Notice:

```python
2 is not start (1 exists)
3 is not start (2 exists)
4 is not start (3 exists)
```

Thus every sequence is processed exactly once.

---

## Visualization

```text
Set = {100,4,200,1,3,2}

100 → start
      length = 1

4   → skip (3 exists)

200 → start
      length = 1

1   → start
      1→2→3→4
      length = 4
```

Answer = 4

---

### Complexity

* Time: **O(n)**
* Space: **O(n)**

Each number is visited at most once.

---

### Code

```python
class Solution:
    def longestConsecutive(self, nums):
        num_set = set(nums)

        longest = 0

        for num in num_set:

            if num - 1 not in num_set:

                current = num
                length = 1

                while current + 1 in num_set:
                    current += 1
                    length += 1

                longest = max(longest, length)

        return longest
```

# Pattern 5: Hash Map Boundary Merge (Advanced)

### Idea

Maintain sequence lengths at boundaries.

Example:

```python
1 → length 1

Add 2
Sequence = [1,2]
Length = 2

Add 3
Sequence = [1,2,3]
Length = 3
```

Used in some advanced interview discussions.

### Complexity

* Time: O(n)
* Space: O(n)

### Code

```python
class Solution:
    def longestConsecutive(self, nums):
        mp = {}
        longest = 0

        for num in nums:

            if num in mp:
                continue

            left = mp.get(num - 1, 0)
            right = mp.get(num + 1, 0)

            length = left + right + 1

            mp[num] = length

            mp[num - left] = length
            mp[num + right] = length

            longest = max(longest, length)

        return longest
```

# Pattern Comparison

| Pattern                  | Technique               | Time       | Space | Interview Rating |
| ------------------------ | ----------------------- | ---------- | ----- | ---------------- |
| Brute Force              | Linear search           | O(n²)      | O(1)  | ★                |
| Sorting                  | Sort + streak count     | O(n log n) | O(1)  | ★★★              |
| Hash Expansion           | Set + expand both sides | O(n²)      | O(n)  | ★★               |
| Hash Set Start Detection | Set + sequence start    | **O(n)**   | O(n)  | ★★★★★            |
| Boundary Merge           | Hash Map lengths        | **O(n)**   | O(n)  | ★★★★             |

# Optimized Solution Pattern

### Pattern Name

**Hash Set + Sequence Start Detection**

### Recognition Clues

* Unsorted array
* Consecutive integers
* Need O(n)
* Longest streak/sequence
* Presence lookup required

### Template

```python
num_set = set(nums)

for num in num_set:

    if num - 1 not in num_set:

        current = num

        while current + 1 in num_set:
            current += 1
```

### Use In

* Longest Consecutive Sequence
* Longest Increasing Consecutive Streak
* Consecutive Number Tracking
* Sequence Detection Problems

### Interview Choice

✅ **Pattern 4 (Hash Set + Sequence Start Detection)** is the standard Google/Amazon/Meta/Microsoft expected solution because it achieves **O(n)** time and is simple to explain and implement.
