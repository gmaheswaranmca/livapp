# Two Sum

**Problem:** Find indices of two numbers such that they add up to a given target.

**Difficulty:** Easy

**Companies:** Amazon, Google, Meta, Microsoft, Apple

---

## Pattern 1: Brute Force (Nested Loops)

### Idea

Check every pair and see whether their sum equals the target.

### Pattern

* Fix first element.
* Check all remaining elements.
* Return when sum matches target.

### Code

```python
def twoSum(nums, target):
    n = len(nums)

    for i in range(n):
        for j in range(i + 1, n):
            if nums[i] + nums[j] == target:
                return [i, j]

    return []
```

### Complexity

* Time: O(N²)
* Space: O(1)

---

## Pattern 2: Hash Map (Two Pass)

### Idea

Store every number and its index in a hash table.

Then check whether `target - current_number` exists.

### Pattern

1. Build hashmap.
2. Traverse again.
3. Search complement.

### Code

```python
def twoSum(nums, target):
    mp = {}

    for i in range(len(nums)):
        mp[nums[i]] = i

    for i in range(len(nums)):
        complement = target - nums[i]

        if complement in mp and mp[complement] != i:
            return [i, mp[complement]]

    return []
```

### Complexity

* Time: O(N)
* Space: O(N)

---

## Pattern 3: Hash Map (One Pass)

### Idea

While traversing, immediately check whether the complement has already appeared.

### Pattern

1. Calculate complement.
2. Search complement in hashmap.
3. If found → answer.
4. Else store current element.

### Code

```python
def twoSum(nums, target):
    mp = {}

    for i, num in enumerate(nums):
        complement = target - num

        if complement in mp:
            return [mp[complement], i]

        mp[num] = i

    return []
```

### Complexity

* Time: O(N)
* Space: O(N)

---

## Pattern 4: Sorting + Two Pointers

### Idea

Sort the array and use two pointers.

Useful when only values are required. If indices are required, original indices must be preserved.

### Pattern

* Sort values.
* left = 0
* right = n-1
* Move pointers according to sum.

### Code

```python
def twoSum(nums, target):
    arr = sorted(nums)

    left = 0
    right = len(arr) - 1

    while left < right:
        curr = arr[left] + arr[right]

        if curr == target:
            return [arr[left], arr[right]]

        elif curr < target:
            left += 1

        else:
            right -= 1

    return []
```

### Complexity

* Time: O(N log N)
* Space: O(N)

---

# Optimized Solution Pattern

## One-Pass Hashing

### Why it is Optimal

* Single traversal.
* Constant-time lookup using hash map.
* Most commonly expected in interviews.
* Works directly with indices.
* No sorting required.

### Interview Template

```python
def twoSum(nums, target):
    seen = {}

    for i, num in enumerate(nums):
        needed = target - num

        if needed in seen:
            return [seen[needed], i]

        seen[num] = i

    return []
```

### Complexity

* Time: O(N)
* Space: O(N)
