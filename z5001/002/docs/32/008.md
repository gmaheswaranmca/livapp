# Subarray Sum Equals K (LeetCode 560)

**Problem:**
Given an integer array `nums` and an integer `k`, return the **total number of continuous subarrays whose sum equals `k`**.

### Example

```python
nums = [1,1,1]
k = 2

Output: 2
```

Subarrays:

```python
[1,1]  -> sum = 2
[1,1]  -> sum = 2
```

---

# Pattern 1: Brute Force (Generate All Subarrays)

## Idea

Generate every possible subarray and calculate its sum.

## Algorithm

1. Pick starting index.
2. Pick ending index.
3. Compute sum.
4. If sum == k, increment count.

## Code

```python
def subarraySum(nums, k):
    n = len(nums)
    count = 0

    for i in range(n):
        for j in range(i, n):
            s = sum(nums[i:j+1])

            if s == k:
                count += 1

    return count
```

## Complexity

* Time: O(N³)
* Space: O(1)

---

# Pattern 2: Running Sum for Every Start Index

## Idea

Avoid recalculating sum repeatedly.

While expanding subarray, keep a running sum.

## Algorithm

1. Fix start index.
2. Expand end index.
3. Maintain current sum.
4. Check if sum == k.

## Code

```python
def subarraySum(nums, k):
    n = len(nums)
    count = 0

    for i in range(n):
        current_sum = 0

        for j in range(i, n):
            current_sum += nums[j]

            if current_sum == k:
                count += 1

    return count
```

## Complexity

* Time: O(N²)
* Space: O(1)

# Pattern 3: Prefix Sum Array

## Idea

Precompute prefix sums.

Subarray sum:

```text
sum(i...j) = prefix[j+1] - prefix[i]
```

## Code

```python
def subarraySum(nums, k):
    n = len(nums)

    prefix = [0] * (n + 1)

    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]

    count = 0

    for i in range(n):
        for j in range(i, n):
            if prefix[j + 1] - prefix[i] == k:
                count += 1

    return count
```

## Complexity

* Time: O(N²)
* Space: O(N)

# Pattern 4: Prefix Sum + HashMap (Optimal)

## Core Observation

Let:

```text
prefixSum = sum of elements from 0 to current index
```

We need:

```text
currentPrefix - previousPrefix = k
```

Therefore:

```text
previousPrefix = currentPrefix - k
```

If such a prefix already exists, then a subarray with sum `k` exists.

---

## Example

```python
nums = [1, 2, 3]
k = 3
```

| Num | PrefixSum | Need (Prefix-K) | Found? | Count |
| --- | --------- | --------------- | ------ | ----- |
| 1   | 1         | -2              | No     | 0     |
| 2   | 3         | 0               | Yes    | 1     |
| 3   | 6         | 3               | Yes    | 2     |

Answer = 2

Subarrays:

```python
[1,2]
[3]
```

---

## Algorithm

1. Store frequency of prefix sums.
2. Initialize:

```python
{0:1}
```

3. Calculate running prefix sum.
4. Check whether:

```python
prefixSum - k
```

exists.
5. Add its frequency to answer.
6. Update current prefix sum frequency.

---

## Code

```python
def subarraySum(nums, k):
    prefix_count = {0: 1}

    prefix_sum = 0
    count = 0

    for num in nums:
        prefix_sum += num

        if prefix_sum - k in prefix_count:
            count += prefix_count[prefix_sum - k]

        prefix_count[prefix_sum] = (
            prefix_count.get(prefix_sum, 0) + 1
        )

    return count
```

---

## Complexity

* Time: O(N)
* Space: O(N)

# Pattern Recognition

This problem belongs to:

### Prefix Sum + HashMap Pattern

Look for this pattern when asked:

* Count subarrays with sum = K
* Count subarrays divisible by K
* Longest subarray with sum K
* Binary Subarrays With Sum
* Continuous Subarray Sum
* Subarray Sums Divisible by K
* Contiguous Array

Common formula:

```text
Current Prefix - Previous Prefix = Target
```

or

```text
Previous Prefix = Current Prefix - Target
```

## Optimized Solution

✅ **Prefix Sum + HashMap**

```python
def subarraySum(nums, k):
    prefix_count = {0: 1}
    prefix_sum = 0
    count = 0

    for num in nums:
        prefix_sum += num

        count += prefix_count.get(prefix_sum - k, 0)

        prefix_count[prefix_sum] = (

```

**Why optimal?**

* Single traversal.
* Handles positive, negative, and zero values.
* O(N) time complexity.
* Most frequently expected interview solution at Amazon, Google, Meta, and Microsoft.
