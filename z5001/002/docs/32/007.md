# Intersection of Two Arrays II

**Problem:** Given two arrays `nums1` and `nums2`, return their intersection including duplicate occurrences.

**Example**

```python
nums1 = [1,2,2,1]
nums2 = [2,2]

Output: [2,2]
```

---

# Pattern 1: Brute Force (Visited Array)

### Idea

For each element in `nums1`, search in `nums2`.
Mark matched elements as visited.

### Algorithm

1. Create visited array for `nums2`.
2. For every element in `nums1`

   * Scan `nums2`
   * If same element found and not visited

     * Add to result
     * Mark visited

### Complexity

* Time: **O(n × m)**
* Space: **O(m)**

### Code

```python
def intersect(nums1, nums2):
    visited = [False] * len(nums2)
    result = []

    for num in nums1:
        for j in range(len(nums2)):
            if not visited[j] and nums2[j] == num:
                result.append(num)
                visited[j] = True
                break

    return result
```

# Pattern 2: Sorting + Two Pointers

### Idea

Sort both arrays.

If elements match:

* Add to answer
* Move both pointers

Otherwise:

* Move smaller element pointer

### Pattern Used

**Two Pointers on Sorted Arrays**

### Complexity

* Time: **O(n log n + m log m)**
* Space: **O(1)** (excluding sorting)

### Code

```python
def intersect(nums1, nums2):
    nums1.sort()
    nums2.sort()

    i = j = 0
    result = []

    while i < len(nums1) and j < len(nums2):

        if nums1[i] == nums2[j]:
            result.append(nums1[i])
            i += 1
            j += 1

        elif nums1[i] < nums2[j]:
            i += 1

        else:
            j += 1

    return result
```

# Pattern 3: Hash Map Frequency Counting

### Idea

Store frequency of elements from one array.

While traversing second array:

* If frequency exists
* Add to result
* Reduce frequency

### Pattern Used

**Frequency Counter (Hashing)**

### Complexity

* Time: **O(n + m)**
* Space: **O(min(n,m))**

### Code

```python
def intersect(nums1, nums2):

    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    freq = {}

    for num in nums1:
        freq[num] = freq.get(num, 0) + 1

    result = []

    for num in nums2:
        if freq.get(num, 0) > 0:
            result.append(num)
            freq[num] -= 1

    return result
```

# Pattern 4: Counter Library

### Idea

Use Python's `Counter`.

### Complexity

* Time: **O(n + m)**
* Space: **O(min(n,m))**

### Code

```python
from collections import Counter

def intersect(nums1, nums2):

    count = Counter(nums1)
    result = []

    for num in nums2:
        if count[num] > 0:
            result.append(num)
            count[num] -= 1

    return result
```

# Optimized Solution

### Best Pattern

**Hash Map Frequency Counting**

### Why?

* Linear time.
* Handles duplicates naturally.
* No sorting required.
* Most commonly expected by Amazon, Google, Meta, and Microsoft.

### Optimized Code

```python
def intersect(nums1, nums2):

    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    freq = {}

    for num in nums1:
        freq[num] = freq.get(num, 0) + 1

    result = []

    for num in nums2:
        if freq.get(num, 0) > 0:
            result.append(num)
            freq[num] -= 1

    return result
```

### Interview Pattern Recognition

| Clue in Problem                     | Pattern            |
| ----------------------------------- | ------------------ |
| Common elements                     | Hashing            |
| Duplicates matter                   | Frequency Map      |
| Count occurrences                   | Frequency Counter  |
| Need efficient lookup               | Hash Table         |
| Array intersection with frequencies | Hashing + Counting |

**Final Pattern:** **Hash Map Frequency Counting (Frequency Counter Pattern)** → **O(n + m)** time, **O(min(n,m))** space.
