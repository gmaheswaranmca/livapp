# Contains Duplicate II

**Problem:** Given an integer array `nums` and an integer `k`, return `True` if there are two distinct indices `i` and `j` such that:

* `nums[i] == nums[j]`
* `abs(i - j) <= k`

Otherwise return `False`.

**Difficulty:** Easy
**Companies:** Google, Amazon, Meta, Microsoft

---

# Pattern 1: Brute Force (Nested Loop)

## Idea

For every element, check the next `k` elements.

## Algorithm

* For each index `i`
* Check indices from `i+1` to `min(i+k, n-1)`
* If duplicate found → return `True`

## Code

```python
def containsNearbyDuplicate(nums, k):
    n = len(nums)

    for i in range(n):
        for j in range(i + 1, min(i + k + 1, n)):
            if nums[i] == nums[j]:
                return True

    return False
```

## Complexity

* Time: O(n*k)
* Space: O(1)

---

# Pattern 2: Hash Map (Value → Last Seen Index)

## Pattern Name

**Hashing + Index Tracking**

## Idea

Store the last index where each value appeared.

When the same value appears again:

```text
current_index - previous_index <= k
```

then duplicate within distance exists.

---

## Example

```python
nums = [1,2,3,1]
k = 3
```

Processing:

```text
1 -> index 0
2 -> index 1
3 -> index 2

1 appears again at index 3

3 - 0 = 3 <= k
```

Return True.

---

## Code

```python
def containsNearbyDuplicate(nums, k):
    last_seen = {}

    for i, num in enumerate(nums):

        if num in last_seen:
            if i - last_seen[num] <= k:
                return True

        last_seen[num] = i

    return False
```

## Complexity

* Time: O(n)
* Space: O(n)

---

# Pattern 3: Sliding Window + Hash Set

## Pattern Name

**Fixed Size Sliding Window**

## Idea

Maintain a window of size at most `k`.

If a duplicate exists inside the window, answer is `True`.

---

## Example

```python
nums = [1,2,3,1]
k = 3
```

Window:

```text
[1]
[1,2]
[1,2,3]

Next value = 1

Already in window
=> True
```

---

## Code

```python
def containsNearbyDuplicate(nums, k):
    window = set()

    for i in range(len(nums)):

        if nums[i] in window:
            return True

        window.add(nums[i])

        if len(window) > k:
            window.remove(nums[i - k])

    return False
```

---

## Complexity

* Time: O(n)
* Space: O(min(n, k))

---

# Pattern 4: Ordered Window (Balanced BST Concept)

Useful when window-based range queries are also needed.

## Idea

Maintain last `k` elements in an ordered structure.

For this problem it is unnecessary, but appears as a stepping stone to:

* Contains Duplicate III
* Nearby Almost Duplicate
* Range-based searching

## Complexity

* Time: O(n log k)
* Space: O(k)

---

# Pattern Comparison

| Pattern               | Time       | Space | Interview Value |
| --------------------- | ---------- | ----- | --------------- |
| Brute Force           | O(n*k)     | O(1)  | Low             |
| Hash Map (Last Index) | O(n)       | O(n)  | Very High       |
| Sliding Window Set    | O(n)       | O(k)  | Very High       |
| Ordered Window        | O(n log k) | O(k)  | Medium          |

---

# Which Pattern is Optimal?

### Hash Map (Last Seen Index)

```python
last_seen[num] = index
```

**Why?**

* Single pass
* Easy to explain
* Directly checks distance
* Most commonly expected in interviews

Complexity:

```text
Time  : O(n)
Space : O(n)
```

---

# Interview Pattern Recognition

| Clue in Question                      | Pattern                    |
| ------------------------------------- | -------------------------- |
| "Duplicate exists?"                   | Hash Set                   |
| "Duplicate within k distance"         | Hash Map + Last Seen Index |
| "Maintain recent k elements"          | Sliding Window             |
| "Almost duplicate / range difference" | Ordered Set / BST          |
| "Find repeated element quickly"       | Hashing                    |

### Template to Remember

```python
seen = {}

for i, num in enumerate(nums):

    if num in seen and i - seen[num] <= k:
        return True

    seen[num] = i

return False
```

This **Hash Map + Last Seen Index Pattern** is the standard and most optimized solution expected by Google, Amazon, Meta, and Microsoft interviews.
