# Find All Anagrams in a String

**Problem:** Find all starting indices of `p`'s anagrams in string `s`.

Example:

```text
Input:
s = "cbaebabacd"
p = "abc"

Output:
[0, 6]
```

---

# Pattern 1: Generate Every Substring + Sort Comparison (Brute Force)

## Idea

Generate every substring of length `len(p)`, sort it, and compare with sorted pattern.

## Algorithm

1. Sort pattern `p`.
2. For every window of size `m`:

   * Sort window.
   * Compare with sorted pattern.
3. If equal, store index.

## Code

```python
class Solution:
    def findAnagrams(self, s: str, p: str):
        n, m = len(s), len(p)

        if m > n:
            return []

        target = sorted(p)
        result = []

        for i in range(n - m + 1):
            if sorted(s[i:i+m]) == target:
                result.append(i)

        return result
```

### Complexity

```text
Time  : O((N-M+1) * M log M)
Space : O(M)
```

---

# Pattern 2: Frequency Count for Every Window

## Idea

Count character frequencies for each substring.

## Algorithm

1. Build frequency count of pattern.
2. For every window:

   * Create frequency count.
   * Compare with pattern count.

## Code

```python
from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str):
        n, m = len(s), len(p)

        if m > n:
            return []

        p_count = Counter(p)
        result = []

        for i in range(n - m + 1):
            window = Counter(s[i:i+m])

            if window == p_count:
                result.append(i)

        return result
```

### Complexity

```text
Time  : O((N-M+1) * M)
Space : O(26)
```

# Pattern 3: Sliding Window + Counter

## Idea

Instead of rebuilding count every time, slide the window.

## Algorithm

1. Store pattern frequency.
2. Build first window.
3. Slide:

   * Add right character.
   * Remove left character.
4. Compare counters.

## Code

```python
from collections import Counter

class Solution:
    def findAnagrams(self, s: str, p: str):
        n, m = len(s), len(p)

        if m > n:
            return []

        p_count = Counter(p)
        window = Counter(s[:m])

        result = []

        if window == p_count:
            result.append(0)

        for i in range(m, n):

            window[s[i]] += 1

            left_char = s[i - m]
            window[left_char] -= 1

            if window[left_char] == 0:
                del window[left_char]

            if window == p_count:
                result.append(i - m + 1)

        return result
```

### Complexity

```text
Time  : O(N * 26)
Space : O(26)
```

# Pattern 4: Sliding Window + Fixed Array Frequency (Optimal)

## Idea

Since only lowercase English letters exist, use two arrays of size 26.

This avoids Counter overhead and hash lookups.

## Algorithm

1. Create two arrays:

   * pattern frequency
   * window frequency
2. Initialize first window.
3. Compare arrays.
4. Slide:

   * Increment entering character.
   * Decrement leaving character.
5. Compare arrays.

## Code

```python
class Solution:
    def findAnagrams(self, s: str, p: str):
        n, m = len(s), len(p)

        if m > n:
            return []

        p_count = [0] * 26
        window = [0] * 26

        for ch in p:
            p_count[ord(ch) - ord('a')] += 1

        for ch in s[:m]:
            window[ord(ch) - ord('a')] += 1

        result = []

        if window == p_count:
            result.append(0)

        for i in range(m, n):

            window[ord(s[i]) - ord('a')] += 1
            window[ord(s[i-m]) - ord('a')] -= 1

            if window == p_count:
                result.append(i - m + 1)

        return result
```

### Complexity

```text
Time  : O(N)
Space : O(26)
```

# Pattern 5: Sliding Window + Match Count (Most Interview-Optimized)

## Idea

Avoid comparing all 26 positions after every slide.

Track how many character frequencies currently match.

## Algorithm

1. Build frequency arrays.
2. Count matching positions.
3. While sliding:

   * Update entering character.
   * Update leaving character.
   * Adjust match count.
4. If matches = 26 → anagram found.

## Code

```python
class Solution:
    def findAnagrams(self, s: str, p: str):

        n, m = len(s), len(p)

        if m > n:
            return []

        p_count = [0] * 26
        window = [0] * 26

        for ch in p:
            p_count[ord(ch) - ord('a')] += 1

        for ch in s[:m]:
            window[ord(ch) - ord('a')] += 1

        matches = 0

        for i in range(26):
            if p_count[i] == window[i]:
                matches += 1

        result = []

        if matches == 26:
            result.append(0)

        left = 0

        for right in range(m, n):

            idx = ord(s[right]) - ord('a')

            if window[idx] == p_count[idx]:
                matches -= 1

            window[idx] += 1

            if window[idx] == p_count[idx]:
                matches += 1

            idx = ord(s[left]) - ord('a')

            if window[idx] == p_count[idx]:
                matches -= 1

            window[idx] -= 1

            if window[idx] == p_count[idx]:
                matches += 1

            left += 1

            if matches == 26:
                result.append(left)

        return result
```

### Complexity

```text
Time  : O(N)
Space : O(26)
```

# Pattern Comparison

| Pattern | Technique                    | Time           | Space |
| ------- | ---------------------------- | -------------- | ----- |
| 1       | Sort Every Window            | O(N × M log M) | O(M)  |
| 2       | Rebuild Frequency            | O(N × M)       | O(26) |
| 3       | Sliding Window + Counter     | O(N)           | O(26) |
| 4       | Sliding Window + Array       | O(N)           | O(26) |
| 5       | Sliding Window + Match Count | O(N)           | O(26) |
