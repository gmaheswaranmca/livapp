# Full Progression of Coding Categories

Typical progression:

```text
Conditionals
   ↓
Loops
   ↓
Arrays & Strings
   ↓
Functions & Recursion
   ↓
Basic Data Structures
   ↓
Algorithms & Patterns
   ↓
Advanced DSA
   ↓
System Design
```

For Tier-1 preparation, companies assume:

* conditionals
* loops
* functions
* arrays
* basic strings

are already mastered foundations before advanced DSA rounds begin.
