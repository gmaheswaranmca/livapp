# Search in Rotated Sorted Array

Given a rotated sorted array and a target value, return the index of the target.
If not found, return `-1`.

Example:

```text
Input:
nums = [4,5,6,7,0,1,2]
target = 0

Output:
4
```

---

# Main Patterns Used

1. Linear Search
2. Binary Search after Finding Pivot
3. Modified Binary Search (Optimized)

---

# 1. Linear Search Pattern

## Idea

Traverse the array one by one and compare with target.

## Pattern Type

* Brute Force
* Sequential Traversal

## Time Complexity

* Time: `O(n)`
* Space: `O(1)`

## Code

```python
def search(nums, target):
    for i in range(len(nums)):
        if nums[i] == target:
            return i
    return -1


nums = [4,5,6,7,0,1,2]
target = 0

print(search(nums, target))
```

---

# 2. Binary Search After Finding Pivot

## Idea

Rotated array has two sorted halves.

Steps:

1. Find pivot index
2. Decide which side target belongs to
3. Apply binary search

---

## Pattern Type

* Binary Search
* Pivot Detection

---

## Time Complexity

* Pivot Search: `O(log n)`
* Binary Search: `O(log n)`
* Total: `O(log n)`

---

## Code

```python
def find_pivot(nums):
    low = 0
    high = len(nums) - 1

    while low < high:
        mid = (low + high) // 2

        if nums[mid] > nums[high]:
            low = mid + 1
        else:
            high = mid

    return low


def binary_search(nums, low, high, target):
    while low <= high:
        mid = (low + high) // 2

        if nums[mid] == target:
            return mid

        elif nums[mid] < target:
            low = mid + 1

        else:
            high = mid - 1

    return -1


def search(nums, target):
    n = len(nums)

    pivot = find_pivot(nums)

    if nums[pivot] <= target <= nums[n - 1]:
        return binary_search(nums, pivot, n - 1, target)

    return binary_search(nums, 0, pivot - 1, target)


nums = [4,5,6,7,0,1,2]
target = 0

print(search(nums, target))
```

# 3. Modified Binary Search (Most Optimized)

## Idea

At every step:

* One half is always sorted
* Check whether target lies in sorted half
* Eliminate the other half

No separate pivot finding needed.

---

## Pattern Type

* Modified Binary Search
* Divide and Conquer

---

## Time Complexity

* Time: `O(log n)`
* Space: `O(1)`

---

## Core Logic Visualization

f(n)=\log n

---

## Code

```python
def search(nums, target):
    low = 0
    high = len(nums) - 1

    while low <= high:

        mid = (low + high) // 2

        if nums[mid] == target:
            return mid

        # Left half sorted
        if nums[low] <= nums[mid]:

            # Target inside left half
            if nums[low] <= target < nums[mid]:
                high = mid - 1

            else:
                low = mid + 1

        # Right half sorted
        else:

            # Target inside right half
            if nums[mid] < target <= nums[high]:
                low = mid + 1

            else:
                high = mid - 1

    return -1


nums = [4,5,6,7,0,1,2]
target = 0

print(search(nums, target))
```

Move right:

```text
low = mid + 1
```

```text

```

Left half sorted:

```text
[0,1]
```

Target inside left half.

Move left:

```text
high = mid - 1
```

low = 4

# Comparison of Patterns

| Pattern                | Time     | Space | Easy?     | Interview Value |
| ---------------------- | -------- | ----- | --------- | --------------- |
| Linear Search          | O(n)     | O(1)  | Very Easy | Low             |
| Pivot + Binary Search  | O(log n) | O(1)  | Medium    | Good            |
| Modified Binary Search | O(log n) | O(1)  | Medium    | Best            |

---

# Optimized Pattern

## Best Choice

✅ Modified Binary Search

Because:

* No extra pivot function
* Single traversal
* Cleaner logic
* Most asked in interviews
* Optimal `O(log n)`

---

# Important Interview Observation

In rotated sorted arrays:

```text
At least one half is always sorted
```

This is the key observation used to eliminate half of the array every iteration.
