# 3Sum

Find all **unique triplets** in the array such that:

```text
a + b + c = 0
```

Example:

```text
Input:  [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
```

---

# Solution Patterns

## Pattern 1 — Brute Force (3 Nested Loops)

### Idea

Try every possible triplet.

* Pick first number
* Pick second number
* Pick third number
* Check if sum is 0
* Use a set to avoid duplicates

---

## Time Complexity

```text
O(n³)
```

## Space Complexity

```text
O(k)
```

(k = number of unique triplets)

---

## Code

```python
def three_sum_bruteforce(nums):
    n = len(nums)
    result = set()

    for i in range(n):
        for j in range(i + 1, n):
            for k in range(j + 1, n):

                if nums[i] + nums[j] + nums[k] == 0:
                    triplet = tuple(sorted([nums[i], nums[j], nums[k]]))
                    result.add(triplet)

    return [list(x) for x in result]


nums = [-1,0,1,2,-1,-4]
print(three_sum_bruteforce(nums))
```

---

# Pattern 2 — Hashing / Two Sum Inside Loop

## Idea

Fix one element.

Then solve remaining problem as:

```text
Two Sum = -nums[i]
```

Use a hash set to find complement.

---

## Time Complexity

```text
O(n²)
```

## Space Complexity

```text
O(n)
```

---

## Code

```python
def three_sum_hashing(nums):
    n = len(nums)
    result = set()

    for i in range(n):

        seen = set()

        for j in range(i + 1, n):

            target = -(nums[i] + nums[j])

            if target in seen:
                triplet = tuple(sorted([nums[i], nums[j], target]))
                result.add(triplet)

            seen.add(nums[j])

    return [list(x) for x in result]


nums = [-1,0,1,2,-1,-4]
print(three_sum_hashing(nums))
```

# Pattern 3 — Sorting + Two Pointers (Optimized)

## Idea

This is the most important and interview-expected pattern.

### Steps

1. Sort array
2. Fix one element
3. Use:

   * left pointer
   * right pointer
4. Move pointers based on sum

---

## Visualization

Sorted array:

```text
[-4, -1, -1, 0, 1, 2]
```

Fix:

```text
i = -1
```

Now solve:

```text
left + right = 1
```

using two pointers.

---

# Optimized Logic

If:

```text
sum < 0
```

move left forward.

If:

```text
sum > 0
```

move right backward.

If:

```text
sum == 0
```

store answer and skip duplicates.

---

## Time Complexity

```text
O(n²)
```

## Space Complexity

```text
O(1)
```

(ignoring output array)

---

# Optimized Code

```python
def three_sum(nums):

    nums.sort()

    result = []
    n = len(nums)

    for i in range(n):

        # Skip duplicate fixed elements
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        left = i + 1
        right = n - 1

        while left < right:

            total = nums[i] + nums[left] + nums[right]

            if total < 0:
                left += 1

            elif total > 0:
                right -= 1

            else:
                result.append([nums[i], nums[left], nums[right]])

                left += 1
                right -= 1

                # Skip duplicates
                while left < right and nums[left] == nums[left - 1]:
                    left += 1

                while left < right and nums[right] == nums[right + 1]:
                    right -= 1

    return result


nums = [-1,0,1,2,-1,-4]
print(three_sum(nums))
```

# Dry Run

Input:

```text

```

After sorting:

```text
[-4,-1,-1,0,1,2]
```

### Fixed = -4

```text
Need pair sum = 4
```

No valid pair.

---

### Fixed = -1

Pointers:

```text
left = -1
right = 2
```

Sum:

```text
-1 + -1 + 2 = 0
```

Answer:

```text
[-1,-1,2]
```

Move pointers.

---


```text
[-1,0,1]
```

# Why Sorting + Two Pointer is Best

| Pattern               | Time  | Space | Interview Value |
| --------------------- | ----- | ----- | --------------- |
| Brute Force           | O(n³) | O(k)  | Low             |
| Hashing               | O(n²) | O(n)  | Medium          |
| Sorting + Two Pointer | O(n²) | O(1)  | Best            |

# Key Interview Insight

The major optimization comes from:

```text
Sorting + Two Pointer
```

because:

```text
Two Sum in sorted array = O(n)
```

So overall:

```text
Outer loop O(n)
Inner two pointer O(n)

=> O(n²)
```
