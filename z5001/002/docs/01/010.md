# Find Minimum in Rotated Sorted Array

Find the smallest element in a rotated sorted array.

Example:

```text
Input:  [4,5,6,7,0,1,2]
Output: 0
```

---

# Key Observation

A rotated sorted array has:

* One sorted half
* One unsorted half
* Minimum element lies in the unsorted part

Example:

```text
[4,5,6,7,0,1,2]
         ^
       minimum
```

---

# Solution Patterns

---

# Pattern 1 — Linear Scan

## Idea

Traverse entire array and track minimum.

---

## Code

```python
def find_min(nums):
    minimum = nums[0]

    for num in nums:
        if num < minimum:
            minimum = num

    return minimum
```

---

## Complexity

* Time: O(n)
* Space: O(1)

---

## When Useful

* Very small arrays
* Simplicity preferred

---

# Pattern 2 — Compare Adjacent Elements

## Idea

In rotated array:

```text
previous > current
```

That current element is minimum.

Example:

```text
[4,5,6,7,0,1,2]
        7 > 0
```

---

## Code

```python
def find_min(nums):
    n = len(nums)

    for i in range(1, n):
        if nums[i - 1] > nums[i]:
            return nums[i]

    return nums[0]
```

---

## Complexity

* Time: O(n)
* Space: O(1)

---

## Special Insight

If no breaking point exists:

```text
[1,2,3,4,5]
```

then array was never rotated.

Minimum = first element.

---

# Pattern 3 — Binary Search (Optimized)

## Core Idea

Use sorted-half property.

---

## Important Observation

If:

```text
nums[mid] > nums[right]
```

minimum is on right side.

Else:

```text
minimum is on left side including mid
```

---

# Visual Understanding

Example:

```text
[4,5,6,7,0,1,2]

left = 0
right = 6

mid = 3 → value = 7

7 > 2
```

Minimum must be right side.

Move:

```text
left = mid + 1
```

---

# Binary Search Logic

```text
Case 1:
nums[mid] > nums[right]
Minimum is right side

Case 2:
nums[mid] <= nums[right]
Minimum is left side including mid
```

---

## Code

```python
def find_min(nums):
    left = 0
    right = len(nums) - 1

    while left < right:

        mid = (left + right) // 2

        # minimum in right half
        if nums[mid] > nums[right]:
            left = mid + 1

        # minimum in left half including mid
        else:
            right = mid

    return nums[left]
```

---

Input:


```text

```


```text

```

```text
nums[4] = 0
```

# Complexity Comparison

| Pattern             | Time     | Space | Efficient |
| ------------------- | -------- | ----- | --------- |
| Linear Scan         | O(n)     | O(1)  | No        |
| Adjacent Comparison | O(n)     | O(1)  | No        |
| Binary Search       | O(log n) | O(1)  | Yes       |

---

# Optimized Solution Pattern

## Best Pattern

Binary Search

Because:

* Array is partially sorted
* We can eliminate half search space
* O(log n) time complexity

---

# Most Important Binary Search Rule

```text
nums[mid] > nums[right]
```

means:

```text
minimum is on right side
```

otherwise:

```text
minimum is on left side including mid
```

---

# Final Optimized Code

```python
def find_min(nums):

    left = 0
    right = len(nums) - 1

    while left < right:

        mid = (left + right) // 2

        if nums[mid] > nums[right]:
            left = mid + 1
        else:
            right = mid

    return nums[left]
```

# Interview Follow-Up

If duplicates exist:

```text
[2,2,2,0,1]
```

then additional handling is required because:

```text
nums[mid] == nums[right]
```

cannot determine side confidently.
