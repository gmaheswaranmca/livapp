# Container With Most Water

Given an array `height[]`, where each element represents the height of a vertical line at index `i`.

Find two lines that together with the x-axis form a container that can hold the maximum amount of water.

Example:

```text
Input:  [1,8,6,2,5,4,8,3,7]
Output: 49

Explanation:
Choose heights 8 and 7.
Width = 8 - 1 = 7
Area = min(8,7) * 7 = 49
```

---

# Core Formula

Area between two lines:

\text{Area} = \min(h_i, h_j) \times (j-i)

Where:

* `h_i` = left height
* `h_j` = right height
* `j - i` = width

---

# Solution Patterns

---

# Pattern 1 — Brute Force

## Idea

Try every pair of lines.

For each pair:

1. Calculate width
2. Calculate minimum height
3. Compute area
4. Track maximum

---

## Time Complexity

* Time: `O(n²)`
* Space: `O(1)`

---

## Python Code

```python
def maxArea(height):
    n = len(height)
    max_area = 0

    for i in range(n):
        for j in range(i + 1, n):

            width = j - i
            curr_height = min(height[i], height[j])

            area = width * curr_height

            max_area = max(max_area, area)

    return max_area


arr = [1,8,6,2,5,4,8,3,7]
print(maxArea(arr))
```

---

# Pattern 2 — Two Pointer Pattern (Optimized)

## Idea

Use two pointers:

* Left pointer at start
* Right pointer at end

Why?

Because width is already maximum initially.

Now:

* Area depends on:

  * width
  * smaller height

If we keep the smaller height:

* area can never improve

So:

* move the smaller height pointer inward

This is the key greedy observation.

---

# Visualization

```text
[1,8,6,2,5,4,8,3,7]
 L               R

Area = min(1,7) * 8 = 8

Move L because 1 is smaller.
```

---

## Optimized Logic

At every step:

```text
If left height < right height:
    move left pointer
Else:
    move right pointer
```

---

## Time Complexity

* Time: `O(n)`
* Space: `O(1)`

---

## Python Code

```python
def maxArea(height):

    left = 0
    right = len(height) - 1

    max_area = 0

    while left < right:

        width = right - left

        curr_height = min(height[left], height[right])

        area = width * curr_height

        max_area = max(max_area, area)

        # Move smaller height
        if height[left] < height[right]:
            left += 1
        else:
            right -= 1

    return max_area


arr = [1,8,6,2,5,4,8,3,7]
print(maxArea(arr))
```

## Step 1

```text

Move left
```

---

## Step 2

```text
L=8, R=7
Width = 7
Area = 7 * 7 = 49
Move right
```

Maximum becomes `49`.

---

# Why Two Pointer Works

Suppose:

```text
height[left] < height[right]
```

Current area:

```text
height[left] * width
```

Even if width decreases,
we need a taller left height to possibly improve area.

Keeping smaller height cannot help.

So we discard it safely.

This reduces:

```text
O(n²) → O(n)
```
