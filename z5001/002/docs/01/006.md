# Maximum Product Subarray

Find the contiguous subarray with the largest product.

Example:

```text
Input:  [2,3,-2,4]
Output: 6
Explanation: [2,3] => 2 * 3 = 6
```

---

# Key Observation

Unlike Maximum Sum Subarray, product problems are tricky because:

* Negative × Negative = Positive
* Multiplying by `0` resets the product

So we must track:

* current maximum product
* current minimum product

because a minimum negative value can become maximum later.

---

# Solution Patterns

| Pattern                           | Idea                                       | Time  | Space | Recommended |
| --------------------------------- | ------------------------------------------ | ----- | ----- | ----------- |
| Brute Force                       | Generate all subarrays and compute product | O(n²) | O(1)  | ❌           |
| Prefix Product                    | Maintain rolling products                  | O(n²) | O(1)  | ❌           |
| Dynamic Tracking (Kadane Variant) | Track max/min products                     | O(n)  | O(1)  | ✅ Best      |

---

# Pattern 1 — Brute Force

## Idea

Generate every contiguous subarray.

Compute product for each.

Keep maximum.

---

## Code

```python
def maxProduct(nums):
    n = len(nums)
    ans = nums[0]

    for i in range(n):
        product = 1

        for j in range(i, n):
            product *= nums[j]
            ans = max(ans, product)

    return ans


nums = [2, 3, -2, 4]
print(maxProduct(nums))
```

---

## How it Works

Subarrays:

```text
[2] = 2
[2,3] = 6
[2,3,-2] = -12
[2,3,-2,4] = -48
[3] = 3
[3,-2] = -6
[3,-2,4] = -24
[-2] = -2
[-2,4] = -8
[4] = 4
```

Maximum = `6`

---

## Complexity

```text
Time  : O(n²)
Space : O(1)
```

---

# Pattern 2 — Prefix Product Style

## Idea

Keep multiplying forward.

Reset when product becomes `0`.

Can also scan from both directions.

This improves handling of negatives.

---

## Code

```python
def maxProduct(nums):
    n = len(nums)

    prefix = 1
    suffix = 1

    ans = nums[0]

    for i in range(n):

        if prefix == 0:
            prefix = 1

        if suffix == 0:
            suffix = 1

        prefix *= nums[i]
        suffix *= nums[n - 1 - i]

        ans = max(ans, prefix, suffix)

    return ans


nums = [2, 3, -2, 4]
print(maxProduct(nums))
```

---

## Why Two Directions?

Negative numbers can flip signs.

Example:

```text
[-1,-2,-3]
```

Forward product:

```text
-1
2
-6
```

Backward scan helps catch missed positive products.

---

## Complexity

```text
Time  : O(n)
Space : O(1)
```

# Pattern 3 — Dynamic Tracking (Optimized Kadane Variant)

## Core Idea

At every index:

We maintain:

* `cur_max`
* `cur_min`

because:

```text
negative × minimum negative = maximum positive
```

---

## Transition Logic

If current number is negative:

```text
max becomes min
min becomes max
```

So swap them.

---

## Optimized Code

```python
def maxProduct(nums):

    cur_max = nums[0]
    cur_min = nums[0]

    ans = nums[0]

    for i in range(1, len(nums)):

        num = nums[i]

        # negative flips max/min
        if num < 0:
            cur_max, cur_min = cur_min, cur_max

        cur_max = max(num, cur_max * num)
        cur_min = min(num, cur_min * num)

        ans = max(ans, cur_max)

    return ans


nums = [2, 3, -2, 4]
print(maxProduct(nums))
```

---

# Dry Run

Input:

```text
[2,3,-2,4]
```

Initial:

```text
cur_max = 2
cur_min = 2
ans = 2
```

---

### num = 3

```text
cur_max = max(3, 2*3) = 6
cur_min = min(3, 2*3) = 3

ans = 6
```

---

### num = -2

Negative → swap

```text
cur_max = 3
cur_min = 6
```

Update:

```text
cur_max = max(-2, 3*-2) = -2
cur_min = min(-2, 6*-2) = -12
```

---

### num = 4

```text
cur_max = max(4, -2*4) = 4
cur_min = min(4, -12*4) = -48
```

Final:

```text
ans = 6
```

---

# Most Important Interview Concept

For maximum sum:

```text
Only maximum matters
```

For maximum product:

```text
Both maximum and minimum matter
```

because negatives flip signs.

---

# Final Recommended Pattern

## Use:

### Dynamic Tracking (Kadane Variant)

Why?

* Optimal O(n)
* Handles negatives elegantly
* Most asked in interviews
* Clean logic
* Standard accepted solution

# Final Optimized Code

```python
def maxProduct(nums):

    cur_max = nums[0]
    cur_min = nums[0]
    ans = nums[0]

    for num in nums[1:]:

        if num < 0:
            cur_max, cur_min = cur_min, cur_max

        cur_max = max(num, cur_max * num)
        cur_min = min(num, cur_min * num)

        ans = max(ans, cur_max)

    return ans
```
