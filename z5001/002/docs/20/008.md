# Factorial Trailing Zeroes

**Problem:**
Given an integer `n`, return the number of trailing zeroes in `n!`.

**Asked By:** Microsoft, Amazon, Google, Meta
**Difficulty:** Medium

---

# Key Observation

A trailing zero is produced by:

[
10 = 2 \times 5
]

In `n!`, there are always more factors of `2` than factors of `5`.

Therefore:

**Number of trailing zeroes = Number of factors of 5 in n!**

---

# Pattern 1: Compute Factorial and Count Zeroes

## Idea

1. Compute `n!`
2. Convert to string.
3. Count zeroes from the end.

## Complexity

* Time: **O(n)**
* Space: **O(n)** (huge factorial value)

## Code

```python
def trailingZeroes(n):
    fact = 1

    for i in range(2, n + 1):
        fact *= i

    count = 0

    while fact % 10 == 0:
        count += 1
        fact //= 10

    return count
```

---

# Pattern 2: Count Factors of 5 Individually

## Idea

For every number from `1` to `n`:

* Count how many times it is divisible by `5`
* Add to answer

Example:

```
25 contributes 2 fives
125 contributes 3 fives
```

## Complexity

* Time: **O(n log n)**
* Space: **O(1)**

## Code

```python
def trailingZeroes(n):
    count = 0

    for num in range(5, n + 1):
        x = num

        while x % 5 == 0:
            count += 1
            x //= 5

    return count
```

# Pattern 3: Mathematical Counting of Powers of 5

## Idea

Count multiples of:

* 5
* 25
* 125
* 625
* ...

Formula:

[
\left\lfloor \frac{n}{5} \right\rfloor
+
\left\lfloor \frac{n}{25} \right\rfloor
+
\left\lfloor \frac{n}{125} \right\rfloor
+\cdots
]

Example:

For `n = 100`

```
100//5   = 20
100//25  = 4
100//125 = 0
```

Answer:

```
20 + 4 = 24
```

## Complexity

* Time: **O(log₅ n)**
* Space: **O(1)**

## Code

```python
def trailingZeroes(n):
    count = 0

    while n > 0:
        n //= 5
        count += n

    return count
```

---

# Pattern 4: Recursive Mathematical Approach

## Idea

Same mathematical formula recursively.

[
f(n) = \left\lfloor \frac{n}{5} \right\rfloor + f\left(\left\lfloor \frac{n}{5} \right\rfloor\right)
]

## Complexity

* Time: **O(log₅ n)**
* Space: **O(log₅ n)** (recursion stack)

## Code

```python
def trailingZeroes(n):
    if n == 0:
        return 0

    return n // 5 + trailingZeroes(n // 5)
```

# Example Walkthrough

For `n = 125`

Factors of 5 come from:

```
125//5   = 25
125//25  = 5
125//125 = 1
```

Total:

```
25 + 5 + 1 = 31
```

Therefore:

```
125! has 31 trailing zeroes
```

# Optimized Solution

```python
def trailingZeroes(n):
    count = 0

    while n:
        n //= 5
        count += n

    return count
```

### Why it is optimal

* Does not compute factorial.
* Uses the mathematical property of trailing zeroes.
* Constant extra memory.
* Runs in only **O(log₅ n)** operations.

### Interview Recommendation

Progression typically discussed in interviews:

1. Brute Force Factorial
2. Observe `10 = 2 × 5`
3. Count factors of `5`
4. Derive:

[
\sum_{k=1}^{\infty}\left\lfloor \frac{n}{5^k}\right\rfloor
]



5. Implement the iterative mathematical solution (**Pattern 3**), which is the expected interview answer.
