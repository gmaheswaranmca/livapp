# Ugly Number II (LeetCode 264)

**Problem:**
Find the **n-th ugly number**.

Ugly numbers are positive numbers whose prime factors are limited to **2, 3, and 5**.

### Example

```text
Input: n = 10

Ugly Numbers:
1, 2, 3, 4, 5, 6, 8, 9, 10, 12

Output: 12
```

---

# Solution Patterns

## Pattern 1: Brute Force + Ugly Check

Generate numbers one by one and check whether each number is ugly.

### Idea

For every number:

* Divide by 2 until not divisible.
* Divide by 3 until not divisible.
* Divide by 5 until not divisible.
* If remaining value becomes 1 → ugly.

### Code

```python
def is_ugly(num):
    if num <= 0:
        return False

    for factor in [2, 3, 5]:
        while num % factor == 0:
            num //= factor

    return num == 1


def nthUglyNumber(n):
    count = 0
    num = 0

    while count < n:
        num += 1

        if is_ugly(num):
            count += 1

    return num
```

### Complexity

```text
Time  : Very High
Space : O(1)
```

Not practical for large n.

# Pattern 2: Min Heap (Generate in Sorted Order)

### Idea

Start with 1.

For every ugly number popped:

Generate:

```text
x * 2
x * 3
x * 5
```

Use:

* Min Heap → smallest ugly first
* Set → avoid duplicates

### Code

```python
import heapq

def nthUglyNumber(n):
    heap = [1]
    visited = {1}

    ugly = 1

    for _ in range(n):
        ugly = heapq.heappop(heap)

        for factor in [2, 3, 5]:
            nxt = ugly * factor

            if nxt not in visited:
                visited.add(nxt)
                heapq.heappush(heap, nxt)

    return ugly
```

### Complexity

```text
Time  : O(n log n)
Space : O(n)
```

# Pattern 3: Dynamic Programming + Three Pointers

This is the standard interview solution.

### Observation

Every ugly number comes from:

```text
previous ugly × 2
previous ugly × 3
previous ugly × 5
```

Maintain:

```text
i2 → next multiple of 2
i3 → next multiple of 3
i5 → next multiple of 5
```

Generate ugly numbers in sorted order.

---

## Example

```text
ugly = [1]

2*1 = 2
3*1 = 3
5*1 = 5

Pick minimum = 2

ugly = [1,2]

Next:
2*2 = 4
3*1 = 3
5*1 = 5

Pick minimum = 3

ugly = [1,2,3]
```

Continue until nth number.

---

### Code

```python
def nthUglyNumber(n):
    ugly = [0] * n

    ugly[0] = 1

    i2 = i3 = i5 = 0

    next2 = 2
    next3 = 3
    next5 = 5

    for i in range(1, n):

        next_ugly = min(next2, next3, next5)

        ugly[i] = next_ugly

        if next_ugly == next2:
            i2 += 1
            next2 = ugly[i2] * 2

        if next_ugly == next3:
            i3 += 1
            next3 = ugly[i3] * 3

        if next_ugly == next5:
            i5 += 1
            next5 = ugly[i5] * 5

    return ugly[-1]
```

### Complexity

```text
Time  : O(n)
Space : O(n)
```

# Pattern 4: DP + Pointer Array (Generalized K Pointers)

Useful when ugly factors become:

```text
[2, 3, 5, 7]
```

or arbitrary primes.

### Code

```python
def nthUglyNumber(n):
    primes = [2, 3, 5]

    ugly = [1] * n

    pointers = [0] * len(primes)

    for i in range(1, n):

        candidates = [
            ugly[pointers[j]] * primes[j]
            for j in range(len(primes))
        ]

        next_ugly = min(candidates)

        ugly[i] = next_ugly

        for j in range(len(primes)):
            if candidates[j] == next_ugly:
                pointers[j] += 1

    return ugly[-1]
```

### Complexity

```text
Time  : O(n × k)
Space : O(n)
```

where `k = number of primes`.

# Optimized Solution

### Dynamic Programming + Three Pointers

```python
def nthUglyNumber(n):
    ugly = [1] * n

    i2 = i3 = i5 = 0

    for i in range(1, n):

        next_ugly = min(
            ugly[i2] * 2,
            ugly[i3] * 3,
            ugly[i5] * 5
        )

        ugly[i] = next_ugly

        if next_ugly == ugly[i2] * 2:
            i2 += 1

        if next_ugly == ugly[i3] * 3:
            i3 += 1

        if next_ugly == ugly[i5] * 5:
            i5 += 1

    return ugly[-1]
```

### Why this is optimal

* Generates ugly numbers directly in sorted order.
* No factor checking.
* No heap operations.
* Handles duplicates naturally (`6 = 2×3 = 3×2`).
* Accepted optimal solution used in most interviews.

### Final Complexity

```text
Time  : O(n)
Space : O(n)
```

### Interview Pattern Recognition

Whenever you see:

```text
Generate nth number
Number formed from previous numbers
Multiple generators (×2, ×3, ×5)
Need sorted sequence
```

think:

```text
Dynamic Programming + Multiple Pointers
```

This same pattern is used in:

* Super Ugly Number
* Merge K Sorted Streams
* Hamming Numbers
* K-way Sequence Generation problems.
