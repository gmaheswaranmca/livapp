# Power of Four (Easy)

**Problem:**
Given an integer `n`, return `True` if it is a power of 4, otherwise return `False`.

**Examples**

```text
Input: n = 16
Output: True

Input: n = 8
Output: False

Input: n = 1
Output: True
```

---

# Pattern 1: Repeated Division by 4 (Brute Force)

## Idea

Keep dividing by 4 until the number becomes 1.

## Algorithm

1. If `n <= 0`, return `False`.
2. While `n % 4 == 0`, divide by 4.
3. If final value is 1, return `True`.

## Code

```python
def isPowerOfFour(n):
    if n <= 0:
        return False

    while n % 4 == 0:
        n //= 4

    return n == 1
```

## Complexity

* Time: `O(log₄ n)`
* Space: `O(1)`

---

# Pattern 2: Recursive Division

## Idea

A power of 4 can be repeatedly divided by 4 until reaching 1.

## Code

```python
def isPowerOfFour(n):
    if n == 1:
        return True

    if n <= 0 or n % 4 != 0:
        return False

    return isPowerOfFour(n // 4)
```

## Complexity

* Time: `O(log₄ n)`
* Space: `O(log₄ n)` (recursion stack)

---

# Pattern 3: Logarithm Based

## Idea

For power of four:

n=4^k

Take logarithm base 4 and check if result is an integer.

## Code

```python
import math

def isPowerOfFour(n):
    if n <= 0:
        return False

    k = math.log(n, 4)
    return abs(k - round(k)) < 1e-10
```

## Complexity

* Time: `O(1)`
* Space: `O(1)`

## Limitation

Floating-point precision issues.

# Pattern 4: Bit Manipulation (Power of Two + Position Check)

## Observation

Every power of four is also a power of two.

```text
1   = 0001
4   = 0100
16  = 00010000
64  = 01000000
```

Single set bit appears only at even positions (0,2,4,...).

### Step 1: Check Power of Two

n\ &\ (n-1)=0

### Step 2: Check Bit Position

Use mask:

```text
0x55555555
=
01010101010101010101010101010101
```

It keeps only even-position bits.

## Code

```python
def isPowerOfFour(n):
    return (
        n > 0 and
        (n & (n - 1)) == 0 and
        (n & 0x55555555) != 0
    )
```

## Complexity

* Time: `O(1)`
* Space: `O(1)`

---

# Pattern 5: Mathematical Property

## Observation

All powers of four are powers of two.

Also:

```text
4^k % 3 = 1
```

Examples:

```text
1  % 3 = 1
4  % 3 = 1
16 % 3 = 1
64 % 3 = 1
```

So:

1. Must be power of two.
2. Must satisfy `n % 3 == 1`.

## Code

```python
def isPowerOfFour(n):
    return (
        n > 0 and
        (n & (n - 1)) == 0 and
        n % 3 == 1
    )
```

## Complexity

* Time: `O(1)`
* Space: `O(1)`

# Optimized Solution

## Best Interview Solution

```python
def isPowerOfFour(n):
    return (
        n > 0 and
        (n & (n - 1)) == 0 and
        (n & 0x55555555) != 0
    )
```

### Why?

* Constant time.
* Constant space.
* No loops.
* No recursion.
* No floating-point errors.
* Demonstrates strong understanding of bit manipulation.

**Recommended Pattern Order for Interviews:**

1. Repeated Division (easy explanation)
2. Power of Two check
3. Bit Mask solution (**optimal**)
4. Mathematical `% 3` trick (advanced observation)
