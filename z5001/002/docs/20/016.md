# Super Ugly Number (LeetCode 313)

**Difficulty:** Medium
**Companies:** Google, Amazon, Microsoft

## Problem

A **Super Ugly Number** is a positive integer whose prime factors are only from a given list `primes`.

Given:

* `n` → find the nth super ugly number
* `primes` → list of prime factors

Return the nth super ugly number.

### Example

```text
Input:
n = 12
primes = [2,7,13,19]

Output:
32

Sequence:
1,2,4,7,8,13,14,16,19,26,28,32...
```

---

# Solution Patterns

## Pattern 1: Brute Force Enumeration

### Idea

Generate numbers one by one and check whether every prime factor belongs to `primes`.

### Steps

1. Start from 1.
2. Check every number.
3. Divide repeatedly by allowed primes.
4. If reduced to 1 → super ugly.
5. Count until nth number.

### Code

```python
def nthSuperUglyNumber(n, primes):

    def is_super_ugly(num):
        temp = num

        for p in primes:
            while temp % p == 0:
                temp //= p

        return temp == 1

    count = 0
    num = 1

    while True:
        if is_super_ugly(num):
            count += 1

            if count == n:
                return num

        num += 1
```

### Complexity

```text
Time  : Very Large
Space : O(1)
```

### Verdict

❌ TLE for large n

# Pattern 2: Min Heap + Set

## Idea

Similar to Ugly Number II.

Every super ugly number generates:

```text
num * p
```

for every prime `p`.

Use:

* Min Heap → next smallest number
* Set → avoid duplicates

---

### Example

```text
primes = [2,7,13]

Start:
heap = [1]

Pop 1
Push:
2,7,13

Pop 2
Push:
4,14,26

Pop 4
Push:
8,28,52
...
```

---

### Code

```python
import heapq

def nthSuperUglyNumber(n, primes):

    heap = [1]
    seen = {1}

    ugly = 1

    for _ in range(n):

        ugly = heapq.heappop(heap)

        for p in primes:
            nxt = ugly * p

            if nxt not in seen:
                seen.add(nxt)
                heapq.heappush(heap, nxt)

    return ugly
```

### Complexity

Let:

```text
k = len(primes)
```

```text
Time  : O(n*k*log(nk))
Space : O(n*k)
```

### Verdict

✅ Accepted

❌ Extra heap overhead

# Pattern 3: DP + Multiple Pointers (Optimal)

This is the extension of **Ugly Number II**.

---

## Key Observation

For each prime:

```text
2 × previous ugly
7 × previous ugly
13 × previous ugly
19 × previous ugly
```

Maintain one pointer for each prime.

---

### Example

```text
primes = [2,7,13]

ugly = [1]

ptrs:
2 -> index 0
7 -> index 0
13 -> index 0

Candidates:
2,7,13

Choose 2
ugly = [1,2]

Move pointer of 2

Candidates:
4,7,13

Choose 4
...
```

---

## Duplicate Handling

Suppose:

```text
2 × 7 = 14
7 × 2 = 14
```

After choosing 14:

Move BOTH pointers.

```python
for i:
    if candidate[i] == next_ugly:
        ptr[i] += 1
```

This prevents duplicates.

---

## DP State

```text
dp[i]
=
(i+1)th super ugly number
```

---

## Code

```python
def nthSuperUglyNumber(n, primes):

    k = len(primes)

    dp = [1] * n

    pointers = [0] * k

    for i in range(1, n):

        candidates = [
            dp[pointers[j]] * primes[j]
            for j in range(k)
        ]

        next_ugly = min(candidates)

        dp[i] = next_ugly

        for j in range(k):
            if candidates[j] == next_ugly:
                pointers[j] += 1

    return dp[-1]
```

---

### Complexity

```text
Time  : O(n*k)
Space : O(n)
```

Where:

```text
k = len(primes)
```

### Verdict

✅ Standard interview solution

✅ Most commonly expected

# Pattern 4: Optimized DP (Reuse Candidates)

Instead of rebuilding candidates every iteration.

Store current values.

---

## Idea

```text
pointer[i]
value[i] = dp[pointer[i]] * primes[i]
```

When pointer moves:

```text
value[i] =
dp[new_pointer] * primes[i]
```

No need to recompute all candidates.

---

## Code

```python
def nthSuperUglyNumber(n, primes):

    k = len(primes)

    dp = [1] * n

    pointers = [0] * k

    values = primes[:]

    for i in range(1, n):

        next_ugly = min(values)

        dp[i] = next_ugly

        for j in range(k):

            if values[j] == next_ugly:

                pointers[j] += 1

                values[j] = (
                    dp[pointers[j]] * primes[j]
                )

    return dp[-1]
```

---

## Complexity

```text
Time  : O(n*k)
Space : O(n + k)
```

### Advantages

* No candidate array reconstruction
* Fewer multiplications
* Cleaner implementation

# Optimized Interview Answer

Use **DP + Multiple Pointers with Cached Candidates**.

```python
def nthSuperUglyNumber(n, primes):

    k = len(primes)

    dp = [1] * n
    pointers = [0] * k
    values = primes[:]

    for i in range(1, n):

        next_ugly = min(values)
        dp[i] = next_ugly

        for j in range(k):

            if values[j] == next_ugly:

                pointers[j] += 1

                values[j] = (
                    dp[pointers[j]] * primes[j]
                )

    return dp[-1]
```

### Final Complexity

```text
Time  : O(n * k)
Space : O(n + k)
```

This is the **optimal and most expected solution** in Google, Amazon, Microsoft, and LeetCode interviews.
