# Roman to Integer

Convert a Roman numeral string into its integer value.

**Asked By:** Amazon, Meta, Google, Microsoft
**Difficulty:** Easy

---

# Understanding the Rule

Roman symbols:

| Symbol | Value |
| ------ | ----- |
| I      | 1     |
| V      | 5     |
| X      | 10    |
| L      | 50    |
| C      | 100   |
| D      | 500   |
| M      | 1000  |

Normally values are added:

```
VIII = 5 + 1 + 1 + 1 = 8
```

Special cases (subtraction):

```
IV = 4
IX = 9
XL = 40
XC = 90
CD = 400
CM = 900
```

If a smaller symbol appears before a larger symbol, subtract it.

---

# Pattern 1: Brute Force Pair Checking

## Idea

Check every possible subtraction pair explicitly.

```
IV, IX, XL, XC, CD, CM
```

When found:

* Add special value
* Skip next character

Otherwise add normal value.

## Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def romanToInt(s):
    values = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    i = 0
    result = 0

    while i < len(s):
        if i + 1 < len(s):
            pair = s[i:i+2]

            if pair == "IV":
                result += 4
                i += 2
                continue
            elif pair == "IX":
                result += 9
                i += 2
                continue
            elif pair == "XL":
                result += 40
                i += 2
                continue
            elif pair == "XC":
                result += 90
                i += 2
                continue
            elif pair == "CD":
                result += 400
                i += 2
                continue
            elif pair == "CM":
                result += 900
                i += 2
                continue

        result += values[s[i]]
        i += 1

    return result
```

# Pattern 2: Look Ahead (Most Common Interview Solution)

## Idea

For each character:

* If current value < next value → subtract
* Else → add

Example:

```
MCMIV

M = 1000 add
C = 100 < M = 1000 subtract
M = 1000 add
I = 1 < V = 5 subtract
V = 5 add
```

Result:

```
1000 -100 +1000 -1 +5 = 1904
```

## Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def romanToInt(s):
    values = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    result = 0

    for i in range(len(s)):
        if i < len(s) - 1 and values[s[i]] < values[s[i + 1]]:
            result -= values[s[i]]
        else:
            result += values[s[i]]

    return result
```

# Pattern 3: Reverse Traversal

## Idea

Traverse from right to left.

Maintain previous value.

* If current < previous → subtract
* Else → add

Example:

```
MCMIV

Right to Left

V -> +5
I -> -1
M -> +1000
C -> -100
M -> +1000

= 1904
```

## Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def romanToInt(s):
    values = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    result = 0
    prev = 0

    for ch in reversed(s):
        curr = values[ch]

        if curr < prev:
            result -= curr
        else:
            result += curr

        prev = curr

    return result
```

# Pattern 4: Two-Character Formula

## Idea

Add every symbol.

Whenever:

```
current > previous
```

We have already added the previous value once.

So:

```
result += current - 2 * previous
```

because previous should have been subtracted.

Example:

```
IV

I => result = 1

V => result += 5 - 2*1
   => 4
```

## Complexity

* Time: O(n)
* Space: O(1)

## Code

```python
def romanToInt(s):
    values = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    result = 0
    prev = 0

    for ch in s:
        curr = values[ch]

        result += curr

        if curr > prev:
            result -= 2 * prev

        prev = curr

    return result
```

# Comparison of Patterns

| Pattern                   | Time | Space | Interview Value |
| ------------------------- | ---- | ----- | --------------- |
| Brute Force Pair Checking | O(n) | O(1)  | Low             |
| Look Ahead                | O(n) | O(1)  | Very High       |
| Reverse Traversal         | O(n) | O(1)  | High            |
| Two-Character Formula     | O(n) | O(1)  | High            |

# Optimized Solution

The **Look Ahead** approach is generally considered the best interview solution because:

* Simple logic
* Easy to explain
* Handles all subtraction cases naturally
* O(n) time
* O(1) space

```python
def romanToInt(s):
    values = {
        'I': 1,
        'V': 5,
        'X': 10,
        'L': 50,
        'C': 100,
        'D': 500,
        'M': 1000
    }

    result = 0

    for i in range(len(s)):
        if i < len(s) - 1 and values[s[i]] < values[s[i + 1]]:
            result -= values[s[i]]
        else:
            result += values[s[i]]

    return result
```

### Complexity

* **Time:** O(n)
* **Space:** O(1)

This is the solution most commonly expected in Amazon, Meta, Google, and Microsoft interviews.
