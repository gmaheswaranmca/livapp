# Excel Sheet Column Number

**Problem:** Convert an Excel column title (e.g., `"A"`, `"AB"`, `"ZY"`) into its corresponding column number.

### Examples

```text
"A"  -> 1
"B"  -> 2
"Z"  -> 26
"AA" -> 27
"AB" -> 28
"ZY" -> 701
```

---

# Understanding the Pattern

Excel columns follow a **Base-26 Number System**:

```text
A = 1
B = 2
...
Z = 26
```

For `"AB"`:

```text
A = 1
B = 2

(1 × 26) + 2 = 28
```

For `"ZY"`:

```text
Z = 26
Y = 25

(26 × 26) + 25 = 701
```

---

# Pattern 1: Left-to-Right Base-26 Conversion (Optimal)

## Idea

Process each character:

```python
result = result * 26 + current_letter_value
```

This is exactly how decimal numbers are formed:

```text
123

((1 × 10) + 2) × 10 + 3
```

Similarly:

```text
AB

((0 × 26) + 1) × 26 + 2
```

---

## Code

```python
def titleToNumber(columnTitle):
    result = 0

    for ch in columnTitle:
        value = ord(ch) - ord('A') + 1
        result = result * 26 + value

    return result
```

---

## Dry Run

```text
columnTitle = "AB"

result = 0

'A'
value = 1

result = 0*26 + 1
       = 1

'B'
value = 2

result = 1*26 + 2
       = 28

Answer = 28
```

---

## Complexity

```text
Time  : O(n)
Space : O(1)
```

where `n` is length of column title.

---

# Pattern 2: Right-to-Left Positional Multiplication

## Idea

Use powers of 26.

```text
ABC

A × 26² + B × 26¹ + C × 26⁰
```

---

## Code

```python
def titleToNumber(columnTitle):
    result = 0
    power = 1

    for i in range(len(columnTitle) - 1, -1, -1):
        value = ord(columnTitle[i]) - ord('A') + 1
        result += value * power
        power *= 26

    return result
```

---

## Dry Run

```text
AB

B = 2 × 1   = 2
A = 1 × 26  = 26

Total = 28
```

---

## Complexity

```text
Time  : O(n)
Space : O(1)
```

---

# Pattern 3: Recursive Base-26 Evaluation

## Idea

Treat the string like a number and recursively evaluate.

---

## Code

```python
def titleToNumber(columnTitle):
    if not columnTitle:
        return 0

    first = ord(columnTitle[0]) - ord('A') + 1

    return first * (26 ** (len(columnTitle) - 1)) + \
           titleToNumber(columnTitle[1:])
```

---

## Complexity

```text
Time  : O(n²)
Space : O(n)
```

Reason:

* Recursive calls
* Repeated exponent calculations

---

# Pattern 4: Using Functional Programming

## Code

```python
from functools import reduce

def titleToNumber(columnTitle):
    return reduce(
        lambda result, ch:
        result * 26 + (ord(ch) - ord('A') + 1),
        columnTitle,
        0
    )
```

---

## Complexity

```text
Time  : O(n)
Space : O(1)
```

---

# Pattern Comparison

| Pattern                  | Time  | Space | Interview Use |
| ------------------------ | ----- | ----- | ------------- |
| Left-to-Right Base-26    | O(n)  | O(1)  | ⭐ Best        |
| Right-to-Left Positional | O(n)  | O(1)  | Good          |
| Recursive                | O(n²) | O(n)  | Rare          |
| Functional Reduce        | O(n)  | O(1)  | Less Common   |

# Optimized Pattern

## Base-26 Accumulation

```python
def titleToNumber(columnTitle):
    result = 0

    for ch in columnTitle:
        result = result * 26 + (ord(ch) - ord('A') + 1)

    return result
```

### Why it is Optimal

* Single pass through the string.
* No extra data structures.
* No exponentiation.
* No recursion overhead.
* Natural base-conversion approach.

## Complexity

```text
Time  : O(n)
Space : O(1)
```

This is the standard interview solution used by companies such as Amazon, Google, Microsoft, and Apple.
