# Happy Number

**Problem Statement**

A **Happy Number** is a number defined by the following process:

1. Start with any positive integer `n`.
2. Replace the number by the sum of the squares of its digits.
3. Repeat the process until:

   * The number becomes `1` (happy number), or
   * The process enters a cycle that does not include `1` (not happy).

**Asked By:** Google, Amazon, Meta, Microsoft
**Difficulty:** Easy

---

# Solution Patterns

## Pattern 1: Simulation + Visited Set

### Idea

Keep calculating the sum of squares of digits.

* If number becomes `1` → Happy Number.
* If a number repeats → Cycle detected → Not Happy.

### Example

```
19

1² + 9² = 82
8² + 2² = 68
6² + 8² = 100
1² + 0² + 0² = 1
```

Output: `True`

---

### Complexity

* Time: **O(log n)**
* Space: **O(log n)**

---

### Code

```python
class Solution:
    def get_next(self, n):
        total = 0

        while n > 0:
            digit = n % 10
            total += digit * digit
            n //= 10

        return total

    def isHappy(self, n):
        visited = set()

        while n != 1:
            if n in visited:
                return False

            visited.add(n)
            n = self.get_next(n)

        return True
```

## Pattern 2: Floyd Cycle Detection (Fast & Slow Pointers)

### Idea

This problem is actually a cycle detection problem.

Treat each number as a node.

```
n -> sumSquares(n)
```

Use:

* Slow pointer moves one step.
* Fast pointer moves two steps.

If:

* Fast reaches `1` → Happy.
* Slow and Fast meet → Cycle exists.

---

### Complexity

* Time: **O(log n)**
* Space: **O(1)**

---

### Code

```python
class Solution:
    def get_next(self, n):
        total = 0

        while n > 0:
            digit = n % 10
            total += digit * digit
            n //= 10

        return total

    def isHappy(self, n):
        slow = n
        fast = self.get_next(n)

        while fast != 1 and slow != fast:
            slow = self.get_next(slow)
            fast = self.get_next(self.get_next(fast))

        return fast == 1
```

## Pattern 3: Recursive + Visited Set

### Idea

Use recursion to repeatedly calculate the next number.

Maintain a set to detect cycles.

---

### Complexity

* Time: **O(log n)**
* Space: **O(log n)**

---

### Code

```python
class Solution:
    def get_next(self, n):
        total = 0

        while n > 0:
            digit = n % 10
            total += digit * digit
            n //= 10

        return total

    def helper(self, n, visited):
        if n == 1:
            return True

        if n in visited:
            return False

        visited.add(n)

        return self.helper(self.get_next(n), visited)

    def isHappy(self, n):
        return self.helper(n, set())
```

# Optimized Solution Comparison

| Pattern               | Time     | Space    | Interview Rating |
| --------------------- | -------- | -------- | ---------------- |
| Simulation + Set      | O(log n) | O(log n) | Good             |
| Floyd Cycle Detection | O(log n) | O(1)     | Best             |
| Recursive + Set       | O(log n) | O(log n) | Average          |

# Recommended Pattern for Interviews

### Use: Floyd Cycle Detection (Fast & Slow Pointers)

Why?

* Constant extra space.
* Demonstrates knowledge of cycle detection.
* Common interviewer expectation.
* Same technique used in:

  * Linked List Cycle
  * Find Duplicate Number
  * Cycle Detection Problems

### Interview Template

def get_next(n):
