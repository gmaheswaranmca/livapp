# Power of Three (LeetCode Easy)

**Problem:**
Given an integer `n`, return `True` if it is a power of 3. Otherwise, return `False`.

Examples:

```text
Input: n = 27
Output: True

Input: n = 0
Output: False

Input: n = 45
Output: False
```

---

# Pattern 1: Repeated Division (Simulation)

## Idea

Keep dividing by 3 while the number is divisible by 3.

If the final value becomes 1, then it is a power of 3.

## Pattern

```text
n = 27

27 → 9 → 3 → 1

Answer = True
```

## Code

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        if n <= 0:
            return False

        while n % 3 == 0:
            n //= 3

        return n == 1
```

## Complexity

* Time: O(log₃ n)
* Space: O(1)

---

# Pattern 2: Recursive Division

## Idea

Recursively divide by 3 until:

* n == 1 → True
* n not divisible by 3 → False

## Code

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        if n == 1:
            return True

        if n <= 0 or n % 3 != 0:
            return False

        return self.isPowerOfThree(n // 3)
```

## Complexity

* Time: O(log₃ n)
* Space: O(log₃ n)

---

# Pattern 3: Logarithm Pattern

## Idea

For power of three:

```text
n = 3^k

k = log₃(n)
```

If `k` is an integer, then `n` is a power of three.

## Code

```python
import math

class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        if n <= 0:
            return False

        k = math.log(n, 3)

        return abs(k - round(k)) < 1e-10
```

## Complexity

* Time: O(1)
* Space: O(1)

## Drawback

Floating-point precision issues.

# Pattern 4: Maximum Power Divisibility Trick

## Idea

For 32-bit signed integers:

Largest power of 3:

```text
3^19 = 1162261467
```

Any positive power of 3 must divide this number.

### Why?

```text
1162261467 = 3^19

If n = 3^k

Then 3^19 % 3^k = 0
```

## Code

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        return n > 0 and 1162261467 % n == 0
```

## Complexity

* Time: O(1)
* Space: O(1)

---

# Pattern 5: Precomputed Hash Set

## Idea

Store all powers of three within constraints.

## Code

```python
class Solution:
    powers = {
        1, 3, 9, 27, 81, 243,
        729, 2187, 6561, 19683,
        59049, 177147, 531441,
        1594323, 4782969, 14348907,
        43046721, 129140163,
        387420489, 1162261467
    }

    def isPowerOfThree(self, n: int) -> bool:
        return n in self.powers
```

## Complexity

* Time: O(1)
* Space: O(1)

# Optimized Solution

For interviews, the safest choice is:

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        if n <= 0:
            return False

        while n % 3 == 0:
            n //= 3

        return n == 1
```

### Why?

* No floating-point errors
* No hardcoded constants
* Easy to explain
* Works for any integer range
* Commonly expected by interviewers

If the interviewer specifically asks for **O(1)** time, use:

```python
class Solution:
    def isPowerOfThree(self, n: int) -> bool:
        return n > 0 and 1162261467 % n == 0
```

This is the most optimized solution for the standard 32-bit LeetCode constraint.
