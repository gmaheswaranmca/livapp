# Problem: Sqrt(x)

**Statement:**
Given a non-negative integer `x`, return the integer square root of `x`.

The integer square root is the largest integer `r` such that:

r^2 \le x

Examples:

```text
Input: 4
Output: 2

Input: 8
Output: 2
```

**Asked By:** Google, Microsoft, Amazon, Adobe
**Difficulty:** Easy

---

# Solution Patterns

## Pattern 1: Brute Force

### Idea

Start from `0` and keep increasing until `i*i > x`.

The answer is `i-1`.

### Complexity

* Time: **O(√x)**
* Space: **O(1)**

### Code

```python
def mySqrt(x):
    i = 0

    while i * i <= x:
        i += 1

    return i - 1
```

---

## Pattern 2: Binary Search

### Idea

The square root of `x` must lie between `0` and `x`.

Use binary search to find the largest number whose square is less than or equal to `x`.

### Complexity

* Time: **O(log x)**
* Space: **O(1)**

### Visualization

We are searching for the largest integer `mid` satisfying:

```text
mid² ≤ x
```

### Code

```python
def mySqrt(x):
    if x < 2:
        return x

    left = 1
    right = x
    ans = 0

    while left <= right:
        mid = left + (right - left) // 2
        square = mid * mid

        if square == x:
            return mid

        elif square < x:
            ans = mid
            left = mid + 1

        else:
            right = mid - 1

    return ans
```

---

## Pattern 3: Newton's Method (Newton-Raphson)

### Idea

Use the iterative formula:

g_{n+1}=\frac{g_n+x/g_n}{2}

Start with an initial guess and repeatedly improve it until convergence.

### Complexity

* Time: **O(log x)** (very fast convergence)
* Space: **O(1)**

### Code

```python
def mySqrt(x):
    if x == 0:
        return 0

    guess = x

    while guess * guess > x:
        guess = (guess + x // guess) // 2

    return guess
```

# Optimized Solution

### Recommended Pattern: Binary Search

Why?

* Classic interview solution.
* Easy to explain.
* Guaranteed correctness.
* No mathematical derivation required.
* Frequently expected by Google, Microsoft, Amazon, and Adobe interviewers.

### Optimized Code

```python
def mySqrt(x):
    if x < 2:
        return x

    left = 1
    right = x

    while left <= right:
        mid = left + (right - left) // 2

        if mid * mid == x:
            return mid

        if mid * mid < x:
            left = mid + 1
        else:
            right = mid - 1

    return right
```

### Complexity

* **Time:** O(log x)
* **Space:** O(1)

This is the standard interview-optimal solution for **LeetCode 69 - Sqrt(x)**.
