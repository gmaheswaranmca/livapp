# Add Digits

**Problem Statement:**
Given an integer `num`, repeatedly add all its digits until the result has only one digit.

### Example 1

```text
Input: num = 38

38 → 3 + 8 = 11
11 → 1 + 1 = 2

Output: 2
```

### Example 2

```text
Input: num = 0
Output: 0
```

---

# Pattern 1: Simulation (Digit Sum Repeatedly)

## Idea

Keep summing the digits until the number becomes a single digit.

## Algorithm

1. While `num >= 10`
2. Find sum of digits.
3. Replace `num` with digit sum.
4. Return `num`.

## Code

```python
def addDigits(num):
    while num >= 10:
        digit_sum = 0

        while num > 0:
            digit_sum += num % 10
            num //= 10

        num = digit_sum

    return num
```

## Complexity

* Time: `O(d × iterations)`
* Space: `O(1)`

where `d` is number of digits.

---

# Pattern 2: String-Based Simulation

## Idea

Convert number to string and sum digits repeatedly.

## Code

```python
def addDigits(num):
    while num >= 10:
        num = sum(int(ch) for ch in str(num))

    return num
```

## Complexity

* Time: `O(d × iterations)`
* Space: `O(d)`

---

# Pattern 3: Recursive Digit Sum

## Idea

Use recursion until a single digit remains.

## Code

```python
def addDigits(num):
    if num < 10:
        return num

    digit_sum = 0

    while num:
        digit_sum += num % 10
        num //= 10

    return addDigits(digit_sum)
```

## Complexity

* Time: `O(d × iterations)`
* Space: `O(recursion depth)`

---

# Pattern 4: Digital Root Mathematics (Optimal)

## Observation

Examples:

```text
38 -> 2
999 -> 9
12345 -> 6
```

A mathematical property called **Digital Root** exists.

For any positive number:

```text
Digital Root = 1 + ((num - 1) % 9)
```

Special case:

```text
num = 0 => answer = 0
```

---

## Formula

For:

```text
num = 0
answer = 0

otherwise
answer = 1 + (num - 1) % 9
```

## Code

```python
def addDigits(num):
    if num == 0:
        return 0

    return 1 + (num - 1) % 9
```

Or:

```python
def addDigits(num):
    return 0 if num == 0 else 1 + (num - 1) % 9
```

## Complexity

* Time: `O(1)`
* Space: `O(1)`

---

# Why Digital Root Works

Consider:

```text
38 = 3×10 + 8
```

Since:

```text
10 ≡ 1 (mod 9)
```

Therefore:

```text
38 ≡ 3 + 8 (mod 9)
```

Similarly:

```text
12345 ≡ 1+2+3+4+5 (mod 9)
```

Repeated digit summation preserves the value modulo 9.

The final single digit is therefore:

```text
1 + ((num - 1) % 9)
```

# Optimized Solution

```python
def addDigits(num):
    return 0 if num == 0 else 1 + (num - 1) % 9
```

### Why?

* Constant time.
* Constant space.
* Uses Digital Root property.
* Most preferred interview solution when follow-up asks for **O(1)** runtime.

**Recommended Pattern Progression:**

1. Simulation (easy to derive)
2. Recursive approach
3. Digital Root (optimal and interview favorite) ✅
