# Problem: Plus One

Given an integer represented as an array of digits, add one to the integer and return the resulting array.

### Example

```python
Input:  [1,2,3]
Output: [1,2,4]

Input:  [9]
Output: [1,0]

Input:  [9,9,9]
Output: [1,0,0,0]
```

---

# Pattern 1: Convert to Integer and Back

## Idea

1. Convert array to number.
2. Add 1.
3. Convert back to digit array.

## Complexity

* Time: O(n)
* Space: O(n)

## Code

```python
def plusOne(digits):
    num = int(''.join(map(str, digits)))
    num += 1
    return [int(ch) for ch in str(num)]
```

## Pros

* Very easy to understand.

## Cons

* May overflow in languages with fixed-size integers.
* Not the intended interview solution.

---

# Pattern 2: Simulate Manual Addition (Carry Propagation)

## Idea

Start from the last digit.

* If digit < 9, increment and return.
* If digit == 9, make it 0 and carry to previous digit.
* If all digits become 0, add leading 1.

Example:

```python
[1,2,9]
      ↑
[1,3,0]
```

Example:

```python
[9,9,9]
↓
[0,0,0]
↓
[1,0,0,0]
```

## Complexity

* Time: O(n)
* Space: O(1) (excluding output)

## Code

```python
def plusOne(digits):
    n = len(digits)

    for i in range(n - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits

        digits[i] = 0

    return [1] + digits
```

## Pros

* No integer conversion.
* Handles arbitrarily large numbers.
* Classic interview solution.

## Cons

* Slightly more logic than Pattern 1.

---

# Pattern 3: Recursive Carry Propagation

## Idea

Use recursion to propagate carry from right to left.

## Complexity

* Time: O(n)
* Space: O(n) recursion stack

## Code

```python
def plusOne(digits):

    def helper(i):
        if i < 0:
            digits.insert(0, 1)
            return

        if digits[i] < 9:
            digits[i] += 1
            return

        digits[i] = 0
        helper(i - 1)

    helper(len(digits) - 1)
    return digits
```

## Pros

* Demonstrates recursion.

## Cons

* Extra stack space.
* Not preferred in interviews.

# Pattern Comparison

| Pattern            | Time | Space | Interview Friendly |
| ------------------ | ---- | ----- | ------------------ |
| Convert to Integer | O(n) | O(n)  | ❌                  |
| Manual Carry       | O(n) | O(1)  | ✅                  |
| Recursive Carry    | O(n) | O(n)  | ⚠️                 |

# Optimized Pattern (Recommended)

Use **Manual Carry Propagation**.

```python
def plusOne(digits):
    for i in range(len(digits) - 1, -1, -1):
        if digits[i] < 9:
            digits[i] += 1
            return digits

        digits[i] = 0

    return [1] + digits
```

### Why this is optimal

* Single right-to-left scan.
* Constant extra space.
* Works for very large integers.
* Expected solution in Google, Amazon, Apple, and Microsoft interviews.

**Pattern:** Array Traversal + Carry Propagation
**Time:** O(n)
**Space:** O(1)
**Interview Choice:** ✅ Best Solution
