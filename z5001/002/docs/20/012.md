# Divide Two Integers

**Problem:** Divide Two Integers
Perform division without using `*`, `/`, or `%`.

**Asked By:** Meta, Amazon, Google, Microsoft
**Difficulty:** Medium

---

# Key Observations

Given:

```python
dividend = 10
divisor = 3
```

Result:

```python
10 // 3 = 3
```

Requirements:

* No multiplication (`*`)
* No division (`/`)
* No modulo (`%`)
* Truncate toward zero
* Handle overflow:

```python
[-2^31, 2^31 - 1]
```

If result exceeds:

```python
2^31 - 1
```

return:

```python
2^31 - 1
```

---

# Pattern 1: Repeated Subtraction (Brute Force)

## Idea

Keep subtracting divisor from dividend.

```text
10 - 3 = 7
7 - 3 = 4
4 - 3 = 1

Count = 3
```

---

## Code

```python
def divide(dividend, divisor):
    sign = -1 if (dividend < 0) ^ (divisor < 0) else 1

    dividend = abs(dividend)
    divisor = abs(divisor)

    quotient = 0

    while dividend >= divisor:
        dividend -= divisor
        quotient += 1

    return sign * quotient
```

---

## Complexity

* Time: O(quotient)
* Space: O(1)

### Drawback

For:

```python
2147483647 / 1
```

Nearly 2 billion iterations.

Not practical.

---

# Pattern 2: Repeated Doubling (Binary Search Style)

## Idea

Instead of subtracting divisor one-by-one:

```text
3
6
12
24
48
...
```

Keep doubling divisor until it exceeds dividend.

---

### Example

```python
43 / 3
```

Largest doubles:

```text
3   -> 1
6   -> 2
12  -> 4
24  -> 8
```

Subtract:

```text
43 - 24 = 19
```

Again:

```text
19 - 12 = 7
```

Again:

```text
7 - 6 = 1
```

Quotient:

```text
8 + 4 + 2 = 14
```

---

## Code

```python
def divide(dividend, divisor):
    INT_MAX = 2**31 - 1
    INT_MIN = -2**31

    if dividend == INT_MIN and divisor == -1:
        return INT_MAX

    sign = -1 if (dividend < 0) ^ (divisor < 0) else 1

    dividend = abs(dividend)
    divisor = abs(divisor)

    quotient = 0

    while dividend >= divisor:

        temp = divisor
        multiple = 1

        while dividend >= (temp << 1):
            temp <<= 1
            multiple <<= 1

        dividend -= temp
        quotient += multiple

    return sign * quotient
```

---

## Complexity

* Time: O((log n)²)
* Space: O(1)

Better than repeated subtraction.

# Pattern 3: Bit Manipulation (Most Optimized)

## Idea

Division is finding:

```text
dividend = divisor × quotient + remainder
```

Check powers of two from largest to smallest.

Use:

```python
divisor << shift
```

which means:

```text
divisor × 2^shift
```

No multiplication used.

---

## Example

```python
43 / 3
```

Check:

```text
3 × 16 = 48  (too large)

3 × 8 = 24   (take it)
43 - 24 = 19

3 × 4 = 12   (take it)
19 - 12 = 7

3 × 2 = 6    (take it)
7 - 6 = 1
```

Answer:

```text
8 + 4 + 2 = 14
```

---

## Code

```python
def divide(dividend, divisor):
    INT_MAX = 2**31 - 1
    INT_MIN = -2**31

    if dividend == INT_MIN and divisor == -1:
        return INT_MAX

    sign = -1 if (dividend < 0) ^ (divisor < 0) else 1

    dividend = abs(dividend)
    divisor = abs(divisor)

    quotient = 0

    for shift in range(31, -1, -1):

        if dividend >= (divisor << shift):
            dividend -= divisor << shift
            quotient += 1 << shift

    return sign * quotient
```

---

## Complexity

* Time: O(32) ≈ O(1)
* Space: O(1)

For fixed 32-bit integers.

For general integers:

* Time: O(log n)
* Space: O(1)

# Pattern 4: Recursive Doubling

## Idea

Use recursion to find largest doubled divisor.

---

## Code

```python
def divide(dividend, divisor):

    def helper(dividend, divisor):

        if dividend < divisor:
            return 0

        temp = divisor
        multiple = 1

        while dividend >= (temp << 1):
            temp <<= 1
            multiple <<= 1

        return multiple + helper(dividend - temp, divisor)

    INT_MAX = 2**31 - 1

    if dividend == -2**31 and divisor == -1:
        return INT_MAX

    sign = -1 if (dividend < 0) ^ (divisor < 0) else 1

    result = helper(abs(dividend), abs(divisor))

    return sign * result
```

---

## Complexity

* Time: O((log n)²)
* Space: O(log n) recursion

---

# Pattern Comparison

| Pattern              | Idea                           | Time        | Space    |
| -------------------- | ------------------------------ | ----------- | -------- |
| Repeated Subtraction | Subtract one divisor at a time | O(quotient) | O(1)     |
| Repeated Doubling    | Exponential jumps              | O((log n)²) | O(1)     |
| Recursive Doubling   | Same with recursion            | O((log n)²) | O(log n) |
| Bit Manipulation     | Check powers of two directly   | O(log n)    | O(1)     |

---

# Optimized Pattern

## Bit Manipulation + Shifts

```python
for shift in range(31, -1, -1):
```

This is the standard interview solution.

### Why it is best?

* No multiplication/division/modulo
* Uses bit operations only
* Constant space
* O(log n) time
* Handles overflow cleanly
* Expected by Meta, Amazon, Google, Microsoft interviewers

```python
def divide(dividend, divisor):
    INT_MAX = 2**31 - 1
    INT_MIN = -2**31

    if dividend == INT_MIN and divisor == -1:
        return INT_MAX

    sign = -1 if (dividend < 0) ^ (divisor < 0) else 1

    dividend = abs(dividend)
    divisor = abs(divisor)

    quotient = 0

    for shift in range(31, -1, -1):
        if dividend >= (divisor << shift):
            dividend -= divisor << shift
            quotient += 1 << shift

    return sign * quotient
```

### Interview Pattern

**Repeated Subtraction → Doubling → Bit Manipulation**

This progression demonstrates how division can be implemented efficiently using powers of two and binary decomposition, leading naturally to the optimal bit-manipulation solution.
