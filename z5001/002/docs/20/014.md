# Ugly Number (LeetCode 263)

**Problem Statement**

Given an integer `n`, return `True` if `n` is an ugly number.

An ugly number is a positive integer whose prime factors are limited to **2, 3, and 5**.

### Examples

```text
Input: n = 6
Output: True
Explanation: 6 = 2 × 3

Input: n = 8
Output: True
Explanation: 8 = 2 × 2 × 2

Input: n = 14
Output: False
Explanation: 14 = 2 × 7
```

---

# Solution Patterns

## Pattern 1: Prime Factor Removal (Iterative Division) ✅ Optimal

### Idea

If a number is ugly, repeatedly dividing by `2`, `3`, and `5` should eventually reduce it to `1`.

### Algorithm

1. If `n <= 0`, return `False`.
2. Divide by `2` while divisible.
3. Divide by `3` while divisible.
4. Divide by `5` while divisible.
5. If final value is `1`, it is ugly.

### Dry Run

```text
n = 30

30 ÷ 2 = 15
15 ÷ 3 = 5
5 ÷ 5 = 1

Result = True
```

### Code

```python
def isUgly(n):
    if n <= 0:
        return False

    for factor in [2, 3, 5]:
        while n % factor == 0:
            n //= factor

    return n == 1
```

### Complexity

```text
Time  : O(log n)
Space : O(1)
```

---

## Pattern 2: Recursive Factor Reduction

### Idea

Recursively divide by valid factors until reaching `1`.

### Code

```python
def isUgly(n):
    if n <= 0:
        return False

    if n == 1:
        return True

    if n % 2 == 0:
        return isUgly(n // 2)

    if n % 3 == 0:
        return isUgly(n // 3)

    if n % 5 == 0:
        return isUgly(n // 5)

    return False
```

### Complexity

```text
Time  : O(log n)
Space : O(log n)   # recursion stack
```

---

## Pattern 3: General Prime Factorization

### Idea

Factorize the number completely and verify every prime factor belongs to `{2,3,5}`.

### Code

```python
def isUgly(n):
    if n <= 0:
        return False

    d = 2

    while d * d <= n:
        while n % d == 0:
            if d not in (2, 3, 5):
                return False
            n //= d
        d += 1

    if n > 1 and n not in (2, 3, 5):
        return False

    return True
```

### Complexity

```text
Time  : O(√n)
Space : O(1)
```

# Optimized Pattern

### Key Observation

An ugly number contains **only** factors `2`, `3`, and `5`.

Instead of finding all prime factors, simply keep removing these three factors.

If something remains other than `1`, another prime factor exists.

### Optimized Code

```python
def isUgly(n):
    if n <= 0:
        return False

    for factor in (2, 3, 5):
        while n % factor == 0:
            n //= factor

    return n == 1
```

### Complexity

```text
Time  : O(log n)
Space : O(1)
```

### Why This Is Best

```text
✓ No extra memory
✓ No recursion
✓ No prime factorization
✓ Simple and clean
✓ Accepted optimal interview solution
```
