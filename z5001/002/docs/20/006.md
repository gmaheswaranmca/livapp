# Reverse Integer

**Problem:** Reverse digits of a 32-bit signed integer.

Given an integer `x`, return its digits reversed.

If reversing causes the value to go outside the signed 32-bit integer range:

* `[-2^31, 2^31 - 1]`
* `[-2147483648, 2147483647]`

return `0`.

**Asked By:** Amazon, Meta, Microsoft, Bloomberg
**Difficulty:** Medium

---

# Solution Patterns

## Pattern 1: String Reversal

### Idea

Convert number to string, reverse it, and convert back.

### Steps

1. Store sign.
2. Convert absolute value to string.
3. Reverse string.
4. Convert back to integer.
5. Restore sign.
6. Check overflow.

### Complexity

* Time: **O(d)**
* Space: **O(d)**

where `d` = number of digits.

### Code

```python
def reverse(x):
    INT_MIN = -(2 ** 31)
    INT_MAX = 2 ** 31 - 1

    sign = -1 if x < 0 else 1

    rev = int(str(abs(x))[::-1])
    rev *= sign

    if rev < INT_MIN or rev > INT_MAX:
        return 0

    return rev
```

## Pattern 2: Mathematical Digit Extraction

### Idea

Extract digits one by one and build reversed number.

### Example

```
123

digit = 3
rev = 3

digit = 2
rev = 32

digit = 1
rev = 321
```

### Complexity

* Time: **O(d)**
* Space: **O(1)**

### Code

```python
def reverse(x):
    INT_MIN = -(2 ** 31)
    INT_MAX = 2 ** 31 - 1

    sign = -1 if x < 0 else 1
    x = abs(x)

    rev = 0

    while x:
        digit = x % 10
        rev = rev * 10 + digit
        x //= 10

    rev *= sign

    if rev < INT_MIN or rev > INT_MAX:
        return 0

    return rev
```

---

## Pattern 3: Mathematical Reversal with Overflow Check During Construction

### Idea

Instead of checking overflow at the end, detect it before adding the next digit.

This mirrors how languages like Java/C++ handle fixed-size integers.

### Complexity

* Time: **O(d)**
* Space: **O(1)**

### Code

```python
def reverse(x):
    INT_MAX = 2147483647

    sign = -1 if x < 0 else 1
    x = abs(x)

    rev = 0

    while x:
        digit = x % 10
        x //= 10

        if rev > INT_MAX // 10:
            return 0

        if rev == INT_MAX // 10 and digit > 7:
            return 0

        rev = rev * 10 + digit

    return sign * rev
```

# Optimized Pattern

## Mathematical Reversal + Overflow Check

### Why?

* No string conversion.
* Constant extra space.
* Handles overflow correctly.
* Demonstrates digit manipulation skills.
* Most commonly expected in interviews.

### Recommended Code

```python
def reverse(x):
    INT_MAX = 2147483647

    sign = -1 if x < 0 else 1
    x = abs(x)

    rev = 0

    while x:
        digit = x % 10
        x //= 10

        if rev > INT_MAX // 10:
            return 0

        if rev == INT_MAX // 10 and digit > 7:
            return 0

        rev = rev * 10 + digit

    return sign * rev
```

### Example

```python
reverse(123)
# 321

reverse(-123)
# -321

reverse(120)
# 21

reverse(1534236469)
# 0
```
