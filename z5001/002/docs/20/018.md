# Power of Two (Easy)

**Problem:**
Given an integer `n`, determine whether it is a power of 2.

Examples:

```text
Input: n = 1
Output: True
Explanation: 2^0 = 1

Input: n = 16
Output: True
Explanation: 2^4 = 16

Input: n = 3
Output: False
```

---

# Pattern 1: Repeated Division

## Idea

Keep dividing the number by 2 until it becomes 1.

If at any point it is not divisible by 2, it is not a power of two.

## Algorithm

1. If `n <= 0`, return `False`.
2. While `n % 2 == 0`

   * `n = n // 2`
3. Check whether `n == 1`.

## Code

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n <= 0:
            return False

        while n % 2 == 0:
            n //= 2

        return n == 1
```

## Complexity

* Time: **O(log n)**
* Space: **O(1)**

---

# Pattern 2: Recursive Division

## Idea

Power of two numbers eventually reach 1 after repeated division by 2.

## Code

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n == 1:
            return True

        if n <= 0 or n % 2 != 0:
            return False

        return self.isPowerOfTwo(n // 2)
```

## Complexity

* Time: **O(log n)**
* Space: **O(log n)** (recursion stack)

---

# Pattern 3: Binary Representation

## Observation

Powers of two have exactly one set bit.

```text
1  -> 0001
2  -> 0010
4  -> 0100
8  -> 1000
16 -> 10000
```

Count set bits and verify count is 1.

## Code

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n <= 0:
            return False

        count = 0

        while n:
            count += n & 1
            n >>= 1

        return count == 1
```

## Complexity

* Time: **O(log n)**
* Space: **O(1)**

---

# Pattern 4: Brian Kernighan Set-Bit Removal

## Idea

The operation:

```text
n & (n - 1)
```

removes the rightmost set bit.

A power of two contains exactly one set bit.

Example:

```text
n = 8

1000
0111
----
0000
```

## Code

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n <= 0:
            return False

        count = 0

        while n:
            n = n & (n - 1)
            count += 1

        return count == 1
```

## Complexity

* Time: **O(number of set bits)**
* Space: **O(1)**

---

# Pattern 5: Bit Manipulation (Optimal)

## Key Property

For every power of two:

```text
n & (n - 1) == 0
```

Examples:

```text
8

1000
0111
----
0000

16

10000
01111
-----
00000
```

Non-power of two:

```text
10

1010
1001
----
1000
```

Not zero.

## Code

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        return n > 0 and (n & (n - 1)) == 0
```

## Complexity

* Time: **O(1)**
* Space: **O(1)**

---

# Pattern 6: Using Lowest Set Bit

## Observation

For powers of two:

```text
n & (-n) == n
```

Examples:

```text
8  -> 1000
-8 -> two's complement

1000 & 1000 = 1000
```

## Code

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        return n > 0 and (n & -n) == n
```

## Complexity

* Time: **O(1)**
* Space: **O(1)**

# Optimized Solution Pattern

## Pattern Name

**Bit Manipulation — Single Set Bit Detection**

## Core Formula

n\ &\ (n-1)=0

for all positive powers of two.

## Optimal Code

```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        return n > 0 and (n & (n - 1)) == 0
```

## Why This Is Optimal

* Constant time.
* Constant space.
* Uses a fundamental binary property.
* Most expected solution in Google, Amazon, Microsoft, and Apple interviews.

**Recommended interview pattern:**
