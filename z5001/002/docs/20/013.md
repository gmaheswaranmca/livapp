# Fraction to Recurring Decimal

**Problem:** Convert a fraction `numerator / denominator` into its decimal string representation. If the decimal repeats, enclose the repeating part in parentheses.

### Examples

```text
1/2   = "0.5"
2/1   = "2"
2/3   = "0.(6)"
4/333 = "0.(012)"
1/6   = "0.1(6)"
```

**Asked By:** Google, Meta, Bloomberg, Amazon
**Difficulty:** Medium

---

# Solution Patterns

## Pattern 1: Floating Point Conversion (Incorrect for Interviews)

### Idea

Use Python division and convert to string.

### Why It Fails

* Precision errors
* Cannot detect repeating decimals
* Large numbers lose accuracy

### Code

```python
def fractionToDecimal(numerator, denominator):
    return str(numerator / denominator)
```

### Complexity

* Time: O(1)
* Space: O(1)

### Verdict

❌ Not accepted

---

# Pattern 2: Long Division Simulation

### Idea

Perform manual long division.

* Integer part = numerator // denominator
* Remainder = numerator % denominator
* Multiply remainder by 10 repeatedly
* Generate digits one by one

### Example

```text
1 / 2

0 remainder 1

10 / 2 = 5
remainder = 0

Answer = 0.5
```

### Limitation

Cannot identify where repetition begins.

### Complexity

* Time: O(k)
* Space: O(k)

where `k` is number of generated digits.

### Verdict

⚠️ Partial solution

---

# Pattern 3: Long Division + Hash Map (Optimal)

### Core Observation

During division:

```text
remainder -> next digit sequence
```

If the same remainder appears again:

```text
The decimal starts repeating.
```

Store:

```python
remainder -> position in result
```

When a remainder repeats:

```python
insert "(" at first occurrence
append ")" at end
```

---

# Optimized Solution (Hash Map)

```python
def fractionToDecimal(numerator, denominator):
    if numerator == 0:
        return "0"

    result = []

    # Handle sign
    if (numerator < 0) ^ (denominator < 0):
        result.append("-")

    numerator = abs(numerator)
    denominator = abs(denominator)

    # Integer part
    result.append(str(numerator // denominator))

    remainder = numerator % denominator

    if remainder == 0:
        return "".join(result)

    result.append(".")

    seen = {}

    while remainder:

        if remainder in seen:
            idx = seen[remainder]
            result.insert(idx, "(")
            result.append(")")
            break

        seen[remainder] = len(result)

        remainder *= 10

        result.append(str(remainder // denominator))

        remainder %= denominator

    return "".join(result)
```

# Complexity Analysis

### Time Complexity

Each unique remainder is processed once.

```text
O(denominator)
```

Worst case:

```text
O(d)
```

where `d = denominator`.

---

### Space Complexity

Hash map stores remainders.

```text
O(d)
```

# Interview Pattern Recognition

Use **Long Division + Hash Map** when:

* Detecting repeating decimals
* Tracking cycles in generated sequences
* Mapping remainder → position
* Converting rational numbers to exact decimal representation

### Similar Problems

* Happy Number (cycle detection)
* Linked List Cycle
* Decimal Expansion Problems
* Repeating Sequence Detection

## Recommended Pattern for Interviews

✅ **Long Division + Hash Map (Remainder → Position)**

Reason:

* Exact arithmetic
* Detects repeating cycles naturally
* Standard accepted solution
* Optimal and expected by Google, Meta, Amazon, and Bloomberg interviewers.
