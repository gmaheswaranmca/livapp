# Longest Common Prefix

Find the longest common prefix among all strings.

Example:

```text
Input:  ["flower","flow","flight"]
Output: "fl"
```

---

# Pattern 1 — Horizontal Scanning

## Idea

Take first string as prefix.
Compare with every next string and shrink prefix until matched.

---

## Code

```python
class Solution:
    def longestCommonPrefix(self, strs):
        if not strs:
            return ""

        prefix = strs[0]

        for s in strs[1:]:

            while not s.startswith(prefix):
                prefix = prefix[:-1]

                if not prefix:
                    return ""

        return prefix
```

---

## Time Complexity

```text
O(S)
```

S = total characters in all strings

## Space Complexity

```text
O(1)
```

---

# Pattern 2 — Vertical Scanning

## Idea

Compare characters column by column.

Stop when mismatch occurs.

---

## Code

```python
class Solution:
    def longestCommonPrefix(self, strs):
        if not strs:
            return ""

        for i in range(len(strs[0])):

            ch = strs[0][i]

            for s in strs[1:]:

                if i >= len(s) or s[i] != ch:
                    return strs[0][:i]

        return strs[0]
```

---

## Time Complexity

```text
O(S)
```

## Space Complexity

```text
O(1)
```

---

# Pattern 3 — Sorting Based

## Idea

After sorting:

* smallest string
* largest string

will contain maximum mismatch.

Only compare first and last strings.

---

## Code

```python
class Solution:
    def longestCommonPrefix(self, strs):
        if not strs:
            return ""

        strs.sort()

        first = strs[0]
        last = strs[-1]

        i = 0

        while i < len(first) and i < len(last):

            if first[i] != last[i]:
                break

            i += 1

        return first[:i]
```

---

## Time Complexity

```text
O(N log N + S)
```

## Space Complexity

```text
O(1)
```

# Pattern 4 — Trie

## Idea

Insert all strings into Trie.

Walk until:

* more than one child
* word end occurs

---

## Code

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False


class Solution:

    def longestCommonPrefix(self, strs):

        if not strs:
            return ""

        root = TrieNode()

        for word in strs:

            node = root

            for ch in word:

                if ch not in node.children:
                    node.children[ch] = TrieNode()

                node = node.children[ch]

            node.is_end = True

        prefix = []
        node = root

        while len(node.children) == 1 and not node.is_end:

            ch = next(iter(node.children))

            prefix.append(ch)

            node = node.children[ch]

        return "".join(prefix)
```

---

## Time Complexity

```text
O(S)
```

## Space Complexity

```text
O(S)
```

# Pattern 5 — Divide and Conquer

## Idea

Split array into halves.

Find LCP of left half and right half.

Merge results.

---

## Code

```python
class Solution:

    def commonPrefix(self, left, right):

        length = min(len(left), len(right))

        i = 0

        while i < length and left[i] == right[i]:
            i += 1

        return left[:i]

    def divide(self, strs, l, r):

        if l == r:
            return strs[l]

        mid = (l + r) // 2

        left = self.divide(strs, l, mid)
        right = self.divide(strs, mid + 1, r)

        return self.commonPrefix(left, right)

    def longestCommonPrefix(self, strs):

        if not strs:
            return ""

        return self.divide(strs, 0, len(strs) - 1)
```

# Optimized Pattern Comparison

| Pattern          | Best Use                   | Time       | Space    | Interview Value |
| ---------------- | -------------------------- | ---------- | -------- | --------------- |
| Horizontal Scan  | Simple implementation      | O(S)       | O(1)     | High            |
| Vertical Scan    | Most common optimized      | O(S)       | O(1)     | Very High       |
| Sorting          | Short elegant code         | O(N log N) | O(1)     | Medium          |
| Trie             | Multiple prefix operations | O(S)       | O(S)     | High            |
| Divide & Conquer | Recursive learning         | O(S)       | O(log N) | Medium          |

# Most Optimized for Interviews

## Recommended

Vertical Scanning

Why:

* Simple
* Fast
* O(1) space
* Easy to explain
* Common interviewer expectation
