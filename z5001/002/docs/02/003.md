# Longest Palindromic Substring

Find the longest substring that is a palindrome.

Example:

```text id="glq7a5"
Input:  s = "babad"
Output: "bab"
Explanation: "aba" is also valid.

Input:  s = "cbbd"
Output: "bb"
```

---

# Pattern 1 — Brute Force Pattern

## Idea

* Generate all substrings.
* Check whether substring is palindrome.
* Track longest palindrome.

## Pattern Type

* Nested Loop
* String Checking

## Time Complexity

[
O(n^3)
]

## Code

```python id="cxzv5z"
def longestPalindrome(s):

    n = len(s)

    longest = ""

    for i in range(n):

        for j in range(i, n):

            substring = s[i:j+1]

            if substring == substring[::-1]:

                if len(substring) > len(longest):
                    longest = substring

    return longest


# Test
print(longestPalindrome("babad"))  # bab / aba
print(longestPalindrome("cbbd"))   # bb
```

# Pattern 2 — Dynamic Programming Pattern

## Idea

* Use DP table.
* `dp[i][j] = True` if substring `s[i:j+1]` is palindrome.

Rules:

* Single char → palindrome
* Two chars same → palindrome
* Inner substring palindrome + outer chars same

## Pattern Type

* Dynamic Programming
* Interval DP

## Time Complexity

[
O(n^2)
]

## Space Complexity

[
O(n^2)
]

## Code

```python id="jlwm8s"
def longestPalindrome(s):

    n = len(s)

    dp = [[False] * n for _ in range(n)]

    start = 0
    max_len = 1

    for i in range(n):
        dp[i][i] = True

    for length in range(2, n + 1):

        for i in range(n - length + 1):

            j = i + length - 1

            if s[i] == s[j]:

                if length == 2 or dp[i + 1][j - 1]:

                    dp[i][j] = True

                    if length > max_len:
                        start = i
                        max_len = length

    return s[start:start + max_len]


# Test
print(longestPalindrome("babad"))  # bab / aba
print(longestPalindrome("cbbd"))   # bb
```

# Pattern 3 — Expand Around Center Pattern

## Idea

Every palindrome expands from center.

Two centers possible:

* Odd length → single center
* Even length → double center

Expand outward while characters match.

## Pattern Type

* Two Pointer
* Expand Around Center

## Time Complexity

[
O(n^2)
]

## Space Complexity

[
O(1)
]

## Code

```python id="dd91fv"
def longestPalindrome(s):

    def expand(left, right):

        while left >= 0 and right < len(s) and s[left] == s[right]:

            left -= 1
            right += 1

        return s[left + 1:right]

    longest = ""

    for i in range(len(s)):

        odd = expand(i, i)

        even = expand(i, i + 1)

        if len(odd) > len(longest):
            longest = odd

        if len(even) > len(longest):
            longest = even

    return longest


# Test
print(longestPalindrome("babad"))  # bab / aba
print(longestPalindrome("cbbd"))   # bb
```

# Pattern 4 — Manacher’s Algorithm

## Idea

* Advanced linear-time palindrome algorithm.
* Converts string to avoid odd/even handling separately.
* Uses previously computed palindrome information.

## Pattern Type

* Advanced String Algorithm

## Time Complexity

[
O(n)
]

## Space Complexity

[
O(n)
]

## Code

```python id="t3s7gx"
def longestPalindrome(s):

    transformed = "#" + "#".join(s) + "#"

    n = len(transformed)

    p = [0] * n

    center = 0
    right = 0

    max_len = 0
    center_index = 0

    for i in range(n):

        mirror = 2 * center - i

        if i < right:
            p[i] = min(right - i, p[mirror])

        left = i - (p[i] + 1)
        right_side = i + (p[i] + 1)

        while left >= 0 and right_side < n and transformed[left] == transformed[right_side]:

            p[i] += 1

            left -= 1
            right_side += 1

        if i + p[i] > right:
            center = i
            right = i + p[i]

        if p[i] > max_len:
            max_len = p[i]
            center_index = i

    start = (center_index - max_len) // 2

    return s[start:start + max_len]


# Test
print(longestPalindrome("babad"))  # bab / aba
print(longestPalindrome("cbbd"))   # bb
```

# Most Recommended Interview Pattern

## Expand Around Center

```python id="9ztg3n"
def longestPalindrome(s):

    start = 0
    end = 0

    def expand(left, right):

        while left >= 0 and right < len(s) and s[left] == s[right]:

            left -= 1
            right += 1

        return right - left - 1

    for i in range(len(s)):

        len1 = expand(i, i)

        len2 = expand(i, i + 1)

        max_len = max(len1, len2)

        if max_len > end - start:

            start = i - (max_len - 1) // 2
            end = i + max_len // 2

    return s[start:end + 1]
```

---

# Why This Pattern Is Preferred

* Easy to explain
* Constant extra space
* Handles odd/even palindromes naturally
* Common interview expectation
* Much simpler than Manacher’s algorithm
