# String to Integer (atoi) — Solution Patterns

Problem: Convert string to integer while handling:

* Leading spaces
* Optional `+` / `-`
* Digits parsing
* Ignore trailing characters
* 32-bit overflow handling

---

# Pattern 1 — Brute Force Parsing

## Idea

* Trim spaces
* Detect sign
* Read digits
* Convert manually using place values

## Time Complexity

* `O(n)`

## Space Complexity

* `O(1)`

## Code

```python
class Solution:
    def myAtoi(self, s: str) -> int:

        INT_MAX = 2**31 - 1
        INT_MIN = -2**31

        s = s.lstrip()

        if not s:
            return 0

        sign = 1
        i = 0

        if s[i] == '-':
            sign = -1
            i += 1
        elif s[i] == '+':
            i += 1

        num = 0

        while i < len(s) and s[i].isdigit():
            num = num * 10 + int(s[i])
            i += 1

        num *= sign

        if num < INT_MIN:
            return INT_MIN

        if num > INT_MAX:
            return INT_MAX

        return num
```

# Pattern 2 — FSM (Finite State Machine)

## Idea

Treat parsing as states:

* Start
* Sign
* Number
* End

Useful for parser-design understanding.

---

## Time Complexity

* `O(n)`

## Space Complexity

* `O(1)`

---

## Code

```python
class Solution:

    def myAtoi(self, s: str) -> int:

        INT_MAX = 2**31 - 1
        INT_MIN = -2**31

        state = "start"
        sign = 1
        num = 0

        for ch in s:

            if state == "start":

                if ch == ' ':
                    continue

                elif ch == '+':
                    sign = 1
                    state = "signed"

                elif ch == '-':
                    sign = -1
                    state = "signed"

                elif ch.isdigit():
                    num = int(ch)
                    state = "number"

                else:
                    return 0

            elif state in ("signed", "number"):

                if ch.isdigit():

                    state = "number"

                    digit = int(ch)

                    if num > (2**31 - 1 - digit) // 10:

                        if sign == 1:
                            return INT_MAX
                        else:
                            return INT_MIN

                    num = num * 10 + digit

                else:
                    break

        return sign * num
```

# Pattern 3 — Optimized Incremental Overflow Check (Best)

## Idea

While building number:

Before adding digit:

```python
num > (INT_MAX - digit) // 10
```

means overflow will happen.

This avoids:

* Big integer creation
* Final overflow correction

---

# Optimized Pattern (Recommended)

## Time Complexity

* `O(n)`

## Space Complexity

* `O(1)`

---

## Code

```python
class Solution:

    def myAtoi(self, s: str) -> int:

        INT_MAX = 2**31 - 1
        INT_MIN = -2**31

        i = 0
        n = len(s)

        while i < n and s[i] == ' ':
            i += 1

        if i == n:
            return 0

        sign = 1

        if s[i] == '-':
            sign = -1
            i += 1

        elif s[i] == '+':
            i += 1

        num = 0

        while i < n and s[i].isdigit():

            digit = int(s[i])

            if num > (INT_MAX - digit) // 10:

                if sign == 1:
                    return INT_MAX
                else:
                    return INT_MIN

            num = num * 10 + digit

            i += 1

        return sign * num
```
