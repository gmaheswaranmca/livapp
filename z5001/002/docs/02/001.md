# Valid Anagram

Check whether two strings contain the same characters with the same frequency.

Example:

```text
Input:  s = "anagram", t = "nagaram"
Output: True

Input:  s = "rat", t = "car"
Output: False
```

---

# Pattern 1 — Sorting Pattern

## Idea

* Sort both strings.
* If sorted strings are equal → anagram.

## Pattern Type

* Sorting
* Comparison

## Time Complexity

[
O(n \log n)
]

## Code

```python
def isAnagram(s, t):
    return sorted(s) == sorted(t)


# Test
print(isAnagram("anagram", "nagaram"))  # True
print(isAnagram("rat", "car"))          # False
```

---

# Pattern 2 — HashMap / Frequency Count Pattern

## Idea

* Count frequency of each character.
* Compare frequencies.

## Pattern Type

* Hashing
* Frequency Counter

## Time Complexity

[
O(n)
]

## Space Complexity

[
O(n)
]

## Code

```python
def isAnagram(s, t):

    if len(s) != len(t):
        return False

    freq = {}

    for ch in s:
        freq[ch] = freq.get(ch, 0) + 1

    for ch in t:

        if ch not in freq:
            return False

        freq[ch] -= 1

        if freq[ch] < 0:
            return False

    return True


# Test
print(isAnagram("anagram", "nagaram"))  # True
print(isAnagram("rat", "car"))          # False
```

# Pattern 3 — Fixed Array Frequency Pattern

## Idea

* Since lowercase English letters are only 26:

  * Use array of size 26.
* Faster than hashmap.

## Pattern Type

* Array Counting
* Character Frequency

## Time Complexity

[
O(n)
]

## Space Complexity

[
O(1)
]

(26 fixed size)

## Code

```python
def isAnagram(s, t):

    if len(s) != len(t):
        return False

    count = [0] * 26

    for ch in s:
        index = ord(ch) - ord('a')
        count[index] += 1

    for ch in t:
        index = ord(ch) - ord('a')
        count[index] -= 1

    for value in count:
        if value != 0:
            return False

    return True


# Test
print(isAnagram("anagram", "nagaram"))  # True
print(isAnagram("rat", "car"))          # False
```

# Pattern 4 — Counter Pattern

## Idea

Use Python built-in `Counter`.

## Pattern Type

* Hashing
* Library Based Counting

## Time Complexity

[
O(n)
]

## Code

```python
from collections import Counter

def isAnagram(s, t):
    return Counter(s) == Counter(t)


# Test
print(isAnagram("anagram", "nagaram"))  # True
print(isAnagram("rat", "car"))          # False
```

# Optimized Solution Comparison

| Pattern           | Time       | Space | Best Use                             |
| ----------------- | ---------- | ----- | ------------------------------------ |
| Sorting           | O(n log n) | O(n)  | Simple interviews                    |
| HashMap Frequency | O(n)       | O(n)  | General best solution                |
| Fixed Array Count | O(n)       | O(1)  | Best optimized for lowercase letters |
| Counter           | O(n)       | O(n)  | Pythonic short solution              |

# Most Optimized Pattern

If only lowercase English letters:

```python
def isAnagram(s, t):

    if len(s) != len(t):
        return False

    count = [0] * 26

    for i in range(len(s)):
        count[ord(s[i]) - ord('a')] += 1
        count[ord(t[i]) - ord('a')] -= 1

    for value in count:
        if value != 0:
            return False

    return True
```

## Why Optimized?

* Single traversal
* Constant space
* No sorting
* Fastest practical approach for interviews
