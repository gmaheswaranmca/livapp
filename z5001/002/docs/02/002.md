# Longest Substring Without Repeating Characters

Find the length of the longest substring containing unique characters only.

Example:

```text id="1pmqg6"
Input:  s = "abcabcbb"
Output: 3
Explanation: "abc"

Input:  s = "bbbbb"
Output: 1
Explanation: "b"

Input:  s = "pwwkew"
Output: 3
Explanation: "wke"
```

---

# Pattern 1 — Brute Force Pattern

## Idea

* Generate all substrings.
* Check whether substring has duplicate characters.
* Track maximum length.

## Pattern Type

* Nested Loop
* Substring Checking

## Time Complexity

[
O(n^3)
]

## Code

```python id="ycvpwb"
def lengthOfLongestSubstring(s):

    n = len(s)
    max_len = 0

    for i in range(n):

        for j in range(i, n):

            substring = s[i:j+1]

            if len(substring) == len(set(substring)):
                max_len = max(max_len, len(substring))

    return max_len


# Test
print(lengthOfLongestSubstring("abcabcbb"))  # 3
print(lengthOfLongestSubstring("bbbbb"))     # 1
```

# Pattern 2 — Better Sliding Window with Set

## Idea

* Maintain window with unique characters.
* Expand right pointer.
* If duplicate found:

  * Shrink left pointer until duplicate removed.

## Pattern Type

* Sliding Window
* Two Pointer
* HashSet

## Time Complexity

[
O(2n) \approx O(n)
]

## Space Complexity

[
O(n)
]

## Code

```python id="cnqoz2"
def lengthOfLongestSubstring(s):

    left = 0
    seen = set()
    max_len = 0

    for right in range(len(s)):

        while s[right] in seen:
            seen.remove(s[left])
            left += 1

        seen.add(s[right])

        max_len = max(max_len, right - left + 1)

    return max_len


# Test
print(lengthOfLongestSubstring("abcabcbb"))  # 3
print(lengthOfLongestSubstring("bbbbb"))     # 1
```

# Pattern 3 — Optimized Sliding Window with HashMap

## Idea

Instead of removing one-by-one:

* Store latest index of each character.
* Jump left pointer directly.

## Pattern Type

* Optimized Sliding Window
* HashMap Index Tracking

## Time Complexity

[
O(n)
]

## Space Complexity

[
O(n)
]

## Code

```python id="wo7dl4"
def lengthOfLongestSubstring(s):

    last_seen = {}

    left = 0
    max_len = 0

    for right in range(len(s)):

        ch = s[right]

        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1

        last_seen[ch] = right

        max_len = max(max_len, right - left + 1)

    return max_len


# Test
print(lengthOfLongestSubstring("abcabcbb"))  # 3
print(lengthOfLongestSubstring("bbbbb"))     # 1
print(lengthOfLongestSubstring("pwwkew"))    # 3
```

# Pattern 4 — Fixed Array ASCII Optimization

## Idea

* Use array instead of hashmap.
* Faster for ASCII characters.

## Pattern Type

* Sliding Window
* Array Index Mapping

## Time Complexity

[
O(n)
]

## Space Complexity

[
O(1)
]

(ASCII size fixed)

## Code

```python id="s3d5v5"
def lengthOfLongestSubstring(s):

    last_seen = [-1] * 128

    left = 0
    max_len = 0

    for right in range(len(s)):

        ch_index = ord(s[right])

        if last_seen[ch_index] >= left:
            left = last_seen[ch_index] + 1

        last_seen[ch_index] = right

        max_len = max(max_len, right - left + 1)

    return max_len


# Test
print(lengthOfLongestSubstring("abcabcbb"))  # 3
print(lengthOfLongestSubstring("bbbbb"))     # 1
```

# Most Optimized Pattern

```python id="7oc0h6"
def lengthOfLongestSubstring(s):

    last_seen = {}

    left = 0
    max_len = 0

    for right, ch in enumerate(s):

        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1

        last_seen[ch] = right

        max_len = max(max_len, right - left + 1)

    return max_len
```

---

# Why This Is Optimized

* Each character processed once
* Left pointer jumps directly
* No unnecessary removals
* True linear time
