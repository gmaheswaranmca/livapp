# Implement strStr

Find the first occurrence index of `needle` inside `haystack`.

Example:

```text
Input: haystack = "sadbutsad", needle = "sad"
Output: 0
```

---

# Pattern 1: Brute Force Window Matching

## Idea

Check every possible starting index and compare characters one by one.

## Pattern

* Fixed-size sliding window
* Nested loop string matching

## Time Complexity

* Worst: `O((n-m+1) * m)`
* Space: `O(1)`

---

## Code

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n = len(haystack)
        m = len(needle)

        if m == 0:
            return 0

        for i in range(n - m + 1):

            j = 0

            while j < m and haystack[i + j] == needle[j]:
                j += 1

            if j == m:
                return i

        return -1
```

---

# Pattern 2: Slicing Comparison

## Idea

Compare substring slices directly.

## Pattern

* Fixed-size substring comparison

## Time Complexity

* Worst: `O((n-m+1) * m)`
* Space: `O(m)` because slicing creates new substring

---

## Code

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n = len(haystack)
        m = len(needle)

        if m == 0:
            return 0

        for i in range(n - m + 1):

            if haystack[i:i+m] == needle:
                return i

        return -1
```

# Pattern 3: Two Pointer Matching

## Idea

Use two pointers:

* One for haystack
* One for needle

Restart needle matching on mismatch.

## Pattern

* Two pointers
* Restart matching

## Time Complexity

* Worst: `O(n * m)`
* Space: `O(1)`

---

## Code

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        n = len(haystack)
        m = len(needle)

        if m == 0:
            return 0

        i = 0

        while i <= n - m:

            h = i
            p = 0

            while p < m and haystack[h] == needle[p]:
                h += 1
                p += 1

            if p == m:
                return i

            i += 1

        return -1
```

# Pattern 4: KMP (Knuth Morris Pratt) — Optimized

## Idea

Avoid rechecking characters using LPS array.

LPS = Longest Prefix which is also Suffix.

## Pattern

* String preprocessing
* Prefix table
* Efficient mismatch handling

## Time Complexity

* `O(n + m)`
* Space: `O(m)`

---

## KMP Visualization

Needle:

```text
a b a b c
0 0 1 2 0
```

LPS tells:
After mismatch, where to continue from.

---

## Code

```python
class Solution:

    def buildLPS(self, pattern):

        m = len(pattern)

        lps = [0] * m

        length = 0
        i = 1

        while i < m:

            if pattern[i] == pattern[length]:

                length += 1
                lps[i] = length
                i += 1

            else:

                if length != 0:
                    length = lps[length - 1]
                else:
                    lps[i] = 0
                    i += 1

        return lps

    def strStr(self, haystack: str, needle: str) -> int:

        n = len(haystack)
        m = len(needle)

        if m == 0:
            return 0

        lps = self.buildLPS(needle)

        i = 0
        j = 0

        while i < n:

            if haystack[i] == needle[j]:
                i += 1
                j += 1

            if j == m:
                return i - j

            elif i < n and haystack[i] != needle[j]:

                if j != 0:
                    j = lps[j - 1]
                else:
                    i += 1

        return -1
```

# Pattern Comparison

| Pattern     | Time   | Space | Best Use             |
| ----------- | ------ | ----- | -------------------- |
| Brute Force | O(n*m) | O(1)  | Easy understanding   |
| Slicing     | O(n*m) | O(m)  | Pythonic/simple      |
| Two Pointer | O(n*m) | O(1)  | Manual matching      |
| KMP         | O(n+m) | O(m)  | Optimized interviews |

---

# Optimized Solution

## Best Choice: KMP

Why?

* Linear time
* No unnecessary backtracking
* Best for large strings

## Optimized Complexity

```text
Time  : O(n + m)
Space : O(m)
```
