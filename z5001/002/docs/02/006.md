# Valid Palindrome

Check whether a string becomes a palindrome after:

* Ignoring non-alphanumeric characters
* Ignoring uppercase/lowercase differences

Example:

```text
Input:  "A man, a plan, a canal: Panama"
Output: True
```

Because after cleaning:

```text
amanaplanacanalpanama
```

which is the same forward and backward.

---

# Pattern 1 — Clean String + Reverse Compare

## Idea

1. Remove non-alphanumeric characters
2. Convert to lowercase
3. Compare with reverse

---

## Pattern Used

* String Cleaning
* Two-pass traversal
* Reverse comparison

---

## Code

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:

        cleaned = ""

        for ch in s:
            if ch.isalnum():
                cleaned += ch.lower()

        return cleaned == cleaned[::-1]
```

---

## Time Complexity

```text
O(n)
```

## Space Complexity

```text
O(n)
```

(extra cleaned string)

---

# Pattern 2 — Two Pointers (Better)

## Idea

Use:

* left pointer from beginning
* right pointer from end

Skip:

* symbols
* spaces
* punctuation

Compare characters directly.

---

## Pattern Used

* Two Pointers
* In-place comparison
* Character skipping

---

## Code

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:

        left = 0
        right = len(s) - 1

        while left < right:

            # Skip non-alphanumeric from left
            while left < right and not s[left].isalnum():
                left += 1

            # Skip non-alphanumeric from right
            while left < right and not s[right].isalnum():
                right -= 1

            # Compare lowercase characters
            if s[left].lower() != s[right].lower():
                return False

            left += 1
            right -= 1

        return True
```

---

# Dry Run

Input:

```text
"A man, a plan, a canal: Panama"
```

Pointers move like:

```text
A ↔ a
m ↔ m
a ↔ a
n ↔ n
...
```

All match → palindrome.

# Pattern 3 — List + Reverse

## Idea

Store valid lowercase characters in list.

---

## Code

```python
class Solution:
    def isPalindrome(self, s: str) -> bool:

        arr = []

        for ch in s:
            if ch.isalnum():
                arr.append(ch.lower())

        return arr == arr[::-1]
```

---

# Complexity Comparison

| Pattern                | Time | Space | Best Use                           |
| ---------------------- | ---- | ----- | ---------------------------------- |
| Clean String + Reverse | O(n) | O(n)  | Easy to understand                 |
| List + Reverse         | O(n) | O(n)  | Better than repeated string concat |
| Two Pointers           | O(n) | O(1)  | Optimized interview solution       |

---

# Why Two Pointers is Optimized

Because:

* No extra cleaned string
* No extra array
* Single traversal
* Constant space

# Important Interview Insight

## Why `isalnum()`?

It checks:

```text
a-z
A-Z
0-9
```

and ignores:

```text
spaces
commas
:
!
@
#
...
```
