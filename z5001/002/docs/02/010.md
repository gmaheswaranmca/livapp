# Decode String

Decode encoded strings like:

```text id="n8h6ms"
Input:  "3[a2[c]]"
Output: "accaccacc"
```

Rule:

```text id="ylf0lk"
k[encoded_string]
```

means repeat encoded_string `k` times.

---

# Pattern 1 — Stack (Most Common)

## Idea

Use:

* number stack
* string stack

When:

* digit → build number
* `[` → push current state
* `]` → pop and build decoded string

---

## Code

```python id="uqe17m"
class Solution:
    def decodeString(self, s):

        num_stack = []
        str_stack = []

        curr_num = 0
        curr_str = ""

        for ch in s:

            if ch.isdigit():

                curr_num = curr_num * 10 + int(ch)

            elif ch == '[':

                num_stack.append(curr_num)
                str_stack.append(curr_str)

                curr_num = 0
                curr_str = ""

            elif ch == ']':

                repeat = num_stack.pop()
                prev = str_stack.pop()

                curr_str = prev + curr_str * repeat

            else:

                curr_str += ch

        return curr_str
```

---

## Time Complexity

```text id="u0jq1k"
O(N)
```

## Space Complexity

```text id="xj8m3u"
O(N)
```

# Pattern 2 — Single Stack

## Idea

Push everything into one stack.

When `]` appears:

* extract substring
* extract number
* repeat and push back

---

## Code

```python id="6m9v4d"
class Solution:
    def decodeString(self, s):

        stack = []

        for ch in s:

            if ch != ']':

                stack.append(ch)

            else:

                substr = ""

                while stack[-1] != '[':
                    substr = stack.pop() + substr

                stack.pop()

                num = ""

                while stack and stack[-1].isdigit():
                    num = stack.pop() + num

                stack.append(substr * int(num))

        return "".join(stack)
```

---

## Time Complexity

```text id="p3d5ku"
O(N)
```

## Space Complexity

```text id="qijm0m"
O(N)
```

# Pattern 3 — Recursion / DFS

## Idea

Recursive call handles inner bracket.

When `]` reached:

* return decoded substring

---

## Code

```python id="nww5iq"
class Solution:

    def decodeString(self, s):

        self.i = 0

        def dfs():

            result = ""
            num = 0

            while self.i < len(s):

                ch = s[self.i]

                if ch.isdigit():

                    num = num * 10 + int(ch)

                elif ch == '[':

                    self.i += 1

                    decoded = dfs()

                    result += decoded * num

                    num = 0

                elif ch == ']':

                    return result

                else:

                    result += ch

                self.i += 1

            return result

        return dfs()
```

```text id="fth1w2"
O(N)
```

## Space Complexity

```text id="jlwm0r"

```

# Pattern 4 — Regex Replacement (Iterative)

## Idea

Repeatedly:

* find innermost `k[...]`
* decode
* replace

---

## Code

```python id="hl5hgm"
import re

class Solution:
    def decodeString(self, s):

        pattern = r'(\d+)\[([a-zA-Z]*)\]'

        while '[' in s:

            s = re.sub(
                pattern,
                lambda m: int(m.group(1)) * m.group(2),
                s
            )

        return s
```

---

## Time Complexity

```text id="0kxv7v"
Worst: O(N²)
```

## Space Complexity

```text id="5g3k2m"
O(N)
```

# Pattern 5 — Queue + Recursion

## Idea

Convert string into queue.

Recursive parser consumes characters one-by-one.

---

## Code

```python id="4yo5hu"
from collections import deque

class Solution:

    def decodeString(self, s):

        queue = deque(s)

        def helper():

            result = ""
            num = 0

            while queue:

                ch = queue.popleft()

                if ch.isdigit():

                    num = num * 10 + int(ch)

                elif ch == '[':

                    decoded = helper()

                    result += decoded * num

                    num = 0

                elif ch == ']':

                    return result

                else:

                    result += ch

            return result

        return helper()
```

# Optimized Pattern Comparison

| Pattern       | Best Use                    | Time  | Space | Interview Value |
| ------------- | --------------------------- | ----- | ----- | --------------- |
| Two Stack     | Standard interview solution | O(N)  | O(N)  | Very High       |
| Single Stack  | Compact iterative           | O(N)  | O(N)  | High            |
| Recursion DFS | Natural nested parsing      | O(N)  | O(N)  | Very High       |
| Regex         | Small/simple cases          | O(N²) | O(N)  | Low             |
| Queue + DFS   | Parser-style problems       | O(N)  | O(N)  | Medium          |

---

# Most Optimized for Interviews

## Recommended

Two Stack Pattern

Why:

* Clean logic
* Easy nested handling
* No recursion depth issue
* Most expected by interviewers
