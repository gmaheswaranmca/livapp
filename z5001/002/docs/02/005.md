# Minimum Window Substring

Find the **smallest substring** in string `s` that contains all characters of string `t`.

Example:

```text
Input:
s = "ADOBECODEBANC"
t = "ABC"

Output:
"BANC"
```

---

# Pattern Recognition

This problem is mainly solved using:

1. **Brute Force Enumeration**
2. **Sliding Window + Frequency Count** ← Optimized
3. **Sliding Window + Counter Optimization**

---

# 1. Brute Force Pattern

## Idea

Generate every substring and check whether it contains all characters of `t`.

---

## Steps

* Generate all substrings
* Count characters
* Compare with target frequency map
* Track minimum valid substring

---

## Time Complexity

* Substrings → O(N²)
* Validation → O(256) or O(T)

Overall:

```text
O(N³)
```

---

## Code

```python
from collections import Counter

def min_window_bruteforce(s, t):
    if not s or not t:
        return ""

    target = Counter(t)

    min_len = float('inf')
    result = ""

    for i in range(len(s)):
        freq = {}

        for j in range(i, len(s)):
            ch = s[j]
            freq[ch] = freq.get(ch, 0) + 1

            valid = True

            for c in target:
                if freq.get(c, 0) < target[c]:
                    valid = False
                    break

            if valid:
                if (j - i + 1) < min_len:
                    min_len = j - i + 1
                    result = s[i:j+1]

    return result


print(min_window_bruteforce("ADOBECODEBANC", "ABC"))
```

---

# 2. Sliding Window Pattern (Standard Optimized)

## Main Idea

Use:

* `right` → expand window
* `left` → shrink window
* Frequency maps
* Track when all characters are matched

This is the core optimized approach.

---

# Visualization

```text
s = "ADOBECODEBANC"
t = "ABC"

Expand right →
ADOBEC

Valid window found

Shrink left →
DOBEC  ❌ missing A

Expand again →
CODEBA

Expand →
BANC ✅
```

---

# Core Logic

We maintain:

* `target_count`
* `window_count`
* `have`
* `need`

Where:

```text
need = number of unique chars in t
have = matched unique chars
```

When:

```text
have == need
```

window becomes valid.

---

# Time Complexity

```text
O(N)
```

Each character moves:

* once by right
* once by left

---

# Space Complexity

```text
O(256) or O(T)
```

---

# Optimized Code

```python
from collections import Counter

def min_window(s, t):

    if not s or not t:
        return ""

    target_count = Counter(t)
    window_count = {}

    have = 0
    need = len(target_count)

    left = 0

    min_len = float('inf')
    result = [-1, -1]

    for right in range(len(s)):

        ch = s[right]

        window_count[ch] = window_count.get(ch, 0) + 1

        # character requirement satisfied
        if ch in target_count and window_count[ch] == target_count[ch]:
            have += 1

        # valid window
        while have == need:

            # update answer
            window_len = right - left + 1

            if window_len < min_len:
                min_len = window_len
                result = [left, right]

            # shrink from left
            left_char = s[left]

            window_count[left_char] -= 1

            if (
                left_char in target_count and
                window_count[left_char] < target_count[left_char]
            ):
                have -= 1

            left += 1

    l, r = result

    return s[l:r+1] if min_len != float('inf') else ""


print(min_window("ADOBECODEBANC", "ABC"))
```

# 3. Sliding Window with Array Optimization

Useful when characters are ASCII.

Instead of dictionaries:

```python
freq = [0] * 128
```

This reduces hashing overhead.

---

# Optimized ASCII Version

```python
def min_window_ascii(s, t):

    if not s or not t:
        return ""

    target = [0] * 128
    window = [0] * 128

    for ch in t:
        target[ord(ch)] += 1

    required = len(t)

    left = 0

    min_len = float('inf')
    start = 0

    for right in range(len(s)):

        ch = s[right]
        idx = ord(ch)

        window[idx] += 1

        if target[idx] > 0 and window[idx] <= target[idx]:
            required -= 1

        while required == 0:

            if (right - left + 1) < min_len:
                min_len = right - left + 1
                start = left

            left_idx = ord(s[left])

            window[left_idx] -= 1

            if (
                target[left_idx] > 0 and
                window[left_idx] < target[left_idx]
            ):
                required += 1

            left += 1

    if min_len == float('inf'):
        return ""

    return s[start:start + min_len]


print(min_window_ascii("ADOBECODEBANC", "ABC"))
```

# Pattern Comparison

| Pattern                | Idea                    | Time  | Space  | Interview Value |
| ---------------------- | ----------------------- | ----- | ------ | --------------- |
| Brute Force            | Generate all substrings | O(N³) | O(T)   | Basic           |
| Sliding Window         | Expand + shrink         | O(N)  | O(T)   | Very High       |
| Sliding Window + Array | Hash optimization       | O(N)  | O(128) | High            |

---

# Best Optimized Pattern

## Sliding Window

Why?

* Linear time
* Most expected in interviews
* Standard template for:

  * smallest substring
  * longest substring
  * anagrams
  * distinct characters
  * window problems

---

# Important Interview Insight

This problem teaches the master sliding-window template:

```python
for right in range(n):

    add current char

    while window is valid:

        update answer

        shrink from left
```

This same pattern is used in:

* Longest Repeating Character Replacement
* Permutation in String
* Find All Anagrams
* Longest Substring with K Distinct Characters
* Smallest Window Problems

# Edge Cases

## Empty strings

```python
s = ""
t = "ABC"
```

Output:

```python
""
```

---

## No valid substring

```python
s = "HELLO"
t = "XYZ"
```

Output:

```python
""
```

---

## Repeated characters in target

```python
s = "AAABBC"
t = "AABC"
```

Need:

* 2 A's
* 1 B
* 1 C

Sliding window handles this correctly using frequencies.
