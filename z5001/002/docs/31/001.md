# Merge Intervals (Medium)

**Problem Statement**
Given an array of intervals where `intervals[i] = [start, end]`, merge all overlapping intervals and return the resulting non-overlapping intervals.

**Example**

```python
Input: [[1,3],[2,6],[8,10],[15,18]]

Output: [[1,6],[8,10],[15,18]]
```

---

# Solution Patterns

## Pattern 1: Brute Force Merging

### Idea

Compare every interval with every other interval and merge overlaps repeatedly until no more merges are possible.

### Steps

1. Compare each interval with all others.
2. Merge if overlapping.
3. Repeat until stable.

### Complexity

* Time: **O(N²)**
* Space: **O(N)**

### Code

```python
def merge(intervals):
    changed = True

    while changed:
        changed = False
        result = []

        while intervals:
            current = intervals.pop()

            i = 0
            while i < len(intervals):
                if not (current[1] < intervals[i][0] or current[0] > intervals[i][1]):
                    current = [
                        min(current[0], intervals[i][0]),
                        max(current[1], intervals[i][1])
                    ]
                    intervals.pop(i)
                    changed = True
                else:
                    i += 1

            result.append(current)

        intervals = result

    return intervals
```

## Pattern 2: Sorting + Scan (Standard Approach)

### Idea

After sorting by start time:

* If current interval overlaps with previous merged interval:

  * Extend the end.
* Otherwise:

  * Start a new interval.

### Steps

```text
Sort intervals

Take first interval

For every next interval:
    overlap?
        merge
    else
        add new interval
```

### Complexity

* Time: **O(N log N)** (sorting)
* Space: **O(N)**

### Code

```python
def merge(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for start, end in intervals[1:]:

        last_end = merged[-1][1]

        if start <= last_end:
            merged[-1][1] = max(last_end, end)
        else:
            merged.append([start, end])

    return merged
```

---

## Pattern 3: Sorting + Stack

### Idea

Use a stack to keep merged intervals.

### Complexity

* Time: **O(N log N)**
* Space: **O(N)**

### Code

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])

    stack = []

    for interval in intervals:

        if not stack:
            stack.append(interval)

        elif stack[-1][1] >= interval[0]:
            stack[-1][1] = max(stack[-1][1], interval[1])

        else:
            stack.append(interval)

    return stack
```

# Optimized Solution

### Pattern: Sorting + Scan

Why?

* Overlapping relationship depends on interval ordering.
* Sorting guarantees all possible overlaps become adjacent.
* Single pass after sorting.
* Most commonly expected in Amazon, Google, Meta, Microsoft, and Bloomberg interviews.

### Optimized Code

```python
def merge(intervals):
    if len(intervals) <= 1:
        return intervals

    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for start, end in intervals[1:]:

        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])

    return merged
```

### Complexity

* **Time:** O(N log N)
* **Space:** O(N)
