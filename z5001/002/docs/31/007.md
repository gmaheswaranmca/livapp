# Insert Interval (Medium)

**Problem:**
Given a list of **non-overlapping intervals sorted by start time**, insert a new interval and merge if necessary.

### Example

```text
Input:
intervals = [[1,3],[6,9]]
newInterval = [2,5]

Output:
[[1,5],[6,9]]
```

---

# Pattern 1: Brute Force (Append + Sort + Merge)

## Idea

1. Add the new interval to the list.
2. Sort all intervals.
3. Perform normal Merge Intervals.

## Pattern Used

* Sorting
* Interval Merging

## Time Complexity

* Sorting: O(n log n)
* Merge: O(n)

**Overall:** O(n log n)

## Space Complexity

O(n)

## Code

```python
def insert(intervals, newInterval):
    intervals.append(newInterval)

    intervals.sort(key=lambda x: x[0])

    result = []

    for interval in intervals:
        if not result or result[-1][1] < interval[0]:
            result.append(interval)
        else:
            result[-1][1] = max(result[-1][1], interval[1])

    return result
```

# Pattern 2: Three-Phase Traversal

## Idea

Since intervals are already sorted:

### Phase 1

Add all intervals completely before newInterval.

```text
[1,2] [3,5] [6,7]
          [8,10]
```

Take first three directly.

---

### Phase 2

Merge overlapping intervals.

```text
[3,5]
[4,8]
```

becomes

```text
[3,8]
```

---

### Phase 3

Add remaining intervals.

---

## Pattern Used

* Linear Scan
* Merge While Traversing

## Time Complexity

O(n)

## Space Complexity

O(n)

## Code

```python
def insert(intervals, newInterval):
    result = []
    i = 0
    n = len(intervals)

    # Phase 1
    while i < n and intervals[i][1] < newInterval[0]:
        result.append(intervals[i])
        i += 1

    # Phase 2
    while i < n and intervals[i][0] <= newInterval[1]:
        newInterval[0] = min(newInterval[0], intervals[i][0])
        newInterval[1] = max(newInterval[1], intervals[i][1])
        i += 1

    result.append(newInterval)

    # Phase 3
    while i < n:
        result.append(intervals[i])
        i += 1

    return result
```

# Pattern 3: Build Result While Iterating

## Idea

Process intervals one by one.

### Cases

#### Case 1: Interval before newInterval

```text
[1,2]     [5,7]
```

Add interval.

---

#### Case 2: Interval after newInterval

```text
      [1,3]
[5,7]
```

Insert newInterval once.

---

#### Case 3: Overlap

```text
[1,5]
   [3,8]
```

Merge.

---

## Pattern Used

* Greedy
* Single Pass

## Time Complexity

O(n)

## Space Complexity

O(n)

## Code

```python
def insert(intervals, newInterval):
    result = []
    inserted = False

    for interval in intervals:

        if interval[1] < newInterval[0]:
            result.append(interval)

        elif interval[0] > newInterval[1]:

            if not inserted:
                result.append(newInterval)
                inserted = True

            result.append(interval)

        else:
            newInterval[0] = min(newInterval[0], interval[0])
            newInterval[1] = max(newInterval[1], interval[1])

    if not inserted:
        result.append(newInterval)

    return result
```

# Pattern 4: In-Place Modification

## Idea

Insert at correct position and merge directly inside array.

Useful when minimizing extra structures.

## Time Complexity

O(n)

## Space Complexity

O(1) extra (excluding output)

## Code

```python
def insert(intervals, newInterval):
    intervals.append(newInterval)
    intervals.sort(key=lambda x: x[0])

    idx = 0

    while idx < len(intervals) - 1:
        current = intervals[idx]
        nxt = intervals[idx + 1]

        if current[1] >= nxt[0]:
            current[1] = max(current[1], nxt[1])
            intervals.pop(idx + 1)
        else:
            idx += 1

    return intervals
```

# Optimized Solution

### Best Pattern: Three-Phase Traversal

Why?

✅ Uses the fact that intervals are already sorted
✅ No unnecessary sorting
✅ Single linear scan
✅ Easy to explain in interviews
✅ Standard solution expected by Google, Amazon, Meta, Microsoft

## Optimized Code

```python
def insert(intervals, newInterval):
    result = []
    i = 0
    n = len(intervals)

    while i < n and intervals[i][1] < newInterval[0]:
        result.append(intervals[i])
        i += 1

    while i < n and intervals[i][0] <= newInterval[1]:
        newInterval[0] = min(newInterval[0], intervals[i][0])
        newInterval[1] = max(newInterval[1], intervals[i][1])
        i += 1

    result.append(newInterval)

    while i < n:
        result.append(intervals[i])
        i += 1

    return result
```

### Key Interview Pattern

This problem is a classic **Intervals + Merge Intervals Pattern** and is often asked immediately after:

1. Merge Intervals
2. Meeting Rooms
3. Non-overlapping Intervals
4. Employee Free Time
5. Interval List Intersections

The expected interview solution is **O(n) linear scan with three phases**.
