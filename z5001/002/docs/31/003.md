# Sort Colors (Dutch National Flag)

**Problem:**
Given an array containing only `0`, `1`, and `2`, sort it in-place without using built-in sorting.

**Companies:** Amazon, Microsoft, Meta, Google
**Difficulty:** Medium

---

# Pattern 1: Counting Sort (Frequency Counting)

### Idea

Count the occurrences of `0`, `1`, and `2`, then overwrite the array.

### Pattern

* Counting
* Frequency Array

### Time Complexity

* **O(n)**

### Space Complexity

* **O(1)**

### Code

```python
def sortColors(nums):
    count0 = count1 = count2 = 0

    for num in nums:
        if num == 0:
            count0 += 1
        elif num == 1:
            count1 += 1
        else:
            count2 += 1

    index = 0

    for _ in range(count0):
        nums[index] = 0
        index += 1

    for _ in range(count1):
        nums[index] = 1
        index += 1

    for _ in range(count2):
        nums[index] = 2
        index += 1
```

# Pattern 2: Dutch National Flag Algorithm (Three Pointers)

### Idea

Maintain three regions:

```text
[0 ... low-1]      -> 0s
[low ... mid-1]    -> 1s
[mid ... high]     -> Unknown
[high+1 ... end]   -> 2s
```

Process the unknown region.

### Pattern

* Three Pointers
* In-place Partitioning
* Dutch National Flag

### Time Complexity

* **O(n)**

### Space Complexity

* **O(1)**

### Code

```python
def sortColors(nums):
    low = 0
    mid = 0
    high = len(nums) - 1

    while mid <= high:

        if nums[mid] == 0:
            nums[low], nums[mid] = nums[mid], nums[low]
            low += 1
            mid += 1

        elif nums[mid] == 1:
            mid += 1

        else:
            nums[mid], nums[high] = nums[high], nums[mid]
            high -= 1
```

### Example

```python
nums = [2,0,2,1,1,0]

low=0 mid=0 high=5

2 -> swap with high
0 -> swap with low
0 -> swap with low
1 -> move mid
1 -> move mid
2 -> done

Result:
[0,0,1,1,2,2]
```

# Optimized Solution

### Use Dutch National Flag Algorithm

Why?

✅ Single traversal
✅ Constant extra space
✅ In-place sorting
✅ Most frequently expected by Amazon, Google, Meta, Microsoft interviews
✅ Specifically designed for three distinct values

```python
def sortColors(nums):
    low = 0
    mid = 0
    high = len(nums) - 1

    while mid <= high:

        if nums[mid] == 0:
            nums[low], nums[mid] = nums[mid], nums[low]
            low += 1
            mid += 1

        elif nums[mid] == 1:
            mid += 1

        else:
            nums[mid], nums[high] = nums[high], nums[mid]
            high -= 1

    return nums
```

### Interview Pattern Recognition

If you see:

* Array contains only a few distinct values
* Need in-place partitioning
* Sort 0s, 1s, 2s
* Three categories/groups
* One-pass requirement

Think:
