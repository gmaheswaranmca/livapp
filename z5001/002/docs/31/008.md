# Non-overlapping Intervals

**Problem:** Remove the minimum number of intervals so that the remaining intervals do not overlap.

Example:

```python
Input: [[1,2],[2,3],[3,4],[1,3]]
Output: 1
```

---

# Pattern 1: Brute Force (Try Removing Intervals)

### Idea

Generate possible removals and check if remaining intervals overlap.

### Complexity

* Time: Exponential
* Space: O(n)

### Not recommended for interviews.

---

# Pattern 2: Dynamic Programming (Interval Scheduling Variant)

### Idea

1. Sort intervals by start time.
2. Let `dp[i]` = maximum non-overlapping intervals ending at `i`.
3. Find maximum intervals that can be kept.
4. Answer = total intervals - maximum kept.

### Complexity

* Time: O(n²)
* Space: O(n)

### Code

```python
def eraseOverlapIntervals(intervals):
    intervals.sort()

    n = len(intervals)
    dp = [1] * n

    for i in range(n):
        for j in range(i):
            if intervals[j][1] <= intervals[i][0]:
                dp[i] = max(dp[i], dp[j] + 1)

    return n - max(dp)
```

---

# Pattern 3: Greedy by Earliest End Time (Optimal)

### Idea

This is identical to the classic **Activity Selection Problem**.

Instead of deciding which interval to remove:

* Keep intervals with the earliest finishing time.
* Earlier finishing leaves maximum room for future intervals.
* Count overlaps that must be removed.

### Steps

1. Sort by ending time.
2. Keep first interval.
3. If current interval starts before previous ends:

   * overlap found
   * remove current interval
4. Else:

   * keep interval
   * update previous end

---

### Visualization

```text
[1,2]
    [1,3]   ← overlap

Keep [1,2]
Remove [1,3]

Reason:
end=2 is better than end=3
```

---

### Complexity

* Time: O(n log n) (sorting)
* Space: O(1)

---

### Code

```python
def eraseOverlapIntervals(intervals):
    if not intervals:
        return 0

    intervals.sort(key=lambda x: x[1])

    removals = 0
    prev_end = intervals[0][1]

    for start, end in intervals[1:]:
        if start < prev_end:
            removals += 1
        else:
            prev_end = end

    return removals
```

# Pattern 4: Greedy by Start Time

### Idea

Sort by start time.

When overlap occurs:

* Remove interval having larger end time.
* Keep interval ending earlier.

### Complexity

* Time: O(n log n)
* Space: O(1)

### Code

```python
def eraseOverlapIntervals(intervals):
    intervals.sort()

    removals = 0
    prev_end = intervals[0][1]

    for i in range(1, len(intervals)):
        start, end = intervals[i]

        if start < prev_end:
            removals += 1
            prev_end = min(prev_end, end)
        else:
            prev_end = end

    return removals
```

---

# Pattern Comparison

| Pattern              | Time        | Space | Interview Value |
| -------------------- | ----------- | ----- | --------------- |
| Brute Force          | Exponential | O(n)  | Poor            |
| Dynamic Programming  | O(n²)       | O(n)  | Medium          |
| Greedy by Start Time | O(n log n)  | O(1)  | Good            |
| Greedy by End Time   | O(n log n)  | O(1)  | Best            |

# Optimized Solution Pattern

### Greedy + Interval Scheduling

The key observation:

> To maximize the number of intervals kept, always keep the interval that finishes earliest.

This is the same proof used in Activity Selection.

### Recommended Interview Solution

```python
def eraseOverlapIntervals(intervals):
    if not intervals:
        return 0

    intervals.sort(key=lambda x: x[1])

    removals = 0
    last_end = intervals[0][1]

    for start, end in intervals[1:]:
        if start < last_end:
            removals += 1
        else:
            last_end = end

    return removals
```

### Complexity

* **Time:** O(n log n)
* **Space:** O(1)

### Pattern to Remember

```text
Intervals Problem
 ├─ Merge overlapping      → Sort by Start
 ├─ Meeting rooms          → Min Heap
 ├─ Insert interval        → Merge Pattern
 ├─ Activity selection     → Sort by End
 └─ Non-overlapping intervals
        → Greedy
        → Sort by End
        → Keep earliest ending interval
```
