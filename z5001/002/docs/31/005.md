# Largest Number (LeetCode 179)

**Problem Statement:**
Given a list of non-negative integers, arrange them such that they form the largest possible number.

**Example**

```python
Input: nums = [3,30,34,5,9]
Output: "9534330"
```

---

# Pattern Identification

This problem belongs to:

* Custom Sorting
* Greedy
* Comparator-Based Sorting
* String Manipulation

---

# Pattern 1: Generate All Permutations (Brute Force)

### Idea

Try every possible arrangement and choose the largest number.

### Algorithm

1. Generate all permutations.
2. Concatenate numbers.
3. Return maximum.

### Complexity

* Time: O(N! × N)
* Space: O(N!)

### Python

```python
from itertools import permutations

def largestNumber(nums):
    largest = ""

    for perm in permutations(nums):
        current = ''.join(map(str, perm))
        largest = max(largest, current)

    return largest
```

### Drawback

Not feasible beyond very small inputs.

---

# Pattern 2: Greedy Custom Sort (Comparison Function)

### Key Observation

For two numbers:

```text
a = "3"
b = "30"
```

Compare:

```text
"330"
"303"
```

Since:

```text
330 > 303
```

Place `3` before `30`.

---

### Comparator Rule

For any two strings:

```python
a before b if a+b > b+a
```

This guarantees the globally largest number.

---

### Algorithm

1. Convert integers to strings.
2. Sort using custom comparator.
3. Join strings.
4. Handle all-zero case.

### Complexity

* Time: O(N log N)
* Space: O(N)

---

### Python

```python
from functools import cmp_to_key

def largestNumber(nums):

    nums = list(map(str, nums))

    def compare(a, b):
        if a + b > b + a:
            return -1
        elif a + b < b + a:
            return 1
        return 0

    nums.sort(key=cmp_to_key(compare))

    result = ''.join(nums)

    return '0' if result[0] == '0' else result
```

# Pattern 3: Custom Sort Using Extended Key Trick

### Idea

Some languages allow sorting by repeated strings.

Example:

```python
"3"   -> "333333"
"30"  -> "303030"
"34"  -> "343434"
```

Sort descending.

### Python

```python
def largestNumber(nums):

    nums = list(map(str, nums))

    nums.sort(key=lambda x: x * 10, reverse=True)

    result = ''.join(nums)

    return '0' if result[0] == '0' else result
```

### Complexity

* Time: O(N log N)
* Space: O(N)

### Drawback

Relies on input constraints. Not universally correct for arbitrary-length numbers.

Consider:

```python
nums = [10, 2]
```

Compare:

```text
"102"
"210"
```

Since:

```text
210 > 102
```

Order:

```python
[2,10]
```

Result:

```text

```

```python
nums = [3,30,34,5,9]
```

Sorting by:

```text

```

Produces:

```python

```

Result:


# Optimized Interview Solution

```python
from functools import cmp_to_key

class Solution:
    def largestNumber(self, nums):

        nums = list(map(str, nums))

        def compare(a, b):
            if a + b > b + a:
                return -1
            elif a + b < b + a:
                return 1
            return 0

        nums.sort(key=cmp_to_key(compare))

        result = ''.join(nums)

        return "0" if result[0] == "0" else result
```

### Complexity Analysis

```text
Time  : O(N log N)
Space : O(N)
```
