# Merge Sorted Array (LeetCode 88)

**Problem:**
Given two sorted arrays `nums1` and `nums2`, merge `nums2` into `nums1` as one sorted array.
`nums1` has enough space (`m + n`) to hold all elements.

Example:

```python
nums1 = [1,2,3,0,0,0]
m = 3

nums2 = [2,5,6]
n = 3

Output:
[1,2,2,3,5,6]
```

---

# Pattern 1: Extra Array (Brute Force)

### Idea

* Copy elements from both arrays into a new array.
* Sort the result.
* Copy back to `nums1`.

### Time Complexity

* Sorting: **O((m+n) log(m+n))**

### Space Complexity

* **O(m+n)**

### Code

```python
class Solution:
    def merge(self, nums1, m, nums2, n):
        temp = nums1[:m] + nums2
        temp.sort()

        for i in range(m + n):
            nums1[i] = temp[i]
```

# Pattern 2: Two Pointers + Extra Array

### Idea

* Use two pointers on both arrays.
* Merge like Merge Sort.
* Store result in temporary array.

### Time Complexity

* **O(m+n)**

### Space Complexity

* **O(m+n)**

### Code

```python
class Solution:
    def merge(self, nums1, m, nums2, n):
        i = 0
        j = 0
        temp = []

        while i < m and j < n:
            if nums1[i] <= nums2[j]:
                temp.append(nums1[i])
                i += 1
            else:
                temp.append(nums2[j])
                j += 1

        while i < m:
            temp.append(nums1[i])
            i += 1

        while j < n:
            temp.append(nums2[j])
            j += 1

        for k in range(m + n):
            nums1[k] = temp[k]
```

# Pattern 3: Insertion from Front

### Idea

* For each element in `nums2`,
  find its position in `nums1`.
* Shift elements right.

### Time Complexity

* **O(m × n)**

### Space Complexity

* **O(1)**

### Code

```python
class Solution:
    def merge(self, nums1, m, nums2, n):
        length = m

        for num in nums2:
            pos = 0

            while pos < length and nums1[pos] <= num:
                pos += 1

            for k in range(length, pos, -1):
                nums1[k] = nums1[k - 1]

            nums1[pos] = num
            length += 1
```

# Pattern 4: Three Pointers from End (Optimal)

### Pattern Used

**Two Pointers + Reverse Merge**

### Idea

Since `nums1` has extra space at the end:

* Compare largest elements from both arrays.
* Place larger element at the last available position.
* Move backwards.

This avoids shifting elements.

### Visualization

```text
nums1 = [1,2,3,0,0,0]
          ↑
          i

nums2 = [2,5,6]
            ↑
            j

place = 5
```

Process:

```text
6 > 3 → place 6
5 > 3 → place 5
3 > 2 → place 3
2 = 2 → place 2
...
```

Result:

```text
[1,2,2,3,5,6]
```

### Time Complexity

* **O(m+n)**

### Space Complexity

* **O(1)**

### Code

```python
class Solution:
    def merge(self, nums1, m, nums2, n):
        i = m - 1
        j = n - 1
        k = m + n - 1

        while i >= 0 and j >= 0:
            if nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1

            k -= 1

        while j >= 0:
            nums1[k] = nums2[j]
            j -= 1
            k -= 1
```

# Pattern 5: Gap Method (Shell Sort Style)

### Idea

* Treat both arrays as a single array.
* Compare elements at a gap distance.
* Reduce gap gradually.

Useful when arrays are separate and no extra space is allowed.

### Time Complexity

* Approximately **O((m+n) log(m+n))**

### Space Complexity

* **O(1)**

### Code

```python
class Solution:
    def next_gap(self, gap):
        if gap <= 1:
            return 0
        return (gap // 2) + (gap % 2)

    def merge(self, nums1, m, nums2, n):
        gap = self.next_gap(m + n)

        while gap > 0:
            left = 0
            right = gap

            while right < m + n:

                if left < m:
                    a = nums1[left]
                else:
                    a = nums2[left - m]

                if right < m:
                    b = nums1[right]
                else:
                    b = nums2[right - m]

                if a > b:
                    if left < m and right < m:
                        nums1[left], nums1[right] = nums1[right], nums1[left]
                    elif left < m and right >= m:
                        nums1[left], nums2[right - m] = nums2[right - m], nums1[left]
                    else:
                        nums2[left - m], nums2[right - m] = nums2[right - m], nums2[left - m]

                left += 1
                right += 1

            gap = self.next_gap(gap)
```

# Pattern Comparison

| Pattern                    | Time             | Space  | Interview Value |
| -------------------------- | ---------------- | ------ | --------------- |
| Extra Array + Sort         | O((m+n)log(m+n)) | O(m+n) | Low             |
| Merge with Temp Array      | O(m+n)           | O(m+n) | Medium          |
| Insertion/Shifting         | O(m×n)           | O(1)   | Low             |
| Reverse Merge (3 Pointers) | O(m+n)           | O(1)   | Very High       |
| Gap Method                 | O((m+n)log(m+n)) | O(1)   | High            |

# Optimized Solution

### Best Pattern

**Three Pointers from End (Reverse Merge)**

Why?

✅ Linear time `O(m+n)`
✅ Constant space `O(1)`
✅ Uses given extra space efficiently
✅ Most commonly asked by Microsoft, Amazon, Google, and Meta

```python
class Solution:
    def merge(self, nums1, m, nums2, n):
        i = m - 1
        j = n - 1
        k = m + n - 1

        while i >= 0 and j >= 0:
            if nums1[i] > nums2[j]:
                nums1[k] = nums1[i]
                i -= 1
            else:
                nums1[k] = nums2[j]
                j -= 1
            k -= 1

        while j >= 0:
            nums1[k] = nums2[j]
            j -= 1
            k -= 1
```
