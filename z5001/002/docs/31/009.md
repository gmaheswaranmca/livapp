# Queue Reconstruction by Height

**Problem:**
Given people as `[height, k]`, where:

* `height` = person's height
* `k` = number of people in front of this person who have height **>= height**

Reconstruct the original queue.

**Example**

```python
Input:
[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]

Output:
[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

---

# Pattern 1: Brute Force Simulation

### Idea

Try placing people one by one and repeatedly verify whether all `k` conditions are satisfied.

### Steps

1. Generate possible arrangements.
2. Check each arrangement.
3. Return valid queue.

### Complexity

* Time: Exponential / O(n!)
* Space: O(n)

### Verdict

❌ Not practical.

---

# Pattern 2: Sort Shortest First + Empty Slot Placement

### Idea

1. Sort by:

   * Height ascending
   * k ascending
2. Place each person into the `(k+1)`th empty slot.

### Why it works

When shorter people are placed first, taller people do not affect their count.

### Complexity

* Time: O(n²)
* Space: O(n)

### Code

```python
class Solution:
    def reconstructQueue(self, people):
        n = len(people)
        result = [None] * n

        people.sort(key=lambda x: (x[0], x[1]))

        for h, k in people:
            spaces = k + 1

            for i in range(n):
                if result[i] is None:
                    spaces -= 1

                    if spaces == 0:
                        result[i] = [h, k]
                        break

        return result
```

# Pattern 3: Greedy Sorting + List Insertion (Most Popular)

### Core Observation

If taller people are placed first:

* Their position never depends on shorter people.
* Shorter people inserted later won't affect taller people's `k`.

### Strategy

Sort:

```python
height descending
k ascending
```

Then insert each person at index `k`.

---

### Example

Input:

```python
[[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
```

Sorted:

```python
[[7,0],[7,1],[6,1],[5,0],[5,2],[4,4]]
```

Process:

```python
[]

insert [7,0] at 0
[[7,0]]

insert [7,1] at 1
[[7,0],[7,1]]

insert [6,1] at 1
[[7,0],[6,1],[7,1]]

insert [5,0] at 0
[[5,0],[7,0],[6,1],[7,1]]

insert [5,2] at 2
[[5,0],[7,0],[5,2],[6,1],[7,1]]

insert [4,4] at 4
[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

Final Answer:

```python
[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

---

### Code

```python
class Solution:
    def reconstructQueue(self, people):
        people.sort(key=lambda x: (-x[0], x[1]))

        queue = []

        for person in people:
            queue.insert(person[1], person)

        return queue
```

### Complexity

* Sorting: O(n log n)
* Insertions: O(n²)

Overall:

```python
O(n²)
```

Space:

```python
O(n)
```

# Pattern 4: Binary Indexed Tree (Fenwick Tree)

### Idea

Avoid costly list insertions.

Use:

* Fenwick Tree
* Order Statistics

Track available positions.

For each person:

1. Sort by height ascending.
2. Find `(k+1)`th empty position.
3. Place person there.

### Complexity

* Time: O(n log n)
* Space: O(n)

### Code

```python
class Fenwick:
    def __init__(self, n):
        self.n = n
        self.bit = [0] * (n + 1)

    def update(self, idx, delta):
        while idx <= self.n:
            self.bit[idx] += delta
            idx += idx & -idx

    def query(self, idx):
        s = 0
        while idx:
            s += self.bit[idx]
            idx -= idx & -idx
        return s

    def kth(self, k):
        pos = 0
        bit_mask = 1 << (self.n.bit_length())

        while bit_mask:
            nxt = pos + bit_mask

            if nxt <= self.n and self.bit[nxt] < k:
                k -= self.bit[nxt]
                pos = nxt

            bit_mask >>= 1

        return pos + 1


class Solution:
    def reconstructQueue(self, people):
        n = len(people)

        people.sort(key=lambda x: (x[0], x[1]))

        bit = Fenwick(n)

        for i in range(1, n + 1):
            bit.update(i, 1)

        ans = [None] * n

        for h, k in people:
            pos = bit.kth(k + 1)

            ans[pos - 1] = [h, k]

            bit.update(pos, -1)

        return ans
```

### Complexity

```python
Time  : O(n log n)
Space : O(n)
```

# Pattern Comparison

| Pattern              | Idea                       | Time       | Space | Interview Use |
| -------------------- | -------------------------- | ---------- | ----- | ------------- |
| Brute Force          | Generate & verify          | O(n!)      | O(n)  | ❌             |
| Empty Slot Placement | Shortest first             | O(n²)      | O(n)  | ⚠️            |
| Greedy + Insert      | Tallest first, insert at k | O(n²)      | O(n)  | ✅ Most Asked  |
| Fenwick Tree         | Order statistics           | O(n log n) | O(n)  | ⭐ Advanced    |

# Interview-Optimal Pattern

### Pattern to Remember

```text
1. Sort by height descending.
2. If heights equal, sort by k ascending.
3. Insert each person at index k.
```

### Why It Is Preferred

* Very elegant greedy proof.
* Easy to explain.
* Most commonly expected in Google, Meta, Amazon, and Microsoft interviews.
* Standard accepted solution.

### Final Optimized Interview Code

```python
class Solution:
    def reconstructQueue(self, people):
        people.sort(key=lambda x: (-x[0], x[1]))

        result = []

        for person in people:
            result.insert(person[1], person)

        return result
```

**Recommended Pattern:** Greedy Sorting + List Insertion (Pattern 3) — the canonical interview solution.
