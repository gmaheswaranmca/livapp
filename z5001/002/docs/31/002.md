# Meeting Rooms II

**Problem:** Find the minimum number of meeting rooms required to accommodate all meetings without conflicts.

Example:

```python
Input: [[0,30],[5,10],[15,20]]
Output: 2
```

---

# Pattern 1: Brute Force Overlap Counting

### Idea

For every meeting, count how many meetings overlap with it.

### Algorithm

1. Compare every interval with every other interval.
2. Count concurrent meetings.
3. Return maximum overlap.

### Code

```python
class Solution:
    def minMeetingRooms(self, intervals):
        n = len(intervals)

        max_rooms = 0

        for i in range(n):
            rooms = 1

            for j in range(n):
                if i != j:
                    if intervals[j][0] < intervals[i][1] and intervals[j][1] > intervals[i][0]:
                        rooms += 1

            max_rooms = max(max_rooms, rooms)

        return max_rooms
```

### Complexity

```text
Time  : O(N²)
Space : O(1)
```

### Pattern

```text
Brute Force Interval Comparison
```

# Pattern 2: Min Heap (Most Popular Interview Solution)

### Idea

Keep track of meeting end times.

If earliest ending meeting finishes before current meeting starts,
reuse that room.

### Algorithm

1. Sort intervals by start time.
2. Store end times in min heap.
3. If current start >= smallest end:

   * Reuse room.
4. Else:

   * Allocate new room.
5. Heap size = rooms currently used.
6. Maximum heap size is answer.

### Code

```python
import heapq

class Solution:
    def minMeetingRooms(self, intervals):
        if not intervals:
            return 0

        intervals.sort(key=lambda x: x[0])

        heap = [intervals[0][1]]

        for start, end in intervals[1:]:

            if start >= heap[0]:
                heapq.heappop(heap)

            heapq.heappush(heap, end)

        return len(heap)
```

### Complexity

```text
Time  : O(N log N)
Space : O(N)
```

### Pattern

```text
Greedy + Min Heap
```

# Pattern 3: Two Sorted Arrays (Best Interview Optimization)

### Idea

Separate start times and end times.

Whenever a meeting starts:

* Need a room.

Whenever a meeting ends:

* Free a room.

Track maximum rooms used.

### Algorithm

1. Extract starts.
2. Extract ends.
3. Sort both arrays.
4. Use two pointers.
5. If start < end:

   * Need new room.
6. Else:

   * Reuse room.

### Code

```python
class Solution:
    def minMeetingRooms(self, intervals):
        if not intervals:
            return 0

        starts = sorted(i[0] for i in intervals)
        ends = sorted(i[1] for i in intervals)

        s = 0
        e = 0

        rooms = 0
        max_rooms = 0

        while s < len(intervals):

            if starts[s] < ends[e]:
                rooms += 1
                max_rooms = max(max_rooms, rooms)
                s += 1
            else:
                rooms -= 1
                e += 1

        return max_rooms
```

### Complexity

```text
Time  : O(N log N)
Space : O(N)
```

### Pattern

```text
Line Sweep / Chronological Ordering
```

# Pattern 4: Sweep Line Using Events

### Idea

Convert meetings into:

* Start event → +1 room
* End event → -1 room

Process chronologically.

### Code

```python
class Solution:
    def minMeetingRooms(self, intervals):

        events = []

        for start, end in intervals:
            events.append((start, 1))
            events.append((end, -1))

        events.sort(key=lambda x: (x[0], x[1]))

        rooms = 0
        max_rooms = 0

        for _, change in events:
            rooms += change
            max_rooms = max(max_rooms, rooms)

        return max_rooms
```

### Complexity

```text
Time  : O(N log N)
Space : O(N)
```

### Pattern

```text
Sweep Line / Event Processing
```

# Optimized Solution

### Recommended Pattern

```text
Line Sweep / Two Sorted Arrays
```

Reason:

* Same complexity as heap solution.
* Simpler logic.
* No heap operations.
* Frequently expected by Google, Meta, Amazon, Microsoft.

### Final Optimized Code

```python
class Solution:
    def minMeetingRooms(self, intervals):
        if not intervals:
            return 0

        starts = sorted(i[0] for i in intervals)
        ends = sorted(i[1] for i in intervals)

        s = e = 0
        rooms = 0
        answer = 0

        while s < len(intervals):

            if starts[s] < ends[e]:
                rooms += 1
                answer = max(answer, rooms)
                s += 1
            else:
                rooms -= 1
                e += 1

        return answer
```
