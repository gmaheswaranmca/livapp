# K Closest Points to Origin (Medium)

**Problem:** Given an array of points `points[i] = [xi, yi]` and an integer `k`, return the `k` closest points to the origin `(0,0)`.

Distance formula:

d^2=x^2+y^2

We use **squared distance** because square root is unnecessary for comparison.

---

# Pattern 1: Sorting

## Idea

Compute distance of every point and sort.

### Complexity

* Time: **O(n log n)**
* Space: **O(n)**

### Code

```python
class Solution:
    def kClosest(self, points, k):
        points.sort(key=lambda p: p[0] * p[0] + p[1] * p[1])
        return points[:k]
```

---

# Pattern 2: Max Heap (Keep K Elements)

## Idea

Maintain a max heap of size `k`.

* Insert first k points.
* If a new point is closer than heap top, replace it.
* Heap always stores k closest points.

### Complexity

* Time: **O(n log k)**
* Space: **O(k)**

### Code

```python
import heapq

class Solution:
    def kClosest(self, points, k):
        heap = []

        for x, y in points:
            dist = x * x + y * y

            if len(heap) < k:
                heapq.heappush(heap, (-dist, [x, y]))
            else:
                if dist < -heap[0][0]:
                    heapq.heappop(heap)
                    heapq.heappush(heap, (-dist, [x, y]))

        return [point for _, point in heap]
```

# Pattern 3: Min Heap (Heapify All)

## Idea

Store all points in a min heap ordered by distance.

Extract k smallest.

### Complexity

* Time: **O(n + k log n)**
* Space: **O(n)**

### Code

```python
import heapq

class Solution:
    def kClosest(self, points, k):
        heap = []

        for x, y in points:
            dist = x * x + y * y
            heap.append((dist, [x, y]))

        heapq.heapify(heap)

        result = []

        for _ in range(k):
            result.append(heapq.heappop(heap)[1])

        return result
```

# Pattern 4: Quick Select

## Idea

Similar to Quick Sort partitioning.

* Partition based on distance.
* Keep searching only required half.
* Average linear time.

### Complexity

* Average: **O(n)**
* Worst: **O(n²)**
* Space: **O(1)**

### Code

```python
class Solution:
    def kClosest(self, points, k):

        def dist(i):
            return points[i][0] ** 2 + points[i][1] ** 2

        def partition(left, right):
            pivot = dist(right)
            p = left

            for i in range(left, right):
                if dist(i) <= pivot:
                    points[p], points[i] = points[i], points[p]
                    p += 1

            points[p], points[right] = points[right], points[p]
            return p

        left = 0
        right = len(points) - 1

        while True:
            pivot = partition(left, right)

            if pivot == k - 1:
                break
            elif pivot < k - 1:
                left = pivot + 1
            else:
                right = pivot - 1

        return points[:k]
```

# Pattern 5: Bucket Style (Distance Range Known)

## Idea

Possible only when coordinate range is small and bounded.

* Group points by distance.
* Collect from smallest distance bucket.

### Complexity

* Time: **O(n)**
* Space: **O(n)**

### Code

```python
from collections import defaultdict

class Solution:
    def kClosest(self, points, k):
        buckets = defaultdict(list)

        for x, y in points:
            dist = x * x + y * y
            buckets[dist].append([x, y])

        result = []

        for dist in sorted(buckets):
            for point in buckets[dist]:
                result.append(point)

                if len(result) == k:
                    return result
```

# Pattern Comparison

| Pattern             | Time           | Space | Interview Usage |
| ------------------- | -------------- | ----- | --------------- |
| Sorting             | O(n log n)     | O(n)  | Easy            |
| Max Heap Size K     | O(n log k)     | O(k)  | Very Common     |
| Min Heap All Points | O(n + k log n) | O(n)  | Common          |
| Quick Select        | O(n) Avg       | O(1)  | Most Optimized  |
| Bucket              | O(n)           | O(n)  | Rare            |

# Optimized Solution Choice

### If interviewer asks for first solution

✅ Sorting

### If stream of points / very large input

✅ Max Heap of size K

### If asked for best average complexity

✅ Quick Select

### FAANG Preferred Progression

```
Sorting
   ↓
Heap (O(n log k))
   ↓
Quick Select (O(n))
```

### Final Interview Answer

**Quick Select** is the most optimized expected solution:

* Average Time: **O(n)**
* Space: **O(1)**
* Frequently discussed in Amazon, Google, Meta, and Microsoft interviews after the heap solution.
