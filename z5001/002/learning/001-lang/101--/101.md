# Phase 1 — Built-in Algorithms

## Topic 1 — Sorting

Sorting is the most frequently used built-in algorithm in Competitive Programming. Every language has a highly optimized implementation, but APIs and default behavior differ.

---

# Sort (Ascending)

| Language   | Syntax                          | In-place | Stable                 | Time       |
| ---------- | ------------------------------- | -------- | ---------------------- | ---------- |
| C++        | `sort(v.begin(), v.end())`      | ✅        | ❌                      | O(n log n) |
| Rust       | `v.sort()`                      | ✅        | ✅                      | O(n log n) |
| Go         | `slices.Sort(arr)` *(Go 1.21+)* | ✅        | ❌                      | O(n log n) |
| Java       | `Arrays.sort(arr)`              | ✅        | Primitive: ❌ Object: ✅ | O(n log n) |
| Python     | `arr.sort()`                    | ✅        | ✅                      | O(n log n) |
| JavaScript | `arr.sort((a,b)=>a-b)`          | ✅        | ✅ (modern engines)     | O(n log n) |
| C#         | `Array.Sort(arr)`               | ✅        | ❌                      | O(n log n) |

| JavaScript | `arr.sort((a,b)=>b-a)`                                                                                        |     |            |

| Language   | Syntax                                 |
| ---------- | -------------------------------------- |
| C++        | `auto b=v; sort(b.begin(),b.end());`   |

| Go         | `b:=slices.Clone(arr); slices.Sort(b)` |
| Java       | `int[] b=arr.clone(); Arrays.sort(b);` |

| JavaScript | `const b=[...arr].sort((a,b)=>a-b)`    |

# Stable Sort

Maintains the relative order of equal elements.

| Language   | Syntax                                          | Available |
| ---------- | ----------------------------------------------- | --------- |
| C++        | `stable_sort(begin,end)`                        | ✅         |
| Rust       | `sort()`                                        | ✅         |
| Go         | `slices.SortStableFunc()` *(custom comparator)* | ✅         |
| Java       | `Arrays.sort(Object[])`                         | ✅         |
| Python     | `sort()`                                        | ✅         |
| JavaScript | `sort()` *(ES2019+)*                            | ✅         |
| C#         | `OrderBy()` (LINQ)                              | ✅         |

# Sort by Key / Field

Suppose

```text
(id, score)
```

Sort by score.

| Language   | Syntax                                                                |   |            |
| ---------- | --------------------------------------------------------------------- | - | ---------- |
| C++        | `sort(v.begin(),v.end(),[](auto&a,auto&b){return a.score<b.score;});` |   |            |
| Rust       | `v.sort_by_key(                                                       | x | x.score);` |
| Go         | `slices.SortFunc(v, func(a,b Item) int { return a.Score-b.Score })`   |   |            |
| Java       | `Arrays.sort(arr, Comparator.comparingInt(x->x.score));`              |   |            |
| Python     | `arr.sort(key=lambda x:x.score)`                                      |   |            |
| JavaScript | `arr.sort((a,b)=>a.score-b.score)`                                    |   |            |
| C#         | `Array.Sort(arr,(a,b)=>a.Score.CompareTo(b.Score));`                  |   |            |

# Complexity

| Operation   | Time       | Space                                       |
| ----------- | ---------- | ------------------------------------------- |
| Sort        | O(n log n) | O(log n) to O(n) (implementation dependent) |
| Stable Sort | O(n log n) | Usually O(n) extra                          |
| Sorted Copy | O(n log n) | O(n)                                        |

---

# CP Recommendations

| Situation                            | Recommendation                                                                                                   |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Normal numeric sorting               | Use the default sort for your language.                                                                          |
| Need descending order                | Use a comparator rather than sorting then reversing (except Java primitive arrays).                              |
| Need to preserve equal-element order | Use a stable sort.                                                                                               |
| Sorting objects                      | Sort by key/field instead of writing complex comparison logic when possible.                                     |
| Need original array unchanged        | Create a copy, then sort the copy.                                                                               |
| Very large inputs                    | Built-in sorting functions are highly optimized; avoid implementing your own quicksort or mergesort in contests. |

# Language Notes

| Language   | Notes                                                                                                                 |
| ---------- | --------------------------------------------------------------------------------------------------------------------- |
| C++        | `std::sort` (Introsort) is the fastest general-purpose choice for CP. Use `stable_sort` only when stability matters.  |
| Rust       | `sort()` is stable; use `sort_unstable()` for better performance when stability is unnecessary.                       |
| Go         | Prefer the `slices` package (`Go 1.21+`) over the older `sort` package for slices.                                    |
| Java       | Primitive arrays use Dual-Pivot Quicksort (not stable); object arrays use TimSort (stable).                           |
| Python     | Uses TimSort, which is stable and performs exceptionally well on partially sorted data.                               |
| JavaScript | Always provide a numeric comparator (`(a, b) => a - b`) when sorting numbers, as the default sort is lexicographical. |
| C#         | `Array.Sort` is efficient but not stable; use LINQ's `OrderBy` if stability is required (with some overhead).         |
