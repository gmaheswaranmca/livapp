That's a very good observation. This is actually one of the biggest differences between **C++** and the other CP languages.

The short answer is:

> **Competitive Programming algorithms are language-independent, but C++ is the only language that exposes many of them directly as STL algorithms.**

For example:

| Algorithm            | C++ | Python             | Java    | Go      | Rust           |
| -------------------- | --- | ------------------ | ------- | ------- | -------------- |
| `sort()`             | ✅   | ✅                  | ✅       | ✅       | ✅              |
| `reverse()`          | ✅   | ✅                  | ✅       | ✅       | ✅              |
| `rotate()`           | ✅   | Partial            | Partial | ❌       | ✅              |
| `shuffle()`          | ✅   | ✅                  | ✅       | ✅       | External crate |
| `next_permutation()` | ✅   | ❌                  | ❌       | ❌       | ❌              |
| `prev_permutation()` | ✅   | ❌                  | ❌       | ❌       | ❌              |
| `lower_bound()`      | ✅   | Partial (`bisect`) | Partial | Partial | Partial        |
| `nth_element()`      | ✅   | ❌                  | ❌       | ❌       | ❌              |
| `set_union()`        | ✅   | ❌                  | ❌       | ❌       | ❌              |
| `partition()`        | ✅   | ❌                  | Partial | ❌       | Partial        |

The C++ STL contains **70+ generic algorithms**, while most other languages expose only a handful.

---

# Why does C++ have so many?

The C++ STL is divided into two major parts:

* **Containers**

  * vector
  * deque
  * map
  * set
  * ...
* **Algorithms**

  * sort
  * reverse
  * rotate
  * next_permutation
  * lower_bound
  * nth_element
  * merge
  * unique
  * partition
  * ...

The philosophy is:

> "Don't rewrite algorithms. Just call them."

Other languages instead put these operations:

* inside the container (`list.sort()`)
* inside utility classes (`Arrays.sort()`)
* or expect you to write them.

# Why do CP people love C++?

One line.

In Python:

You implement the entire algorithm.
