# Phase 1 — Built-in Algorithms

## Topic 4 — Shuffle

Shuffling randomly permutes the elements of a container. It is useful for randomized algorithms, stress testing, randomized quicksort, and avoiding adversarial test cases.

> **CP Note:** True random shuffling is **rarely required** in competitive programming, but knowing the APIs is useful.

---

# Shuffle Entire Container

| Language   | Syntax                               | In-place | Time |
| ---------- | ------------------------------------ | -------- | ---- |
| C++        | `shuffle(v.begin(), v.end(), rng)`   | ✅        | O(n) |
| Rust       | `v.shuffle(&mut rng)` *(rand crate)* | ✅        | O(n) |
| Go         | `rand.Shuffle(len(arr), swapFunc)`   | ✅        | O(n) |
| Java       | `Collections.shuffle(list)`          | ✅        | O(n) |
| Python     | `random.shuffle(arr)`                | ✅        | O(n) |
| JavaScript | ❌ No built-in                        | —        | —    |
| C#         | ❌ No built-in                        | —        | —    |

---

# Required Random Generator

| Language   | Generator                                                  |
| ---------- | ---------------------------------------------------------- |
| C++        | `mt19937 rng(random_device{}());`                          |
| Rust       | `let mut rng = rand::thread_rng();`                        |
| Go         | `rand.New(rand.NewSource(seed))` or `rand.Shuffle()`       |
| Java       | `Collections.shuffle(list, new Random())` *(optional RNG)* |
| Python     | `random` module                                            |
| JavaScript | `Math.random()`                                            |
| C#         | `Random rnd = new Random();`                               |

---

# Fisher–Yates Shuffle (Universal Algorithm)

Works in **all languages**.

```text
for i = n-1 down to 1
    j = random integer in [0, i]
    swap(arr[i], arr[j])
```

Time: **O(n)**

Space: **O(1)**

# Shuffle a Copy

| Language   | Syntax                                                           |
| ---------- | ---------------------------------------------------------------- |
| C++        | `auto b=v; shuffle(b.begin(), b.end(), rng);`                    |
| Rust       | `let mut b=v.clone(); b.shuffle(&mut rng);`                      |
| Go         | `b:=slices.Clone(arr); rand.Shuffle(...)`                        |
| Java       | `List<Integer> b=new ArrayList<>(list); Collections.shuffle(b);` |
| Python     | `b=arr.copy(); random.shuffle(b)`                                |
| JavaScript | `const b=[...arr]; // Fisher–Yates`                              |
| C#         | `var b=arr.ToArray(); // Fisher–Yates`                           |

# Random Element

| Language   | Syntax                                              |
| ---------- | --------------------------------------------------- |
| C++        | `v[rng()%v.size()]` *(prefer uniform distribution)* |
| Rust       | `v.choose(&mut rng)` *(rand crate)*                 |
| Go         | `arr[rand.Intn(len(arr))]`                          |
| Java       | `arr[random.nextInt(arr.length)]`                   |
| Python     | `random.choice(arr)`                                |
| JavaScript | `arr[Math.floor(Math.random()*arr.length)]`         |
| C#         | `arr[random.Next(arr.Length)]`                      |

---

# Random Integer

| Language   | Syntax                                    |
| ---------- | ----------------------------------------- |
| C++        | `uniform_int_distribution<int>(l,r)(rng)` |
| Rust       | `rng.gen_range(l..=r)`                    |
| Go         | `rand.Intn(r-l+1)+l`                      |
| Java       | `random.nextInt(r-l+1)+l`                 |
| Python     | `random.randint(l,r)`                     |
| JavaScript | `Math.floor(Math.random()*(r-l+1))+l`     |
| C#         | `random.Next(l,r+1)`                      |

# CP Recommendations

| Situation               | Recommendation                                                                 |
| ----------------------- | ------------------------------------------------------------------------------ |
| Randomize test cases    | Use the language's built-in shuffle if available.                              |
| Randomized QuickSort    | Use Fisher–Yates or a random pivot.                                            |
| JavaScript/C#           | Implement Fisher–Yates; no standard shuffle API exists.                        |
| Reproducible debugging  | Use a fixed seed instead of a time-based seed.                                 |
| Competitive programming | Avoid unnecessary randomness unless the problem specifically benefits from it. |

---

# Common Mistakes

| Language   | Mistake                                                                           |
| ---------- | --------------------------------------------------------------------------------- |
| C++        | Using deprecated `random_shuffle()` instead of `shuffle()`.                       |
| Rust       | Forgetting to add the `rand` crate.                                               |
| Go         | Forgetting to seed the random generator when reproducibility isn't desired.       |
| Java       | Calling `Collections.shuffle()` on an array instead of a `List`.                  |
| Python     | Expecting `random.shuffle()` to return a new list—it returns `None`.              |
| JavaScript | Using `arr.sort(() => Math.random() - 0.5)`—this is biased and should be avoided. |
| C#         | Recreating `Random` repeatedly inside loops, leading to poor randomness.          |

---

# Language Notes

| Language   | Notes                                                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------------------ |
| C++        | `std::shuffle()` replaces the deprecated `random_shuffle()` and requires a random number engine such as `mt19937`. |
| Rust       | Shuffling is provided by the external `rand` crate rather than the standard library.                               |
| Go         | `rand.Shuffle()` uses a swap callback, making it work for any slice type.                                          |
| Java       | `Collections.shuffle()` only operates on `List` implementations.                                                   |
| Python     | `random.shuffle()` uses the Fisher–Yates algorithm internally and is the standard CP choice.                       |
| JavaScript | Always implement Fisher–Yates instead of using a random comparator with `sort()`.                                  |
| C#         | A simple Fisher–Yates implementation is the standard approach in CP.                                               |
