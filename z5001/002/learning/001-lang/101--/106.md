# Phase 1 — Built-in Algorithms

## Topic 6 — `prev_permutation`

`prev_permutation` transforms a sequence into the **previous lexicographically smaller permutation**.

If no smaller permutation exists (the sequence is in ascending order), it rearranges the sequence into the **largest (descending) permutation** and indicates that no previous permutation existed.

It is the exact opposite of `next_permutation`.

---

## Example

```text
Input:
[3,2,1]

Successive calls:

[3,2,1]
↓
[3,1,2]
↓
[2,3,1]
↓
[2,1,3]
↓
[1,3,2]
↓
[1,2,3]
↓
[3,2,1]   (wrapped around)
```

---

---

# C++ Usage

```cpp
sort(v.begin(), v.end(), greater<>());

do {
    // process permutation
} while (prev_permutation(v.begin(), v.end()));
```

This generates **all permutations in reverse lexicographical order**.

---

# Universal Algorithm (All Languages)

### Steps

```text
1. Find the rightmost index i where
      a[i] > a[i+1]

2. If none exists
      reverse entire array
      return false

3. Find the rightmost j where
      a[j] < a[i]

4. Swap a[i], a[j]

5. Reverse suffix
      (i+1 ... end)

6. return true
```

This is the mirror image of the `next_permutation` algorithm.

# Duplicate Elements

Example

```text
[2,1,1]
```

Generated permutations:

```text
211
121
112
```

Starting from the **largest sorted order** avoids duplicate permutations.

---

# Complexity

| Operation                  | Time      | Extra Space             |
| -------------------------- | --------- | ----------------------- |
| Single `prev_permutation`  | O(n)      | O(1)                    |
| Enumerate all permutations | O(n × n!) | O(1) (excluding output) |

---

# CP Recommendations

| Situation                               | Recommendation                      |
| --------------------------------------- | ----------------------------------- |
| Need descending lexicographic traversal | Use `prev_permutation()` in C++.    |
| Other languages                         | Reuse the universal implementation. |
| Duplicate values                        | Start from descending sorted order. |
| Small `n`                               | Enumeration is practical.           |
| Large `n`                               | Avoid factorial algorithms.         |

# Common Mistakes

| Language   | Mistake                                                                                         |
| ---------- | ----------------------------------------------------------------------------------------------- |
| C++        | Forgetting to sort in **descending** order before the first call.                               |
| Rust       | Using the `next_permutation` comparison (`<`) instead of (`>`).                                 |
| Go         | Finding the swap element from the left instead of the right.                                    |
| Java       | Forgetting to reverse the suffix after swapping.                                                |
| Python     | Assuming `itertools.permutations()` can generate previous permutations incrementally—it cannot. |
| JavaScript | Mishandling the "already smallest permutation" case.                                            |
| C#         | Returning `true` after wrapping to the largest permutation.                                     |

---

# Language Notes

| Language   | Notes                                                                                                                         |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| C++        | `prev_permutation()` complements `next_permutation()` and resets to descending order after reaching the smallest permutation. |
| Rust       | No standard-library equivalent; implement the mirrored algorithm.                                                             |
| Go         | Commonly implemented manually in CP libraries.                                                                                |
| Java       | No built-in API; the implementation closely mirrors `nextPermutation` with reversed comparisons.                              |
| Python     | Usually implemented manually when needed; `itertools` does not provide incremental previous permutations.                     |
| JavaScript | A reusable implementation is useful for permutation-based problems.                                                           |
| C#         | No built-in support; use the universal algorithm.                                                                             |

# `next_permutation` vs `prev_permutation`

| Feature            | `next_permutation`       | `prev_permutation`        |
| ------------------ | ------------------------ | ------------------------- |
| Direction          | Lexicographically larger | Lexicographically smaller |
| Start from         | Ascending order          | Descending order          |
| End at             | Descending order         | Ascending order           |
| Wraps to           | Smallest permutation     | Largest permutation       |
| Built into C++ STL | ✅                        | ✅                         |
| Time               | O(n)                     | O(n)                      |
| Extra Space        | O(1)                     | O(1)                      |
