# Phase 1 — Built-in Algorithms

## Topic 2 — Reverse

Reversing is commonly used in Competitive Programming for two-pointer techniques, string manipulation, palindrome problems, permutation generation, and array transformations.

---

# Reverse Entire Array / List

| Language   | Syntax                                    | In-place | Time |
| ---------- | ----------------------------------------- | -------- | ---- |
| C++        | `reverse(v.begin(), v.end())`             | ✅        | O(n) |
| Rust       | `v.reverse()`                             | ✅        | O(n) |
| Go         | `slices.Reverse(arr)` *(Go 1.21+)*        | ✅        | O(n) |
| Java       | `Collections.reverse(list)` *(List only)* | ✅        | O(n) |
| Python     | `arr.reverse()`                           | ✅        | O(n) |
| JavaScript | `arr.reverse()`                           | ✅        | O(n) |
| C#         | `Array.Reverse(arr)`                      | ✅        | O(n) |

> **Note:** Java has no built-in `Arrays.reverse()` for primitive arrays.

---

# Reverse a String

| Language   | Syntax                                         |
| ---------- | ---------------------------------------------- |
| C++        | `reverse(s.begin(), s.end())`                  |
| Rust       | `let rev: String = s.chars().rev().collect();` |
| Go         | `r:=[]rune(s); slices.Reverse(r); s=string(r)` |
| Java       | `new StringBuilder(s).reverse().toString()`    |
| Python     | `s[::-1]`                                      |
| JavaScript | `s.split('').reverse().join('')`               |
| C#         | `new string(s.Reverse().ToArray())`            |

---

# Reverse a Subrange

Reverse elements in the interval **[l, r]** (inclusive).

| Language   | Syntax                                              |
| ---------- | --------------------------------------------------- |
| C++        | `reverse(v.begin()+l, v.begin()+r+1)`               |
| Rust       | `v[l..=r].reverse()`                                |
| Go         | `slices.Reverse(arr[l:r+1])`                        |
| Java       | Manual two-pointer swap                             |
| Python     | `arr[l:r+1] = reversed(arr[l:r+1])`                 |
| JavaScript | `arr.splice(l,r-l+1,...arr.slice(l,r+1).reverse())` |
| C#         | `Array.Reverse(arr,l,r-l+1)`                        |

---

# Reverse Copy (Keep Original)

| Language   | Syntax                                     |
| ---------- | ------------------------------------------ |
| C++        | `auto b=v; reverse(b.begin(),b.end());`    |
| Rust       | `let mut b=v.clone(); b.reverse();`        |
| Go         | `b:=slices.Clone(arr); slices.Reverse(b)`  |
| Java       | `int[] b=arr.clone(); // reverse manually` |
| Python     | `b=arr[::-1]`                              |
| JavaScript | `const b=[...arr].reverse()`               |
| C#         | `var b=arr.ToArray(); Array.Reverse(b);`   |

---

# Reverse Iteration

| Language   | Syntax                                        |
| ---------- | --------------------------------------------- |
| C++        | `for(auto it=v.rbegin(); it!=v.rend(); ++it)` |
| Rust       | `for x in v.iter().rev()`                     |
| Go         | `for i:=len(arr)-1;i>=0;i--`                  |
| Java       | `for(int i=n-1;i>=0;i--)`                     |
| Python     | `for x in reversed(arr)`                      |
| JavaScript | `for(let i=arr.length-1;i>=0;i--)`            |
| C#         | `for(int i=arr.Length-1;i>=0;i--)`            |

# Reverse Digits of an Integer

Example: `12345 → 54321`

| Language   | Common Approach                                                |
| ---------- | -------------------------------------------------------------- |
| C++        | While loop using `%10` and `/10`                               |
| Rust       | Same arithmetic approach                                       |
| Go         | Same arithmetic approach                                       |
| Java       | Same arithmetic approach                                       |
| Python     | Arithmetic or `int(str(n)[::-1])`                              |
| JavaScript | Arithmetic or `Number(String(n).split('').reverse().join(''))` |
| C#         | Arithmetic or string approach                                  |

> In CP, prefer the **arithmetic approach** to avoid string conversion overhead and to handle overflow explicitly.

# Reverse Comparator (Descending Traversal)

Sometimes you only need to iterate in reverse rather than reverse the container.

| Language   | Syntax                                                 |
| ---------- | ------------------------------------------------------ |
| C++        | `rbegin(), rend()`                                     |
| Rust       | `.iter().rev()`                                        |
| Go         | Reverse index loop                                     |
| Java       | Reverse index loop                                     |
| Python     | `reversed(arr)`                                        |
| JavaScript | Reverse index loop                                     |
| C#         | `Enumerable.Reverse()` *(creates reverse enumeration)* |

# Complexity

| Operation                | Time | Extra Space |
| ------------------------ | ---- | ----------- |
| Reverse entire container | O(n) | O(1)        |
| Reverse subrange         | O(k) | O(1)        |
| Reverse copy             | O(n) | O(n)        |
| Reverse iteration        | O(n) | O(1)        |

---

# CP Recommendations

| Situation                     | Recommendation                                                                          |
| ----------------------------- | --------------------------------------------------------------------------------------- |
| Reverse an array/vector       | Use the built-in reverse function.                                                      |
| Reverse a string              | Prefer language-specific optimized methods (`StringBuilder`, slicing, etc.).            |
| Reverse only part of an array | Use built-in subrange reversal when available; otherwise, implement a two-pointer swap. |
| Need original preserved       | Create a copy, then reverse the copy.                                                   |
| Only need reverse traversal   | Iterate in reverse instead of modifying the container.                                  |

# Common Mistakes

| Language   | Mistake                                                                               |
| ---------- | ------------------------------------------------------------------------------------- |
| C++        | Forgetting that `reverse(last)` is **exclusive** (`begin()+r+1`).                     |
| Rust       | Attempting to reverse a `String` directly instead of iterating over `chars()`.        |
| Go         | Reversing UTF-8 strings byte-wise instead of converting to `[]rune`.                  |
| Java       | Expecting `Arrays.reverse()` to exist for arrays—it doesn't.                          |
| Python     | Using `reversed(arr)` expecting a list; it returns an iterator.                       |
| JavaScript | Using `reverse()` on a string (strings are immutable).                                |
| C#         | Confusing `Array.Reverse()` (in-place) with LINQ `Reverse()` (returns an enumerable). |

---

# Language Notes

| Language   | Notes                                                                                  |
| ---------- | -------------------------------------------------------------------------------------- |
| C++        | `std::reverse` works with any bidirectional iterator.                                  |
| Rust       | `Vec::reverse()` is in-place; strings require `chars()` because of UTF-8 encoding.     |
| Go         | `slices.Reverse()` is the preferred API for slices in Go 1.21+.                        |
| Java       | `Collections.reverse()` works only for `List`, not primitive arrays.                   |
| Python     | Slicing (`[::-1]`) creates a copy, while `reverse()` modifies the list in place.       |
| JavaScript | `reverse()` mutates the original array. Clone first if needed.                         |
| C#         | `Array.Reverse()` is efficient for arrays; `List<T>.Reverse()` is available for lists. |
