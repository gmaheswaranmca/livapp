# Phase 1 — Built-in Algorithms

## Topic 3 — Rotate

Rotation shifts elements while preserving their relative order. It is commonly used in array manipulation, cyclic shifts, string rotation, queue simulation, and algorithmic tricks.

---

# Rotate Left by `k`

Example:

```text
[1,2,3,4,5]
k = 2

Result:
[3,4,5,1,2]
```

| Language   | Syntax                                                                       | In-place | Time |
| ---------- | ---------------------------------------------------------------------------- | -------- | ---- |
| C++        | `rotate(v.begin(), v.begin()+k, v.end())`                                    | ✅        | O(n) |
| Rust       | `v.rotate_left(k)`                                                           | ✅        | O(n) |
| Go         | `slices.Rotate` ❌ *(not available)* → manual (`append` or reverse algorithm) | Depends  | O(n) |
| Java       | `Collections.rotate(list,-k)` *(List only)*                                  | ✅        | O(n) |
| Python     | `collections.deque.rotate(-k)` *(deque)*                                     | ✅        | O(n) |
| JavaScript | `arr.push(...arr.splice(0,k))`                                               | ✅        | O(n) |
| C#         | Manual (reverse algorithm or copy)                                           | Depends  | O(n) |

---

# Rotate Right by `k`

Example

```text
[1,2,3,4,5]
k = 2

Result

[4,5,1,2,3]
```

| Language   | Syntax                                  |
| ---------- | --------------------------------------- |
| C++        | `rotate(v.begin(), v.end()-k, v.end())` |
| Rust       | `v.rotate_right(k)`                     |
| Go         | Manual                                  |
| Java       | `Collections.rotate(list,k)`            |
| Python     | `deque.rotate(k)`                       |
| JavaScript | `arr.unshift(...arr.splice(-k))`        |
| C#         | Manual                                  |

# Rotate Using Reverse Algorithm

Useful when no built-in rotate exists.

Left rotation by `k`

```text
reverse(0,k-1)
reverse(k,n-1)
reverse(0,n-1)
```

Right rotation by `k`

```text
reverse(0,n-k-1)
reverse(n-k,n-1)
reverse(0,n-1)
```

Applicable to:

* C++
* Rust
* Go
* Java
* Python
* JavaScript
* C#

---

# Circular Rotation (Without Modifying Array)

Instead of rotating:

```text
index = (i + k) % n
```

or

```text
index = (i - k + n) % n
```

Works in every language.

# Rotate String

Example

```text
abcde

↓

cdeab
```

| Language   | Common Method                            |
| ---------- | ---------------------------------------- |
| C++        | `s.substr(k)+s.substr(0,k)`              |
| Rust       | Use `chars()` or byte slice (ASCII only) |
| Go         | Convert to `[]rune` then slice           |
| Java       | `s.substring(k)+s.substring(0,k)`        |
| Python     | `s[k:]+s[:k]`                            |
| JavaScript | `s.slice(k)+s.slice(0,k)`                |
| C#         | `s[k..]+s[..k]`                          |

---

# Rotate Copy (Keep Original)

| Language   | Syntax                                                             |
| ---------- | ------------------------------------------------------------------ |
| C++        | `auto b=v; rotate(b.begin(),b.begin()+k,b.end());`                 |
| Rust       | `let mut b=v.clone(); b.rotate_left(k);`                           |
| Go         | `b:=append(arr[k:],arr[:k]...)`                                    |
| Java       | `List<Integer> b=new ArrayList<>(list); Collections.rotate(b,-k);` |
| Python     | `b=arr[k:]+arr[:k]`                                                |
| JavaScript | `const b=[...arr.slice(k),...arr.slice(0,k)]`                      |
| C#         | `var b=arr.Skip(k).Concat(arr.Take(k)).ToArray();`                 |

# Complexity

| Operation           | Time | Extra Space |
| ------------------- | ---- | ----------- |
| Built-in rotate     | O(n) | O(1)        |
| Reverse algorithm   | O(n) | O(1)        |
| Slice/copy rotation | O(n) | O(n)        |
| Index arithmetic    | O(1) | O(1)        |

---

# CP Recommendations

| Situation  | Recommendation                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------- |
| C++        | Prefer `std::rotate()`—it's concise and efficient.                                                 |
| Rust       | Use `rotate_left()` / `rotate_right()`.                                                            |
| Go         | Use the reverse algorithm for in-place rotation; use slicing for simple copy-based rotation.       |
| Java       | Use `Collections.rotate()` only for `List`; for arrays, implement the reverse algorithm.           |
| Python     | For lists, slicing is usually the simplest. For repeated rotations, `deque.rotate()` is excellent. |
| JavaScript | `splice()` works but mutates the array. Clone first if the original must be preserved.             |
| C#         | Implement the reverse algorithm for in-place rotation; LINQ-based solutions allocate memory.       |

---

# Common Mistakes

| Language   | Mistake                                                                                               |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| C++        | Forgetting `std::rotate(first, middle, last)` rotates **so that `middle` becomes the first element**. |
| Rust       | Not reducing `k` using `k %= len` when implementing manually.                                         |
| Go         | Using `append()` without realizing it creates a new slice.                                            |
| Java       | Expecting `Collections.rotate()` to work on primitive arrays.                                         |
| Python     | Using `deque.rotate()` on a list—it only exists for `deque`.                                          |
| JavaScript | `splice()` modifies the original array.                                                               |
| C#         | Using LINQ for large arrays in tight loops, causing unnecessary allocations.                          |

---

# Language Notes

| Language   | Notes                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------- |
| C++        | `std::rotate()` is one of the most powerful STL algorithms and works with forward iterators and above.              |
| Rust       | `rotate_left()` and `rotate_right()` are built into slices and are very efficient.                                  |
| Go         | There is currently no built-in slice rotation in the standard library.                                              |
| Java       | `Collections.rotate()` is convenient for lists but not suitable for primitive arrays.                               |
| Python     | List slicing is generally the most idiomatic approach in CP; `deque.rotate()` is ideal for many repeated rotations. |
| JavaScript | Normalize `k` with `k %= arr.length` before rotating.                                                               |
| C#         | The reverse algorithm gives an O(n), O(1)-space solution similar to C++.                                            |
