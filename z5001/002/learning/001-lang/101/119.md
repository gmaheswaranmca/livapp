# 1. Swap

## Purpose

Exchange the values of two variables or elements.

Example

```text
a = 5
b = 8

↓

a = 8
b = 5
```

| Language       | Idiomatic CP Syntax             | Built-in | Time | Space |
| -------------- | ------------------------------- | -------- | ---- | ----- |
| **C++**        | `swap(a,b)`                     | ✅        | O(1) | O(1)  |
| **Rust**       | `std::mem::swap(&mut a,&mut b)` | ✅        | O(1) | O(1)  |
| **Go**         | `a, b = b, a`                   | ✅        | O(1) | O(1)  |
| **Java**       | Temporary variable              | ❌        | O(1) | O(1)  |
| **Python**     | `a, b = b, a`                   | ✅        | O(1) | O(1)  |
| **JavaScript** | `[a,b]=[b,a]`                   | ✅        | O(1) | O(1)  |
| **C#**         | `(a,b)=(b,a)`                   | ✅        | O(1) | O(1)  |

### CP Recommendation

Use the language's built-in swap mechanism. Avoid XOR swap—it is slower, less readable, and error-prone.

# 2. Fill

## Purpose

Assign the same value to every element.

Example

```text
Array

1 2 3 4

Fill with 0

↓

0 0 0 0
```

| Language       | Idiomatic CP Syntax    |
| -------------- | ---------------------- |
| **C++**        | `fill(begin,end,val)`  |
| **Rust**       | `slice.fill(val)`      |
| **Go**         | Manual loop            |
| **Java**       | `Arrays.fill(arr,val)` |
| **Python**     | `arr=[val]*n` or loop  |
| **JavaScript** | `arr.fill(val)`        |
| **C#**         | `Array.Fill(arr,val)`  |

### Complexity

* Time: **O(n)**
* Space: **O(1)**

### CP Recommendation

Use built-in fill APIs instead of writing repetitive loops where available.

# 3. Copy

## Purpose

Copy data from one collection to another.

Example

```text
A

1 2 3

↓

B

1 2 3
```

| Language       | Idiomatic CP Syntax   |
| -------------- | --------------------- |
| **C++**        | `copy(begin,end,out)` |
| **Rust**       | `clone_from_slice()`  |
| **Go**         | `copy(dst,src)`       |
| **Java**       | `System.arraycopy()`  |
| **Python**     | `dst = src[:]`        |
| **JavaScript** | `dst = [...src]`      |
| **C#**         | `Array.Copy()`        |

### Complexity

* Time: **O(n)**
* Space: **O(n)**

### CP Recommendation

Prefer library copy routines—they are optimized and less error-prone.

# 4. Clone

## Purpose

Create an independent copy of a collection.

Unlike assignment, modifying the clone does **not** affect the original.

| Language       | Idiomatic CP Syntax      |
| -------------- | ------------------------ |
| **C++**        | `vector<int> b = a;`     |
| **Rust**       | `let b = a.clone();`     |
| **Go**         | `append([]T(nil), a...)` |
| **Java**       | `arr.clone()`            |
| **Python**     | `arr.copy()`             |
| **JavaScript** | `[...arr]`               |
| **C#**         | `arr.Clone()`            |

### CP Recommendation

Know whether assignment creates an alias/reference or a copy in your language.

# 5. Resize

## Purpose

Change the size of a dynamic collection.

Example

```text
Size

5

↓

Resize

8
```

New elements receive default values.

| Language       | Idiomatic CP Syntax             |
| -------------- | ------------------------------- |
| **C++**        | `v.resize(n)`                   |
| **Rust**       | `v.resize(n,val)`               |
| **Go**         | `s = s[:n]` / `append()`        |
| **Java**       | `ArrayList` grows automatically |
| **Python**     | `append()/extend()`             |
| **JavaScript** | `arr.length=n`                  |
| **C#**         | `List<T>` grows automatically   |

### Complexity

* Increase: Usually **O(n)** (may reallocate)
* Decrease: Usually **O(1)** logical truncation

### CP Recommendation

Preallocate when the final size is known to reduce reallocations.

# 6. Slice

## Purpose

Extract a contiguous portion of a collection.

Example

```text
Array

1 2 3 4 5

Slice

[1:4]

↓

2 3 4
```

| Language       | Idiomatic CP Syntax        |
| -------------- | -------------------------- |
| **C++**        | Iterator range constructor |
| **Rust**       | `&v[l..r]`                 |
| **Go**         | `s[l:r]`                   |
| **Java**       | `Arrays.copyOfRange()`     |
| **Python**     | `arr[l:r]`                 |
| **JavaScript** | `slice(l,r)`               |
| **C#**         | `arr[l..r]` (ranges)       |

### Complexity

| Language   | View          | Copy     |
| ---------- | ------------- | -------- |
| Rust       | ✅             | Optional |
| Go         | ✅             | Optional |
| Python     | ❌             | ✅        |
| JavaScript | ❌             | ✅        |
| Java       | ❌             | ✅        |
| C++        | Iterator view | Optional |
| C#         | Usually copy  |          |

### CP Recommendation

Be aware of whether slicing creates a copy or a view.

# 7. Enumerate

## Purpose

Iterate with both index and value.

Example

```text
Index Value

0     10

1     20

2     30
```

| Language       | Idiomatic CP Syntax     |
| -------------- | ----------------------- |
| **C++**        | Index loop / ranges     |
| **Rust**       | `iter().enumerate()`    |
| **Go**         | `for i,v := range s`    |
| **Java**       | Index loop              |
| **Python**     | `enumerate(arr)`        |
| **JavaScript** | `arr.entries()`         |
| **C#**         | `for` loop / `Select()` |

### Complexity

* Time: **O(n)**
* Space: **O(1)**

### CP Recommendation

Prefer native enumeration constructs over manually tracking indices when available.

# 8. Zip

## Purpose

Iterate over multiple collections simultaneously.

Example

```text
A

1 2 3

B

4 5 6

↓

(1,4)

(2,5)

(3,6)
```

| Language       | Idiomatic CP Syntax |
| -------------- | ------------------- |
| **C++**        | Index loop          |
| **Rust**       | `iter().zip()`      |
| **Go**         | Index loop          |
| **Java**       | Index loop          |
| **Python**     | `zip(a,b)`          |
| **JavaScript** | Index loop          |
| **C#**         | `Zip()`             |

### Complexity

* Time: **O(min(n,m))**
* Space: **O(1)**

### CP Recommendation

Python and Rust provide elegant built-in support; index-based loops are standard elsewhere.

# CP Recommendations

* ✅ Use built-in **swap**, **fill**, and **copy** functions—they are optimized and improve readability.
* ✅ Understand whether **slicing returns a view or a copy**, especially in Go and Rust versus Python and JavaScript.
* ✅ Preallocate and resize collections when the final size is known to reduce reallocations.
* ✅ Prefer native **enumerate** and **zip** constructs where available instead of manually tracking indices.
* ✅ Use **any/all** for concise condition checks, but in tight performance-critical loops, explicit loops may be slightly faster in some languages.
* ✅ Know the difference between **copy**, **clone**, and **assignment** in your language to avoid unintended aliasing.

---

# Common Mistakes

| Mistake                                                    | Why It Happens             | Better Approach                           |
| ---------------------------------------------------------- | -------------------------- | ----------------------------------------- |
| Assuming assignment creates a deep copy                    | Language semantics differ  | Use explicit clone/copy APIs              |
| Forgetting that Python/JavaScript slicing copies data      | Hidden memory allocation   | Avoid unnecessary slices in large inputs  |
| Using XOR swap                                             | Outdated optimization myth | Use built-in swap                         |
| Modifying a slice that shares underlying storage (Go/Rust) | Views share data           | Copy when independent storage is required |
| Repeatedly resizing without preallocation                  | Frequent reallocations     | Reserve/preallocate when possible         |

## Choosing the Right Utility

| Scenario                              | Best Choice  |
| ------------------------------------- | ------------ |
| Exchange two values                   | Swap         |
| Initialize an array                   | Fill         |
| Duplicate data                        | Copy / Clone |
| Grow or shrink a dynamic array        | Resize       |
| Extract a contiguous portion          | Slice        |
| Iterate with index                    | Enumerate    |
| Iterate over two collections together | Zip          |
| Check if any element matches          | Any          |
| Check if all elements match           | All          |
