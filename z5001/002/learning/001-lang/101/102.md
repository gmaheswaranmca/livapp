# Phase 1 — Common Competitive Programming Operations

# Topic 2 — Reverse Operations

Reversing is a fundamental operation in Competitive Programming. It is commonly used in:

* Two Pointers
* String manipulation
* Array rotation
* Next/Previous Permutation
* Palindrome problems
* Stack simulation
* Reverse traversal

Most languages provide efficient built-in support for reversing entire collections, while reversing subranges or creating reversed copies varies by language.

---

# 1. Reverse Array

## Purpose

Reverse the entire array or dynamic array.

Example

```text
Before
1 2 3 4 5

After
5 4 3 2 1
```

| Language       | Idiomatic CP Syntax                | Built-in | In-place | Time | Space |
| -------------- | ---------------------------------- | -------- | -------- | ---- | ----- |
| **C++**        | `reverse(v.begin(), v.end())`      | STL      | ✅        | O(n) | O(1)  |
| **Rust**       | `v.reverse()`                      | std      | ✅        | O(n) | O(1)  |
| **Go**         | `slices.Reverse(arr)` *(Go 1.21+)* | std      | ✅        | O(n) | O(1)  |
| **Java**       | Manual two pointers                | Manual   | ✅        | O(n) | O(1)  |
| **Python**     | `arr.reverse()`                    | built-in | ✅        | O(n) | O(1)  |
| **JavaScript** | `arr.reverse()`                    | built-in | ✅        | O(n) | O(1)  |
| **C#**         | `Array.Reverse(arr)`               | .NET     | ✅        | O(n) | O(1)  |

### CP Recommendation

* Use the built-in API whenever available.
* Java requires a manual implementation for primitive arrays.

### Common Mistakes

* Assuming `reverse()` returns a new array (it modifies the original in most languages).
* Forgetting that reversing changes indices.

# 2. Reverse String

## Purpose

Reverse all characters in a string.

Example

```text
abcde

↓

edcba
```

| Language       | Idiomatic CP Syntax                   | Mutable? | Notes             |
| -------------- | ------------------------------------- | -------- | ----------------- |
| **C++**        | `reverse(s.begin(), s.end())`         | ✅        | Efficient         |
| **Rust**       | `s.chars().rev().collect::<String>()` | ❌        | Strings are UTF-8 |
| **Go**         | Convert to `[]rune`, reverse          | ❌        | Unicode-safe      |
| **Java**       | `new StringBuilder(s).reverse()`      | ❌        | Standard approach |
| **Python**     | `s[::-1]`                             | ❌        | Fast and concise  |
| **JavaScript** | `s.split("").reverse().join("")`      | ❌        | Common idiom      |
| **C#**         | `new string(s.Reverse().ToArray())`   | ❌        | Uses LINQ         |

### CP Recommendation

* Python slicing is the simplest.
* In Go and Rust, be careful with Unicode strings.

### Common Mistakes

* Reversing bytes instead of Unicode characters.
* Expecting immutable strings to change in place.

# 3. Reverse Subrange

## Purpose

Reverse only part of a collection.

Example

```text
1 2 3 4 5 6

Reverse index 1..4

↓

1 5 4 3 2 6
```

| Language       | Idiomatic Approach                  | Built-in |
| -------------- | ----------------------------------- | -------- |
| **C++**        | `reverse(begin+l, begin+r)`         | ✅        |
| **Rust**       | `v[l..r].reverse()`                 | ✅        |
| **Go**         | Manual swap loop                    | ❌        |
| **Java**       | Manual swap loop                    | ❌        |
| **Python**     | `arr[l:r] = reversed(arr[l:r])`     | ✅        |
| **JavaScript** | Slice + reverse + splice            | Partial  |
| **C#**         | `Array.Reverse(arr, index, length)` | ✅        |

### Time Complexity

* O(length of subrange)

### Space Complexity

* Usually O(1)
* Python/JavaScript slicing creates temporary storage.

### CP Recommendation

Useful for:

* Array rotation
* Next permutation
* String transformations

# 4. Reverse Iterator / Reverse Traversal

## Purpose

Iterate from the last element to the first without modifying the collection.

Example

```text
5
4
3
2
1
```

| Language       | Idiomatic CP Syntax                           |
| -------------- | --------------------------------------------- |
| **C++**        | `for(auto it=v.rbegin(); it!=v.rend(); ++it)` |
| **Rust**       | `for x in v.iter().rev()`                     |
| **Go**         | `for i:=len(arr)-1; i>=0; i--`                |
| **Java**       | `for(int i=n-1;i>=0;i--)`                     |
| **Python**     | `for x in reversed(arr)`                      |
| **JavaScript** | Reverse index loop                            |
| **C#**         | Reverse `for` loop or `Enumerable.Reverse()`  |

### CP Recommendation

Prefer reverse iteration over reversing the container if you only need to read elements.

### Common Mistakes

* Reversing the data when only traversal is needed.
* Off-by-one errors in reverse index loops.

# 5. Reverse Copy

## Purpose

Create a reversed copy while leaving the original unchanged.

Example

```text
Original

1 2 3

Copy

3 2 1
```

| Language       | Idiomatic CP Syntax                                    | Original Modified? |
| -------------- | ------------------------------------------------------ | ------------------ |
| **C++**        | `vector<int> b(v.rbegin(), v.rend())`                  | ❌                  |
| **Rust**       | `let b = v.iter().rev().cloned().collect::<Vec<_>>();` | ❌                  |
| **Go**         | Copy then reverse                                      | ❌                  |
| **Java**       | Copy then reverse manually                             | ❌                  |
| **Python**     | `b = arr[::-1]`                                        | ❌                  |
| **JavaScript** | `b = arr.toReversed()` *(modern JS)*                   | ❌                  |
| **C#**         | `var b = arr.Reverse().ToArray();`                     | ❌                  |

### Time Complexity

* O(n)

### Space Complexity

* O(n)

### CP Recommendation

Use reverse copies when:

* Original order is needed later.
* Multiple algorithms require different traversal directions.

# Complexity Summary

| Operation         | Time | Space                                |
| ----------------- | ---- | ------------------------------------ |
| Reverse Array     | O(n) | O(1)                                 |
| Reverse String    | O(n) | O(n) for immutable strings           |
| Reverse Subrange  | O(k) | O(1) (except slice-based approaches) |
| Reverse Traversal | O(n) | O(1)                                 |
| Reverse Copy      | O(n) | O(n)                                 |

---

# CP Recommendations

* ✅ Prefer built-in reverse functions for full-array reversal.
* ✅ Use reverse traversal (`reversed()`, `.rev()`, reverse iterators) when you only need to read elements.
* ✅ For immutable strings, create a new reversed string rather than attempting in-place modification.
* ✅ Use reverse subranges for algorithms like array rotation, next permutation, and interval manipulation.
* ✅ Be mindful of Unicode handling in Go and Rust when reversing strings.
* ✅ If the original order is needed later, create a reversed copy instead of modifying the original.

---

# Common Mistakes

| Mistake                                          | Why It Happens                       | Better Approach                   |
| ------------------------------------------------ | ------------------------------------ | --------------------------------- |
| Reversing when only reverse iteration is needed  | Unnecessary work                     | Use reverse iterators/index loops |
| Expecting `reverse()` to return a new collection | Many APIs modify in place            | Check whether the API is mutating |
| Reversing UTF-8 bytes                            | Breaks multibyte characters          | Reverse Unicode code points/runes |
| Off-by-one errors in subrange reversal           | Confusing inclusive/exclusive bounds | Verify index conventions          |
| Losing original order accidentally               | In-place reversal                    | Create a reversed copy if needed  |
