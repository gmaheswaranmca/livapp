# Phase 1 — Common Competitive Programming Operations

# Topic 6 — Counting

Counting is one of the most common operations in Competitive Programming. It is used to:

* Count occurrences of a value
* Build frequency tables
* Character counting
* Prefix frequency
* Histogram problems
* Majority element
* Sliding Window
* Hashing
* Greedy
* Counting Sort

---

# 1. Count

## Purpose

Count how many times a value appears in a collection.

Example

```text
Array

1 3 2 3 5 3

Count(3)

↓

3
```

| Language       | Idiomatic CP Syntax           | Built-in | Time           | Space |      |      |
| -------------- | ----------------------------- | -------- | -------------- | ----- | ---- | ---- |
| **C++**        | `count(begin, end, x)`        | STL      | O(n)           | O(1)  |      |      |
| **Rust**       | `iter().filter(               | &&v      | v==x).count()` | std   | O(n) | O(1) |
| **Go**         | Manual loop                   | ❌        | O(n)           | O(1)  |      |      |
| **Java**       | Manual loop                   | ❌        | O(n)           | O(1)  |      |      |
| **Python**     | `arr.count(x)`                | built-in | O(n)           | O(1)  |      |      |
| **JavaScript** | `arr.filter(v=>v===x).length` | Partial  | O(n)           | O(n)* |      |      |
| **C#**         | `arr.Count(v=>v==x)` *(LINQ)* | ✅        | O(n)           | O(1)  |      |      |

* `filter()` creates a temporary array. A manual loop is more memory-efficient.

### CP Recommendation

* Prefer built-in counting functions where available.
* For repeated counting queries, build a frequency map instead of scanning every time.

# 2. Frequency Map

## Purpose

Count the occurrences of every distinct value.

Example

```text
Array

4 2 4 1 2 4

↓

{
4 : 3
2 : 2
1 : 1
}
```

| Language       | Typical Container               |
| -------------- | ------------------------------- |
| **C++**        | `unordered_map<int,int>`        |
| **Rust**       | `HashMap<i32, usize>`           |
| **Go**         | `map[int]int`                   |
| **Java**       | `HashMap<Integer,Integer>`      |
| **Python**     | `collections.Counter` or `dict` |
| **JavaScript** | `Map`                           |
| **C#**         | `Dictionary<int,int>`           |

### Complexity

| Operation           | Time         |
| ------------------- | ------------ |
| Build Frequency Map | O(n)         |
| Query Frequency     | O(1) average |

### CP Recommendation

Frequency maps are among the most frequently used data structures in contests.

Typical problems:

* Two Sum
* Majority Element
* Top K Frequent
* Group Anagrams
* Sliding Window

# 3. Character Frequency

## Purpose

Count occurrences of characters in a string.

Example

```text
banana

↓

a → 3
b → 1
n → 2
```

### Method 1 — Fixed-size Frequency Array

Best when the character set is small (e.g., lowercase English letters).

| Language       | Recommended         |
| -------------- | ------------------- |
| **C++**        | `vector<int>(26)`   |
| **Rust**       | `[0;26]`            |
| **Go**         | `make([]int,26)`    |
| **Java**       | `int[26]`           |
| **Python**     | `[0]*26`            |
| **JavaScript** | `Array(26).fill(0)` |
| **C#**         | `new int[26]`       |

### Complexity

* Time: **O(n)**
* Space: **O(26)** → effectively **O(1)**

### Method 2 — Hash Map

Useful for:

* Unicode
* Large alphabets
* Arbitrary symbols

### CP Recommendation

Prefer arrays over hash maps whenever the alphabet size is fixed—they are faster and more cache-friendly.

# 4. Count by Predicate

## Purpose

Count elements satisfying a condition.

Example

```text
Array

3 8 2 11 14

Count Even

↓

3
```

Possible predicates:

* Even numbers
* Prime numbers
* Negative numbers
* Values greater than `k`
* Valid intervals

| Language       | Idiomatic CP Syntax             |
| -------------- | ------------------------------- |
| **C++**        | `count_if(begin,end,predicate)` |
| **Rust**       | `iter().filter(...).count()`    |
| **Go**         | Manual loop                     |
| **Java**       | Manual loop                     |
| **Python**     | `sum(1 for x in arr if cond)`   |
| **JavaScript** | `arr.filter(cond).length`       |
| **C#**         | `Count(predicate)` *(LINQ)*     |

### Complexity

* Time: **O(n)**
* Space: **O(1)** (manual loop)

### CP Recommendation

Manual loops are often the fastest approach in Go, Java, and JavaScript.

# Frequency Array vs Frequency Map

| Feature           | Frequency Array         | Frequency Map            |
| ----------------- | ----------------------- | ------------------------ |
| Lookup            | O(1)                    | O(1) average             |
| Memory            | O(K)                    | O(Distinct Values)       |
| Fixed Alphabet    | ✅ Excellent             | Works                    |
| Unicode           | ❌                       | ✅                        |
| Speed             | Faster                  | Slightly slower          |
| CP Recommendation | Preferred when possible | Use for arbitrary values |

# Complexity Summary

| Operation                      | Time | Space                  |
| ------------------------------ | ---- | ---------------------- |
| Count Value                    | O(n) | O(1)                   |
| Frequency Map Build            | O(n) | O(Distinct Values)     |
| Character Frequency (Array)    | O(n) | O(Alphabet Size)       |
| Character Frequency (Hash Map) | O(n) | O(Distinct Characters) |
| Count by Predicate             | O(n) | O(1)                   |

---

# CP Recommendations

* ✅ For a single counting query, use the built-in count operation or a simple loop.
* ✅ For multiple counting or lookup queries, build a **frequency map** once in **O(n)**.
* ✅ Use a **fixed-size frequency array** (`int[26]`, `[0]*26`, etc.) for lowercase English letters or other small fixed alphabets.
* ✅ Prefer arrays over hash maps whenever the value range is small and known.
* ✅ Use `collections.Counter` in Python for concise and reliable frequency counting.
* ✅ Avoid using `filter(...).length` in JavaScript for performance-critical code; a manual loop avoids creating a temporary array.

---

# Common Mistakes

| Mistake                                         | Why It Happens                                   | Better Approach                 |
| ----------------------------------------------- | ------------------------------------------------ | ------------------------------- |
| Recounting the same value repeatedly            | Multiple O(n) scans                              | Build a frequency map once      |
| Using a hash map for a fixed 26-letter alphabet | Unnecessary overhead                             | Use a frequency array           |
| Forgetting to initialize counts                 | Default values not set                           | Initialize arrays/maps properly |
| Using `arr.count(x)` inside a loop (Python)     | Results in O(n²)                                 | Precompute frequencies          |
| Assuming `filter()` is memory-free              | Creates a temporary collection in many languages | Prefer manual loops in CP       |

---

## Choosing the Right Counting Technique

| Scenario                          | Best Choice                       |
| --------------------------------- | --------------------------------- |
| Count one value once              | Built-in `count()` or manual loop |
| Many frequency queries            | Frequency Map                     |
| Lowercase English letters         | Frequency Array (size 26)         |
| Unicode characters                | Hash Map / Dictionary             |
| Count values matching a condition | Predicate count / Manual loop     |
| Small bounded integer range       | Frequency Array                   |
