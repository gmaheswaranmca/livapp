# Phase 1 — Common Competitive Programming Operations

# Topic 13 — Partition

Partition rearranges elements into groups based on a predicate without necessarily sorting them. It is widely used in:

* QuickSort
* QuickSelect
* Two Pointers
* Dutch National Flag
* Sliding Window
* Greedy
* Stable grouping

Unlike sorting (**O(n log n)**), partitioning typically runs in **O(n)**.

---

# 1. Partition

## Purpose

Rearrange elements so that all elements satisfying a predicate come before the others.

The relative order within each group is **not preserved**.

Example

```text id="1b6e4u"
Array

5 2 8 1 7 4

Partition Even

↓

2 8 4 5 1 7

(any valid partition is acceptable)
```

| Language       | Idiomatic CP Syntax                | Built-in | Stable  | Time | Space     |
| -------------- | ---------------------------------- | -------- | ------- | ---- | --------- |
| **C++**        | `partition(begin,end,pred)`        | STL      | ❌       | O(n) | O(1)      |
| **Rust**       | Manual two pointers                | ❌        | ❌       | O(n) | O(1)      |
| **Go**         | Manual two pointers                | ❌        | ❌       | O(n) | O(1)      |
| **Java**       | Manual two pointers                | ❌        | ❌       | O(n) | O(1)      |
| **Python**     | Two pointers / list comprehensions | Partial  | Depends | O(n) | O(1)/O(n) |
| **JavaScript** | Manual                             | ❌        | ❌       | O(n) | O(1)      |
| **C#**         | Manual                             | ❌        | ❌       | O(n) | O(1)      |

### CP Recommendation

When order does **not** matter, use in-place partitioning because it is faster and uses constant extra memory.

---

# 2. Stable Partition

## Purpose

Partition while preserving the relative order of elements in both groups.

Example

```text id="6qjlwm"
Input

5 2 8 1 7 4

Stable Even Partition

↓

2 8 4 5 1 7
```

Notice:

```text id="1hvl2q"
Even numbers

2 8 4

remain in their original order.

Odd numbers

5 1 7

also remain ordered.
```

| Language       | Built-in             | Notes                    |
| -------------- | -------------------- | ------------------------ |
| **C++**        | `stable_partition()` | ✅                        |
| **Rust**       | Manual               | Collect into two vectors |
| **Go**         | Manual               | Two temporary slices     |
| **Java**       | Manual               | Two lists                |
| **Python**     | List comprehensions  | Naturally stable         |
| **JavaScript** | Two arrays           | Stable                   |
| **C#**         | LINQ / two lists     | Stable                   |

### Complexity

| Time | Space |
| ---- | ----- |
| O(n) | O(n)  |

### CP Recommendation

Use stable partition only when preserving order is required, as it usually needs extra memory.

# 3. Predicate Partition

## Purpose

Partition using any Boolean condition (predicate).

Examples of predicates:

* Even / Odd
* Positive / Negative
* Prime / Composite
* Visited / Unvisited
* Less than `k`
* Ends before time `t`

Example

```text id="wdq55j"
Partition

x < 10
```

### Standard Two-Pointer Algorithm

```text id="pfpkl3"
left = 0
right = n - 1

while left <= right

    advance left while predicate is true

    advance right while predicate is false

    swap if needed
```

### Complexity

* Time: **O(n)**
* Space: **O(1)**

### CP Recommendation

This is the basis of:

* QuickSort
* QuickSelect
* Dutch National Flag
* Segregating positives/negatives
* Segregating zeros/ones

---

# Partition vs Stable Partition

| Feature                  | Partition      | Stable Partition       |
| ------------------------ | -------------- | ---------------------- |
| Relative Order Preserved | ❌              | ✅                      |
| Extra Memory             | O(1)           | Usually O(n)           |
| Speed                    | Faster         | Slightly slower        |
| CP Recommendation        | Default choice | Use only when required |

# CP Recommendations

* ✅ Prefer **in-place partition** when element order does not matter.
* ✅ Use **stable partition** only when the original ordering of each group must be preserved.
* ✅ Learn the **two-pointer partition algorithm**; it forms the foundation of QuickSort and QuickSelect.
* ✅ For Python, list comprehensions provide a concise stable partition but allocate extra memory.
* ✅ Choose partition over sorting when you only need to separate elements into groups—it reduces the complexity from **O(n log n)** to **O(n)**.
* ✅ Be careful when writing custom partition logic to avoid infinite loops or incorrect pointer movement.

---

# Common Mistakes

| Mistake                              | Why It Happens                     | Better Approach                        |
| ------------------------------------ | ---------------------------------- | -------------------------------------- |
| Sorting instead of partitioning      | Simpler but slower                 | Use partition for O(n) grouping        |
| Assuming partition preserves order   | Standard partition is unstable     | Use stable partition if order matters  |
| Incorrect pointer updates            | Infinite loops or skipped elements | Advance pointers carefully after swaps |
| Using extra arrays unnecessarily     | Higher memory usage                | Use in-place partition when possible   |
| Choosing stable partition by default | Unnecessary overhead               | Use it only when required              |

---

## Choosing the Right Partition Technique

| Scenario                                          | Best Choice                        |
| ------------------------------------------------- | ---------------------------------- |
| Group elements without caring about order         | In-place Partition                 |
| Preserve original order within groups             | Stable Partition                   |
| QuickSort / QuickSelect                           | Partition                          |
| Separate even/odd or positive/negative            | Predicate Partition                |
| Functional-style filtering while preserving order | Stable Partition (two collections) |
| Memory-constrained problems                       | In-place Partition                 |
