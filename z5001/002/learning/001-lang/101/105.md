# Phase 1 — Common Competitive Programming Operations

# Topic 5 — Searching

Searching means locating an element, its index, or an element satisfying a condition. Unlike **Binary Search**, these operations work on **unsorted** collections unless otherwise noted.

Searching is commonly used in:

* Linear scans
* Simulation
* Greedy algorithms
* String processing
* Graph traversal
* Filtering
* Validation

---

# 1. Find

## Purpose

Find the **first occurrence** of a value.

Example

```text
Array

5 9 3 7 9

Find 9

↓

Index = 1
```

| Language       | Idiomatic CP Syntax     | Built-in | Returns  | Time | Space           |      |      |
| -------------- | ----------------------- | -------- | -------- | ---- | --------------- | ---- | ---- |
| **C++**        | `find(begin, end, x)`   | STL      | Iterator | O(n) | O(1)            |      |      |
| **Rust**       | `iter().position(       | &v       | v==x)`   | std  | `Option<usize>` | O(n) | O(1) |
| **Go**         | Manual loop             | ❌        | Index    | O(n) | O(1)            |      |      |
| **Java**       | Manual loop             | ❌        | Index    | O(n) | O(1)            |      |      |
| **Python**     | `arr.index(x)`*         | built-in | Index    | O(n) | O(1)            |      |      |
| **JavaScript** | `arr.indexOf(x)`        | built-in | Index    | O(n) | O(1)            |      |      |
| **C#**         | `Array.IndexOf(arr, x)` | .NET     | Index    | O(n) | O(1)            |      |      |

* Raises an exception if the value is not found.

### CP Recommendation

* For Python, avoid `list.index()` if the element may not exist; a manual scan is often safer in contests.
* Use a linear scan unless the data is sorted (then use Binary Search).

# 2. Contains

## Purpose

Check whether a value exists.

Example

```text
Contains 7 ?

↓

true
```

| Language       | Idiomatic CP Syntax             |
| -------------- | ------------------------------- |
| **C++**        | `find(...) != end`              |
| **Rust**       | `v.contains(&x)`                |
| **Go**         | Manual loop                     |
| **Java**       | Manual loop / `list.contains()` |
| **Python**     | `x in arr`                      |
| **JavaScript** | `arr.includes(x)`               |
| **C#**         | `arr.Contains(x)` *(LINQ)*      |

### Complexity

* Array/List: **O(n)**
* Hash Set/Hash Map: **O(1)** average

### CP Recommendation

If many membership queries are needed, preprocess into a **Hash Set**.

# 3. Index Of

## Purpose

Return the position of the first occurrence.

Example

```text
10 20 30 40

IndexOf(30)

↓

2
```

| Language       | API                          | Not Found |
| -------------- | ---------------------------- | --------- |
| **C++**        | `distance(begin, find(...))` | `n`       |
| **Rust**       | `position()`                 | `None`    |
| **Go**         | Manual                       | `-1`      |
| **Java**       | Manual                       | `-1`      |
| **Python**     | `index()`                    | Exception |
| **JavaScript** | `indexOf()`                  | `-1`      |
| **C#**         | `IndexOf()`                  | `-1`      |

### CP Recommendation

Returning `-1` is generally easier to work with than exceptions.

# 4. Find by Predicate

## Purpose

Find the first element satisfying a condition instead of matching an exact value.

Example

```text
Array

2 5 8 11 14

Find first even > 10

↓

14
```

Typical predicates:

* First even number
* First negative number
* First prime
* First interval ending after x

| Language       | Idiomatic CP Syntax                       |
| -------------- | ----------------------------------------- |
| **C++**        | `find_if(begin,end,predicate)`            |
| **Rust**       | `iter().find(...)`                        |
| **Go**         | Manual loop                               |
| **Java**       | Manual loop / Streams (avoid in CP)       |
| **Python**     | `next((x for x in arr if cond), default)` |
| **JavaScript** | `arr.find(predicate)`                     |
| **C#**         | `Array.Find(arr, predicate)`              |

### Complexity

* Time: **O(n)**
* Space: **O(1)** (excluding iterator/generator overhead)

### CP Recommendation

Prefer simple loops over Streams/LINQ in performance-critical contest code.

# CP Recommendations

* ✅ Use **linear search** for unsorted arrays.
* ✅ If there are many lookup queries, build a **Hash Set** or **Hash Map** once and perform **O(1)** average-time lookups.
* ✅ Use **Binary Search** instead of linear search on sorted arrays.
* ✅ Prefer simple `for` loops in Go and Java for maximum performance and readability.
* ✅ In Python, use `x in set` instead of `x in list` when repeated membership tests are required.
* ✅ Use predicate-based search (`find_if`, `find`, `Array.Find`, etc.) when searching by a condition rather than an exact value.

# Common Mistakes

| Mistake                                                     | Why It Happens         | Better Approach                                    |
| ----------------------------------------------------------- | ---------------------- | -------------------------------------------------- |
| Using linear search on sorted data                          | Missed optimization    | Use Binary Search (O(log n))                       |
| Calling `list.index()` in Python without checking existence | Raises `ValueError`    | Use `x in arr` first or a manual loop              |
| Using Streams/LINQ in tight loops                           | Additional overhead    | Prefer explicit loops in CP                        |
| Repeating linear searches inside another loop               | Leads to O(n²)         | Preprocess into a Hash Set/Map                     |
| Confusing `indexOf()` with `find()` in JavaScript           | Different return types | Use `find()` for elements, `indexOf()` for indices |

---

## Choosing the Right Search Operation

| Goal                                    | Best Choice                              |
| --------------------------------------- | ---------------------------------------- |
| Find exact value in unsorted array      | Linear search                            |
| Check existence repeatedly              | Hash Set                                 |
| Find exact value in sorted array        | Binary Search                            |
| Find insertion position                 | `lower_bound` / `bisect_left`            |
| Find first element matching a condition | Predicate search                         |
| Find index of first occurrence          | `indexOf()` / `position()` / manual loop |
