# Phase 1 — Common Competitive Programming Operations

# Topic 17 — Randomization

Randomization is occasionally used in Competitive Programming for:

* Randomized QuickSort
* Randomized QuickSelect
* Stress testing
* Test case generation
* Monte Carlo algorithms
* Random hashing
* Random pivot selection

> **CP Note:** Most contest solutions should be deterministic. Use randomization only when it improves expected performance or when explicitly required.

---

# 1. Shuffle

## Purpose

Randomly reorder all elements.

Example

```text id="ec9y4m"
Input

1 2 3 4 5

↓

Possible Output

3 1 5 2 4
```

A valid shuffle gives every permutation an equal probability.

| Language       | Idiomatic CP Syntax         | Built-in       | Time | Space |
| -------------- | --------------------------- | -------------- | ---- | ----- |
| **C++**        | `shuffle(begin, end, rng)`  | STL            | O(n) | O(1)  |
| **Rust**       | `slice.shuffle(&mut rng)`*  | External crate | O(n) | O(1)  |
| **Go**         | `rand.Shuffle(...)`         | std            | O(n) | O(1)  |
| **Java**       | `Collections.shuffle(list)` | JDK            | O(n) | O(1)  |
| **Python**     | `random.shuffle(arr)`       | built-in       | O(n) | O(1)  |
| **JavaScript** | Fisher-Yates                | ❌              | O(n) | O(1)  |
| **C#**         | Fisher-Yates                | ❌              | O(n) | O(1)  |

* Uses the commonly available `rand` crate, but verify contest rules before relying on external crates.

### CP Recommendation

Never implement a shuffle by repeatedly swapping with random indices unless it follows the Fisher-Yates algorithm.

# 2. Random Integer

## Purpose

Generate a random integer within a range.

Example

```text id="4tnd9j"
Range

1 ... 100

↓

57
```

| Language       | Idiomatic CP Syntax                           |
| -------------- | --------------------------------------------- |
| **C++**        | `uniform_int_distribution<int>(l, r)`         |
| **Rust**       | `rng.gen_range(l..=r)`*                       |
| **Go**         | `rand.Intn(r-l+1)+l`                          |
| **Java**       | `ThreadLocalRandom.current().nextInt(l, r+1)` |
| **Python**     | `random.randint(l, r)`                        |
| **JavaScript** | `Math.floor(Math.random()*(r-l+1))+l`         |
| **C#**         | `Random.Next(l, r+1)`                         |

### Complexity

* Time: **O(1)**
* Space: **O(1)**

### CP Recommendation

For stress testing, fix the seed to make failures reproducible.

# 4. Fisher-Yates Shuffle

## Purpose

Generate a **uniform random permutation**.

This is the standard shuffle algorithm.

### Algorithm

```text id="tr2l8v"
for i from n-1 down to 1

    j = random integer in [0, i]

    swap(i, j)
```

Example

```text id="i8b6dv"
1 2 3 4

↓

4 1 2 3
```

Every permutation is equally likely.

### Complexity

| Time | Space |
| ---- | ----- |
| O(n) | O(1)  |

### Availability

| Language       | Built-in                              |
| -------------- | ------------------------------------- |
| **C++**        | `shuffle()` uses this idea internally |
| **Rust**       | `shuffle()`*                          |
| **Go**         | `rand.Shuffle()`                      |
| **Java**       | `Collections.shuffle()`               |
| **Python**     | `random.shuffle()`                    |
| **JavaScript** | Manual                                |
| **C#**         | Manual                                |

### CP Recommendation

If your language has no built-in shuffle, implement Fisher-Yates instead of inventing your own algorithm.

# Randomization vs Deterministic Algorithms

| Feature                  | Randomized   | Deterministic |
| ------------------------ | ------------ | ------------- |
| Same Input → Same Output | ❌            | ✅             |
| Worst-case Guarantee     | Usually ❌    | Usually ✅     |
| Expected Performance     | Often better | Fixed         |
| Debugging                | Harder       | Easier        |
| CP Usage                 | Occasional   | Preferred     |

# CP Recommendations

* ✅ Use the language's built-in shuffle API when available.
* ✅ If no shuffle API exists, implement the **Fisher-Yates Shuffle**; it guarantees a uniform random permutation.
* ✅ Prefer deterministic algorithms unless randomization provides a clear advantage (e.g., randomized pivot selection).
* ✅ For stress testing and debugging, use a **fixed random seed** so failing test cases can be reproduced.
* ✅ Select a random element by generating a random index rather than repeatedly sampling until a valid value is found.
* ✅ Avoid using randomness in problems that require identical output across runs unless the problem explicitly permits randomized solutions.

---

# Common Mistakes

| Mistake                                                             | Why It Happens                     | Better Approach                                |
| ------------------------------------------------------------------- | ---------------------------------- | ---------------------------------------------- |
| Shuffling by swapping with any random index every iteration         | Produces biased permutations       | Use Fisher-Yates                               |
| Forgetting to fix the seed during stress testing                    | Bugs become difficult to reproduce | Use a constant seed                            |
| Assuming `Math.random()` or similar is suitable for every purpose   | Quality varies and APIs differ     | Use standard language facilities appropriately |
| Relying on external libraries in contests                           | May not be available               | Verify contest environment first               |
| Using randomization when a deterministic O(n log n) solution exists | Unnecessary complexity             | Prefer deterministic algorithms                |

---

## Choosing the Right Randomization Technique

| Scenario                   | Best Choice                            |
| -------------------------- | -------------------------------------- |
| Randomly reorder an array  | Shuffle / Fisher-Yates                 |
| Generate a random integer  | Built-in random integer API            |
| Pick a random element      | Random index (or `choice()` in Python) |
| Random pivot for QuickSort | Random Integer                         |
| Stress testing             | Fixed-seed random generator            |
| Test case generation       | Random Integer + Shuffle               |
