# Phase 1 — Common Competitive Programming Operations

# Topic 16 — Heap Utilities

A Heap (Priority Queue) is one of the most important data structures in Competitive Programming. It is used in:

* Dijkstra's Algorithm
* Prim's Algorithm
* Top-K problems
* K-way Merge
* Median maintenance
* Greedy algorithms
* Event simulation
* Scheduling

A heap maintains the highest- or lowest-priority element at the top without fully sorting the data.

---

# 1. Heapify

## Purpose

Convert an unsorted collection into a heap.

Example

```text id="9fx3ql"
Input

4 1 7 3 8 5

↓

Min Heap

1
├──3
│  ├──4
│  └──8
└──5
   └──7
```

> The internal array representation may vary, but the heap property is maintained.

| Language       | Idiomatic CP Syntax               | Built-in         | Time         | Space |
| -------------- | --------------------------------- | ---------------- | ------------ | ----- |
| **C++**        | `make_heap(begin,end)`*           | STL              | O(n)         | O(1)  |
| **Rust**       | `BinaryHeap::from(vec)`           | std              | O(n)         | O(1)  |
| **Go**         | `heap.Init(&h)`                   | `container/heap` | O(n)         | O(1)  |
| **Java**       | `new PriorityQueue<>(collection)` | JDK              | O(n)         | O(1)  |
| **Python**     | `heapq.heapify(arr)`              | `heapq`          | O(n)         | O(1)  |
| **JavaScript** | Manual heap                       | ❌                | O(n)         | O(1)  |
| **C#**         | Repeated insert / custom          | Partial          | O(n log n)** | —     |

* `make_heap()` creates a **max heap** by default.

** Modern .NET `PriorityQueue` does not expose a dedicated heapify API.

### CP Recommendation

Use heap construction (`heapify`) instead of repeated insertions whenever you already have all elements.

# 2. Push

## Purpose

Insert a new element into the heap.

Example

```text id="6l4rzl"
Heap

2 4 5

Push 1

↓

Top = 1
```

| Language       | Idiomatic CP Syntax                     | Time     |
| -------------- | --------------------------------------- | -------- |
| **C++**        | `push_heap()` / `priority_queue.push()` | O(log n) |
| **Rust**       | `heap.push(x)`                          | O(log n) |
| **Go**         | `heap.Push(&h, x)`                      | O(log n) |
| **Java**       | `pq.offer(x)` / `pq.add(x)`             | O(log n) |
| **Python**     | `heapq.heappush(h, x)`                  | O(log n) |
| **JavaScript** | Manual                                  | O(log n) |
| **C#**         | `Enqueue(item, priority)`               | O(log n) |

### CP Recommendation

Prefer `offer()` over `add()` in Java for queue semantics.

# 3. Pop

## Purpose

Remove and return the highest- or lowest-priority element.

Example

```text id="s1d2z8"
Heap Top

1

↓

Pop

↓

Next Top

2
```

| Language       | Idiomatic CP Syntax                   | Time     |
| -------------- | ------------------------------------- | -------- |
| **C++**        | `pop_heap()` / `priority_queue.pop()` | O(log n) |
| **Rust**       | `heap.pop()`                          | O(log n) |
| **Go**         | `heap.Pop(&h)`                        | O(log n) |
| **Java**       | `pq.poll()`                           | O(log n) |
| **Python**     | `heapq.heappop(h)`                    | O(log n) |
| **JavaScript** | Manual                                | O(log n) |
| **C#**         | `Dequeue()`                           | O(log n) |

### CP Recommendation

Always check that the heap is non-empty before popping.

# 4. Peek

## Purpose

Read the top element without removing it.

Example

```text id="p3e8cx"
Heap

1 3 5

Peek

↓

1
```

| Language       | Idiomatic CP Syntax     | Time |
| -------------- | ----------------------- | ---- |
| **C++**        | `pq.top()`              | O(1) |
| **Rust**       | `heap.peek()`           | O(1) |
| **Go**         | `h[0]`                  | O(1) |
| **Java**       | `pq.peek()`             | O(1) |
| **Python**     | `heap[0]`               | O(1) |
| **JavaScript** | `heap[0]` (manual heap) | O(1) |
| **C#**         | `Peek()`                | O(1) |

### CP Recommendation

Use `peek()`/`top()` when only the highest-priority element is needed.

# 5. Min Heap

## Purpose

Maintain the smallest element at the top.

Example

```text id="1wceep"
Input

5 3 8 1

↓

Top

1
```

| Language       | Default Heap                 |
| -------------- | ---------------------------- |
| **C++**        | ❌ Max Heap                   |
| **Rust**       | ❌ Max Heap                   |
| **Go**         | ✅ Min Heap                   |
| **Java**       | ✅ Min Heap                   |
| **Python**     | ✅ Min Heap                   |
| **JavaScript** | Manual                       |
| **C#**         | ✅ Min Heap (`PriorityQueue`) |

### C++ Min Heap

```text id="gsg4j3"
priority_queue<
    int,
    vector<int>,
    greater<int>
>
```

### Rust Min Heap

Use `std::cmp::Reverse<T>` inside `BinaryHeap`.

### CP Recommendation

Know how to create a min heap in C++ and Rust—they default to max heaps.

# 6. Max Heap

## Purpose

Maintain the largest element at the top.

Example

```text id="d6cty6"
Input

5 3 8 1

↓

Top

8
```

| Language       | Recommended                                   |
| -------------- | --------------------------------------------- |
| **C++**        | Default `priority_queue`                      |
| **Rust**       | Default `BinaryHeap`                          |
| **Go**         | Custom comparator (invert ordering)           |
| **Java**       | `PriorityQueue<>(Collections.reverseOrder())` |
| **Python**     | Negate values (`-x`)                          |
| **JavaScript** | Manual                                        |
| **C#**         | Negate priorities / custom wrapper            |

### CP Recommendation

Python's standard solution is to push `-value` to simulate a max heap.

# 7. Custom Comparator

## Purpose

Order elements by a user-defined priority.

Examples

* Shortest path distance
* Interval ending time
* Pair second value
* Highest frequency
* Earliest deadline

| Language       | Support                           |
| -------------- | --------------------------------- |
| **C++**        | Comparator class / lambda         |
| **Rust**       | Implement `Ord` or wrap type      |
| **Go**         | Implement `heap.Interface`        |
| **Java**       | Comparator                        |
| **Python**     | Tuple priorities / custom wrapper |
| **JavaScript** | Manual implementation             |
| **C#**         | Priority value or custom comparer |

### Example Priorities

```text id="2tgs2i"
(distance, node)

(endTime, interval)

(-frequency, value)
```

### CP Recommendation

When multiple fields determine priority, store tuples/pairs instead of writing complex comparison logic.

# CP Recommendations

* ✅ Use **heapify** (`O(n)`) instead of inserting elements one by one (`O(n log n)`) when building a heap from existing data.
* ✅ Remember each language's default heap type:

  * **Max Heap:** C++, Rust
  * **Min Heap:** Go, Java, Python, C#
* ✅ In Python, simulate a max heap by pushing **negative values**.
* ✅ For problems involving priorities on multiple fields, store tuples/pairs such as `(distance, node)` or `(cost, id)` instead of writing complicated comparators.
* ✅ Heaps are the standard choice for **Top-K**, **Dijkstra**, **Prim**, **K-way Merge**, and scheduling problems.
* ✅ Always check that the heap is not empty before calling `pop()` or `peek()`.

# Common Mistakes

| Mistake                                              | Why It Happens                       | Better Approach                            |
| ---------------------------------------------------- | ------------------------------------ | ------------------------------------------ |
| Assuming every language defaults to a min heap       | Defaults differ                      | Know the default behavior of your language |
| Building a heap via repeated insertions              | O(n log n) instead of O(n)           | Use heapify when possible                  |
| Forgetting to negate values in Python for a max heap | `heapq` is min-heap only             | Push `-x` and negate again when popping    |
| Using an incorrect comparator                        | Heap order becomes invalid           | Test comparator logic on small examples    |
| Expecting iteration over a heap to be sorted         | Heap only guarantees the top element | Repeatedly pop to obtain sorted order      |

## Choosing the Right Heap Configuration

| Scenario                       | Best Choice       |
| ------------------------------ | ----------------- |
| Smallest element first         | Min Heap          |
| Largest element first          | Max Heap          |
| Top-K smallest/largest         | Heap              |
| Shortest path (Dijkstra)       | Min Heap          |
| Merge K sorted lists           | Min Heap          |
| Highest-priority scheduling    | Custom Comparator |
| Build heap from existing array | Heapify           |
