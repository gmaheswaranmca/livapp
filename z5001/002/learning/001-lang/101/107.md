# Phase 1 — Common Competitive Programming Operations

# Topic 7 — Min / Max Operations

Finding minimum and maximum values is one of the most common operations in Competitive Programming. These operations are used in:

* Greedy algorithms
* Dynamic Programming
* Sliding Window
* Binary Search on Answer
* Range Queries
* Graph algorithms
* Geometry
* Simulation

Most languages provide built-in APIs for these operations.

---

# 1. `min`

## Purpose

Return the smaller of two values.

Example

```text
min(8, 5)

↓

5
```

| Language       | Idiomatic CP Syntax      | Built-in | Time | Space |
| -------------- | ------------------------ | -------- | ---- | ----- |
| **C++**        | `min(a, b)`              | STL      | O(1) | O(1)  |
| **Rust**       | `a.min(b)`               | std      | O(1) | O(1)  |
| **Go**         | `min(a, b)` *(Go 1.21+)* | std      | O(1) | O(1)  |
| **Java**       | `Math.min(a, b)`         | JDK      | O(1) | O(1)  |
| **Python**     | `min(a, b)`              | built-in | O(1) | O(1)  |
| **JavaScript** | `Math.min(a, b)`         | built-in | O(1) | O(1)  |
| **C#**         | `Math.Min(a, b)`         | .NET     | O(1) | O(1)  |

### CP Recommendation

Use built-in functions instead of ternary expressions.

# 3. `min_element`

## Purpose

Find the minimum element in a collection.

Example

```text
Array

7 3 8 1 5

↓

1
```

| Language       | Idiomatic CP Syntax                           | Built-in |
| -------------- | --------------------------------------------- | -------- |
| **C++**        | `*min_element(begin, end)`                    | ✅        |
| **Rust**       | `iter().min()`                                | ✅        |
| **Go**         | Manual loop *(or `slices.Min()` in Go 1.21+)* | Partial  |
| **Java**       | Manual loop                                   | ❌        |
| **Python**     | `min(arr)`                                    | ✅        |
| **JavaScript** | `Math.min(...arr)`*                           | Partial  |
| **C#**         | `arr.Min()` *(LINQ)*                          | ✅        |

* Avoid the spread operator for very large arrays in JavaScript because it may exceed argument limits. A manual loop is safer in CP.

### Complexity

* **Time:** O(n)
* **Space:** O(1)

### CP Recommendation

Use a manual loop in Java and for large JavaScript arrays.

# 5. Min / Max of Multiple Values

## Purpose

Find the minimum or maximum among several values.

Example

```text
Values

8 3 11 5

Minimum = 3
Maximum = 11
```

| Language       | Minimum                 | Maximum                 |
| -------------- | ----------------------- | ----------------------- |
| **C++**        | `min({a,b,c,d})`        | `max({a,b,c,d})`        |
| **Rust**       | Nested `.min()`         | Nested `.max()`         |
| **Go**         | Nested `min()` / manual | Nested `max()` / manual |
| **Java**       | Nested `Math.min()`     | Nested `Math.max()`     |
| **Python**     | `min(a,b,c,d)`          | `max(a,b,c,d)`          |
| **JavaScript** | `Math.min(a,b,c,d)`     | `Math.max(a,b,c,d)`     |
| **C#**         | Nested `Math.Min()`     | Nested `Math.Max()`     |

### CP Recommendation

* C++ initializer-list syntax is concise.
* Python naturally supports multiple arguments.

# 6. `clamp`

## Purpose

Restrict a value to a given range.

Formula

```text
clamp(x, lo, hi)

↓

max(lo, min(x, hi))
```

Example

```text
Range

10..20

Value

25

↓

20
```

```text
Range

10..20

Value

7

↓

10
```

| Language       | Idiomatic CP Syntax             |
| -------------- | ------------------------------- |
| **C++**        | `clamp(x, lo, hi)` *(C++17)*    |
| **Rust**       | `x.clamp(lo, hi)`               |
| **Go**         | `min(max(x, lo), hi)`           |
| **Java**       | `Math.max(lo, Math.min(x, hi))` |
| **Python**     | `max(lo, min(x, hi))`           |
| **JavaScript** | `Math.max(lo, Math.min(x, hi))` |
| **C#**         | `Math.Clamp(x, lo, hi)`         |

### Complexity

* **Time:** O(1)
* **Space:** O(1)

### CP Recommendation

Useful for:

* Grid boundaries
* Coordinate clipping
* Simulation
* Geometry

# CP Recommendations

* ✅ Use built-in `min` and `max` for pairwise comparisons.
* ✅ Use `min_element`/`max_element` (or equivalents) instead of writing custom loops when the language provides them.
* ✅ In Java, a simple manual loop is the standard CP approach for finding array minima/maxima.
* ✅ Avoid `Math.min(...arr)` or `Math.max(...arr)` with very large JavaScript arrays due to argument limits; iterate manually instead.
* ✅ Use `clamp` (or its manual equivalent) to simplify boundary checks in grid and simulation problems.
* ✅ When you need both the minimum and maximum in one pass, compute them together in a single traversal instead of scanning the array twice.

---

# Common Mistakes

| Mistake                                   | Why It Happens                                    | Better Approach                           |
| ----------------------------------------- | ------------------------------------------------- | ----------------------------------------- |
| Calling `min(arr)` on an empty collection | Undefined/error depending on language             | Check that the collection is non-empty    |
| Using JavaScript spread on huge arrays    | May exceed maximum argument count                 | Use a manual loop                         |
| Scanning twice for min and max            | Unnecessary O(2n) work                            | Compute both in one pass                  |
| Confusing `min` with `min_element`        | One compares values, the other scans a collection | Choose the appropriate API                |
| Forgetting to clamp indices               | Out-of-bounds access                              | Apply `clamp` or explicit boundary checks |

---

## Choosing the Right Min/Max Operation

| Scenario                          | Best Choice                                |
| --------------------------------- | ------------------------------------------ |
| Compare two values                | `min` / `max`                              |
| Find smallest element in an array | `min_element` / `min(arr)`                 |
| Find largest element in an array  | `max_element` / `max(arr)`                 |
| Compare several values            | Multi-argument `min`/`max` or nested calls |
| Restrict a value to a range       | `clamp` or `max(lo, min(x, hi))`           |
| Find both minimum and maximum     | Single manual traversal                    |
