# Phase 1 — Common Competitive Programming Operations

# Topic 11 — Remove / Erase Operations

Removing elements is a common operation in Competitive Programming. It is used in:

* Filtering data
* Sliding Window
* Simulation
* Greedy algorithms
* Interval problems
* String processing
* Dynamic arrays

The biggest difference across languages is **whether removal is in-place or creates a new collection**.

---

# 1. Remove by Value

## Purpose

Remove **all occurrences** (or the first occurrence) of a given value.

Example

```text
Array

1 2 3 2 4 2

Remove 2

↓

1 3 4
```

| Language       | Idiomatic CP Syntax                                    | Built-in | In-place | Time | Space |      |      |
| -------------- | ------------------------------------------------------ | -------- | -------- | ---- | ----- | ---- | ---- |
| **C++**        | `erase(remove(begin,end,x), end)`                      | STL      | ✅        | O(n) | O(1)  |      |      |
| **Rust**       | `retain(                                               | &v       | v != x)` | std  | ✅     | O(n) | O(1) |
| **Go**         | Manual overwrite (two pointers)                        | ❌        | ✅        | O(n) | O(1)  |      |      |
| **Java**       | Manual overwrite for arrays; `list.remove()` for lists | Partial  | ✅        | O(n) | O(1)  |      |      |
| **Python**     | `arr[:] = [v for v in arr if v != x]`                  | Partial  | ✅        | O(n) | O(n)* |      |      |
| **JavaScript** | `arr = arr.filter(v => v !== x)`                       | ✅        | ❌        | O(n) | O(n)  |      |      |
| **C#**         | `list.RemoveAll(v => v == x)`                          | ✅        | ✅        | O(n) | O(1)  |      |      |

* Uses temporary storage for the list comprehension.

### CP Recommendation

* For arrays/vectors, use **two-pointer compaction** when no built-in in-place API exists.
* Avoid repeatedly removing one element at a time from the middle of an array.

---

# 2. Remove by Index

## Purpose

Remove the element at a specific index.

Example

```text
Array

10 20 30 40

Remove index 2

↓

10 20 40
```

| Language       | Idiomatic CP Syntax             | Time |
| -------------- | ------------------------------- | ---- |
| **C++**        | `v.erase(v.begin()+idx)`        | O(n) |
| **Rust**       | `v.remove(idx)`                 | O(n) |
| **Go**         | `append(a[:i], a[i+1:]...)`     | O(n) |
| **Java**       | `list.remove(idx)`              | O(n) |
| **Python**     | `arr.pop(idx)` / `del arr[idx]` | O(n) |
| **JavaScript** | `arr.splice(idx, 1)`            | O(n) |
| **C#**         | `list.RemoveAt(idx)`            | O(n) |

### Why O(n)?

All elements after the removed position must be shifted left.

### CP Recommendation

Frequent middle deletions suggest using a linked list or a different algorithm, though vectors/arrays are usually faster overall in CP.

---

# 3. Remove Range

## Purpose

Remove a continuous range of elements.

Example

```text
1 2 3 4 5 6

Remove [2,5)

↓

1 2 6
```

| Language       | Idiomatic CP Syntax          |
| -------------- | ---------------------------- |
| **C++**        | `v.erase(begin+l, begin+r)`  |
| **Rust**       | `v.drain(l..r)`              |
| **Go**         | `append(a[:l], a[r:]...)`    |
| **Java**       | `list.subList(l, r).clear()` |
| **Python**     | `del arr[l:r]`               |
| **JavaScript** | `arr.splice(l, r-l)`         |
| **C#**         | `list.RemoveRange(l, count)` |

### Complexity

* Time: **O(n)**
* Space: **O(1)** (excluding temporary slices in some languages)

---

# 4. Remove If

## Purpose

Remove all elements satisfying a predicate.

Example

```text
Array

1 4 7 8 2

Remove Even

↓

1 7
```

| Language       | Idiomatic CP Syntax             |   |                 |
| -------------- | ------------------------------- | - | --------------- |
| **C++**        | `erase(remove_if(...), end)`    |   |                 |
| **Rust**       | `retain(                        | x | !predicate(x))` |
| **Go**         | Manual overwrite                |   |                 |
| **Java**       | `removeIf(predicate)` *(Lists)* |   |                 |
| **Python**     | List comprehension              |   |                 |
| **JavaScript** | `filter()`                      |   |                 |
| **C#**         | `RemoveAll(predicate)`          |   |                 |

### Complexity

* Time: **O(n)**
* Space: O(1) to O(n), depending on the implementation.

### CP Recommendation

For arrays, in-place compaction is often more memory-efficient than creating a new collection.

# 5. Erase-Remove Idiom (C++)

## Purpose

Efficiently remove elements from a `vector`.

```text
erase(
    remove(begin, end, value),
    end
)
```

### Why?

`remove()` **does not actually erase elements**.

It only moves the retained elements to the front and returns the new logical end.

```text
Original

1 2 3 2 4

↓

remove(2)

1 3 4 ? ?

↓

erase()

1 3 4
```

### Complexity

* Time: **O(n)**
* Space: **O(1)**

### CP Recommendation

This is the standard way to remove values from `std::vector`.

---

# 6. Filter

## Purpose

Create a new collection containing only elements satisfying a condition.

Example

```text
Array

1 2 3 4 5

Keep Odd

↓

1 3 5
```

| Language       | Idiomatic CP Syntax            |
| -------------- | ------------------------------ |
| **C++**        | `copy_if()`                    |
| **Rust**       | `iter().filter(...).collect()` |
| **Go**         | Manual loop                    |
| **Java**       | Manual loop / Streams          |
| **Python**     | `[x for x in arr if cond]`     |
| **JavaScript** | `arr.filter(cond)`             |
| **C#**         | `Where(...).ToList()`          |

### Complexity

* Time: **O(n)**
* Space: **O(n)**

### CP Recommendation

Use filtering when you need to preserve the original collection.

# CP Recommendations

* ✅ Prefer **in-place removal** when the original collection is no longer needed.
* ✅ Use the **erase-remove idiom** in C++; `remove()` alone does **not** shrink the vector.
* ✅ For repeated removals from arrays, use a **two-pointer overwrite** technique instead of repeatedly calling remove/erase.
* ✅ Use **filtering** only when you need to preserve the original data.
* ✅ Avoid Java Streams and excessive LINQ usage in tight loops during contests; explicit loops are typically faster.
* ✅ Be aware that removing from the middle of an array/vector/list usually requires shifting elements and is **O(n)**.

---

# Common Mistakes

| Mistake                                     | Why It Happens                    | Better Approach                               |
| ------------------------------------------- | --------------------------------- | --------------------------------------------- |
| Calling `remove()` in C++ without `erase()` | `remove()` only reorders elements | Use `erase(remove(...), end)`                 |
| Removing elements while iterating forward   | Indices shift after removal       | Iterate backwards or use two pointers         |
| Repeated `erase()` in a loop                | Leads to O(n²) behavior           | Compact once with two pointers or `remove_if` |
| Using `filter()` when memory is tight       | Creates a new collection          | Prefer in-place compaction                    |
| Forgetting that `pop(idx)` shifts elements  | Subsequent indices change         | Update indices or iterate carefully           |

---

## Choosing the Right Removal Technique

| Scenario                          | Best Choice                                              |
| --------------------------------- | -------------------------------------------------------- |
| Remove all occurrences of a value | Erase-remove / `retain()` / two-pointer compaction       |
| Remove one element by index       | `erase()` / `remove()` / `pop()` / `splice()`            |
| Remove a contiguous range         | Range erase APIs                                         |
| Remove by condition               | `remove_if()` / `retain()` / `RemoveAll()` / manual loop |
| Preserve original collection      | Filter into a new collection                             |
| Remove many elements efficiently  | Single-pass two-pointer compaction                       |
