# Title
Search a 2D Matrix

## Difficulty
Medium

## Description
Given an m x n matrix with the following properties:
- Integers in each row are sorted in ascending order from left to right.
- The first integer of each row is greater than the last integer of the previous row.
Determine if a target value exists in the matrix.

## Examples

### Example 1
```text
Input: matrix = [[1,3,5],[7,9,11]], target = 9
Output: true
Explanation: 9 is present at matrix[1][1].
```

### Example 2
```text
Input: matrix = [[1,3,5],[7,9,11]], target = 6
Output: false
Explanation: 6 is not present.
```

## Constraints
```text
m = matrix.length, n = matrix[0].length
1 <= m, n <= 100
-10^4 <= matrix[i][j], target <= 10^4
matrix rows sorted ascending; first element of row i > last element of row i-1
```

---

## Idea
Treat the matrix as a sorted 1D array of length m*n and perform binary search.

---

## Pseudo Code
```text
function searchMatrix(matrix, target)
    if matrix is empty or matrix[0] is empty return false
    m = number of rows in matrix
    n = number of columns in matrix
    low = 0
    high = m * n - 1
    while low <= high
        mid = (low + high) // 2
        row = mid // n
        col = mid % n
        value = matrix[row][col]
        if value == target return true
        if value < target low = mid + 1 else high = mid - 1
    return false
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log(m*n)) = O(log m + log n) |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (low,high,mid,row,col,value) | Operation                                | Result            |
| ---- | ---------------------------------- | ---------------------------------------- | ----------------- |
| 1    | (0,5,2,0,2,5)                       | value(5) < target(9)                     | low = mid + 1 = 3 |
| 2    | (3,5,4,1,1,9)                       | value(9) == target(9)                    | return true       |

1. Map mid index to (row,col) via row = mid//n, col = mid%n.
2. Compare matrix[row][col] with target.
3. Move low/high accordingly until found or exhausted.
4. Return boolean indicating presence.

## Other Patterns

### Pattern 1

**Idea**
Binary search on each row (find candidate row then binary search) or check row by scanning first elements then binary search in candidate row.

**Pseudo Code**
```text
function searchMatrix_rowwise(matrix, target)
    if matrix is empty or matrix[0] is empty return false
    m = number of rows
    n = number of columns
    lowRow = 0
    highRow = m - 1
    while lowRow <= highRow
        midRow = (lowRow + highRow) // 2
        if matrix[midRow][0] <= target <= matrix[midRow][n-1]
            return binarySearchRow(matrix[midRow], target)
        if target < matrix[midRow][0] highRow = midRow - 1 else lowRow = midRow + 1
    return false

function binarySearchRow(row, target)
    low = 0
    high = length(row) - 1
    while low <= high
        mid = (low + high) // 2
        if row[mid] == target return true
        if row[mid] < target low = mid + 1 else high = mid - 1
    return false
```

### Pattern 2

**Idea**
Staircase search from top-right corner moving left/down based on comparison.

**Pseudo Code**
```text
function searchMatrix_staircase(matrix, target)
    if matrix is empty or matrix[0] is empty return false
    m = number of rows
    n = number of columns
    row = 0
    col = n - 1
    while row < m and col >= 0
        value = matrix[row][col]
        if value == target return true
        if value > target col = col - 1 else row = row + 1
    return false
```

## Comparison

| Approach                | Idea                                          | Time       | Space | Recommended |
| ----------------------- | --------------------------------------------- | ---------- | ----- | ----------- |
| Flattened Binary Search | Treat matrix as 1D sorted array and binary search | O(log(m*n)) | O(1)  | Yes         |
| Row-wise Binary Search  | Binary search to find row, then binary in row | O(log m + log n) | O(1)  | No (slightly more steps) |
| Staircase Search        | Start at top-right and move left/down         | O(m + n)   | O(1)  | No (useful if m,n large and binary search constraints unknown) |
