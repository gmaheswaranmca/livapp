# Maximum Sum Circular Subarray

## Difficulty
Medium

## Description
Find the maximum sum of a non-empty subarray in a circular integer array. A circular array means the end of the array wraps to the start.

## Examples

### Example 1

```text
Input: [1, -2, 3, -2]
Output: 3
Explanation: Non-circular subarray [3] gives 3.
```

### Example 2

```text
Input: [5, -3, 5]
Output: 10
Explanation: Circular subarray [5,5] (wraps) gives 10.
```

### Example 3

```text
Input: [-3, -2, -1]
Output: -1
Explanation: All negative, pick largest element -1.
```

## Constraints

```text
1 <= nums.length <= 10^5
-10^5 <= nums[i] <= 10^5
Must run in linear time and constant extra space for optimal solution.
```

---

## Idea
Use Kadane's algorithm to get the maximum subarray and minimum subarray; answer = max(max_kadane, total_sum - min_kadane) unless all numbers are negative.

---

## Pseudo Code

```text
function maxSubarrayCircular(nums)
    if nums is empty return 0
    total = 0
    currMax = nums[0]
    maxSoFar = nums[0]
    currMin = nums[0]
    minSoFar = nums[0]
    for i from 0 to length(nums)-1
        x = nums[i]
        total = total + x
        if i == 0
            currMax = x
            maxSoFar = x
            currMin = x
            minSoFar = x
            continue
        currMax = max(x, currMax + x)
        maxSoFar = max(maxSoFar, currMax)
        currMin = min(x, currMin + x)
        minSoFar = min(minSoFar, currMin)
    if maxSoFar < 0
        return maxSoFar
    return max(maxSoFar, total - minSoFar)
```

| Metric           | Value  |

| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | State (currMax, maxSoFar, currMin, minSoFar, total) | Operation | Result |
| ---- | --------------------------------------------------- | --------- | ------ |
| 1    | (1, 1, 1, 1, 1)                                     | init with nums[0]=1 | totals updated |
| 2    | ( -1, 1, -2, -2, -1 )                               | x=-2: currMax=max(-2,1-2)=-1; maxSoFar=max(1,-1)=1; currMin=min(-2,1-2)=-2; minSoFar=min(1,-2)=-2; total= -1 |
| 3    | ( 3, 3, 1, -2, 2 )                                  | x=3: currMax=max(3,-1+3)=3; maxSoFar=3; currMin=min(3,-2+3)=1; minSoFar=-2; total=2 |
| 4    | ( 1, 3, -2, -2, 0 )                                 | x=-2: currMax=max(-2,3-2)=1; maxSoFar=3; currMin=min(-2,1-2)=-2; minSoFar=-2; total=0 |
| end  | maxSoFar=3, minSoFar=-2, total=0                    | maxSoFar >= 0 so return max(3, 0 - (-2)=2) | answer=3 |

## Other Patterns

### Pattern 1

**Idea**
Brute force check all subarrays including wrap by duplicating array.

**Pseudo Code**

```text
function maxSubarrayCircularBrute(nums)
    n = length(nums)
    arr = nums concatenated with nums
    best = -infinity
    for i from 0 to n-1
        sum = 0
        for j from i to i+n-1
            sum = sum + arr[j]
            best = max(best, sum)
    return best
```

### Pattern 2

**Idea**
Divide and conquer using max subarray technique (non-circular) and combine prefix/suffix maxima for circular case.

**Pseudo Code**

```text
function maxSubarrayDivideConquer(nums)
    return helper(nums, 0, length(nums)-1).best
function helper(nums, L, R)
    if L == R
        return node(best=nums[L], sum=nums[L], prefix=nums[L], suffix=nums[L])
    mid = (L+R)//2
    left = helper(nums, L, mid)
    right = helper(nums, mid+1, R)
    sum = left.sum + right.sum
    prefix = max(left.prefix, left.sum + right.prefix)
    suffix = max(right.suffix, right.sum + left.suffix)
    best = max(left.best, right.best, left.suffix + right.prefix)
    return node(best, sum, prefix, suffix)
```

## Comparison

| Approach                 | Idea                                      | Time    | Space  | Recommended |
| ------------------------ | ----------------------------------------- | ------- | ------ | ----------- |
| Kadane (optimal)         | Max and min Kadane, use total - min       | O(n)    | O(1)   | Yes        |
| Brute Force (duplicate)  | Check all subarrays on duplicated array   | O(n^2)  | O(n)   | No         |
| Divide & Conquer         | Merge segment results (prefix/suffix)     | O(n)    | O(log n) stack | No (more complex)
