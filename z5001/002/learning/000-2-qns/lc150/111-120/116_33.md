# Title
Search in Rotated Sorted Array

## Difficulty
Medium

## Description
Given a sorted array rotated at an unknown pivot and a target value, return the index of target if found, otherwise return -1. All elements are unique.

## Examples

### Example 1
```text
Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4
Explanation: 0 is at index 4.
```

### Example 2
```text
Input: nums = [4,5,6,7,0,1,2], target = 3
Output: -1
Explanation: 3 is not present.
```

## Constraints
```text
1 <= nums.length <= 10^5
-10^9 <= nums[i], target <= 10^9
All elements are unique.
Expected time: O(log n) for optimal solution.
```

---

## Idea
Use modified binary search: at each step determine which half is sorted and decide which half may contain target.

---

## Pseudo Code
```text
function search(nums, target)
    left = 0
    right = length(nums) - 1
    while left <= right
        mid = floor((left + right) / 2)
        if nums[mid] == target
            return mid
        if nums[left] <= nums[mid]                  // left half is sorted
            if nums[left] <= target < nums[mid]
                right = mid - 1
            else
                left = mid + 1
        else                                       // right half is sorted
            if nums[mid] < target <= nums[right]
                left = mid + 1
            else
                right = mid - 1
    return -1
```

## Code Explanation

### Dry Run

| Step | left | right | mid | nums[mid] | Operation | Result |
| ---- | ---- | ----- | --- | --------- | --------- | ------ |
| 1    | 0    | 6     | 3   | 7         | nums[left]<=nums[mid] true; target 0 not in [4,7) | left = 4 |
| 2    | 4    | 6     | 5   | 1         | nums[left]<=nums[mid] true; target 0 in [0,1) | right = 4 |
| 3    | 4    | 4     | 4   | 0         | nums[mid]==target | return 4 |

## Other Patterns

### Pattern 1

**Idea**
Linear scan.

**Pseudo Code**
```text
function search_linear(nums, target)
    for i from 0 to length(nums)-1
        if nums[i] == target
            return i
    return -1
```

### Pattern 2

**Idea**
Find rotation pivot (minimum) with binary search, then binary search in the appropriate subarray.

**Pseudo Code**
```text
function find_pivot(nums)
    left = 0
    right = length(nums)-1
    while left < right
        mid = floor((left + right) / 2)
        if nums[mid] > nums[right]
            left = mid + 1
        else
            right = mid
    return left

function search_with_pivot(nums, target)
    n = length(nums)
    pivot = find_pivot(nums)
    left = 0
    right = n - 1
    while left <= right
        mid = floor((left + right) / 2)
        real_mid = (mid + pivot) % n
        if nums[real_mid] == target
            return real_mid
        if nums[real_mid] < target
            left = mid + 1
        else
            right = mid - 1
    return -1
```

## Comparison

| Approach        | Idea                                      | Time     | Space | Recommended |
| --------------- | ----------------------------------------- | -------- | ----- | ----------- |
| Modified Binary | Determine sorted half each step           | O(log n) | O(1)  | Yes         |
| Pivot + Binary  | Find rotation pivot then normal binary    | O(log n) | O(1)  | No (more steps) |
| Linear Scan     | Check each element                         | O(n)     | O(1)  | No          |
