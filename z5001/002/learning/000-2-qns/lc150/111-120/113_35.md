# Search Insert Position

## Difficulty
Easy

## Description
Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be inserted to maintain sorted order.

## Examples

### Example 1

```text
Input: nums = [1,3,5,6], target = 5
Output: 2
Explanation: 5 is found at index 2.
```

### Example 2

```text
Input: nums = [1,3,5,6], target = 2
Output: 1
Explanation: 2 would be inserted at index 1.
```

### Example 3

```text
Input: nums = [1,3,5,6], target = 7
Output: 4
Explanation: 7 would be inserted at the end (index 4).
```

## Constraints

```text
1 <= nums.length <= 10^4
-10^4 <= nums[i], target <= 10^4
nums is sorted in strictly increasing order
```

---

## Idea
Use binary search to find the target or the insertion index in O(log n).

---

## Pseudo Code

```text
function searchInsert(nums, target)
    low = 0
    high = length(nums) - 1
    while low <= high
        mid = low + (high - low) // 2
        if nums[mid] == target
            return mid
        if nums[mid] < target
            low = mid + 1
        else
            high = mid - 1
    return low
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log n) |
| Space Complexity | O(1) |

---

## Code Explanation

### Dry Run

| Step | low | high | mid | nums[mid] | Operation | Result |
| ---- | --- | ---- | --- | --------- | --------- | ------ |
| 1    | 0   | 3    | 1   | 3         | nums[mid] < target | low = mid + 1 => 2 |
| 2    | 2   | 3    | 2   | 5         | nums[mid] == target | return 2 |

## Other Patterns

### Pattern 1

**Idea**

Linear scan until element >= target.

**Pseudo Code**

```text
function searchInsertLinear(nums, target)
    for i from 0 to length(nums)-1
        if nums[i] >= target
            return i
    return length(nums)
```

### Pattern 2

**Idea**

Use language built-in binary-search / bisect utilities.

**Pseudo Code**

```text
function searchInsertBuiltin(nums, target)
    return lower_bound_index_using_library(nums, target)
```

## Comparison

| Approach          | Idea                                | Time     | Space | Recommended |
| ----------------- | ----------------------------------- | -------- | ----- | ----------- |
| Binary Search     | Classic divide-and-conquer search   | O(log n) | O(1)  | Yes         |
| Linear Scan       | Scan until nums[i] >= target        | O(n)     | O(1)  | No          |
| Built-in / Bisect | Use standard library lower_bound    | O(log n) | O(1)  | No (interview) |
