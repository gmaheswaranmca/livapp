# Kth Largest Element in an Array

## Difficulty
Medium

## Description
Find the k-th largest element in an unsorted array.

## Examples

### Example 1

```text
Input: nums = [3,2,1,5,6,4], k = 2
Output: 5
Explanation: The 2nd largest element is 5.
```

### Example 2

```text
Input: nums = [3,2,3,1,2,4,5,5,6], k = 4
Output: 4
Explanation: The 4th largest element is 4.
```

## Constraints

```text
1 <= k <= nums.length <= 10^5
-10^9 <= nums[i] <= 10^9
Time and memory limits require O(n log k) or O(n) average solutions
```

---

## Idea
Maintain a min-heap of size k so the heap root is the k-th largest.

---

## Pseudo Code

```text
function findKthLargest(nums, k)
    create empty minHeap
    for each num in nums
        minHeap.push(num)
        if minHeap.size() > k
            minHeap.pop()           // remove smallest in heap
    return minHeap.top()            // root is k-th largest
```

---

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(n log k)  |
| Space Complexity | O(k)        |

---

## Code Explanation

### Dry Run

| Step | State (minHeap contents) | Operation               | Result (root / comment) |
| ---- | ------------------------ | ----------------------- | ------------------------ |
| 1    | [3]                      | push 3                  | root=3                  |
| 2    | [2,3]                    | push 2                  | root=2                  |
| 3    | [1,3,2] -> pop -> [2,3]  | push 1; size>2 then pop | root=2                  |
| 4    | [2,5] -> pop -> [5,2]    | push 5; pop smallest   | root=2                  |
| 5    | [5,6] -> pop -> [6,5]    | push 6; pop smallest   | root=5                  |
| 6    | [4,6] -> pop -> [6,4]    | push 4; pop smallest   | root=5 (final)          |

## Other Patterns

### Pattern 1

**Idea**

Use Quickselect (partition-based selection) average O(n).

**Pseudo Code**

```text
function findKthLargest_quickselect(nums, k)
    targetIndex = k - 1
    left = 0
    right = nums.length - 1
    while left <= right
        pivotIndex = partitionByGreater(nums, left, right)
        if pivotIndex == targetIndex
            return nums[pivotIndex]
        if pivotIndex < targetIndex
            left = pivotIndex + 1
        else
            right = pivotIndex - 1

function partitionByGreater(nums, left, right)
    pivot = nums[right]
    store = left
    for i from left to right - 1
        if nums[i] > pivot
            swap nums[store] and nums[i]
            store = store + 1
    swap nums[store] and nums[right]
    return store
```

### Pattern 2

**Idea**

Sort the array and pick element at index n-k.

**Pseudo Code**

```text
function findKthLargest_sort(nums, k)
    sort nums in ascending order
    return nums[nums.length - k]
```

### Pattern 3

**Idea**

Build a max-heap and extract k-1 times.

**Pseudo Code**

```text
function findKthLargest_maxheap(nums, k)
    build maxHeap from nums
    repeat k - 1 times
        maxHeap.pop()
    return maxHeap.top()
```

## Comparison

| Approach    | Idea                           | Time           | Space | Recommended |
| ----------- | ------------------------------ | -------------- | ----- | ----------- |
| Min-heap    | Maintain min-heap of size k    | O(n log k)     | O(k)  | Yes         |
| Quickselect | Partition to target index      | O(n) avg, O(n^2) worst | O(1) | Yes (if average-case acceptable) |
| Sort        | Sort and index                 | O(n log n)     | O(1)/O(n) | No      |
| Max-heap    | Build max-heap, pop k-1 times  | O(n + k log n) | O(n)  | No          |
