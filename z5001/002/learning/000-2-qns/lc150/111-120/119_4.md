# Median of Two Sorted Arrays

## Difficulty
Hard

## Description
Find the median of two sorted arrays nums1 and nums2 in O(log(min(m,n))) time without fully merging them.

## Examples

### Example 1

```text
Input: nums1 = [1,3], nums2 = [2]
Output: 2.0
Explanation: Combined sorted array = [1,2,3], median = 2
```

### Example 2

```text
Input: nums1 = [1,2], nums2 = [3,4]
Output: 2.5
Explanation: Combined sorted array = [1,2,3,4], median = (2+3)/2 = 2.5
```

## Constraints

```text
0 <= len(nums1), len(nums2)
nums1 and nums2 are sorted in non-decreasing order
Total length >= 1
Elements fit in 64-bit signed range
Expected time: O(log(min(m,n)))
```

---

## Idea
Binary-search partition the smaller array to ensure left partitions contain half of combined elements and compute median from neighbors.

---

## Pseudo Code

```text
function findMedianSortedArrays(nums1, nums2)
    if len(nums1) > len(nums2) then
        swap nums1 and nums2
    x = len(nums1)
    y = len(nums2)
    low = 0
    high = x
    while low <= high
        partitionX = (low + high) // 2
        partitionY = (x + y + 1) // 2 - partitionX
        maxLeftX = if partitionX == 0 then -INF else nums1[partitionX - 1]
        minRightX = if partitionX == x then +INF else nums1[partitionX]
        maxLeftY = if partitionY == 0 then -INF else nums2[partitionY - 1]
        minRightY = if partitionY == y then +INF else nums2[partitionY]
        if maxLeftX <= minRightY and maxLeftY <= minRightX
            if (x + y) % 2 == 0
                return (max(maxLeftX, maxLeftY) + min(minRightX, minRightY)) / 2.0
            else
                return max(maxLeftX, maxLeftY)
        else if maxLeftX > minRightY
            high = partitionX - 1
        else
            low = partitionX + 1
    // unreachable if inputs valid
    return 0.0
```

## Code Explanation

### Dry Run

| Step | partitionX | partitionY | maxLeftX | minRightX | maxLeftY | minRightY | Condition checked | Action / Result |
| ---- | ---------- | ---------- | -------- | --------- | -------- | --------- | ----------------- | --------------- |
| 1    | 1          | 1          | 1        | 3         | 2        | INF       | maxLeftX<=minRightY (1<=INF) and maxLeftY<=minRightX (2<=3) | Valid partition, (3 elements odd) median = max(1,2)=2 |
| (Example1 result) | | | | | | | | 2.0 |

If even total length, median computed as average of max(lefts) and min(rights).

## Other Patterns

### Pattern 1

**Idea**

Merge until reaching median position (two-pointer).

**Pseudo Code**

```text
function findMedianByMerge(nums1, nums2)
    i = 0
    j = 0
    m = len(nums1)
    n = len(nums2)
    target = (m + n) // 2
    prev = 0
    curr = 0
    for k from 0 to target
        prev = curr
        if i < m and (j >= n or nums1[i] <= nums2[j])
            curr = nums1[i]
            i = i + 1
        else
            curr = nums2[j]
            j = j + 1
    if (m + n) % 2 == 1
        return curr
    else
        return (prev + curr) / 2.0
```

### Pattern 2

**Idea**

Find k-th element using recursive binary reduction (k = (m+n+1)/2 and k+1 if even).

**Pseudo Code**

```text
function findKth(A, B, k)
    if len(A) == 0 then return B[k-1]
    if len(B) == 0 then return A[k-1]
    if k == 1 then return min(A[0], B[0])
    i = min(len(A), k//2)
    j = min(len(B), k//2)
    if A[i-1] <= B[j-1]
        return findKth(A[i:], B, k - i)
    else
        return findKth(A, B[j:], k - j)

function findMedianByKth(nums1, nums2)
    total = len(nums1) + len(nums2)
    if total % 2 == 1
        return findKth(nums1, nums2, (total+1)//2)
    else
        a = findKth(nums1, nums2, total//2)
        b = findKth(nums1, nums2, total//2 + 1)
        return (a + b) / 2.0
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Binary Search Partition | Partition smaller array with binary search | O(log(min(m,n))) | O(1) | Yes |
| Merge Until Median | Two-pointer merge until middle | O(m+n) | O(1) | No (inefficient for large arrays) |
| K-th Element (Recursive) | Remove k/2 elements each step recursively | O(log(m+n)) average but O(log(m)+log(n)) variant | O(1) or O(log k) recursion | Yes (alternative) |
