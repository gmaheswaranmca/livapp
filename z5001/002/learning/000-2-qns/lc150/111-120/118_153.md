# Find Minimum in Rotated Sorted Array

## Difficulty
Medium

## Description
Given a rotated sorted array of unique integers, find the minimum element. The array was originally sorted in ascending order and then rotated between 0 and n-1 times.

## Examples

### Example 1

```text
Input: [3,4,5,1,2]
Output: 1
Explanation: Array rotated; minimum at index 3.
```

### Example 2

```text
Input: [1,2,3,4,5]
Output: 1
Explanation: Not rotated; first element is minimum.
```

### Example 3

```text
Input: [2]
Output: 2
Explanation: Single element.
```

## Constraints

```text
1 <= n <= 10^5
-10^4 <= nums[i] <= 10^4
All elements are unique.
Array is a rotation of a sorted ascending array.
```

---

## Idea
Use binary search to locate pivot where order breaks; minimum is at pivot.

---

## Pseudo Code

```text
function findMin(nums)
    if nums is empty then return null
    low = 0
    high = length(nums) - 1
    while low < high
        mid = low + (high - low) // 2
        if nums[mid] > nums[high] then
            low = mid + 1
        else
            high = mid
    return nums[low]
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log n) |
| Space Complexity | O(1) |

## Code Explanation

### Dry Run

| Step | low | high | mid | nums[mid] | nums[high] | Action                      | Result      |
| ---- | --- | ---- | --- | --------- | ---------- | --------------------------- | ----------- |
| 1    | 0   | 4    | 2   | 5         | 2          | nums[mid] > nums[high]      | low = 3     |
| 2    | 3   | 4    | 3   | 1         | 2          | nums[mid] <= nums[high]     | high = 3    |
| 3    | 3   | 3    | 3   | 1         | 1          | loop ends                   | return 1    |

## Other Patterns

### Pattern 1

**Idea**

Linear scan to find first element smaller than previous.

**Pseudo Code**

```text
function findMinLinear(nums)
    if nums is empty then return null
    for i from 1 to length(nums)-1
        if nums[i] < nums[i-1] then return nums[i]
    return nums[0]
```

### Pattern 2

**Idea**

Recursive binary search to find pivot (divide and conquer).

**Pseudo Code**

```text
function findMinRecursive(nums)
    return helper(nums, 0, length(nums)-1)

function helper(nums, low, high)
    if low == high then return nums[low]
    mid = low + (high - low) // 2
    if nums[mid] > nums[high] then
        return helper(nums, mid+1, high)
    else
        return helper(nums, low, mid)
```
