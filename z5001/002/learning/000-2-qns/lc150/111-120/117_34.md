# Find First and Last Position of Element in Sorted Array

## Difficulty
Medium

## Description
Given a sorted array of integers and a target value, find the starting and ending index of the target value. If target is not found, return [-1, -1]. Use logarithmic time.

## Examples

### Example 1

```text
Input: nums = [5,7,7,8,8,10], target = 8
Output: [3,4]
Explanation: 8 appears from index 3 to 4.
```

### Example 2

```text
Input: nums = [5,7,7,8,8,10], target = 6
Output: [-1,-1]
Explanation: 6 does not exist in the array.
```

## Constraints

```text
0 <= nums.length <= 10^5
-10^9 <= nums[i], target <= 10^9
nums is sorted in non-decreasing order
Expected time: O(log n)
```

---

## Idea
Perform two binary searches: one to find the leftmost index of target and one to find the rightmost index.

---

## Pseudo Code

```text
function searchRange(nums, target)
    if nums is empty
        return [-1, -1]
    left = findFirst(nums, target)
    if left == -1
        return [-1, -1]
    right = findLast(nums, target)
    return [left, right]

function findFirst(nums, target)
    low = 0
    high = length(nums) - 1
    result = -1
    while low <= high
        mid = low + (high - low) // 2
        if nums[mid] == target
            result = mid
            high = mid - 1
        else if nums[mid] < target
            low = mid + 1
        else
            high = mid - 1
    return result

function findLast(nums, target)
    low = 0
    high = length(nums) - 1
    result = -1
    while low <= high
        mid = low + (high - low) // 2
        if nums[mid] == target
            result = mid
            low = mid + 1
        else if nums[mid] < target
            low = mid + 1
        else
            high = mid - 1
    return result
```

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | left search: low=0 high=5 mid=2 nums[mid]=7 target=8 | nums[mid]<target -> low=mid+1 | low=3 high=5 |
| 2    | left search: low=3 high=5 mid=4 nums[mid]=8 target=8 | found -> result=4 high=mid-1 | result=4 low=3 high=3 |
| 3    | left search: low=3 high=3 mid=3 nums[mid]=8 target=8 | found -> result=3 high=mid-1 | result=3 low=3 high=2 -> loop ends; left=3 |
| 4    | right search: low=0 high=5 mid=2 nums[mid]=7 target=8 | nums[mid]<target -> low=mid+1 | low=3 high=5 |
| 5    | right search: low=3 high=5 mid=4 nums[mid]=8 target=8 | found -> result=4 low=mid+1 | result=4 low=5 high=5 |
| 6    | right search: low=5 high=5 mid=5 nums[mid]=10 target=8 | nums[mid]>target -> high=mid-1 | low=5 high=4 -> loop ends; right=4 |
| 7    | Final | return [left, right] | [3,4] |

## Other Patterns

### Pattern 1

**Idea**
Linear scan to find first and last occurrence.

**Pseudo Code**

```text
function searchRangeLinear(nums, target)
    start = -1
    end = -1
    for i from 0 to length(nums)-1
        if nums[i] == target and start == -1
            start = i
        if nums[i] == target
            end = i
    return [start, end]
```

### Pattern 2

**Idea**
Use language built-in lower_bound/upper_bound (bisect) to get indices.

**Pseudo Code**

```text
function searchRangeBisect(nums, target)
    left = lower_bound(nums, target)
    if left == length(nums) or nums[left] != target
        return [-1, -1]
    right = upper_bound(nums, target) - 1
    return [left, right]
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Two binary searches | Find leftmost and rightmost via two binary searches | O(log n) | O(1) | Yes |
| Linear scan | Single pass to record first and last | O(n) | O(1) | No (when n large) |
| Bisect / lower/upper bound | Use built-in binary search helpers | O(log n) | O(1) | Yes (if available) |
