# Find Peak Element

## Difficulty
Medium

## Description
Given an integer array nums, find and return the index of any peak element. A peak element is an element that is strictly greater than its neighbors. For boundary elements, only one neighbor is considered. Array may contain multiple peaks; return any valid peak index.

## Examples

### Example 1

```text
Input: [1,2,3,1]
Output: 2
Explanation: nums[2]=3 is a peak (3>2 and 3>1).
```

### Example 2

```text
Input: [1,2]
Output: 1
Explanation: nums[1]=2 is a peak (only right neighbor doesn't exist).
```

### Example 3

```text
Input: [3,2,1]
Output: 0
Explanation: nums[0]=3 is a peak (only left neighbor doesn't exist).
```

## Constraints

```text
1 <= nums.length <= 10^5
-2^31 <= nums[i] <= 2^31-1
nums[i] may not be unique
Any valid peak index can be returned
```

---

## Idea
Binary search on the slope: move toward the side that contains a peak using nums[mid] vs nums[mid+1].

---

## Pseudo Code

```text
function findPeak(nums)
    if nums is empty then
        return -1
    set left = 0
    set right = length(nums) - 1
    while left < right
        set mid = floor((left + right) / 2)
        if nums[mid] > nums[mid + 1] then
            set right = mid
        else
            set left = mid + 1
    return left
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log n) |
| Space Complexity | O(1) |

---

## Code Explanation

### Dry Run

| Step | State (left,right,mid) | Operation | Result |
| ---- | ---------------------- | --------- | ------ |
| 1    | (0,3,1)                | nums[1]=2 <= nums[2]=3 so left=mid+1 | (2,3) |
| 2    | (2,3,2)                | nums[2]=3 > nums[3]=1 so right=mid | (2,2) |
| 3    | (2,2,2)                | left==right stop | return 2 |

1. Initialize left and right to cover the whole array.
2. At each step compare nums[mid] with nums[mid+1].
3. If descending at mid (nums[mid] > nums[mid+1]) a peak exists at mid or left side, move right=mid.
4. Otherwise ascending at mid, move left=mid+1.
5. Loop ends when left==right; that index is a peak.

## Other Patterns

### Pattern 1

**Idea**

Linear scan to find first element greater than its next neighbor.

**Pseudo Code**

```text
function findPeakLinear(nums)
    if nums is empty then
        return -1
    for i from 0 to length(nums)-2
        if nums[i] > nums[i+1] then
            return i
    return length(nums)-1
```
