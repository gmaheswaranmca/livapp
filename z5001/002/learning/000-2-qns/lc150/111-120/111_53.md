# Maximum Subarray

## Difficulty
Easy

## Description
Find the contiguous subarray (containing at least one number) which has the largest sum and return its sum.

## Examples

### Example 1

```text
Input: [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: [4,-1,2,1] has the largest sum = 6.
```

### Example 2

```text
Input: [1]
Output: 1
Explanation: Single element array.
```

### Example 3

```text
Input: [-3,-2,-5]
Output: -2
Explanation: Choose the maximum single element = -2.
```

## Constraints

```text
1 <= nums.length <= 3 * 10^4
-10^5 <= nums[i] <= 10^5
Answer fits in 32-bit signed integer
```

---

## Idea
Kadane's algorithm: track current subarray sum ending at i and global maximum, update both in one pass.

---

## Pseudo Code

```text
function maxSubarray(nums)
    n := length(nums)
    if n == 0 then return 0
    current := nums[0]
    maximum := nums[0]
    for i from 1 to n-1
        current := max(nums[i], current + nums[i])
        maximum := max(maximum, current)
    return maximum
```

## Other Patterns

### Pattern 1

**Idea**
Divide and conquer: max subarray is either left, right, or crossing middle.

**Pseudo Code**

```text
function maxSubarrayDivide(nums, l, r)
    if l == r then return nums[l]
    m := (l + r) // 2
    leftMax := maxSubarrayDivide(nums, l, m)
    rightMax := maxSubarrayDivide(nums, m+1, r)
    leftSuffix := -inf
    sum := 0
    for i from m down to l
        sum := sum + nums[i]
        leftSuffix := max(leftSuffix, sum)
    rightPrefix := -inf
    sum := 0
    for i from m+1 to r
        sum := sum + nums[i]
        rightPrefix := max(rightPrefix, sum)
    cross := leftSuffix + rightPrefix
    return max(leftMax, rightMax, cross)
```

### Pattern 2

**Idea**
Prefix sums: maintain min prefix sum seen so far; current max = prefix - minPrefix.

**Pseudo Code**

```text
function maxSubarrayPrefix(nums)
    minPrefix := 0
    prefix := 0
    maximum := -inf
    for each x in nums
        prefix := prefix + x
        maximum := max(maximum, prefix - minPrefix)
        minPrefix := min(minPrefix, prefix)
    return maximum
```

### Pattern 3

**Idea**
Brute force: check all subarrays (useful for small n or validation).

**Pseudo Code**

```text
function maxSubarrayBrute(nums)
    n := length(nums)
    maximum := -inf
    for i from 0 to n-1
        sum := 0
        for j from i to n-1
            sum := sum + nums[j]
            maximum := max(maximum, sum)
    return maximum
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Kadane's | Track best ending here | O(n) | O(1) | Yes |
| Divide & Conquer | Recurse left/right/cross | O(n log n) | O(log n) recursion | No |
| Prefix Sums | Use min prefix sum | O(n) | O(1) | Yes |
| Brute Force | Test all subarrays | O(n^2) | O(1) | No |
