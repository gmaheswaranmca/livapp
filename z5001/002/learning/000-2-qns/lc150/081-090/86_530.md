# Minimum Absolute Difference in BST

## Difficulty
Easy

## Description
Given the root of a Binary Search Tree (BST), return the minimum absolute difference between values of any two nodes.

## Examples

### Example 1
```text
Input: [4,2,6,1,3]
Output: 1
Explanation: Inorder traversal gives sorted values [1,2,3,4,6]. Minimum adjacent difference is 1.
```

### Example 2
```text
Input: [1,0,48,null,null,12,49]
Output: 1
Explanation: Sorted values [0,1,12,48,49], minimum adjacent difference is 1.
```

## Constraints
```text
The number of nodes is in the range [2, 10^4].
0 <= Node.val <= 10^5 (or values may be negative depending on variant).
Tree is a valid Binary Search Tree.
```

---

## Idea
Inorder traversal of BST yields sorted values, so minimum absolute difference occurs between adjacent inorder values.

---

## Pseudo Code
```text
function minDiffInBST(root)
    prev <- null
    minDiff <- +infinity
    function inorder(node)
        if node is null then return
        inorder(node.left)
        if prev is not null then
            diff <- abs(node.val - prev)
            if diff < minDiff then minDiff <- diff
        prev <- node.val
        inorder(node.right)
    inorder(root)
    return minDiff
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h) (recursion stack), h = tree height |

### Dry Run

| 1    | (null, +inf)          | Visit 1   | prev=1, minDiff=+inf |

| 3    | (2, 1)                | Visit 3   | diff=1 -> minDiff=1, prev=3 |
| 4    | (3, 1)                | Visit 4   | diff=1 -> minDiff=1, prev=4 |

## Other Patterns

### Pattern 1

**Idea**
Iterative inorder traversal using an explicit stack, track prev value and minDiff.

**Pseudo Code**
```text
function minDiffInBST(root)
    prev <- null
    minDiff <- +infinity
    stack <- empty stack
    node <- root
    while node is not null or stack not empty do
        while node is not null do
            stack.push(node)
            node <- node.left
        node <- stack.pop()
        if prev is not null then
            diff <- abs(node.val - prev)
            if diff < minDiff then minDiff <- diff
        prev <- node.val
        node <- node.right
    return minDiff
```

### Pattern 2

**Idea**
Collect inorder traversal into an array then compute minimum adjacent difference.

**Pseudo Code**
```text
function minDiffInBST(root)
    arr <- empty list
    function inorder(node)
        if node is null then return
        inorder(node.left)
        arr.append(node.val)
        inorder(node.right)
    inorder(root)
    minDiff <- +infinity
    for i from 1 to arr.length-1 do
        diff <- abs(arr[i] - arr[i-1])
        if diff < minDiff then minDiff <- diff
    return minDiff
```

## Comparison

| Approach       | Idea                                  | Time  | Space       | Recommended |
| -------------- | ------------------------------------- | ----- | ----------- | ----------- |
| Recursive Inorder | Track prev during recursion           | O(n)  | O(h)        | Yes        |
| Iterative Stack   | Explicit stack for inorder            | O(n)  | O(h)        | Yes        |
| Inorder to Array  | Store all values then scan            | O(n)  | O(n)        | No         |
