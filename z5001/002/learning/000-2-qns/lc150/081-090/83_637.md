# Average of Levels in Binary Tree

## Difficulty
Easy

## Description
Given the root of a binary tree, return an array where each element is the average value of the nodes on that level (floating point).

## Examples

### Example 1

```text
Input: [3,9,20,null,null,15,7]
Output: [3.0,14.5,11.0]
Explanation: Level 0 average = 3.0, Level 1 average = (9+20)/2 = 14.5, Level 2 average = (15+7)/2 = 11.0
```

## Constraints

```text
The number of nodes in the tree is in the range [0, 10^4].
-2^31 <= Node.val <= 2^31-1
Answers within 10^-5 of the actual value are accepted.
```

---

## Idea
Traverse the tree level by level (BFS), compute sum and count for each level, append sum/count to result.

---

## Pseudo Code

```text
function averageOfLevels(root)
    if root == null then return []
    result = []
    queue = new Queue()
    enqueue(queue, root)
    while queue is not empty
        levelSum = 0
        levelCount = size(queue)
        for i from 1 to levelCount
            node = dequeue(queue)
            levelSum = levelSum + node.val
            if node.left != null then enqueue(queue, node.left)
            if node.right != null then enqueue(queue, node.right)
        append(result, levelSum / levelCount)
    return result
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(w) where w is max width of tree (O(n) worst-case) |

## Other Patterns

### Pattern 1

**Idea**

Depth-first traversal accumulating sum and count per level, then compute averages.

**Pseudo Code**

```text
function averageOfLevelsDFS(root)
    if root == null then return []
    sums = []
    counts = []
    function dfs(node, depth)
        if node == null then return
        if depth >= length(sums) then
            append(sums, 0)
            append(counts, 0)
        sums[depth] = sums[depth] + node.val
        counts[depth] = counts[depth] + 1
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    dfs(root, 0)
    result = []
    for i from 0 to length(sums)-1
        append(result, sums[i] / counts[i])
    return result
```

| Approach | Idea                                          | Time | Space        | Recommended |
| -------- | --------------------------------------------- | ---- | ------------ | ----------- |
| BFS      | Level-order traversal computing sum/count     | O(n) | O(w)         | Yes         |
| DFS      | Accumulate sums and counts per depth, then avg| O(n) | O(d) (recursion) | Yes (when recursion ok) |
