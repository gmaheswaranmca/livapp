# Kth Smallest Element in a BST

## Difficulty
Medium

## Description
Given the root of a binary search tree (BST) and an integer k, return the kth smallest value (1-indexed) of all the nodes in the tree.

## Examples

### Example 1

```text
Input: root = [3,1,4,null,2], k = 1
Output: 1
Explanation: Inorder traversal yields [1,2,3,4]; the 1st smallest is 1.
```

### Example 2

```text
Input: root = [5,3,6,2,4,null,null,1], k = 3
Output: 3
Explanation: Inorder traversal yields [1,2,3,4,5,6]; the 3rd smallest is 3.
```

## Constraints

```text
The number of nodes in the tree is n.
1 <= k <= n <= 10^4
-10^5 <= Node.val <= 10^5
The tree is a valid Binary Search Tree.
```

---

## Idea
Perform an inorder traversal (left, node, right) and stop once the k-th node is visited.

---

## Pseudo Code

```text
function kthSmallest(root, k)
    stack = empty stack
    current = root
    count = 0
    while stack not empty OR current != null
        while current != null
            push stack current
            current = current.left
        node = pop stack
        count = count + 1
        if count == k
            return node.val
        current = node.right
    return null
```

---

## Complexity

| Metric           | Value    |
| ---------------- | -------- |
| Time Complexity  | O(h + k) |
| Space Complexity | O(h)     |

(h = tree height)

---

## Code Explanation

### Dry Run

| Step | State (stack, current)      | Operation                         | Result         |
| ---- | --------------------------- | --------------------------------- | -------------- |
| 1    | ([], 3)                     | push 3 -> go left                 | stack=[3], current=1 |
| 2    | ([3], 1)                    | push 1 -> go left                 | stack=[3,1], current=null |
| 3    | ([3,1], null)               | pop -> visit 1 (count=1)          | return 1 (k=1) |

1. Initialize an empty stack, set current=root and count=0.
2. Push left children until null, then pop, increment count and check k.
3. If popped node is k-th, return its value; else set current to node.right and repeat.

## Other Patterns

### Pattern 1

**Idea**

Recursive inorder traversal with early stop using a counter.

**Pseudo Code**

```text
function kthSmallest(root, k)
    count = 0
    result = null
    function inorder(node)
        if node == null OR result != null
            return
        inorder(node.left)
        count = count + 1
        if count == k
            result = node.val
            return
        inorder(node.right)
    inorder(root)
    return result
```

### Pattern 2

**Idea**

Augment each node with subtree sizes to find k-th smallest in O(h).

**Pseudo Code**

```text
function kthSmallest(root, k)
    node = root
    while node != null
        leftSize = node.left != null ? node.left.size : 0
        if k == leftSize + 1
            return node.val
        if k <= leftSize
            node = node.left
        else
            k = k - (leftSize + 1)
            node = node.right
    return null
```

## Comparison

| Approach           | Idea                                 | Time       | Space   | Recommended |
| ------------------ | ------------------------------------ | ---------- | ------- | ----------- |
| Iterative Inorder  | Inorder with stack, stop at k        | O(h + k)   | O(h)    | Yes         |
| Recursive Inorder  | Recursive inorder, early stop        | O(h + k)   | O(h)    | Yes         |
| Augmented BST      | Use subtree sizes to jump to k       | O(h)       | O(h)    | Yes (many queries) |
