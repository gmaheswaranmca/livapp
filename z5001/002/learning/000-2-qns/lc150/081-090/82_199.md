# Binary Tree Right Side View

## Difficulty
Medium

## Description
Return the list of node values visible when looking at a binary tree from the right side (one value per depth level, the rightmost node at that level).

## Examples

### Example 1
```text
Input: [1,2,3,null,5,null,4]
Output: [1,3,4]
Explanation: Level-order: level1->[1] pick 1, level2->[2,3] pick 3, level3->[5,4] pick 4
```

## Constraints
```text
0 <= number of nodes <= 10^4
-10^5 <= Node.val <= 10^5
Tree may be skewed; aim for O(n) time and O(n) auxiliary space
```

---

## Idea
Level-order traverse the tree and collect the last node value of each level.

---

## Pseudo Code
```text
function rightSideView(root)
    if root is null
        return []

    result <- empty list
    queue <- empty queue
    enqueue(queue, root)

    while queue is not empty
        levelSize <- size(queue)
        for i from 1 to levelSize
            node <- dequeue(queue)
            if node.left is not null
                enqueue(queue, node.left)
            if node.right is not null
                enqueue(queue, node.right)
            if i == levelSize
                append(result, node.val)

    return result
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

## Code Explanation

### Dry Run

| Step | Queue (front→back)       | Operation                          | Result |
| ---- | ------------------------ | ---------------------------------- | ------ |
| 1    | [1]                      | process levelSize=1, pick 1        | [1]    |
| 2    | [2,3]                    | process levelSize=2, pick 3        | [1,3]  |
| 3    | [5,4]                    | process levelSize=2, pick 4        | [1,3,4]|

## Other Patterns

### Pattern 1

**Idea**

Depth-first search prioritizing right child and record first node visited at each depth.

**Pseudo Code**

```text
function rightSideViewDFS(root)
    result <- empty list
    function dfs(node, depth)
        if node is null
            return
        if depth == size(result)
            append(result, node.val)
        dfs(node.right, depth + 1)
        dfs(node.left, depth + 1)
    dfs(root, 0)
    return result
```

### Pattern 2

**Idea**

BFS but enqueue right child before left child and take first node of each level.

**Pseudo Code**

```text
function rightSideViewBFSRightFirst(root)
    if root is null
        return []
    result <- empty list
    queue <- empty queue
    enqueue(queue, root)
    while queue is not empty
        levelSize <- size(queue)
        for i from 1 to levelSize
            node <- dequeue(queue)
            if i == 1
                append(result, node.val)
            if node.right is not null
                enqueue(queue, node.right)
            if node.left is not null
                enqueue(queue, node.left)
    return result
```

## Comparison

| Approach               | Idea                                  | Time | Space | Recommended |
| ---------------------- | ------------------------------------- | ---- | ----- | ----------- |
| BFS (level-order)      | Collect last node of each level       | O(n) | O(n)  | Yes         |
| DFS (right-first)      | Visit right child first; record first node per depth | O(n) | O(h)  | Yes (if recursion stack ok) |
| BFS (right-first push) | Enqueue right before left; take first per level | O(n) | O(n)  | No (equivalent to DFS semantics) |
