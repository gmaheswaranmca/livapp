# Binary Tree Zigzag Level Order Traversal

## Difficulty
Medium

## Description
Given the root of a binary tree, return the level order traversal of its nodes' values in zigzag order (left-to-right for level 0, right-to-left for level 1, and so on).

## Examples

### Example 1

```text
Input: [3,9,20,null,null,15,7]
Output: [[3],[20,9],[15,7]]
Explanation: Level 0 left->right [3], level 1 right->left [20,9], level 2 left->right [15,7].
```

### Example 2

```text
Input: []
Output: []
Explanation: Empty tree returns empty list.
```

### Example 3

```text
Input: [1]
Output: [[1]]
Explanation: Single node.
```

## Constraints

```text
0 <= number of nodes <= 2000
-100 <= Node.val <= 100
```

---

## Idea
BFS level-order traversal while toggling a boolean to reverse values of alternate levels.

---

## Pseudo Code

```text
function zigzagLevelOrder(root)
    if root is null then
        return []
    result <- []
    queue <- new Queue()
    enqueue(queue, root)
    leftToRight <- true
    while queue is not empty
        levelSize <- size(queue)
        levelVals <- new List()
        for i from 1 to levelSize
            node <- dequeue(queue)
            if leftToRight then
                append(levelVals, node.val)
            else
                insertAtFront(levelVals, node.val)
            if node.left is not null then
                enqueue(queue, node.left)
            if node.right is not null then
                enqueue(queue, node.right)
        append(result, levelVals)
        leftToRight <- not leftToRight
    return result
```

| 2    | [9,20]        | process level rightToLeft; collect [20,9]; enqueue 15,7 | [[3],[20,9]] |
| 3    | [15,7]        | process level leftToRight; collect [15,7]; enqueue none | [[3],[20,9],[15,7]] |

## Other Patterns

### Pattern 1

**Idea**
DFS recursion collecting nodes per depth and inserting values at front for odd depths.

**Pseudo Code**

```text
function zigzagLevelOrderDFS(root)
    result <- []
    function dfs(node, depth)
        if node is null then
            return
        if depth >= size(result) then
            append(result, new List())
        if depth % 2 == 0 then
            append(result[depth], node.val)
        else
            insertAtFront(result[depth], node.val)
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    dfs(root, 0)
    return result
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| BFS (queue) | Level-order with toggle and per-level reversal via insertAtFront | O(n) | O(n) | Yes |
| DFS (recursion) | Depth-first collect per level and insert at front for odd depths | O(n) | O(n) (recursion stack) | Yes |
