# 98. Validate Binary Search Tree

## Difficulty
Easy

## Description
Determine whether a binary tree is a valid Binary Search Tree (BST). A BST requires every node's left subtree values to be strictly less than the node's value and every node's right subtree values to be strictly greater than the node's value.

## Examples

### Example 1

```text
Input: [2,1,3]
Output: true
Explanation: 1 < 2 < 3, tree satisfies BST rules.
```

### Example 2

```text
Input: [5,1,4,null,null,3,6]
Output: false
Explanation: 3 is in the right subtree of 5 but 3 < 5, violates BST rules.
```

## Constraints

```text
0 <= number of nodes <= 10^4
Node values are 32-bit signed integers
Use long/infinite bounds to avoid overflow when comparing extremes
```

---

## Idea
DFS recursion carrying a valid (low, high) range for each node: node.val must satisfy low < node.val < high.

---

## Pseudo Code

```text
function isValidBST(root)
    return validate(root, -INF, +INF)

function validate(node, low, high)
    if node == null return true
    if node.val <= low or node.val >= high return false
    if not validate(node.left, low, node.val) return false
    if not validate(node.right, node.val, high) return false
    return true
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h)   |

---

## Code Explanation

### Dry Run

| Step | State                              | Operation                          | Result |
| ---- | ---------------------------------- | ---------------------------------- | ------ |
| 1    | node=2, range=(-INF, +INF)         | 2 in range?                         | yes    |
| 2    | go left -> node=1, range=(-INF,2)  | 1 in range?                         | yes    |
| 3    | left of 1 is null                  | return true                         | true   |
| 4    | right of 1 is null                 | return true                         | true   |
| 5    | back to 2, go right -> node=3      | 3 in range?(2,+INF)                 | yes    |
| 6    | left/right of 3 null               | return true                         | true   |
| 7    | all checks passed                  | final result                        | true   |

## Other Patterns

### Pattern 1

**Idea**
Inorder traversal yields strictly increasing sequence for a valid BST.

**Pseudo Code**

```text
function isValidBST_Inorder(root)
    prev = -INF
    stack = empty stack
    node = root
    while node != null or stack not empty
        while node != null
            push node to stack
            node = node.left
        node = pop stack
        if node.val <= prev return false
        prev = node.val
        node = node.right
    return true
```

### Pattern 2

**Idea**
Recursive inorder with a passed reference to previous value.

**Pseudo Code**

```text
function isValidBST_RecInorder(root)
    prev = -INF_REFERENCE
    return inorder(root, prev)

function inorder(node, prev)
    if node == null return true
    if not inorder(node.left, prev) return false
    if node.val <= prev.value return false
    prev.value = node.val
    if not inorder(node.right, prev) return false
    return true
```

## Comparison

| Approach        | Idea                                 | Time | Space | Recommended |
| --------------- | ------------------------------------ | ---- | ----- | ----------- |
| DFS range       | Validate each node within (low,high) | O(n) | O(h)  | Yes         |
| Inorder (iter)  | Check strictly increasing sequence   | O(n) | O(h)  | Yes         |
| Inorder (rec)   | Recursive inorder with prev pointer  | O(n) | O(h)  | No (stack depth)
