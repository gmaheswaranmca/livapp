# Number of Islands

## Difficulty
Medium

## Description
Given a 2D grid of '1's (land) and '0's (water), count the number of connected islands. Cells connect horizontally and vertically.

## Examples

### Example 1

```text
Input: grid = [["1","1","0"],["1","0","0"],["0","0","1"]]
Output: 2
Explanation: There are two connected groups of '1's: one at top-left and one at bottom-right.
```

## Constraints

```text
m == grid.length
n == grid[i].length
1 <= m, n <= 300
grid[i][j] is '0' or '1'
```

---

## Idea
Traverse the grid; when a '1' is found, increment count and flood-fill (DFS/BFS) to mark the entire island as visited.

---

## Pseudo Code

```text
function numIslands(grid)
    if grid is empty return 0
    rows <- number of rows in grid
    cols <- number of columns in grid
    count <- 0
    for r from 0 to rows-1
        for c from 0 to cols-1
            if grid[r][c] == '1'
                count <- count + 1
                dfsMark(grid, r, c, rows, cols)
    return count

function dfsMark(grid, r, c, rows, cols)
    if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1' return
    grid[r][c] <- '0'
    dfsMark(grid, r-1, c, rows, cols)
    dfsMark(grid, r+1, c, rows, cols)
    dfsMark(grid, r, c-1, rows, cols)
    dfsMark(grid, r, c+1, rows, cols)
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(m * n) worst-case recursion stack |

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | grid = [["1","1","0"],["1","0","0"],["0","0","1"]] | start iterate at (0,0) finds '1' | count=1; call dfsMark(0,0) |
| 2    | during dfsMark | mark (0,0)->'0', recurse to (0,1),(1,0) | grid = [["0","0","0"],["0","0","0"],["0","0","1"]] |
| 3    | continue iterate | skip visited cells, reach (2,2) finds '1' | count=2; call dfsMark(2,2) |
| 4    | during dfsMark | mark (2,2)->'0' | grid = [["0","0","0"],["0","0","0"],["0","0","0"]] |
| 5    | finish | all cells processed | return 2 |

## Other Patterns

### Pattern 2

**Idea**

Iterative BFS flood-fill using a queue.

**Pseudo Code**

```text
function numIslandsBFS(grid)
    if grid is empty return 0
    rows <- number of rows in grid
    cols <- number of columns in grid
    count <- 0
    for r from 0 to rows-1
        for c from 0 to cols-1
            if grid[r][c] == '1'
                count <- count + 1
                grid[r][c] <- '0'
                enqueue (r,c)
                while queue not empty
                    (x,y) <- dequeue
                    for (dx,dy) in [(1,0),(-1,0),(0,1),(0,-1)]
                        nx <- x + dx
                        ny <- y + dy
                        if nx >= 0 and nx < rows and ny >= 0 and ny < cols and grid[nx][ny] == '1'
                            grid[nx][ny] <- '0'
                            enqueue (nx,ny)
    return count
```

### Pattern 3

**Idea**

Union-Find: union adjacent lands and count distinct roots.

**Pseudo Code**

```text
function numIslandsUnionFind(grid)
    if grid is empty return 0
    rows <- number of rows in grid
    cols <- number of columns in grid
    uf <- new UnionFind(rows * cols)
    waterCount <- 0
    for r from 0 to rows-1
        for c from 0 to cols-1
            if grid[r][c] == '0'
                waterCount <- waterCount + 1
            else
                for (dx,dy) in [(1,0),(0,1)]
                    nr <- r + dx
                    nc <- c + dy
                    if nr >= 0 and nr < rows and nc >= 0 and nc < cols and grid[nr][nc] == '1'
                        uf.union(index(r,c), index(nr,nc))
    return uf.count() - waterCount
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| DFS (recursive) | Flood-fill by recursion marking visited | O(m * n) | O(m * n) worst-case stack | Yes |
| BFS (iterative) | Flood-fill using queue | O(m * n) | O(min(m,n)) to O(m*n) queue | Yes |
| Union-Find | Union adjacent lands and count roots | O(m * n * α(mn)) | O(m * n) | No (useful when dynamic merges or repeated queries) |
