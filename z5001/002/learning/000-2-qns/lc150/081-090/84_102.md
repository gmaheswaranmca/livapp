# Binary Tree Level Order Traversal

## Difficulty
Easy

## Description
Return the node values of a binary tree level by level from top to bottom. Each level's values are grouped in a list.

## Examples

### Example 1

```text
Input: [3,9,20,null,null,15,7]
Output: [[3],[9,20],[15,7]]
Explanation: Standard BFS using queue.
```

### Example 2

```text
Input: []
Output: []
Explanation: Empty tree returns empty list.
```

## Constraints

```text
0 <= number of nodes <= 2000
-1000 <= Node.val <= 1000
Tree structure provided as usual binary tree
```

---

## Idea
Use BFS (queue) to process nodes level by level and collect values per level.

---

## Pseudo Code

```text
function levelOrder(root)
    if root == null then return []
    result = []
    queue = new Queue()
    queue.enqueue(root)
    while queue is not empty
        levelSize = queue.size()
        level = []
        for i from 1 to levelSize do
            node = queue.dequeue()
            level.append(node.val)
            if node.left != null then queue.enqueue(node.left)
            if node.right != null then queue.enqueue(node.right)
        result.append(level)
    return result
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

### Dry Run

| Step | State (queue)     | Operation                         | Result                  |
| ---- | ----------------- | --------------------------------- | ----------------------- |
| 1    | [3]               | process levelSize=1               | level=[3]; enqueue 9,20 |
| 2    | [9,20]            | process levelSize=2               | level=[9,20]; enqueue 15,7 |
| 3    | [15,7]            | process levelSize=2               | level=[15,7]; enqueue none |
| 4    | []                | finished                          | result=[[3],[9,20],[15,7]] |

## Other Patterns

### Pattern 1

**Idea**

Use DFS recursion to collect values by depth.

**Pseudo Code**

```text
function levelOrderDFS(root)
    if root == null then return []
    result = []
    dfs(root, 0, result)
    return result

function dfs(node, depth, result)
    if node == null then return
    if depth == result.size() then result.append([])
    result[depth].append(node.val)
    dfs(node.left, depth+1, result)
    dfs(node.right, depth+1, result)
```

## Comparison

| Approach | Idea                                | Time | Space | Recommended |
| -------- | ----------------------------------- | ---- | ----- | ----------- |
| BFS      | Queue level-by-level traversal      | O(n) | O(n)  | Yes         |
| DFS      | Recursion collect values by depth   | O(n) | O(n)  | Yes (small trees) |
