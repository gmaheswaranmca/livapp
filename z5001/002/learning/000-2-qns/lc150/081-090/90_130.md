# Surrounded Regions

## Difficulty
Medium

## Description
Capture all regions of 'O' that are completely surrounded by 'X' in a 2D board. Replace captured 'O's with 'X'. Border-connected 'O's must remain 'O'.

## Examples

### Example 1

```text
Input: board = [
 ["X","X","X","X"],
 ["X","O","O","X"],
 ["X","X","O","X"],
 ["X","O","X","X"]
]
Output: [
 ["X","X","X","X"],
 ["X","X","X","X"],
 ["X","X","X","X"],
 ["X","O","X","X"]
]
Explanation: Mark border-connected O's first, then flip remaining O -> X.
```

## Constraints

```text
m = board.length, n = board[i].length
1 <= m, n <= 200
board[i][j] is 'X' or 'O'
In-place modification allowed
```

---

## Idea
Mark all 'O's connected to the border (temporary mark), flip remaining 'O' to 'X', then revert marks back to 'O'.

---

## Pseudo Code

```text
function solve(board)
    if board is empty return
    m = number of rows in board
    n = number of cols in board
    dirs = [(1,0),(-1,0),(0,1),(0,-1)]
    queue = empty queue

    for i from 0 to m-1
        for j from 0 to n-1
            if (i is 0 or i is m-1 or j is 0 or j is n-1) and board[i][j] == 'O'
                enqueue(queue, (i,j))
                board[i][j] = 'E'

    while queue not empty
        (r,c) = dequeue(queue)
        for (dr,dc) in dirs
            nr = r + dr
            nc = c + dc
            if 0 <= nr < m and 0 <= nc < n and board[nr][nc] == 'O'
                enqueue(queue, (nr,nc))
                board[nr][nc] = 'E'

    for i from 0 to m-1
        for j from 0 to n-1
            if board[i][j] == 'O' board[i][j] = 'X'
            else if board[i][j] == 'E' board[i][j] = 'O'
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(m * n) (queue worst-case) |

## Other Patterns

### Pattern 1

**Idea**
DFS recursive marking from border then flip and revert.

**Pseudo Code**

```text
function solve(board)
    if board is empty return
    m = rows, n = cols
    dirs = [(1,0),(-1,0),(0,1),(0,-1)]

    function dfs(r,c)
        if r < 0 or r >= m or c < 0 or c >= n or board[r][c] != 'O' return
        board[r][c] = 'E'
        for (dr,dc) in dirs
            dfs(r+dr, c+dc)

    for i from 0 to m-1
        for j from 0 to n-1
            if (i is 0 or i is m-1 or j is 0 or j is n-1) and board[i][j] == 'O'
                dfs(i,j)

    for i from 0 to m-1
        for j from 0 to n-1
            if board[i][j] == 'O' board[i][j] = 'X'
            else if board[i][j] == 'E' board[i][j] = 'O'
```

### Pattern 2

**Idea**
Union-Find: connect border 'O's to a dummy root; flip 'O's not connected to dummy.

**Pseudo Code**

```text
function solve(board)
    if board is empty return
    m = rows, n = cols
    uf = UnionFind(m*n + 1)
    dummy = m*n
    index = function(r,c) return r*n + c

    for r from 0 to m-1
        for c from 0 to n-1
            if board[r][c] == 'O'
                if r is 0 or r is m-1 or c is 0 or c is n-1
                    uf.union(index(r,c), dummy)
                for (dr,dc) in [(1,0),(0,1)]
                    nr = r + dr
                    nc = c + dc
                    if 0 <= nr < m and 0 <= nc < n and board[nr][nc] == 'O'
                        uf.union(index(r,c), index(nr,nc))

    for r from 0 to m-1
        for c from 0 to n-1
            if board[r][c] == 'O' and uf.find(index(r,c)) != uf.find(dummy)
                board[r][c] = 'X'
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| BFS / Iterative | Mark border-connected 'O' with BFS then flip | O(m*n) | O(m*n) | Yes |
| DFS / Recursive | Mark border-connected 'O' with recursion then flip | O(m*n) | O(m*n) recursion | No (risk stack overflow) |
| Union-Find | Union border 'O' to dummy then flip non-connected | O(m*n * α) | O(m*n) | No (more code, similar complexity) |
