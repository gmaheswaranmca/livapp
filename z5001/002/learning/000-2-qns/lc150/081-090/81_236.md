# Title
Lowest Common Ancestor of a Binary Tree (LeetCode 236)

## Difficulty
Medium

## Description
Given a binary tree and two nodes p and q, return their lowest common ancestor (LCA). The LCA is the lowest node that has both p and q as descendants (a node can be a descendant of itself).

## Examples

### Example 1

```text
Input: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
Output: 3
Explanation: Nodes 5 and 1 have LCA = 3.
```

### Example 2

```text
Input: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
Output: 5
Explanation: Node 5 is an ancestor of 4 and is the LCA.
```

## Constraints

```text
The number of nodes in the tree is in the range [1, 10^4].
-10^9 <= Node.val <= 10^9
All Node.val are unique.
p and q are different and both exist in the tree.
```

---

## Idea
DFS postorder: return node if it is p or q, propagate non-null child results; first node with both non-null children is LCA.

---

## Pseudo Code

```text
function lowestCommonAncestor(root, p, q)
    if root is null
        return null
    if root is p or root is q
        return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left is not null and right is not null
        return root
    if left is not null
        return left
    return right
```

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h)   |

## Code Explanation

### Dry Run

| Step | State (node) | Operation | Result |
| ---- | ------------ | --------- | ------ |
| 1    | 3 (root)     | call left on 5 and right on 1 | recurse both sides |
| 2    | 5            | root == p so return 5 | left returns 5 up to 3 |
| 3    | 1            | root == q so return 1 | right returns 1 up to 3 |
| 4    | 3            | left != null and right != null | return 3 as LCA |
| 5    | 5 & 4 case   | when p=5,q=4, left subtree returns 5, right null | return 5 as LCA |

1. Visit a node.
2. If node is null return null.
3. If node equals p or q return node.
4. Recurse left and right.
5. If both sides non-null current node is LCA.
6. Else propagate the non-null side upward.

## Other Patterns

### Pattern 1

**Idea**

Build parent pointers with DFS, then move ancestors of p and q.

**Pseudo Code**

```text
function lowestCommonAncestor(root, p, q)
    parent = map()
    stack = [root]
    parent[root] = null
    while p not in parent or q not in parent
        node = pop(stack)
        if node.left is not null
            parent[node.left] = node
            push(stack, node.left)
        if node.right is not null
            parent[node.right] = node
            push(stack, node.right)
    ancestors = set()
    while p is not null
        add p to ancestors
        p = parent[p]
    while q not in ancestors
        q = parent[q]
    return q
```

### Pattern 2

**Idea**

Iterative postorder using stack and tracking visited nodes to simulate recursion.

**Pseudo Code**

```text
function lowestCommonAncestor(root, p, q)
    stack = []
    lastVisited = null
    node = root
    foundP = false
    foundQ = false
    lca = null
    while stack not empty or node is not null
        if node is not null
            push(stack, node)
            node = node.left
        else
            peek = top(stack)
            if peek.right is not null and lastVisited is not peek.right
                node = peek.right
            else
                pop(stack)
                if peek is p or peek is q
                    if lca is null
                        lca = peek
                    else
                        return lca
                if lca is not null and (peek is lca) and stack not empty
                    lca = top(stack)
                lastVisited = peek
    return null
```
