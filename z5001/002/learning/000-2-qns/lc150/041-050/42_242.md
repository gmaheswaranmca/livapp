# Valid Anagram

## Difficulty
Easy

## Description
Determine whether two strings are anagrams of each other (contain the same characters with the same frequencies).

## Examples

### Example 1

```text
Input: s = "anagram", t = "nagaram"
Output: true
Explanation: Both strings have same character frequencies.
```

### Example 2

```text
Input: s = "rat", t = "car"
Output: false
Explanation: Character frequencies differ.
```

## Constraints

```text
1 <= s.length, t.length <= 5 * 10^4
s and t consist of lowercase English letters (a-z)
```

---

## Idea
Compare frequency counts of characters in both strings.

---

## Pseudo Code

```text
function isAnagram(s, t)
    if length(s) != length(t) return false
    create counts[26] initialized to 0
    for i from 0 to length(s)-1
        counts[s[i] - 'a'] += 1
        counts[t[i] - 'a'] -= 1
    for i from 0 to 25
        if counts[i] != 0 return false
    return true
```

---

## Complexity

| Metric           | Value      |
| ---------------- | ---------- |
| Time Complexity  | O(n)       |
| Space Complexity | O(1) (26)  |

---

## Code Explanation

### Dry Run

| Step | State                         | Operation                                   | Result                         |
| ---- | ----------------------------- | ------------------------------------------- | ------------------------------ |
| 1    | counts = [0...0]              | i=0: s[0]='a' t[0]='n'                      | counts['a']+=1 counts['n']-=1  |
| 2    | counts after s processed some | loop continues for all indices simultaneously | net counts reflect diffs       |
| 3    | after full loop               | check counts array                          | all zeros -> return true       |

## Other Patterns

### Pattern 1

**Idea**

Sort both strings and compare.

**Pseudo Code**

```text
function isAnagram_sort(s, t)
    if length(s) != length(t) return false
    sort s
    sort t
    return s == t
```

### Pattern 2

**Idea**

Use a hashmap (dictionary) to count frequencies then compare.

**Pseudo Code**

```text
function isAnagram_map(s, t)
    if length(s) != length(t) return false
    create map counts
    for ch in s
        counts[ch] = counts.get(ch,0) + 1
    for ch in t
        if ch not in counts return false
        counts[ch] -= 1
        if counts[ch] == 0 remove ch from counts
    return counts is empty
```

## Comparison

| Approach   | Idea                            | Time     | Space        | Recommended |
| ---------- | ------------------------------- | -------- | ------------ | ----------- |
| Counting   | Fixed-size frequency array      | O(n)     | O(1) (26)    | Yes         |
| Sorting    | Sort both strings               | O(n log n)| O(n)        | No          |
| Hash Map   | Dynamic frequency dictionary    | O(n)     | O(k)         | Conditional |
