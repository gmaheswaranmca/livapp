# Merge Intervals

## Difficulty
Medium

## Description
Given a collection of intervals, merge all overlapping intervals and return an array of the non-overlapping intervals that cover all the intervals in the input. Intervals are given as [start, end].

## Examples

### Example 1
```text
Input: [[1,3],[2,6],[8,10],[15,18]]
Output: [[1,6],[8,10],[15,18]]
Explanation: [1,3] and [2,6] overlap and are merged into [1,6].
```

### Example 2
```text
Input: [[1,4],[4,5]]
Output: [[1,5]]
Explanation: Touching intervals merge because end == next start.
```

### Example 3
```text
Input: [[5,6],[1,3],[2,4]]
Output: [[1,4],[5,6]]
Explanation: Sorted by start gives [[1,3],[2,4],[5,6]] then merge first two.
```

## Constraints
```text
1 <= intervals.length <= 10^5
intervals[i].length == 2
-10^9 <= intervals[i][0] <= intervals[i][1] <= 10^9
Output order must be sorted by start.
```

---

## Idea
Sort intervals by start and iterate, merging current interval with the last merged if they overlap.

---

## Pseudo Code
```text
function mergeIntervals(intervals)
    if intervals is empty return []
    sort intervals by start ascending
    create merged as empty list
    for each interval in intervals
        if merged is empty append interval to merged
        else
            let last = merged.last
            if interval.start <= last.end
                last.end = max(last.end, interval.end)
            else
                append interval to merged
    return merged
```

## Code Explanation

### Dry Run

| Step | State (merged)         | Operation                     | Result                      |
| ---- | ---------------------- | ----------------------------- | --------------------------- |
| 1    | []                     | sort -> [[1,3],[2,6],[8,10],[15,18]] | []                        |
| 2    | []                     | take [1,3], merged empty      | [[1,3]]                     |
| 3    | [[1,3]]                | take [2,6], overlap with [1,3]| merge -> [[1,6]]            |
| 4    | [[1,6]]                | take [8,10], no overlap       | [[1,6],[8,10]]              |
| 5    | [[1,6],[8,10]]        | take [15,18], no overlap      | [[1,6],[8,10],[15,18]]      |

Steps:
1. Sort intervals by start.
2. Maintain list of merged intervals.
3. For each interval, merge with last if overlap (interval.start <= last.end) updating last.end = max(last.end, interval.end).
4. Otherwise append as new interval.

## Other Patterns

### Pattern 1

**Idea**
Use sweep line: convert to events (start +1, end -1) and build merged intervals from active count transitions.

**Pseudo Code**
```text
function mergeIntervalsSweep(intervals)
    create events as empty list
    for each [s,e] in intervals
        append (s, 1) to events
        append (e, -1) to events
    sort events by position ascending then by delta descending
    active = 0
    start = null
    create result as empty list
    for each (pos, delta) in events
        prev = active
        active = active + delta
        if prev == 0 and active > 0
            start = pos
        if prev > 0 and active == 0
            append [start, pos] to result
    return result
```

### Pattern 2

**Idea**
Build and query an interval tree to insert intervals and merge overlapping nodes (useful for many dynamic queries).

**Pseudo Code**
```text
function mergeIntervalsIntervalTree(intervals)
    create intervalTree
    for each interval in intervals
        intervalTree.insertAndMerge(interval)
    return intervalTree.inorderMergedIntervals()
```
