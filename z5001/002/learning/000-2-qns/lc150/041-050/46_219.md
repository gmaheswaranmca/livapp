# Contains Duplicate II

## Difficulty
Easy

## Description
Given an integer array nums and an integer k, return true if there are two distinct indices i and j in the array such that nums[i] == nums[j] and |i - j| <= k.

## Examples

### Example 1
```text
Input: nums = [1,2,3,1], k = 3
Output: true
Explanation: nums[0] == nums[3] and |0 - 3| = 3 <= k
```

### Example 2
```text
Input: nums = [1,0,1,1], k = 1
Output: true
Explanation: nums[2] == nums[3] and |2 - 3| = 1 <= k
```

### Example 3
```text
Input: nums = [1,2,3,1,2,3], k = 2
Output: false
Explanation: nearest equal values are farther than k
```

## Constraints
```text
1 <= nums.length <= 10^5
-2^31 <= nums[i] <= 2^31-1
0 <= k <= 10^5
```

---

## Idea
Use a hash map to store the latest index of each value and check if current index minus stored index <= k.

---

## Pseudo Code
```text
function containsDuplicateNearby(nums, k)
    create empty map valueToIndex
    for i from 0 to length(nums)-1
        v = nums[i]
        if v exists in valueToIndex
            lastIndex = valueToIndex[v]
            if i - lastIndex <= k
                return true
        valueToIndex[v] = i
    return false
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

## Code Explanation

### Dry Run

| Step | i | v | Map before operation       | Operation                              | Result        |
| ---- | -:| -:| -------------------------- | -------------------------------------- | ------------- |
| 1    | 0 | 1 | {}                         | insert 1 -> 0                          | map = {1:0}   |
| 2    | 1 | 2 | {1:0}                      | insert 2 -> 1                          | map = {1:0,2:1} |
| 3    | 2 | 3 | {1:0,2:1}                  | insert 3 -> 2                          | map = {1:0,2:1,3:2} |
| 4    | 3 | 1 | {1:0,2:1,3:2}              | found 1 -> lastIndex=0, 3-0 <= 3 => true | return true   |

## Other Patterns

### Pattern 1
**Idea**
Maintain a sliding window set of size at most k and check membership.

**Pseudo Code**
```text
function containsDuplicateNearby_set(nums, k)
    if k <= 0
        return false
    create empty set window
    for i from 0 to length(nums)-1
        v = nums[i]
        if v in window
            return true
        add v to window
        if size(window) > k
            remove nums[i - k] from window
    return false
```

### Pattern 2
**Idea**
Brute force check all pairs within distance k.

**Pseudo Code**
```text
function containsDuplicateNearby_bruteforce(nums, k)
    for i from 0 to length(nums)-1
        for j from i+1 to min(length(nums)-1, i+k)
            if nums[i] == nums[j]
                return true
    return false
```

## Comparison

| Approach               | Idea                                  | Time       | Space        | Recommended |
| ---------------------- | ------------------------------------- | ---------- | ------------ | ----------- |
| HashMap latest index   | Map value -> latest index and check   | O(n)       | O(n)         | Yes         |
| Sliding window HashSet | Keep set of last k elements           | O(n)       | O(min(n,k))  | Yes (memory sensitive) |
| Brute Force            | Check pairs within k                  | O(n*k)     | O(1)         | No          |
