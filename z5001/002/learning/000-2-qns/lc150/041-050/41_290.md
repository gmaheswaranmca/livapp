# Word Pattern

## Difficulty
Easy

## Description
Given a pattern string and a sentence s, determine if s follows the same pattern: each character in pattern must map to a whole word in s and mapping must be bijective (no two chars map to the same word and vice versa).

## Examples

### Example 1

```text
Input: pattern = "abba", s = "dog cat cat dog"
Output: true
Explanation: 'a'->"dog", 'b'->"cat"
```

### Example 2

```text
Input: pattern = "abba", s = "dog cat cat fish"
Output: false
Explanation: last word doesn't match mapping for 'a'
```

### Example 3

```text
Input: pattern = "aaaa", s = "dog cat cat dog"
Output: false
Explanation: 'a' maps to multiple distinct words
```

### Example 4

```text
Input: pattern = "abba", s = "dog dog dog dog"
Output: false
Explanation: two chars map to same word
```

## Constraints

```text
1 <= pattern.length, number of words in s <= 10^5 (practical limit)
pattern contains only letters
s contains words separated by single spaces
Words consist of non-space characters
```

---

## Idea
Use two hash maps to enforce a bijection: char -> word and word -> char while scanning aligned positions.

---

## Pseudo Code

```text
function solve(pattern, s)
    words = split(s, ' ')
    if length(pattern) != length(words) return false
    charToWord = empty map
    wordToChar = empty map
    for i from 0 to length(pattern)-1
        c = pattern[i]
        w = words[i]
        if c in charToWord and charToWord[c] != w return false
        if w in wordToChar and wordToChar[w] != c return false
        charToWord[c] = w
        wordToChar[w] = c
    return true
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

## Code Explanation

### Dry Run

| Step | State (charToWord, wordToChar)           | Operation                           | Result                     |
| ---- | ---------------------------------------- | ------------------------------------| -------------------------- |
| 1    | ({}, {})                                 | read c='a', w="dog", assign maps    | ({'a':'dog'}, {'dog':'a'})|
| 2    | ({'a':'dog'}, {'dog':'a'})               | read c='b', w="cat", assign maps    | ({'a':'dog','b':'cat'}, {'dog':'a','cat':'b'}) |
| 3    | ({'a':'dog','b':'cat'}, {'dog':'a','cat':'b'}) | read c='b', w="cat", checks pass | unchanged                  |
| 4    | unchanged                                | read c='a', w="dog", checks pass    | unchanged                  |
| End  | maps consistent                           | return true                         | true                      |

## Other Patterns

### Pattern 2

**Idea**

Use one map char->word plus a set of used words to ensure bijection.

**Pseudo Code**

```text
function solve(pattern, s)
    words = split(s, ' ')
    if length(pattern) != length(words) return false
    charToWord = empty map
    usedWords = empty set
    for i from 0 to length(pattern)-1
        c = pattern[i]
        w = words[i]
        if c in charToWord
            if charToWord[c] != w return false
        else
            if w in usedWords return false
            charToWord[c] = w
            add w to usedWords
    return true
```

### Pattern 3

**Idea**

Encode both pattern and words by first-seen index sequence and compare canonical forms.

**Pseudo Code**

```text
function canonical(sequence)
    mapElemToIndex = empty map
    result = empty list
    nextIndex = 0
    for elem in sequence
        if elem not in mapElemToIndex
            mapElemToIndex[elem] = nextIndex
            nextIndex = nextIndex + 1
        append mapElemToIndex[elem] to result
    return result

function solve(pattern, s)
    words = split(s, ' ')
    if length(pattern) != length(words) return false
    return canonical(list(pattern)) == canonical(words)
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| HashMap bijection | Two maps char->word and word->char | O(n) | O(n) | Yes |
| Single map + set | Map char->word + set for used words | O(n) | O(n) | Yes |
| Canonical encoding | Compare index-sequence encodings | O(n) | O(n) | No |
