# Summary Ranges

## Difficulty
Easy

## Description
Given a sorted unique integer array nums, return the smallest sorted list of ranges that cover all the numbers in the array exactly. A range "a->b" is used for consecutive numbers from a to b (inclusive). Single numbers are represented as the string of the number.

## Examples

### Example 1

```text
Input: nums = [0,1,2,4,5,7]
Output: ["0->2","4->5","7"]
Explanation: Consecutive runs: 0..2, 4..5, 7
```

### Example 2

```text
Input: nums = [0,2,3,4,6,8,9]
Output: ["0","2->4","6","8->9"]
Explanation: Runs: 0, 2..4, 6, 8..9
```

## Constraints

```text
0 <= nums.length <= 10^4
-2^31 <= nums[i] <= 2^31-1
nums is sorted in strictly increasing order (unique elements)
```

---

## Idea
Scan once, track current range start and extend while consecutive; when break occurs emit start or start->end.

---

## Pseudo Code

```text
function summaryRanges(nums)
    result = empty list
    if nums is empty then return result
    start = nums[0]
    end = nums[0]
    i = 1
    while i < length(nums)
        if nums[i] == end + 1
            end = nums[i]
        else
            if start == end
                append string(start) to result
            else
                append string(start) + "->" + string(end) to result
            start = nums[i]
            end = nums[i]
        i = i + 1
    if start == end
        append string(start) to result
    else
        append string(start) + "->" + string(end) to result
    return result
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(k) where k is number of output ranges (O(n) worst-case) |

## Code Explanation

### Dry Run

| Step | i | start | end | nums[i] | Operation | Result |
| ---- | -:| -----:| ----:| ------- | --------- | ------ |
| 1    | 1 | 0     | 0    | 1       | 1 == 0+1 -> extend end=1 | [] |
| 2    | 2 | 0     | 1    | 2       | 2 == 1+1 -> extend end=2 | [] |
| 3    | 3 | 0     | 2    | 4       | break -> append "0->2"; start=end=4 | ["0->2"] |
| 4    | 4 | 4     | 4    | 5       | 5 == 4+1 -> extend end=5 | ["0->2"] |
| 5    | 5 | 4     | 5    | 7       | break -> append "4->5"; start=end=7 | ["0->2","4->5"] |
| End  | -  | 7     | 7    | -       | finish -> append "7" | ["0->2","4->5","7"] |

## Other Patterns

### Pattern 1

**Idea**
Single-pass using for-loop with previous value tracking.

**Pseudo Code**

```text
function summaryRanges(nums)
    result = empty list
    if nums is empty then return result
    start = nums[0]
    prev = nums[0]
    for i from 1 to length(nums)-1
        if nums[i] == prev + 1
            prev = nums[i]
        else
            if start == prev
                append string(start) to result
            else
                append string(start) + "->" + string(prev) to result
            start = nums[i]
            prev = nums[i]
    if start == prev
        append string(start) to result
    else
        append string(start) + "->" + string(prev) to result
    return result
```

### Pattern 2

**Idea**
Build ranges by checking next element with index lookahead.

**Pseudo Code**

```text
function summaryRanges(nums)
    result = empty list
    i = 0
    while i < length(nums)
        start = nums[i]
        j = i
        while j + 1 < length(nums) and nums[j+1] == nums[j] + 1
            j = j + 1
        if start == nums[j]
            append string(start) to result
        else
            append string(start) + "->" + string(nums[j]) to result
        i = j + 1
    return result
```

## Comparison

| Approach   | Idea                                   | Time | Space         | Recommended |
| ---------- | -------------------------------------- | ---- | ------------- | ----------- |
| Two pointers (main) | Track start and extend end in one pass | O(n) | O(k) output   | Yes |
| For-loop prev tracking | Same as two pointers using prev var    | O(n) | O(k) output   | Yes |
| Lookahead inner-loop  | Advance inner pointer to end of run     | O(n) | O(k) output   | No (slightly less concise) |
