# Happy Number

## Difficulty
Easy

## Description
Given a positive integer n, repeatedly replace the number by the sum of the squares of its digits. Return true if this process eventually reaches 1; otherwise return false (it loops endlessly in a cycle).

## Examples

### Example 1
```text
Input: n = 19
Output: true
Explanation: 19 -> 82 -> 68 -> 100 -> 1
```

### Example 2
```text
Input: n = 2
Output: false
Explanation: 2 -> 4 -> 16 -> 37 -> 58 -> 89 -> 145 -> 42 -> 20 -> 4 ... (cycle)
```

## Constraints
```text
1 <= n <= 2^31 - 1
Use O(1) or O(log n) additional memory if possible.
```

---

## Idea
Use a HashSet to record seen numbers; compute next number as sum of squares of digits and detect cycles.

---

## Pseudo Code
```text
function isHappy(n)
    if n <= 0 return false
    seen = empty HashSet
    while n != 1
        if seen.contains(n) return false
        seen.add(n)
        n = nextNumber(n)
    return true

function nextNumber(x)
    sum = 0
    while x > 0
        digit = x % 10
        sum = sum + digit * digit
        x = x / 10
    return sum
```

---

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(k * log n) where k is iterations until cycle or 1 |
| Space Complexity | O(k) (size of visited set) |

---

## Code Explanation

### Dry Run

| Step | State (n) | Operation                 | Result |
| ---- | --------- | ------------------------- | ------ |
| 1    | 19        | not seen, compute next    | 82     |
| 2    | 82        | not seen, compute next    | 68     |
| 3    | 68        | not seen, compute next    | 100    |
| 4    | 100       | not seen, compute next    | 1      |
| 5    | 1         | reached 1                 | return true |

1. Initialize empty HashSet seen.
2. Loop until n == 1.
3. If n already in seen return false (cycle detected).
4. Add n to seen and set n = nextNumber(n).
5. If n becomes 1 return true.

## Other Patterns

### Pattern 1

**Idea**

Use Floyd's cycle detection (tortoise and hare) to detect cycles in O(1) space.

**Pseudo Code**
```text
function isHappyFloyd(n)
    if n <= 0 return false
    slow = n
    fast = n
    do
        slow = nextNumber(slow)
        fast = nextNumber(nextNumber(fast))
    while slow != fast
    return slow == 1

function nextNumber(x)
    sum = 0
    while x > 0
        digit = x % 10
        sum = sum + digit * digit
        x = x / 10
    return sum
```

## Comparison

| Approach | Idea                             | Time         | Space | Recommended |
| -------- | -------------------------------- | ------------ | ----- | ----------- |
| HashSet  | Store visited numbers to detect cycle | O(k * log n) | O(k)  | Yes        |
| Floyd    | Tortoise and hare cycle detection | O(k * log n) | O(1)  | Yes (when space constrained) |
