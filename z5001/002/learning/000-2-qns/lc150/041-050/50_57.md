# Insert Interval

## Difficulty
Medium

## Description
Given a list of non-overlapping intervals sorted by start time, insert a new interval and merge if necessary so that the result remains sorted and non-overlapping.

## Examples

### Example 1

```text
Input: intervals = [[1,3],[6,9]], newInterval = [2,5]
Output: [[1,5],[6,9]]
Explanation: [2,5] overlaps with [1,3] and merges to [1,5].
```

### Example 2

```text
Input: intervals = [[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval = [4,8]
Output: [[1,2],[3,10],[12,16]]
Explanation: [4,8] merges with [3,5],[6,7],[8,10] into [3,10].
```

## Constraints

```text
0 <= intervals.length <= 10^4
intervals[i].length == 2
0 <= intervals[i][0] <= intervals[i][1] <= 10^9
newInterval.length == 2
intervals sorted by start and non-overlapping
```

---

## Idea
Sweep once: append all intervals ending before new, merge all overlapping with new, then append remaining intervals.

---

## Pseudo Code

```text
function insertInterval(intervals, newInterval)
    result = empty list
    i = 0
    n = length(intervals)
    while i < n and intervals[i].end < newInterval.start
        append intervals[i] to result
        i = i + 1
    merged = newInterval.copy()
    while i < n and intervals[i].start <= merged.end
        merged.start = min(merged.start, intervals[i].start)
        merged.end = max(merged.end, intervals[i].end)
        i = i + 1
    append merged to result
    while i < n
        append intervals[i] to result
        i = i + 1
    return result
```

| Metric           | Value  |

| Time Complexity  | O(n)   |

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | i=0, result=[], new=[2,5] | intervals[0]=[1,3], 3 < 2? no -> go merge | merged expands with [1,3] => [1,5] |
| 2    | i=1, merged=[1,5] | intervals[1]=[6,9], 6 <= 5? no -> stop merge | append merged => result=[[1,5]] |
| 3    | i=1 | append remaining intervals from i | result=[[1,5],[6,9]] |

1. Collect all intervals that end before newInterval starts (left).
2. Merge overlapping intervals with newInterval by extending start and end.
3. Append merged interval.
4. Append all remaining intervals (right).

## Other Patterns

### Pattern 1

**Idea**

Binary search to find first interval with end >= new.start then merge forward.

**Pseudo Code**

```text
function insertIntervalBinarySearch(intervals, newInterval)
    result = empty list
    n = length(intervals)
    pos = binarySearchFirst(intervals, interval => interval.end >= newInterval.start)
    for j from 0 to pos-1
        append intervals[j] to result
    merged = newInterval.copy()
    i = pos
    while i < n and intervals[i].start <= merged.end
        merged.start = min(merged.start, intervals[i].start)
        merged.end = max(merged.end, intervals[i].end)
        i = i + 1
    append merged to result
    for j from i to n-1
        append intervals[j] to result
    return result
```

### Pattern 2

**Idea**

Insert new interval, sort by start, then run linear merge.

**Pseudo Code**

```text
function insertIntervalSortAndMerge(intervals, newInterval)
    append newInterval to intervals
    sort intervals by start
    result = empty list
    for each interval in intervals
        if result is empty or result.last.end < interval.start
            append interval to result
        else
            result.last.end = max(result.last.end, interval.end)
    return result
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| One-pass sweep | Separate left, overlap, right in single scan | O(n) | O(n) | Yes |
| Binary search + merge | Locate start boundary by binary search then merge | O(log n + k) ~ O(n) worst | O(n) | No (useful if many queries) |
| Insert+sort+merge | Insert then sort then merge | O(n log n) | O(n) | No (worse time)
