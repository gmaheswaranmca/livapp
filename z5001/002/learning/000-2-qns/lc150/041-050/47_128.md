# Longest Consecutive Sequence

## Difficulty
Medium

## Description
Given an unsorted integer array nums, return the length of the longest sequence of consecutive integers. Sequence elements do not need to be adjacent in the array. Duplicates may appear.

## Examples

### Example 1

```text
Input: [100,4,200,1,3,2]
Output: 4
Explanation: The longest consecutive sequence is [1,2,3,4].
```

### Example 2

```text
Input: []
Output: 0
Explanation: Empty array has length 0.
```

### Example 3

```text
Input: [0, -1]
Output: 2
Explanation: The longest consecutive sequence is [-1,0].
```

## Constraints

```text
0 <= nums.length <= 10^5
-10^9 <= nums[i] <= 10^9
Elements may repeat.
```

---

## Idea
Use a HashSet and only start expanding sequences from numbers that are sequence beginnings (num-1 not in set).

---

## Pseudo Code

```text
function solve(nums)
    if nums is empty return 0
    set = empty HashSet
    for each num in nums
        add num to set
    maxLen = 0
    for each num in set
        if (num - 1) not in set
            current = num
            length = 1
            while (current + 1) in set
                current = current + 1
                length = length + 1
            if length > maxLen
                maxLen = length
    return maxLen
```

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | nums=[100,4,200,1,3,2] | build set | set={100,4,200,1,3,2} |
| 2    | iterate set | num=1, (1-1)=0 not in set -> expand | current:1->2->3->4, length=4 |
| 3    | update maxLen | maxLen = 4 |
| 4    | remaining nums checked | no longer beginnings produce longer seq | final result = 4 |

## Other Patterns

### Pattern 1

**Idea**

Sort array and count consecutive runs.

**Pseudo Code**

```text
function solve(nums)
    if nums is empty return 0
    sort nums
    maxLen = 1
    currLen = 1
    for i from 1 to nums.length-1
        if nums[i] == nums[i-1] continue
        if nums[i] == nums[i-1] + 1
            currLen = currLen + 1
        else
            if currLen > maxLen
                maxLen = currLen
            currLen = 1
    if currLen > maxLen
        maxLen = currLen
    return maxLen
```

### Pattern 2

**Idea**

Use Union-Find mapping each value to a node and union num with num+1 when present.

**Pseudo Code**

```text
function solve(nums)
    if nums is empty return 0
    map = empty HashMap   // value -> node id
    uf = new UnionFind
    id = 0
    for each num in nums
        if num not in map
            map[num] = id
            uf.add(id)
            id = id + 1
        if (num + 1) in map
            uf.union(map[num], map[num + 1])
        if (num - 1) in map
            uf.union(map[num], map[num - 1])
    maxSize = 0
    for each node in uf
        maxSize = max(maxSize, uf.sizeOfSet(node))
    return maxSize
```

## Comparison

| HashSet (main)| Expand from sequence starts         | O(n)        | O(n)        | Yes        |
