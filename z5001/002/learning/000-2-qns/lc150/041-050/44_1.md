# Two Sum

## Difficulty
Easy

## Description
Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target. Assume exactly one solution exists and you may not use the same element twice.

## Examples

### Example 1
```text
Input: nums=[2,7,11,15], target=9
Output: [0,1]
Explanation: nums[0]+nums[1]=2+7=9
```

### Example 2
```text
Input: nums=[3,2,4], target=6
Output: [1,2]
Explanation: nums[1]+nums[2]=2+4=6
```

## Constraints
```text
2 <= nums.length <= 10^5
-10^9 <= nums[i] <= 10^9
-10^9 <= target <= 10^9
Exactly one valid answer exists
```

---

## Idea
Store seen values and their indices in a hash map; for each value check if its complement exists.

---

## Pseudo Code
```text
function twoSum(nums, target)
    create empty map valueToIndex
    for i from 0 to length(nums)-1
        complement = target - nums[i]
        if complement in valueToIndex return [valueToIndex[complement], i]
        valueToIndex[nums[i]] = i
    return []
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | i | num | complement | map (before op) | Operation | Result |
| ---- | - | --- | ---------- | --------------- | --------- | ------ |
| 1    | 0 | 2   | 7          | {}              | store 2->0 | map={2:0} |
| 2    | 1 | 7   | 2          | {2:0}           | found 2   | return [0,1] |

## Other Patterns

### Pattern 1

**Idea**
Sort array with original indices and use two pointers.

**Pseudo Code**
```text
function twoSumSorted(nums, target)
    pairs = []
    for i from 0 to length(nums)-1
        append (value=nums[i], index=i) to pairs
    sort pairs by value ascending
    l = 0
    r = length(pairs)-1
    while l < r
        sum = pairs[l].value + pairs[r].value
        if sum == target return [pairs[l].index, pairs[r].index]
        if sum < target l = l + 1 else r = r - 1
    return []
```

### Pattern 2

**Idea**
Brute force check all pairs.

**Pseudo Code**
```text
function twoSumBruteForce(nums, target)
    n = length(nums)
    for i from 0 to n-2
        for j from i+1 to n-1
            if nums[i] + nums[j] == target return [i, j]
    return []
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Hash Map | Store complements in map | O(n) | O(n) | Yes |
| Sorting + Two Pointers | Sort values with indices and use two pointers | O(n log n) | O(n) | No (if indices order matters) |
| Brute Force | Check every pair | O(n^2) | O(1) | No |
