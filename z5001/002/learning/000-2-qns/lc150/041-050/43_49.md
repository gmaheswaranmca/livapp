# Group Anagrams

## Difficulty
Medium

## Description
Given an array of strings, group the anagrams together. Return the groups in any order.

## Examples

### Example 1

```text
Input: ["eat","tea","tan","ate","nat","bat"]
Output: [["eat","tea","ate"],["tan","nat"],["bat"]]
Explanation: Anagrams are grouped together; order of groups and order within a group does not matter.
```

### Example 2

```text
Input: ["" , "b"]
Output: [[""],["b"]]
Explanation: Empty string handled as valid key.
```

## Constraints

```text
1 <= strs.length <= 10^4
0 <= strs[i].length <= 100
strs[i] consists of lowercase English letters
```

---

## Idea
Use the sorted string as a canonical key and map each string to its key, grouping values.

---

## Pseudo Code

```text
function groupAnagrams(strs)
    create empty map key->list
    for each s in strs
        key = sort_characters_of(s)
        if key not in map
            map[key] = empty list
        append s to map[key]
    return list of values from map
```

---

## Complexity

| Metric           | Value        |
| ---------------- | ------------ |
| Time Complexity  | O(N * K log K) |
| Space Complexity | O(N * K)     |

N = number of strings, K = max length of a string.

---

## Code Explanation

### Dry Run

| Step | Processed String | Key   | Map State |
| ---- | ---------------- | ----- | --------- |
| 1    | "eat"            | "aet" | {"aet": ["eat"]} |
| 2    | "tea"            | "aet" | {"aet": ["eat","tea"]} |
| 3    | "tan"            | "ant" | {"aet": ["eat","tea"], "ant": ["tan"]} |
| 4    | "ate"            | "aet" | {"aet": ["eat","tea","ate"], "ant": ["tan"]} |
| 5    | "nat"            | "ant" | {"aet": ["eat","tea","ate"], "ant": ["tan","nat"]} |
| 6    | "bat"            | "abt" | {"aet": ["eat","tea","ate"], "ant": ["tan","nat"], "abt": ["bat"]} |

1. Iterate all strings, compute sorted key, append to corresponding list.
2. Return map values as grouped anagrams.

## Other Patterns

### Pattern 1

**Idea**
Use character frequency (26-count tuple) as key to avoid per-string sort.

**Pseudo Code**

```text
function groupAnagrams_CountKey(strs)
    create empty map key->list
    for each s in strs
        counts = array[26] initialized to 0
        for each ch in s
            counts[ch - 'a'] += 1
        key = serialize(counts)   // e.g., join with '#'
        if key not in map
            map[key] = empty list
        append s to map[key]
    return list of values from map
```

### Pattern 2

**Idea**
Use prime number multiplication per character as hash key (beware overflow).

**Pseudo Code**

```text
function groupAnagrams_PrimeHash(strs)
    primes = [2,3,5,7,11,13,...]  // 26 primes
    create empty map hash->list
    for each s in strs
        product = 1 (use big integer or handle overflow)
        for each ch in s
            product *= primes[ch - 'a']
        key = product
        if key not in map
            map[key] = empty list
        append s to map[key]
    return list of values from map
```

## Comparison

| Approach       | Idea                         | Time             | Space      | Recommended |
| -------------- | ---------------------------- | ---------------- | ---------- | ----------- |
| Sorting Key    | Sort characters per string   | O(N * K log K)   | O(N * K)   | Yes         |
| Count Key      | Use 26-length frequency tuple| O(N * K)         | O(N * K)   | Yes (large K)|
| Prime Hash     | Multiply primes per char     | O(N * K)         | O(N) (keys) | No (overflow risk) |
