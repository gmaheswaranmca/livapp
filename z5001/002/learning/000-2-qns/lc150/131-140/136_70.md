# Climbing Stairs (LeetCode 70)

## Difficulty
Easy

## Description
Given n steps, count distinct ways to reach the top when you can climb 1 or 2 steps at a time.

## Examples

### Example 1

```text
Input: n = 5
Output: 8
Explanation: Ways: 11111, 1112, 1121, 1211, 2111, 122, 212, 221 (8 ways)
```

### Example 2

```text
Input: n = 1
Output: 1
Explanation: Only one way: 1
```

## Constraints

```text
1 <= n <= 45
Result fits in 32-bit signed integer
```

---

## Idea
The number of ways equals Fibonacci(n): use iterative DP with two variables to compute in O(n) time and O(1) space.

---

## Pseudo Code

```text
function climbStairs(n)
    if n <= 2
        return n
    a <- 1                // ways for step 1
    b <- 2                // ways for step 2
    for i from 3 to n
        temp <- b
        b <- a + b
        a <- temp
    return b
```

| Metric           | Value    |

## Other Patterns

### Pattern 1

**Idea**

Top-down recursion with memoization (O(n) time, O(n) space).

**Pseudo Code**

```text
function climbStairsMemo(n)
    memo <- empty map
    return dfs(n, memo)

function dfs(k, memo)
    if k <= 2
        return k
    if k in memo
        return memo[k]
    memo[k] <- dfs(k-1, memo) + dfs(k-2, memo)
    return memo[k]
```

### Pattern 2

**Idea**

Fast doubling (matrix exponentiation variant) to compute Fibonacci in O(log n) time.

**Pseudo Code**

```text
function climbStairsFast(n)
    if n <= 2
        return n
    return fib(n)       // returns F(n) where F(1)=1, F(2)=2

function fib(k)
    if k == 0
        return (0, 1)
    (a, b) <- fib(floor(k/2))
    c <- a * (2*b - a)
    d <- a*a + b*b
    if k % 2 == 0
        return (c, d)
    else
        return (d, c + d)
```

### Pattern 3

**Idea**

Use closed-form (Binet's formula) with floating arithmetic (O(1) time) — may suffer precision issues for larger n.

**Pseudo Code**

```text
function climbStairsBinet(n)
    phi <- (1 + sqrt(5)) / 2
    psi <- (1 - sqrt(5)) / 2
    // Fibonacci variant mapping: F(1)=1, F(2)=2 => compute F(n)
    result <- round((phi^(n+1) - psi^(n+1)) / sqrt(5))
    return result
```

## Comparison

| Approach               | Idea                               | Time    | Space  | Recommended |
| ---------------------- | ---------------------------------- | ------- | ------ | ----------- |
| Iterative DP (two vars)| Fibonacci iterative                 | O(n)    | O(1)   | Yes         |
| Recursion + Memo       | Top-down DP                         | O(n)    | O(n)   | No (extra mem) |
| Fast Doubling          | Fibonacci via divide & conquer      | O(log n)| O(1)   | Yes (for large n) |
| Binet Formula          | Closed-form using floating math     | O(1)    | O(1)   | No (precision) |
