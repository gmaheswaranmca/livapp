# Coin Change (Minimum coins to make amount)

## Difficulty
Medium

## Description
Given an array of distinct positive integers coins and a non-negative integer amount, return the fewest number of coins needed to make up that amount. Return -1 if the amount cannot be made with the given coins.

## Examples

### Example 1
```text
Input: coins = [1,2,5], amount = 11
Output: 3
Explanation: 11 = 5 + 5 + 1
```

### Example 2
```text
Input: coins = [2], amount = 3
Output: -1
Explanation: No combination makes 3.
```

## Constraints
```text
1 <= coins.length <= 12
1 <= coins[i] <= 2^31 - 1
0 <= amount <= 10000
All coins are distinct.
```

---

## Idea
Bottom-up dynamic programming computing dp[a] = minimum coins to make amount a.

---

## Pseudo Code
```text
function coinChange(coins, amount)
    if amount == 0
        return 0
    INF = amount + 1
    dp = array of size amount + 1 filled with INF
    dp[0] = 0
    for a from 1 to amount
        for coin in coins
            if coin <= a
                dp[a] = min(dp[a], dp[a - coin] + 1)
    if dp[amount] <= amount
        return dp[amount]
    else
        return -1
```

---

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(amount * n) where n = number of coins |
| Space Complexity | O(amount)   |

## Other Patterns

### Pattern 1

**Idea**

Top-down DFS with memoization (recursive).

**Pseudo Code**

```text
function coinChangeTopDown(coins, amount)
    memo = map()
    function dfs(rem)
        if rem == 0
            return 0
        if rem < 0
            return INF
        if rem in memo
            return memo[rem]
        res = INF
        for coin in coins
            res = min(res, 1 + dfs(rem - coin))
        memo[rem] = res
        return res
    ans = dfs(amount)
    return ans if ans <= amount else -1
```

### Pattern 2

**Idea**

BFS on remainder states to find shortest number of coins (level order).

**Pseudo Code**

```text
function coinChangeBFS(coins, amount)
    if amount == 0
        return 0
    visited = set()
    queue = new queue()
    enqueue(queue, amount)
    steps = 0
    while queue not empty
        steps = steps + 1
        size = queue.size()
        for i from 1 to size
            rem = dequeue(queue)
            for coin in coins
                nextRem = rem - coin
                if nextRem == 0
                    return steps
                if nextRem > 0 and nextRem not in visited
                    add nextRem to visited
                    enqueue(queue, nextRem)
    return -1
```

## Comparison

| Approach         | Idea                                | Time                     | Space       | Recommended |
| ---------------- | ----------------------------------- | ------------------------ | ----------- | ----------- |
| Bottom-up DP     | Build dp for all amounts up to target | O(amount * n)            | O(amount)   | Yes         |
| Top-down Memo    | Recursive DFS with memo             | O(amount * n) amortized  | O(amount)   | Yes         |
| BFS              | Shortest path on state graph        | O(amount * n) worst-case | O(amount)   | No (useful when few reachable states) |
