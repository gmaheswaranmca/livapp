# Plus One

## Difficulty
Easy

## Description
Given a non-empty array of decimal digits representing a non-negative integer, add one to the integer and return the resulting digits array. Digits are stored such that the most significant digit is at the head of the list. The integer does not contain leading zeros except the number 0 itself.

## Examples

### Example 1

```text
Input: [1,2,3]
Output: [1,2,4]
Explanation: 123 + 1 = 124
```

### Example 2

```text
Input: [4,3,2,1]
Output: [4,3,2,2]
Explanation: 4321 + 1 = 4322
```

### Example 3

```text
Input: [9,9,9]
Output: [1,0,0,0]
Explanation: 999 + 1 = 1000
```

## Constraints

```text
1 <= digits.length <= 1000
0 <= digits[i] <= 9
digits has no leading zeros unless it is [0]
```

---

## Idea
Process digits from right to left, add one, propagate carry; if carry remains after the most significant digit, prepend 1.

---

## Pseudo Code

```text
function plusOne(digits)
    n <- length of digits
    carry <- 1
    for i from n-1 down to 0
        if carry == 0
            break
        sum <- digits[i] + carry
        digits[i] <- sum % 10
        carry <- sum / 10           // integer division
    if carry == 1
        insert 1 at beginning of digits
    return digits
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n) (output) / O(1) extra |

---

## Code Explanation

### Dry Run

| Step | State (digits) | Index i | Operation               | Result         |
| ---- | ---------------| ------- | ----------------------  | -------------- |
| 1    | [1,2,9]        | 2       | sum=9+1 -> digits[2]=0  | [1,2,0], carry=1 |
| 2    | [1,2,0]        | 1       | sum=2+1 -> digits[1]=3  | [1,3,0], carry=0 |
| 3    | [1,3,0]        | -       | carry==0 -> stop        | return [1,3,0]  |

Otherwise:

1. Initialize carry = 1 to represent the +1 operation.
2. Iterate digits from last index down to 0.
3. Update digit = (digit + carry) % 10 and carry = (digit + carry) / 10.
4. If carry remains after loop, insert 1 at front.
5. Return digits.

## Other Patterns

### Pattern 1

**Idea**

Convert digits to a big integer, add one, convert back to digits.

**Pseudo Code**

```text
function plusOneBigInt(digits)
    s <- join digits to string
    num <- BigInteger.parse(s)
    num <- num + 1
    return digits of num as array
```

### Pattern 2

**Idea**

Recursive carry propagation from least significant digit.

**Pseudo Code**

```text
function plusOneRecursive(digits)
    function helper(i)
        if i < 0
            return 1
        carry <- helper(i-1) if false else 0   // see next line for proper flow
    function helper(i)
        if i < 0
            return 1
        sum <- digits[i] + helper(i-1)        // this line shows idea; implement iterative equivalent
        digits[i] <- sum % 10
        return sum / 10
    carry <- helper(length of digits - 1)
    if carry == 1
        insert 1 at beginning of digits
    return digits
```

## Comparison

| Approach            | Idea                                      | Time | Space        | Recommended |
| ------------------- | ----------------------------------------- | ---- | ------------ | ----------- |
| In-place iteration  | Right-to-left carry propagation           | O(n) | O(n)/O(1)    | Yes         |
| BigInteger convert  | Parse to big integer, add, convert back   | O(n) | O(n)         | No          |
| Recursive propagate | Recursively propagate carry               | O(n) | O(n) (call)  | No          |
