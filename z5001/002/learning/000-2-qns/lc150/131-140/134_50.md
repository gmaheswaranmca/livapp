# Pow(x, n)

## Difficulty
Easy

## Description
Compute x raised to the integer power n (x^n). Handle negative n by returning 1 / (x^|n|). Use fast exponentiation (binary exponentiation) for optimal performance.

## Examples

### Example 1

```text
Input: x = 2, n = 10
Output: 1024
Explanation: 2^10 = 1024
```

### Example 2

```text
Input: x = 2.1, n = 3
Output: 9.261
Explanation: 2.1^3 = 9.261
```

### Example 3

```text
Input: x = 2, n = -2
Output: 0.25
Explanation: 2^-2 = 1 / (2^2) = 0.25
```

## Constraints

```text
x is a floating point number.
n is a 32-bit signed integer.
Result may require double precision.
Expect large |n| up to 2^31-1; use long/64-bit for exponent manipulation.
```

---

## Idea
Use binary exponentiation: square base and halve exponent, multiply result when exponent bit is 1.

---

## Pseudo Code

```text
function myPow(x: float, n: int) -> float
    if n == 0 return 1.0
    signNegative = (n < 0)
    power = absolute_value_as_long(n)
    result = 1.0
    base = x
    while power > 0
        if (power mod 2) == 1
            result = result * base
        base = base * base
        power = power // 2
    if signNegative return 1.0 / result
    return result
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log n) |
| Space Complexity | O(1) |

## Code Explanation

### Dry Run

| Step | State (base, power, result) | Operation | Result |
| ---- | --------------------------- | --------- | ------ |
| 1    | (2, 10, 1)                  | power even: square base, power//=2 | (4, 5, 1) |
| 2    | (4, 5, 1)                   | power odd: result*=base; square base; power//=2 | (16, 2, 4) |
| 3    | (16, 2, 4)                  | power even: square base; power//=2 | (256, 1, 4) |
| 4    | (256, 1, 4)                 | power odd: result*=base; square base; power//=2 | (65536, 0, 1024) |
| 5    | (65536, 0, 1024)            | finish | return 1024 |

## Other Patterns

### Pattern 1

**Idea**

Recursive divide and conquer: x^n = (x^(n/2))^2 and handle odd n.

**Pseudo Code**

```text
function myPowRecursive(x: float, n: int) -> float
    if n == 0 return 1.0
    if n < 0 return 1.0 / myPowRecursive(x, -n)
    half = myPowRecursive(x, n // 2)
    if n mod 2 == 0 return half * half
    return half * half * x
```

### Pattern 2

**Idea**

Naive iterative multiplication for small n or when simplicity preferred.

**Pseudo Code**

```text
function myPowNaive(x: float, n: int) -> float
    if n == 0 return 1.0
    signNegative = (n < 0)
    power = absolute_value_as_long(n)
    result = 1.0
    for i from 1 to power
        result = result * x
    if signNegative return 1.0 / result
    return result
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Iterative Binary Exponentiation | Square base and use bits of n | O(log n) | O(1) | Yes |
| Recursive Divide and Conquer | Recursively compute half powers | O(log n) | O(log n) (call stack) | No |
| Naive Iterative | Multiply x n times | O(n) | O(1) | No |
