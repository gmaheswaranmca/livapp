# Factorial Trailing Zeroes

## Difficulty
Easy

## Description
Given an integer n, return the number of trailing zeroes in n! (the factorial of n). Trailing zeroes are produced by pairs of prime factors 2 and 5; count occurrences of factor 5.

## Examples

### Example 1
```text
Input:  n = 5
Output: 1
Explanation: 5! = 120 has 1 trailing zero (one factor 5).
```

### Example 2
```text
Input:  n = 100
Output: 24
Explanation: floor(100/5)=20, floor(100/25)=4 -> 20+4=24 trailing zeroes.
```

### Example 3
```text
Input:  n = 0
Output: 0
Explanation: 0! = 1 has 0 trailing zeroes.
```

## Constraints
```text
0 <= n <= 10^18
Answer fits in 64-bit integer.
```

---

## Idea
Count how many times 5 (and powers of 5) divide n! by summing floor(n/5^k) while 5^k <= n.

---

## Pseudo Code
```text
function countTrailingZeroes(n)
    result = 0
    divisor = 5
    while divisor <= n
        result = result + floor(n / divisor)
        divisor = divisor * 5
    return result
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log_5 n) |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State                         | Operation                 | Result |
| ---- | ----------------------------- | ------------------------- | ------ |
| 1    | n=100, result=0, divisor=5    | floor(100/5)=20          | result=20, divisor=25 |
| 2    | n=100, result=20, divisor=25  | floor(100/25)=4          | result=24, divisor=125 |
| 3    | n=100, result=24, divisor=125 | divisor>n -> stop        | return 24 |

1. Initialize result=0 and divisor=5.
2. While divisor <= n add floor(n/divisor) to result and multiply divisor by 5.
3. Return result.

---

## Other Patterns

### Pattern 1

**Idea**

Repeatedly divide n by 5 and accumulate the quotients.

**Pseudo Code**

```text
function countTrailingZeroesDivideInPlace(n)
    result = 0
    while n > 0
        n = floor(n / 5)
        result = result + n
    return result
```

### Pattern 2

**Idea**

Recursive sum of floor(n/5^k) until term is zero.

**Pseudo Code**

```text
function countTrailingZeroesRecursive(n)
    if n < 5
        return 0
    return floor(n / 5) + countTrailingZeroesRecursive(floor(n / 5))
```

## Comparison

| Approach | Idea                               | Time         | Space | Recommended |
| -------- | ---------------------------------- | ------------ | ----- | ----------- |
| Iterative (divisor * 5) | Sum floor(n / 5^k) using divisor multiplier | O(log_5 n)  | O(1)  | Yes |
| In-place division       | Repeatedly n = floor(n/5) and add n        | O(log_5 n)  | O(1)  | Yes |
| Recursive              | Recursively sum floor(n/5^k)               | O(log_5 n)  | O(log_5 n) (call stack) | No |
