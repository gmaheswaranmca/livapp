# House Robber

## Difficulty
Medium

## Description
Given an array nums of non-negative integers representing money at each house, return the maximum amount you can rob without robbing two adjacent houses.

## Examples

### Example 1
```text
Input: nums = [1,2,3,1]
Output: 4
Explanation: Rob houses 1 and 3 (1 + 3 = 4).
```

### Example 2
```text
Input: nums = [2,7,9,3,1]
Output: 12
Explanation: Rob houses 1,3,5 (2 + 9 + 1 = 12).
```

## Constraints
```text
1 <= nums.length <= 10^5
0 <= nums[i] <= 10^5
Answer fits in 64-bit integer
```

---

## Idea
Use iterative DP with two variables tracking max up to previous and up to current (include/exclude pattern).

---

## Pseudo Code
```text
function rob(nums)
    if nums is empty then
        return 0
    prev = 0
    curr = 0
    for each num in nums do
        temp = curr
        curr = max(curr, prev + num)
        prev = temp
    return curr
```

---

## Complexity

| Metric           | Value     |
| ---------------- | --------- |
| Time Complexity  | O(n)      |
| Space Complexity | O(1)      |

---

## Code Explanation

### Dry Run

| Step | i | num | prev(before) | curr(before) | curr(after) = max(curr, prev+num) | prev(after) |
| ---- | - | --- | ------------ | ------------ | ---------------------------------- | ----------- |
| 1    | 0 | 1   | 0            | 0            | max(0,0+1)=1                        | 0           |
| 2    | 1 | 2   | 0            | 1            | max(1,0+2)=2                        | 1           |
| 3    | 2 | 3   | 1            | 2            | max(2,1+3)=4                        | 2           |
| 4    | 3 | 1   | 2            | 4            | max(4,2+1)=4                        | 4           |

1. Initialize prev=0 (max excluding previous), curr=0 (max including up to previous).
2. For each house value num compute new curr as max(curr, prev+num).
3. Update prev to old curr and continue.
4. Return curr as maximum robbable amount.

## Other Patterns

### Pattern 1

**Idea**
Standard DP array storing best up to each index.

**Pseudo Code**
```text
function rob_dp_array(nums)
    n = length of nums
    if n == 0 then
        return 0
    if n == 1 then
        return nums[0]
    dp = array of size n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i from 2 to n-1 do
        dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    return dp[n-1]
```

### Pattern 2

**Idea**
Top-down recursion with memoization.

**Pseudo Code**
```text
function rob_memo(nums)
    n = length of nums
    memo = map()
    function dfs(i)
        if i >= n then
            return 0
        if memo contains i then
            return memo[i]
        take = nums[i] + dfs(i + 2)
        skip = dfs(i + 1)
        memo[i] = max(take, skip)
        return memo[i]
    return dfs(0)
```

## Comparison

| Approach         | Idea                                | Time    | Space    | Recommended |
| ---------------- | ----------------------------------- | ------- | -------- | ----------- |
| Optimized DP     | Two variables track prev and curr   | O(n)    | O(1)     | Yes        |
| DP Array         | dp[i] = max(dp[i-1], dp[i-2]+nums[i]) | O(n)    | O(n)     | No         |
| Recursion+Memo   | Top-down include/exclude with memo  | O(n)    | O(n)     | No         |
