# Integer Square Root (floor)

## Difficulty
Easy

## Description
Compute the integer square root of a non-negative integer x, i.e., the greatest integer r such that r * r <= x.

## Examples

### Example 1

```text
Input: 8
Output: 2
Explanation: floor(sqrt(8)) = 2
```

### Example 2

```text
Input: 0
Output: 0
Explanation: floor(sqrt(0)) = 0
```

### Example 3

```text
Input: 16
Output: 4
Explanation: floor(sqrt(16)) = 4
```

## Constraints

```text
0 <= x <= 2^31 - 1
Time limit: typical interview constraints
Memory limit: O(1) additional space
```

---

## Idea
Binary search on the answer range [0, x] (or [1, x//2] for x>=2) using division to avoid overflow.

---

## Pseudo Code

```text
function integerSqrt(x)
    if x < 2 return x
    low = 1
    high = x // 2
    result = 1
    while low <= high
        mid = low + (high - low) // 2
        if mid > x // mid
            high = mid - 1
        else
            result = mid
            low = mid + 1
    return result
```

| Metric           | Value     |
| ---------------- | --------- |
| Time Complexity  | O(log x)  |

## Code Explanation

### Dry Run

| Step | State (low, high, mid, result) | Operation                        | Result |
| ---- | ------------------------------ | -------------------------------- | ------ |
| 1    | (1, 4, -, 1)                   | mid = (1+4)//2 = 2               | mid=2  |
| 2    | (1, 4, 2, 1)                   | 2 > 8//2 ? false -> result=2; low=3 | (3,4,2,2) |
| 3    | (3, 4, -, 2)                   | mid = (3+4)//2 = 3               | mid=3  |
| 4    | (3, 4, 3, 2)                   | 3 > 8//3 ? true -> high=2        | (3,2,3,2) |
| 5    | low=3 high=2                   | loop ends                        | return 2 |

## Other Patterns

### Pattern 1

**Idea**
Newton's (Heron) method to converge to sqrt(x).

**Pseudo Code**

```text
function integerSqrtNewton(x)
    if x < 2 return x
    r = x
    while r * r > x
        r = (r + x // r) // 2
    return r
```

### Pattern 2

**Idea**
Use language builtin sqrt and floor (subject to floating point precision).

**Pseudo Code**

```text
function integerSqrtBuiltin(x)
    y = floor(sqrt(x))
    if (y+1)*(y+1) <= x return y+1
    return y
```

## Comparison

| Approach        | Idea                              | Time        | Space | Recommended |
| --------------- | --------------------------------- | ----------- | ----- | ----------- |
| Binary Search   | Search integer answer with division to avoid overflow | O(log x)    | O(1)  | Yes         |
| Newton's Method | Iterative convergence using averages | O(log x) amortized | O(1)  | Yes (fast)  |
| Builtin sqrt    | Use floating sqrt then fix edge case | O(1)        | O(1)  | No (precision issues) |
