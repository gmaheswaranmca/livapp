# Word Break

## Difficulty
Medium

## Description
Given a string s and a list of words wordDict, determine if s can be segmented into a sequence of one or more dictionary words. Words can be reused from wordDict.

## Examples

### Example 1

```text
Input: s = "leetcode", wordDict = ["leet","code"]
Output: true
Explanation: "leetcode" -> "leet" + "code"
```

### Example 2

```text
Input: s = "applepenapple", wordDict = ["apple","pen"]
Output: true
Explanation: "applepenapple" -> "apple" + "pen" + "apple"
```

### Example 3

```text
Input: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
Output: false
Explanation: no segmentation covers entire string
```

## Constraints

```text
1 <= s.length <= 300
1 <= wordDict.length <= 1000
1 <= word.length <= 20
s and words consist of lowercase English letters only
```

---

## Idea
Use dynamic programming on prefixes: dp[i] = true if s[0:i] can be segmented.

---

## Pseudo Code

```text
function wordBreak(s, wordDict)
    n := length(s)
    dict := set(wordDict)
    dp := array of false of size n+1
    dp[0] := true
    for i from 1 to n
        for j from 0 to i-1
            if dp[j] and substring(s, j, i) in dict
                dp[i] := true
                break
    return dp[n]
```

---

## Complexity

| Metric           | Value     |
| ---------------- | --------- |
| Time Complexity  | O(n^2)    |
| Space Complexity | O(n)      |

---

## Code Explanation

### Dry Run

| Step | State (dp)               | Operation                         | Result                         |
| ---- | ------------------------ | --------------------------------- | ------------------------------ |
| 1    | dp = [T, F, F, F, F, F, F, F, F] | i=4, j=0, substring(0,4)="leet" in dict | dp[4]=T                        |
| 2    | dp = [T, F, F, F, T, F, F, F, F] | i=8, j=4, dp[4]=T, substring(4,8)="code" in dict | dp[8]=T                        |
| 3    | dp = [..., T]             | end of loops                      | return dp[8]=T                 |

1. Initialize dp[0]=true (empty prefix).
2. For each prefix length i, check all split points j where dp[j] is true and s[j:i] is a word.
3. If any valid split found set dp[i]=true and stop further j for that i.
4. Final answer is dp[n].

## Other Patterns

### Pattern 1

**Idea**

Top-down DFS with memoization to avoid repeated work.

**Pseudo Code**

```text
function wordBreakDFS(s, wordDict)
    dict := set(wordDict)
    n := length(s)
    memo := map<int,bool>
    return dfs(0)

function dfs(start)
    if start == n
        return true
    if start in memo
        return memo[start]
    for end from start+1 to n
        if substring(s, start, end) in dict and dfs(end)
            memo[start] := true
            return true
    memo[start] := false
    return false
```

### Pattern 2

**Idea**

BFS on indices: treat indices as nodes and words as edges; find a path from 0 to n.

**Pseudo Code**

```text
function wordBreakBFS(s, wordDict)
    dict := set(wordDict)
    n := length(s)
    queue := empty queue
    visited := array of false of size n+1
    enqueue(queue, 0)
    visited[0] := true
    while queue not empty
        start := dequeue(queue)
        for end from start+1 to n
            if not visited[end] and substring(s, start, end) in dict
                if end == n
                    return true
                enqueue(queue, end)
                visited[end] := true
    return false
```
