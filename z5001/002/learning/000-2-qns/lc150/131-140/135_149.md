# Max Points on a Line

## Difficulty
Medium

## Description
Given a list of points in a 2D plane, find the maximum number of points that lie on a single straight line.

## Examples

### Example 1

```text
Input: points = [[1,1],[2,2],[3,3]]
Output: 3
Explanation: All three points lie on the line y = x.
```

### Example 2

```text
Input: points = [[1,1],[1,1],[2,2]]
Output: 3
Explanation: Duplicate points count; all three are collinear.
```

## Constraints

```text
1 <= points.length <= 300
points[i].length == 2
-10^4 <= points[i][j] <= 10^4
Points are integer coordinates.
```

---

## Idea
For each point, count slopes to all other points using a hashmap of normalized (dx,dy) to find the line through that base point with most points; handle duplicates and vertical/horizontal normalization.

---

## Pseudo Code

```text
function maxPoints(points)
    n = length(points)
    if n < 3 return n
    result = 0
    for i from 0 to n-1
        map = empty hash map from pair to int
        duplicates = 1
        currentMax = 0
        for j from i+1 to n-1
            dx = points[j].x - points[i].x
            dy = points[j].y - points[i].y
            if dx == 0 and dy == 0
                duplicates = duplicates + 1
                continue
            g = gcd(abs(dx), abs(dy))
            dx = dx / g
            dy = dy / g
            if dx < 0 then dx = -dx; dy = -dy
            else if dx == 0 and dy < 0 then dy = -dy
            key = (dx, dy)
            map[key] = map.get(key, 0) + 1
            currentMax = max(currentMax, map[key])
        result = max(result, currentMax + duplicates)
    return result

function gcd(a, b)
    while b != 0
        temp = a % b
        a = b
        b = temp
    return a
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n^2) |
| Space Complexity | O(n)   |

## Code Explanation

### Dry Run

| Step | State                        | Operation                                      | Result |
| ---- | ---------------------------- | ---------------------------------------------- | ------ |
| 1    | i=0 base=(1,1), map={}, dup=1| j=1: compute dx=1, dy=1, g=1, key=(1,1)       | map[(1,1)]=1, currMax=1 |
| 2    | i=0                         | j=2: compute dx=2, dy=2, g=2, key=(1,1)       | map[(1,1)]=2, currMax=2 |
| 3    | end i=0                     | result = max(0, 2+1) = 3                       | result=3 |
| 4    | others                      | would not exceed 3                             | final 3 |

## Other Patterns

### Pattern 1

**Idea**

Use normalized line coefficients (A,B,C) for ax+by+c=0 stored in hashmap.

**Pseudo Code**

```text
function maxPointsLineCoefficients(points)
    n = length(points)
    if n < 3 return n
    result = 0
    for i from 0 to n-1
        map = empty hash map from tuple to int
        duplicates = 1
        currentMax = 0
        for j from i+1 to n-1
            x1,y1 = points[i]; x2,y2 = points[j]
            A = y2 - y1
            B = x1 - x2
            C = x2*y1 - x1*y2
            g = gcd(abs(A), abs(B), abs(C))
            A = A / g; B = B / g; C = C / g
            if A < 0 or (A == 0 and B < 0) then A=-A; B=-B; C=-C
            if A==0 and B==0 and C==0 then duplicates=duplicates+1 else
                key=(A,B,C)
                map[key] = map.get(key,0) + 1
                currentMax = max(currentMax, map[key])
        result = max(result, currentMax + duplicates)
    return result

function gcd(a,b,c)
    return gcd(gcd(a,b),c)
```

### Pattern 2

**Idea**

Brute force: for every pair of points, count how many other points lie on that line (O(n^3)).

**Pseudo Code**

```text
function maxPointsBrute(points)
    n = length(points)
    if n < 3 return n
    result = 0
    for i from 0 to n-1
        for j from i+1 to n-1
            count = 2
            for k from j+1 to n-1
                if collinear(points[i], points[j], points[k]) then count = count + 1
            result = max(result, count)
    return result

function collinear(a,b,c)
    return (b.y - a.y)*(c.x - a.x) == (c.y - a.y)*(b.x - a.x)
```

## Comparison

| Approach                | Idea                                      | Time   | Space | Recommended |
| ----------------------- | ----------------------------------------- | ------ | ----- | ----------- |
| Slope HashMap (main)    | Normalize slope (dx,dy) per base point    | O(n^2) | O(n)  | Yes         |
| Line Coefficients Hash  | Normalize (A,B,C) for each line           | O(n^2) | O(n)  | No (similar) |
| Brute Force             | Check every pair and count collinear pts  | O(n^3) | O(1)  | No          |
