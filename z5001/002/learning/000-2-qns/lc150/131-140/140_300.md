# Longest Increasing Subsequence

## Difficulty
Medium

## Description
Given an integer array nums, return the length of the longest strictly increasing subsequence.

## Examples

### Example 1
```text
Input: [10,9,2,5,3,7,101,18]
Output: 4
Explanation: The longest increasing subsequence is [2,3,7,101] or [2,3,7,18].
```

## Constraints
```text
1 <= nums.length <= 10^5
-10^9 <= nums[i] <= 10^9
Expected time: O(n log n) for large n
```

---

## Idea
Maintain a "tails" array where tails[i] = minimum possible tail value of an increasing subsequence of length i+1, and use binary search to update it.

---

## Pseudo Code
```text
function lengthOfLIS(nums)
    if nums is empty
        return 0
    tails := empty list
    for each x in nums
        if tails is empty OR x > tails[last index]
            append x to tails
        else
            idx := lower_bound(tails, x)
            tails[idx] := x
    return length of tails

function lower_bound(arr, target)
    left := 0
    right := length of arr - 1
    result := length of arr
    while left <= right
        mid := left + (right - left) // 2
        if arr[mid] >= target
            result := mid
            right := mid - 1
        else
            left := mid + 1
    return result
```

## Code Explanation

### Dry Run

| Step | Value | Operation | Tails |
| ---- | ----- | --------- | ----- |
| 1 | 10 | append (tails empty) | [10] |
| 2 | 9 | replace lower_bound(>=9) at idx 0 | [9] |
| 3 | 2 | replace idx 0 | [2] |
| 4 | 5 | append (5>2) | [2,5] |
| 5 | 3 | replace idx 1 | [2,3] |
| 6 | 7 | append (7>3) | [2,3,7] |
| 7 | 101 | append (101>7) | [2,3,7,101] |
| 8 | 18 | replace idx 3 | [2,3,7,18] |
| result | - | length of tails | 4 |

## Other Patterns

### Pattern 1

**Idea**
Dynamic programming O(n^2) computing LIS ending at each index.

**Pseudo Code**
```text
function lengthOfLIS_DP(nums)
    if nums is empty
        return 0
    n := length of nums
    dp := array of size n filled with 1
    best := 1
    for i from 0 to n-1
        for j from 0 to i-1
            if nums[j] < nums[i]
                dp[i] := max(dp[i], dp[j] + 1)
        best := max(best, dp[i])
    return best
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Patience + Binary Search | Maintain tails and binary search position | O(n log n) | O(n) | Yes |
| Dynamic Programming | dp[i] = 1 + max dp[j] for all j<i with nums[j]<nums[i] | O(n^2) | O(n) | No |
