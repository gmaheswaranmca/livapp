# Triangle - Minimum Path Sum

## Difficulty
Medium

## Description
Given a triangle array, return the minimum path sum from top to bottom. Each step you may move to adjacent numbers on the row below.

## Examples

### Example 1
```text
Input: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
Output: 11
Explanation: 2 + 3 + 5 + 1 = 11
```

### Example 2
```text
Input: triangle = [[-1]]
Output: -1
Explanation: Single element.
```

## Constraints
```text
1 <= number of rows <= 200
triangle[i].length == i + 1
-10^4 <= triangle[i][j] <= 10^4
Total elements N = 1 + 2 + ... + R = O(R^2)
```

---

## Idea
Bottom-up DP: propagate minimum child costs from the last row up to the top.

---

## Pseudo Code
```text
function solve(triangle)
    if triangle is empty return 0
    R = number of rows in triangle
    dp = copy of triangle[R-1]             // 1D array of size R
    for r from R-2 down to 0
        row = triangle[r]
        for i from 0 to length(row)-1
            left = dp[i]
            right = dp[i+1]
            dp[i] = row[i] + min(left, right)
    return dp[0]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(N) where N is total elements |
| Space Complexity | O(R) where R is number of rows |

### Dry Run

| Step | State (dp)        | Operation                                   | Result (dp)      |
| ---- | ----------------- | ------------------------------------------- | ---------------- |
| 1    | [4,1,8,3]         | start with last row                          | [4,1,8,3]        |
| 2    | [4,1,8,3]         | row [6,5,7]: dp[0]=6+min(4,1)=10; dp[1]=5+min(1,8)=6; dp[2]=7+min(8,3)=15 | [10,6,15]       |

| 5    | [11]              | return dp[0]                                 | 11               |

## Other Patterns

### Pattern 1
**Idea**
Bottom-up in-place: overwrite triangle rows from bottom to top to save extra space.

**Pseudo Code**
```text
function solve(triangle)
    if triangle is empty return 0
    for r from number of rows-2 down to 0
        for i from 0 to length(triangle[r])-1
            triangle[r][i] = triangle[r][i] + min(triangle[r+1][i], triangle[r+1][i+1])
    return triangle[0][0]
```

### Pattern 2
**Idea**
Top-down recursion with memoization (row, index) caches minimum path sum.

**Pseudo Code**
```text
function solve(triangle)
    R = number of rows
    memo = map or 2D array initialized with null
    function dfs(r,i)
        if r == R return 0
        if memo[r][i] is not null return memo[r][i]
        val = triangle[r][i] + min(dfs(r+1,i), dfs(r+1,i+1))
        memo[r][i] = val
        return val
    return dfs(0,0)
```

### Pattern 3
**Idea**
Brute-force DFS exploring all paths (exponential) — not recommended.

**Pseudo Code**
```text
function solve(triangle)
    R = number of rows
    best = +infinity
    function dfs(r,i,sum)
        if r == R
            best = min(best,sum)
            return
        dfs(r+1,i,sum + triangle[r][i])
        dfs(r+1,i+1,sum + triangle[r][i])
    dfs(0,0,0)
    return best
```

## Comparison

| Approach           | Idea                                | Time        | Space   | Recommended |
| ------------------ | ----------------------------------- | ----------- | ------- | ----------- |
| Bottom-up (1D DP)  | Propagate min costs using 1D array  | O(N)        | O(R)    | Yes         |
| Bottom-up (in-place)| Overwrite triangle rows             | O(N)        | O(1)    | Yes (if mutating allowed) |
| Top-down memo      | Recursion with memoization          | O(N)        | O(N)    | Yes (clear intent) |
| Brute-force DFS    | Explore all paths                   | O(2^R)      | O(R)    | No          |
