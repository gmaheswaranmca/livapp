# Title
Minimum Path Sum

## Difficulty
Medium

## Description
Given an m x n grid filled with non-negative integers, find a path from top-left to bottom-right which minimizes the sum of all numbers along the path. You can only move either down or right at any point.

## Examples

### Example 1

```text
Input: grid = [[1,3,1],[1,5,1],[4,2,1]]
Output: 7
Explanation: Path 1→3→1→1→1 yields sum = 7.
```

## Constraints

```text
1 <= m, n <= 1000
grid[i][j] are non-negative integers
Expected solution uses O(m*n) time or O(n) space
```

---

## Idea
Dynamic programming: dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1]) with boundary handling.

---

## Pseudo Code

```text
function minPathSum(grid)
    if grid is empty return 0
    m = number of rows in grid
    n = number of columns in grid
    for i from 0 to m-1
        for j from 0 to n-1
            if i == 0 and j == 0 continue
            top = +INF if i == 0 else grid[i-1][j]
            left = +INF if j == 0 else grid[i][j-1]
            grid[i][j] = grid[i][j] + min(top, left)
    return grid[m-1][n-1]
```

| Metric           | Value  |

## Code Explanation

### Dry Run

| Step | State (grid after updates) | Operation | Result |
| ---- | -------------------------- | --------- | ------ |
| 1    | [[1,3,1],[1,5,1],[4,2,1]]  | start     | initial |
| 2    | [[1,4,5],[1,5,1],[4,2,1]]  | update (0,1)=3+1, (0,2)=1+4 | first row cumulative |
| 3    | [[1,4,5],[2,7,6],[4,2,1]]  | update row1: (1,0)=1+1, (1,1)=5+min(4,2)=7, (1,2)=1+min(5,7)=6 |
| 4    | [[1,4,5],[2,7,6],[6,8,7]]  | update row2 similarly; final cell (2,2)=7 |
| 5    | 7                          | return    | minimum path sum |

## Other Patterns

### Pattern 1

**Idea**
Use a 1D DP array of size n to reduce space to O(n).

**Pseudo Code**

```text
function minPathSum1D(grid)
    if grid is empty return 0
    m = rows, n = cols
    dp = array of size n filled with +INF
    dp[0] = 0
    for i from 0 to m-1
        for j from 0 to n-1
            if j == 0
                dp[j] = dp[j] + grid[i][j]
            else
                dp[j] = min(dp[j], dp[j-1]) + grid[i][j]
    return dp[n-1]
```

### Pattern 2

**Idea**
Model as shortest path on a directed acyclic grid graph and run Dijkstra (overkill but generalizes to variable move costs).

**Pseudo Code**

```text
function minPathSumDijkstra(grid)
    if grid is empty return 0
    m = rows, n = cols
    dist = 2D array filled with +INF
    dist[0][0] = grid[0][0]
    pq = min-priority queue of (dist, i, j)
    push (dist[0][0], 0, 0) into pq
    while pq not empty
        (d, i, j) = pop pq
        if d > dist[i][j] continue
        for (ni, nj) in {(i+1,j),(i,j+1)}
            if ni in range and nj in range and dist[ni][nj] > d + grid[ni][nj]
                dist[ni][nj] = d + grid[ni][nj]
                push (dist[ni][nj], ni, nj) into pq
    return dist[m-1][n-1]
```

## Comparison

| Approach  | Idea                            | Time      | Space    | Recommended |
| --------- | ------------------------------- | --------- | -------- | ----------- |
| In-place DP | Update grid with cumulative sums | O(m*n)    | O(1)     | Yes        |
| 1D DP     | Maintain rolling array per row   | O(m*n)    | O(n)     | Yes (if cannot modify input) |
| Dijkstra  | General shortest path on grid    | O(m*n log(m*n)) | O(m*n) | No         |
