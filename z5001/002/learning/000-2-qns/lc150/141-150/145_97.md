# Interleaving String

## Difficulty
Medium

## Description
Given strings s1, s2, s3, determine if s3 is formed by interleaving s1 and s2 (preserving character order from each).

## Examples

### Example 1
```text
Input: s1="aabcc", s2="dbbca", s3="aadbbcbcac"
Output: true
Explanation: s3 can be formed by interleaving s1 and s2.
```

### Example 2
```text
Input: s1="a", s2="b", s3="ab"
Output: true
```

### Example 3
```text
Input: s1="a", s2="b", s3="ba"
Output: true
```

### Example 4
```text
Input: s1="aab", s2="axy", s3="abaaxy"
Output: false
```

## Constraints
```text
0 <= len(s1), len(s2) <= 1000
len(s3) == len(s1) + len(s2)
All strings contain printable characters.
```

---

## Idea
Use a 2D DP table dp[i][j] = whether s3[0..i+j-1] is interleaving of s1[0..i-1] and s2[0..j-1].

---

## Pseudo Code
```text
function isInterleave(s1, s2, s3)
    n = length(s1)
    m = length(s2)
    if length(s3) != n + m then return false
    create dp array of size (n+1) x (m+1) initialized to false
    dp[0][0] = true
    for i from 1 to n
        dp[i][0] = dp[i-1][0] and s1[i-1] == s3[i-1]
    for j from 1 to m
        dp[0][j] = dp[0][j-1] and s2[j-1] == s3[j-1]
    for i from 1 to n
        for j from 1 to m
            match1 = dp[i-1][j] and s1[i-1] == s3[i+j-1]
            match2 = dp[i][j-1] and s2[j-1] == s3[i+j-1]
            dp[i][j] = match1 or match2
    return dp[n][m]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n * m) |
| Space Complexity | O(n * m) (can be reduced to O(m)) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | lengths n=5,m=5 -> total=10 equals len(s3)=10 | length check | continue |
| 2 | dp initialized 6x6 with dp[0][0]=T | fill first column with s1 vs s3 | dp[1][0]=T, dp[2][0]=T, others false |
| 3 | fill first row with s2 vs s3 | dp[0][1..5]=F (s2[0] != s3[0]) | first row mostly false |
| 4 | iterate i=1..5, j=1..5 applying recurrence | fill internal cells using matches from s1/s2 to s3 | dp[5][5] = true (final answer) |

## Other Patterns

### Pattern 2

**Idea**

Top-down DFS with memoization: try consuming chars from s1 or s2 and memoize (i,j) states.

**Pseudo Code**

```text
function isInterleaveDFS(s1, s2, s3)
    if length(s3) != length(s1) + length(s2) then return false
    create memo dictionary
    return dfs(0,0,0)

function dfs(i, j, k)
    if k == length(s3) then return i == length(s1) and j == length(s2)
    if (i,j) in memo then return memo[(i,j)]
    valid = false
    if i < length(s1) and s1[i] == s3[k]
        valid = valid or dfs(i+1, j, k+1)
    if not valid and j < length(s2) and s2[j] == s3[k]
        valid = valid or dfs(i, j+1, k+1)
    memo[(i,j)] = valid
    return valid
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| 2D DP | Bottom-up table dp over indices of s1 and s2 | O(n*m) | O(n*m) | Yes |
| DFS + Memo | Top-down recursion with memo on (i,j) | O(n*m) amortized | O(n*m) | Yes (if recursion allowed) |
