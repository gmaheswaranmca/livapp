# Maximal Square

## Difficulty
Medium

## Description
Given a 2D binary matrix of characters '0' and '1', return the area of the largest square containing only '1's.

## Examples

### Example 1

```text
Input: matrix = [["1","0"],["1","1"]]
Output: 1
Explanation: Largest square has side length 1, area = 1.
```

## Constraints

```text
1 <= rows, cols <= 300
matrix[i][j] is '0' or '1'
```

---

## Idea
DP: dp[i][j] = side length of largest square with bottom-right at (i,j) = 0 if cell is '0', else min(top,left,diag)+1.

---

## Pseudo Code

```text
function maximalSquare(matrix)
    if matrix is empty return 0
    rows = number of rows in matrix
    cols = number of cols in matrix
    create dp array of size (rows+1) x (cols+1) filled with 0
    maxSide = 0
    for i from 1 to rows
        for j from 1 to cols
            if matrix[i-1][j-1] == '1'
                dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
                if dp[i][j] > maxSide
                    maxSide = dp[i][j]
            else
                dp[i][j] = 0
    return maxSide * maxSide
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(rows * cols) |
| Space Complexity | O(rows * cols) |

---

## Code Explanation

### Dry Run

| Step | State (i,j) | Operation | Result (dp partial) |
| ---- | ----------- | --------- | ------------------- |
| 1    | start       | dp zeros with size 3x3 | dp = [[0,0,0],[0,0,0],[0,0,0]] maxSide=0 |
| 2    | (1,1)       | matrix[0][0]='1' -> dp[1][1]=1 | dp row1=[0,1,0] maxSide=1 |
| 3    | (1,2)       | matrix[0][1]='0' -> dp[1][2]=0 | dp row1=[0,1,0] maxSide=1 |
| 4    | (2,1)       | matrix[1][0]='1' -> dp[2][1]=1 | dp row2=[0,1,0] maxSide=1 |
| 5    | (2,2)       | matrix[1][1]='1' -> dp[2][2]=min(0,1,1)+1=1 | dp row2=[0,1,1] maxSide=1 |
| 6    | end         | return maxSide*maxSide = 1 | result = 1 |

## Other Patterns

### Pattern 1

**Idea**

Brute force check every possible square.

**Pseudo Code**

```text
function maximalSquareBrute(matrix)
    rows = number of rows
    cols = number of cols
    maxSide = 0
    for i from 0 to rows-1
        for j from 0 to cols-1
            if matrix[i][j] == '1'
                side = 1
                while i+side-1 < rows and j+side-1 < cols
                    if all cells in square (i..i+side-1, j..j+side-1) are '1'
                        maxSide = max(maxSide, side)
                        side = side + 1
                    else
                        break
    return maxSide * maxSide
```

### Pattern 2

**Idea**

DP with rolling 1D array to reduce space to O(cols).

**Pseudo Code**

```text
function maximalSquareRolling(matrix)
    if matrix is empty return 0
    rows = number of rows
    cols = number of cols
    create dp array of size cols+1 filled with 0
    prev = 0
    maxSide = 0
    for i from 1 to rows
        prev = 0
        for j from 1 to cols
            temp = dp[j]
            if matrix[i-1][j-1] == '1'
                dp[j] = min(dp[j], dp[j-1], prev) + 1
                if dp[j] > maxSide
                    maxSide = dp[j]
            else
                dp[j] = 0
            prev = temp
    return maxSide * maxSide
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| 2D DP    | Use top,left,diag relations | O(rows*cols) | O(rows*cols) | Yes |
| Rolling DP | 1D dp with prev diag | O(rows*cols) | O(cols) | Yes |
| Brute Force | Check every square explicitly | O(rows*cols*min(rows,cols)) worst-case per check | O(1) | No |
