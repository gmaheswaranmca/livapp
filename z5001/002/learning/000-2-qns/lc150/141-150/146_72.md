# Edit Distance (Levenshtein Distance)

## Difficulty
Medium

## Description
Find the minimum number of operations (insert, delete, replace) required to convert string word1 into string word2.

## Examples

### Example 1

```text
Input: word1 = "horse", word2 = "ros"
Output: 3
Explanation: horse -> rorse (replace 'h' with 'r') -> rose (delete 'r') -> ros (delete 'e')
```

### Example 2

```text
Input: word1 = "intention", word2 = "execution"
Output: 5
Explanation: Common minimal sequence of insert/delete/replace operations = 5
```

## Constraints

```text
0 <= word1.length, word2.length <= 500
word1 and word2 contain lowercase/uppercase letters or digits
Aim for O(m*n) time and O(min(m,n)) space when possible
```

---

## Idea
Use dynamic programming where dp[i][j] = min operations to convert prefix word1[0..i-1] to prefix word2[0..j-1].

---

## Pseudo Code

```text
function editDistance(word1, word2)
    let m = length(word1)
    let n = length(word2)
    create dp matrix of size (m+1) x (n+1)
    for i from 0 to m
        dp[i][0] = i
    for j from 0 to n
        dp[0][j] = j
    for i from 1 to m
        for j from 1 to n
            if word1[i-1] == word2[j-1]
                dp[i][j] = dp[i-1][j-1]
            else
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(m * n) (can be optimized to O(min(m,n))) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | Initialize dp with dimensions 6 x 4 (for "horse"(m=5) and "ros"(n=3)) | set first row and column | dp rows = [0,1,2,3]; first column = [0,1,2,3,4,5] |
| 2 | Compute dp[1][1] where word1[0]='h', word2[0]='r' | chars differ -> dp[1][1] = 1 + min(dp[0][1],dp[1][0],dp[0][0]) = 1 | dp[1][1]=1 |
| 3 | Compute remaining cells iteratively | fill table using recurrence | final dp matrix yields dp[5][3]=3 |
| 4 | Return result | dp[5][3] | 3 |

## Other Patterns

### Pattern 1

**Idea**

Top-down recursion with memoization.

**Pseudo Code**

```text
function editDistanceMemo(word1, word2)
    let m = length(word1)
    let n = length(word2)
    create memo map from pair(i,j) to int
    return helper(m, n)

function helper(i, j)
    if (i == 0) return j
    if (j == 0) return i
    if memo contains (i,j) return memo[(i,j)]
    if word1[i-1] == word2[j-1]
        res = helper(i-1, j-1)
    else
        res = 1 + min(helper(i-1, j), helper(i, j-1), helper(i-1, j-1))
    memo[(i,j)] = res
    return res
```

### Pattern 2

**Idea**

Space-optimized bottom-up DP using two rows (or one row) since current row depends only on previous row.

**Pseudo Code**

```text
function editDistanceSpaceOptimized(word1, word2)
    if length(word1) < length(word2) swap(word1, word2)
    let m = length(word1)
    let n = length(word2)
    create prev array of size n+1
    create curr array of size n+1
    for j from 0 to n
        prev[j] = j
    for i from 1 to m
        curr[0] = i
        for j from 1 to n
            if word1[i-1] == word2[j-1]
                curr[j] = prev[j-1]
            else
                curr[j] = 1 + min(prev[j], curr[j-1], prev[j-1])
        swap(prev, curr)
    return prev[n]
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Bottom-up DP | 2D DP table (insert/delete/replace) | O(m*n) | O(m*n) | Yes |
| Top-down Memoization | Recursion with memo | O(m*n) | O(m*n) (recursion stack) | Yes |
| Space-optimized DP | Two rows or one row | O(m*n) | O(min(m,n)) | Yes (when memory constrained) |
