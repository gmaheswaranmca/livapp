# Title
Longest Palindromic Substring

## Difficulty
Medium

## Description
Given a string s, return the longest substring of s that is a palindrome.

## Examples

### Example 1
```text
Input: s = "babad"
Output: "bab"
Explanation: "aba" is also valid; either is acceptable.
```

### Example 2
```text
Input: s = "cbbd"
Output: "bb"
Explanation: longest palindromic substring is "bb".
```

## Constraints
```text
1 <= s.length <= 1000
s consists of printable ASCII characters
```

---

## Idea
Expand around each center (odd and even) to find the longest palindrome in O(n^2) time and O(1) extra space.

---

## Pseudo Code
```text
function longestPalindrome(s)
    if s is null or length(s) < 1 then
        return ""
    start <- 0
    end <- 0
    for i from 0 to length(s)-1
        len1 <- expandFromCenter(s, i, i)         // odd-length
        len2 <- expandFromCenter(s, i, i+1)       // even-length
        len <- max(len1, len2)
        if len > end - start + 1 then
            start <- i - (len - 1) / 2
            end <- i + len / 2
    return substring(s, start, end+1)

function expandFromCenter(s, left, right)
    while left >= 0 and right < length(s) and s[left] == s[right]
        left <- left - 1
        right <- right + 1
    return right - left - 1   // length of palindrome
```

## Other Patterns

### Pattern 1

**Idea**

Dynamic Programming table: dp[i][j] indicates s[i..j] is palindrome.

**Pseudo Code**
```text
function longestPalindromeDP(s)
    n <- length(s)
    if n == 0 then return ""
    dp <- n x n matrix initialized false
    start <- 0
    maxLen <- 1
    for i from 0 to n-1
        dp[i][i] <- true
    for L from 2 to n
        for i from 0 to n-L
            j <- i + L - 1
            if s[i] == s[j] and (L == 2 or dp[i+1][j-1] == true)
                dp[i][j] <- true
                if L > maxLen
                    start <- i
                    maxLen <- L
    return substring(s, start, start+maxLen)
```

### Pattern 2

**Idea**

Manacher's algorithm to get O(n) time by transforming string and using radius array.

**Pseudo Code**
```text
function longestPalindromeManacher(s)
    if s is empty then return ""
    t <- '^'
    for each char c in s
        t <- t + '#' + c
    t <- t + "#$"
    n <- length(t)
    P <- array of zeros length n
    center <- 0
    right <- 0
    for i from 1 to n-2
        mirror <- 2*center - i
        if right > i
            P[i] <- min(right - i, P[mirror])
        while t[i + 1 + P[i]] == t[i - 1 - P[i]]
            P[i] <- P[i] + 1
        if i + P[i] > right
            center <- i
            right <- i + P[i]
    maxLen <- max value in P
    centerIndex <- index of maxLen in P
    start <- (centerIndex - maxLen - 1) / 2
    return substring(s, start, start + maxLen)
```
