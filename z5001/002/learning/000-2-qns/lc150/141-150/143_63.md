# Unique Paths II

## Difficulty
Medium

## Description
Count number of unique paths from top-left to bottom-right in an m x n grid with obstacles (1 = obstacle, 0 = free). You can only move right or down. Return 0 if start or end is blocked.

## Examples

### Example 1

```text
Input: obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
Output: 2
Explanation: Two paths avoid the obstacle at (1,1).
```

### Example 2

```text
Input: obstacleGrid = [[0,1],[0,0]]
Output: 1
Explanation: Only one path (down, right).
```

## Constraints

```text
1 <= m, n <= 100
obstacleGrid[i][j] ∈ {0,1}
Start (0,0) and end (m-1,n-1) may be blocked
```

---

## Idea
Use dynamic programming with a 1D rolling array; set dp[j]=0 for obstacles and dp[j]+=dp[j-1] for free cells.

---

## Pseudo Code

```text
function uniquePathsWithObstacles(grid)
    if grid is empty return 0
    m = number of rows in grid
    n = number of columns in grid
    dp = array of length n filled with 0
    dp[0] = 1 if grid[0][0] == 0 else 0
    for i from 0 to m-1
        for j from 0 to n-1
            if grid[i][j] == 1
                dp[j] = 0
            else if j > 0
                dp[j] = dp[j] + dp[j-1]
    return dp[n-1]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(n) |

---

## Code Explanation

### Dry Run

| Step | State (dp) | Operation | Result |
| ---- | ---------- | --------- | ------ |
| init | [1,0,0]    | set dp[0]=1 since start free | [1,0,0] |
| row0 j1 | [1,0,0] | dp[1]=dp[1]+dp[0]=0+1 | [1,1,0] |
| row0 j2 | [1,1,0] | dp[2]=dp[2]+dp[1]=0+1 | [1,1,1] |
| row1 j1 (obst) | [1,1,1] | grid[1][1]==1 => dp[1]=0 | [1,0,1] |
| row1 j2 | [1,0,1] | dp[2]=dp[2]+dp[1]=1+0 | [1,0,1] |
| row2 j1 | [1,0,1] | dp[1]=dp[1]+dp[0]=0+1 | [1,1,1] |
| row2 j2 | [1,1,1] | dp[2]=dp[2]+dp[1]=1+1 | [1,1,2] |
| end  | [1,1,2]    | return dp[2] | 2 |

## Other Patterns

### Pattern 1

**Idea**
2D DP table storing number of ways for each cell.

**Pseudo Code**

```text
function uniquePathsWithObstacles2D(grid)
    if grid is empty return 0
    m = rows; n = cols
    dp = 2D array m x n filled with 0
    if grid[0][0] == 0 then dp[0][0] = 1 else dp[0][0] = 0
    for i from 0 to m-1
        for j from 0 to n-1
            if grid[i][j] == 1
                dp[i][j] = 0
            else
                if i > 0 then dp[i][j] += dp[i-1][j]
                if j > 0 then dp[i][j] += dp[i][j-1]
    return dp[m-1][n-1]
```

### Pattern 2

**Idea**
DFS with memoization (top-down) to count paths avoiding obstacles.

**Pseudo Code**

```text
function uniquePathsDFS(grid)
    if grid is empty return 0
    m = rows; n = cols
    memo = map of (i,j) to int
    function dfs(i,j)
        if i<0 or j<0 or i>=m or j>=n return 0
        if grid[i][j] == 1 return 0
        if i == m-1 and j == n-1 return 1
        if (i,j) in memo return memo[(i,j)]
        ways = dfs(i+1,j) + dfs(i,j+1)
        memo[(i,j)] = ways
        return ways
    return dfs(0,0)
```

## Comparison

| Approach    | Idea                         | Time       | Space     | Recommended |
| ----------- | ---------------------------- | ---------- | --------- | ----------- |
| 1D DP       | Rolling 1D array             | O(m*n)     | O(n)      | Yes        |
| 2D DP       | Full DP table                | O(m*n)     | O(m*n)    | No         |
| DFS+Memo    | Top-down recursion + memoize | O(m*n)     | O(m*n)    | No         |
