# Best Time to Buy and Sell Stock III

## Difficulty
Hard

## Description
Given an array prices where prices[i] is the price of a given stock on the i-th day, find the maximum profit you can achieve with at most two transactions. You may not engage in multiple transactions simultaneously (i.e., you must sell before you buy again).

## Examples

### Example 1

```text
Input: prices = [3,3,5,0,0,3,1,4]
Output: 6
Explanation: Buy on day 4 (price = 0) and sell on day 6 (price = 3), profit = 3.
Then buy on day 7 (price = 1) and sell on day 8 (price = 4), profit = 3.
Total profit = 3 + 3 = 6.
```

### Example 2

```text
Input: prices = [1,2,3,4,5]
Output: 4
Explanation: One transaction: buy on day1 price=1 and sell on day5 price=5 profit=4.
```

## Constraints

```text
1 <= prices.length <= 10^5
0 <= prices[i] <= 10^5
At most two transactions allowed.
```

---

## Idea
Use dynamic programming with four state variables: max profit after first buy, first sell, second buy, and second sell; update in one pass.

---

## Pseudo Code

```text
function maxProfitTwoTransactions(prices)
    if prices is empty return 0
    first_buy = -infinity
    first_sell = 0
    second_buy = -infinity
    second_sell = 0
    for each price in prices
        first_buy = max(first_buy, -price)
        first_sell = max(first_sell, first_buy + price)
        second_buy = max(second_buy, first_sell - price)
        second_sell = max(second_sell, second_buy + price)
    return second_sell
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | State (first_buy, first_sell, second_buy, second_sell) | Operation (price) | Result |
| ---- | ------------------------------------------------------ | ----------------- | ------ |
| 1    | (-3, 0, -3, 0)                                         | price=3           | initial after first price |
| 2    | (-3, 0, -3, 0)                                         | price=3           | no change |
| 3    | (-3, 2, -3, 2)                                         | price=5           | first_sell becomes 2, second_sell becomes 2 |
| 4    | (0, 2, 2, 2)                                           | price=0           | first_buy becomes 0, second_buy becomes 2 |
| 5    | (0, 2, 2, 2)                                           | price=0           | no change |
| 6    | (0, 3, 2, 5)                                           | price=3           | first_sell=3, second_sell=5 |
| 7    | (0, 3, 2, 5)                                           | price=1           | no change |
| 8    | (0, 4, 2, 6)                                           | price=4           | second_sell=6 final result |

Otherwise:

1. Iterate prices updating the four states to represent best outcomes after each action.
2. first_buy: best (negative) cost after first buy.
3. first_sell: best profit after first sell.
4. second_buy: best net after buying second time (first_sell - price).
5. second_sell: best total profit after second sell (answer).

## Other Patterns

### Pattern 1

**Idea**

DP with k=2 using 2D arrays over days and transactions.

**Pseudo Code**

```text
function maxProfitDPArray(prices)
    if prices is empty return 0
    k = 2
    n = length(prices)
    dp = array of size (k+1) initialized to 0
    minPrice = array of size (k+1) with +infinity
    for i from 1 to k
        minPrice[i] = prices[0]
    for i from 1 to n-1
        for t from 1 to k
            minPrice[t] = min(minPrice[t], prices[i] - dp[t-1])
            dp[t] = max(dp[t], prices[i] - minPrice[t])
    return dp[k]
```

### Pattern 2

**Idea**

Two-pass prefix/suffix arrays: compute max profit up to day i and max profit from day i to end, then combine.

**Pseudo Code**

```text
function maxProfitPrefixSuffix(prices)
    if prices is empty return 0
    n = length(prices)
    left = array of size n initialized to 0
    right = array of size n initialized to 0
    minPrice = prices[0]
    for i from 1 to n-1
        minPrice = min(minPrice, prices[i])
        left[i] = max(left[i-1], prices[i] - minPrice)
    maxPrice = prices[n-1]
    for i from n-2 down to 0
        maxPrice = max(maxPrice, prices[i])
        right[i] = max(right[i+1], maxPrice - prices[i])
    best = 0
    for i from 0 to n-1
        best = max(best, left[i] + right[i])
    return best
```

## Comparison

| Approach                | Idea                                    | Time | Space | Recommended |
| ----------------------- | --------------------------------------- | ---- | ----- | ----------- |
| State-compressed DP     | Four variables tracking two transactions | O(n) | O(1)  | Yes         |
| DP with arrays (k=2)    | General DP for k transactions            | O(nk)| O(k)  | No (overkill)|
| Prefix-suffix two-pass  | Max up-to-i and from-i combine           | O(n) | O(n)  | No (useful) |
