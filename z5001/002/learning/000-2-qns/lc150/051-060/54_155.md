# Min Stack

## Difficulty
Easy

## Description
Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

Supported operations:
- push(val): push integer val onto the stack.
- pop(): remove the element on top of the stack.
- top(): get the top element.
- getMin(): retrieve the minimum element in the stack.

## Examples

### Example 1

```text
Input: ["MinStack","push","push","push","getMin","pop","top","getMin"]
       [[],[-2],[0],[-3],[],[],[],[]]
Output: [null,null,null,null,-3,null,0,-2]
Explanation:
MinStack ms = new MinStack();
ms.push(-2);
ms.push(0);
ms.push(-3);
ms.getMin(); // returns -3
ms.pop();
ms.top();    // returns 0
ms.getMin(); // returns -2
```

## Constraints

```text
At most 3 * 10^4 operations.
Values are 32-bit signed integers.
pop/top/getMin will be called only on non-empty stack.
```

---

## Idea
Maintain an auxiliary stack that tracks the current minimum at each state (push when new value <= current min; pop when equal).

---

## Pseudo Code

```text
function MinStack()
    create empty mainStack
    create empty minStack

function push(val)
    push val onto mainStack
    if minStack is empty OR val <= top(minStack)
        push val onto minStack

function pop()
    popped = pop from mainStack
    if popped == top(minStack)
        pop from minStack

function top()
    return top of mainStack

function getMin()
    return top of minStack
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(1) per operation |
| Space Complexity | O(n) worst-case (extra stack) |

## Other Patterns

### Pattern 1

**Idea**
Store pairs (value, currentMin) on a single stack so each element carries the min at push time.

**Pseudo Code**

```text
function MinStack()
    create empty stack of pairs

function push(val)
    if stack is empty
        push (val, val) onto stack
    else
        currentMin = top(stack).min
        push (val, min(val, currentMin)) onto stack

function pop()
    pop from stack

function top()
    return top(stack).value

function getMin()
    return top(stack).min
```

### Pattern 2

**Idea**
Encode difference between value and current min in a single stack to achieve O(1) extra space for some values.

**Pseudo Code**

```text
function MinStack()
    create empty stack
    minVal = null

function push(val)
    if stack is empty
        push 0 onto stack
        minVal = val
    else
        diff = val - minVal
        push diff onto stack
        if diff < 0
            minVal = val

function pop()
    diff = pop from stack
    if diff < 0
        minVal = minVal - diff

function top()
    diff = top of stack
    if diff >= 0
        return minVal + diff
    else
        return minVal

function getMin()
    return minVal
```

### Pattern 3

**Idea**
Use a balanced BST or heap to track minima; operations are not all O(1) but support additional queries.

**Pseudo Code**

```text
function MinStack()
    create empty stack
    create empty multiset (BST or heap) for values

function push(val)
    push val onto stack
    insert val into multiset

function pop()
    val = pop from stack
    remove one instance of val from multiset

function top()
    return top of stack

function getMin()
    return minimum element from multiset
```

Do NOT provide explanation for alternative approaches.

## Comparison

| Approach            | Idea                                      | Time         | Space           | Recommended |
| ------------------- | ----------------------------------------- | ------------ | --------------- | ----------- |
| Auxiliary min stack | Keep separate stack of minima             | O(1) each    | O(n)            | Yes         |
| Pair stack          | Store (value, currentMin) per element     | O(1) each    | O(n)            | Yes         |
| Encoded differences | Store diff to avoid second stack          | O(1) each    | O(n) (less aux) | Yes (advanced) |
| Multiset/Heap/BST   | Maintain global min via multiset          | O(log n)     | O(n)            | No          |
