# 57 141 Linked List Cycle

## Difficulty
Easy

## Description
Determine whether a singly linked list contains a cycle (a node reachable again by following next pointers). Return true if there is a cycle, otherwise false.

## Examples

### Example 1

```text
Input: head = [3,2,0,-4], pos = 1
Output: true
Explanation: tail connects to node index 1 (value 2), forming a cycle.
```

### Example 2

```text
Input: head = [1,2], pos = 0
Output: true
Explanation: tail connects to head forming a cycle.
```

### Example 3

```text
Input: head = [1], pos = -1
Output: false
Explanation: no cycle.
```

## Constraints

```text
The number of nodes is in the range [0, 10^4].
-10^5 <= Node.val <= 10^5
pos is -1 or a valid index in the linked list.
No changes to node class assumed except next pointer.
```

---

## Idea
Use Floyd's Tortoise and Hare: move one pointer by 1 and another by 2; if they meet there is a cycle.

---

## Pseudo Code

```text
function hasCycle(head)
    if head == null then return false
    slow := head
    fast := head
    while fast != null and fast.next != null
        slow := slow.next
        fast := fast.next.next
        if slow == fast then return true
    return false
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (slow, fast values) | Operation                          | Result          |
| ---- | ------------------------- | ---------------------------------- | --------------- |
| 1    | (3, 3)                    | initialize                         | no meet         |
| 2    | (2, 0)                    | slow->next, fast->next.next       | no meet         |
| 3    | (0, 2)                    | slow->next, fast->next.next       | no meet         |
| 4    | (-4, -4)                  | slow->next, fast->next.next       | meet -> return true |

---

## Other Patterns

### Pattern 1

**Idea**

Use a hash set to record visited nodes; if a node repeats there is a cycle.

**Pseudo Code**

```text
function hasCycle_hash(head)
    visited := empty set
    node := head
    while node != null
        if node in visited then return true
        add node to visited
        node := node.next
    return false
```

### Pattern 2

**Idea**

Temporarily modify next pointers to mark visited nodes by pointing them to a sentinel; destructive but O(1) space.

**Pseudo Code**

```text
function hasCycle_mark(head)
    sentinel := new Node()
    node := head
    while node != null
        if node.next == sentinel then return true
        nextNode := node.next
        node.next := sentinel
        node := nextNode
    return false
```

## Comparison

| Approach    | Idea                                       | Time  | Space  | Recommended |
| ----------- | ------------------------------------------ | ----- | ------ | ----------- |
| Floyd       | Two pointers moving at different speeds    | O(n)  | O(1)   | Yes         |
| HashSet     | Store visited nodes in a set               | O(n)  | O(n)   | Yes (if extra memory ok) |
| Mark & Mod  | Modify next pointers to a sentinel (destructive) | O(n)  | O(1)   | No (destructive) |
