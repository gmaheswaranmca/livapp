# Title
Minimum Number of Arrows to Burst Balloons

## Difficulty
Medium

## Description
Given a list of balloons represented as intervals points[i] = [xstart, xend], find the minimum number of arrows required to burst all balloons. An arrow shot at position x bursts all balloons with xstart <= x <= xend.

## Examples

### Example 1

```text
Input: points = [[10,16],[2,8],[1,6],[7,12]]
Output: 2
Explanation: Shoot at x = 6 to burst [1,6] and [2,8], and at x = 12 to burst [7,12] and [10,16].
```

### Example 2

```text
Input: points = [[1,2],[3,4],[5,6],[7,8]]
Output: 4
Explanation: No intervals overlap; need one arrow per balloon.
```

### Example 3

```text
Input: points = [[1,10],[2,3],[4,5],[6,7]]
Output: 1
Explanation: One arrow at x = 5 (or any x in [1,10]) bursts them all.
```

## Constraints

```text
1 <= points.length <= 10^5
points[i].length == 2
-2^31 <= xstart < xend <= 2^31 - 1
```

---

## Idea
Sort intervals by end coordinate and greedily place an arrow at the end of the earliest-ending interval whenever a balloon is not already burst.

---

## Pseudo Code

```text
function minArrows(points)
    if points is empty
        return 0
    sort points by end ascending
    arrows = 0
    current_end = -infinity
    for each interval in points
        if interval.start > current_end
            arrows = arrows + 1
            current_end = interval.end
    return arrows
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n log n) |
| Space Complexity | O(1) (or O(n) if sorting creates a copy) |

## Code Explanation

### Dry Run

| Step | State                         | Operation                             | Result                |
| ---- | ----------------------------- | ------------------------------------- | --------------------- |
| 1    | points unsorted               | sort by end                           | [[1,6],[2,8],[7,12],[10,16]] |
| 2    | arrows=0,current_end=-inf     | process [1,6], 1 > -inf               | arrows=1,current_end=6 |
| 3    | arrows=1,current_end=6        | process [2,8], 2 <= 6                 | no change             |
| 4    | arrows=1,current_end=6        | process [7,12], 7 > 6                 | arrows=2,current_end=12 |
| 5    | arrows=2,current_end=12       | process [10,16], 10 <= 12             | no change             |
| 6    | final                         | return arrows                         | 2                     |

## Other Patterns

### Pattern 1

**Idea**
Sweep-line using start/end events and count active overlaps.

**Pseudo Code**

```text
function minArrowsSweep(points)
    events = empty list
    for each interval in points
        events.append((interval.start, +1))
        events.append((interval.end, -1))
    sort events by position ascending, tie-break end(-1) before start(+1)
    active = 0
    arrows = 0
    for each event in events
        if event.type == +1
            if active == 0
                arrows = arrows + 1
            active = active + 1
        else
            active = active - 1
    return arrows
```

### Pattern 2

**Idea**
Greedy sorting by start and merging overlapping intervals, count merged groups.

**Pseudo Code**

```text
function minArrowsMerge(points)
    if points is empty
        return 0
    sort points by start ascending
    arrows = 0
    current_end = +infinity
    for each interval in points
        if interval.start > current_end
            arrows = arrows + 1
            current_end = interval.end
        else
            current_end = min(current_end, interval.end)
    return arrows + (arrows == 0 ? 1 : 0)
```

## Comparison

| Approach                     | Idea                                | Time      | Space      | Recommended |
| --------------------------- | ----------------------------------- | --------- | ---------- | ----------- |
| Greedy by end (primary)     | Sort by end and place arrow at end  | O(n log n)| O(1)       | Yes         |
| Sweep-line events           | Use start/end events                | O(n log n)| O(n)       | No          |
| Merge by start (variant)    | Merge overlaps and count groups     | O(n log n)| O(1)       | No          |
