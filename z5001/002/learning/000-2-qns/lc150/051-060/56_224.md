# Basic Calculator

## Difficulty
Medium

## Description
Evaluate a given arithmetic expression string containing non-negative integers, '+', '-', parentheses '(' and ')', and spaces. Return the computed integer result.

## Examples

### Example 1

```text
Input: s = "1 + (2 - 3)"
Output: 0
Explanation: 1 + (2 - 3) = 1 + (-1) = 0
```

### Example 2

```text
Input: s = "2-1 + 2"
Output: 3
Explanation: 2 - 1 + 2 = 3
```

## Constraints

```text
1 <= s.length <= 3 * 10^5
s consists of digits, '+', '-', '(', ')', and ' '.
Valid arithmetic expression with balanced parentheses.
No multiplication/division; only + and -.
```

---

## Idea
Use a stack to store previous result and sign when encountering '(' and evaluate by scanning once.

---

## Pseudo Code

```text
function evaluateExpression(s)
    i := 0
    n := length(s)
    result := 0           // cumulative result so far
    num := 0              // current number being parsed
    sign := 1             // current sign: 1 for '+', -1 for '-'
    stack := empty stack

    while i < n
        ch := s[i]
        if ch is digit
            num := num * 10 + (ch - '0')
        else if ch == '+'
            result := result + sign * num
            num := 0
            sign := 1
        else if ch == '-'
            result := result + sign * num
            num := 0
            sign := -1
        else if ch == '('
            push(stack, result)
            push(stack, sign)
            result := 0
            sign := 1
            num := 0
        else if ch == ')'
            result := result + sign * num
            num := 0
            prevSign := pop(stack)
            prevResult := pop(stack)
            result := prevResult + prevSign * result
        // else ch is space -> skip
        i := i + 1

    result := result + sign * num
    return result
```

## Other Patterns

### Pattern 1

**Idea**

Recursive descent parsing using index passed by reference to evaluate inside parentheses.

**Pseudo Code**

```text
function evaluateRecursive(s)
    i := 0
    return parseExpr(s, i)

function parseExpr(s, i)
    result := 0
    num := 0
    sign := 1
    while i < length(s) and s[i] != ')'
        if s[i] is digit
            num := num*10 + digit(s[i])
            i := i + 1
        else if s[i] == '+'
            result := result + sign * num
            num := 0
            sign := 1
            i := i + 1
        else if s[i] == '-'
            result := result + sign * num
            num := 0
            sign := -1
            i := i + 1
        else if s[i] == '('
            i := i + 1
            val := parseExpr(s, i)
            num := val
        else
            i := i + 1
    result := result + sign * num
    if i < length(s) and s[i] == ')' then i := i + 1
    return result
```

### Pattern 2

**Idea**

Convert to Reverse Polish Notation using Shunting Yard then evaluate RPN.

**Pseudo Code**

```text
function evaluateShuntingYard(s)
    output := empty queue
    ops := empty stack
    for each token in tokenize(s)
        if token is number then enqueue(output, token)
        else if token is '+' or '-'
            while ops not empty and precedence(top(ops)) >= precedence(token) and top(ops) != '('
                enqueue(output, pop(ops))
            push(ops, token)
        else if token == '('
            push(ops, token)
        else if token == ')'
            while top(ops) != '('
                enqueue(output, pop(ops))
            pop(ops) // remove '('
    while ops not empty
        enqueue(output, pop(ops))
    return evaluateRPN(output)

function evaluateRPN(queue)
    st := empty stack
    while queue not empty
        token := dequeue(queue)
        if token is number then push(st, token)
        else
            b := pop(st); a := pop(st)
            push(st, apply(token, a, b))
    return pop(st)
```

## Comparison

| Approach        | Idea                                   | Time | Space | Recommended |
| --------------- | -------------------------------------- | ---- | ----- | ----------- |
| Stack (iterative)| Single pass, push result/sign at '('  | O(n) | O(n)  | Yes         |
| Recursion       | Parse recursively entering parentheses | O(n) | O(n)  | Yes         |
| Shunting Yard   | Convert to RPN then evaluate           | O(n) | O(n)  | No          |
