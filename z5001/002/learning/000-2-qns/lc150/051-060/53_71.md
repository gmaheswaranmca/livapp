# Simplify Path

## Difficulty
Medium

## Description
Given an absolute Unix-style path, simplify it to its canonical path by resolving "." and "..", removing duplicate slashes, and ensuring the path begins with a single slash and contains no trailing slash (except for root).

## Examples

### Example 1
```text
Input: path = "/home//foo/"
Output: "/home/foo"
Explanation: Duplicate slashes removed and trailing slash removed.
```

### Example 2
```text
Input: path = "/a/./b/../../c/"
Output: "/c"
Explanation: '.' refers to current directory; '..' moves up one directory.
```

### Example 3
```text
Input: path = "/../"
Output: "/"
Explanation: Cannot go above root; result is root.
```

## Constraints
```text
1 <= path.length <= 3000
path consists of English letters, digits, '/', '.' and '_' characters.
path is an absolute path (starts with '/').
```

---

## Idea
Use a stack to push valid directory names, pop on "..", ignore "." and empty tokens, then join stack with '/' and prefix with '/' (or return "/" if empty).

---

## Pseudo Code
```text
function simplifyPath(path)
    tokens = split(path, '/')
    stack = empty list
    for each token in tokens
        if token == '' or token == '.' then
            continue
        else if token == '..' then
            if stack not empty then
                pop stack
            end if
        else
            push token onto stack
        end if
    end for
    if stack empty then
        return "/"
    end if
    result = join(stack with '/')
    return "/" + result
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | Token  | Operation                    | Stack State     |
| ---- | ------ | ---------------------------- | --------------- |
| 1    | ""     | skip                         | []              |
| 2    | "a"    | push "a"                     | ["a"]           |
| 3    | "."    | skip                         | ["a"]           |
| 4    | "b"    | push "b"                     | ["a","b"]       |
| 5    | ".."   | pop                          | ["a"]           |
| 6    | ".."   | pop                          | []              |
| 7    | "c"    | push "c"                     | ["c"]           |
| 8    | ""     | skip                         | ["c"]           |
| End  |        | join -> "/c"                 | ["c"]           |

1. Split path by '/' to get tokens.
2. Iterate tokens: ignore empty or ".", pop on ".." if possible, else push directory names.
3. If stack empty return "/", else join with '/' and prefix '/'.

## Other Patterns

### Pattern 1

**Idea**

Two-pointer manual parsing without full split to reduce temporary substrings.

**Pseudo Code**
```text
function simplifyPath(path)
    stack = empty list
    i = 0
    n = length(path)
    while i < n
        if path[i] == '/' then
            i = i + 1
            continue
        end if
        j = i
        while j < n and path[j] != '/' do
            j = j + 1
        end while
        token = substring(path, i, j)
        if token == '.' then
            // do nothing
        else if token == '..' then
            if stack not empty then
                pop stack
            end if
        else
            push token onto stack
        end if
        i = j
    end while
    if stack empty then
        return "/"
    end if
    return "/" + join(stack with '/')
```

## Comparison

| Approach        | Idea                                   | Time  | Space | Recommended |
| --------------- | -------------------------------------- | ----- | ----- | ----------- |
| Stack + split   | Split by '/' and process tokens with stack | O(n)  | O(n)  | Yes         |
| Two-pointer     | Parse tokens in-place without split    | O(n)  | O(n)  | Yes (memory optimized) |
