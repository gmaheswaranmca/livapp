# Palindrome Number

## Difficulty
Easy

## Description
Determine whether a given integer is a palindrome without using extra space (i.e., read the same forward and backward).

## Examples

### Example 1

```text
Input: x = 121
Output: true
Explanation: Reverse half the number; 121 is a palindrome.
```

### Example 2

```text
Input: x = -121
Output: false
Explanation: Negative numbers are not palindromes.
```

### Example 3

```text
Input: x = 10
Output: false
Explanation: Numbers ending with 0 (and not 0 itself) cannot be palindromes.
```

## Constraints

```text
-2^31 <= x <= 2^31 - 1
Constant extra space expected (O(1)).
Time should be O(log10(n)) typically (digits count).
```

---

## Idea
Reverse only half of the digits and compare with the remaining half.

---

## Pseudo Code

```text
function isPalindromeNumber(x)
    if x < 0 then return false
    if x % 10 == 0 and x != 0 then return false
    reversedHalf = 0
    while x > reversedHalf
        digit = x % 10
        reversedHalf = reversedHalf * 10 + digit
        x = x / 10   // integer division
    return x == reversedHalf or x == reversedHalf / 10   // handles odd digit count
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log10(n)) |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (x, reversedHalf) | Operation                         | Result        |
| ---- | ----------------------- | --------------------------------- | ------------- |
| 1    | (121, 0)                | digit=121%10=1; rev=0*10+1; x=12 | (12, 1)       |
| 2    | (12, 1)                 | digit=12%10=2; rev=1*10+2; x=1   | (1, 12)       |
| 3    | (1, 12)                 | loop stops since x<=rev; compare  | x == rev/10 -> 1 == 12/10 => true |

1. Reject negatives and numbers ending in 0 (except 0).
2. Build reversedHalf by popping digits from x until reversedHalf >= x.
3. For even digits: x == reversedHalf. For odd digits: x == reversedHalf/10.

## Other Patterns

### Pattern 1

**Idea**

Convert number to string and check palindrome.

**Pseudo Code**

```text
function isPalindromeString(x)
    if x < 0 then return false
    s = toString(x)
    i = 0
    j = length(s) - 1
    while i < j
        if s[i] != s[j] then return false
        i = i + 1
        j = j - 1
    return true
```

### Pattern 2

**Idea**

Reverse the whole number numerically and compare (watch overflow).

**Pseudo Code**

```text
function isPalindromeReverseFull(x)
    if x < 0 then return false
    original = x
    reversed = 0
    while x != 0
        digit = x % 10
        if reversed > (MAX_INT - digit) / 10 then return false   // overflow guard
        reversed = reversed * 10 + digit
        x = x / 10
    return original == reversed
```

## Comparison

| Approach           | Idea                          | Time            | Space | Recommended |
| ------------------ | ----------------------------- | --------------- | ----- | ----------- |
| Reverse Half       | Reverse only half digits      | O(log10(n))     | O(1)  | Yes         |
| String Check       | Convert to string and compare | O(log10(n))     | O(log10(n)) | No      |
| Reverse Full       | Reverse entire number         | O(log10(n))     | O(1)  | No (overflow risk) |
