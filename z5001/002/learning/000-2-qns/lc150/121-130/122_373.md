# Find K Pairs with Smallest Sums

## Difficulty
Medium

## Description
Given two sorted integer arrays nums1 and nums2 and an integer k, return k pairs (u,v) where u is from nums1 and v is from nums2 with the smallest sums. Each pair should be represented as [u,v]. If there are fewer than k pairs, return all possible pairs.

## Examples

### Example 1

```text
Input: nums1 = [1,7,11], nums2 = [2,4,6], k = 3
Output: [[1,2],[1,4],[1,6]]
Explanation: The first 3 smallest sums are 3,5,7 corresponding to pairs (1,2),(1,4),(1,6).
```

### Example 2

```text
Input: nums1 = [1,1,2], nums2 = [1,2,3], k = 2
Output: [[1,1],[1,1]]
Explanation: Two smallest pairs are (1,1) from the two 1's in nums1 paired with the first 1 in nums2.
```

## Constraints

```text
1 <= nums1.length, nums2.length <= 10^5
-10^9 <= nums1[i], nums2[j] <= 10^9
nums1 and nums2 are sorted in ascending order
1 <= k <= 10^9 (practically limited by nums1.length * nums2.length)
```

---

## Idea
Use a min-heap to perform a k-way merge: initialize heap with pairs (i,0) for i in [0..min(k-1,n1-1)] keyed by nums1[i]+nums2[0], then repeatedly pop and push next (i,j+1).

---

## Pseudo Code

```text
function solve(nums1, nums2, k)
    n1 := length(nums1)
    n2 := length(nums2)
    if n1 == 0 or n2 == 0 or k <= 0
        return []
    result := empty list
    minHeap := empty min-heap    // stores tuples (sum, i, j)

    limit := min(k, n1)
    for i from 0 to limit - 1
        push minHeap (nums1[i] + nums2[0], i, 0)

    while k > 0 and minHeap is not empty
        (sum, i, j) := pop minHeap
        append [nums1[i], nums2[j]] to result
        k := k - 1
        if j + 1 < n2
            push minHeap (nums1[i] + nums2[j+1], i, j+1)

    return result
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(min(k,n1) + k * log(min(k,n1))) ≈ O(k log min(k,n1)) |
| Space Complexity | O(min(k,n1)) |

## Code Explanation

### Dry Run

| Step | Heap State (sum,i,j)                          | Operation             | Result Pairs       |
| ---- | --------------------------------------------- | --------------------- | ------------------ |
| 1    | push (1+2,0,0)=(3,0,0),(9,1,0),(13,2,0)       | init heap             | []                 |
| 2    | pop (3,0,0)                                    | add (1,2); push (1+4,0,1)=(5,0,1) | [[1,2]]            |
| 3    | pop (5,0,1)                                    | add (1,4); push (1+6,0,2)=(7,0,2) | [[1,2],[1,4]]     |
| 4    | pop (7,0,2)                                    | add (1,6); j+1 out of range      | [[1,2],[1,4],[1,6]] |

1. Initialize heap with (nums1[i]+nums2[0], i, 0) for i in [0..min(k-1,n1-1)].
2. Pop smallest sum, append its pair to result.
3. If the popped pair used nums2[j], push (i, j+1) to consider next pair with same nums1[i].
4. Stop after k pops or heap empty.

## Other Patterns

### Pattern 1

**Idea**
Brute-force generate all pairs then sort by sum.

**Pseudo Code**

```text
function solve(nums1, nums2, k)
    pairs := empty list
    for i from 0 to length(nums1)-1
        for j from 0 to length(nums2)-1
            append (nums1[i]+nums2[j], nums1[i], nums2[j]) to pairs
    sort pairs by sum ascending
    return first min(k, length(pairs)) pairs as [[u,v],...]
```

### Pattern 2

**Idea**
Use pointers and binary-search-like expansion: keep for each nums1[i] an index pointer into nums2 and use a min-heap keyed by current sums (similar to main but conceptually pointer-array).

**Pseudo Code**

```text
function solve(nums1, nums2, k)
    n1 := length(nums1)
    idx := array of zeros size n1
    minHeap := empty min-heap
    for i from 0 to n1-1
        if n2 > 0
            push minHeap (nums1[i]+nums2[0], i)
    result := empty list
    while k > 0 and minHeap not empty
        (sum, i) := pop minHeap
        j := idx[i]
        append [nums1[i], nums2[j]] to result
        idx[i] := idx[i] + 1
        if idx[i] < length(nums2)
            push minHeap (nums1[i] + nums2[idx[i]], i)
        k := k - 1
    return result
```

## Comparison

| Approach     | Idea                                | Time                                  | Space            | Recommended |
| ------------ | ----------------------------------- | ------------------------------------- | ---------------- | ----------- |
| Min-Heap (main) | k-way merge via heap of i indices | O(min(k,n1) + k log min(k,n1))       | O(min(k,n1))     | Yes         |
| Brute Force  | Generate all pairs and sort         | O(n1*n2 log(n1*n2))                   | O(n1*n2)         | No          |
| Pointer-Heap | Per-i pointer + heap (variant)      | O(min(k,n1) + k log n1)               | O(n1) or O(min)  | Yes (variant)
