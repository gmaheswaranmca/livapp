# Add Binary

## Difficulty
Easy

## Description
Add two binary strings and return their sum as a binary string.

## Examples

### Example 1

```text
Input: a = "11", b = "1"
Output: "100"
Explanation: 3 + 1 = 4 -> "100"
```

### Example 2

```text
Input: a = "1010", b = "1011"
Output: "10101"
Explanation: 10 + 11 = 21 -> "10101"
```

## Constraints

```text
1 <= a.length, b.length <= 10^4
a and b consist only of '0' or '1'
No leading zeros except for the string "0"
```

---

## Idea
Simulate binary addition from least significant digit using two pointers and a carry.

---

## Pseudo Code

```text
function addBinary(a, b)
    i <- length(a) - 1
    j <- length(b) - 1
    carry <- 0
    result <- empty list of characters
    while i >= 0 or j >= 0 or carry == 1
        x <- 0
        if i >= 0
            x <- a[i] - '0'
            i <- i - 1
        y <- 0
        if j >= 0
            y <- b[j] - '0'
            j <- j - 1
        sum <- x + y + carry
        append (char)((sum % 2) + '0') to result
        carry <- sum / 2
    reverse result
    return join result as string
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | i,j | carry | bitA | bitB | sum | result (built L->R) |
| ---- | --- | ----- | ---- | ---- | --- | ------------------- |
| 1    | 1,0 | 0     | 1    | 1    | 2   | "0"                 |
| 2    | 0,-1| 1     | 1    | 0    | 2   | "00"                |
| 3    | -1,-1| 1    | 0    | 0    | 1   | "001"               |
| End  | -1,-1| 0    | -    | -    | -   | reversed -> "100"   |

1. Initialize pointers at ends and carry=0.
2. Loop while any pointer valid or carry is 1.
3. Sum bits + carry, append sum%2, update carry=sum/2.
4. Reverse accumulated digits and return.

## Other Patterns

### Pattern 1

**Idea**
Convert binary strings to integer types, add, convert back (only safe for small lengths).

**Pseudo Code**

```text
function addBinary_convert(a, b)
    x <- parseBinaryToInteger(a)
    y <- parseBinaryToInteger(b)
    sum <- x + y
    return integerToBinaryString(sum)
```

### Pattern 2

**Idea**
Use language BigInteger/BigInt to parse and add directly for arbitrarily large values.

**Pseudo Code**

```text
function addBinary_bigint(a, b)
    x <- BigInt.parse(a, base=2)
    y <- BigInt.parse(b, base=2)
    sum <- x + y
    return sum.toString(base=2)
```

## Comparison

| Approach         | Idea                                         | Time  | Space | Recommended |
| ---------------- | -------------------------------------------- | ----- | ----- | ----------- |
| Two-pointer      | Simulate addition with carry from LSB to MSB | O(n)  | O(n)  | Yes         |
| Convert to int   | Parse strings to integers, add, convert back | O(n)  | O(n)  | No (overflow)|
| BigInt/BigInteger| Use arbitrary-precision integer operations   | O(n)  | O(n)  | Yes (if available) |
