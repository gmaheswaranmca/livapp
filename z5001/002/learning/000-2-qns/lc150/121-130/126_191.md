# Number of 1 Bits

## Difficulty
Easy

## Description
Count the number of set bits (1s) in the binary representation of a non-negative integer n.

## Examples

### Example 1

```text
Input: 11
Output: 3
Explanation: 11 in binary is 1011 which has three 1 bits.
```

### Example 2

```text
Input: 0
Output: 0
Explanation: 0 in binary has no 1 bits.
```

### Example 3

```text
Input: 4294967295
Output: 32
Explanation: For 32-bit unsigned, all bits are 1.
```

## Constraints

```text
0 <= n < 2^32  (assume 32-bit unsigned)
Time per call should be small for repeated queries.
Memory usage should be O(1) unless using lookup tables.
```

---

## Idea
Use Brian Kernighan's trick: repeatedly clear the lowest set bit via n = n & (n − 1) and count iterations.

---

## Pseudo Code

```text
function countSetBits(n)
    count <- 0
    while n != 0
        n <- n & (n - 1)
        count <- count + 1
    return count
```

---

## Complexity

| Metric           | Value                        |
| ---------------- | ---------------------------- |
| Time Complexity  | O(k) where k = number of set bits (worst O(b) for b-bit integer) |
| Space Complexity | O(1)                         |

---

## Code Explanation

### Dry Run

| Step | State (n) | Operation           | Result (n after) | Count |
| ---- | --------- | ------------------- | ----------------- | ----- |
| 1    | 11 (1011) | n <- n & (n - 1)    | 10 (1010)         | 1     |
| 2    | 10 (1010) | n <- n & (n - 1)    | 8  (1000)         | 2     |
| 3    | 8  (1000) | n <- n & (n - 1)    | 0  (0000)         | 3     |

1. Initialize count = 0.
2. Each loop clears the lowest set bit and increments count.
3. Loop ends when n becomes 0; return count.

## Other Patterns

### Pattern 1

**Idea**
Check each bit by shifting a mask from LSB to MSB.

**Pseudo Code**

```text
function countSetBits_shift(n)
    count <- 0
    mask <- 1
    for i from 0 to b-1
        if (n & mask) != 0
            count <- count + 1
        mask <- mask << 1
    return count
```

### Pattern 2

**Idea**
Use a precomputed lookup table for bytes (0..255) and sum for each byte of n.

**Pseudo Code**

```text
function countSetBits_lookup(n)
    table <- precomputed array of size 256 with bit counts
    count <- 0
    for i from 0 to (b/8)-1
        byte <- (n >> (i*8)) & 0xFF
        count <- count + table[byte]
    return count
```

### Pattern 3

**Idea**
Use hardware/popcount intrinsic or builtin (O(1) on supporting CPUs).

**Pseudo Code**

```text
function countSetBits_builtin(n)
    return POPCOUNT(n)  // use compiler/hardware intrinsic
```

## Comparison

| Approach           | Idea                                   | Time              | Space   | Recommended |
| ------------------ | -------------------------------------- | ----------------- | ------- | ----------- |
| Brian Kernighan    | Clear lowest set bit each iteration    | O(k) (k=set bits) | O(1)    | Yes        |
| Bit-shift mask     | Test each bit with shifting mask       | O(b)              | O(1)    | No (simple) |
| Lookup table (8-bit)| Precompute counts for bytes            | O(b/8)            | O(256)  | Yes (many queries) |
| Built-in POPCOUNT  | Use CPU/compiler intrinsic             | O(1)              | O(1)    | Yes (if available) |
