# Title
Bitwise AND of Numbers Range

## Difficulty
Medium

## Description
Compute the bitwise AND of all numbers in the inclusive range [left, right].

## Examples

### Example 1

```text
Input: left = 5, right = 7
Output: 4
Explanation: 5 & 6 & 7 = 4
```

### Example 2

```text
Input: left = 0, right = 1
Output: 0
Explanation: 0 & 1 = 0
```

## Constraints

```text
0 <= left <= right <= 2^31 - 1
```

---

## Idea
Find the common binary prefix of left and right by shifting both right until equal, then shift back.

---

## Pseudo Code

```text
function rangeBitwiseAnd_shift(left, right)
    shift = 0
    while left != right
        left = left >> 1
        right = right >> 1
        shift = shift + 1
    return left << shift
```

```text
function rangeBitwiseAnd_mask(left, right)
    mask = ~0                        // all 1s
    while (left & mask) != (right & mask)
        mask = mask << 1
    return left & mask
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log M) where M = right (number of bits) |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | left (bin) | right (bin) | shift | Operation                                  | Result (dec) |
| ---- | ---------- | ------------| ----- | ------------------------------------------ | ------------ |
| 1    | 101 (5)    | 111 (7)     | 0     | left!=right -> right shift both            | left=10(2), right=11(3) |
| 2    | 10 (2)     | 11 (3)      | 1     | left!=right -> right shift both            | left=1(1), right=1(1) |
| 3    | 1 (1)      | 1 (1)       | 2     | left==right -> return left<<shift          | 1<<2 = 4     |

1. Shift both left and right rightwards until they become equal; count shifts.
2. The remaining equal value is the common prefix; shift it back by counted shifts.
3. The mask approach narrows bits from MSB by left-shifting mask until masked values match.

## Other Patterns

### Pattern 1

**Idea**

Shift both numbers right until equal, then shift left back.

**Pseudo Code**

```text
function rangeBitwiseAnd_shift(left, right)
    shift = 0
    while left != right
        left = left >> 1
        right = right >> 1
        shift = shift + 1
    return left << shift
```

### Pattern 2

**Idea**

Use a mask of leading ones and left-shift it until masked values are equal.

**Pseudo Code**

```text
function rangeBitwiseAnd_mask(left, right)
    mask = ~0
    while (left & mask) != (right & mask)
        mask = mask << 1
    return left & mask
```
