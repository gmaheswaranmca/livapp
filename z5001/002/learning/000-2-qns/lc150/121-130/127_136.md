# Single Number

## Difficulty
Easy

## Description
Given a non-empty array of integers where every element appears twice except for one, find that single one. Use constant extra space and linear time.

## Examples

### Example 1

```text
Input: [2,2,1]
Output: 1
Explanation: 2 ^ 2 ^ 1 = 1
```

### Example 2

```text
Input: [4,1,2,1,2]
Output: 4
Explanation: 4 ^ 1 ^ 2 ^ 1 ^ 2 = 4
```

## Constraints

```text
1 <= nums.length <= 3 * 10^4
-2^31 <= nums[i] <= 2^31 - 1
Every element appears exactly twice except for one element which appears once.
```

---

## Idea
Use XOR to cancel paired numbers; XOR of all elements yields the single number.

---

## Pseudo Code

```text
function singleNumber(nums)
    result <- 0
    for each num in nums
        result <- result XOR num
    return result
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State        | Operation      | Result |
| ---- | ------------ | -------------- | ------ |
| 1    | result = 0   | result ^ 2     | 2      |
| 2    | result = 2   | result ^ 2     | 0      |
| 3    | result = 0   | result ^ 1     | 1      |

1. Initialize result to 0.
2. XOR each element into result; duplicates cancel.
3. Remaining value is the unique element.

## Other Patterns

### Pattern 1

**Idea**

Count occurrences using a hash map and return the key with count 1.

**Pseudo Code**

```text
function singleNumberHash(nums)
    map <- empty hash map
    for each num in nums
        if map contains num
            map[num] <- map[num] + 1
        else
            map[num] <- 1
    for each (key, value) in map
        if value == 1
            return key
```
