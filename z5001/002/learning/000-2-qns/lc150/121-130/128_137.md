# Single Number II

## Difficulty
Medium

## Description
Given an integer array where every element appears three times except for one which appears exactly once, find and return that single element.

## Examples

### Example 1

```text
Input: [2,2,3,2]
Output: 3
Explanation: 3 appears once; 2 appears three times.
```

### Example 2

```text
Input: [0,1,0,1,0,1,99]
Output: 99
Explanation: 99 appears once; 0 and 1 appear three times each.
```

## Constraints

```text
1 <= nums.length <= 3 * 10^4
-2^31 <= nums[i] <= 2^31 - 1
All numbers except one appear exactly three times.
```

---

## Idea
Count bits at each position modulo 3 and reconstruct the unique number.

---

## Pseudo Code

```text
function singleNumber(nums)
    nbits <- 32
    counts <- array of size nbits initialized to 0
    for each num in nums
        for i from 0 to nbits-1
            counts[i] <- counts[i] + ((num >> i) & 1)
    result <- 0
    for i from 0 to nbits-1
        bit <- counts[i] % 3
        result <- result | (bit << i)
    // Convert to signed 32-bit if necessary
    if result >= (1 << 31)
        result <- result - (1 << 32)
    return result
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n * B) where B = 32 (=> O(n)) |
| Space Complexity | O(B) => O(1) |

---

## Code Explanation

### Dry Run

| Step | State (counts[0..3]) | Operation                                 | Result |
| ---- | -------------------- | ----------------------------------------- | ------ |
| 1    | [0,0,0,0]            | process 2 (10b): add bits for i=0..2      | [0,1,0,0] |
| 2    | [0,1,0,0]            | process 2:                                | [0,2,0,0] |
| 3    | [0,2,0,0]            | process 3 (11b): add bits                 | [1,3,0,0] |
| 4    | [1,3,0,0]            | process 2:                                | [1,4,0,0] |
| 5    | [1,4,0,0]            | counts % 3 -> [1,1,0,0] reconstruct bits  | result = 3 |

1. Initialize 32-bit counts array to 0.
2. For each number add its i-th bit to counts[i].
3. Reduce each counts[i] modulo 3 to obtain the unique number's bits.
4. Combine bits into result and adjust for signed 32-bit representation if needed.

## Other Patterns

### Pattern 1

**Idea**

Use two bitmasks (ones, twos) to simulate modulo-3 counting in O(1) space.

**Pseudo Code**

```text
function singleNumber(nums)
    ones <- 0
    twos <- 0
    for each num in nums
        twos <- twos | (ones & num)
        ones <- ones ^ num
        common <- ones & twos
        ones <- ones & (~common)
        twos <- twos & (~common)
    return ones
```

### Pattern 2

**Idea**

Use a hash map to count frequencies and return the key with frequency 1.

**Pseudo Code**

```text
function singleNumber(nums)
    map <- empty dictionary
    for each num in nums
        map[num] <- map.get(num, 0) + 1
    for each (key, val) in map
        if val == 1
            return key
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Bit-counting | Count bits at each position mod 3 | O(n * 32) => O(n) | O(1) | Yes |
| Bitwise masks (ones, twos) | Two-mask state machine for mod-3 | O(n) | O(1) | Yes |
| Hash map | Frequency counting | O(n) | O(n) | No |
