# IPO (Maximize Capital)

## Difficulty
Medium

## Description
Given initial capital W, arrays profits and capital of length n, and integer k, select at most k projects to maximize final capital. You can start a project only if current capital >= project's capital requirement; after finishing a project you gain its profit added to capital. Return the maximum capital achievable.

## Examples

### Example 1

```text
Input: k = 2, W = 0, profits = [1,2,3], capital = [0,1,1]
Output: 4
Explanation: Start with W=0. Choose profit 1 (capital requirement 0) -> W=1. Then choose profit 3 (requirement 1) -> W=4.
```

### Example 2

```text
Input: k = 3, W = 0, profits = [1,2,3], capital = [0,1,2]
Output: 6
Explanation: Choose profits 1,2,3 in sequence -> final W=6.
```

## Constraints

```text
1 <= k <= 10^5
n = len(profits) = len(capital)
1 <= n <= 10^5
0 <= profits[i], capital[i], W <= 10^9
```

---

## Idea
Sort projects by capital requirement and repeatedly push all currently affordable projects' profits into a max-heap; pop the largest profit up to k times, adding to capital.

---

## Pseudo Code

```text
function maximizeCapital(k, W, profits, capital)
    n = length(profits)
    projects = list of pairs (capital[i], profits[i]) for i in 0..n-1
    sort projects by capital ascending
    maxHeap = empty max-heap
    idx = 0
    for i from 1 to k
        while idx < n and projects[idx].capital <= W
            push projects[idx].profit into maxHeap
            idx = idx + 1
        if maxHeap is empty
            break
        bestProfit = pop maxHeap
        W = W + bestProfit
    return W
```

### Dry Run

| Step | State (W, idx, maxHeap)      | Operation                                 | Result (W, idx, maxHeap)    |
| ---- | ---------------------------- | ----------------------------------------- | --------------------------- |
| 1    | (0, 0, [])                   | push projects with capital<=0 -> profit 1 | (0,1,[1])                   |
| 2    | (0,1,[1])                    | pop maxHeap -> add 1                      | (1,1,[])                    |
| 3    | (1,1,[])                     | push projects with capital<=1 -> 2,3      | (1,3,[3,2])                 |
| 4    | (1,3,[3,2])                  | pop maxHeap -> add 3                      | (4,3,[2])                   |
| End  | Final W                      |                                           | 4                           |

## Other Patterns

### Pattern 1

**Idea**

Use sort + max-heap (greedy).

**Pseudo Code**

```text
function maximizeCapital(k, W, profits, capital)
    n = length(profits)
    projects = list of pairs (capital[i], profits[i]) for i in 0..n-1
    sort projects by capital ascending
    maxHeap = empty max-heap
    idx = 0
    for i from 1 to k
        while idx < n and projects[idx].capital <= W
            push projects[idx].profit into maxHeap
            idx = idx + 1
        if maxHeap is empty
            break
        W = W + pop maxHeap
    return W
```

### Pattern 2

**Idea**

Use selection (partial sort) each iteration to pick the best affordable profit.

**Pseudo Code**

```text
function maximizeCapitalSelection(k, W, profits, capital)
    n = length(profits)
    idxSet = all indices
    for i from 1 to k
        candidates = [j in idxSet where capital[j] <= W]
        if candidates is empty
            break
        jmax = index of max profit among candidates
        W = W + profits[jmax]
        remove jmax from idxSet
    return W
```

### Pattern 3

**Idea**

Use balanced BST (multiset) keyed by profit for available projects.

**Pseudo Code**

```text
function maximizeCapitalBST(k, W, profits, capital)
    n = length(profits)
    projects = list of pairs (capital[i], profits[i]) for i in 0..n-1
    sort projects by capital ascending
    bst = empty multiset sorted by profit descending
    idx = 0
    for i from 1 to k
        while idx < n and projects[idx].capital <= W
            insert projects[idx].profit into bst
            idx = idx + 1
        if bst is empty
            break
        best = extract max from bst
        W = W + best
    return W
```
