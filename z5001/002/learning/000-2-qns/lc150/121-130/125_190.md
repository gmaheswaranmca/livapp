# Reverse Bits

## Difficulty
Easy

## Description
Reverse bits of a 32-bit unsigned integer.

## Examples

### Example 1

```text
Input:  n = 43261596
Output: 964176192
Explanation: 00000010100101000001111010011100 -> 00111001011110000010100101000000
```

### Example 2

```text
Input:  n = 4294967293
Output: 3221225471
Explanation: 11111111111111111111111111111101 -> 10111111111111111111111111111111
```

## Constraints

```text
Input is a 32-bit unsigned integer.
Return value fits in 32-bit unsigned integer.
Favor O(1) time or O(32) operations and O(1) space.
```

---

## Idea
Process bits one by one: extract LSB from input, append it to result by left-shifting result and OR-ing the bit.

---

## Pseudo Code

```text
function reverseBits(n)
    result = 0
    for i from 0 to 31
        result = result << 1
        result = result | (n & 1)
        n = n >> 1    // use unsigned right shift if language has signed ints
    return result & 0xFFFFFFFF
```

## Other Patterns

### Pattern 1

**Idea**

Use a 256-entry lookup table to reverse each byte and assemble four reversed bytes.

**Pseudo Code**

```text
function reverseBits(n)
    table = precomputed_reverse_of_byte[0..255]
    result = 0
    for i from 0 to 3
        byte = (n >> (i * 8)) & 0xFF
        result = (result << 8) | table[byte]
    return result & 0xFFFFFFFF
```

### Pattern 2

**Idea**

Use bitwise folding (parallel bit swaps) with masks to reverse in O(1) few operations.

**Pseudo Code**

```text
function reverseBits(n)
    n = ((n >> 1) & 0x55555555) | ((n & 0x55555555) << 1)
    n = ((n >> 2) & 0x33333333) | ((n & 0x33333333) << 2)
    n = ((n >> 4) & 0x0F0F0F0F) | ((n & 0x0F0F0F0F) << 4)
    n = ((n >> 8) & 0x00FF00FF) | ((n & 0x00FF00FF) << 8)
    n = (n >> 16) | (n << 16)
    return n & 0xFFFFFFFF
```

## Comparison

| Approach         | Idea                               | Time         | Space | Recommended |
| ---------------- | ---------------------------------- | ------------ | ----- | ----------- |
| Bit-by-bit       | Shift and append LSB 32 times      | O(32)=O(1)   | O(1)  | Yes         |
| Byte Lookup      | Reverse per-byte using table       | O(4)=O(1)    | O(256)| Yes         |
| Bitwise Folding  | Parallel swaps with masks          | O(1) (few ops)| O(1) | Yes         |
