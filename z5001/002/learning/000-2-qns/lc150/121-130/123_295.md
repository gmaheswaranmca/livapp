# Find Median from Data Stream

## Difficulty
Hard

## Description
Design a data structure that supports adding numbers from a data stream and retrieving the median of all elements seen so far.
Operations:
- addNum(num): insert a number into the stream.
- findMedian(): return the median of all inserted numbers (as float).

## Examples

### Example 1
```text
Input:
["MedianFinder","addNum","addNum","findMedian","addNum","findMedian"]
[[],[1],[2],[],[3],[]]
Output:
[null,null,null,1.5,null,2.0]
Explanation:
addNum(1)
addNum(2)
findMedian() -> (1 + 2) / 2 = 1.5
addNum(3)
findMedian() -> 2.0
```

### Example 2
```text
Input:
["MedianFinder","addNum","findMedian","addNum","findMedian"]
[[],[5],[],[10],[]]
Output:
[null,null,5.0,null,7.5]
Explanation:
addNum(5)
findMedian() -> 5.0
addNum(10)
findMedian() -> (5 + 10) / 2 = 7.5
```

## Constraints
```text
1 <= number of operations <= 10^5
-10^9 <= num <= 10^9
addNum and findMedian may be called in any order
Expected real-time performance for streaming data
```

---

## Idea
Maintain two heaps: max-heap for lower half and min-heap for upper half; keep sizes balanced and medians at heap tops.

---

## Pseudo Code
```text
function MedianFinder()
    create empty maxHeap   // stores lower half
    create empty minHeap   // stores upper half

function addNum(num)
    if maxHeap is empty OR num <= maxHeap.top()
        maxHeap.push(num)
    else
        minHeap.push(num)
    if maxHeap.size() > minHeap.size() + 1
        val = maxHeap.pop()
        minHeap.push(val)
    if minHeap.size() > maxHeap.size()
        val = minHeap.pop()
        maxHeap.push(val)

function findMedian()
    if maxHeap.size() == minHeap.size()
        return (maxHeap.top() + minHeap.top()) / 2.0
    else
        return maxHeap.top() * 1.0
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log n) per addNum, O(1) per findMedian |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | State (maxHeap | minHeap)        | Operation       | Result (median) |
| ---- | ------------------------------ | --------------- | --------------- |
| 1    | [] | []                         | addNum(1)       | maxHeap=[1], minHeap=[] -> median=1.0 |
| 2    | [1] | []                        | addNum(2)       | maxHeap=[1], minHeap=[2] -> median=1.5 |
| 3    | [1] | [2]                       | addNum(3)       | rebalance -> maxHeap=[2,1], minHeap=[3] -> median=2.0 |
| 4    | [2,1] | [3]                     | findMedian()    | median=2.0 |

## Other Patterns

### Pattern 1

**Idea**
Order-statistics balanced BST or indexed tree to get k-th element in O(log n).

**Pseudo Code**
```text
function MedianFinderBST()
    create empty balancedBST with subtree sizes

function addNum(num)
    balancedBST.insert(num)

function findMedian()
    n = balancedBST.size()
    if n is odd
        return balancedBST.kth((n+1)/2)
    else
        a = balancedBST.kth(n/2)
        b = balancedBST.kth(n/2 + 1)
        return (a + b) / 2.0
```

### Pattern 2

**Idea**
Use multiset (ordered container) and two iterators to maintain median positions.

**Pseudo Code**
```text
function MedianFinderMultiset()
    create empty multiset s
    create iterator lo, hi

function addNum(num)
    s.insert(num)
    adjust lo and hi to point to median positions in O(1) amortized by localized moves

function findMedian()
    if s.size() is odd
        return *lo
    else
        return (*lo + *hi) / 2.0
```

### Pattern 3

**Idea**
Counting array for limited value range, maintain cumulative counts to compute median in O(range) or O(log range) with Fenwick tree.

**Pseudo Code**
```text
function MedianFinderCounting()
    create frequency array or Fenwick tree for value range

function addNum(num)
    update frequency or Fenwick tree at index(num)

function findMedian()
    find k-th element using prefix sums on frequencies
    compute median from k-th(s)
```

## Comparison

| Approach               | Idea                                 | Time               | Space  | Recommended |
| ---------------------- | ------------------------------------ | ------------------ | ------ | ----------- |
| Two Heaps              | Split stream into two balanced heaps | O(log n) add, O(1) find | O(n)   | Yes         |
| Balanced BST (order-stat) | Maintain subtree sizes to kth element | O(log n) add, O(log n) find | O(n) | No (complex impl) |
| Multiset + two iterators | Keep iterators at median positions  | O(log n) add, O(1) find amortized | O(n) | No (language-dependent) |
| Counting / Fenwick     | Use counts for limited ranges        | O(log R) add, O(log R) find | O(R) | No (only when range small) |
