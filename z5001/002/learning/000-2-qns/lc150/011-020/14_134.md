# Gas Station

## Difficulty
Medium

## Description
Given two integer arrays gas and cost of length n representing gas at each station and cost to travel to next station, return the starting gas station index if you can travel around the circuit once; otherwise return -1. If multiple solutions exist return the smallest index.

## Examples

### Example 1
```text
Input: gas=[1,2,3,4,5], cost=[3,4,5,1,2]
Output: 3
Explanation: Start at station 3 (0-based). Cumulative balance never drops below zero and total gas >= total cost.
```

## Constraints
```text
n == gas.length == cost.length
1 <= n <= 10^5
0 <= gas[i], cost[i] <= 10^4
```

---

## Idea
Use a single pass greedy: reset start when current tank goes negative and ensure total gas >= total cost.

---

## Pseudo Code
```text
function canCompleteCircuit(gas, cost)
    n := length of gas
    total := 0
    tank := 0
    start := 0
    for i from 0 to n-1
        diff := gas[i] - cost[i]
        total := total + diff
        tank := tank + diff
        if tank < 0
            start := i + 1
            tank := 0
    if total < 0
        return -1
    return start
```

| Metric           | Value  |

## Other Patterns

### Pattern 1

**Idea**  
Brute force simulation from every station.

**Pseudo Code**
```text
function canCompleteCircuitBrute(gas, cost)
    n := length of gas
    for start from 0 to n-1
        tank := 0
        valid := true
        for k from 0 to n-1
            i := (start + k) mod n
            tank := tank + gas[i] - cost[i]
            if tank < 0
                valid := false
                break
        if valid
            return start
    return -1
```

### Pattern 2

**Idea**  
Compute prefix sums of diffs and return index after the minimum prefix sum.

**Pseudo Code**
```text
function canCompleteCircuitMinPrefix(gas, cost)
    n := length of gas
    diffs := array of size n
    for i from 0 to n-1
        diffs[i] := gas[i] - cost[i]
    prefix := 0
    minPrefix := +infinity
    minIndex := -1
    for i from 0 to n-1
        prefix := prefix + diffs[i]
        if prefix < minPrefix
            minPrefix := prefix
            minIndex := i
    if prefix < 0
        return -1
    return (minIndex + 1) mod n
```

## Comparison

| Approach               | Idea                                 | Time   | Space | Recommended |
| ---------------------- | ------------------------------------ | ------ | ----- | ----------- |
| Greedy (one pass)      | Reset start when tank < 0            | O(n)   | O(1)  | Yes        |
| Min-prefix method      | Start after global minimum prefix    | O(n)   | O(1)  | Yes        |
| Brute force simulation | Try every start                      | O(n^2) | O(1)  | No         |
