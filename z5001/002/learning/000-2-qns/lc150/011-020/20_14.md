# Longest Common Prefix

## Difficulty
Easy

## Description
Find the longest common prefix string amongst an array of strings. If there is no common prefix, return an empty string.

## Examples

### Example 1

```text
Input: ["flower","flow","flight"]
Output: "fl"
Explanation: Compare characters column-wise and stop at first mismatch.
```

### Example 2

```text
Input: ["dog","racecar","car"]
Output: ""
Explanation: No common prefix at index 0.
```

### Example 3

```text
Input: []
Output: ""
Explanation: Empty input returns empty prefix.
```

## Constraints

```text
0 <= strs.length <= 200
0 <= strs[i].length <= 200
All inputs contain only lowercase English letters (or general characters).
```

---

## Idea
Compare characters column-wise across all strings; stop at first mismatch or when any string ends.

---

## Pseudo Code

```text
function longestCommonPrefix(strs)
    if strs is empty
        return ""
    n = length of strs
    minLen = length of strs[0]
    for i from 1 to n-1
        if length of strs[i] < minLen
            minLen = length of strs[i]
    for i from 0 to minLen-1
        ch = character at strs[0][i]
        for j from 1 to n-1
            if character at strs[j][i] != ch
                return substring(strs[0], 0, i)
    return substring(strs[0], 0, minLen)
```

## Complexity

| Metric           | Value      |
| ---------------- | ---------- |
| Time Complexity  | O(N * M)   |
| Space Complexity | O(M)       |

## Other Patterns

### Pattern 1

**Idea**

Horizontal scanning: keep prefix and shrink by comparing with each string.

**Pseudo Code**

```text
function longestCommonPrefix_horizontal(strs)
    if strs is empty
        return ""
    prefix = strs[0]
    for i from 1 to length of strs - 1
        while prefix is not empty and strs[i] does not start with prefix
            prefix = substring(prefix, 0, length(prefix)-1)
        if prefix is empty
            return ""
    return prefix
```

### Pattern 2

**Idea**

Divide and conquer: split array, get LCP of halves, then LCP of results.

**Pseudo Code**

```text
function longestCommonPrefix_divide(strs)
    if strs is empty
        return ""
    return lcpRange(strs, 0, length(strs)-1)

function lcpRange(strs, left, right)
    if left == right
        return strs[left]
    mid = (left + right) // 2
    lcpLeft = lcpRange(strs, left, mid)
    lcpRight = lcpRange(strs, mid+1, right)
    return commonPrefixBetween(lcpLeft, lcpRight)

function commonPrefixBetween(a, b)
    minLen = min(length(a), length(b))
    for i from 0 to minLen-1
        if a[i] != b[i]
            return substring(a, 0, i)
    return substring(a, 0, minLen)
```

### Pattern 3

**Idea**

Binary search on prefix length and verify all strings share that length.

**Pseudo Code**

```text
function longestCommonPrefix_binary(strs)
    if strs is empty
        return ""
    minLen = min length in strs
    low = 0
    high = minLen
    while low <= high
        mid = (low + high) // 2
        if all strings share prefix of length mid
            low = mid + 1
        else
            high = mid - 1
    return substring(strs[0], 0, (low+high)//2)
```

### Pattern 4

**Idea**

Build a Trie of strings and walk from root until a node has !=1 child or is end-of-word.

**Pseudo Code**

```text
function longestCommonPrefix_trie(strs)
    if strs is empty
        return ""
    root = new TrieNode()
    for each s in strs
        insert s into root
    node = root
    prefix = ""
    while node has exactly one child and node is not end-of-word
        node = the single child
        append node.char to prefix
    return prefix
```

## Comparison

| Approach            | Idea                                 | Time        | Space       | Recommended |
| ------------------- | ------------------------------------ | ----------- | ----------- | ----------- |
| Column-wise (vertical) | Compare chars column-wise            | O(N * M)    | O(M)        | Yes         |
| Horizontal scanning | Shrink prefix by comparing each string | O(N * M)    | O(M)        | Yes         |
| Divide and Conquer  | Split and merge LCPs                 | O(N * M)    | O(M log N)  | No          |
| Binary Search       | Search prefix length                 | O(N * M)    | O(M)        | No          |
| Trie                | Build trie and walk single-child path| O(N * M)    | O(total chars) | No       |
