# H-Index

## Difficulty
Medium

## Description
Given an array of citation counts for a researcher, compute the researcher's H-index: the maximum h such that the researcher has at least h papers with at least h citations each.

## Examples

### Example 1

```text
Input: [3,0,6,1,5]
Output: 3
Explanation: After sorting descending -> [6,5,3,1,0]. There are 3 papers with >=3 citations.
```

## Constraints

```text
n = citations.length, 1 <= n <= 1e5
0 <= citations[i] <= 1e9
```

---

## Idea
Sort citations descending and find largest index h where citations[h-1] >= h.

---

## Pseudo Code

```text
function computeHIndex(citations)
    if citations is empty then return 0
    sort citations in descending order
    h = 0
    for i from 1 to length(citations)
        if citations[i-1] >= i then h = i
        else break
    return h
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n log n) |
| Space Complexity | O(1) extra (or O(n) if sort uses extra space) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | citations = [3,0,6,1,5] | sort descending | [6,5,3,1,0] |
| 2 | i=1, h=0 | check 6 >= 1 | h=1 |
| 3 | i=2, h=1 | check 5 >= 2 | h=2 |
| 4 | i=3, h=2 | check 3 >= 3 | h=3 |
| 5 | i=4, h=3 | check 1 >= 4 -> false | break, return 3 |

## Other Patterns

### Pattern 1

**Idea**
Use bucket/counting approach with O(n) time by capping citations at n.

**Pseudo Code**

```text
function computeHIndexBucket(citations)
    n = length(citations)
    buckets = array of zeros of size n+1
    for each c in citations
        if c >= n then buckets[n] += 1
        else buckets[c] += 1
    total = 0
    for i from n down to 0
        total += buckets[i]
        if total >= i then return i
    return 0
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Sorting | Sort descending then scan | O(n log n) | O(1) extra | Yes (simple, robust) |
| Bucket (counting) | Count citations capped at n and scan from high to low | O(n) | O(n) | Yes (when n large and values huge) |
