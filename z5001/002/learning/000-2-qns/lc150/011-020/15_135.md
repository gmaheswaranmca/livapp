# Candy

## Difficulty
Medium

## Description
Distribute candies to children standing in a line with given ratings so that:
- Each child has at least one candy.
- Any child with a higher rating than an adjacent child gets more candies than that neighbor.
Return the minimum total candies required.

## Examples

### Example 1

```text
Input: ratings = [1,0,2]
Output: 5
Explanation: candies = [2,1,2], total = 5
```

### Example 2

```text
Input: ratings = [1,2,2]
Output: 4
Explanation: candies = [1,2,1], total = 4
```

## Constraints

```text
1 <= ratings.length <= 20000
0 <= ratings[i] <= 10^5
```

---

## Idea
Greedy two-pass: give 1 candy each, left-to-right enforce increasing neighbors, right-to-left enforce decreasing neighbors using max.

---

## Pseudo Code

```text
function minCandies(ratings)
    n = length(ratings)
    if n == 0 then return 0
    candies = array of size n filled with 1
    for i from 1 to n-1
        if ratings[i] > ratings[i-1] then
            candies[i] = candies[i-1] + 1
    for i from n-2 downto 0
        if ratings[i] > ratings[i+1] then
            candies[i] = max(candies[i], candies[i+1] + 1)
    total = 0
    for i from 0 to n-1
        total = total + candies[i]
    return total
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | State (ratings) | Operation | Result (candies) |
| ---- | --------------- | --------- | ---------------- |
| 1    | [1,0,2]         | init      | [1,1,1]          |
| 2    | [1,0,2]         | left pass: i=1 -> no change | [1,1,1] |
| 3    | [1,0,2]         | left pass: i=2, 2>0 -> candies[2]=2 | [1,1,2] |
| 4    | [1,0,2]         | right pass: i=1 -> no change | [1,1,2] |
| 5    | [1,0,2]         | right pass: i=0, 1>0 -> candies[0]=max(1,1+1)=2 | [2,1,2] |
| 6    | [1,0,2]         | sum       | total = 5        |

1. Initialize all candies to 1.
2. Left-to-right: increase candies when current rating > previous rating.
3. Right-to-left: ensure decreases to right also satisfy condition using max to preserve left pass.
4. Sum candies for result.

## Other Patterns

### Pattern 1

**Idea**

Single-pass slope (up/down) tracking with O(1) extra space.

**Pseudo Code**

```text
function minCandiesSlope(ratings)
    n = length(ratings)
    if n == 0 then return 0
    total = 1
    up = 0
    down = 0
    prev_slope = 0
    for i from 1 to n-1
        if ratings[i] > ratings[i-1] then
            slope = 1
        else if ratings[i] < ratings[i-1] then
            slope = -1
        else
            slope = 0
        if (prev_slope < 0 and slope >= 0) then
            total = total + (up*(up+1))/2 + (down*(down+1))/2 - min(up,down)
            up = 0
            down = 0
        if slope > 0 then
            up = up + 1
            total = total + up
        else if slope == 0 then
            total = total + 1
        else
            down = down + 1
            total = total + down
        prev_slope = slope
    return total
```

### Pattern 2

**Idea**

Iterative relaxation (simulate until no changes) — simple but O(n^2).

**Pseudo Code**

```text
function minCandiesBrute(ratings)
    n = length(ratings)
    candies = array of size n filled with 1
    changed = true
    while changed
        changed = false
        for i from 0 to n-1
            if i>0 and ratings[i] > ratings[i-1] and candies[i] <= candies[i-1]
                candies[i] = candies[i-1] + 1
                changed = true
            if i<n-1 and ratings[i] > ratings[i+1] and candies[i] <= candies[i+1]
                candies[i] = candies[i+1] + 1
                changed = true
    total = sum(candies)
    return total
```

## Comparison

| Approach       | Idea                                    | Time  | Space | Recommended |
| -------------- | --------------------------------------- | ----- | ----- | ----------- |
| Two-pass Greedy| Left-to-right then right-to-left adjust | O(n)  | O(n)  | Yes         |
| Slope method   | Track up/down slopes, O(1) extra space  | O(n)  | O(1)  | Yes (if careful) |
| Brute force    | Iterative relax until stable            | O(n^2)| O(n)  | No          |
