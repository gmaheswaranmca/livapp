# Integer to Roman

## Difficulty
Easy

## Description
Convert an integer (1 to 3999) to its Roman numeral representation using standard Roman symbols and subtractive notation.

## Examples

### Example 1

```text
Input: 1994
Output: "MCMXCIV"
Explanation: 1000=M, 900=CM, 90=XC, 4=IV -> MCMXCIV
```

### Example 2

```text
Input: 58
Output: "LVIII"
Explanation: 50=L, 5=V, 3=III -> LVIII
```

### Example 3

```text
Input: 4
Output: "IV"
Explanation: 4=IV
```

## Constraints

```text
1 <= num <= 3999
Use standard Roman symbols: I,V,X,L,C,D,M with subtractive pairs IV,IX,XL,XC,CD,CM
```

---

## Idea
Greedy: subtract the largest Roman-value while appending its symbol until the number becomes zero.

---

## Pseudo Code

```text
function intToRoman(num)
    values := [1000,900,500,400,100,90,50,40,10,9,5,4,1]
    symbols := ["M","CM","D","CD","C","XC","L","XL","X","IX","V","IV","I"]
    result := empty list
    for i from 0 to length(values)-1
        while num >= values[i]
            append symbols[i] to result
            num := num - values[i]
    return join(result)
```

---

## Complexity

| Metric           | Value        |
| ---------------- | ------------ |
| Time Complexity  | O(k)         |
| Space Complexity | O(k)         |

k = number of output symbols (bounded, constant <= ~15 for num<=3999)

---

## Code Explanation

### Dry Run

| Step | State         | Operation            | Result        |
| ---- | ------------- | -------------------- | ------------- |
| 1    | num=1994      | num>=1000 -> append M| result="M", num=994 |
| 2    | num=994       | num>=900 -> append CM| result="MCM", num=94 |
| 3    | num=94        | num>=90 -> append XC | result="MCMXC", num=4 |
| 4    | num=4         | num>=4 -> append IV  | result="MCMXCIV", num=0 |

## Other Patterns

### Pattern 2

**Idea**

Map thousands/hundreds/tens/ones to strings and concatenate.

**Pseudo Code**

```text
function intToRoman(num)
    thousands := ["","M","MM","MMM"]
    hundreds := ["","C","CC","CCC","CD","D","DC","DCC","DCCC","CM"]
    tens := ["","X","XX","XXX","XL","L","LX","LXX","LXXX","XC"]
    ones := ["","I","II","III","IV","V","VI","VII","VIII","IX"]
    result := thousands[num / 1000]
    result := result + hundreds[(num % 1000) / 100]
    result := result + tens[(num % 100) / 10]
    result := result + ones[num % 10]
    return result
```
