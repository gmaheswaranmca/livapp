# Trapping Rain Water

## Difficulty
Medium

## Description
Given an array heights representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

## Examples

### Example 1

```text
Input: [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
Explanation: Total trapped water units = 6.
```

### Example 2

```text
Input: [4,2,0,3,2,5]
Output: 9
Explanation: Trapped water between bars sums to 9.
```

## Constraints

```text
1 <= n <= 10^5
0 <= heights[i] <= 10^5
Expected time: O(n) for optimal solution
```

---

## Idea
Use two pointers from both ends, track left_max and right_max, accumulate water by advancing the smaller side.

---

## Pseudo Code

```text
function trap(heights)
    if heights is empty return 0
    left <- 0
    right <- length(heights) - 1
    left_max <- 0
    right_max <- 0
    ans <- 0
    while left <= right
        if heights[left] <= heights[right]
            if heights[left] >= left_max
                left_max <- heights[left]
            else
                ans <- ans + (left_max - heights[left])
            left <- left + 1
        else
            if heights[right] >= right_max
                right_max <- heights[right]
            else
                ans <- ans + (right_max - heights[right])
            right <- right - 1
    return ans
```

## Other Patterns

### Pattern 1

**Idea**

Precompute left_max and right_max arrays and sum min(left_max[i], right_max[i]) - height[i].

**Pseudo Code**

```text
function trap_dp(heights)
    n <- length(heights)
    if n == 0 return 0
    left_max <- array of size n
    right_max <- array of size n
    left_max[0] <- heights[0]
    for i from 1 to n-1
        left_max[i] <- max(left_max[i-1], heights[i])
    right_max[n-1] <- heights[n-1]
    for i from n-2 down to 0
        right_max[i] <- max(right_max[i+1], heights[i])
    ans <- 0
    for i from 0 to n-1
        ans <- ans + max(0, min(left_max[i], right_max[i]) - heights[i])
    return ans
```

### Pattern 2

**Idea**

Use a monotonic decreasing stack to find bounded regions and accumulate trapped water per popped bar.

**Pseudo Code**

```text
function trap_stack(heights)
    stack <- empty stack
    ans <- 0
    for i from 0 to length(heights)-1
        while stack is not empty and heights[i] > heights[stack.top()]
            top <- stack.pop()
            if stack is empty break
            distance <- i - stack.top() - 1
            bounded_height <- min(heights[i], heights[stack.top()]) - heights[top]
            ans <- ans + distance * bounded_height
        stack.push(i)
    return ans
```

## Comparison

| Approach      | Idea                                             | Time  | Space     | Recommended |
| ------------- | ------------------------------------------------ | ----- | --------- | ----------- |
| Two Pointers  | Advance smaller side tracking left_max/right_max | O(n)  | O(1)      | Yes         |
| DP Arrays     | Precompute left/right max arrays                 | O(n)  | O(n)      | No (if O(1) needed) |
| Monotonic Stack | Use stack to compute bounded regions           | O(n)  | O(n)      | No (useful alternative) |
