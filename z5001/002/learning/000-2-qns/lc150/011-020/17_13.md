# Title
Roman to Integer

## Difficulty
Easy

## Description
Convert a Roman numeral string to its integer value. Handle subtraction pairs (IV, IX, XL, XC, CD, CM).

## Examples

### Example 1

```text
Input: "MCMXCIV"
Output: 1994
Explanation: M(1000) + CM(900) + XC(90) + IV(4) = 1994
```

### Example 2

```text
Input: "III"
Output: 3
Explanation: I + I + I = 3
```

### Example 3

```text
Input: "LVIII"
Output: 58
Explanation: L(50) + V(5) + I + I + I = 58
```

### Example 4

```text
Input: "IV"
Output: 4
Explanation: IV = 5 - 1 = 4
```

## Constraints

```text
1 <= s.length <= 15
s contains only characters: I,V,X,L,C,D,M
The numeral represents an integer in range [1, 3999]
```

---

## Idea
Single pass with value map; subtract when a smaller-value symbol precedes a larger-value symbol.

---

## Pseudo Code

```text
function romanToInt(s)
    map = {'I':1,'V':5,'X':10,'L':50,'C':100,'D':500,'M':1000}
    total = 0
    n = length(s)
    for i from 0 to n-1
        if i+1 < n and map[s[i]] < map[s[i+1]] then
            total = total - map[s[i]]
        else
            total = total + map[s[i]]
    return total
```

| Metric           | Value  |

## Other Patterns

### Pattern 1

**Idea**

Scan and replace subtractive pairs first, then sum tokens.

**Pseudo Code**

```text
function romanToInt_pairs(s)
    pairs = {'IV':4,'IX':9,'XL':40,'XC':90,'CD':400,'CM':900}
    singles = {'I':1,'V':5,'X':10,'L':50,'C':100,'D':500,'M':1000}
    total = 0
    i = 0
    n = length(s)
    while i < n
        if i+1 < n and s[i:i+2] in pairs then
            total = total + pairs[s[i:i+2]]
            i = i + 2
        else
            total = total + singles[s[i]]
            i = i + 1
    return total
```

### Pattern 2

**Idea**

Replace known subtractive strings with single placeholders then sum mapped values.

**Pseudo Code**

```text
function romanToInt_replace(s)
    replace_map = {'CM':'@','CD':'^','XC':'~','XL':'`','IX':'#','IV':'$'}
    value_map = {'M':1000,'D':500,'C':100,'L':50,'X':10,'V':5,'I':1,'@':900,'^':400,'~':90,'`':40,'#':9,'$':4}
    for pair, token in replace_map items
        s = replace_all(s, pair, token)
    total = 0
    for ch in s
        total = total + value_map[ch]
    return total
```

## Comparison

| Approach   | Idea                                         | Time | Space | Recommended |
| ---------- | -------------------------------------------- | ---- | ----- | ----------- |
| Single pass| One-pass subtract-when-smaller-before-larger | O(n) | O(1)  | Yes         |
| Pairs scan | Check two-char pairs and consume them       | O(n) | O(1)  | No (equivalent)|
| Replace    | Replace pairs with tokens then sum          | O(n) | O(1)  | No (more work) |
