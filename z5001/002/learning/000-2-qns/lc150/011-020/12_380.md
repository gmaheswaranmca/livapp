# Insert Delete GetRandom O(1)

## Difficulty
Medium

## Description
Design a data structure that supports insert(val), remove(val), and getRandom() in average O(1) time. insert returns true if val was not present and was inserted; false otherwise. remove returns true if val was present and removed; false otherwise. getRandom returns a random element from current set with uniform probability.

## Examples

### Example 1

```text
Input: ["RandomizedSet","insert","insert","insert","getRandom","remove","getRandom"]
       [[],[1],[2],[1],[],[1],[]]
Output: [null,true,true,false,1,true,2]
Explanation: insert(1) -> true, insert(2) -> true, insert(1) -> false (already present),
getRandom() -> 1 or 2, remove(1) -> true, getRandom() -> 2
```

## Constraints

```text
Values are integers.
No duplicate elements allowed.
Number of operations <= 2*10^5.
Memory fits O(n) where n is number of stored elements.
getRandom called only when set is non-empty.
```

---

## Idea
Use a dynamic array to store values and a hashmap mapping value -> its index in the array; swap-remove to delete in O(1).

---

## Pseudo Code

```text
function RandomizedSet()
    array = empty dynamic array
    map = empty hash map from value to index

function insert(val)
    if map contains val then
        return false
    append val to array
    map[val] = array.length - 1
    return true

function remove(val)
    if map does not contain val then
        return false
    idx = map[val]
    lastVal = array[array.length - 1]
    swap array[idx] and array[array.length - 1]
    map[lastVal] = idx
    remove last element from array
    remove val from map
    return true

function getRandom()
    idx = random integer in [0, array.length - 1]
    return array[idx]
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(1) average per operation |
| Space Complexity | O(n)   |

## Code Explanation

### Dry Run

| Step | State (array) | State (map value->index) | Operation | Result |
| ---- | ------------- | ------------------------ | --------- | ------ |
| 1    | []            | {}                       | insert(1) | array=[1], map={1:0}, returns true |
| 2    | [1]           | {1:0}                    | insert(2) | array=[1,2], map={1:0,2:1}, returns true |
| 3    | [1,2]         | {1:0,2:1}                | insert(1) | unchanged, returns false |
| 4    | [1,2]         | {1:0,2:1}                | remove(1) | swap 1 and 2 -> array=[2,1], update map{2:0}, pop -> array=[2], map={2:0}, returns true |
| 5    | [2]           | {2:0}                    | getRandom | returns 2 |

## Other Patterns

### Pattern 1

**Idea**
Use HashSet only; insert/remove O(1) but getRandom O(n).

**Pseudo Code**

```text
function insert(val)
    return set.add(val)

function remove(val)
    return set.remove(val)

function getRandom()
    convert set to array or iterate k steps to pick random item -> O(n)
```

### Pattern 2

**Idea**
Maintain balanced BST for ordered set; insert/remove O(log n); getRandom can be O(log n) if nodes store subtree sizes.

**Pseudo Code**

```text
function insert(val)
    insert val into BST and update subtree sizes
    return true if inserted else false

function remove(val)
    remove val from BST and update subtree sizes
    return true if removed else false

function getRandom()
    k = random integer in [1, root.size]
    return select k-th element using subtree sizes
```
