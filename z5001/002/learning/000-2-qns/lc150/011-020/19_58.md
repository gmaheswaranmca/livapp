# Length of Last Word

## Difficulty
Easy

## Description
Given a string s consisting of words and spaces, return the length of the last word in the string. A word is a maximal substring consisting of non-space characters.

## Examples

### Example 1

```text
Input: "Hello World"
Output: 5
Explanation: Last word is "World" with length 5.
```

### Example 2

```text
Input: "   fly me   to   the moon  "
Output: 4
Explanation: Last word is "moon" with length 4 (ignore trailing spaces).
```

## Constraints

```text
1 <= s.length <= 10^4
s consists of English letters and spaces ' '.
There is at least one word in s.
```

---

## Idea
Traverse from the end: skip trailing spaces then count characters until the next space or start.

---

## Pseudo Code

```text
function lengthOfLastWord(s)
    i := length(s) - 1
    count := 0
    while i >= 0 and s[i] == ' '
        i := i - 1
    while i >= 0 and s[i] != ' '
        count := count + 1
        i := i - 1
    return count
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (i, count) | Operation                         | Result         |
| ---- | ---------------- | --------------------------------- | -------------- |
| 1    | (10,0)           | skip trailing spaces at "Hello World" end | i moves to 9  |
| 2    | (9,0)            | s[9]='d' != ' ' then count++     | count=1, i=8   |
| 3    | (8,1)            | s[8]='l' != ' ' then count++     | count=2, i=7   |
| 4    | (7,2)            | s[7]='r' != ' ' then count++     | count=3, i=6   |
| 5    | (6,3)            | s[6]='o' != ' ' then count++     | count=4, i=5   |
| 6    | (5,4)            | s[5]='W' != ' ' then count++     | count=5, i=4   |
| 7    | (4,5)            | s[4]=' ' stop                      | return 5       |

## Other Patterns

### Pattern 1

**Idea**
Split by spaces and take last non-empty token.

**Pseudo Code**

```text
function lengthOfLastWord_split(s)
    tokens := split(s, ' ')
    for j from length(tokens)-1 down to 0
        if tokens[j] != ""
            return length(tokens[j])
    return 0
```

### Pattern 2

**Idea**
Single forward pass tracking current word length and updating when space encountered.

**Pseudo Code**

```text
function lengthOfLastWord_forward(s)
    current := 0
    last := 0
    for i from 0 to length(s)-1
        if s[i] != ' '
            current := current + 1
        else if current > 0
            last := current
            current := 0
    return current if current > 0 else last
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Reverse traverse | Skip trailing spaces then count backward | O(n) | O(1) | Yes |
| Split | Split string and pick last non-empty token | O(n) | O(n) | No |
| Forward pass | Track current word length and update last | O(n) | O(1) | Yes (equally) |
