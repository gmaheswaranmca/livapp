# 148 - Sort List

## Difficulty
Medium

## Description
Sort a singly-linked list in O(n log n) time and return the sorted list. Preserve list nodes; do not create arrays unless using an alternative approach.

## Examples

### Example 1

```text
Input: [4,2,1,3]
Output: [1,2,3,4]
Explanation: Merge Sort on linked list.
```

### Example 2

```text
Input: [-1,5,3,4,0]
Output: [-1,0,3,4,5]
```

## Constraints

```text
Number of nodes: 0 <= n <= 5 * 10^4
Node value range: -10^5 <= val <= 10^5
Expected time: O(n log n)
```

---

## Idea
Use merge sort: split list by fast/slow pointers, recursively sort halves, then merge two sorted lists.

---

## Pseudo Code

```text
function sortList(head)
    if head == null or head.next == null
        return head
    prev = null
    slow = head
    fast = head
    while fast != null and fast.next != null
        prev = slow
        slow = slow.next
        fast = fast.next.next
    prev.next = null
    left = sortList(head)
    right = sortList(slow)
    return mergeTwoLists(left, right)

function mergeTwoLists(a, b)
    dummy = new Node(0)
    tail = dummy
    while a != null and b != null
        if a.val <= b.val
            tail.next = a
            a = a.next
        else
            tail.next = b
            b = b.next
        tail = tail.next
    if a != null
        tail.next = a
    else
        tail.next = b
    return dummy.next
```

## Complexity

| Metric           | Value    |
| ---------------- | -------- |
| Time Complexity  | O(n log n) |
| Space Complexity | O(log n) (recursion stack) |

## Code Explanation

### Dry Run

| Step | State               | Operation                             | Result           |
| ---- | ------------------- | ------------------------------------- | ---------------- |
| 1    | [4,2,1,3]           | Find mid using fast/slow              | left=[4,2], right=[1,3] |
| 2    | left=[4,2]          | Split left                             | left1=[4], left2=[2] |
| 3    | right=[1,3]         | Split right                            | right1=[1], right2=[3] |
| 4    | merge left1,left2   | Merge [4] and [2]                      | [2,4]            |
| 5    | merge right1,right2 | Merge [1] and [3]                      | [1,3]            |
| 6    | merge [2,4] and [1,3] | Final merge                          | [1,2,3,4]        |

1. Use fast/slow to split the list into halves and cut the link.
2. Recursively sort left and right halves until single nodes.
3. Merge two sorted lists using a dummy head and return merged head.

## Other Patterns

### Pattern 1

**Idea**
Bottom-up iterative merge sort to avoid recursion.

**Pseudo Code**

```text
function sortListBottomUp(head)
    if head == null or head.next == null
        return head
    length = 0
    node = head
    while node != null
        length = length + 1
        node = node.next
    dummy = new Node(0)
    dummy.next = head
    size = 1
    while size < length
        prev = dummy
        curr = dummy.next
        while curr != null
            left = curr
            right = split(left, size)
            curr = split(right, size)
            merged = mergeTwoLists(left, right)
            prev.next = merged
            while prev.next != null
                prev = prev.next
        size = size * 2
    return dummy.next

function split(head, size)
    if head == null
        return null
    i = 1
    while i < size and head.next != null
        head = head.next
        i = i + 1
    next = head.next
    head.next = null
    return next
```

### Pattern 2

**Idea**
Copy nodes to array, sort array, rebuild list (uses O(n) extra space).

**Pseudo Code**

```text
function sortListUsingArray(head)
    arr = empty list
    node = head
    while node != null
        arr.append(node)
        node = node.next
    sort arr by node.val
    for i from 0 to arr.length - 2
        arr[i].next = arr[i+1]
    if arr.length > 0
        arr[-1].next = null
        return arr[0]
    return null
```

## Comparison

| Approach           | Idea                                 | Time       | Space      | Recommended |
| ------------------ | ------------------------------------ | ---------- | ---------- | ----------- |
| Recursive Merge    | Split with fast/slow, recurse, merge | O(n log n) | O(log n)   | Yes         |
| Bottom-up Merge    | Iterative merges by sublist size     | O(n log n) | O(1)       | Yes         |
| Array + Sort       | Convert to array, sort, rebuild      | O(n log n) | O(n)       | No          |
