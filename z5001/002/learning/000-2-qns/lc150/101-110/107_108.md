# Convert Sorted Array to Binary Search Tree

## Difficulty
Easy

## Description
Given a sorted (ascending) integer array nums, convert it to a height-balanced binary search tree (BST). A height-balanced BST is defined as a binary tree in which the depth of the two subtrees of every node never differs by more than 1.

## Examples

### Example 1

```text
Input: nums = [-10,-3,0,5,9]
Output: A height-balanced BST (one possible):
       0
      / \
   -10   5
     \    \
     -3    9
Explanation: Choose middle element as root recursively.
```

### Example 2

```text
Input: nums = [1,3]
Output: One possible BST:
   1
    \
     3
Explanation: Middle chosen as left-mid (index floor((0+1)/2)=0).
```

## Constraints

```text
1 <= nums.length <= 10^4
-10^5 <= nums[i] <= 10^5
nums is sorted in strictly increasing order (no duplicates).
```

---

## Idea
Recursively pick the middle element of the current subarray as root, build left subtree from left subarray and right subtree from right subarray.

---

## Pseudo Code

```text
function sortedArrayToBST(nums)
    if nums is empty
        return null
    return build(0, length(nums)-1)

function build(l, r)
    if l > r
        return null
    mid = floor((l + r) / 2)
    node = new TreeNode(nums[mid])
    node.left = build(l, mid - 1)
    node.right = build(mid + 1, r)
    return node
```

| Metric           | Value  |

| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

## Code Explanation

### Dry Run

| Step | State (l,r,mid) | Operation                      | Result (node created / link)        |
| ---- | --------------- | ------------------------------ | ----------------------------------- |
| 1    | (0,4,2)         | create node with nums[2]=0     | root = 0                            |
| 2    | (0,1,0)         | create node with nums[0]=-10   | root.left = -10                     |
| 3    | (0,-1,?)        | base case l>r                  | left child of -10 = null            |
| 4    | (1,1,1)         | create node with nums[1]=-3    | right child of -10 = -3             |
| 5    | (3,4,3)         | create node with nums[3]=5     | root.right = 5                      |
| 6    | (3,2,?)        | base case l>r                  | left child of 5 = null              |
| 7    | (4,4,4)         | create node with nums[4]=9     | right child of 5 = 9                |

## Other Patterns

### Pattern 1

**Idea**

Iterative construction using a queue of subarray ranges to assign parents level-order.

**Pseudo Code**

```text
function sortedArrayToBST(nums)
    if nums is empty
        return null
    root = new TreeNode(0)          // placeholder value
    queue = empty queue
    enqueue(queue, (root, 0, length(nums)-1))
    while queue is not empty
        (node, l, r) = dequeue(queue)
        mid = floor((l + r) / 2)
        node.val = nums[mid]
        if l <= mid - 1
            node.left = new TreeNode(0)
            enqueue(queue, (node.left, l, mid - 1))
        if mid + 1 <= r
            node.right = new TreeNode(0)
            enqueue(queue, (node.right, mid + 1, r))
    return root
```

### Pattern 2

**Idea**

Choose right-middle for even-length subarray to influence tree shape.

**Pseudo Code**

```text
function sortedArrayToBST(nums)
    if nums is empty
        return null
    return buildRightMid(0, length(nums)-1)

function buildRightMid(l, r)
    if l > r
        return null
    mid = ceil((l + r) / 2)
    node = new TreeNode(nums[mid])
    node.left = buildRightMid(l, mid - 1)
    node.right = buildRightMid(mid + 1, r)
    return node
```

## Comparison

| Approach           | Idea                              | Time  | Space       | Recommended |
| ------------------ | ---------------------------------- | ----- | ----------- | ----------- |
| Recursive (mid)    | Middle as root, recurse left/right | O(n)  | O(n) total, O(log n) auxiliary | Yes         |
| Iterative (queue)  | Level-order build with ranges      | O(n)  | O(n)        | No (use if recursion is constrained) |
| Recursive (right)  | Use right-middle for even lengths  | O(n)  | O(n) total, O(log n) auxiliary | No (shape preference) |
