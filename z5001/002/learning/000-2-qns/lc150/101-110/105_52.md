# Title
N-Queens II (Count valid N-Queens arrangements)

## Difficulty
Medium

## Description
Count the number of distinct ways to place n queens on an n×n chessboard so that no two queens attack each other.

## Examples

### Example 1

```text
Input: n = 4
Output: 2
Explanation: Two valid configurations exist for 4x4 board.
```

## Constraints

```text
1 <= n <= 14
Return integer count of distinct solutions.
```

---

## Idea
Backtracking using bitmasks to track occupied columns and diagonals, enabling O(1) checks and fast pruning.

---

## Pseudo Code

```text
function totalNQueens(n)
    if n <= 0 then return 0
    limit ← (1 << n) - 1
    return backtrack(limit, 0, 0, 0)

function backtrack(limit, cols, diags, antiDiags)
    if cols == limit then return 1
    count ← 0
    available ← limit & ~(cols | diags | antiDiags)
    while available != 0
        position ← available & -available
        available ← available - position
        count ← count + backtrack(limit, cols | position, (diags | position) << 1, (antiDiags | position) >> 1)
    return count
```

---

## Complexity

| Metric           | Value             |
| ---------------- | ----------------- |
| Time Complexity  | O(k) where k ≈ number of valid/backtracked states (upper-bounded by O(n!)) |
| Space Complexity | O(n) recursion depth (plus O(1) bitmask storage) |

## Code Explanation

### Dry Run

| Step | Row | cols (bin) | diags (bin) | antiDiags (bin) | available (bin) | chosen (bin) | count |
| ---- | --- | ---------- | ----------- | --------------- | --------------- | ------------ | ----- |
| 1    | 0   | 0000       | 0000        | 0000            | 1111            | 0001         | 0     |
| 2    | 1   | 0001       | 0010        | 0000            | 1100            | 0100         | 0     |
| 3    | 2   | 0101       | 1010        | 0010            | 0000            | -            | 0     |
| 4    | backtrack to row1, choose next pos | cols=0001 | diags=0010 | antiDiags=0000 | available=1000 | chosen=1000 | 0 |
| 5    | row2 after second choice | cols=1001 | diags=0001<<1→0010? (updated accordingly) | ... | available etc. | chosen etc. | 1 (found one solution) |
| 6    | explore other branches | ... | ... | ... | ... | ... | 2 (final) |

(Important states shown; final count = 2 for n=4.)

1. Initialize limit = (1<<n)-1 to represent all n columns available.
2. At each row compute available = limit & ~(cols | diags | antiDiags).
3. Extract lowest set bit as position = available & -available to try one column.
4. Update cols, diags, antiDiags and recurse; shift diags left and antiDiags right for next row.
5. Accumulate counts when cols == limit (all queens placed).

## Other Patterns

### Pattern 2

**Idea**

Backtracking using sets (or boolean arrays) for columns and diagonals.

**Pseudo Code**

```text
function totalNQueens_sets(n)
    cols ← empty set
    posDiags ← empty set   # r + c
    negDiags ← empty set   # r - c
    return backtrack_sets(0, n, cols, posDiags, negDiags)

function backtrack_sets(row, n, cols, posDiags, negDiags)
    if row == n then return 1
    count ← 0
    for col from 0 to n-1
        if col in cols or (row + col) in posDiags or (row - col) in negDiags then continue
        add col to cols
        add (row + col) to posDiags
        add (row - col) to negDiags
        count ← count + backtrack_sets(row + 1, n, cols, posDiags, negDiags)
        remove col from cols
        remove (row + col) from posDiags
        remove (row - col) from negDiags
    return count
```

## Comparison

| Approach       | Idea                                  | Time               | Space         | Recommended |
| -------------- | ------------------------------------- | ------------------ | ------------- | ----------- |
| Bitmask        | Use integer masks and bit ops         | Much faster in practice; upper-bounded by O(n!) | O(n)         | Yes         |
| Sets / Arrays  | Use sets or boolean arrays for checks | Simpler; slower due to set ops, still backtracking | O(n)         | No (for max performance) |
