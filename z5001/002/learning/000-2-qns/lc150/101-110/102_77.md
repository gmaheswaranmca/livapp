# Combinations (Generate all combinations of k numbers from 1 to n)

## Difficulty
Easy / Medium

## Description
Generate all combinations of k distinct numbers chosen from the range 1..n (order of numbers inside a combination does not matter). Use include/exclude recursion to enumerate combinations.

## Examples

### Example 1

```text
Input: n = 4, k = 2
Output: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
Explanation: All 2-number combinations from 1..4.
```

## Constraints

```text
1 <= k <= n
1 <= n <= 20       // n reasonably small because output size is C(n,k)
Output size = C(n,k)
```

---

## Idea
Use include/exclude recursion: at each value i decide to include i or skip it, pruning when remaining items cannot fill the combination.

---

## Pseudo Code

```text
function combine(n, k)
    result = empty list
    function backtrack(start, chosen)
        if size(chosen) == k
            append copy(chosen) to result
            return
        if start > n
            return
        if (n - start + 1) < (k - size(chosen))
            return
        // include start
        append start to chosen
        backtrack(start + 1, chosen)
        remove last from chosen
        // exclude start
        backtrack(start + 1, chosen)
    backtrack(1, empty list)
    return result
```

---

## Complexity

| Metric           | Value                          |
| ---------------- | ------------------------------ |
| Time Complexity  | O(C(n,k) * k)                  |
| Space Complexity | O(k) (recursion stack) + O(C(n,k)*k) (output) |

---

## Code Explanation

### Dry Run

| Step | State                | Operation                     | Result                   |
| ---- | -------------------- | ----------------------------- | ------------------------ |
| 1    | start=1 chosen=[]    | include 1                     | chosen=[1]               |
| 2    | start=2 chosen=[1]   | include 2                     | chosen=[1,2] -> output   |
| 3    | back to start=2      | exclude 2                     | chosen=[1]               |
| 4    | start=3 chosen=[1]   | include 3                     | chosen=[1,3] -> output   |
| 5    | back to start=3      | exclude 3                     | chosen=[1]               |
| 6    | start=4 chosen=[1]   | include 4                     | chosen=[1,4] -> output   |

## Other Patterns

### Pattern 1

**Idea**
Lexicographic next-combination by maintaining an index array.

**Pseudo Code**

```text
function combine_iterative(n, k)
    if k == 0
        return [[]]
    indices = [1,2,...,k]
    result = empty list
    while true
        append copy(mapped indices) to result
        i = k
        while i >= 1 and indices[i] == n - k + i
            i = i - 1
        if i == 0
            break
        indices[i] = indices[i] + 1
        for j from i+1 to k
            indices[j] = indices[j-1] + 1
    return result
```

### Pattern 2

**Idea**
Use bitmask enumeration of n bits and select masks with exactly k bits set.

**Pseudo Code**

```text
function combine_bitmask(n, k)
    result = empty list
    for mask from 0 to (1 << n) - 1
        if popcount(mask) != k
            continue
        combo = empty list
        for i from 0 to n-1
            if (mask >> i) & 1 == 1
                append (i+1) to combo
        append combo to result
    return result
```

## Comparison

| Approach            | Idea                                 | Time                 | Space                         | Recommended |
| ------------------- | ------------------------------------ | -------------------- | ----------------------------- | ----------- |
| Include/Exclude     | Backtracking include or exclude each | O(C(n,k)*k)          | O(k)+output                   | Yes         |
| Lexicographic       | Next-combination indices             | O(C(n,k)*k)          | O(k)+output                   | Yes (iterative) |
| Bitmask Enumeration | Test all 2^n masks                    | O(2^n * n)           | O(n)+output                   | No (if n large)
