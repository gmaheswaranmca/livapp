# Word Search

## Difficulty
Medium

## Description
Given a 2D board of characters and a word, determine if the word exists in the grid by sequentially adjacent cells (horizontally or vertically). The same cell may not be used more than once.

## Examples

### Example 1

```text
Input: board = [
 ["A","B","C","E"],
 ["S","F","C","S"],
 ["A","D","E","E"]
], word = "ABCCED"
Output: true
Explanation: A->B->C->C->E->D forms the word.
```

### Example 2

```text
Input: board = [
 ["A","B","C","E"],
 ["S","F","C","S"],
 ["A","D","E","E"]
], word = "ABCB"
Output: false
Explanation: Cannot reuse the same cell twice.
```

## Constraints

```text
m = number of rows, n = number of columns
1 <= m, n <= 200
1 <= word.length <= 1000
board[i][j] and word consist of English letters
```

---

## Idea
Use DFS with backtracking from every cell that matches word[0], marking visited cells to avoid reuse.

---

## Pseudo Code

```text
function exist(board, word)
    m = rows of board
    n = columns of board
    if m == 0 or n == 0 then return false
    visited = 2D array m x n initialized false
    for r from 0 to m-1
        for c from 0 to n-1
            if board[r][c] == word[0] and dfs(board, word, r, c, 0, visited) then return true
    return false

function dfs(board, word, r, c, i, visited)
    if i == length(word) then return true
    if r < 0 or r >= m or c < 0 or c >= n then return false
    if visited[r][c] == true or board[r][c] != word[i] then return false
    visited[r][c] = true
    // explore 4 directions
    if dfs(board, word, r+1, c, i+1, visited) then return true
    if dfs(board, word, r-1, c, i+1, visited) then return true
    if dfs(board, word, r, c+1, i+1, visited) then return true
    if dfs(board, word, r, c-1, i+1, visited) then return true
    visited[r][c] = false
    return false
```

---

## Complexity

| Metric           | Value              |
| ---------------- | ------------------ |
| Time Complexity  | O(m * n * 4^L)     |
| Space Complexity | O(m * n) (visited) + O(L) recursion |

## Code Explanation

### Dry Run

| Step | State (r,c) | i (index in word) | Operation | Result |
| ---- | ----------- | ----------------- | --------- | ------ |
| 1    | (0,0)       | 0                 | match 'A' start DFS | visited (0,0)=T |
| 2    | (0,1)       | 1                 | move right match 'B' | visited (0,1)=T |
| 3    | (0,2)       | 2                 | move right match 'C' | visited (0,2)=T |
| 4    | (1,2)       | 3                 | move down match 'C' | visited (1,2)=T |
| 5    | (2,2)       | 4                 | move down match 'E' | visited (2,2)=T |
| 6    | (2,1)       | 5                 | move left match 'D' and i==len-1 | success true |

## Other Patterns

### Pattern 1

**Idea**

DFS backtracking with a separate visited matrix.

**Pseudo Code**

```text
function exist(board, word)
    initialize visited[m][n] = false
    loop all cells and call dfs as main pseudocode above
```

### Pattern 2

**Idea**

Modify board in-place to mark visited cells (e.g., set to '#') to avoid extra visited matrix.

**Pseudo Code**

```text
function exist(board, word)
    for each cell
        if board[r][c] == word[0] and dfs_inplace(board, word, r, c, 0) then return true
    return false

function dfs_inplace(board, word, r, c, i)
    if i == length(word) then return true
    if r < 0 or r >= m or c < 0 or c >= n or board[r][c] != word[i] then return false
    temp = board[r][c]
    board[r][c] = '#' // mark
    if dfs_inplace(board, word, r+1, c, i+1) then return true
    if dfs_inplace(board, word, r-1, c, i+1) then return true
    if dfs_inplace(board, word, r, c+1, i+1) then return true
    if dfs_inplace(board, word, r, c-1, i+1) then return true
    board[r][c] = temp
    return false
```

## Comparison

| Approach                  | Idea                                | Time             | Space            | Recommended |
| ------------------------- | ----------------------------------- | ---------------- | ---------------- | ----------- |
| DFS with visited matrix   | Safe backtracking with visited grid | O(m*n*4^L)       | O(m*n)           | Yes         |
| DFS in-place modification | Mark cells by overwriting characters| O(m*n*4^L)       | O(L) recursion   | Yes (if mutating input allowed) |
