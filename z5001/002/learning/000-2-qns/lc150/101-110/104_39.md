# Combination Sum

## Difficulty
Medium

## Description
Given an array of distinct positive integers candidates and a target positive integer target, return all unique combinations of candidates where the chosen numbers sum to target. Each number in candidates may be used unlimited times. Combinations may be returned in any order.

## Examples

### Example 1

```text
Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
Explanation: 2 can be used multiple times to form 2+2+3 = 7 and 7 itself is a candidate.
```

### Example 2

```text
Input: candidates = [2,3,5], target = 8
Output: [[2,2,2,2],[2,3,3],[3,5]]
Explanation: Multiple combinations use unlimited repetitions.
```

## Constraints

```text
1 <= candidates.length <= 30
1 <= candidates[i] <= 50
All elements of candidates are distinct.
1 <= target <= 500
```

---

## Idea
Use DFS backtracking with candidates sorted and pruning when partial sum exceeds target.

---

## Pseudo Code

```text
function combinationSum(candidates, target)
    sort candidates ascending
    result := empty list
    backtrack(startIndex=0, currentList=[], currentSum=0)
    return result

function backtrack(startIndex, currentList, currentSum)
    if currentSum == target
        append copy of currentList to result
        return
    if currentSum > target
        return
    for i from startIndex to length(candidates)-1
        candidate := candidates[i]
        if currentSum + candidate > target
            break
        append candidate to currentList
        backtrack(i, currentList, currentSum + candidate)  // allow reuse
        remove last element from currentList
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(k * N^(T/min_c)) approximate, exponential in target T (N = number of candidates, min_c = smallest candidate, k = average combination length) |
| Space Complexity | O(T/min_c) recursion depth + O(output size) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | [] sum=0 start=0 | choose 2 | [2] sum=2 |
| 2 | [2] sum=2 start=0 | choose 2 | [2,2] sum=4 |
| 3 | [2,2] sum=4 start=0 | choose 2 | [2,2,2] sum=6 |
| 4 | [2,2,2] sum=6 start=0 | choose 2 -> sum 8 >7 prune | backtrack |
| 5 | [2,2] sum=4 start=0 | choose 3 | [2,2,3] sum=7 -> add to result |
| 6 | [] explore other branches | choose 7 | [7] sum=7 -> add to result |

1. Sort candidates to allow early pruning.
2. Use backtrack(startIndex, currentList, currentSum) to build combinations.
3. If currentSum equals target, save a copy of currentList.
4. If currentSum exceeds target, abort branch.
5. Iterate i from startIndex to N-1, append candidates[i], recurse with same i to allow reuse, then pop.

## Other Patterns

### Pattern 1

**Idea**

Dynamic programming building combinations for each subtotal up to target.

**Pseudo Code**

```text
function combinationSumDP(candidates, target)
    dp := array of lists of lists size target+1
    dp[0] := list containing empty list
    sort candidates ascending
    for each c in candidates
        for sum from c to target
            for each comb in dp[sum - c]
                newComb := copy of comb
                append c to newComb
                append newComb to dp[sum]
    return unique combinations in dp[target] (ensure non-decreasing order in each)
```

### Pattern 2

**Idea**

Memoized DFS returning combinations for a remaining target to avoid recomputing subproblems.

**Pseudo Code**

```text
function combinationSumMemo(candidates, target)
    sort candidates ascending
    memo := map from int to list of lists
    return dfs(target, 0)

function dfs(remain, startIndex)
    if remain == 0
        return list containing empty list
    if (remain, startIndex) in memo
        return memo[(remain, startIndex)]
    res := empty list
    for i from startIndex to length(candidates)-1
        c := candidates[i]
        if c > remain
            break
        sublists := dfs(remain - c, i)
        for sub in sublists
            newComb := copy of sub
            prepend c to newComb (or append and maintain order)
            append newComb to res
    memo[(remain, startIndex)] := res
    return res
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Backtracking (DFS) | Explore combinations with pruning by sorted candidates | Exponential O(N^(T/min_c)) | O(T/min_c)+output | Yes |
| Dynamic Programming | Build combinations bottom-up for each subtotal | Polynomial in target * combinations generated (may be heavy) | O(target * avg_combinations) | No (for large target) |
| Memoized DFS | Cache results for (remain,start) to avoid recompute | Similar to backtracking but can reduce repeated work | Extra memo storage + recursion | Yes (when many overlapping subproblems)
