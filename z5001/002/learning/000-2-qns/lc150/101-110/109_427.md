# Construct Quad Tree

## Difficulty
Medium

## Description
Given an n x n binary grid (n is a power of 2), construct the corresponding quadtree. Each node has fields: val (boolean), isLeaf (boolean), topLeft, topRight, bottomLeft, bottomRight. If a region is uniform (all 0 or all 1), create a leaf node; otherwise split the region into four equal quadrants and recurse.

## Examples

### Example 1

```text
Input: grid = [[1,1],[1,1]]
Output: Node(isLeaf=true, val=1)
Explanation: Entire grid is all 1s so quadtree is a single leaf with val = 1.
```

### Example 2

```text
Input: grid = [[0,1],[1,0]]
Output: Node(isLeaf=false, val=1,
            topLeft=Node(isLeaf=true,val=0),
            topRight=Node(isLeaf=true,val=1),
            bottomLeft=Node(isLeaf=true,val=1),
            bottomRight=Node(isLeaf=true,val=0))
Explanation: No uniform large region; split into four 1x1 leaves.
```

## Constraints

```text
n == grid.length == grid[i].length
n is a power of 2
1 <= n <= 64
grid[i][j] is 0 or 1
```

---

## Idea
Use divide-and-conquer with a 2D prefix sum to test region homogeneity in O(1), building the quadtree recursively.

---

## Pseudo Code

```text
function constructQuadTree(grid)
    n := length(grid)
    prefix := buildPrefixSum(grid, n)
    return build(0, 0, n, prefix)

function buildPrefixSum(grid, n)
    create prefix array (n+1) x (n+1) initialized to 0
    for i from 1 to n
        for j from 1 to n
            prefix[i][j] := grid[i-1][j-1] + prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1]
    return prefix

function sumRegion(prefix, r1, c1, size)
    r2 := r1 + size - 1
    c2 := c1 + size - 1
    return prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]

function build(r, c, size, prefix)
    total := sumRegion(prefix, r, c, size)
    if total == 0
        return Node(isLeaf=true, val=0)
    if total == size * size
        return Node(isLeaf=true, val=1)
    half := size / 2
    topLeft := build(r, c, half, prefix)
    topRight := build(r, c + half, half, prefix)
    bottomLeft := build(r + half, c, half, prefix)
    bottomRight := build(r + half, c + half, half, prefix)
    return Node(isLeaf=false, val=1, topLeft=topLeft, topRight=topRight, bottomLeft=bottomLeft, bottomRight=bottomRight)
```

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | grid=[[1,1],[1,1]] | buildPrefixSum | prefix = [[0,0,0],[0,1,2],[0,2,4]] |
| 2    | build(0,0,2) | sumRegion -> total=4 | total == size*size -> leaf val=1 |
| 3    | return | root is leaf | Node(isLeaf=true,val=1) |

## Other Patterns

### Pattern 1

**Idea**
Recursive divide-and-check by scanning the region directly (no prefix sums).

**Pseudo Code**

```text
function constructQuadTree_naive(grid)
    return build(0, 0, length(grid), grid)

function build(r, c, size, grid)
    first := grid[r][c]
    uniform := true
    for i from r to r+size-1
        for j from c to c+size-1
            if grid[i][j] != first
                uniform := false
                break both loops
    if uniform
        return Node(isLeaf=true, val=first)
    half := size / 2
    topLeft := build(r, c, half, grid)
    topRight := build(r, c + half, half, grid)
    bottomLeft := build(r + half, c, half, grid)
    bottomRight := build(r + half, c + half, half, grid)
    return Node(isLeaf=false, val=1, topLeft=topLeft, topRight=topRight, bottomLeft=bottomLeft, bottomRight=bottomRight)
```

### Pattern 2

**Idea**
Bottom-up merge from 1x1 cells: create leaves for all cells and iteratively merge 2x2 blocks if all four children are leaves with same value.

**Pseudo Code**

```text
function constructQuadTree_bottomUp(grid)
    n := length(grid)
    create nodeGrid[n][n]
    for i from 0 to n-1
        for j from 0 to n-1
            nodeGrid[i][j] := Node(isLeaf=true, val=grid[i][j])
    size := 1
    while size < n
        for i from 0 to n-1 step size*2
            for j from 0 to n-1 step size*2
                a := nodeGrid[i][j]
                b := nodeGrid[i][j+size]
                c := nodeGrid[i+size][j]
                d := nodeGrid[i+size][j+size]
                if a.isLeaf and b.isLeaf and c.isLeaf and d.isLeaf and a.val==b.val==c.val==d.val
                    nodeGrid[i][j] := Node(isLeaf=true, val=a.val)
                else
                    nodeGrid[i][j] := Node(isLeaf=false, val=1, topLeft=a, topRight=b, bottomLeft=c, bottomRight=d)
        size := size * 2
    return nodeGrid[0][0]
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Prefix-sum + Recursion | Test region sum in O(1) and recurse | O(n^2) | O(n^2) | Yes |
| Naive Recursion | Scan region to test uniformity | O(n^2 log n) worst-case | O(n^2) | No |
| Bottom-up Merge | Build leaves then merge blocks iteratively | O(n^2) | O(n^2) | No (works but more bookkeeping) |
