# Letter Combinations of a Phone Number

## Difficulty
Medium

## Description
Given a string containing digits from 2-9 inclusive, return all possible letter combinations that the number could represent using the telephone keypad mapping. Return an empty list if input is empty.

## Examples

### Example 1
```text
Input: digits = "23"
Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
Explanation: '2' -> "abc", '3' -> "def"; combine each letter from first with each from second.
```

### Example 2
```text
Input: digits = ""
Output: []
Explanation: empty input yields no combinations.
```

## Constraints
```text
0 <= digits.length <= 10
digits[i] is a digit in the range ['2','9'].
Total combinations <= 4^n where n = digits.length.
```

---

## Idea
Use backtracking (DFS) to build combinations one digit at a time.

---

## Pseudo Code
```text
function letterCombinations(digits)
    mapping <- { '2':"abc", '3':"def", '4':"ghi", '5':"jkl", '6':"mno", '7':"pqrs", '8':"tuv", '9':"wxyz" }
    result <- empty list
    if digits is empty then return result
    function backtrack(index, path)
        if index == length(digits) then
            add join(path) to result
            return
        letters <- mapping[digits[index]]
        for each ch in letters do
            append ch to path
            backtrack(index + 1, path)
            remove last char from path
    backtrack(0, empty list)
    return result
```

---

## Complexity

| Metric           | Value                                    |
| ---------------- | ---------------------------------------- |
| Time Complexity  | O(4^n * n)                                |
| Space Complexity | O(4^n * n) (output) / O(n) (recursion)   |

---

## Code Explanation

### Dry Run

| Step | State             | Operation                      | Result              |
| ---- | ----------------- | ------------------------------ | ------------------- |
| 1    | index=0 path=""   | letters="abc" choose 'a'       | path="a"            |
| 2    | index=1 path="a"  | letters="def" choose 'd'       | path="ad" -> add    |
| 3    | backtrack         | pop to path="a" choose 'e'     | path="ae" -> add    |
| 4    | backtrack         | pop to path="a" choose 'f'     | path="af" -> add    |
| 5    | backtrack         | pop to path="" choose 'b'      | path="b" then "bd"  |
| 6    | ...               | continue for all letters       | final 9 combos      |

## Other Patterns

### Pattern 1

**Idea**
Iterative BFS using a queue to append letters level by level.

**Pseudo Code**
```text
function letterCombinationsBFS(digits)
    mapping <- same as above
    if digits is empty then return empty list
    queue <- list containing empty string
    for each digit in digits do
        letters <- mapping[digit]
        newQueue <- empty list
        for each prefix in queue do
            for each ch in letters do
                add prefix + ch to newQueue
        queue <- newQueue
    return queue
```

### Pattern 2

**Idea**
Use functional Cartesian product (reduce) to accumulate combinations.

**Pseudo Code**
```text
function letterCombinationsProduct(digits)
    mapping <- same as above
    if digits is empty then return empty list
    result <- list with empty string
    for each digit in digits do
        letters <- mapping[digit]
        result <- [ prefix + ch for each prefix in result for each ch in letters ]
    return result
```

## Comparison

| Approach     | Idea                              | Time         | Space                   | Recommended |
| ------------ | --------------------------------- | ------------ | ----------------------- | ----------- |
| Backtracking | DFS build one char per level      | O(4^n * n)   | O(4^n * n) / O(n)       | Yes         |
| BFS (Queue)  | Level-by-level iterative expansion| O(4^n * n)   | O(4^n * n)              | No (simple) |
| Product      | Functional reduce Cartesian prod  | O(4^n * n)   | O(4^n * n)              | No (concise) |
