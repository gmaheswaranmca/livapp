# Merge k Sorted Lists

## Difficulty
Hard

## Description
Merge k sorted singly-linked lists into one sorted linked list and return its head.

## Examples

### Example 1

```text
Input: [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]
Explanation: Divide lists into halves and merge recursively.
```

### Example 2

```text
Input: []
Output: []
Explanation: No lists to merge.
```

### Example 3

```text
Input: [[]]
Output: []
Explanation: Single empty list.
```

## Constraints

```text
0 <= k <= 10^4
0 <= total number of nodes (N) <= 10^5
-10^4 <= node.val <= 10^4
```

---

## Idea
Divide lists into halves and merge pairs recursively (divide and conquer).

---

## Pseudo Code

```text
function mergeKLists(lists)
    if lists is empty return null
    return mergeRange(lists, 0, length(lists)-1)

function mergeRange(lists, left, right)
    if left == right return lists[left]
    mid = left + (right - left) // 2
    l1 = mergeRange(lists, left, mid)
    l2 = mergeRange(lists, mid+1, right)
    return mergeTwoLists(l1, l2)

function mergeTwoLists(l1, l2)
    dummy = new Node(0)
    tail = dummy
    while l1 != null and l2 != null
        if l1.val <= l2.val
            tail.next = l1
            l1 = l1.next
        else
            tail.next = l2
            l2 = l2.next
        tail = tail.next
    if l1 != null tail.next = l1
    if l2 != null tail.next = l2
    return dummy.next
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(N log k) |
| Space Complexity | O(log k) (recursion) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | lists = [[1,4,5],[1,3,4],[2,6]] | mergeRange(0,2) splits into (0,1) and (2,2) | left->mergeRange(0,1), right->[2,6] |
| 2    | left side lists (0,1) | mergeRange(0,1) splits into (0,0) and (1,1) | mergeTwoLists([1,4,5],[1,3,4]) |
| 3    | mergeTwoLists result | merge [1,4,5] and [1,3,4] | [1,1,3,4,4,5] |
| 4    | merge final | merge [1,1,3,4,4,5] and [2,6] | [1,1,2,3,4,4,5,6] |

## Other Patterns

### Pattern 1

**Idea**

Use a min-heap (priority queue) containing current heads of all lists.

**Pseudo Code**

```text
function mergeKListsHeap(lists)
    heap = new MinHeap()
    for each node in lists
        if node != null heap.push(node.val, node)
    dummy = new Node(0)
    tail = dummy
    while heap is not empty
        val,node = heap.pop()
        tail.next = node
        tail = tail.next
        if node.next != null heap.push(node.next.val, node.next)
    return dummy.next
```

### Pattern 2

**Idea**

Iteratively merge lists one by one into an accumulator.

**Pseudo Code**

```text
function mergeKListsSequential(lists)
    if lists is empty return null
    result = lists[0]
    for i from 1 to length(lists)-1
        result = mergeTwoLists(result, lists[i])
    return result
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Divide & Conquer | Pairwise recursive merging | O(N log k) | O(log k) | Yes |
| Min-Heap | Maintain k heads in a heap | O(N log k) | O(k) | Yes (when k is small) |
| Sequential Merge | Merge lists one-by-one | O(kN) | O(1) | No |
