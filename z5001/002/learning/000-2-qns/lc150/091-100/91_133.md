# Clone Graph

## Difficulty
Medium

## Description
Given a reference of a node in a connected undirected graph, return a deep copy (clone) of the graph. Each node contains a value and list of its neighbors.

## Examples

### Example 1
```text
Input: adjList = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
Explanation: Node values preserved and neighbor relations identical. Graph is:
1--2
|  |
4--3
```

### Example 2
```text
Input: adjList = [[]]
Output: [[]]
Explanation: Single node with no neighbors.
```

### Example 3
```text
Input: adjList = []
Output: []
Explanation: Empty graph -> return null.
```

## Constraints
```text
Number of nodes: 0 <= n <= 100
Node values unique positive integers (commonly 1..n)
Graph is connected when n > 0
Graph is undirected, may contain cycles and self-loops
Node structure: Node { int val; List<Node> neighbors; }
```

---

## Idea
Use DFS with a hashmap mapping original node -> cloned node to avoid revisiting and to connect neighbors.

---

## Pseudo Code
```text
function cloneGraph(node)
    if node == null return null
    visited = empty map                // oldNode -> clonedNode
    return dfs(node, visited)

function dfs(node, visited)
    if node in visited return visited[node]
    clone = Node(node.val)
    visited[node] = clone
    for neighbor in node.neighbors
        clonedNeighbor = dfs(neighbor, visited)
        clone.neighbors.append(clonedNeighbor)
    return clone
```

## Complexity

| Metric           | Value        |
| ---------------- | ------------ |
| Time Complexity  | O(N + E)     |
| Space Complexity | O(N)         |

---

## Code Explanation

### Dry Run

| Step | State (visited map)               | Operation                            | Result                                  |
| ---- | --------------------------------- | ------------------------------------ | --------------------------------------- |
| 1    | {}                                | cloneGraph(1) -> create 1'           | visited = {1 -> 1'}                     |
| 2    | {1->1'}                           | dfs(2) from 1 -> create 2'           | visited = {1->1', 2->2'}                |
| 3    | {1->1',2->2'}                     | dfs(1) from 2 sees visited -> return | 2'.neighbors includes 1'                |
| 4    | {1->1',2->2'}                     | dfs(3) from 2 -> create 3'           | visited = {1->1',2->2',3->3'}           |
| 5    | ...                               | continue until all neighbors visited | cloned graph with same topology created |

1. Start DFS at input node, create cloned node and store mapping.
2. For each neighbor, recurse; if neighbor already in mapping return cloned neighbor.
3. Append returned clones to current clone's neighbor list.
4. Return clone of the starting node.

## Other Patterns

### Pattern 1

**Idea**
BFS iterative using queue with hashmap old->new.

**Pseudo Code**
```text
function cloneGraphBFS(node)
    if node == null return null
    visited = empty map
    queue = empty queue
    visited[node] = Node(node.val)
    enqueue(queue, node)
    while queue not empty
        curr = dequeue(queue)
        for neighbor in curr.neighbors
            if neighbor not in visited
                visited[neighbor] = Node(neighbor.val)
                enqueue(queue, neighbor)
            visited[curr].neighbors.append(visited[neighbor])
    return visited[node]
```

| Approach | Idea                            | Time     | Space | Recommended |

| DFS      | Recursive DFS + hashmap         | O(N+E)   | O(N)  | Yes         |
| BFS      | Iterative BFS + queue + hashmap | O(N+E)   | O(N)  | Yes         |
