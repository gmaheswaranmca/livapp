# Snakes and Ladders — Minimum Dice Throws

## Difficulty
Medium

## Description
Given an n x n board representing a Snakes and Ladders game (board[r][c] = -1 or target square), compute the minimum number of dice throws (1–6) to reach the last square starting from square 1. The board is labeled in Boustrophedon order (left-right, then right-left on the next row from bottom).

## Examples

### Example 1
```text
Input: board = [[-1,-1,-1],[-1,9,8],[-1,8,9]]
Output: 1
Explanation: From square 1, roll 2 -> square 3 which has 9 -> reach last square in 1 throw.
```

## Constraints
```text
n = board.length
1 <= n <= 20
board[i].length == n
board[i][j] == -1 or 1 <= board[i][j] <= n*n
start = 1, target = n*n
dice faces = 6
```

---

## Idea
Model squares as graph nodes and use BFS over dice outcomes, applying board redirects (snakes/ladders) when present.

---

## Pseudo Code
```text
function solve(board)
    n <- board.length
    target <- n * n
    function idxToCell(idx)    // 1-based index -> (r,c)
        rowFromBottom <- (idx - 1) // (n)
        r <- n - 1 - (idx - 1) / n    // integer division
        rowParity <- (n - 1 - r) % 2   // 0 -> left->right, 1 -> right->left
        posInRow <- (idx - 1) % n
        if rowParity == 0
            c <- posInRow
        else
            c <- n - 1 - posInRow
        return (r, c)
    visited <- array[1..target] of false
    queue <- empty queue of (square, moves)
    enqueue(queue, (1, 0))
    visited[1] <- true
    while queue not empty
        (s, moves) <- dequeue(queue)
        if s == target return moves
        for face from 1 to 6
            nextIdx <- s + face
            if nextIdx > target break
            (r, c) <- idxToCell(nextIdx)
            if board[r][c] != -1
                nextIdx <- board[r][c]
            if not visited[nextIdx]
                visited[nextIdx] <- true
                enqueue(queue, (nextIdx, moves + 1))
    return -1   // unreachable
```

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | queue=[(1,0)] visited={1} | Dequeue (1,0) | explore faces 1..6 |
| 2    | face=1 -> idx=2 -> board[2]=8 | jump to 8 | enqueue (8,1) visited add 8 |
| 3    | face=2 -> idx=3 -> board[3]=9 | jump to 9 | enqueue (9,1) visited add 9 |
| 4    | Dequeue (8,1) | not target | continue |
| 5    | Dequeue (9,1) | s==target | return 1 |

## Other Patterns

### Pattern 1

**Idea**
Bidirectional BFS from start and target over implicit graph of dice moves.

**Pseudo Code**
```text
function solve_bidirectional(board)
    n <- board.length
    target <- n*n
    startSet <- {1}
    endSet <- {target}
    visitedStart <- set{1}
    visitedEnd <- set{target}
    moves <- 0
    while startSet not empty and endSet not empty
        if size(startSet) > size(endSet) swap(startSet, endSet); swap(visitedStart, visitedEnd)
        nextSet <- empty set
        for s in startSet
            for face from 1 to 6
                nextIdx <- s + face
                if nextIdx > target break
                (r,c) <- idxToCell(nextIdx)
                if board[r][c] != -1 nextIdx <- board[r][c]
                if nextIdx in visitedEnd return moves + 1
                if nextIdx not in visitedStart
                    visitedStart.add(nextIdx)
                    nextSet.add(nextIdx)
        startSet <- nextSet
        moves <- moves + 1
    return -1
```
