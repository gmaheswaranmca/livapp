# Word Ladder

## Difficulty
Medium

## Description
Given beginWord, endWord and a wordList, find the length of the shortest transformation sequence from beginWord to endWord such that:
- Only one letter can be changed at a time.
- Each transformed word must exist in the wordList.
Return 0 if no such transformation exists. Each transformation step counts as 1 (include begin and end in count).

## Examples

### Example 1

```text
Input: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log","cog"]
Output: 5
Explanation: "hit" -> "hot" -> "dot" -> "dog" -> "cog"
```

### Example 2

```text
Input: beginWord = "hit", endWord = "cog", wordList = ["hot","dot","dog","lot","log"]
Output: 0
Explanation: endWord "cog" is not in wordList so no valid transformation.
```

## Constraints

```text
1 <= wordList.length <= 5000
1 <= beginWord.length == endWord.length <= 10
All words consist of lowercase English letters.
No duplicate words in wordList.
```

---

## Idea
Use BFS on an implicit graph built via generic intermediate states (replace one letter by '*') to find shortest path length.

---

## Pseudo Code

```text
function ladderLength(beginWord, endWord, wordList)
    if endWord not in wordList then return 0
    L := length(beginWord)
    allCombDict := empty map from string to list of string
    for each word in wordList
        for i from 0 to L-1
            key := word with char at i replaced by '*'
            append word to allCombDict[key]
    queue := empty queue
    enqueue (beginWord, 1) into queue
    visited := set containing beginWord
    while queue not empty
        (currentWord, level) := dequeue queue
        for i from 0 to L-1
            intermediate := currentWord with char at i replaced by '*'
            for each neighbor in allCombDict[intermediate]
                if neighbor == endWord then return level + 1
                if neighbor not in visited
                    add neighbor to visited
                    enqueue (neighbor, level + 1) into queue
            set allCombDict[intermediate] := empty list
    return 0
```

---

## Complexity

| Metric           | Value             |
| ---------------- | ----------------- |
| Time Complexity  | O(N * L)          |
| Space Complexity | O(N * L)          |

N = number of words in wordList, L = length of each word.

### Dry Run

| Step | Queue                        | Operation                             | Result / Notes                              |
| ---- | ---------------------------- | ------------------------------------- | ------------------------------------------- |
| 1    | ("hit",1)                    | Dequeue ("hit",1)                     | Generate "*it","h*t","hi*"                  |
| 2    |                              | For "h*t" neighbors -> ["hot"]        | Enqueue ("hot",2)                           |
| 3    | ("hot",2)                    | Dequeue ("hot",2)                     | Generate "*ot","h*t","ho*"                  |
| 4    |                              | For "*ot" neighbors -> ["hot","dot","lot"] | Enqueue ("dot",3), ("lot",3)          |
| 5    | ("dot",3),("lot",3)          | Dequeue ("dot",3)                     | For "do*" neighbors -> ["dot","dog"]        |
| 6    | ("lot",3),("dog",4)          | Enqueue ("dog",4)                     |                                           |
| 7    | ("lot",3),("dog",4)          | Dequeue ("lot",3)                     | For "lo*" neighbors -> ["lot","log"]        |
| 8    | ("dog",4),("log",4)          | Enqueue ("log",4)                     |                                           |
| 9    | ("dog",4)                    | Dequeue ("dog",4)                     | For "do*" neighbors -> finds "cog"? no     |

## Other Patterns

### Pattern 1

**Idea**
Bidirectional BFS from beginWord and endWord to meet in the middle.

**Pseudo Code**

```text
function ladderLengthBidirectional(beginWord, endWord, wordList)
    if endWord not in wordList then return 0
    L := length(beginWord)
    allCombDict := build intermediate map like previous
    beginSet := set containing beginWord
    endSet := set containing endWord
    visited := set containing beginWord and endWord
    level := 1
    while beginSet not empty and endSet not empty
        if size(beginSet) > size(endSet) then swap beginSet and endSet
        nextSet := empty set
        for word in beginSet
            for i from 0 to L-1
                intermediate := word with char at i replaced by '*'
                for neighbor in allCombDict[intermediate]
                    if neighbor in endSet then return level + 1
                    if neighbor not in visited
                        add neighbor to visited
                        add neighbor to nextSet
        beginSet := nextSet
        level := level + 1
    return 0
```

### Pattern 2

**Idea**
Build explicit adjacency by comparing every pair of words (O(N^2 * L)) and run BFS.

**Pseudo Code**

```text
function ladderLengthAdjacency(beginWord, endWord, wordList)
    add beginWord to wordList if not present
    graph := adjacency list map
    for i from 0 to N-1
        for j from i+1 to N-1
            if wordsDifferByOne(wordList[i], wordList[j]) then
                add edge both ways in graph
    return BFS shortest path length from beginWord to endWord using graph
```

## Comparison

| Approach                 | Idea                                      | Time        | Space       | Recommended |
| ------------------------ | ----------------------------------------- | ----------- | ----------- | ----------- |
| BFS with intermediate map| Use generic states "*": build map + BFS   | O(N * L)    | O(N * L)    | Yes         |
| Bidirectional BFS        | Two-way BFS meeting in middle             | O(N * L) / 2 expected | O(N * L) | Yes (for large N) |
| Full adjacency graph     | Compare all pairs and BFS                 | O(N^2 * L)  | O(N^2)      | No          |
