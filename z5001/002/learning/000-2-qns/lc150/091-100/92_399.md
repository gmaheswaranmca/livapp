# Title
Evaluate Division (Weighted graph traversal)

## Difficulty
Medium

## Description
Given equations in the form A / B = k, answer queries asking for the value of X / Y. If no relation exists return -1.0. Equations form a weighted directed graph where edge A->B has weight k and B->A has weight 1/k.

## Examples

### Example 1

```text
Input: equations = [["a","b"],["b","c"]], values = [6.0,2.0], queries = [["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]
Output: [12.0,0.16666666666666666,-1.0,1.0,-1.0]
Explanation:
a->b = 6.0, b->c = 2.0 so a->c = 6.0 * 2.0 = 12.0
b->a = 1/6.0 = 0.166...
a->e unknown => -1.0
a->a = 1.0
x unknown => -1.0
```

## Constraints

```text
n = equations.length, m = queries.length
1 <= n, m <= 1000 (practical limits depend on platform)
Variable names are non-empty strings; values are positive real numbers
```

---

## Idea
Model variables as graph nodes with weighted edges; answer each query by graph traversal accumulating multiplicative weights.

---

## Pseudo Code

```text
function solve(equations, values, queries)
    graph = build_graph(equations, values)
    results = empty list
    for each (src, dst) in queries
        append results with query_value(graph, src, dst)
    return results

function build_graph(equations, values)
    graph = map from string to list of (neighbor, weight)
    for i from 0 to len(equations)-1
        a = equations[i][0]
        b = equations[i][1]
        w = values[i]
        add (b, w) to graph[a]
        add (a, 1.0 / w) to graph[b]
    return graph

function query_value(graph, src, dst)
    if src not in graph or dst not in graph then return -1.0
    if src == dst then return 1.0
    visited = empty set
    stack = stack of (src, 1.0)
    while stack not empty
        (node, prod) = pop stack
        if node == dst then return prod
        add node to visited
        for each (nei, w) in graph[node]
            if nei not in visited
                push (nei, prod * w) onto stack
    return -1.0
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(q * (V + E)) where V is distinct variables and E = 2n |
| Space Complexity | O(V + E) |

## Code Explanation

1. Build adjacency list: for each equation A/B = k add A->B weight k and B->A weight 1/k.
2. For each query, handle edge cases: missing node -> -1.0, same node -> 1.0.
3. Use iterative DFS/BFS to find a path from src to dst while accumulating product; mark visited to avoid cycles.
4. Return the accumulated product when dst is reached, otherwise -1.0.

### Dry Run

| Step | State                     | Operation                               | Result        |
| ---- | ------------------------- | ----------------------------------------| ------------- |
| 1    | graph                     | build from [["a","b"],["b","c"]],[6,2]   | a->(b,6), b->(a,1/6),(c,2), c->(b,1/2) |
| 2    | query ("a","c")           | stack = [(a,1.0)]                        | visited = {}  |
| 3    | pop (a,1.0)               | explore neighbors -> push (b,6.0)        | stack = [(b,6.0)] |
| 4    | pop (b,6.0)               | neighbor c with w=2 -> prod = 12.0      | return 12.0   |

## Other Patterns

### Pattern 1

**Idea**
Union-Find with multiplicative weights to maintain ratio between node and its parent.

**Pseudo Code**

```text
function solve(equations, values, queries)
    uf = init_union_find()
    for i from 0 to len(equations)-1
        union(uf, equations[i][0], equations[i][1], values[i])
    results = empty list
    for each (x, y) in queries
        if find_root(uf, x) != find_root(uf, y) or x not in uf or y not in uf
            append -1.0
        else
            append weight(x) / weight(y)
    return results

function init_union_find()
    parent = map
    weight = map  // weight[node] = node / parent[node]
    return (parent, weight)

function find_root(uf, x)
    if x not in parent
        parent[x] = x
        weight[x] = 1.0
        return x
    if parent[x] != x
        orig = parent[x]
        root = find_root(uf, orig)
        weight[x] = weight[x] * weight[orig]
        parent[x] = root
    return parent[x]

function union(uf, x, y, value)  // x / y = value
    rx = find_root(uf, x)
    ry = find_root(uf, y)
    if rx == ry then return
    parent[rx] = ry
    weight[rx] = (value * weight[y]) / weight[x]
```

### Pattern 2

**Idea**
Floyd-Warshall: compute all-pairs ratios by initializing adjacency matrix and running transitive multiplicative closure.

**Pseudo Code**

```text
function solve(equations, values, queries)
    map variable to index
    n = count of variables
    mat = n x n matrix initialized with -1.0
    for i in 0..n-1
        mat[i][i] = 1.0
    for each equation A/B = v
        mat[idx(A)][idx(B)] = v
        mat[idx(B)][idx(A)] = 1.0 / v
    for k in 0..n-1
        for i in 0..n-1
            for j in 0..n-1
                if mat[i][k] > 0 and mat[k][j] > 0
                    mat[i][j] = mat[i][k] * mat[k][j]
    answer queries by lookup mat[idx(x)][idx(y)] or -1.0
```
