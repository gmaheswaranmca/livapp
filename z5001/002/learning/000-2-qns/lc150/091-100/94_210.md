# Course Schedule II

## Difficulty
Medium

## Description
Given numCourses and a list of prerequisite pairs [a, b] meaning to take course a you must first take course b, return a valid order of courses or an empty array if no valid order exists.

## Examples

### Example 1

```text
Input: numCourses = 2, prerequisites = [[1,0]]
Output: [0,1]
Explanation: To take course 1 you must first take course 0. One valid order is [0,1].
```

## Constraints

```text
1 <= numCourses <= 10^5
0 <= prerequisites.length <= 10^5
prerequisites[i].length == 2
0 <= ai, bi < numCourses
No duplicate prerequisite pairs assumed but algorithm tolerates them.
```

---

## Idea
Perform a topological sort (Kahn's algorithm) using indegree and a queue to produce a valid course ordering or detect a cycle.

---

## Pseudo Code

```text
function findCourseOrder(numCourses, prerequisites)
    create adj list of size numCourses
    create indegree array of size numCourses filled with 0
    for each pair [course, pre] in prerequisites
        append course to adj[pre]
        indegree[course] = indegree[course] + 1
    create queue
    for i from 0 to numCourses-1
        if indegree[i] == 0
            enqueue i
    create result list empty
    while queue is not empty
        node = dequeue
        append node to result
        for each neighbor in adj[node]
            indegree[neighbor] = indegree[neighbor] - 1
            if indegree[neighbor] == 0
                enqueue neighbor
    if length of result == numCourses
        return result
    else
        return empty list
```

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(V + E)    |
| Space Complexity | O(V + E)    |

## Code Explanation

### Dry Run

| Step | State (indegree, queue, result) | Operation | Result |
| ---- | -------------------------------- | --------- | ------ |
| 1    | indegree=[0,1], queue=[0], result=[] | dequeue 0 | result=[0] |
| 2    | adj[0]=[1], indegree -> [0,0], queue becomes [1] | dequeue 1 | result=[0,1] |
| 3    | queue empty, len(result)=2 == numCourses | finish | return [0,1] |

## Other Patterns

### Pattern 1

**Idea**
DFS with 3-color cycle detection and postorder stack to build topological order.

**Pseudo Code**

```text
function findCourseOrderDFS(numCourses, prerequisites)
    create adj list of size numCourses
    for each pair [course, pre] in prerequisites
        append course to adj[pre]
    create state array of size numCourses filled with 0  # 0=unvisited,1=visiting,2=visited
    create stack empty
    function dfs(node) -> boolean
        if state[node] == 1 return false
        if state[node] == 2 return true
        state[node] = 1
        for each nei in adj[node]
            if not dfs(nei) return false
        state[node] = 2
        push node onto stack
        return true
    for i from 0 to numCourses-1
        if state[i] == 0
            if not dfs(i) return empty list
    return reverse(stack)
```
