# Word Search II (LeetCode 212)

## Difficulty
Hard

## Description
Given an m x n board of characters and a list of words, return all words that can be formed by sequentially adjacent cells (horizontally or vertically). The same letter cell may not be used more than once in a single word. Words must be matched exactly.

## Examples

### Example 1

```text
Input: board = [
  ["o","a","a","n"],
  ["e","t","a","e"],
  ["i","h","k","r"],
  ["i","f","l","v"]
], words = ["oath","pea","eat","rain"]
Output: ["oath","eat"]
Explanation: "oath" and "eat" can be formed; "pea" and "rain" cannot.
```

### Example 2

```text
Input: board = [["a","b"],["c","d"]], words = ["abcb"]
Output: []
Explanation: "abcb" requires reusing a cell.
```

## Constraints

```text
1 <= board.length, board[i].length <= 12
1 <= words.length <= 3 * 10^4
1 <= words[i].length <= 10
board[i][j] and words[i] consist of lowercase English letters.
```

---

## Idea
Use a Trie of the words and backtracking DFS from each board cell to find matching word paths while pruning visited paths and removing found words from the Trie.

---

## Pseudo Code

```text
function buildTrie(words)
    root = newTrieNode()
    for word in words
        node = root
        for ch in word
            if node.children[ch] == null
                node.children[ch] = newTrieNode()
            node = node.children[ch]
        node.isWord = true
        node.word = word
    return root

function dfs(board, i, j, node, result)
    if i < 0 or i >= rows or j < 0 or j >= cols
        return
    ch = board[i][j]
    if ch == '#' or node.children[ch] == null
        return
    node = node.children[ch]
    if node.isWord
        result.add(node.word)
        node.isWord = false
        // optional: remove leaf nodes to prune Trie
    board[i][j] = '#'
    for (di,dj) in [(1,0),(-1,0),(0,1),(0,-1)]
        dfs(board, i+di, j+dj, node, result)
    board[i][j] = ch
    // optional: prune child if empty to shrink trie

function findWords(board, words)
    if board is empty or words is empty
        return []
    root = buildTrie(words)
    rows = board.length
    cols = board[0].length
    result = empty set or list
    for i from 0 to rows-1
        for j from 0 to cols-1
            dfs(board, i, j, root, result)
    return list(result)
```

---

## Complexity

| Metric           | Value                                   |
| ---------------- | --------------------------------------- |
| Time Complexity  | O(m * n * 4^L + S) where L = max word length, m*n = board cells, S = sum of word lengths (trie build) |
| Space Complexity | O(S + L) where S = sum of word lengths (Trie) and L = recursion depth |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | words = ["oath","pea","eat","rain"] | buildTrie(words) | Trie containing all words with terminal nodes storing words |
| 2    | start at (0,0) = 'o' | dfs sees 'o' in trie | go to neighbors for path "o" |
| 3    | path "o" -> "oa" -> "oat" -> "oath" | node.isWord hits true | add "oath" to result, mark node.isWord=false to avoid duplicates |
| 4    | continue other starts e.g. (1,2) 'a' | dfs finds "eat" path | add "eat" to result |
| 5    | all starts exhausted | return result set | ["oath","eat"] |

## Other Patterns

### Pattern 1

**Idea**
Brute-force DFS for each word checking existence on board.

**Pseudo Code**

```text
function exists(board, word)
    for each cell (i,j)
        if board[i][j] == word[0]
            if dfsCheck(board, i, j, word, 0)
                return true
    return false

function dfsCheck(board, i, j, word, idx)
    if idx == word.length
        return true
    if i<0 or i>=rows or j<0 or j>=cols or board[i][j] != word[idx]
        return false
    ch = board[i][j]
    board[i][j] = '#'
    for (di,dj) in [(1,0),(-1,0),(0,1),(0,-1)]
        if dfsCheck(board, i+di, j+dj, word, idx+1)
            board[i][j] = ch
            return true
    board[i][j] = ch
    return false

function findWords(board, words)
    result = []
    for word in words
        if exists(board, word)
            result.add(word)
    return result
```

### Pattern 2

**Idea**
Use prefix-hashset for pruning: store all prefixes of words; during DFS stop when current prefix not in set.

**Pseudo Code**

```text
function buildPrefixSet(words)
    prefixes = empty set
    for word in words
        for k from 1 to word.length
            prefixes.add(word[0:k])
    return prefixes

function findWordsWithPrefixes(board, words)
    prefixes = buildPrefixSet(words)
    wordSet = set(words)
    result = empty set
    for each cell
        dfsPrefix(board, i, j, "", prefixes, wordSet, result)
    return list(result)

function dfsPrefix(board, i, j, cur, prefixes, wordSet, result)
    if out of bounds or board[i][j]=='#'
        return
    cur2 = cur + board[i][j]
    if cur2 not in prefixes and cur2 not in wordSet
        return
    if cur2 in wordSet
        result.add(cur2)
    mark visited and continue four directions
    restore visited
```

## Comparison

| Approach       | Idea                                      | Time                          | Space                | Recommended |
| -------------- | ----------------------------------------- | ----------------------------- | -------------------- | ----------- |
| Trie + DFS     | Build trie & backtrack from each cell     | O(m*n*4^L + S)                | O(S + L)             | Yes         |
| Brute Force    | For each word run DFS                      | O(W * m * n * 4^L)            | O(L) per DFS         | No          |
| Prefix Set     | Prune DFS using prefix hash set           | O(m*n*4^L + S) (less pruning) | O(S + L)             | Maybe       |
