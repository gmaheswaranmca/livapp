# Course Schedule

## Difficulty
Medium

## Description
Given numCourses and a list of prerequisite pairs [a, b] meaning b -> a, determine if it is possible to finish all courses (i.e., check that the directed graph has no cycle).

## Examples

### Example 1

```text
Input: numCourses = 2, prerequisites = [[1,0]]
Output: true
Explanation: Edge 0 -> 1, no cycle, all courses can be finished.
```

### Example 2

```text
Input: numCourses = 2, prerequisites = [[1,0],[0,1]]
Output: false
Explanation: Edges 0->1 and 1->0 form a cycle.
```

## Constraints

```text
1 <= numCourses <= 10^5
0 <= prerequisites.length <= 10^5
prerequisites[i].length == 2
0 <= prerequisites[i][0], prerequisites[i][1] < numCourses
Graph may be disconnected
```

---

## Idea
Detect a cycle in the directed graph using DFS with 3-state marking (unvisited, visiting, visited).

---

## Pseudo Code

```text
function canFinish(numCourses, prerequisites)
    create adj list of size numCourses with empty lists
    for each pair [a,b] in prerequisites
        append a to adj[b]
    create state array of size numCourses initialized to 0   # 0=unvisited,1=visiting,2=visited
    for node from 0 to numCourses-1
        if state[node] == 0
            if hasCycleDFS(node, adj, state) == true
                return false
    return true

function hasCycleDFS(node, adj, state)
    if state[node] == 1
        return true
    if state[node] == 2
        return false
    state[node] = 1
    for each neighbor in adj[node]
        if hasCycleDFS(neighbor, adj, state) == true
            return true
    state[node] = 2
    return false
```

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | Build graph | prerequisites = [[1,0]] | adj: 0 -> [1], 1 -> [] |
| 2    | Start DFS at 0 | state[0]=0 -> call hasCycleDFS(0) | state[0]=1 (visiting) |
| 3    | Visit neighbor | neighbor=1 -> call hasCycleDFS(1) | state[1]=1 (visiting) |
| 4    | Backtrack from 1 | no neighbors -> state[1]=2 (visited) | return false |
| 5    | Backtrack from 0 | finished neighbors -> state[0]=2 (visited) | return false |
| 6    | All nodes processed | no cycle found | canFinish returns true |

## Other Patterns

### Pattern 1

**Idea**
Kahn's algorithm (BFS topological sort) to check if all nodes can be ordered.

**Pseudo Code**

```text
function canFinishKahn(numCourses, prerequisites)
    create adj list of size numCourses with empty lists
    create indegree array of size numCourses initialized to 0
    for each pair [a,b] in prerequisites
        append a to adj[b]
        indegree[a] = indegree[a] + 1
    create queue
    for node from 0 to numCourses-1
        if indegree[node] == 0
            enqueue node
    count = 0
    while queue not empty
        node = dequeue
        count = count + 1
        for each neighbor in adj[node]
            indegree[neighbor] = indegree[neighbor] - 1
            if indegree[neighbor] == 0
                enqueue neighbor
    return count == numCourses
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| DFS (3-state) | Detect back-edge using recursion and 3-state marking | O(V+E) | O(V+E) | Yes |
| Kahn's BFS | Use indegrees and remove nodes with indegree 0 iteratively | O(V+E) | O(V+E) | Yes (use when recursion depth is a concern) |
