# Minimum Genetic Mutation

## Difficulty
Medium

## Description
Given a start gene string, an end gene string, and a bank of valid gene strings, return the minimum number of single-character mutations needed to convert start to end. Each mutation must change exactly one character and result must be in the bank. Return -1 if transformation is impossible.

## Examples

### Example 1

```text
Input: start="AACCGGTT", end="AACCGGTA", bank=["AACCGGTA"]
Output: 1
Explanation: AACCGGTT -> AACCGGTA
```

### Example 2

```text
Input: start="AACCGGTT", end="AAACGGTA", bank=["AACCGGTA","AACCGCTA","AAACGGTA"]
Output: 2
Explanation: AACCGGTT -> AACCGGTA -> AAACGGTA
```

### Example 3

```text
Input: start="AAAAACCC", end="CCCCCCCC", bank=["AAAACCCA"]
Output: -1
Explanation: No valid path to end.
```

## Constraints

```text
All strings length L = 8 (gene length fixed).
Characters are from {A,C,G,T}.
1 <= bank.length <= 10^3.
start and end are non-empty.
Bank may contain duplicates; treat as set.
```

---

## Idea
Use BFS on the graph of valid gene strings where edges connect strings that differ by one character; each BFS level is one mutation.

---

## Pseudo Code

```text
function minMutation(start, end, bank)
    if end not in bank then return -1
    bankSet <- set(bank)
    genes <- ['A','C','G','T']
    queue <- empty queue
    enqueue(queue, (start, 0))
    visited <- set(start)
    while queue not empty
        (cur, steps) <- dequeue(queue)
        if cur == end then return steps
        for i from 0 to length(cur)-1
            for g in genes
                if g == cur[i] then continue
                nextStr <- cur with char at i replaced by g
                if nextStr in bankSet and nextStr not in visited
                    add nextStr to visited
                    enqueue(queue, (nextStr, steps+1))
    return -1
```

---

## Complexity

| Metric           | Value      |
| ---------------- | ---------- |
| Time Complexity  | O(n * L * 4) => O(n * L) |
| Space Complexity | O(n * L)   |

n = number of strings in bank, L = gene length (8), 4 = alphabet size.

---

## Code Explanation

### Dry Run

| Step | State                         | Operation                                  | Result                   |
| ---- | ----------------------------- | ------------------------------------------ | ------------------------ |
| 1    | queue=[(AACCGGTT,0)]          | Dequeue (AACCGGTT,0)                       | cur=AACCGGTT,steps=0     |
| 2    | generate neighbors            | mutate last char to 'A' -> AACCGGTA in bank| enqueue (AACCGGTA,1)     |
| 3    | queue=[(AACCGGTA,1)]          | Dequeue (AACCGGTA,1)                       | cur==end -> return 1     |

1. Use queue for BFS levels; visited avoids cycles.
2. Mutate each position to all 3 other gene chars.
3. Stop when end is dequeued and return current level (mutations).

## Other Patterns

### Pattern 1

**Idea**
Bidirectional BFS from start and end to meet in middle and reduce search.

**Pseudo Code**

```text
function minMutationBidirectional(start, end, bank)
    if end not in bank then return -1
    bankSet <- set(bank)
    front <- set(start)
    back <- set(end)
    visited <- set(start, end)
    genes <- ['A','C','G','T']
    steps <- 0
    while front not empty and back not empty
        if size(front) > size(back) then swap(front, back)
        nextFront <- empty set
        for cur in front
            for i from 0 to length(cur)-1
                for g in genes
                    if g == cur[i] then continue
                    nextStr <- cur with char at i replaced by g
                    if nextStr in back then return steps+1
                    if nextStr in bankSet and nextStr not in visited
                        add nextStr to visited
                        add nextStr to nextFront
        front <- nextFront
        steps <- steps+1
    return -1
```

### Pattern 2

**Idea**
DFS/backtracking enumerating valid transformations and track minimum depth (not recommended due to depth and repeated work).

**Pseudo Code**

```text
function minMutationDFS(start, end, bank)
    bankSet <- set(bank)
    if end not in bankSet then return -1
    best <- INF
    visited <- set()
    function dfs(cur, steps)
        if steps >= best then return
        if cur == end then best <- min(best, steps); return
        for i from 0 to length(cur)-1
            for g in ['A','C','G','T']
                if g == cur[i] then continue
                nextStr <- cur with char at i replaced by g
                if nextStr in bankSet and nextStr not in visited
                    add nextStr to visited
                    dfs(nextStr, steps+1)
                    remove nextStr from visited
    add start to visited
    dfs(start, 0)
    return -1 if best == INF else best
```

### Pattern 3

**Idea**
Precompute adjacency via wildcard patterns (e.g., A*C*G*T) to build graph then BFS on graph.

**Pseudo Code**

```text
function minMutationWithPatterns(start, end, bank)
    allGenes <- unique list(bank plus start)
    patternMap <- map from pattern to list
    for s in allGenes
        for i from 0 to length(s)-1
            pattern <- s with i-th char replaced by '*'
            append s to patternMap[pattern]
    build adjacency list using patternMap
    return BFS_on_graph(start, end, adjacency)
```

## Comparison

| Approach            | Idea                                 | Time             | Space        | Recommended |
| ------------------- | ------------------------------------ | ---------------- | ------------ | ----------- |
| BFS                 | Level-order search on valid mutations| O(n * L)         | O(n * L)     | Yes         |
| Bidirectional BFS   | Search from both ends                | O(n * L) (lower constant) | O(n * L) | Yes (when bank large) |
| DFS (Backtracking)  | Explore all paths                     | Potentially exponential; worst O(4^L) or O(n * L) with pruning | O(n) | No          |
| Pattern adjacency   | Precompute wildcard neighbors         | O(n * L)         | O(n * L)     | Sometimes   |
