# Implement Trie (Prefix Tree)

## Difficulty
Easy

## Description
Design a trie (prefix tree) that supports insert(word), search(word) and startsWith(prefix). Implement insert to add a word, search to check if the exact word exists, and startsWith to check if any inserted word begins with the given prefix.

## Examples

### Example 1

```text
Input:
operations = ["Trie","insert","search","search","startsWith","insert","search"]
arguments  = [[],["apple"],["apple"],["app"],["app"],["app"],["app"]]

Output:
[null,null,true,false,true,null,true]

Explanation:
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // returns true
trie.search("app");     // returns false
trie.startsWith("app"); // returns true
trie.insert("app");
trie.search("app");     // returns true
```

## Constraints

```text
1 <= total number of calls <= 3*10^4
1 <= length of word/prefix <= 2000
Words consist of lowercase English letters (a-z)
Memory limited by number of inserted characters
```

---

## Idea
Use a tree of nodes where each node maps a character to a child node and stores a boolean flag marking the end of a word.

---

## Pseudo Code

```text
class TrieNode
    children := empty map<char, TrieNode>
    isEnd := false

class Trie
    root := new TrieNode()

    function insert(word)
        node := root
        for each ch in word
            if ch not in node.children
                node.children[ch] := new TrieNode()
            node := node.children[ch]
        node.isEnd := true

    function search(word)
        node := root
        for each ch in word
            if ch not in node.children
                return false
            node := node.children[ch]
        return node.isEnd

    function startsWith(prefix)
        node := root
        for each ch in prefix
            if ch not in node.children
                return false
            node := node.children[ch]
        return true
```

---

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(L) per operation, where L = length of word/prefix |
| Space Complexity | O(N * L) worst-case for storing N words of average length L |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | root children = {} | insert("apple") process 'a' | create node for 'a' |
| 2    | a -> {}            | continue 'p','p','l','e'     | create nodes for p,p,l,e |
| 3    | e.isEnd = false    | mark end                      | e.isEnd = true |
| 4    | trie populated     | search("apple") traverse a->p->p->l->e | found node with isEnd = true => return true |
| 5    | same trie          | search("app") traverse a->p->p | node.isEnd = false => return false |
| 6    | same trie          | startsWith("app") traverse a->p->p | traversal succeeds => return true |

## Other Patterns

### Pattern 1

**Idea**
Use fixed-size array[26] per node for lowercase letters for O(1) child access.

**Pseudo Code**

```text
class TrieNode
    children := array[26] of TrieNode initialized to null
    isEnd := false

class Trie
    root := new TrieNode()

    function insert(word)
        node := root
        for each ch in word
            idx := ch - 'a'
            if node.children[idx] == null
                node.children[idx] := new TrieNode()
            node := node.children[idx]
        node.isEnd := true

    function search(word)
        node := root
        for each ch in word
            idx := ch - 'a'
            if node.children[idx] == null
                return false
            node := node.children[idx]
        return node.isEnd

    function startsWith(prefix)
        node := root
        for each ch in prefix
            idx := ch - 'a'
            if node.children[idx] == null
                return false
            node := node.children[idx]
        return true
```

### Pattern 3

**Idea**
Use a compressed trie (radix tree) to reduce memory by storing edge strings instead of single chars.

**Pseudo Code**

```text
class RadixNode
    edges := list of (string label, RadixNode child)
    isEnd := false

class RadixTrie
    root := new RadixNode()

    function insert(word)
        node := root
        while word not empty
            find edge with commonPrefix between word and edge.label
            if no commonPrefix
                append new edge (word, new RadixNode with isEnd=true)
                return
            if commonPrefix == edge.label
                node := edge.child
                word := word.substring(commonPrefix.length)
                continue
            split edge into commonPrefix node and leftover node
            if leftover word empty
                mark new node.isEnd := true
                return
            create new child edge for remaining word and mark end
            return

    function search(word)
        node := root
        while word not empty
            find edge whose label is prefix of word
            if none return false
            word := word.substring(edge.label.length)
            node := edge.child
        return node.isEnd

    function startsWith(prefix)
        node := root
        while prefix not empty
            find edge with commonPrefix between prefix and edge.label
            if no commonPrefix return false
            if commonPrefix.length < prefix.length and commonPrefix != edge.label return false
            if commonPrefix == edge.label
                prefix := prefix.substring(commonPrefix.length)
                node := edge.child
                continue
            return true
        return true
```

## Comparison

| Approach        | Idea                                | Time               | Space               | Recommended |
| --------------- | ----------------------------------- | ------------------ | ------------------- | ----------- |
| HashMap trie    | Map per node (flexible charset)     | O(L) per op        | O(N*L)              | Yes         |
| Array[26] trie  | Fixed array for lowercase letters   | O(L) per op (faster constants) | O(26 * nodes)       | Yes (when charset small) |
| Radix tree      | Compress edges to save memory       | O(L) amortized, substring ops | Lower for common prefixes | No (complex) |
