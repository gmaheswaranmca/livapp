# Design Add and Search Words Data Structure

## Difficulty
Medium

## Description
Implement a data structure that supports adding new words and searching for words where '.' can match any single letter.

## Examples

### Example 1
```text
Input:
addWord("bad")
search(".ad")
Output:
true
Explanation:
'.' matches 'b' so ".ad" matches "bad".
```

### Example 2
```text
Input:
addWord("dad")
addWord("mad")
search("pad")
search("b..")
Output:
false
true
Explanation:
"pad" not added. "b.." matches any 3-letter word starting with 'b' (if present).
```

## Constraints
```text
1 <= word.length <= 500
word consists of lowercase letters or '.'
Total calls to addWord and search <= 3 * 10^4
```

---

## Idea
Use a Trie for stored words and DFS/backtracking when encountering '.' during search.

---

## Pseudo Code
```text
class TrieNode
    children = map<char, TrieNode>
    isWord = false

class WordDictionary
    root = new TrieNode()

    function addWord(word)
        node = root
        for each ch in word
            if ch not in node.children
                node.children[ch] = new TrieNode()
            node = node.children[ch]
        node.isWord = true

    function search(word)
        return dfs(root, word, 0)

    function dfs(node, word, index)
        if node is null
            return false
        if index == length(word)
            return node.isWord
        ch = word[index]
        if ch != '.'
            if ch in node.children
                return dfs(node.children[ch], word, index + 1)
            else
                return false
        else
            for each child in node.children.values()
                if dfs(child, word, index + 1)
                    return true
            return false
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | addWord: O(L), search: O(26^L) worst-case (L = word length) |
| Space Complexity | O(N * L) (total trie nodes for N words) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | root empty | addWord("bad") | create nodes b->a->d, mark d.isWord = true |
| 2    | trie contains "bad" | addWord("dad") | create node d->a->d, mark d.isWord = true |
| 3    | search(".ad") at index 0 | '.' so iterate children {b,d} | try child 'b' then dfs at index1 |
| 4    | node at 'b' index1 | ch='a' found | move to 'a' then 'd' and index3 -> node.isWord true -> return true |

## Other Patterns

### Pattern 1
**Idea**
Brute-force list of words and match each with pattern allowing '.'.

**Pseudo Code**
```text
class WordDictionaryBrute
    words = list()

    function addWord(word)
        words.append(word)

    function search(word)
        for each w in words
            if length(w) != length(word)
                continue
            match = true
            for i from 0 to length(word)-1
                if word[i] != '.' and word[i] != w[i]
                    match = false
                    break
            if match
                return true
        return false
```

### Pattern 2
**Idea**
Bucket words by length in hashmap, then compare only within same length.

**Pseudo Code**
```text
class WordDictionaryByLength
    buckets = map<int, list<string>>()

    function addWord(word)
        buckets[length(word)].append(word)

    function search(word)
        list = buckets.get(length(word), empty)
        for each w in list
            match = true
            for i from 0 to length(word)-1
                if word[i] != '.' and word[i] != w[i]
                    match = false
                    break
            if match
                return true
        return false
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Trie + DFS | Trie with backtracking for '.' | add O(L), search worst O(26^L) | O(N * L) | Yes |
| Brute-force | Store list and check all | search O(M * L) (M = number of words) | O(M * L) | No |
| Buckets by length | Only check same-length words | search O(K * L) (K words same length) | O(M * L) | Yes (if many lengths vary)
