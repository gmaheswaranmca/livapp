# Merge Sorted Array

## Difficulty
Easy

## Description
Merge two sorted integer arrays nums1 and nums2 into nums1 as one sorted array. nums1 has a size of m + n, where the last n elements are set to 0 and should be ignored. Modify nums1 in-place.

## Examples

### Example 1
```text
Input: nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
Output: [1,2,2,3,5,6]
Explanation: Merge nums2 into nums1 to become a single sorted array.
```

### Example 2
```text
Input: nums1 = [0], m = 0, nums2 = [1], n = 1
Output: [1]
Explanation: nums1 is empty (m=0), result is nums2.
```

## Constraints
```text
nums1.length == m + n
nums2.length == n
0 <= m, n <= 10^5
-10^9 <= nums1[i], nums2[i] <= 10^9
nums1 and nums2 are sorted in non-decreasing order
```

---

## Idea
Use three pointers starting from the end to fill nums1 in-place, choosing the larger tail element each step.

---

## Pseudo Code
```text
function mergeSortedArrays(nums1, m, nums2, n)
    i = m - 1
    j = n - 1
    k = m + n - 1
    while i >= 0 and j >= 0
        if nums1[i] > nums2[j]
            nums1[k] = nums1[i]
            i = i - 1
        else
            nums1[k] = nums2[j]
            j = j - 1
        k = k - 1
    while j >= 0
        nums1[k] = nums2[j]
        j = j - 1
        k = k - 1
    return nums1
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m + n) |
| Space Complexity | O(1)    |

## Code Explanation

### Dry Run

| Step | State (nums1,m,i,k)             | State (nums2,n,j) | Operation            | Result (nums1)         |
| ---- | ------------------------------- | ----------------- | -------------------- | ---------------------- |
| 1    | [1,2,3,0,0,0], m=3, i=2, k=5    | [2,5,6], n=3, j=2 | compare 3 and 6      | place 6 at k -> [1,2,3,0,0,6] |
| 2    | i=2, k=4                        | j=1               | compare 3 and 5      | place 5 -> [1,2,3,0,5,6] |
| 3    | i=2, k=3                        | j=0               | compare 3 and 2      | place 3 -> [1,2,3,3,5,6] |
| 4    | i=1, k=2                        | j=0               | compare 2 and 2      | place 2 (from nums2) -> [1,2,2,3,5,6] |
| 5    | i=1, k=1                        | j=-1              | nums2 exhausted      | done                   |

## Other Patterns

### Pattern 1
**Idea**
Merge into a new array by two-pointer forward traversal then copy back.

**Pseudo Code**
```text
function mergeWithExtraArray(nums1, m, nums2, n)
    i = 0
    j = 0
    res = new array of size m + n
    k = 0
    while i < m and j < n
        if nums1[i] <= nums2[j]
            res[k] = nums1[i]
            i = i + 1
        else
            res[k] = nums2[j]
            j = j + 1
        k = k + 1
    while i < m
        res[k] = nums1[i]
        i = i + 1
        k = k + 1
    while j < n
        res[k] = nums2[j]
        j = j + 1
        k = k + 1
    copy res into nums1
    return nums1
```

### Pattern 2
**Idea**
Append nums2 into nums1 tail and sort (simple but not optimal).

**Pseudo Code**
```text
function mergeByAppendAndSort(nums1, m, nums2, n)
    for t from 0 to n-1
        nums1[m + t] = nums2[t]
    sort nums1
    return nums1
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Three-pointer (in-place) | Fill from end using three pointers | O(m + n) | O(1) | Yes |
| Extra array merge | Merge into new array then copy | O(m + n) | O(m + n) | No (higher space) |
| Append and sort | Append nums2 then sort whole array | O((m+n) log(m+n)) | O(1) or O(m+n) depending on sort | No (slower) |
