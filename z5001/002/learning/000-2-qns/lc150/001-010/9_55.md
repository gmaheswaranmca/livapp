# Jump Game

## Difficulty
Medium

## Description
Given an array nums where each element indicates the maximum jump length from that position, determine if you can reach the last index starting from the first index.

## Examples

### Example 1

```text
Input: [2,3,1,1,4]
Output: true
Explanation: Jump 1 step from index 0 to 1, then 3 steps to the last index.
```

### Example 2

```text
Input: [3,2,1,0,4]
Output: false
Explanation: Stuck at index 3 because nums[3] == 0 and cannot reach the last index.
```

## Constraints

```text
1 <= nums.length <= 10^5
0 <= nums[i] <= 10^5
Expected average time: O(n)
```

---

## Idea
Track the farthest reachable index while iterating and fail early if current index exceeds it.

---

## Pseudo Code

```text
function canJump(nums)
    n = length(nums)
    if n == 0 then return false
    maxReach = 0
    for i from 0 to n - 1 do
        if i > maxReach then return false
        maxReach = max(maxReach, i + nums[i])
        if maxReach >= n - 1 then return true
    return false
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | i | nums[i] | maxReach before | Operation | maxReach after | Outcome |
| ---- | -:| -------:| ---------------:| --------- | --------------:| ------- |
| 1    | 0 | 2       | 0                | maxReach = max(0,0+2) | 2 | continue |
| 2    | 1 | 3       | 2                | maxReach = max(2,1+3) | 4 | maxReach >= last -> return true |

## Other Patterns

### Pattern 1

**Idea**
Dynamic programming from end marking "good" indices.

**Pseudo Code**

```text
function canJumpDP(nums)
    n = length(nums)
    good = array of false of size n
    good[n-1] = true
    for i from n - 2 down to 0 do
        limit = min(n - 1, i + nums[i])
        for j from i + 1 to limit do
            if good[j] then
                good[i] = true
                break
    return good[0]
```

### Pattern 2

**Idea**
Breadth-first or level-order exploration of reachable indices with visited set.

**Pseudo Code**

```text
function canJumpBFS(nums)
    n = length(nums)
    queue = new queue
    visited = new boolean array of size n
    enqueue 0
    visited[0] = true
    while queue not empty do
        i = dequeue
        if i == n - 1 then return true
        for j from i + 1 to min(n - 1, i + nums[i]) do
            if not visited[j] then
                enqueue j
                visited[j] = true
    return false
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Greedy   | Track farthest reachable index | O(n) | O(1) | Yes |
| DP       | Mark good indices backward | O(n^2) worst-case | O(n) | No |
| BFS      | Explore reachable indices with queue | O(n^2) worst-case | O(n) | No |
