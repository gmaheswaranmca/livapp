# Rotate Array

## Difficulty
Easy

## Description
Given an array nums, rotate the array to the right by k steps, where k is non-negative. Modify the array in-place.

## Examples

### Example 1

```text
Input: nums = [1,2,3,4,5,6,7], k = 3
Output: [5,6,7,1,2,3,4]
Explanation: Rotate right by 3.
```

### Example 2

```text
Input: nums = [-1,-100,3,99], k = 2
Output: [3,99,-1,-100]
Explanation: Rotate right by 2.
```

## Constraints

```text
1 <= nums.length <= 10^5
nums[i] is integer
0 <= k
In-place modification required (if specified)
```

---

## Idea
Reverse entire array, then reverse first k elements, then reverse remaining n-k elements.

---

## Pseudo Code

```text
function rotate(nums, k)
    n = length(nums)
    if n == 0 then return
    k = k mod n
    if k == 0 then return
    reverse(nums, 0, n-1)
    reverse(nums, 0, k-1)
    reverse(nums, k, n-1)

function reverse(arr, left, right)
    while left < right
        swap arr[left] and arr[right]
        left = left + 1
        right = right - 1
```

## Other Patterns

### Pattern 1

**Idea**

Use an extra array to place elements at their rotated positions then copy back.

**Pseudo Code**

```text
function rotate_extra(nums, k)
    n = length(nums)
    if n == 0 then return
    k = k mod n
    if k == 0 then return
    result = new array of size n
    for i from 0 to n-1
        result[(i + k) mod n] = nums[i]
    for i from 0 to n-1
        nums[i] = result[i]
```

### Pattern 2

**Idea**

Perform cyclic replacements using gcd-based cycles to rotate in-place without reversals.

**Pseudo Code**

```text
function rotate_cyclic(nums, k)
    n = length(nums)
    if n == 0 then return
    k = k mod n
    if k == 0 then return
    count = 0
    start = 0
    while count < n
        current = start
        prev = nums[start]
        repeat
            next = (current + k) mod n
            temp = nums[next]
            nums[next] = prev
            prev = temp
            current = next
            count = count + 1
        until current == start
        start = start + 1
```

## Comparison

| Approach           | Idea                                 | Time  | Space | Recommended |
| ------------------ | ------------------------------------ | ----- | ----- | ----------- |
| Reverse (this)     | Reverse whole then reverse parts     | O(n)  | O(1)  | Yes         |
| Extra array        | Copy to new array using shifted idx  | O(n)  | O(n)  | No          |
| Cyclic replacements| Move elements along cycles in-place  | O(n)  | O(1)  | No (complex) |
