# Remove Duplicates from Sorted Array II

## Difficulty
Medium

## Description
Given a sorted array nums, remove duplicates in-place such that each element appears at most twice and return the new length. Do not allocate extra space for another array; modify nums in-place with O(1) extra memory.

## Examples

### Example 1

```text
Input: [1,1,1,2,2,3]
Output: 5, [1,1,2,2,3]
Explanation: The first three 1's are reduced to two 1's.
```

### Example 2

```text
Input: [0,0,1,1,1,1,2,3,3]
Output: 7, [0,0,1,1,2,3,3]
Explanation: The four 1's are reduced to two 1's.
```

## Constraints

```text
1 <= nums.length <= 10^5
-10^4 <= nums[i] <= 10^4
nums is sorted in non-decreasing order
Allowed maximum occurrences = 2
In-place modification required, O(1) extra space
```

---

## Idea
Use two pointers: one to scan and one to write valid elements; allow a value if write < 2 or nums[i] != nums[write-2].

---

## Pseudo Code

```text
function removeDuplicates(nums)
    if nums is empty then
        return 0
    set write = 0
    for i from 0 to length(nums)-1
        if write < 2 or nums[i] != nums[write-2]
            nums[write] = nums[i]
            write = write + 1
    return write
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | i | write | Operation                                 | nums State                |
| ---- | - | ----- | ----------------------------------------- | ------------------------- |
| 1    | 0 | 0     | write<2 true => write nums[0]=1; write=1  | [1,1,1,2,2,3]             |
| 2    | 1 | 1     | write<2 true => write nums[1]=1; write=2  | [1,1,1,2,2,3]             |
| 3    | 2 | 2     | nums[2]==nums[0] => skip                   | [1,1,1,2,2,3]             |
| 4    | 3 | 2     | nums[3]!=nums[0] => nums[2]=2; write=3     | [1,1,2,2,2,3]             |
| 5    | 4 | 3     | nums[4]!=nums[1] => nums[3]=2; write=4     | [1,1,2,2,2,3]             |
| 6    | 5 | 4     | nums[5]!=nums[2] => nums[4]=3; write=5     | [1,1,2,2,3,3]             |
| End  | - | 5     | return 5                                  | final prefix [1,1,2,2,3]  |

## Other Patterns

### Pattern 2

**Idea**

Copy allowed elements into a new array up to two occurrences and return its length.

**Pseudo Code**

```text
function removeDuplicatesExtraArray(nums)
    if nums is empty then
        return 0
    create result = empty list
    for x in nums
        if length(result) < 2 or x != result[length(result)-2]
            append x to result
    copy result back into nums positions 0..length(result)-1
    return length(result)
```

### Pattern 3

**Idea**

Generalize two-pointer to allow at most k occurrences (parameterized solution).

**Pseudo Code**

```text
function removeDuplicatesK(nums, k)
    if nums is empty then
        return 0
    set write = 0
    for i from 0 to length(nums)-1
        if write < k or nums[i] != nums[write-k]
            nums[write] = nums[i]
            write = write + 1
    return write
```

## Comparison

| Approach        | Idea                                     | Time  | Space | Recommended |
| --------------- | ---------------------------------------- | ----- | ----- | ----------- |
| Two-pointer     | In-place write pointer allow up to 2     | O(n)  | O(1)  | Yes         |
| Extra array     | Build new array with allowed occurrences | O(n)  | O(n)  | No          |
| Parameter k     | Two-pointer generalized for k occurrences| O(n)  | O(1)  | Yes (if k variable)
