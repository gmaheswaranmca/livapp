# Best Time to Buy and Sell Stock

## Difficulty
Easy

## Description
Given an array prices where prices[i] is the price of a given stock on the ith day, find the maximum profit you can achieve from one transaction (buy one and sell one share). You must buy before you sell. If no profit is possible, return 0.

## Examples

### Example 1

```text
Input: [7,1,5,3,6,4]
Output: 5
Explanation: Buy on day 2 (price = 1) and sell on day 5 (price = 6), profit = 6 - 1 = 5.
```

### Example 2

```text
Input: [7,6,4,3,1]
Output: 0
Explanation: No transaction is done, max profit = 0.
```

## Constraints

```text
1 <= prices.length <= 10^5
0 <= prices[i] <= 10^4
Only one transaction allowed (one buy and one sell).
```

---

## Idea
Track the minimum price seen so far and compute max profit at each day as current price minus min price.

---

## Pseudo Code

```text
function solve(prices)
    if prices is empty then
        return 0
    minPrice <- +infinity
    maxProfit <- 0
    for each price in prices do
        if price < minPrice then
            minPrice <- price
        profit <- price - minPrice
        if profit > maxProfit then
            maxProfit <- profit
    return maxProfit
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | State (minPrice, price, maxProfit) | Operation                | Result           |
| ---- | ---------------------------------- | ------------------------ | ---------------- |
| 1    | (inf, 7, 0)                        | set minPrice = 7         | (7, 7, 0)        |
| 2    | (7, 1, 0)                          | price < minPrice => minPrice = 1 | (1, 1, 0) |
| 3    | (1, 5, 0)                          | profit = 5-1 = 4 > 0 => maxProfit = 4 | (1, 5, 4) |
| 4    | (1, 3, 4)                          | profit = 3-1 = 2 <= 4 => no change | (1, 3, 4) |
| 5    | (1, 6, 4)                          | profit = 6-1 = 5 > 4 => maxProfit = 5 | (1, 6, 5) |
| 6    | (1, 4, 5)                          | profit = 4-1 = 3 <= 5 => no change | (1, 4, 5) |

## Other Patterns

### Pattern 1

**Idea**

Brute force check every pair of buy and sell days.

**Pseudo Code**

```text
function solve(prices)
    n <- length of prices
    maxProfit <- 0
    for i from 0 to n-2 do
        for j from i+1 to n-1 do
            profit <- prices[j] - prices[i]
            if profit > maxProfit then
                maxProfit <- profit
    return maxProfit
```

### Pattern 2

**Idea**

Transform to differences and apply Kadane's algorithm to find max subarray sum.

**Pseudo Code**

```text
function solve(prices)
    if length of prices < 2 then
        return 0
    maxEnding <- 0
    maxSoFar <- 0
    for i from 1 to length(prices)-1 do
        diff <- prices[i] - prices[i-1]
        maxEnding <- max(0, maxEnding + diff)
        if maxEnding > maxSoFar then
            maxSoFar <- maxEnding
    return maxSoFar
```

## Comparison

| Approach      | Idea                                 | Time    | Space | Recommended |
| ------------- | ------------------------------------ | ------- | ----- | ----------- |
| One-pass      | Track min price and max profit       | O(n)    | O(1)  | Yes         |
| Kadane (diff) | Max subarray on day-to-day differences | O(n)  | O(1)  | Yes         |
| Brute force   | Check all buy-sell pairs             | O(n^2)  | O(1)  | No          |
