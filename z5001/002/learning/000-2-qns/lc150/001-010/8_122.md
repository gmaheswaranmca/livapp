# Best Time to Buy and Sell Stock II

## Difficulty

Easy

## Description

Given an array prices where prices[i] is the price of a given stock on the i-th day, maximize total profit by making as many transactions as you like (buy one and sell one share multiple times). You must sell the stock before you buy again.

## Examples

### Example 1

```text
Input: [7,1,5,3,6,4]
Output: 7
Explanation: Add every positive difference: (5-1)+(6-3)=4+3=7.
```

### Example 2

```text
Input: [1,2,3,4,5]
Output: 4
Explanation: Buy at 1 sell at 5 or add daily gains: (2-1)+(3-2)+(4-3)+(5-4)=4.
```

## Constraints

```text
1 <= prices.length <= 10^5
0 <= prices[i] <= 10^4
Time limit: typical O(n) required
```

---

## Idea

Accumulate every positive day-to-day price increase.

---

## Pseudo Code

```text
function maxProfit(prices)
    if prices is empty return 0
    profit <- 0
    for i from 1 to length(prices)-1
        if prices[i] > prices[i-1] then
            profit <- profit + (prices[i] - prices[i-1])
    return profit
```

## Other Patterns

### Pattern 1

**Idea**

Peak-valley summation: find each valley then the next peak and add peak-valley.

**Pseudo Code**

```text
function maxProfitPeakValley(prices)
    i <- 0
    n <- length(prices)
    profit <- 0
    while i < n-1
        while i < n-1 and prices[i] >= prices[i+1] do i <- i + 1
        valley <- prices[i]
        while i < n-1 and prices[i] <= prices[i+1] do i <- i + 1
        peak <- prices[i]
        profit <- profit + (peak - valley)
    return profit
```

### Pattern 2

**Idea**

State machine DP with hold and cash (useful to generalize to limited transactions/fees).

**Pseudo Code**

```text
function maxProfitDP(prices)
    if prices is empty return 0
    cash <- 0
    hold <- -prices[0]
    for i from 1 to length(prices)-1
        hold <- max(hold, cash - prices[i])
        cash <- max(cash, hold + prices[i])
    return cash
```

## Comparison

| Approach     | Idea                                   | Time | Space | Recommended |
| ------------ | -------------------------------------- | ---- | ----- | ----------- |
| Greedy       | Sum all positive adjacent differences  | O(n) | O(1)  | Yes         |
| Peak-Valley  | Find valleys and next peaks            | O(n) | O(1)  | Yes         |
| DP (hold/cash) | Transaction state machine             | O(n) | O(1)  | No (overkill) |
