# Jump Game II

## Difficulty
Medium

## Description
Given an array nums of non-negative integers where nums[i] is the maximum jump length from index i, return the minimum number of jumps to reach the last index from the first index.

## Examples

### Example 1

```text
Input: [2,3,1,1,4]
Output: 2
Explanation: Jump 1 step from index 0 to 1, then 3 steps to the last index.
```

### Example 2

```text
Input: [2,1]
Output: 1
Explanation: Jump directly from index 0 to index 1.
```

## Constraints

```text
1 <= nums.length <= 10^4
0 <= nums[i] <= 10^5
You can always reach the last index (or assume valid input where solution exists).
```

---

## Idea
Greedy BFS-like range expansion: extend the furthest reachable index within the current range and make a jump when the current range ends.

---

## Pseudo Code

```text
function solve(nums)
    n := length(nums)
    if n <= 1 then
        return 0
    jumps := 0
    current_end := 0
    furthest := 0
    for i from 0 to n - 2
        furthest := max(furthest, i + nums[i])
        if i == current_end
            jumps := jumps + 1
            current_end := furthest
            if current_end >= n - 1
                break
    return jumps
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | i | nums[i] | furthest (before→after) | current_end | jumps | Operation |
| ---- | - | ------- | ----------------------- | ----------- | ----- | --------- |
| 1    | 0 | 2       | 0 → 2                   | 0           | 0 → 1| i==current_end → increment jumps, set current_end=2 |
| 2    | 1 | 3       | 2 → 4                   | 2           | 1    | update furthest |
| 3    | 2 | 1       | 4 → 4                   | 2 → 4       | 1 → 2| i==current_end → increment jumps, set current_end=4 → reached end, break |
| Result | - | -    | -                       | -           | 2     | Minimum jumps = 2 |

## Other Patterns

### Pattern 1

**Idea**

Dynamic programming computing min jumps to each index.

**Pseudo Code**

```text
function solve(nums)
    n := length(nums)
    dp := array of size n filled with INF
    dp[0] := 0
    for i from 0 to n - 1
        for j from 1 to nums[i]
            if i + j < n
                dp[i + j] := min(dp[i + j], dp[i] + 1)
    return dp[n - 1]
```

### Pattern 2

**Idea**

BFS with queue exploring reachable indices level by level.

**Pseudo Code**

```text
function solve(nums)
    n := length(nums)
    if n <= 1 then return 0
    visited := boolean array of size n false
    queue := empty queue
    enqueue(queue, 0)
    visited[0] := true
    jumps := 0
    while queue not empty
        size := queue.size()
        for k from 1 to size
            idx := dequeue(queue)
            if idx == n - 1 return jumps
            for step from 1 to nums[idx]
                next := idx + step
                if next < n and not visited[next]
                    visited[next] := true
                    enqueue(queue, next)
        jumps := jumps + 1
    return -1
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Greedy (range expansion) | Expand furthest reachable in current range and jump at range end | O(n) | O(1) | Yes |
| Dynamic Programming | Compute min jumps to every index using previous results | O(n^2) | O(n) | No |
| BFS (explicit levels) | Level-order traversal of reachable indices | O(n^2) worst-case | O(n) | No |
