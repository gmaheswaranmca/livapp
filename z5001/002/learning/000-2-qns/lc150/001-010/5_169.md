# Majority Element

## Difficulty
Easy

## Description
Find the element that appears more than n/2 times in an array of integers. It is guaranteed that such an element always exists.

## Examples

### Example 1

```text
Input: [3, 2, 3]
Output: 3
Explanation: 3 appears 2 out of 3 times (> n/2).
```

### Example 2

```text
Input: [2,2,1,1,1,2,2]
Output: 2
Explanation: 2 appears 4 out of 7 times (> n/2).
```

## Constraints

```text
1 <= nums.length <= 5 * 10^4
-10^9 <= nums[i] <= 10^9
There is always a majority element (appears > n/2 times).
```

---

## Idea
Use Boyer-Moore Voting Algorithm to keep a running candidate and count, which yields the majority in one pass.

---

## Pseudo Code

```text
function majorityElement(nums)
    candidate <- null
    count <- 0
    for each num in nums
        if count == 0
            candidate <- num
            count <- 1
        else if num == candidate
            count <- count + 1
        else
            count <- count - 1
    return candidate
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (candidate,count) | Operation         | Result              |
| ---- | ----------------------- | ----------------- | ------------------- |
| 1    | (null,0)                | see 3             | candidate=3,count=1 |
| 2    | (3,1)                   | num=2 != candidate| count=0             |
| 3    | (3,0)                   | count==0 set num  | candidate=3,count=1 |
| End  | (3,1)                   | return candidate  | 3                   |

## Other Patterns

### Pattern 1

**Idea**

Count frequencies using a hash map and pick the element with count > n/2.

**Pseudo Code**

```text
function majorityElement(nums)
    freq <- empty map
    for each num in nums
        freq[num] <- freq.get(num,0) + 1
        if freq[num] > length(nums) / 2
            return num
```

### Pattern 2

**Idea**

Sort the array; the middle element (index n/2) is the majority.

**Pseudo Code**

```text
function majorityElement(nums)
    sort(nums)
    return nums[length(nums) / 2]
```

### Pattern 3

**Idea**

Divide and conquer: recursively find majority in halves and combine results by counting.

**Pseudo Code**

```text
function majorityElement(nums)
    return majorityRec(nums, 0, length(nums)-1)

function majorityRec(nums, left, right)
    if left == right
        return nums[left]
    mid <- (left + right) // 2
    leftMajor <- majorityRec(nums, left, mid)
    rightMajor <- majorityRec(nums, mid+1, right)
    if leftMajor == rightMajor
        return leftMajor
    leftCount <- countInRange(nums, leftMajor, left, right)
    rightCount <- countInRange(nums, rightMajor, left, right)
    return leftMajor if leftCount > rightCount else rightMajor

function countInRange(nums, val, left, right)
    count <- 0
    for i from left to right
        if nums[i] == val
            count <- count + 1
    return count
```

### Pattern 4

**Idea**

Randomization: pick random elements until one is majority (expected constant trials).

**Pseudo Code**

```text
function majorityElement(nums)
    while true
        candidate <- random choice from nums
        if count(nums, candidate) > length(nums) / 2
            return candidate
```

## Comparison

| Approach          | Idea                                  | Time        | Space     | Recommended |
| ----------------- | ------------------------------------- | ----------- | --------- | ----------- |
| Boyer-Moore       | Linear scan with candidate and count  | O(n)        | O(1)      | Yes         |
| Hash Map          | Frequency counting                     | O(n)        | O(n)      | No (if O(1) space needed) |
| Sorting           | Sort and take middle                   | O(n log n)  | O(1)/O(n) | No          |
| Divide & Conquer  | Recur halves and combine               | O(n log n)  | O(log n)  | No          |
| Randomization     | Random picks until majority found      | O(n) expected | O(1)    | No          |
