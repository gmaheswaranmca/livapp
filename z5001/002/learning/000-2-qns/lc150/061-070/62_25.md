# Reverse Nodes in k-Group

## Difficulty
Medium

## Description
Given the head of a singly linked list and an integer k, reverse the nodes of the list k at a time and return the modified list. Nodes that remain with count less than k must remain in original order.

## Examples

### Example 1

```text
Input: head = [1,2,3,4,5], k = 2
Output: [2,1,4,3,5]
Explanation: Reverse every 2 nodes.
```

### Example 2

```text
Input: head = [1,2,3,4,5], k = 3
Output: [3,2,1,4,5]
Explanation: First 3 nodes reversed, last 2 remain.
```

### Example 3

```text
Input: head = [1,2], k = 3
Output: [1,2]
Explanation: Less than k nodes, list unchanged.
```

## Constraints

```text
1 <= number of nodes <= 10^5
Node values are integers.
1 <= k <= 10^5
Must perform in-place node re-linking (no value-only swaps).
```

---

## Idea
Iteratively find each k-th node, reverse that segment in-place by pointer re-linking, and connect segments using a dummy head.

---

## Pseudo Code

```text
function reverse_k_group(head, k)
    if head == null or k <= 1: return head
    dummy = Node(0)
    dummy.next = head
    group_prev = dummy
    while True
        kth = get_kth_node(group_prev, k)
        if kth == null: break
        group_next = kth.next
        prev = group_next
        curr = group_prev.next
        while curr != group_next
            temp = curr.next
            curr.next = prev
            prev = curr
            curr = temp
        temp = group_prev.next
        group_prev.next = kth
        group_prev = temp
    return dummy.next

function get_kth_node(start, k)
    node = start
    for i from 1 to k
        node = node.next
        if node == null: return null
    return node
```

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | list = 0(dummy)->1->2->3->4->5 | find kth from dummy with k=2 | kth points to 2 |
| 2 | reversing nodes 1..2 | reverse pointers in segment | 0->2->1->3->4->5 |
| 3 | group_prev moves to node 1 | find kth from group_prev with k=2 | kth points to 4 |
| 4 | reversing nodes 3..4 | reverse pointers in segment | 0->2->1->4->3->5 |
| 5 | find_kth returns null for next group | stop | final 2->1->4->3->5 |

## Other Patterns

### Pattern 1

**Idea**
Recursively reverse first k nodes, connect recursively reversed remainder.

**Pseudo Code**

```text
function reverse_k_group_recursive(head, k)
    kth = get_kth_node(head, k)
    if kth == null: return head
    next_head = kth.next
    prev = null
    curr = head
    while curr != next_head
        temp = curr.next
        curr.next = prev
        prev = curr
        curr = temp
    head.next = reverse_k_group_recursive(next_head, k)
    return prev
```

### Pattern 2

**Idea**
Use a stack to collect k nodes, pop to reverse links.

**Pseudo Code**

```text
function reverse_k_group_stack(head, k)
    dummy = Node(0)
    tail = dummy
    curr = head
    stack = empty
    while curr != null
        stack.push(curr)
        curr = curr.next
        if stack.size == k
            while stack not empty
                node = stack.pop()
                tail.next = node
                tail = node
            tail.next = null
    while stack not empty
        node = stack.shift() // keep original order
        tail.next = node
        tail = node
    tail.next = null
    return dummy.next
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Iterative in-place | Reverse each k-group by pointer rewiring | O(n) | O(1) | Yes |
| Recursive | Reverse first k then recurse | O(n) | O(n/k) recursion depth | No (stack risk) |
| Stack-based | Use stack to reverse nodes per group | O(n) | O(k) | No (extra memory) |
