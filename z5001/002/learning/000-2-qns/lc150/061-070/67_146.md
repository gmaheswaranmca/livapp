# LRU Cache

## Difficulty
Medium

## Description
Design a data structure that supports get(key) and put(key, value) in O(1) time complexity with LRU (Least Recently Used) eviction when capacity is exceeded.

## Examples

### Example 1

```text
Input: 
operations = ["LRUCache","put","put","get","put","get","put","get","get"]
arguments  = [[2],[1,1],[2,2],[1],[3,3],[2],[4,4],[1],[3]]
Output:
[null,null,null,1,null,-1,null,-1,3]
Explanation:
LRUCache(2)
put(1,1)
put(2,2)
get(1) -> 1
put(3,3) evicts key 2
get(2) -> -1
put(4,4) evicts key 1
get(1) -> -1
get(3) -> 3
```

## Constraints

```text
1 <= capacity <= 10^5
0 <= key, value <= 10^9
At most 2*10^5 get/put operations
get must return -1 if key not present
Each operation must be average O(1)
```

---

## Idea
HashMap for O(1) lookup + Doubly Linked List to maintain recency order (head = most recent, tail = least recent).

---

## Pseudo Code

```text
structure Node
    key
    value
    prev
    next

class LRUCache
    capacity
    size
    head    // dummy head
    tail    // dummy tail
    map     // key -> Node

function LRUCache(capacity)
    set this.capacity = capacity
    set this.size = 0
    create dummy head node
    create dummy tail node
    head.next = tail
    tail.prev = head
    create empty map

function add_to_head(node)
    node.prev = head
    node.next = head.next
    head.next.prev = node
    head.next = node

function remove_node(node)
    node.prev.next = node.next
    node.next.prev = node.prev

function move_to_head(node)
    remove_node(node)
    add_to_head(node)

function pop_tail()
    node = tail.prev
    remove_node(node)
    return node

function get(key)
    if key not in map then
        return -1
    node = map[key]
    move_to_head(node)
    return node.value

function put(key, value)
    if key in map then
        node = map[key]
        node.value = value
        move_to_head(node)
        return
    node = new Node
    node.key = key
    node.value = value
    add_to_head(node)
    map[key] = node
    size = size + 1
    if size > capacity then
        tailNode = pop_tail()
        remove map[tailNode.key]
        size = size - 1
```

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(1) per get/put (amortized) |
| Space Complexity | O(capacity) |

## Code Explanation

### Dry Run

| Step | Operation      | DLL (head -> tail most->least) | Map (key->value) |
| ---- | -------------- | -------------------------------- | ---------------- |
| 1    | LRUCache(2)    | head <-> tail                    | {}               |
| 2    | put(1,1)       | 1                                | {1:1}            |
| 3    | put(2,2)       | 2 <-> 1                          | {1:1,2:2}        |
| 4    | get(1) -> 1    | 1 <-> 2                          | {1:1,2:2}        |
| 5    | put(3,3)       | 3 <-> 1                          | {1:1,3:3}        |
| 6    | get(2) -> -1   | 3 <-> 1                          | {1:1,3:3}        |
| 7    | put(4,4)       | 4 <-> 3                          | {3:3,4:4}        |
| 8    | get(1) -> -1   | 4 <-> 3                          | {3:3,4:4}        |
| 9    | get(3) -> 3    | 3 <-> 4                          | {3:3,4:4}        |

## Other Patterns

### Pattern 1

**Idea**

Use language built-in ordered map (OrderedDict / LinkedHashMap) to maintain order and support O(1) operations.

**Pseudo Code**

```text
function LRUCache(capacity)
    create ordered_map
    set this.capacity = capacity

function get(key)
    if key not in ordered_map then
        return -1
    value = ordered_map[key]
    move key to end (most recent)
    return value

function put(key, value)
    if key in ordered_map then
        update ordered_map[key] = value
        move key to end
        return
    ordered_map[key] = value
    if size of ordered_map > capacity then
        remove the first item (least recent)
```

### Pattern 2

**Idea**

HashMap + balanced BST or priority queue keyed by timestamp for O(log n) operations; useful if languages lack ordered maps but tolerance for log factor.

**Pseudo Code**

```text
function LRUCache(capacity)
    create map key->(value, timestamp)
    create BST or min-heap of (timestamp, key)
    set this.capacity = capacity
    set this.time = 0

function get(key)
    if key not in map then
        return -1
    increment time
    update map[key].timestamp = time
    update BST/heap with new timestamp for key
    return map[key].value

function put(key, value)
    increment time
    if key in map then
        update map[key] = (value, time)
        update BST/heap for key
        return
    if size == capacity then
        evict = extract min from BST/heap until top timestamp matches map record
        remove evict.key from map
    insert map[key] = (value, time)
    insert (time, key) into BST/heap
```

## Comparison

| Approach                  | Idea                                  | Time         | Space       | Recommended |
| ------------------------- | ------------------------------------- | ------------ | ----------- | ----------- |
| HashMap + Doubly Linked List | Manual maintenance of recency using DLL | O(1)         | O(capacity) | Yes         |
| OrderedDict / LinkedHashMap | Use built-in ordered associative map  | O(1)         | O(capacity) | Yes (if available) |
| HashMap + BST / Heap      | Use timestamp + BST/heap              | O(log n)     | O(capacity) | No          |
