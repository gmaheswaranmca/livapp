# Reverse Linked List II

## Difficulty
Medium

## Description
Reverse the nodes of a singly linked list from position left to position right (1-indexed) and return the modified list. Do the reversal in-place.

## Examples

### Example 1

```text
Input: head = [1,2,3,4,5], left = 2, right = 4
Output: [1,4,3,2,5]
Explanation: Nodes from position 2 to 4 are reversed.
```

### Example 2

```text
Input: head = [1,2,3], left = 1, right = 3
Output: [3,2,1]
Explanation: Entire list reversed.
```

## Constraints

```text
The number of nodes in the list is n where 1 <= n <= 500.
-500 <= Node.val <= 500
1 <= left <= right <= n
Must perform in-place with O(1) extra space ideally.
```

---

## Idea
Use a dummy node, move to node before left, then iteratively extract and insert nodes from the sublist front (head-insertion) for right-left iterations.

---

## Pseudo Code

```text
function reverseBetween(head, left, right)
    if head is null or left == right
        return head
    dummy = new Node(0)
    dummy.next = head
    prev = dummy
    for i from 1 to left-1
        prev = prev.next
    start = prev.next
    for i from 0 to right-left-1
        temp = start.next
        start.next = temp.next
        temp.next = prev.next
        prev.next = temp
    return dummy.next
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | dummy->1->2->3->4->5, left=2,right=4 | move prev to node before left (prev points to 1) | prev=1, start=2 |
| 2 | prev=1,start=2 | iteration 1: temp = start.next (3); detach 3 and insert after prev | list: 1->3->2->4->5, start=2 |
| 3 | prev=1,start=2 | iteration 2: temp = start.next (4); detach 4 and insert after prev | list: 1->4->3->2->5, start=2 |
| 4 | final | return dummy.next | [1,4,3,2,5] |

## Other Patterns

### Pattern 1

**Idea**
Reverse the sublist by fully reversing the segment then reconnecting ends.

**Pseudo Code**

```text
function reverseBetween(head,left,right)
    if head is null or left == right
        return head
    dummy = new Node(0)
    dummy.next = head
    prev = dummy
    for i from 1 to left-1
        prev = prev.next
    tail = prev.next
    curr = tail
    prevSegment = null
    for i from 0 to right-left
        nextNode = curr.next
        curr.next = prevSegment
        prevSegment = curr
        curr = nextNode
    prev.next = prevSegment
    tail.next = curr
    return dummy.next
```

### Pattern 2

**Idea**
Use recursion to reverse the first n nodes then stitch when left > 1 by moving head forward recursively.

**Pseudo Code**

```text
function reverseFirstN(head, n)
    if n == 1
        successor = head.next
        return head
    last = reverseFirstN(head.next, n-1)
    head.next.next = head
    head.next = successor
    return last

function reverseBetween(head,left,right)
    if left == 1
        return reverseFirstN(head, right)
    head.next = reverseBetween(head.next, left-1, right-1)
    return head
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| In-place insertion (iterative) | Extract and insert nodes at sublist front | O(n) | O(1) | Yes |
| Full-segment reverse then reconnect | Reverse pointers in segment then reconnect | O(n) | O(1) | Yes |
| Recursive reverse-first-n | Recursively reverse first n nodes | O(n) | O(n) (call stack) | No (unless recursion preferred) |
