# Remove Nth Node From End of List

## Difficulty
Medium

## Description
Given the head of a singly linked list, remove the nth node from the end of the list and return its head.

## Examples

### Example 1

```text
Input: head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]
Explanation: The 2nd node from the end is 4, remove it.
```

### Example 2

```text
Input: head = [1], n = 1
Output: []
Explanation: Remove the only node.
```

### Example 3

```text
Input: head = [1,2], n = 1
Output: [1]
Explanation: Remove the last node.
```

## Constraints

```text
The number of nodes in the list is in the range [1, 10^5].
1 <= n <= length of list
Node values are arbitrary.
```

---

## Idea
Use a dummy node and two pointers with a gap of n+1 to locate the predecessor of the node to remove in one pass.

---

## Pseudo Code

```text
function removeNthFromEnd(head, n)
    create dummy node with dummy.next = head
    set fast = dummy
    set slow = dummy
    repeat n+1 times
        fast = fast.next
    while fast != null
        fast = fast.next
        slow = slow.next
    // slow is predecessor of target
    slow.next = slow.next.next
    return dummy.next
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(L)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | fast position | slow position | Operation           | Result               |
| ---- | ------------- | ------------- | ------------------- | -------------------- |
| 1    | dummy         | dummy         | init                | list = 1->2->3->4->5 |
| 2    | 1             | dummy         | advance fast 3 times (n+1) | fast at node value 3 |
| 3    | 2             | 1             | iterate              | fast->4, slow->2     |
| 4    | 3             | 2             | iterate              | fast->5, slow->3     |
| 5    | null          | 3             | iterate end          | fast->null, slow->3  |
| 6    | null          | 3             | remove slow.next     | link 3->5, removed 4 |

## Other Patterns

### Pattern 1

**Idea**

Two-pass: compute length then remove (length - n + 1)th node.

**Pseudo Code**

```text
function removeNthFromEnd(head, n)
    set length = 0
    set cur = head
    while cur != null
        length = length + 1
        cur = cur.next
    set targetIndex = length - n
    create dummy with dummy.next = head
    set cur = dummy
    repeat targetIndex times
        cur = cur.next
    cur.next = cur.next.next
    return dummy.next
```

### Pattern 2

**Idea**

Use a stack to store nodes then pop n nodes to find predecessor.

**Pseudo Code**

```text
function removeNthFromEnd(head, n)
    create dummy with dummy.next = head
    create empty stack
    set cur = dummy
    while cur != null
        push cur onto stack
        cur = cur.next
    repeat n times
        pop from stack
    set pred = pop from stack
    pred.next = pred.next.next
    return dummy.next
```

## Comparison

| Approach     | Idea                                     | Time    | Space | Recommended |
| ------------ | ---------------------------------------- | ------- | ----- | ----------- |
| Two-pointer  | Single pass with n+1 gap and dummy node  | O(L)    | O(1)  | Yes         |
| Two-pass     | Compute length then remove                | O(L)    | O(1)  | No          |
| Stack        | Push nodes then pop n to get predecessor | O(L)    | O(L)  | No          |
