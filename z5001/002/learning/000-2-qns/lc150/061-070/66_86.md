# Partition List

## Difficulty
Medium

## Description
Rearrange a singly linked list so that all nodes with values less than x come before nodes with values greater than or equal to x. Preserve the original relative order within each partition.

## Examples

### Example 1

```text
Input: head = [1,4,3,2,5,2], x = 3
Output: [1,2,2,4,3,5]
Explanation: Nodes < 3 appear in original relative order (1,2,2), followed by nodes >= 3 in original relative order (4,3,5).
```

### Example 2

```text
Input: head = [2,1], x = 2
Output: [1,2]
Explanation: Node 1 is less than 2 and appears before node 2.
```

## Constraints

```text
0 <= n <= 10^5 (n = number of nodes)
-10^9 <= Node.val <= 10^9
-10^9 <= x <= 10^9
```

---

## Idea
Build two lists (less and greater-or-equal) while scanning once, then join them.

---

## Pseudo Code

```text
function partitionList(head, x)
    if head is null then
        return null
    create node lessDummy with next = null
    create node greaterDummy with next = null
    set lessTail = lessDummy
    set greaterTail = greaterDummy
    set current = head
    while current is not null
        if current.val < x then
            lessTail.next = current
            lessTail = lessTail.next
        else
            greaterTail.next = current
            greaterTail = greaterTail.next
        current = current.next
    greaterTail.next = null
    lessTail.next = greaterDummy.next
    return lessDummy.next
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | Node (current) | Less List (after) | Greater List (after) | Action |
| ---- | -------------- | ------------------ | --------------------- | ------ |
| 1    | 1              | 1                  |                     - | 1 < 3 -> append to less |
| 2    | 4              | 1                  | 4                   | 4 >= 3 -> append to greater |
| 3    | 3              | 1                  | 4 -> 3              | 3 >= 3 -> append to greater |
| 4    | 2              | 1 -> 2             | 4 -> 3              | 2 < 3 -> append to less |
| 5    | 5              | 1 -> 2             | 4 -> 3 -> 5         | 5 >= 3 -> append to greater |
| 6    | 2              | 1 -> 2 -> 2        | 4 -> 3 -> 5         | 2 < 3 -> append to less |
| Join | -              | 1 -> 2 -> 2 -> 4 -> 3 -> 5 | -           | lessTail.next = greaterDummy.next |

## Other Patterns

### Pattern 1

**Idea**

Rebuild list using array of values then reconstruct list to preserve partition order.

**Pseudo Code**

```text
function partitionUsingArray(head, x)
    create list lessVals = []
    create list greaterVals = []
    set current = head
    while current is not null
        if current.val < x then
            append current.val to lessVals
        else
            append current.val to greaterVals
        current = current.next
    create dummy node resultDummy
    set tail = resultDummy
    for val in lessVals
        tail.next = new Node(val)
        tail = tail.next
    for val in greaterVals
        tail.next = new Node(val)
        tail = tail.next
    return resultDummy.next
```

### Pattern 2

**Idea**

In-place stable partition by relinking nodes without dummy heads, maintaining two pointers.

**Pseudo Code**

```text
function partitionInPlace(head, x)
    if head is null then
        return null
    set newHead = null
    set newTail = null
    set current = head
    while current is not null
        nextNode = current.next
        if current.val < x then
            if newHead is null then
                newHead = current
                newTail = current
            else
                newTail.next = current
                newTail = current
        else
            if newHead is null then
                newHead = current
                newTail = current
            else
                newTail.next = current
                newTail = current
        current = nextNode
    if newTail is not null then
        newTail.next = null
    return newHead
```

## Comparison

| Approach        | Idea                                    | Time | Space | Recommended |
| --------------- | --------------------------------------- | ---- | ----- | ----------- |
| Two-list (main) | Build less and greater lists then join  | O(n) | O(1)  | Yes         |
| Array rebuild   | Collect values then rebuild list        | O(n) | O(n)  | No          |
| In-place link   | Relink nodes without dummy nodes        | O(n) | O(1)  | No (more error-prone) |
