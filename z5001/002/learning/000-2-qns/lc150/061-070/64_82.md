# Remove Duplicates from Sorted List II

## Difficulty
Medium

## Description
Given the head of a sorted linked list, delete all nodes that have duplicate numbers, leaving only distinct numbers from the original list. Return the linked list sorted as well.

## Examples

### Example 1

```text
Input: [1,2,3,3,4,4,5]
Output: [1,2,5]
Explanation: Nodes with values 3 and 4 occur multiple times and are removed entirely.
```

### Example 2

```text
Input: [1,1,1,2,3]
Output: [2,3]
Explanation: Value 1 occurs multiple times so all nodes with 1 are removed.
```

### Example 3

```text
Input: []
Output: []
Explanation: Empty list remains empty.
```

## Constraints

```text
0 <= number of nodes <= 300
-100 <= Node.val <= 100
List is sorted in non-decreasing order.
```

---

## Idea
Use a dummy node and two pointers (prev, curr); when duplicates are detected skip all nodes with that value and link prev.next to the first non-duplicate node.

---

## Pseudo Code

```text
function deleteDuplicates(head)
    create dummy node with dummy.next = head
    set prev = dummy
    set curr = head
    while curr != null
        if curr.next != null and curr.val == curr.next.val
            set duplicateVal = curr.val
            while curr != null and curr.val == duplicateVal
                set curr = curr.next
            set prev.next = curr
        else
            set prev = prev.next
            set curr = curr.next
    return dummy.next
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | State                          | Operation                            | Result                    |
| ---- | ------------------------------ | -------------------------------------| ------------------------- |
| 1    | dummy->1->2->3->3->4->4->5     | curr=1 not duplicate                 | prev->1, curr->2         |
| 2    | dummy->1->2->3->3->4->4->5     | curr=3 duplicates detected           | skip all 3s -> curr->4   |
| 3    | dummy->1->2->4->4->5           | prev.next = curr (skipped 3s)        | list becomes 1->2->4->4->5|
| 4    | dummy->1->2->4->4->5           | curr=4 duplicates detected           | skip all 4s -> curr->5   |
| 5    | dummy->1->2->5                 | prev.next = curr (skipped 4s)        | list becomes 1->2->5     |
| 6    | dummy->1->2->5                 | curr=5 not duplicate                 | prev->5, curr->null      |
| 7    | dummy->1->2->5                 | finish                               | return [1,2,5]           |

## Other Patterns

### Pattern 1

**Idea**
Recursive removal: if head starts a run of duplicates skip the whole run and recurse on the rest, otherwise keep head and recurse for head.next.

**Pseudo Code**

```text
function deleteDuplicatesRec(head)
    if head == null
        return null
    if head.next != null and head.val == head.next.val
        set val = head.val
        while head != null and head.val == val
            set head = head.next
        return deleteDuplicatesRec(head)
    else
        set head.next = deleteDuplicatesRec(head.next)
        return head
```
