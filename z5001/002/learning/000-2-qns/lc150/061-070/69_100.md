# Same Tree (LeetCode 100)

## Difficulty
Easy

## Description
Given the roots of two binary trees p and q, determine if they are structurally identical and the nodes have the same values.

## Examples

### Example 1
```text
Input: p = [1,2,3], q = [1,2,3]
Output: true
Explanation: Both trees have same structure and values.
```

### Example 2
```text
Input: p = [1,2], q = [1,null,2]
Output: false
Explanation: Structures differ.
```

## Constraints
```text
0 <= number of nodes in p, q <= 100
-10^4 <= Node.val <= 10^4
Trees are binary trees (left, right)
```

---

## Idea
Recursively compare corresponding nodes: both null => true; one null or values differ => false; else compare left and right subtrees.

---

## Pseudo Code
```text
function isSameTree(p, q)
    if p is null and q is null
        return true
    if p is null or q is null
        return false
    if p.val != q.val
        return false
    leftSame = isSameTree(p.left, q.left)
    if leftSame is false
        return false
    return isSameTree(p.right, q.right)
```

---

## Complexity

| Metric           | Value         |
| ---------------- | ------------- |
| Time Complexity  | O(n)          |
| Space Complexity | O(h) (recursion stack), h = tree height |

---

## Code Explanation

### Dry Run

| Step | State (p,q)     | Operation                     | Result        |
| ---- | --------------- | ----------------------------- | ------------- |
| 1    | (1,1)           | both non-null, values equal   | recurse left  |
| 2    | (2,2)           | both non-null, values equal   | recurse left  |
| 3    | (null,null)     | both null                     | return true   |
| 4    | (null,null)     | both null                     | return true   |
| 5    | back to (2,2)   | left true, recurse right      | return true   |
| 6    | back to (1,1)   | left true, recurse right      | return true   |
| 7    | (3,3)           | both non-null, values equal   | return true   |
| 8    | final           | all checks passed             | true          |

1. Check null cases and value equality at current nodes.
2. Recurse on left subtrees; early-return false if mismatch.
3. Recurse on right subtrees; return final result.

## Other Patterns

### Pattern 1

**Idea**
Iterative BFS using a queue comparing node pairs.

**Pseudo Code**
```text
function isSameTree_BFS(p, q)
    create queue
    enqueue pair(p, q)
    while queue not empty
        (a, b) = dequeue
        if a is null and b is null
            continue
        if a is null or b is null
            return false
        if a.val != b.val
            return false
        enqueue pair(a.left, b.left)
        enqueue pair(a.right, b.right)
    return true
```

### Pattern 2

**Idea**
Iterative DFS using a stack comparing node pairs.

**Pseudo Code**
```text
function isSameTree_DFS(p, q)
    create stack
    push pair(p, q)
    while stack not empty
        (a, b) = pop
        if a is null and b is null
            continue
        if a is null or b is null
            return false
        if a.val != b.val
            return false
        push pair(a.right, b.right)
        push pair(a.left, b.left)
    return true
```

## Comparison

| Approach     | Idea                         | Time | Space       | Recommended |
| ------------ | ---------------------------- | ---- | ----------- | ----------- |
| Recursive    | DFS recursion per node       | O(n) | O(h)        | Yes         |
| Iterative BFS| Queue pairwise comparison    | O(n) | O(n)        | No (use if avoid recursion) |
| Iterative DFS| Stack pairwise comparison    | O(n) | O(n)        | Yes (explicit stack)
