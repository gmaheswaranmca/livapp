# Maximum Depth of Binary Tree

## Difficulty
Easy

## Description
Given the root of a binary tree, return its maximum depth (number of nodes along the longest path from the root node down to the farthest leaf node).

## Examples

### Example 1

```text
Input: [3,9,20,null,null,15,7]
Output: 3
Explanation: The longest path is 3 -> 20 -> 15 (or 3 -> 20 -> 7).
```

## Constraints

```text
The number of nodes is in the range [0, 10^4].
-1000 <= Node.val <= 1000
Depth may be up to number of nodes (recursion stack O(n)).
```

---

## Idea
Use DFS recursion: depth(node) = 0 if node is null else 1 + max(depth(left), depth(right)).

---

## Pseudo Code

```text
function solve(root)
    if root == null return 0
    leftDepth = solve(root.left)
    rightDepth = solve(root.right)
    return 1 + max(leftDepth, rightDepth)
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h) where h is tree height (O(n) worst-case recursion) |

---

## Code Explanation

### Dry Run

| Step | State                               | Operation                       | Result |
| ---- | ------------------------------------| ------------------------------- | ------ |
| 1    | root = 3                            | call solve(3)                   | recurse into left and right |
| 2    | node = 9                            | call solve(9)                   | left/right are null, return 1 |
| 3    | back to 3 after left                | leftDepth = 1                   | proceed to right child 20    |
| 4    | node = 20                           | call solve(20)                  | recurse into 15 and 7       |
| 5    | node = 15                           | call solve(15)                  | return 1                    |
| 6    | node = 7                            | call solve(7)                   | return 1                    |
| 7    | back to 20                          | rightDepth = 1, leftDepth = 1   | return 1 + max(1,1) = 2     |
| 8    | back to 3                           | leftDepth = 1, rightDepth = 2   | return 1 + max(1,2) = 3     |

## Other Patterns

### Pattern 1

**Idea**

Level-order BFS counting levels.

**Pseudo Code**

```text
function solve(root)
    if root == null return 0
    queue = empty queue
    enqueue root
    depth = 0
    while queue not empty
        levelSize = queue.size()
        for i from 1 to levelSize
            node = dequeue
            if node.left != null enqueue node.left
            if node.right != null enqueue node.right
        depth = depth + 1
    return depth
```

### Pattern 2

**Idea**

Iterative DFS with stack storing node and current depth.

**Pseudo Code**

```text
function solve(root)
    if root == null return 0
    stack = empty stack
    push (root, 1)
    maxDepth = 0
    while stack not empty
        (node, depth) = pop
        if node == null continue
        maxDepth = max(maxDepth, depth)
        if node.left != null push (node.left, depth + 1)
        if node.right != null push (node.right, depth + 1)
    return maxDepth
```

## Comparison

| Approach     | Idea                                 | Time | Space                        | Recommended |
| ------------ | ------------------------------------ | ---- | ---------------------------- | ----------- |
| Recursive DFS| Simple recursion computing max depth | O(n) | O(h) recursion stack         | Yes         |
| BFS Level-order | Traverse level by level counting levels | O(n) | O(w) where w is max width ~O(n) | Yes         |
| Iterative DFS| Stack with depth tracking            | O(n) | O(h) stack                   | No (but useful) |
