# Invert Binary Tree (LeetCode 226)

## Difficulty
Easy

## Description
Mirror the binary tree by swapping every node's left and right children.

## Examples

### Example 1

```text
Input:  [4,2,7,1,3,6,9]
Output: [4,7,2,9,6,3,1]
Explanation: Swap left and right recursively.
```

### Example 2

```text
Input:  []
Output: []
Explanation: Empty tree remains empty.
```

## Constraints

```text
The number of nodes is in the range [0, 10^4].
-10^5 <= Node.val <= 10^5
The tree nodes may be null.
```

---

## Idea
Recursively swap left and right child for each node (post-order or pre-order both work).

---

## Pseudo Code

```text
function invertTree(root)
    if root == null
        return null
    temp = root.left
    root.left = root.right
    root.right = temp
    invertTree(root.left)
    invertTree(root.right)
    return root
```

---

## Complexity

| Metric           | Value    |
| ---------------- | -------- |
| Time Complexity  | O(n)     |
| Space Complexity | O(h)     |

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | [4,2,7,1,3,6,9] (root=4) | Swap children of 4 | root becomes [4,7,2,6,9,1,3] conceptually then recurse |
| 2 | Subtree at node 7 ([7,6,9]) | Swap children of 7 | subtree becomes [7,9,6] |
| 3 | Subtree at node 2 ([2,1,3]) | Swap children of 2 | subtree becomes [2,3,1] |
| 4 | All nodes processed | Return root | Final tree [4,7,2,9,6,3,1] |

## Other Patterns

### Pattern 1

**Idea**
Iterative BFS: use a queue to visit nodes level-order and swap children at each node.

**Pseudo Code**

```text
function invertTree(root)
    if root == null
        return null
    q = new Queue()
    q.enqueue(root)
    while q is not empty
        node = q.dequeue()
        swap node.left and node.right
        if node.left != null
            q.enqueue(node.left)
        if node.right != null
            q.enqueue(node.right)
    return root
```

### Pattern 2

**Idea**
Iterative DFS: use a stack to traverse nodes and swap children when popped.

**Pseudo Code**

```text
function invertTree(root)
    if root == null
        return null
    st = new Stack()
    st.push(root)
    while st is not empty
        node = st.pop()
        swap node.left and node.right
        if node.left != null
            st.push(node.left)
        if node.right != null
            st.push(node.right)
    return root
```
