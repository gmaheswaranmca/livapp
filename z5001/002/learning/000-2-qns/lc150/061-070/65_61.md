# Rotate List

## Difficulty
Medium

## Description
Given the head of a singly linked list, rotate the list to the right by k places, where k is non-negative. Return the new head.

## Examples

### Example 1

```text
Input: head = [1,2,3,4,5], k = 2
Output: [4,5,1,2,3]
Explanation: Rotate right by 2.
```

### Example 2

```text
Input: head = [0,1,2], k = 4
Output: [2,0,1]
Explanation: k mod n = 1 -> rotate by 1.
```

## Constraints

```text
0 <= n <= 10^5
-10^5 <= Node.val <= 10^5
0 <= k <= 10^9
```

---

## Idea
Make the list cyclic then break at the (n - k % n)th node to form the new head.

---

## Pseudo Code

```text
function rotateList(head, k)
    if head == null or head.next == null or k == 0
        return head
    length = 1
    tail = head
    while tail.next != null
        tail = tail.next
        length = length + 1
    k = k % length
    if k == 0
        return head
    tail.next = head
    stepsToNewTail = length - k
    newTail = head
    for i = 1 to stepsToNewTail - 1
        newTail = newTail.next
    newHead = newTail.next
    newTail.next = null
    return newHead
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | head=[1,2,3,4,5] | find tail & length | tail->5, length=5 |
| 2    | k=2 | k = k % length | k = 2 |
| 3    | tail->5 | tail.next = head (make cycle) | cycle formed 1->2->3->4->5->1 |
| 4    | stepsToNewTail = 5-2 = 3 | move newTail 2 steps from head | newTail->3 |
| 5    | newHead = newTail.next | break cycle newTail.next = null | newHead->4, result [4,5,1,2,3] |

## Other Patterns

### Pattern 1

**Idea**

Rotate by moving tail->next = head repeatedly k times (brute force).

**Pseudo Code**

```text
function rotateListBrute(head, k)
    if head == null or head.next == null or k == 0
        return head
    length = computeLength(head)
    k = k % length
    for i = 1 to k
        prev = null
        cur = head
        while cur.next != null
            prev = cur
            cur = cur.next
        cur.next = head
        prev.next = null
        head = cur
    return head
```

### Pattern 2

**Idea**

Convert nodes to array, compute new head index, relink using array indices.

**Pseudo Code**

```text
function rotateListArray(head, k)
    if head == null or head.next == null or k == 0
        return head
    nodes = empty list
    cur = head
    while cur != null
        append cur to nodes
        cur = cur.next
    n = size(nodes)
    k = k % n
    if k == 0
        return head
    newHead = nodes[n - k]
    newTail = nodes[n - k - 1]
    nodes[n - 1].next = nodes[0]
    newTail.next = null
    return newHead
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Cycle break (main) | Make list cyclic and break at n-k | O(n) | O(1) | Yes |
| Brute force | Move tail to head k times | O(k·n) | O(1) | No |
| Array re-link | Store nodes in array and relink | O(n) | O(n) | No |
