# Title
Construct Binary Tree from Preorder and Inorder Traversal

## Difficulty
Medium

## Description
Given two integer arrays preorder and inorder where preorder is the preorder traversal of a binary tree and inorder is the inorder traversal of the same tree, construct and return the binary tree. Assume all values are unique.

## Examples

### Example 1

```text
Input: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
Output: [3,9,20,null,null,15,7]
Explanation: The constructed binary tree is:
    3
   / \
  9  20
    /  \
   15   7
```

### Example 2

```text
Input: preorder = [1,2], inorder = [2,1]
Output: [1,2]
Explanation: Root 1 with left child 2.
```

## Constraints

```text
1 <= preorder.length == inorder.length <= 3000
-10^4 <= preorder[i], inorder[i] <= 10^4
All values in preorder and inorder are unique.
inorder is a valid inorder traversal of the same tree given by preorder.
```

---

## Idea
Use preorder to pick root sequentially and a hashmap of inorder value->index to split left/right ranges in O(1).

---

## Pseudo Code

```text
function buildTree(preorder, inorder)
    if preorder is empty or inorder is empty then
        return null
    create map indexMap
    for i from 0 to length(inorder)-1
        indexMap[inorder[i]] = i
    set preorderIndex = 0
    return buildSubtree(0, length(inorder)-1)

function buildSubtree(left, right)
    if left > right then
        return null
    set rootVal = preorder[preorderIndex]
    increment preorderIndex by 1
    create node = TreeNode(rootVal)
    set inorderIndex = indexMap[rootVal]
    node.left = buildSubtree(left, inorderIndex - 1)
    node.right = buildSubtree(inorderIndex + 1, right)
    return node
```

## Code Explanation

### Dry Run

| Step | State (preorderIndex, preorder[0..]) | Operation | Result |
| ---- | ----------------------------------- | --------- | ------ |
| 1    | (0, [3,9,20,15,7])                  | pick root=3, inorderIndex=1 | node 3; build left [0..0], right [2..4] |
| 2    | (1, [9,20,15,7])                    | left subtree root=9, inorderIndex=0 | node 9 left null right null; attach to 3.left |
| 3    | (2, [20,15,7])                      | return to root; build right subtree root=20, inorderIndex=3 | node 20; left [2..2], right [4..4] |
| 4    | (3, [15,7])                         | left subtree of 20 root=15, inorderIndex=2 | node 15 attached to 20.left |
| 5    | (4, [7])                            | right subtree of 20 root=7, inorderIndex=4 | node 7 attached to 20.right |
| 6    | (5, [])                             | all nodes placed | final tree root=3 returned |

## Other Patterns

### Pattern 1

**Idea**

Recursive using slicing of arrays (simpler but O(n^2) worst-case due to copying).

**Pseudo Code**

```text
function buildTreeSlice(preorder, inorder)
    if preorder is empty then
        return null
    set rootVal = preorder[0]
    create node = TreeNode(rootVal)
    find idx where inorder[idx] == rootVal
    leftInorder = inorder[0..idx-1]
    rightInorder = inorder[idx+1..end]
    leftPreorder = preorder[1..1+length(leftInorder)]
    rightPreorder = preorder[1+length(leftInorder)..end]
    node.left = buildTreeSlice(leftPreorder, leftInorder)
    node.right = buildTreeSlice(rightPreorder, rightInorder)
    return node
```

### Pattern 2

**Idea**

Iterative stack-based reconstruction using preorder and inorder pointers.

**Pseudo Code**

```text
function buildTreeIterative(preorder, inorder)
    if preorder is empty then
        return null
    create root = TreeNode(preorder[0])
    create stack
    push root onto stack
    set inorderIndex = 0
    for i from 1 to length(preorder)-1
        set node = TreeNode(preorder[i])
        set top = stack.peek()
        if top.val != inorder[inorderIndex] then
            top.left = node
            push node
        else
            while stack not empty and stack.peek().val == inorder[inorderIndex]
                top = stack.pop()
                increment inorderIndex by 1
            top.right = node
            push node
    return root
```
