# Count Complete Tree Nodes

## Difficulty
Medium

## Description
Count the number of nodes in a complete binary tree using height comparison to avoid visiting every node.

## Examples

### Example 1

```text
Input: [1,2,3,4,5,6]
Output: 6
Explanation: The tree is complete and has 6 nodes.
```

## Constraints

```text
0 <= number of nodes <= 5 * 10^4
Tree is a complete binary tree.
Node values are irrelevant to the count.
Aim for better than O(n) when possible.
```

---

## Idea
Compare leftmost heights of left and right subtrees: if equal left subtree is perfect; otherwise right subtree is perfect — use counts directly and recurse on the other subtree.

---

## Pseudo Code

```text
function height(node)
    h = 0
    while node != null
        h = h + 1
        node = node.left
    return h

function countNodes(root)
    if root == null
        return 0
    leftH = height(root.left)
    rightH = height(root.right)
    if leftH == rightH
        nodesLeft = 2^leftH - 1
        return 1 + nodesLeft + countNodes(root.right)
    else
        nodesRight = 2^rightH - 1
        return 1 + nodesRight + countNodes(root.left)
```

---

## Complexity

| Metric           | Value            |
| ---------------- | ---------------- |
| Time Complexity  | O((log n)^2)     |
| Space Complexity | O(log n) stack   |

---

## Code Explanation

### Dry Run

| Step | State                          | Operation                                   | Result |
| ---- | ------------------------------ | ------------------------------------------- | ------ |
| 1    | root=1                         | leftH=2, rightH=2 (equal)                  | nodes = 1 + (2^2-1) + countNodes(3) => 4 + countNodes(3) |
| 2    | node=3                         | leftH=1, rightH=0 (not equal)              | nodes = 1 + (2^0-1) + countNodes(6) => 1 + countNodes(6) |
| 3    | node=6                         | leftH=0, rightH=0 (equal)                  | nodes = 1 + (2^0-1) + countNodes(null) => 1 |
| 4    | back to node=3                 | combine                                      | node3 count = 1 + 1 = 2 |
| 5    | back to root=1                 | combine                                      | total = 4 + 2 = 6 |

## Other Patterns

### Pattern 1

**Idea**

Simple DFS / BFS to visit every node and count.

**Pseudo Code**

```text
function countNodes(root)
    if root == null
        return 0
    stack = [root] or queue = [root]
    count = 0
    while stack not empty
        node = pop stack
        count = count + 1
        if node.left != null push node.left
        if node.right != null push node.right
    return count
```

### Pattern 2

**Idea**

Binary search on the last level using index bits to check existence; total time O(log n * log n).

**Pseudo Code**

```text
function exists(root, idx, depth)
    node = root
    left = 0
    right = 2^depth - 1
    for i from 0 to depth-1
        mid = (left + right) // 2
        if idx <= mid
            node = node.left
            right = mid
        else
            node = node.right
            left = mid + 1
        if node == null return false
    return true

function countNodes(root)
    if root == null return 0
    depth = height(root) - 1
    if depth < 0 return 0
    left = 0
    right = 2^depth - 1
    while left <= right
        mid = (left + right) // 2
        if exists(root, mid, depth) left = mid + 1 else right = mid - 1
    return (2^depth - 1) + left
```

## Comparison

| Approach | Idea                                    | Time             | Space        | Recommended |
| -------- | --------------------------------------- | ---------------- | ------------ | ----------- |
| Height comparison (main) | Use subtree heights to skip full subtrees | O((log n)^2)     | O(log n)     | Yes         |
| DFS/BFS                  | Visit every node                         | O(n)             | O(n)         | No (large n)|
| Binary search last level | Check existence by bit path             | O((log n)^2)     | O(1)         | Yes (alternative) |
