# Flatten Binary Tree to Linked List

## Difficulty
Medium

## Description
Given the root of a binary tree, flatten it to a "linked list" in-place following preorder traversal. The "linked list" should use the right pointers to point to the next node and all left pointers must be null.

## Examples

### Example 1

```text
Input: [1,2,5,3,4,null,6]
Output: [1,null,2,null,3,null,4,null,5,null,6]
Explanation: Preorder sequence 1,2,3,4,5,6 transformed into right-skewed list.
```

## Constraints

```text
The number of nodes in the tree is in the range [0, 10^4].
-10^5 <= Node.val <= 10^5
Must transform in-place: O(1) extra space desirable (excluding recursion).
```

---

## Idea
Process nodes in reverse preorder (right -> left -> node) maintaining a prev pointer to rewire right links into a flattened list.

---

## Pseudo Code

```text
function flatten(root)
    prev = null
    recurse(root)

function recurse(node)
    if node == null
        return
    recurse(node.right)
    recurse(node.left)
    node.right = prev
    node.left = null
    prev = node
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h) (recursion stack) |

---

## Code Explanation

### Dry Run

| Step | State (node visiting) | Operation | Result (prev after op and partial list) |
| ---- | --------------------- | --------- | --------------------------------------- |
| 1    | 6                     | set 6.right = null; 6.left = null; prev = 6 | prev = 6 -> [6] |
| 2    | 5                     | set 5.right = prev; 5.left = null; prev = 5 | prev = 5 -> [5 -> 6] |
| 3    | 4                     | set 4.right = prev; 4.left = null; prev = 4 | prev = 4 -> [4 -> 5 -> 6] |
| 4    | 3                     | set 3.right = prev; 3.left = null; prev = 3 | prev = 3 -> [3 -> 4 -> 5 -> 6] |
| 5    | 2                     | set 2.right = prev; 2.left = null; prev = 2 | prev = 2 -> [2 -> 3 -> 4 -> 5 -> 6] |
| 6    | 1                     | set 1.right = prev; 1.left = null; prev = 1 | prev = 1 -> [1 -> 2 -> 3 -> 4 -> 5 -> 6] |

1. Traverse right subtree first, then left subtree (reverse preorder).
2. For each node, link node.right to prev, set node.left = null, update prev to node.
3. After traversal, root points to flattened list via right pointers.

## Other Patterns

### Pattern 1

**Idea**

Iterative using stack to simulate preorder and rewire pointers.

**Pseudo Code**

```text
function flatten(root)
    if root == null
        return
    stack = empty stack
    push(stack, root)
    prev = null
    while stack not empty
        node = pop(stack)
        if prev != null
            prev.left = null
            prev.right = node
        if node.right != null
            push(stack, node.right)
        if node.left != null
            push(stack, node.left)
        prev = node
```

### Pattern 2

**Idea**

Morris-like O(1) space: for node with left child, attach rightmost of left subtree to node.right and move left to right.

**Pseudo Code**

```text
function flatten(root)
    node = root
    while node != null
        if node.left != null
            predecessor = node.left
            while predecessor.right != null
                predecessor = predecessor.right
            predecessor.right = node.right
            node.right = node.left
            node.left = null
        node = node.right
```

## Comparison

| Approach  | Idea                          | Time | Space    | Recommended |
| --------- | ----------------------------- | ---- | -------- | ----------- |
| Reverse preorder (rec) | Reverse preorder with prev pointer | O(n) | O(h) rec stack | Yes (simple) |
| Stack iterative        | Simulate preorder using stack     | O(n) | O(n)    | Yes (iterative) |
| Morris-like            | Rewire rightmost of left subtree  | O(n) | O(1)    | Yes (optimal space) |
