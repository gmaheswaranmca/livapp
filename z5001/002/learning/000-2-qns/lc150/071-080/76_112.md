# Path Sum

## Difficulty
Easy

## Description
Given the root of a binary tree and an integer targetSum, determine if the tree has a root-to-leaf path such that adding up all the values along the path equals targetSum. A leaf is a node with no children.

## Examples

### Example 1

```text
Input: root = [5,4,8,11, null,13,4,7,2], targetSum = 22
Output: true
Explanation: Path 5->4->11->2 sums to 22.
```

### Example 2

```text
Input: root = [1,2,3], targetSum = 5
Output: false
Explanation: No root-to-leaf path sums to 5.
```

## Constraints

```text
The number of nodes in the tree is in the range [0, 5000].
-1000 <= Node.val <= 1000
-10^9 <= targetSum <= 10^9
```

---

## Idea
Perform DFS from root, subtract node values from target until reaching a leaf and check if remainder equals zero.

---

## Pseudo Code

```text
function hasPathSum(root, targetSum)
    if root == null
        return false
    if root.left == null and root.right == null
        return (root.val == targetSum)
    return hasPathSum(root.left, targetSum - root.val) OR hasPathSum(root.right, targetSum - root.val)
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h)   |

---

## Code Explanation

### Dry Run

| Step | State                                  | Operation                        | Result                     |
| ---- | -------------------------------------- | -------------------------------- | -------------------------- |
| 1    | node=5, remaining=22                   | Not leaf; recurse left with 17   | Proceed to node 4          |
| 2    | node=4, remaining=17                   | Not leaf; recurse left with 13   | Proceed to node 11         |
| 3    | node=11, remaining=13                  | Not leaf; recurse left with 2    | Proceed to node 2          |
| 4    | node=2, remaining=2                    | Leaf and value == remaining      | Return true up the stack   |

1. If tree is empty return false.
2. At each node subtract node.val from targetSum and recurse.
3. If reaching a leaf check whether remainder equals node.val.
4. Return true if any path yields exact sum, otherwise false.

## Other Patterns

### Pattern 1

**Idea**

Iterative DFS using explicit stack storing (node, remainingSum).

**Pseudo Code**

```text
function hasPathSumIterative(root, targetSum)
    if root == null
        return false
    create stack
    push (root, targetSum - root.val) onto stack
    while stack not empty
        node, rem = pop stack
        if node.left == null and node.right == null and rem == 0
            return true
        if node.right != null
            push (node.right, rem - node.right.val) onto stack
        if node.left != null
            push (node.left, rem - node.left.val) onto stack
    return false
```

### Pattern 2

**Idea**

BFS level-order using queue to track remaining sum to leaves.

**Pseudo Code**

```text
function hasPathSumBFS(root, targetSum)
    if root == null
        return false
    create queue
    enqueue (root, targetSum - root.val)
    while queue not empty
        node, rem = dequeue queue
        if node.left == null and node.right == null and rem == 0
            return true
        if node.left != null
            enqueue (node.left, rem - node.left.val)
        if node.right != null
            enqueue (node.right, rem - node.right.val)
    return false
```

## Comparison

| Approach       | Idea                             | Time | Space | Recommended |
| -------------- | -------------------------------- | ---- | ----- | ----------- |
| Recursive DFS  | Subtract value on recursion      | O(n) | O(h)  | Yes         |

| BFS            | Queue with (node, remaining)     | O(n) | O(n)  | No          |
