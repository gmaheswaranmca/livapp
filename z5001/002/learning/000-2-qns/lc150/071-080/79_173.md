# Binary Search Tree Iterator

## Difficulty
Medium

## Description
Design an iterator over a binary search tree (BST) that returns the next smallest number. Methods: constructor(root), hasNext(), next(). Iterator should use O(h) memory where h is tree height and return elements in ascending order.

## Examples

### Example 1

```text
Input: 
BST = [7,3,15,null,null,9,20]
Operations = ["BSTIterator","next","next","hasNext","next","hasNext","next","hasNext","next","hasNext"]
Args = [[root],[],[],[],[],[],[],[],[],[]]

Output:
[null,3,7,true,9,true,15,true,20,false]

Explanation:
iterator = BSTIterator(root)
iterator.next() -> 3
iterator.next() -> 7
iterator.hasNext() -> true
iterator.next() -> 9
iterator.hasNext() -> true
iterator.next() -> 15
iterator.hasNext() -> true
iterator.next() -> 20
iterator.hasNext() -> false
```

## Constraints

```text
Number of nodes n: 0 <= n <= 10^5
Node values are unique (typical BST assumption).
Calls to next() and hasNext() <= 10^5
Allowed additional memory: O(h) where h is tree height
```

---

## Idea
Use a stack to perform controlled inorder traversal by pushing left spine; on next pop one node and push its right child's left spine.

---

## Pseudo Code

```text
class BSTIterator
    stack = empty stack

    function BSTIterator(root)
        call pushLeft(root)

    function pushLeft(node)
        while node != null
            stack.push(node)
            node = node.left

    function hasNext()
        return stack not empty

    function next()
        node = stack.pop()
        value = node.val
        if node.right != null
            call pushLeft(node.right)
        return value
```

---

## Complexity

| Metric           | Value               |
| ---------------- | ------------------- |
| Time Complexity  | O(1) amortized per next, O(h) worst-case per next |
| Space Complexity | O(h)                |

## Other Patterns

### Pattern 1

**Idea**

Precompute inorder list and iterate with index.

**Pseudo Code**

```text
class BSTIteratorArray
    arr = empty list
    idx = 0

    function BSTIteratorArray(root)
        call inorder(root)

    function inorder(node)
        if node == null return
        call inorder(node.left)
        arr.append(node.val)
        call inorder(node.right)

    function hasNext()
        return idx < arr.length

    function next()
        value = arr[idx]
        idx = idx + 1
        return value
```

### Pattern 2

**Idea**

Morris inorder traversal to achieve O(1) space (modifies tree temporarily).

**Pseudo Code**

```text
class BSTIteratorMorris
    current = root

    function BSTIteratorMorris(root)
        current = root

    function hasNext()
        return current != null

    function next()
        while current != null
            if current.left == null
                value = current.val
                current = current.right
                return value
            else
                predecessor = current.left
                while predecessor.right != null and predecessor.right != current
                    predecessor = predecessor.right
                if predecessor.right == null
                    predecessor.right = current
                    current = current.left
                else
                    predecessor.right = null
                    value = current.val
                    current = current.right
                    return value
```

## Comparison

| Approach            | Idea                        | Time                          | Space | Recommended |
| ------------------- | --------------------------- | ----------------------------- | ----- | ----------- |
| Stack Iterator      | Controlled inorder with stack| O(1) amortized per next, O(h) worst | O(h) | Yes         |
| Inorder Array       | Precompute all nodes        | O(1) per next after build; O(n) build | O(n) | No (if memory high) |
| Morris Traversal    | Threaded traversal O(1) space| O(1) amortized per next, complex | O(1) | No (modifies tree, complex) |
