# Title
Populating Next Right Pointers in Each Node II

## Difficulty
Medium

## Description
Given a binary tree where each node has an extra pointer "next", connect each node's next pointer to its next right node on the same level. If there is no next right node, set next to null. The tree is not necessarily perfect. Use only constant extra space (excluding recursion stack).

## Examples

### Example 1

```text
Input: root = [1,2,3,4,null,null,5]
Output: [1,#,2,3,#,4,5,#]
Explanation: After connection, 1->null, 2->3->null, 4->5->null.
```

### Example 2

```text
Input: root = []
Output: []
Explanation: Empty tree returns null.
```

## Constraints

```text
The number of nodes in the tree is in the range [0, 6000].
-100 <= Node.val <= 100
Use of recursion stack is allowed; otherwise extra space should be O(1).
```

---

## Idea
Use level-by-level traversal using already established next pointers and a dummy head to build the next level in O(1) extra space.

---

## Pseudo Code

```text
function connect(root)
    if root == null then
        return null
    current = root
    while current != null do
        dummy = new Node(0)
        prev = dummy
        node = current
        while node != null do
            if node.left != null then
                prev.next = node.left
                prev = prev.next
            if node.right != null then
                prev.next = node.right
                prev = prev.next
            node = node.next
        current = dummy.next
    return root
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(N)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (current, node, prev) | Operation | Result |
| ---- | --------------------------- | --------- | ------ |
| 1 | current=1, node=1, prev=dummy | connect 1.left=2 -> prev.next=2; connect 1.right=3 -> prev.next=3 | level1: 1.next=null; next level head = 2 |
| 2 | current=2, node=2->3, prev=dummy | node=2 connect left=4 -> prev.next=4; node=3 connect right=5 -> prev.next=5 | level2: 2.next=3; next level head = 4 |
| 3 | current=4, node=4->5, prev=dummy | nodes 4 and 5 have no children -> no connections created | level3: 4.next=5; end with current=null |

1. Start at root; use dummy to build next-level linked list via prev.
2. Traverse current level using node = node.next and attach children to prev.next.
3. After finishing a level set current = dummy.next and repeat until none.

## Other Patterns

### Pattern 1

**Idea**
Breadth-first traversal using a queue storing nodes level by level.

**Pseudo Code**

```text
function connect(root)
    if root == null then
        return null
    queue = new Queue()
    enqueue(queue, root)
    while queue is not empty do
        size = queue.size()
        prev = null
        for i from 1 to size do
            node = dequeue(queue)
            if prev != null then
                prev.next = node
            prev = node
            if node.left != null then
                enqueue(queue, node.left)
            if node.right != null then
                enqueue(queue, node.right)
        prev.next = null
    return root
```

### Pattern 2

**Idea**
Recursive approach that uses next pointers to connect children across subtrees by processing right-to-left.

**Pseudo Code**

```text
function connect(root)
    if root == null then
        return null
    if root.left != null and root.right != null then
        root.left.next = root.right
    nextChild = findNextChild(root.next)
    if root.right != null then
        child = root.right
    else if root.left != null then
        child = root.left
    else
        child = null
    if child != null then
        child.next = nextChild
    connect(root.right)
    connect(root.left)
    return root

function findNextChild(node)
    while node != null do
        if node.left != null then
            return node.left
        if node.right != null then
            return node.right
        node = node.next
    return null
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Iterative using next pointers | Dummy head + traverse levels using next | O(N) | O(1) | Yes |
| BFS with queue | Level-order using queue | O(N) | O(N) | No (extra space) |
| Recursive right-to-left | Use recursion and next pointer lookup | O(N) | O(H) (recursion) | Conditional (if recursion allowed) |
