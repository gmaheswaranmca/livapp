# Construct Binary Tree from Inorder and Postorder Traversal

## Difficulty
Medium

## Description
Given inorder and postorder traversal arrays of a binary tree with unique values, reconstruct the binary tree and return its root.

## Examples

### Example 1

```text
Input: inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
Output: Root of binary tree:
    3
   / \
  9  20
    /  \
   15   7
Explanation: Root is last of postorder (3). Split inorder at 3 => left [9], right [15,20,7]. Recur accordingly.
```

### Example 2

```text
Input: inorder = [2,1], postorder = [2,1]
Output: Root of binary tree:
  1
 /
2
Explanation: Root 1, left subtree [2], no right subtree.
```

## Constraints

```text
1 <= inorder.length == postorder.length <= 10^4
Values are unique.
Arrays represent valid traversals of a binary tree.
```

---

## Idea
Use postorder's last element as root and recurse; use a hashmap for inorder index lookup and build right subtree before left to consume postorder from end.

---

## Pseudo Code

```text
function buildTree(inorder, postorder)
    n = length(inorder)
    if n == 0 return null
    idx_map = empty map
    for i from 0 to n-1
        idx_map[inorder[i]] = i
    postIndex = n - 1
    return build(0, n - 1)

function build(in_left, in_right)
    if in_left > in_right return null
    root_val = postorder[postIndex]
    postIndex = postIndex - 1
    root = new TreeNode(root_val)
    idx = idx_map[root_val]
    root.right = build(idx + 1, in_right)
    root.left = build(in_left, idx - 1)
    return root
```

| Metric           | Value  |

| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

## Code Explanation

### Dry Run

| Step | postIndex | Picked root_val | inorder range | Operation | Result |
| ---- | --------- | --------------- | ------------- | --------- | ------ |
| 1    | 4         | 3               | [0..4]        | create root 3; idx=1; build right [2..4] then left [0..0] | partial tree: 3 |
| 2    | 3         | 20              | [2..4]        | create root 20; idx=3; build right [4..4] then left [2..2] | 3->right=20 |
| 3    | 2         | 7               | [4..4]        | create leaf 7; return | 20->right=7 |
| 4    | 1         | 15              | [2..2]        | create leaf 15; return | 20->left=15 |
| 5    | 0         | 9               | [0..0]        | create leaf 9; return | 3->left=9; finished |

1. Build map of inorder values to indices for O(1) lookup.
2. Use global postIndex starting at end of postorder.
3. Each recursion picks postorder[postIndex] as root and decrements it.
4. Recurse right first then left using inorder split index.

## Other Patterns

### Pattern 1

**Idea**

Recursion without hashmap using linear search for inorder split index.

**Pseudo Code**

```text
function buildTree(inorder, postorder)
    postIndex = length(postorder) - 1
    return build(0, length(inorder) - 1)

function build(in_left, in_right)
    if in_left > in_right return null
    root_val = postorder[postIndex]
    postIndex = postIndex - 1
    root = new TreeNode(root_val)
    idx = find index of root_val in inorder between in_left and in_right (linear scan)
    root.right = build(idx + 1, in_right)
    root.left = build(in_left, idx - 1)
    return root
```

### Pattern 2

**Idea**

Iterative using stack processing postorder from end and using inorder pointer from end.

**Pseudo Code**

```text
function buildTree(inorder, postorder)
    if postorder is empty return null
    root = new TreeNode(postorder[last])
    stack = empty stack
    push stack root
    inIndex = length(inorder) - 1
    for i from length(postorder) - 2 down to 0
        node = new TreeNode(postorder[i])
        top = stack.peek()
        if top.value != inorder[inIndex]
            top.right = node
            push stack node
        else
            while stack not empty and stack.peek().value == inorder[inIndex]
                top = stack.pop()
                inIndex = inIndex - 1
            top.left = node
            push stack node
    return root
```

## Comparison

| Approach               | Idea                                      | Time     | Space    | Recommended |
| ---------------------- | ----------------------------------------- | -------- | -------- | ----------- |
| Hashmap Recursion      | Use map for inorder index and recurse R then L | O(n)     | O(n)     | Yes        |
| Naive Recursion        | Linear search for split index             | O(n^2)   | O(n)     | No         |
| Iterative Stack        | Build iteratively using stack and pointers | O(n)     | O(n)     | Yes (when recursion is constrained) |
