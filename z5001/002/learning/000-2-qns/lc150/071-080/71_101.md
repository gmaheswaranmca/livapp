# Symmetric Tree

## Difficulty
Easy

## Description
Given the root of a binary tree, check whether it is a mirror of itself (symmetric around its center).

## Examples

### Example 1

```text
Input: [1,2,2,3,4,4,3]
Output: true
Explanation: Left subtree and right subtree are mirror images.
```

### Example 2

```text
Input: [1,2,2,null,3,null,3]
Output: false
Explanation: Structure/values are not mirror-symmetric.
```

## Constraints

```text
0 <= number of nodes <= 1000
-100 <= Node.val <= 100
Tree may be null (empty tree is symmetric)
```

---

## Idea
Compare left and right subtrees recursively as mirror pairs.

---

## Pseudo Code

```text
function isSymmetric(root)
    if root is null
        return true
    return isMirror(root.left, root.right)

function isMirror(left, right)
    if left is null and right is null
        return true
    if left is null or right is null
        return false
    if left.val != right.val
        return false
    return isMirror(left.left, right.right) and isMirror(left.right, right.left)
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h)   |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | root=(1) left=2 right=2 | call isMirror(2,2) | proceed as vals equal |
| 2    | compare left.left=3 and right.right=3 | isMirror(3,3) | true |
| 3    | compare left.right=4 and right.left=4 | isMirror(4,4) | true |
| 4    | all mirror pairs matched | unwind recursion | return true |

## Other Patterns

### Pattern 1

**Idea**

Iterative BFS using a queue to compare node pairs.

**Pseudo Code**

```text
function isSymmetricIterative(root)
    if root is null
        return true
    create queue
    enqueue(queue, root.left)
    enqueue(queue, root.right)
    while queue not empty
        left = dequeue(queue)
        right = dequeue(queue)
        if left is null and right is null
            continue
        if left is null or right is null
            return false
        if left.val != right.val
            return false
        enqueue(queue, left.left)
        enqueue(queue, right.right)
        enqueue(queue, left.right)
        enqueue(queue, right.left)
    return true
```
