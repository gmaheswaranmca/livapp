# Title
Sum Root to Leaf Numbers

## Difficulty
Medium

## Description
Given a binary tree where each node contains a single digit (0-9), each root-to-leaf path represents a number formed by concatenating node digits along the path. Return the total sum of all root-to-leaf numbers.

## Examples

### Example 1

```text
Input: [1,2,3]
Output: 25
Explanation: Root-to-leaf numbers are 12 and 13. Sum = 12 + 13 = 25.
```

### Example 2

```text
Input: [4,9,0,5,1]
Output: 1026
Explanation: Numbers are 495, 491, 40. Sum = 495 + 491 + 40 = 1026.
```

## Constraints

```text
The number of nodes n: 1 <= n <= 10^4
Node.val is an integer in [0,9]
Tree height h: 1 <= h <= n
Result fits in 32/64-bit integer depending on environment
```

---

## Idea
DFS accumulate current number = parentNum * 10 + node.val; add to sum when node is leaf.

---

## Pseudo Code

```text
function sumRootToLeaf(root)
    if root is null then return 0
    return dfs(root, 0)

function dfs(node, current)
    if node is null then return 0
    current = current * 10 + node.val
    if node.left is null AND node.right is null then return current
    leftSum = dfs(node.left, current)
    rightSum = dfs(node.right, current)
    return leftSum + rightSum
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(h)   |

---

## Code Explanation

1. Start DFS from root with current number 0.
2. At each node update current = current*10 + node.val.
3. If node is leaf add current to total.
4. Recursively sum left and right subtree values.

### Dry Run

| Step | State                     | Operation                              | Result    |
| ---- | ------------------------- | -------------------------------------- | --------- |
| 1    | node=1, current=0         | current = 0*10 + 1                     | current=1 |
| 2    | node=2 (left), current=1  | current = 1*10 + 2                     | current=12|
| 3    | node=2 is leaf            | return current                         | 12        |
| 4    | node=3 (right), current=1 | current = 1*10 + 3                     | current=13|
| 5    | node=3 is leaf            | return current                         | 13        |
| 6    | root combine               | return 12 + 13                         | 25        |

## Other Patterns

### Pattern 1

**Idea**
Iterative DFS using explicit stack storing (node, current).

**Pseudo Code**

```text
function sumRootToLeafIterative(root)
    if root is null then return 0
    total = 0
    stack = empty stack
    push (root, root.val) on stack
    while stack not empty
        (node, current) = pop stack
        if node.left is null AND node.right is null then
            total = total + current
            continue
        if node.right is not null then
            push (node.right, current * 10 + node.right.val) on stack
        if node.left is not null then
            push (node.left, current * 10 + node.left.val) on stack
    return total
```

### Pattern 2

**Idea**
BFS level-order accumulating numbers in queue.

**Pseudo Code**

```text
function sumRootToLeafBFS(root)
    if root is null then return 0
    total = 0
    queue = empty queue
    enqueue (root, root.val) into queue
    while queue not empty
        (node, current) = dequeue queue
        if node.left is null AND node.right is null then
            total = total + current
            continue
        if node.left is not null then
            enqueue (node.left, current * 10 + node.left.val)
        if node.right is not null then
            enqueue (node.right, current * 10 + node.right.val)
    return total
```

## Comparison

| Approach           | Idea                                     | Time | Space | Recommended |
| ------------------ | ----------------------------------------- | ---- | ----- | ----------- |
| Recursive DFS      | Build number along recursion              | O(n) | O(h)  | Yes         |
| Iterative DFS      | Stack with (node,current)                 | O(n) | O(h)  | Yes         |
| BFS (queue)        | Level-order with current numbers in queue | O(n) | O(n)  | No (space)  |
