# Valid Sudoku

## Difficulty
Medium

## Description
Determine whether a partially filled 9×9 Sudoku board is valid. A valid board means no digit 1-9 appears more than once in any row, any column, or any of the nine 3×3 sub-boxes. Empty cells are denoted by '.' and are ignored.

## Examples

### Example 1

```text
Input:
board = [
 ["5","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]
]
Output: true
Explanation: No duplicates in any row, column, or 3×3 box.
```

### Example 2

```text
Input:
board = [
 ["8","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]
]
Output: false
Explanation: '8' repeats in the first column and top-left 3×3 box.
```

## Constraints

```text
board.length == 9
board[i].length == 9
board[i][j] is '.' or a digit '1' to '9'
```

---

## Idea
Use three collections of sets to track seen digits for each row, each column, and each 3×3 box; if any digit is already present when encountered, board is invalid.

---

## Pseudo Code

```text
function isValidSudoku(board)
    initialize rows[9] as empty sets
    initialize cols[9] as empty sets
    initialize boxes[9] as empty sets
    for r from 0 to 8
        for c from 0 to 8
            val = board[r][c]
            if val == '.' then continue
            boxIndex = (r / 3) * 3 + (c / 3)
            if val in rows[r] then return false
            add val to rows[r]
            if val in cols[c] then return false
            add val to cols[c]
            if val in boxes[boxIndex] then return false
            add val to boxes[boxIndex]
    return true
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(1) -> O(9*9) => O(1) (practically O(n^2) where n=9) |
| Space Complexity | O(1) -> O(3*9*9) => O(1) (auxiliary sets bounded by constant) |

## Code Explanation

### Dry Run

| Step | State (r,c) | Operation | Result |
| ---- | ----------- | --------- | ------ |
| 1    | (0,0)       | val='5', boxIndex=0, check sets | add '5' to rows[0], cols[0], boxes[0] |
| 2    | (0,1)       | val='3', boxIndex=0, check sets | add '3' to rows[0], cols[1], boxes[0] |
| 3    | (0,2)       | val='.', skip | no change |
| 4    | (3,0)       | val='8', boxIndex=3, check sets | add '8' to rows[3], cols[0], boxes[3] |
| 5    | (3,0) repeat in invalid board | val='8' found already in cols[0] or boxes[3] | return false |

1. Iterate every cell once.
2. For each non-empty value compute box index as (r/3)*3+(c/3).
3. Check membership in three sets; if found, invalidate.
4. Insert value into corresponding row, column, and box sets.
5. If finished without conflict return true.

## Other Patterns

### Pattern 1

**Idea**
Use bitmasks (integers) for rows, columns, and boxes to record seen digits compactly.

**Pseudo Code**

```text
function isValidSudokuBitmask(board)
    initialize rowMask[9]=0, colMask[9]=0, boxMask[9]=0
    for r from 0 to 8
        for c from 0 to 8
            val = board[r][c]
            if val == '.' then continue
            bit = 1 << (val - '1')
            boxIndex = (r / 3) * 3 + (c / 3)
            if (rowMask[r] & bit) != 0 then return false
            rowMask[r] = rowMask[r] | bit
            if (colMask[c] & bit) != 0 then return false
            colMask[c] = colMask[c] | bit
            if (boxMask[boxIndex] & bit) != 0 then return false
            boxMask[boxIndex] = boxMask[boxIndex] | bit
    return true
```

### Pattern 2

**Idea**
Use boolean 3D array seen[3][9][10] to mark presence for rows/cols/boxes.

**Pseudo Code**

```text
function isValidSudokuBool(board)
    initialize seen[3][9][10] to false
    for r from 0 to 8
        for c from 0 to 8
            val = board[r][c]
            if val == '.' then continue
            d = int(val)
            boxIndex = (r / 3) * 3 + (c / 3)
            if seen[0][r][d] then return false
            seen[0][r][d] = true
            if seen[1][c][d] then return false
            seen[1][c][d] = true
            if seen[2][boxIndex][d] then return false
            seen[2][boxIndex][d] = true
    return true
```
