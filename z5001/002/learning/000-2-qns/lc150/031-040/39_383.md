# Ransom Note

## Difficulty
Easy

## Description
Determine if ransomNote can be constructed from the letters in magazine. Each letter in magazine can be used at most once.

## Examples

### Example 1

```text
Input: ransomNote = "aa", magazine = "aab"
Output: true
Explanation: magazine has two 'a's so ransomNote can be constructed.
```

## Constraints

```text
1 <= ransomNote.length, magazine.length <= 10^5
ransomNote and magazine consist of lowercase English letters.
```

---

## Idea
Count character frequencies in magazine and ensure ransomNote's required counts do not exceed them.

---

## Pseudo Code

```text
function canConstruct(ransomNote, magazine)
    create array counts[26] initialized to 0
    for each char c in magazine
        counts[c - 'a'] = counts[c - 'a'] + 1
    for each char c in ransomNote
        counts[c - 'a'] = counts[c - 'a'] - 1
        if counts[c - 'a'] < 0
            return false
    return true
```

---

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(n + m)    |
| Space Complexity | O(1) (26)   |

---

## Code Explanation

### Dry Run

| Step | State (counts for a,b,c,...) | Operation                                | Result                       |
| ---- | ---------------------------- | ---------------------------------------- | ---------------------------- |
| 1    | all zeros                    | process magazine "aab": +1 for 'a', +1 for 'a', +1 for 'b' | counts['a']=2, counts['b']=1 |
| 2    | counts as above              | process ransomNote "aa": -1 for 'a'      | counts['a']=1                |
| 3    | counts updated               | process next 'a': -1 for 'a'             | counts['a']=0; no negatives  |
| 4    | final                        | no negative seen                          | return true                  |

## Other Patterns

### Pattern 1

**Idea**
Use a hashmap to count magazine letters and check ransomNote requirements.

**Pseudo Code**

```text
function canConstruct(ransomNote, magazine)
    create map counts
    for each char c in magazine
        counts[c] = counts.get(c, 0) + 1
    for each char c in ransomNote
        if counts.get(c, 0) == 0
            return false
        counts[c] = counts[c] - 1
    return true
```

### Pattern 2

**Idea**
Sort both strings and use two pointers to match letters.

**Pseudo Code**

```text
function canConstruct(ransomNote, magazine)
    sort ransomNote into R
    sort magazine into M
    i = 0
    j = 0
    while i < len(R) and j < len(M)
        if R[i] == M[j]
            i = i + 1
            j = j + 1
        else
            j = j + 1
    return i == len(R)
```

## Comparison

| Approach     | Idea                                   | Time       | Space      | Recommended |
| ------------ | -------------------------------------- | ---------- | ---------- | ----------- |
| Count array  | Fixed-size 26 frequency array          | O(n + m)   | O(1)       | Yes         |
| HashMap      | Dynamic frequency map                  | O(n + m)   | O(k)       | No (equal)  |
| Sort & Two‑ptr | Sort both strings then match         | O(n log n) | O(1) / O(n)| No          |
