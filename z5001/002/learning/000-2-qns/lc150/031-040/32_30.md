# Substring with Concatenation of All Words

## Difficulty
Hard

## Description
Given a string s and an array of equal-length words, find all starting indices of substring(s) in s that is a concatenation of each word in words exactly once and without any intervening characters. Words can appear in any order.

## Examples

### Example 1

```text
Input: s = "barfoothefoobarman", words = ["foo","bar"]
Output: [0,9]
Explanation: Substrings starting at 0 -> "barfoo" and 9 -> "foobar" are concatenations.
```

### Example 2

```text
Input: s = "wordgoodgoodgoodbestword", words = ["word","good","best","word"]
Output: []
Explanation: No substring contains each word exactly once.
```

## Constraints

```text
1 <= s.length <= 10000
1 <= words.length <= 5000
1 <= words[i].length <= 30
All words have the same length.
Return indices in any order.
```

---

## Idea
Use a fixed-length sliding window across k offsets (k = word length) and maintain a running frequency map to match word counts.

---

## Pseudo Code

```text
function findSubstring(s, words)
    if s is empty or words is empty: return []
    k = length(words[0])
    m = length(words)
    totalLen = k * m
    if length(s) < totalLen: return []
    wordCount = empty map
    for each w in words
        increment wordCount[w]
    result = empty list
    for offset from 0 to k-1
        left = offset
        count = 0
        current = empty map
        j = offset
        while j + k <= length(s)
            w = substring(s, j, j + k)
            if w in wordCount
                increment current[w]
                if current[w] <= wordCount[w]
                    count = count + 1
                else
                    while current[w] > wordCount[w]
                        leftWord = substring(s, left, left + k)
                        decrement current[leftWord]
                        left = left + k
                        if current[leftWord] < wordCount[leftWord]
                            count = count - 1
                if count == m
                    append left to result
                    leftWord = substring(s, left, left + k)
                    decrement current[leftWord]
                    left = left + k
                    count = count - 1
            else
                clear current
                count = 0
                left = j + k
            j = j + k
    return result
```

---

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(n * m)    |
| Space Complexity | O(m)        |

Notation: n = length(s), m = number of words (wordCount size). Each offset scans s in steps of word length; map ops are O(1) amortized.

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | left=0, j=0, current={}, count=0 | read w="bar" (in map) | current={"bar":1}, count=1 |
| 2 | left=0, j=3, current={"bar":1}, count=1 | read w="foo" (in map) | current={"bar":1,"foo":1}, count=2 -> count==m append 0 -> remove left "bar" | result=[0], left=3, current={"bar":0,"foo":1}, count=1 |
| 3 | left=3, j=6 | read w="the" (not in map) | clear current, count=0, left=9 |
| 4 | left=9, j=9 | read w="foo" | current={"foo":1}, count=1 |
| 5 | left=9, j=12 | read w="bar" | current={"foo":1,"bar":1}, count=2 -> append 9 | result=[0,9] |

1. Iterate k offsets to cover all alignments.
2. For each offset use window of word-size steps.
3. Expand by adding word at j; if overflow over expected count, shrink from left until valid.
4. When matched count == m record left index and move window forward by one word.

## Other Patterns

### Pattern 1

**Idea**
Brute force: check each possible start and validate m consecutive words by counting.

**Pseudo Code**

```text
function findSubstring_bruteforce(s, words)
    if s is empty or words is empty: return []
    k = length(words[0])
    m = length(words)
    totalLen = k * m
    if length(s) < totalLen: return []
    wordCount = map counts of words
    result = empty list
    for i from 0 to length(s) - totalLen
        seen = empty map
        valid = true
        for j from 0 to m-1
            w = substring(s, i + j*k, i + (j+1)*k)
            if w not in wordCount: valid = false; break
            increment seen[w]
            if seen[w] > wordCount[w]: valid = false; break
        if valid: append i to result
    return result
```

### Pattern 2

**Idea**
Use rolling-hash per word (Rabin-Karp) to convert words to integer IDs then apply sliding window with integer comparisons.

**Pseudo Code**

```text
function findSubstring_hash(s, words)
    if s is empty or words is empty: return []
    k = length(words[0])
    m = length(words)
    totalLen = k * m
    if length(s) < totalLen: return []
    mapWordID = map word -> id using hash table or Rabin-Karp
    wordCountID = counts by id
    convert s into list of ids per k-block with sentinel for non-matching
    for each offset from 0 to k-1
        apply same sliding-window over id-list using integer maps
    return result
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Sliding Window (chosen) | Multi-offset window with word-frequency maps | O(n * m) | O(m) | Yes |
| Brute Force | Check every start by validating m words | O(n * m) | O(m) | No |
| Rolling Hash (RK + ids) | Map words to ids using rolling hash then sliding window on ids | O(n * m) amortized | O(m) | No (more complex) |
