# Set Matrix Zeroes

## Difficulty
Medium

## Description
Given an m x n matrix. If an element is 0, set its entire row and column to 0 in-place.

## Examples

### Example 1
```text
Input: [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
Explanation: Use first row and first column as markers and update in-place.
```

### Example 2
```text
Input: [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
Explanation: Zeroes in first row/col handled with flags, rest marked and applied.
```

## Constraints
```text
1 <= m, n <= 200
matrix[i][j] is an integer
Modify matrix in-place
```

---

## Idea
Use first row and first column as marker arrays; track if first row/column originally contained zero with two flags.

---

## Pseudo Code
```text
function setMatrixZeroes(matrix)
    if matrix is empty return
    m := number of rows in matrix
    n := number of columns in matrix
    firstRowZero := false
    firstColZero := false
    for j from 0 to n-1
        if matrix[0][j] == 0 then firstRowZero := true
    for i from 0 to m-1
        if matrix[i][0] == 0 then firstColZero := true
    for i from 1 to m-1
        for j from 1 to n-1
            if matrix[i][j] == 0 then
                matrix[i][0] := 0
                matrix[0][j] := 0
    for i from 1 to m-1
        for j from 1 to n-1
            if matrix[i][0] == 0 or matrix[0][j] == 0 then matrix[i][j] := 0
    if firstRowZero then
        for j from 0 to n-1
            matrix[0][j] := 0
    if firstColZero then
        for i from 0 to m-1
            matrix[i][0] := 0
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(1) (in-place) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | [[1,1,1],[1,0,1],[1,1,1]] | Scan first row/col | firstRowZero=false, firstColZero=false |
| 2 | same | Marking pass (i,j from 1) sees matrix[1][1]==0 | set matrix[1][0]=0 and matrix[0][1]=0 -> [[1,0,1],[0,0,1],[1,1,1]] |
| 3 | [[1,0,1],[0,0,1],[1,1,1]] | Apply markers to inner cells | matrix becomes [[1,0,1],[0,0,0],[1,0,1]] |
| 4 | [[1,0,1],[0,0,0],[1,0,1]] | firstRowZero/firstColZero false so no change | Final matrix unchanged |

1. Use two boolean flags to remember if first row or column had zeros originally.
2. Use first row and column as markers by scanning inner matrix.
3. Apply markers to set inner cells to zero.
4. Finally set first row/column to zero if their flags are true.

## Other Patterns

### Pattern 1

**Idea**
Use two boolean arrays rows[m] and cols[n] to record zero rows and columns.

**Pseudo Code**
```text
function setMatrixZeroesRowsCols(matrix)
    m := number of rows
    n := number of columns
    rows := array of m false
    cols := array of n false
    for i from 0 to m-1
        for j from 0 to n-1
            if matrix[i][j] == 0 then rows[i] := true; cols[j] := true
    for i from 0 to m-1
        for j from 0 to n-1
            if rows[i] or cols[j] then matrix[i][j] := 0
```

### Pattern 2

**Idea**
Create a copy of matrix and use it as reference to avoid modifying original while deciding zeros.

**Pseudo Code**
```text
function setMatrixZeroesCopy(matrix)
    m := number of rows
    n := number of columns
    copy := deep copy of matrix
    for i from 0 to m-1
        for j from 0 to n-1
            if copy[i][j] == 0 then
                for c from 0 to n-1 do matrix[i][c] := 0
                for r from 0 to m-1 do matrix[r][j] := 0
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| In-place markers | Use first row/col as markers with two flags | O(m*n) | O(1) | Yes |
| Row & Col arrays | Use boolean arrays to record zeros | O(m*n) | O(m + n) | No (if O(1) required) |
| Copy matrix | Work on a copy, write zeros to original | O(m*n + cost of copies) | O(m*n) | No |
