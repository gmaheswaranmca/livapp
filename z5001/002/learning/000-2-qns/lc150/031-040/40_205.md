# Title
Isomorphic Strings

## Difficulty
Easy

## Description
Check if characters in one string can map uniquely to characters in another string such that applying the mapping to the first string yields the second string. Mapping must be bijective (one-to-one and onto for used characters).

## Examples

### Example 1

```text
Input: s = "egg", t = "add"
Output: true
Explanation: e -> a, g -> d
```

### Example 2

```text
Input: s = "foo", t = "bar"
Output: false
Explanation: f -> b, o -> a and o -> r conflict
```

## Constraints

```text
1 <= s.length == t.length <= 10^5
Characters can be any valid Unicode code points; algorithm should handle general character sets.
Expected extra space O(k) where k is number of distinct characters (<= length).
```

---

## Idea
Maintain a bijection using two maps (s->t and t->s) and verify consistency for each character pair.

---

## Pseudo Code

```text
function isIsomorphic(s, t)
    if length(s) != length(t) return false
    mapS = empty map
    mapT = empty map
    for i from 0 to length(s)-1
        cs = s[i]
        ct = t[i]
        if cs in mapS and mapS[cs] != ct return false
        if ct in mapT and mapT[ct] != cs return false
        mapS[cs] = ct
        mapT[ct] = cs
    return true
```

---

## Complexity

| Metric           | Value        |
| ---------------- | ------------ |
| Time Complexity  | O(n)         |
| Space Complexity | O(k) where k is number of distinct characters |

---

## Code Explanation

### Dry Run

| Step | State (mapS, mapT)       | Operation                | Result                         |
| ---- | ------------------------ | ------------------------ | ------------------------------ |
| 1    | ({}, {})                 | compare 'e' with 'a'     | mapS={'e':'a'}, mapT={'a':'e'} |
| 2    | ({'e':'a'}, {'a':'e'})   | compare 'g' with 'd'     | mapS={'e':'a','g':'d'}         |
| 3    | ({'e':'a','g':'d'}, {'a':'e','d':'g'}) | compare 'g' with 'd' | consistent, return true        |

## Other Patterns

### Pattern 1

**Idea**
Use last-seen indices arrays to ensure both characters appeared previously at same positions.

**Pseudo Code**

```text
function isIsomorphic_lastSeen(s, t)
    if length(s) != length(t) return false
    create mapLastS empty map default -1
    create mapLastT empty map default -1
    for i from 0 to length(s)-1
        cs = s[i]
        ct = t[i]
        if mapLastS[cs] != mapLastT[ct] return false
        mapLastS[cs] = i
        mapLastT[ct] = i
    return true
```

### Pattern 2

**Idea**
Normalize both strings to canonical pattern labels and compare normalized forms.

**Pseudo Code**

```text
function normalize(s)
    mapCharToLabel = empty map
    nextLabel = 0
    labels = empty list
    for ch in s
        if ch not in mapCharToLabel
            mapCharToLabel[ch] = nextLabel
            nextLabel = nextLabel + 1
        append labels mapCharToLabel[ch]
    return labels

function isIsomorphic_normalize(s, t)
    if length(s) != length(t) return false
    return normalize(s) == normalize(t)
```

## Comparison

| Approach                | Idea                                         | Time  | Space         | Recommended |
| ----------------------- | -------------------------------------------- | ----- | ------------- | ----------- |
| Two maps (main)         | Maintain bijection with two maps             | O(n)  | O(k)          | Yes         |
| Last-seen indices       | Track last seen positions for characters     | O(n)  | O(k)          | Yes (mem-opt for small alphabets) |
| Normalize to labels     | Convert strings to canonical labels then cmp | O(n)  | O(k)          | No (extra step) |
