# Minimum Window Substring

## Difficulty
Hard

## Description
Given strings s and t, find the smallest substring of s that contains all characters of t (including multiplicity). Return empty string if no such substring exists.

## Examples

### Example 1

```text
Input: s="ADOBECODEBANC", t="ABC"
Output: "BANC"
Explanation: "BANC" is the shortest substring containing 'A','B','C'.
```

### Example 2

```text
Input: s="a", t="aa"
Output: ""
Explanation: s does not contain two 'a' characters.
```

## Constraints

```text
1 <= s.length, t.length <= 10^5
s and t consist of ASCII characters.
If no valid window exists return "".
```

---

## Idea
Use a two-pointer sliding window: expand to cover all required chars, then shrink to minimize while still covering.

---

## Pseudo Code

```text
function solve(s, t)
    if s is empty or t is empty then return ""

    need <- empty map
    for each char in t
        need[char] <- need.get(char, 0) + 1

    window <- empty map
    required <- number of unique keys in need
    formed <- 0
    left <- 0
    minLen <- INF
    minLeft <- 0

    for right from 0 to len(s)-1
        ch <- s[right]
        window[ch] <- window.get(ch, 0) + 1
        if ch in need and window[ch] == need[ch] then
            formed <- formed + 1

        while left <= right and formed == required
            if (right - left + 1) < minLen then
                minLen <- right - left + 1
                minLeft <- left
            leftChar <- s[left]
            window[leftChar] <- window[leftChar] - 1
            if leftChar in need and window[leftChar] < need[leftChar] then
                formed <- formed - 1
            left <- left + 1

    if minLen == INF then return "" else return s.substring(minLeft, minLeft + minLen)
```

---

## Complexity

| Metric           | Value              |
| ---------------- | ------------------ |
| Time Complexity  | O(|s| + |t|)       |
| Space Complexity | O(k) where k is number of distinct chars (<= alphabet size) |

---

## Code Explanation

1. Build need map counting chars in t and set required as number of distinct required chars.  
2. Expand right pointer, update window counts and increment formed when a char's count meets need.  
3. When formed == required, attempt to shrink left to minimize window while maintaining validity; update best window.  
4. After scanning, return best substring or empty string.

### Dry Run

| Step | State (left..right) | Operation | Result |
| ---- | ------------------- | --------- | ------ |
| 1    | (0..5) "ADOBEC"     | expand until right=5 when 'C' added -> formed becomes 3 | valid window "ADOBEC", minLen=6, shrink left -> remove 'A' -> formed=2 |
| 2    | left=1, right=5     | continue expand right | not valid |
| 3    | right moves to 9    | window becomes valid again at right=9 covering "DOBECODEB A" -> possible shrink -> minLen updated if smaller |
| 4    | when right=12       | window (9..12) "BANC" becomes valid | minLen updated to 4, final answer "BANC" |
| 5    | end                 | no shorter valid window found | return "BANC" |

## Other Patterns

### Pattern 1

**Idea**
Brute force: check all substrings and test coverage.

**Pseudo Code**

```text
function solve(s, t)
    best <- ""
    for i from 0 to len(s)-1
        for j from i to len(s)-1
            sub <- s.substring(i, j+1)
            if containsAll(sub, t) and (best == "" or len(sub) < len(best)) then
                best <- sub
    return best
```

### Pattern 2

**Idea**
Filtered sliding window: prefilter s to indices of chars that appear in t to reduce iterations.

**Pseudo Code**

```text
function solve(s, t)
    need <- map counts of t
    filtered <- list of pairs (index, char) for index in 0..len(s)-1 if s[index] in need
    apply sliding window on filtered list using same logic as main sliding window
    return result substring or ""
```
