# 3Sum

## Difficulty
Medium

## Description
Given an integer array nums, return all unique triplets [a,b,c] such that a + b + c = 0. Triplets must be unique (order of elements in a triplet does not matter).

## Examples

### Example 1
```text
Input: nums = [-1,0,1,2,-1,-4]
Output: [[-1,-1,2],[-1,0,1]]
Explanation: After sorting [-4,-1,-1,0,1,2], the unique triplets summing to 0 are [-1,-1,2] and [-1,0,1].
```

### Example 2
```text
Input: nums = [0,0,0,0]
Output: [[0,0,0]]
Explanation: Only one unique triplet [0,0,0].
```

## Constraints
```text
3 <= nums.length <= 3000
-10^5 <= nums[i] <= 10^5
Return unique triplets in any order.
```

---

## Idea
Sort the array, fix one element, and find the other two with a two-pointer scan while skipping duplicates.

---

## Pseudo Code
```text
function threeSum(nums)
    sort nums ascending
    result = empty list
    n = length(nums)
    for i from 0 to n-3
        if i > 0 and nums[i] == nums[i-1] then continue
        target = -nums[i]
        left = i + 1
        right = n - 1
        while left < right
            sum = nums[left] + nums[right]
            if sum == target
                append [nums[i], nums[left], nums[right]] to result
                left = left + 1
                right = right - 1
                while left < right and nums[left] == nums[left-1] do left = left + 1
                while left < right and nums[right] == nums[right+1] do right = right - 1
            else if sum < target
                left = left + 1
            else
                right = right - 1
    return result
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n^2) |
| Space Complexity | O(1) (excluding output) |

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | nums sorted = [-4,-1,-1,0,1,2] | i=0, nums[i]=-4, target=4, left=1,right=5 | no pair sums to 4 |
| 2 | same array | i=1, nums[i]=-1, target=1, left=2,right=5 | nums[2]+nums[5]=-1+2=1 => found [-1,-1,2]; move left->3,right->4 |
| 3 | left=3,right=4 | nums[3]+nums[4]=0+1=1 => found [-1,0,1]; move left->4,right->3 stop |
| 4 | continue | skip duplicate i if any; finished loop | result = [[-1,-1,2],[-1,0,1]] |

## Other Patterns

### Pattern 1

**Idea**
Brute-force check all triplets and use a set to deduplicate.

**Pseudo Code**
```text
function threeSumBrute(nums)
    n = length(nums)
    resultSet = empty set
    sort nums
    for i from 0 to n-3
        for j from i+1 to n-2
            for k from j+1 to n-1
                if nums[i] + nums[j] + nums[k] == 0
                    add tuple(nums[i],nums[j],nums[k]) to resultSet
    return list of lists from resultSet
```

### Pattern 2

**Idea**
For each element fix a and use a hash set to find pairs b,c with b + c = -a (two-sum hashmap per iteration).

**Pseudo Code**
```text
function threeSumHash(nums)
    sort nums
    n = length(nums)
    resultSet = empty set
    for i from 0 to n-3
        if i > 0 and nums[i] == nums[i-1] then continue
        target = -nums[i]
        seen = empty set
        for j from i+1 to n-1
            complement = target - nums[j]
            if complement in seen
                add tuple(nums[i], complement, nums[j]) to resultSet
            add nums[j] to seen
    return list of lists from resultSet
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Sorting + Two-Pointer | Sort once, fix one element, two-pointer scan | O(n^2) | O(1) excluding output | Yes |
| Hash per fixed element | Fix element, use hash-set for two-sum | O(n^2) average | O(n) | No (higher space and dedup management) |
| Brute Force | Try all triplets and deduplicate | O(n^3) | O(n^3) or O(k) for set | No |
