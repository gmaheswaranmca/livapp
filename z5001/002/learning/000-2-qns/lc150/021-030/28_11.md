# Container With Most Water

## Difficulty
Medium

## Description
Given an array height[] where each element represents the height of a vertical line at that index, find two lines that together with the x-axis form a container that holds the maximum amount of water. Return the maximum area.

## Examples

### Example 1

```text
Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: Choose lines at indices 1 and 8 (0-based) with heights 8 and 7 -> area = min(8,7) * (8-1) = 49.
```

## Constraints

```text
2 <= height.length <= 10^5
0 <= height[i] <= 10^4
```

---

## Idea
Use two pointers at the ends and move the pointer at the shorter line inward, tracking the maximum area.

---

## Pseudo Code

```text
function maxArea(height)
    left <- 0
    right <- length(height) - 1
    maxArea <- 0
    while left < right
        width <- right - left
        currentHeight <- min(height[left], height[right])
        area <- currentHeight * width
        if area > maxArea then maxArea <- area
        if height[left] < height[right] then left <- left + 1
        else right <- right - 1
    return maxArea
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (l,r) | Operation                         | Result / maxArea |
| ---- | ----------- | --------------------------------- | ---------------- |
| 1    | (0,8)       | area = min(1,7)*8 = 8             | maxArea = 8      |
| 2    | (1,8)       | area = min(8,7)*7 = 49            | maxArea = 49     |
| 3    | (1,7)       | area = min(8,3)*6 = 18            | maxArea = 49     |
| 4    | (1,6)       | area = min(8,8)*5 = 40            | maxArea = 49     |
| 5    | (1,5)       | area = min(8,4)*4 = 32            | maxArea = 49     |
| 6    | ...         | subsequent moves do not exceed 49 | final = 49       |

## Other Patterns

### Pattern 2

**Idea**
Brute-force check all pairs.

**Pseudo Code**

```text
function maxAreaBruteForce(height)
    n <- length(height)
    maxArea <- 0
    for i from 0 to n-2
        for j from i+1 to n-1
            area <- min(height[i], height[j]) * (j - i)
            if area > maxArea then maxArea <- area
    return maxArea
```

## Comparison

| Approach       | Idea                             | Time    | Space | Recommended |
| -------------- | -------------------------------- | ------- | ----- | ----------- |
| Two Pointers   | Move inward from both ends       | O(n)    | O(1)  | Yes         |
| Brute Force    | Check all pairs                  | O(n^2)  | O(1)  | No          |
