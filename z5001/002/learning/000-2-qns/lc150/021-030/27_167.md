# Two Sum II - Input Array Is Sorted

## Difficulty
Easy

## Description
Given a 1-indexed sorted array of integers and a target, find indices of two numbers that add up to target. Return the indices as [index1, index2]. Exactly one solution exists and you may not use the same element twice.

## Examples

### Example 1

```text
Input: numbers = [2,7,11,15], target = 9
Output: [1,2]
Explanation: numbers[1] + numbers[2] = 2 + 7 = 9
```

### Example 2

```text
Input: numbers = [2,3,4], target = 6
Output: [1,3]
Explanation: numbers[1] + numbers[3] = 2 + 4 = 6
```

### Example 3

```text
Input: numbers = [-1,0], target = -1
Output: [1,2]
Explanation: -1 + 0 = -1
```

## Constraints

```text
2 <= numbers.length <= 3*10^4
-10^5 <= numbers[i] <= 10^5
numbers is sorted in non-decreasing order
Exactly one valid answer exists
Indices are 1-based
```

---

## Idea
Use two pointers at array ends and move them based on current sum.

---

## Pseudo Code

```text
function twoSumSorted(numbers, target)
    n = length(numbers)
    left = 0
    right = n - 1
    while left < right
        sum = numbers[left] + numbers[right]
        if sum == target
            return [left + 1, right + 1]
        if sum < target
            left = left + 1
        else
            right = right - 1
    return [-1, -1]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | left | right | numbers[left] | numbers[right] | sum | Operation             | Result     |
| ---- | ---- | ----- | ------------- | -------------- | --- | --------------------- | ---------- |
| 1    | 0    | 3     | 2             | 15             | 17  | sum > target -> right-- | right = 2  |
| 2    | 0    | 2     | 2             | 11             | 13  | sum > target -> right-- | right = 1  |
| 3    | 0    | 1     | 2             | 7              | 9   | sum == target -> return | [1,2]     |

## Other Patterns

### Pattern 2

**Idea**

For each element, binary search the complement in the remainder.

**Pseudo Code**

```text
function twoSumBinarySearch(numbers, target)
    n = length(numbers)
    for i from 0 to n-2
        complement = target - numbers[i]
        lo = i + 1
        hi = n - 1
        while lo <= hi
            mid = lo + (hi - lo) // 2
            if numbers[mid] == complement
                return [i + 1, mid + 1]
            if numbers[mid] < complement
                lo = mid + 1
            else
                hi = mid - 1
    return [-1, -1]
```

### Pattern 3

**Idea**

Use a hash map to store seen numbers and their indices (does not leverage sorted property).

**Pseudo Code**

```text
function twoSumHashMap(numbers, target)
    map = empty hashmap
    for i from 0 to length(numbers)-1
        complement = target - numbers[i]
        if complement in map
            return [map[complement] + 1, i + 1]
        map[numbers[i]] = i
    return [-1, -1]
```

## Comparison

| Approach       | Idea                                   | Time      | Space     | Recommended |
| -------------- | -------------------------------------- | --------- | --------- | ----------- |
| Two Pointers   | Two ends pointers move based on sum    | O(n)      | O(1)      | Yes         |
| Binary Search  | For each element binary search complement | O(n log n)| O(1)      | No (slower) |
| Hash Map       | One-pass lookup of complements         | O(n)      | O(n)      | No (extra space) |
