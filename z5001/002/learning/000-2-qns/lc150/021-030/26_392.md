# Is Subsequence

## Difficulty
Easy

## Description
Given strings s and t, determine if s is a subsequence of t (all characters of s appear in t in the same order, not necessarily contiguous).

## Examples

### Example 1

```text
Input: s = "abc", t = "ahbgdc"
Output: true
Explanation: Move pointers through both strings and match characters.
```

### Example 2

```text
Input: s = "axc", t = "ahbgdc"
Output: false
Explanation: 'x' cannot be matched in t after 'a'.
```

## Constraints

```text
0 <= s.length <= 100
0 <= t.length <= 10^4
s and t consist of ASCII letters (or general characters).
Multiple queries on same t may occur.
```

---

## Idea
Two-pointer greedy: advance pointer on t and match characters of s in order; succeed if all characters of s are matched.

---

## Pseudo Code

```text
function isSubsequence(s, t)
    i <- 0
    j <- 0
    n <- length(s)
    m <- length(t)
    while i < n and j < m
        if s[i] == t[j]
            i <- i + 1
            j <- j + 1
        else
            j <- j + 1
    return i == n
```

---

## Complexity

| Metric           | Value       |
| ---------------- | ----------- |
| Time Complexity  | O(n + m)    |
| Space Complexity | O(1)        |

n = length(s), m = length(t)

## Code Explanation

### Dry Run

| Step | State (i,j) | Operation                | Result (i,j) |
| ---- | ----------- | ------------------------ | ------------ |
| 1    | (0,0)       | Compare s[0]='a' vs t[0]='a' | (1,1)       |
| 2    | (1,1)       | s[1]='b' vs t[1]='h'     | (1,2)        |
| 3    | (1,2)       | s[1]='b' vs t[2]='b'     | (2,3)        |
| 4    | (2,3)       | s[2]='c' vs t[3]='g'     | (2,4)        |
| 5    | (2,4)       | s[2]='c' vs t[4]='d'     | (2,5)        |
| 6    | (2,5)       | s[2]='c' vs t[5]='c'     | (3,6)        |
| 7    | (3,6)       | i == n -> return true    | true         |

## Other Patterns

### Pattern 1

**Idea**

Dynamic programming for Longest Common Subsequence (LCS) and compare length to s.

**Pseudo Code**

```text
function isSubsequenceDP(s, t)
    n <- length(s)
    m <- length(t)
    create dp table (n+1) x (m+1) initialized to 0
    for i from 1 to n
        for j from 1 to m
            if s[i-1] == t[j-1]
                dp[i][j] <- dp[i-1][j-1] + 1
            else
                dp[i][j] <- max(dp[i-1][j], dp[i][j-1])
    return dp[n][m] == n
```

### Pattern 2

**Idea**

Preprocess t to build next-occurrence table and answer multiple queries with binary search or table-walking in O(|s|) per query or O(|s| log |t|).

**Pseudo Code**

```text
function buildNext(t)
    m <- length(t)
    alphabetSize <- number of distinct chars (e.g., 26)
    create next array size (m+1) x alphabetSize filled with -1
    for c in 0..alphabetSize-1
        next[m][c] <- -1
    for i from m-1 downto 0
        for c in 0..alphabetSize-1
            next[i][c] <- next[i+1][c]
        next[i][indexOf(t[i])] <- i
    return next

function isSubsequenceWithNext(s, next)
    pos <- 0
    m <- length of next - 1
    for ch in characters of s
        idx <- indexOf(ch)
        if pos > m
            return false
        posFound <- next[pos][idx]
        if posFound == -1
            return false
        pos <- posFound + 1
    return true
```

## Comparison

| Approach                 | Idea                                    | Time             | Space        | Recommended |
| ------------------------ | --------------------------------------- | ---------------- | ------------ | ----------- |
| Two-pointer (Greedy)     | Single pass matching                     | O(n + m)         | O(1)         | Yes         |
| DP (LCS)                 | Compute LCS length                       | O(n * m)         | O(n * m)     | No          |
| Preprocess next-table    | Next occurrence table for many queries   | Build O(m * A); Query O(|s|) | O(m * A) where A=alphabet | Yes (many queries) |
