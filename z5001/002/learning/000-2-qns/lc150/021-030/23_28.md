# Find the Index of the First Occurrence in a String

## Difficulty
Easy

## Description
Return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack. If needle is an empty string return 0.

## Examples

### Example 1
```text
Input: haystack = "sadbutsad", needle = "sad"
Output: 0
Explanation: "sad" occurs at index 0.
```

### Example 2
```text
Input: haystack = "leetcode", needle = "leeto"
Output: -1
Explanation: "leeto" does not occur in "leetcode".
```

### Example 3
```text
Input: haystack = "abc", needle = ""
Output: 0
Explanation: Empty needle returns 0.
```

## Constraints
```text
0 <= haystack.length, needle.length <= 5 * 10^4
haystack and needle consist of lowercase and uppercase letters and/or other ASCII characters
Must return first occurrence index or -1
```

---

## Idea
Use KMP (Knuth–Morris–Pratt) to build a longest-prefix-suffix (LPS) table for needle and scan haystack in O(n+m).

---

## Pseudo Code
```text
function computeLPS(pattern)
    n <- length(pattern)
    lps <- array of size n initialized with 0
    len <- 0
    i <- 1
    while i < n
        if pattern[i] == pattern[len]
            len <- len + 1
            lps[i] <- len
            i <- i + 1
        else
            if len != 0
                len <- lps[len - 1]
            else
                lps[i] <- 0
                i <- i + 1
    return lps

function strStr(haystack, needle)
    if length(needle) == 0
        return 0
    if length(haystack) < length(needle)
        return -1
    lps <- computeLPS(needle)
    i <- 0    // index for haystack
    j <- 0    // index for needle
    while i < length(haystack)
        if haystack[i] == needle[j]
            i <- i + 1
            j <- j + 1
            if j == length(needle)
                return i - j
        else
            if j != 0
                j <- lps[j - 1]
            else
                i <- i + 1
    return -1
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n + m) |
| Space Complexity | O(m)   |

---

## Code Explanation

1. computeLPS builds lps array where lps[i] = length of the longest proper prefix of pattern[0..i] which is also a suffix.
2. Use two pointers i (haystack) and j (needle) to attempt matches.
3. On match advance both; if j reaches needle length return i-j.
4. On mismatch, if j>0 reset j to lps[j-1], else advance i.
5. If scan completes with no full match return -1.

## Other Patterns

### Pattern 1

**Idea**
Naive sliding window comparison.

**Pseudo Code**
```text
function strStr(haystack, needle)
    if length(needle) == 0
        return 0
    for i from 0 to length(haystack) - length(needle)
        j <- 0
        while j < length(needle) and haystack[i + j] == needle[j]
            j <- j + 1
        if j == length(needle)
            return i
    return -1
```

### Pattern 2

**Idea**
Rabin-Karp rolling hash to compare substring hashes then verify.

**Pseudo Code**
```text
function strStr(haystack, needle)
    if length(needle) == 0
        return 0
    m <- length(needle)
    n <- length(haystack)
    if n < m
        return -1
    base <- 256
    mod <- large_prime
    needleHash <- 0
    windowHash <- 0
    power <- 1
    for i from 0 to m - 2
        power <- (power * base) % mod
    for i from 0 to m - 1
        needleHash <- (needleHash * base + ord(needle[i])) % mod
        windowHash <- (windowHash * base + ord(haystack[i])) % mod
    for i from 0 to n - m
        if needleHash == windowHash
            if haystack[i:i+m] == needle
                return i
        if i < n - m
            windowHash <- (windowHash - ord(haystack[i]) * power) % mod
            windowHash <- (windowHash * base + ord(haystack[i + m])) % mod
            if windowHash < 0
                windowHash <- windowHash + mod
    return -1
```
