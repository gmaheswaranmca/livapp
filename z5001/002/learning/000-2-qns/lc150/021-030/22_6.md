# Zigzag Conversion

## Difficulty
Medium

## Description
Given a string s and an integer rows, write the characters of s in a zigzag pattern on rows and then read line by line to produce a new string. Example: s = "PAYPALISHIRING", rows = 3 -> "PAHNAPLSIIGYIR".

## Examples

### Example 1

```text
Input: s = "PAYPALISHIRING", rows = 3
Output: "PAHNAPLSIIGYIR"
Explanation: Zigzag pattern:
P   A   H   N
A P L S I I G
Y   I   R
Read row-wise -> "PAHNAPLSIIGYIR"
```

### Example 2

```text
Input: s = "A", rows = 1
Output: "A"
Explanation: Single row returns same string.
```

## Constraints

```text
1 <= s.length <= 10^5
1 <= rows <= 10^5
s contains printable ASCII characters
```

---

## Idea
Simulate row-by-row traversal appending characters while toggling direction at top/bottom.

---

## Pseudo Code

```text
function convert_zigzag(s, rows)
    if rows <= 1 or rows >= length(s) then
        return s
    end if
    n := length(s)
    rows_arr := array of rows empty strings
    current_row := 0
    direction := 1
    for i from 0 to n-1 do
        append s[i] to rows_arr[current_row]
        if current_row == 0 then
            direction := 1
        else if current_row == rows - 1 then
            direction := -1
        end if
        current_row := current_row + direction
    end for
    result := empty string
    for r from 0 to rows-1 do
        result := result + rows_arr[r]
    end for
    return result
```

## Code Explanation

### Dry Run

| Step | Index/Char | Operation                                | Result (rows state)                     |
| ---- | ---------- | ---------------------------------------- | --------------------------------------- |
| 1    | 0 / 'P'    | append to row0, at top -> dir = +1       | ["P", "", ""]                           |
| 2    | 1 / 'A'    | append to row1                            | ["P", "A", ""]                          |
| 3    | 2 / 'Y'    | append to row2, at bottom -> dir = -1    | ["P", "A", "Y"]                         |
| 4    | 3 / 'P'    | append to row1                            | ["P", "AP", "Y"]                        |
| 5    | 4 / 'A'    | append to row0, at top -> dir = +1       | ["PA", "AP", "Y"]                       |
| 6    | 5 / 'L'    | append to row1                            | ["PA", "APL", "Y"]                      |
| ...  | ...        | continue until end                       | ["PAHN","APLSIIG","YIR"] -> join -> out |

1. Validate trivial cases rows <=1 or rows >= n.
2. Use rows_arr to collect characters per row.
3. Move current_row up/down by toggling direction at boundaries.
4. Concatenate rows to produce final string.

## Other Patterns

### Pattern 1

**Idea**  
Simulate traversal using row buckets and direction toggle.

**Pseudo Code**

```text
function convert_zigzag_simulation(s, rows)
    if rows <= 1 or rows >= length(s) then
        return s
    end if
    rows_arr := array of rows empty strings
    current := 0
    dir := 1
    for each c in s do
        append c to rows_arr[current]
        if current == 0 then
            dir := 1
        else if current == rows - 1 then
            dir := -1
        end if
        current := current + dir
    end for
    return concatenate all strings in rows_arr
```

### Pattern 2

**Idea**  
Compute indices directly using cycle length to avoid explicit direction simulation.

**Pseudo Code**

```text
function convert_zigzag_cycle(s, rows)
    if rows <= 1 or rows >= length(s) then
        return s
    end if
    n := length(s)
    cycle := 2 * rows - 2
    result := empty string
    for r from 0 to rows-1 do
        for j from r to n-1 step cycle do
            append s[j] to result
            second := j + cycle - 2 * r
            if r != 0 and r != rows - 1 and second < n then
                append s[second] to result
            end if
        end for
    end for
    return result
```
