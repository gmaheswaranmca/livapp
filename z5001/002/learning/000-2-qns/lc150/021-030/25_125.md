# Valid Palindrome

## Difficulty
Easy

## Description
Determine whether a string is a palindrome after removing non-alphanumeric characters and ignoring case.

## Examples

### Example 1

```text
Input: s = "A man, a plan, a canal: Panama"
Output: true
Explanation: After filtering and ignoring case the string becomes "amanaplanacanalpanama" which is a palindrome.
```

### Example 2

```text
Input: s = "race a car"
Output: false
Explanation: After filtering and ignoring case the string becomes "raceacar" which is not a palindrome.
```

## Constraints

```text
0 <= s.length <= 2 * 10^5
s contains printable ASCII characters
```

---

## Idea
Use two pointers from both ends, skip non-alphanumeric characters, compare lowercased characters.

---

## Pseudo Code

```text
function isPalindrome(s)
    left <- 0
    right <- length(s) - 1
    while left < right
        while left < right and not isAlphanumeric(s[left])
            left <- left + 1
        while left < right and not isAlphanumeric(s[right])
            right <- right - 1
        if left >= right
            break
        if toLower(s[left]) != toLower(s[right])
            return false
        left <- left + 1
        right <- right - 1
    return true
```

## Complexity

| Metric           | Value     |
| ---------------- | --------- |
| Time Complexity  | O(n)      |
| Space Complexity | O(1)      |

## Code Explanation

### Dry Run

| Step | State                | Operation                                 | Result                     |
| ---- | -------------------- | ----------------------------------------- | -------------------------- |
| 1    | s="A man,...Panama"  | left=0('A'), right=29('a')                | compare 'a'=='a' -> ok     |
| 2    | left->1(' '), right->28('m') | skip non-alnum left; compare 'm'=='m' | ok                         |
| 3    | continue             | skip punctuation and spaces               | indices move inward        |
| 4    | meet middle          | all comparisons matched                   | return true                |

## Other Patterns

### Pattern 1

**Idea**
Filter only alphanumeric chars to a new string and check equality with its reverse.

**Pseudo Code**

```text
function isPalindrome_Filter(s)
    filtered <- empty list
    for each ch in s
        if isAlphanumeric(ch)
            append to filtered toLower(ch)
    n <- length(filtered)
    for i from 0 to n/2 - 1
        if filtered[i] != filtered[n - 1 - i]
            return false
    return true
```

### Pattern 2

**Idea**
Use regex to remove non-alphanumeric, lowercase and compare with reversed string.

**Pseudo Code**

```text
function isPalindrome_Regex(s)
    cleaned <- regexReplace(s, "[^A-Za-z0-9]", "")
    cleaned <- toLower(cleaned)
    if cleaned == reverse(cleaned)
        return true
    return false
```

## Comparison

| Approach         | Idea                                 | Time   | Space    | Recommended |
| ---------------- | ------------------------------------ | ------ | -------- | ----------- |
| Two Pointers     | Skip non-alnum in-place and compare  | O(n)   | O(1)     | Yes         |
| Filtered String  | Build filtered string then compare   | O(n)   | O(n)     | No          |
| Regex + Reverse  | Clean via regex then reverse compare | O(n)   | O(n)     | No          |
