# Minimum Size Subarray Sum

## Difficulty
Medium

## Description
Given an array of positive integers nums and an integer target, find the minimal length of a contiguous subarray of which the sum is at least target. If no such subarray exists, return 0.

## Examples

### Example 1

```text
Input: target = 7, nums = [2,3,1,2,4,3]
Output: 2
Explanation: The subarray [4,3] has sum ≥ 7 and length 2 which is minimal.
```

### Example 2

```text
Input: target = 15, nums = [1,2,3,4,5]
Output: 5
Explanation: Whole array sum is 15, minimal length is 5.
```

### Example 3

```text
Input: target = 100, nums = [1,2,3,4,5]
Output: 0
Explanation: No subarray meets the target.
```

## Constraints

```text
1 <= nums.length <= 10^5
1 <= nums[i] <= 10^5
1 <= target <= 10^9
All numbers are non-negative (positive).
```

---

## Idea
Use a sliding window: expand right until sum ≥ target then shrink left to minimize length and repeat.

---

## Pseudo Code

```text
function minSubArrayLen(target, nums)
    n <- length of nums
    left <- 0
    sum <- 0
    minLen <- infinity
    for right from 0 to n-1
        sum <- sum + nums[right]
        while sum >= target
            currentLen <- right - left + 1
            if currentLen < minLen then minLen <- currentLen
            sum <- sum - nums[left]
            left <- left + 1
    if minLen == infinity then return 0
    return minLen
```

## Other Patterns

### Pattern 1

**Idea**

Use prefix sums with binary search to find smallest right index for each left.

**Pseudo Code**

```text
function minSubArrayLen_PrefixBinary(target, nums)
    n <- length of nums
    prefix[0] <- 0
    for i from 1 to n
        prefix[i] <- prefix[i-1] + nums[i-1]
    minLen <- infinity
    for left from 0 to n-1
        need <- target + prefix[left]
        right <- lower_bound(prefix, need) // first index with prefix[right] >= need
        if right != not_found then minLen <- min(minLen, right - left)
    if minLen == infinity then return 0
    return minLen
```

### Pattern 2

**Idea**

Brute force check all subarrays compute sums with two loops.

**Pseudo Code**

```text
function minSubArrayLen_BruteForce(target, nums)
    n <- length of nums
    minLen <- infinity
    for i from 0 to n-1
        sum <- 0
        for j from i to n-1
            sum <- sum + nums[j]
            if sum >= target then minLen <- min(minLen, j - i + 1); break
    if minLen == infinity then return 0
    return minLen
```

## Comparison

| Approach                 | Idea                                  | Time      | Space | Recommended |
| ------------------------ | ------------------------------------- | --------- | ----- | ----------- |
| Sliding Window (this)    | Expand right and shrink left when sum≥target | O(n)      | O(1)  | Yes         |
| Prefix Sum + Binary Search | Binary search on prefix sums per left | O(n log n)| O(n)  | No (when nums positive) |
| Brute Force              | Check all subarrays                   | O(n^2)    | O(1)  | No          |
