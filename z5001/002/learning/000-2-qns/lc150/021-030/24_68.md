# Text Justification

## Difficulty
Medium

## Description
Given a list of words and a max width, format the text so that each line has exactly max width characters and is fully (left and right) justified. Use a greedy approach: pack as many words as possible in each line; distribute spaces evenly between words; if spaces don't divide evenly, put extra spaces on the left gaps; last line is left-justified with single spaces between words and extra spaces at the end.

## Examples

### Example 1

```text
Input: words = ["This","is","an"], width = 16
Output: ["This is an      "]
Explanation: Last line is left-justified: single spaces between words and trailing spaces to fill width.
```

### Example 2

```text
Input: words = ["This","is","an","example","of","text","justification."], width = 16
Output:
[
 "This    is    an",
 "example  of text",
 "justification.  "
]
Explanation: Greedy packing and even space distribution; last line left-justified.
```

## Constraints

```text
1 <= words.length <= 500
1 <= words[i].length <= width <= 100
words contain only printable characters (no implicit spaces)
```

---

## Idea
Greedily pack words into a line until next word would overflow, then distribute spaces: if single word or last line left-justify; else distribute spaces evenly and give the first (remainder) gaps one extra space each.

---

## Pseudo Code

```text
function fullJustify(words, maxWidth)
    result <- empty list
    i <- 0
    n <- length(words)
    while i < n
        start <- i
        lineLen <- length(words[i])
        i <- i + 1
        while i < n and lineLen + 1 + length(words[i]) <= maxWidth
            lineLen <- lineLen + 1 + length(words[i])
            i <- i + 1
        end while
        endIndex <- i - 1
        numWords <- endIndex - start + 1
        if i == n or numWords == 1
            line <- leftJustify(words, start, endIndex, maxWidth)
        else
            line <- fullyJustify(words, start, endIndex, maxWidth)
        end if
        append line to result
    end while
    return result

function leftJustify(words, start, endIndex, maxWidth)
    line <- words[start]
    for k from start + 1 to endIndex
        line <- line + " " + words[k]
    end for
    pad <- maxWidth - length(line)
    line <- line + repeat(" ", pad)
    return line

function fullyJustify(words, start, endIndex, maxWidth)
    totalChars <- 0
    for k from start to endIndex
        totalChars <- totalChars + length(words[k])
    end for
    gaps <- endIndex - start
    totalSpaces <- maxWidth - totalChars
    spaceWidth <- totalSpaces // gaps
    extra <- totalSpaces % gaps
    line <- empty string
    for k from start to endIndex - 1
        line <- line + words[k]
        spacesToAdd <- spaceWidth + (1 if (k - start) < extra else 0)
        line <- line + repeat(" ", spacesToAdd)
    end for
    line <- line + words[endIndex]
    return line
```

## Other Patterns

### Pattern 1

**Idea**

Dynamic programming minimizing raggedness (badness) producing optimal global spacing.

**Pseudo Code**

```text
function fullJustifyDP(words, maxWidth)
    n <- length(words)
    cost[i][j] <- infinity for all i,j
    for i from 0 to n-1
        lengthSum <- 0
        for j from i to n-1
            lengthSum <- lengthSum + length(words[j]) + (j - i)
            if lengthSum <= maxWidth
                cost[i][j] <- (maxWidth - (lengthSum))^2
            else
                break
            end if
        end for
    end for
    dp[n] <- 0
    for i from n-1 downto 0
        dp[i] <- infinity
        for j from i to n-1
            if cost[i][j] < infinity and (j == n-1 or dp[j+1] < infinity)
                dp[i] <- min(dp[i], cost[i][j] + dp[j+1])
            end if
        end for
    end for
    reconstruct lines using choices
    return justified lines
```

### Pattern 2

**Idea**

Stream-based single-pass with buffer and output callback for memory-critical environments.

**Pseudo Code**

```text
function justifyStream(wordsIterator, maxWidth, emitLine)
    buffer <- empty list
    bufferLen <- 0
    for word in wordsIterator
        if buffer is empty
            append word to buffer
            bufferLen <- length(word)
            continue
        end if
        if bufferLen + 1 + length(word) <= maxWidth
            append word to buffer
            bufferLen <- bufferLen + 1 + length(word)
        else
            emitLine(makeJustified(buffer, maxWidth, isLast=false))
            buffer <- [word]
            bufferLen <- length(word)
        end if
    end for
    if buffer not empty
        emitLine(makeJustified(buffer, maxWidth, isLast=true))
    end if
```
