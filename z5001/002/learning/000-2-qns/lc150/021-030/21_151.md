# 21  Reverse Words in a String

## Difficulty
Easy

## Description
Given an input string s, reverse the order of the words. A word is defined as a sequence of non-space characters. Remove leading/trailing spaces and reduce multiple spaces between words to a single space.

## Examples

### Example 1

```text
Input: "the sky is blue"
Output: "blue is sky the"
Explanation: Split into words and reverse order.
```

### Example 2

```text
Input: "  hello   world  "
Output: "world hello"
Explanation: Trim spaces and normalize multiple spaces to one.
```

## Constraints

```text
1 <= s.length <= 10^4
s contains English letters (upper/lower-case) and spaces ' '.
There may be multiple spaces between words.
```

---

## Idea
Split the string into words, reverse the list of words, and join with a single space.

---

## Pseudo Code

```text
function reverseWords(s)
    s_trimmed = trim leading and trailing spaces of s
    if s_trimmed is empty then return ""
    words = split s_trimmed by any whitespace sequence
    reverse words in-place
    return join words with single space
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | State                            | Operation                       | Result                  |
| ---- | -------------------------------- | ------------------------------- | ----------------------- |
| 1    | s = "  hello   world  "          | trim                            | "hello   world"         |
| 2    | "hello   world"                  | split by whitespace sequences   | ["hello","world"]       |
| 3    | ["hello","world"]                | reverse                          | ["world","hello"]       |
| 4    | ["world","hello"]                | join with single space           | "world hello"           |

1. Trim leading and trailing spaces.
2. Split on one-or-more whitespace into a list of words.
3. Reverse the list of words (in-place).
4. Join words with a single space and return.

---

## Other Patterns

### Pattern 1

**Idea**

Reverse entire string then reverse each word and clean spaces.

**Pseudo Code**

```text
function reverseWords(s)
    s_trimmed = remove extra spaces from s (leading/trailing and collapse)
    s_reversed = reverse entire s_trimmed
    i = 0
    while i < length(s_reversed)
        j = i
        while j < length(s_reversed) and s_reversed[j] != ' ' then j = j + 1
        reverse substring s_reversed[i..j-1]
        i = j + 1
    return s_reversed
```

### Pattern 2

**Idea**

Parse words by scanning and push onto stack, then pop to build result.

**Pseudo Code**

```text
function reverseWords(s)
    i = 0
    stack = empty stack
    while i < length(s)
        while i < length(s) and s[i] == ' ' then i = i + 1
        if i == length(s) then break
        j = i
        while j < length(s) and s[j] != ' ' then j = j + 1
        push substring s[i..j-1] onto stack
        i = j
    result = empty list
    while stack not empty
        append pop(stack) to result
    return join result with single space
```

## Comparison

| Approach | Idea                               | Time  | Space | Recommended |
| -------- | ---------------------------------- | ----- | ----- | ----------- |
| Split & Reverse | Split by whitespace, reverse list, join | O(n)  | O(n)  | Yes |
| Reverse Whole + Per-word Reverse | Reverse entire string then reverse words and trim | O(n)  | O(1) extra (in-place) | Yes (in-place languages) |
| Stack Parse | Scan and push words then pop to build | O(n)  | O(n)  | No (equivalent to split) |
