# Minimum Bit Flips to Convert Number

## Difficulty
Easy

## Description
Given two non-negative integers start and goal, return the minimum number of bit flips required to convert start to goal. A bit flip toggles a single bit (0->1 or 1->0).

## Examples

### Example 1

```text
Input: start = 10, goal = 7
Output: 3
Explanation: 10 (1010) XOR 7 (0111) = 1101 has three '1' bits.
```

### Example 2

```text
Input: start = 0, goal = 0
Output: 0
Explanation: No flips needed.
```

### Example 3

```text
Input: start = 29, goal = 15
Output: 2
Explanation: 29 (11101) XOR 15 (01111) = 10010 has two '1' bits.
```

## Constraints

```text
0 <= start, goal <= 10^9
Use 32-bit or 64-bit integers depending on language.
Allowed operations: bitwise XOR, bitwise AND, shifts.
```

---

## Idea
XOR start and goal, then count the number of set bits in the result.

---

## Pseudo Code

```text
function minBitFlips(start, goal)
    x = start XOR goal
    count = 0
    while x != 0
        x = x AND (x - 1)    // removes lowest set bit
        count = count + 1
    return count
```

---

## Complexity

| Metric           | Value            |
| ---------------- | ---------------- |
| Time Complexity  | O(k) where k = number of set bits in (start XOR goal) ≤ O(log M) |
| Space Complexity | O(1)             |

---

## Code Explanation

### Dry Run

| Step | State                          | Operation                       | Result |
| ---- | ------------------------------ | ------------------------------- | ------ |
| 1    | start = 10 (1010), goal = 7 (0111) | x = start XOR goal             | x = 13 (1101) |
| 2    | x = 1101                       | x = x & (x - 1)                | x -> 1100 (12), count=1 |
| 3    | x = 1100                       | x = x & (x - 1)                | x -> 1000 (8), count=2 |
| 4    | x = 1000                       | x = x & (x - 1)                | x -> 0000 (0), count=3 |
| 5    | x = 0000                       | loop ends                      | return 3 |

1. Compute XOR to highlight differing bits.
2. Use x & (x-1) repeatedly to remove lowest set bit and increment count.
3. Return count when x becomes zero.

## Other Patterns

### Pattern 1

**Idea**
Use builtin population count (popcount) / bitCount if available.

**Pseudo Code**

```text
function minBitFlips(start, goal)
    x = start XOR goal
    return popcount(x)    // language built-in
```

### Pattern 2

**Idea**
Convert both numbers to binary strings, pad to equal length, and compare positions.

**Pseudo Code**

```text
function minBitFlips(start, goal)
    a = binaryString(start)
    b = binaryString(goal)
    pad both a and b to same length with leading zeros
    count = 0
    for i from 0 to length(a)-1
        if a[i] != b[i] then count = count + 1
    return count
```

## Comparison

| Approach       | Idea                         | Time                 | Space | Recommended |
| -------------- | ---------------------------- | -------------------- | ----- | ----------- |
| Bit trick      | XOR then x & (x-1) loop      | O(k) (k = set bits) | O(1)  | Yes         |
| Built-in popcount | XOR then popcount         | O(1) or O(k) impl.   | O(1)  | Yes         |
| String compare | Binary strings and compare   | O(b) where b = bits  | O(b)  | No          |
