# Non-overlapping Intervals

## Difficulty
Medium

## Description
Given a collection of intervals, find the minimum number of intervals you need to remove to make the rest of the intervals non-overlapping.

## Examples

### Example 1

```text
Input: [[1,2],[2,3],[3,4],[1,3]]
Output: 1
Explanation: Remove [1,3] to make the rest non-overlapping.
```

## Constraints

```text
0 <= intervals.length <= 10^5
intervals[i].length == 2
-10^9 <= intervals[i][0] < intervals[i][1] <= 10^9
```

---

## Idea
Select the maximum number of non-overlapping intervals by greedily choosing intervals with the earliest end times; answer = total - chosen.

---

## Pseudo Code

```text
function eraseOverlapIntervals(intervals)
    if intervals is empty
        return 0
    sort intervals by end ascending, then start ascending
    kept = 1
    last_end = intervals[0].end
    for i from 1 to intervals.length - 1
        if intervals[i].start >= last_end
            kept = kept + 1
            last_end = intervals[i].end
    return intervals.length - kept
```

---

## Complexity

| Metric           | Value      |
| ---------------- | ---------- |
| Time Complexity  | O(n log n) |
| Space Complexity | O(1) (or O(n) for sorting) |

---

## Code Explanation

### Dry Run

| Step | Interval | last_end | Action            | kept | removed |
| ---- | -------- | -------- | ----------------- | ---- | ------- |
| 1    | [1,2]    | 2        | Initialize keep   | 1    | 0       |
| 2    | [1,3]    | 2        | start < last_end -> skip | 1    | 1       |
| 3    | [2,3]    | 2        | start >= last_end -> keep | 2    | 1       |
| 4    | [3,4]    | 3        | start >= last_end -> keep | 3    | 1       |

Final removed = 4 - 3 = 1

## Other Patterns

### Pattern 1

**Idea**

Dynamic programming to compute longest chain of non-overlapping intervals (O(n^2)).

**Pseudo Code**

```text
function eraseOverlapIntervalsDP(intervals)
    if intervals is empty
        return 0
    sort intervals by start ascending
    n = intervals.length
    dp = array of length n filled with 1
    for i from 0 to n-1
        for j from 0 to i-1
            if intervals[j].end <= intervals[i].start
                dp[i] = max(dp[i], dp[j] + 1)
    max_kept = max value in dp
    return n - max_kept
```

## Comparison

| Approach           | Idea                                      | Time       | Space             | Recommended |
| ------------------ | ----------------------------------------- | ---------- | ----------------- | ----------- |
| Greedy by end time | Pick intervals with earliest end times    | O(n log n) | O(1) / O(n) sort  | Yes        |
| Dynamic Programming| Longest compatible chain via DP (n^2)     | O(n^2)     | O(n)              | No         |
