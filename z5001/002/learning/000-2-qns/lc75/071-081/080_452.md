# Minimum Number of Arrows to Burst Balloons

## Difficulty
Medium

## Description
Given a list of balloons represented as intervals [start, end], return the minimum number of arrows required to burst all balloons. An arrow shot at x bursts all balloons whose intervals contain x.

## Examples

### Example 1

```text
Input: [[10,16],[2,8],[1,6],[7,12]]
Output: 2
Explanation: Shoot one arrow at x = 6 to burst [1,6] and [2,8], and another at x = 12 to burst [7,12] and [10,16].
```

### Example 2

```text
Input: [[1,2],[3,4],[5,6],[7,8]]
Output: 4
Explanation: No intervals overlap, need one arrow per balloon.
```

## Constraints

```text
1 <= number of balloons <= 10^5
Each interval is [start, end] with start <= end
Coordinates fit in 32-bit signed integer
```

---

## Idea
Sort intervals by end coordinate and greedily place an arrow at the current interval's end when needed.

---

## Pseudo Code

```text
function solve(balloons)
    if balloons is empty then
        return 0
    sort balloons by end ascending
    arrows = 0
    arrow_pos = -infinity
    for each interval in balloons
        start = interval[0]
        end = interval[1]
        if start > arrow_pos
            arrows = arrows + 1
            arrow_pos = end
    return arrows
```

| Metric           | Value           |
| ---------------- | --------------- |
| Time Complexity  | O(n log n)      |
| Space Complexity | O(1) or O(n) for sorting depending on language |

## Code Explanation

### Dry Run

| Step | State (arrow_pos, arrows) | Operation                        | Result                      |
| ---- | ------------------------- | -------------------------------- | --------------------------- |
| 1    | (-inf, 0)                 | sort -> [[1,6],[2,8],[7,12],[10,16]] | unchanged                   |
| 2    | (-inf, 0)                 | interval [1,6]: 1 > -inf         | arrows=1, arrow_pos=6       |
| 3    | (6, 1)                    | interval [2,8]: 2 <= 6           | covered, no change         |
| 4    | (6, 1)                    | interval [7,12]: 7 > 6           | arrows=2, arrow_pos=12      |
| 5    | (12, 2)                   | interval [10,16]: 10 <= 12       | covered, final arrows=2     |

## Other Patterns

### Pattern 1

**Idea**

Sort by start and maintain current overlapping intersection end; when overlap breaks, place an arrow and reset intersection.

**Pseudo Code**

```text
function solve(balloons)
    if balloons is empty then
        return 0
    sort balloons by start ascending
    arrows = 0
    current_end = +infinity
    for each interval in balloons
        start = interval[0]
        end = interval[1]
        if start > current_end
            arrows = arrows + 1
            current_end = end
        else
            current_end = min(current_end, end)
    return arrows + 1
```

### Pattern 2

**Idea**

Greedy interval covering interpreted as interval scheduling: always pick interval end as shooting point (equivalent to main approach).

**Pseudo Code**

```text
function solve(balloons)
    if balloons is empty then
        return 0
    sort balloons by end ascending
    arrows = 0
    i = 0
    n = length(balloons)
    while i < n
        arrows = arrows + 1
        shot = balloons[i][1]
        i = i + 1
        while i < n and balloons[i][0] <= shot
            i = i + 1
    return arrows
```

## Comparison

| Approach        | Idea                                  | Time       | Space      | Recommended |
| --------------- | ------------------------------------- | ---------- | ---------- | ----------- |
| Greedy by end   | Sort by end; shoot at end when needed | O(n log n) | O(1)/O(n)  | Yes        |
| Sort by start   | Maintain intersection end; reset when broken | O(n log n) | O(1)/O(n)  | No (equivalent) |
| Interval loop   | Sweep placing shot at end and skip covered | O(n log n) | O(1)/O(n)  | Yes        |
