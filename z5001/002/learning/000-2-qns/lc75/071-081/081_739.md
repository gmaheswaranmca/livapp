# Daily Temperatures

## Difficulty
Medium

## Description
Given an array temperatures, for each day find the number of days you have to wait until a warmer temperature. If there is no future day for which this is possible, put 0 for that day.

## Examples

### Example 1

```text
Input: [73,74,75,71,69,72,76,73]
Output: [1,1,4,2,1,1,0,0]
Explanation: For day 0 (73) the next warmer day is day 1 (74) so answer[0]=1; ...
```

## Constraints

```text
1 <= n <= 10^5
-10^5 <= temperatures[i] <= 10^5
Answers fit in int
```

---

## Idea
Use a monotonic decreasing stack of indices to find next greater temperature in one pass.

---

## Pseudo Code

```text
function dailyTemperatures(temperatures)
    n <- length(temperatures)
    result <- array of zeros of length n
    stack <- empty stack // will store indices with decreasing temperatures
    for i from 0 to n-1
        while stack not empty AND temperatures[i] > temperatures[stack.top()]
            prevIndex <- stack.pop()
            result[prevIndex] <- i - prevIndex
        stack.push(i)
    return result
```

---

## Complexity

| Metric           | Value   |
| ---------------- | ------- |
| Time Complexity  | O(n)    |
| Space Complexity | O(n)    |

### Dry Run

1. Maintain indices of days with strictly decreasing temperatures on stack.
2. When a warmer day arrives, pop indices and set distances.
3. Push current day index to be resolved later.

## Other Patterns

### Pattern 1

**Idea**

Brute force: for each day scan forward to find next warmer day.

**Pseudo Code**

```text
function dailyTemperaturesBrute(temperatures)
    n <- length(temperatures)
    result <- array of zeros of length n
    for i from 0 to n-1
        for j from i+1 to n-1
            if temperatures[j] > temperatures[i]
                result[i] <- j - i
                break
    return result
```

### Pattern 2

**Idea**

Use next-occurrence array for bounded temperature range (e.g., 30..100) to find nearest warmer day by scanning possible warmer temperature values.

**Pseudo Code**

```text
function dailyTemperaturesBounded(temperatures, minT, maxT)
    n <- length(temperatures)
    range <- maxT - minT + 1
    nextIndex <- array of -1 of length range
    result <- array of zeros of length n
    for i from n-1 down to 0
        warmerDay <- INF
        for t from temperatures[i]+1 to maxT
            idx <- nextIndex[t - minT]
            if idx != -1 AND idx < warmerDay
                warmerDay <- idx
        if warmerDay != INF
            result[i] <- warmerDay - i
        nextIndex[temperatures[i] - minT] <- i
    return result
```

## Comparison

| Approach                  | Idea                                    | Time     | Space    | Recommended |
| ------------------------- | --------------------------------------- | -------- | -------- | ----------- |
| Monotonic stack (main)    | Maintain decreasing indices stack       | O(n)     | O(n)     | Yes         |
| Brute force               | For each day scan forward               | O(n^2)   | O(1)     | No          |
| Bounded next-occurrence   | Track next index per temperature value  | O(n * R) | O(R)     | Sometimes   |
