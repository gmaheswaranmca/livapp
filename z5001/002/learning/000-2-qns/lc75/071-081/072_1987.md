# Number of Unique Good Subsequences

## Difficulty
Medium

## Description
Count the number of distinct non-empty binary subsequences of a given binary string that are "good" — defined as either the single character "0" or any binary string that starts with '1'. Return the count modulo 10^9+7.

## Examples

### Example 1

```text
Input: "001"
Output: 2
Explanation: Distinct good subsequences are "0" and "1".
```

### Example 2

```text
Input: "101"
Output: 5
Explanation: Distinct good subsequences are "0","1","10","11","101".
```

## Constraints

```text
1 <= length of s <= 10^5
s consists only of '0' and '1'
Return answer modulo 10^9+7
```

---

## Idea
Process string right-to-left: when visiting a character ch, adding ch in front of every distinct subsequence of the suffix creates dp new sequences; subtract duplicates using dp recorded at previous occurrence of ch; accumulate new unique sequences that start with '1'; include single "0" if any zero exists.

---

## Pseudo Code

```text
function solve(s)
    MOD <- 1000000007
    n <- length(s)
    dp <- 1                          // number of distinct subsequences of suffix (including empty)
    lastDP['0'] <- 0
    lastDP['1'] <- 0
    startCount1 <- 0
    hasZero <- false
    for i from n-1 down to 0
        ch <- s[i]
        if ch == '0' then hasZero <- true
        newStarts <- (dp - lastDP[ch]) mod MOD
        if ch == '1' then startCount1 <- (startCount1 + newStarts) mod MOD
        newDP <- (dp * 2 - lastDP[ch]) mod MOD
        lastDP[ch] <- dp
        dp <- (newDP + MOD) mod MOD
    result <- startCount1
    if hasZero then result <- (result + 1) mod MOD   // include single "0"
    return result
```

## Code Explanation

### Dry Run

| Step | i (char) | dp (before) | lastDP['0'] | lastDP['1'] | newStarts | startCount1 | newDP | lastDP[ch] (after) | dp (after) |
| ---- | -------- | ----------- | ----------- | ----------- | --------- | ----------- | ----- | ------------------ | ---------- |
| 1    | 3 ('1')  | 1           | 0           | 0           | 1         | 1           | 2     | lastDP['1']=1      | 2          |
| 2    | 2 ('0')  | 2           | 0           | 1           | 2         | 1           | 4     | lastDP['0']=2      | 4          |
| 3    | 1 ('0')  | 4           | 2           | 1           | 2         | 1           | 6     | lastDP['0']=4      | 6          |

Final: startCount1 = 1, hasZero = true => result = 1+1 = 2

### Pattern 2

**Idea**
Brute-force generate all subsequences, insert into hash set and filter good ones (only for very small n).

**Pseudo Code**

```text
function solve_bruteforce(s)
    set <- empty set
    n <- length(s)
    for mask from 1 to (1<<n)-1
        subseq <- build subsequence from mask
        if subseq == "0" or subseq[0] == '1'
            set.insert(subseq)
    return size(set)
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Right-to-left DP (main) | Build distinct suffix subsequences and count new starts per char | O(n) | O(1) | Yes |
| Standard distinct DP + analytic filter | Left-to-right distinct-subseq, then derive start-with-1 count | O(n) | O(1) | No |
| Brute-force via set | Enumerate all subsequences and deduplicate | O(2^n * n) | O(2^n * n) | No |
