# Single Number II

## Difficulty
Medium

## Description
Given an integer array where every element appears three times except for one which appears exactly once, find the single element.

## Examples

### Example 1

```text
Input: [2,2,3,2]
Output: 3
Explanation: 3 appears once while 2 appears three times.
```

### Example 2

```text
Input: [0,1,0,1,0,1,99]
Output: 99
Explanation: 99 appears once while others appear three times.
```

## Constraints

```text
1 <= nums.length <= 3 * 10^4
-2^31 <= nums[i] <= 2^31 - 1
All elements except one appear exactly three times.
```

---

## Idea
Use two bitmasks (ones, twos) as a finite-state machine to track bits that have appeared once and twice; bits appearing three times are cleared.

---

## Pseudo Code

```text
function singleNumber(nums)
    ones = 0
    twos = 0
    for each num in nums
        new_twos = twos | (ones & num)
        ones = ones ^ num
        common = ones & new_twos
        ones = ones & ~common
        twos = new_twos & ~common
    return ones
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | num | ones(before) | twos(before) | operation | ones(after) | twos(after) |
| ---- | --- | ------------- | ------------- | --------- | ------------ | ------------ |
| 0    | -   | 0             | 0             | init      | 0            | 0            |
| 1    | 2   | 0             | 0             | process   | 2            | 0            |
| 2    | 2   | 2             | 0             | process   | 0            | 2            |
| 3    | 3   | 0             | 2             | process   | 1            | 0            |
| 4    | 2   | 1             | 0             | process   | 3            | 0            |

Otherwise:
1. ones holds bits seen exactly once so far.
2. twos holds bits seen exactly twice so far.
3. new_twos = twos OR (ones AND num) adds bits moving from ones->twos.
4. ones = ones XOR num toggles bits with current num.
5. common = ones AND new_twos identifies bits seen three times.
6. Clear common from ones and twos to reset bits that reached count 3.
7. At the end ones contains the unique number.

## Other Patterns

### Pattern 1

**Idea**
Count bits per position mod 3 and reconstruct the single number.

**Pseudo Code**

```text
function singleNumber(nums)
    bits[0..31] = 0
    for each num in nums
        for i from 0 to 31
            if (num >> i) & 1 == 1 then bits[i] = (bits[i] + 1) % 3
    result = 0
    for i from 0 to 31
        if bits[i] == 1 then result = result | (1 << i)
    return result (handle sign if using 32-bit signed)
```

### Pattern 2

**Idea**
Use a hash map to count occurrences and return the key with count 1.

**Pseudo Code**

```text
function singleNumber(nums)
    map = empty hash map
    for each num in nums
        map[num] = map.get(num,0) + 1
    for each (key,value) in map
        if value == 1 then return key
```

## Comparison

| Approach                 | Idea                          | Time | Space | Recommended |
| ------------------------ | ----------------------------- | ---- | ----- | ----------- |
| Bitwise state machine    | Track ones/twos and clear triplets | O(n) | O(1)  | Yes         |
| Bit counting per position| Count each bit modulo 3       | O(n) | O(1)  | Yes (clearer for sign handling) |
| Hash map counting        | Count frequencies with map    | O(n) | O(n)  | No          |
