# Counting Bits

## Difficulty
Easy

## Description
Given a non-negative integer n, return an array ans of length n+1 where ans[i] is the number of 1's in the binary representation of i.

## Examples

### Example 1

```text
Input: n = 5
Output: [0,1,1,2,1,2]
Explanation:
0 -> 0
1 -> 1
2 -> 10 (1)
3 -> 11 (2)
4 -> 100 (1)
5 -> 101 (2)
```

### Example 2

```text
Input: n = 0
Output: [0]
```

## Constraints

```text
0 <= n <= 10^5
Return array of length n+1
```

---

## Idea
Use DP: bits[i] = bits[i & (i - 1)] + 1 which removes the lowest set bit.

---

## Pseudo Code

```text
function countBits(n)
    create array bits of size n + 1
    bits[0] = 0
    for i from 1 to n
        bits[i] = bits[i & (i - 1)] + 1
    return bits
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | State (bits)     | Operation                    | Result         |
| ---- | ---------------- | ---------------------------- | -------------- |
| 1    | [0]              | i=1 -> bits[1] = bits[1&0]+1 | [0,1]          |
| 2    | [0,1]            | i=2 -> bits[2] = bits[2&1]+1 | [0,1,1]        |
| 3    | [0,1,1]          | i=3 -> bits[3] = bits[3&2]+1 | [0,1,1,2]      |
| 4    | [0,1,1,2]        | i=4 -> bits[4] = bits[4&3]+1 | [0,1,1,2,1]    |
| 5    | [0,1,1,2,1]      | i=5 -> bits[5] = bits[5&4]+1 | [0,1,1,2,1,2]  |

## Other Patterns

### Pattern 1

**Idea**
DP via right shift: bits[i] = bits[i >> 1] + (i & 1)

**Pseudo Code**

```text
function countBits(n)
    create array bits of size n + 1
    bits[0] = 0
    for i from 1 to n
        bits[i] = bits[i >> 1] + (i & 1)
    return bits
```

### Pattern 2

**Idea**
Use highest power of two offset: bits[i] = bits[i - offset] + 1 where offset is largest power of two <= i

**Pseudo Code**

```text
function countBits(n)
    create array bits of size n + 1
    bits[0] = 0
    offset = 1
    for i from 1 to n
        if i == offset * 2 then offset = offset * 2
        bits[i] = bits[i - offset] + 1
    return bits
```

### Pattern 3

**Idea**
Brute force popcount per number using i & (i - 1)

**Pseudo Code**

```text
function countBits(n)
    create array bits of size n + 1
    for i from 0 to n
        x = i
        count = 0
        while x != 0
            x = x & (x - 1)
            count = count + 1
        bits[i] = count
    return bits
```

## Comparison

| Approach          | Idea                                      | Time    | Space | Recommended |
| ----------------- | ----------------------------------------- | ------- | ----- | ----------- |
| Low-bit DP        | bits[i] = bits[i & (i-1)] + 1             | O(n)    | O(n)  | Yes         |
| Shift DP          | bits[i] = bits[i >> 1] + (i & 1)          | O(n)    | O(n)  | Yes         |
| Offset DP         | bits[i] = bits[i - offset] + 1            | O(n)    | O(n)  | Yes         |
| Brute-force popcnt| Count bits by removing lowest set bit     | O(n log n)| O(n)| No          |
