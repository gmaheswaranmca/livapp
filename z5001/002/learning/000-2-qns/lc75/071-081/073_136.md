# Single Number

## Difficulty
Easy

## Description
Given a non-empty array of integers where every element appears twice except for one. Find that single one.

## Examples

### Example 1

```text
Input: [2,2,1]
Output: 1
Explanation: 2 XOR 2 XOR 1 = 1
```

### Example 2

```text
Input: [4,1,2,1,2]
Output: 4
Explanation: 4 XOR 1 XOR 2 XOR 1 XOR 2 = 4
```

## Constraints

```text
1 <= nums.length <= 3 * 10^4
-2^31 <= nums[i] <= 2^31 - 1
Every element appears exactly twice except for one element which appears once.
```

---

## Idea
Use XOR to cancel paired numbers; XOR of all elements yields the unique element.

---

## Pseudo Code

```text
function singleNumber(nums)
    result = 0
    for each num in nums
        result = result XOR num
    return result
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State         | Operation         | Result |
| ---- | ------------- | ----------------- | ------ |
| 1    | result = 0    | process 2         | result = 2 |
| 2    | result = 2    | process 2         | result = 0 |
| 3    | result = 0    | process 1         | result = 1 |

## Other Patterns

### Pattern 1

**Idea**

Use a hash map (frequency) to find the element with count 1.

**Pseudo Code**

```text
function singleNumber_hash(nums)
    map = empty map
    for each num in nums
        map[num] = map.get(num, 0) + 1
    for each (key, value) in map
        if value == 1
            return key
```

### Pattern 2

**Idea**

Sort the array and scan to find the unmatched element.

**Pseudo Code**

```text
function singleNumber_sort(nums)
    sort(nums)
    i = 0
    while i < length(nums) - 1
        if nums[i] != nums[i+1]
            return nums[i]
        i = i + 2
    return nums[length(nums)-1]
```

## Comparison

| Approach  | Idea                          | Time     | Space | Recommended |
| --------- | ----------------------------- | -------- | ----- | ----------- |
| XOR       | XOR all numbers               | O(n)     | O(1)  | Yes        |
| Hash Map  | Count frequencies             | O(n)     | O(n)  | No         |
| Sorting   | Sort and scan for unpaired    | O(n log n)| O(1) or O(n) | No         |
