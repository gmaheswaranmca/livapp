# Counting Bits

## Difficulty
Easy

## Description
Given an integer n, return an array ans of length n+1 where ans[i] is the number of 1 bits in the binary representation of i.

## Examples

### Example 1

```text
Input:  n = 5
Output: [0,1,1,2,1,2]
Explanation: binary(0)=0,1=1,2=10,3=11,4=100,5=101
```

### Example 2

```text
Input:  n = 2
Output: [0,1,1]
Explanation: binary(0)=0,1=1,2=10
```

## Constraints

```text
0 <= n <= 10^5
Expected output size: n+1
Time limit: typical single-pass O(n)
```

---

## Idea
Use DP with bit relation: dp[i] = dp[i & (i-1)] + 1 (remove lowest set bit).

---

## Pseudo Code

```text
function countBits(n)
    allocate array dp of size n+1
    dp[0] = 0
    for i from 1 to n
        dp[i] = dp[i & (i - 1)] + 1
    return dp
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n)   |

---

## Code Explanation

### Dry Run

| Step | State         | Operation                     | Result        |
| ---- | ------------- | ----------------------------- | ------------- |
| 1    | dp = [0,_,_,_,_,_] | initialize dp[0]=0            | [0,_,_,_,_,_] |
| 2    | i=1           | dp[1]=dp[1&(0)]+1 = dp[0]+1   | [0,1,_,_,_,_] |
| 3    | i=2           | dp[2]=dp[2&(1)]+1 = dp[0]+1   | [0,1,1,_,_,_] |
| 4    | i=3           | dp[3]=dp[3&(2)]+1 = dp[2]+1   | [0,1,1,2,_,_] |
| 5    | i=4           | dp[4]=dp[4&(3)]+1 = dp[0]+1   | [0,1,1,2,1,_] |
| 6    | i=5           | dp[5]=dp[5&(4)]+1 = dp[4]+1   | [0,1,1,2,1,2] |

## Other Patterns

### Pattern 2

**Idea**

Use right-shift relation: dp[i] = dp[i >> 1] + (i & 1)

**Pseudo Code**

```text
function countBits(n)
    allocate array dp of size n+1
    dp[0] = 0
    for i from 1 to n
        dp[i] = dp[i >> 1] + (i & 1)
    return dp
```

### Pattern 3

**Idea**

Use highest power of two: dp[i] = dp[i - highbit] + 1, track highbit.

**Pseudo Code**

```text
function countBits(n)
    allocate array dp of size n+1
    dp[0] = 0
    highbit = 1
    for i from 1 to n
        if i == highbit * 2
            highbit = highbit * 2
        dp[i] = dp[i - highbit] + 1
    return dp
```

## Comparison

| Approach         | Idea                                 | Time | Space | Recommended |
| ---------------- | ------------------------------------ | ---- | ----- | ----------- |
| i & (i-1)        | Remove lowest set bit: dp[i]=dp[i&(i-1)]+1 | O(n) | O(n)  | Yes         |
| Right shift      | Use dp[i>>1] + (i&1)                 | O(n) | O(n)  | Yes         |
| Highest bit      | Subtract highest power-of-two        | O(n) | O(n)  | Yes (good)  |
