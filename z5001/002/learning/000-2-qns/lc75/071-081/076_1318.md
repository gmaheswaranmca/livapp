# Title
Minimum Flips to Make a OR b Equal c

## Difficulty
Easy / Interview

## Description
Given three non-negative integers a, b, c, return the minimum number of bit flips required in a and/or b so that (a OR b) == c. A flip changes a single bit from 0 to 1 or from 1 to 0.

## Examples

### Example 1

```text
Input: a = 2, b = 6, c = 5
Output: 3
Explanation: 
a = 010, b = 110, c = 101 (binary).
Bit 0: a0|b0 = 0, c0 = 1 -> flip one bit -> +1
Bit 1: a1|b1 = 1, c1 = 0 -> both a1 and/or b1 that are 1 must be flipped; here both are 1 -> +2
Bit 2: a2|b2 = 1, c2 = 1 -> no flips
Total = 3
```

### Example 2

```text
Input: a = 0, b = 0, c = 0
Output: 0
Explanation: Already equal.
```

### Example 3

```text
Input: a = 1, b = 2, c = 3
Output: 0
Explanation: 01 | 10 = 11 == c.
```

## Constraints

```text
0 <= a, b, c <= 10^9
Work with bits up to max bit-length of (a, b, c)
```

---

## Idea
Count required flips per bit: if c_bit == 1 and (a_bit|b_bit)==0 -> +1; if c_bit == 0 -> add number of 1s among a_bit and b_bit (1 -> +1, 2 -> +2).

---

## Pseudo Code

```text
function minFlips(a, b, c)
    flips <- 0
    while a > 0 or b > 0 or c > 0
        abit <- a & 1
        bbit <- b & 1
        cbit <- c & 1
        if cbit == 1 and (abit | bbit) == 0
            flips <- flips + 1
        else if cbit == 0
            flips <- flips + (abit + bbit)  // 0,1 or 2
        a <- a >> 1
        b <- b >> 1
        c <- c >> 1
    return flips
```

## Code Explanation

### Dry Run

| Step | State (a,b,c) | Bits processed (a0,b0,c0) | Operation                                | Result (flips cumulative) |
| ---- | ------------- | ------------------------- | ---------------------------------------- | ------------------------- |
| 1    | (2,6,5) -> (10,110,101) | bit0: (0,0,1)          | cbit==1 and a|b==0 -> +1                | 1                         |
| 2    | (1,3,2) -> shift right  | bit1: (1,1,0)          | cbit==0 -> add a+b = 2                   | 3                         |
| 3    | (0,1,1)                 | bit2: (0,1,1)          | cbit==1 and a|b==1 -> +0                 | 3                         |

1. Iterate bits until all numbers exhausted.
2. Extract LSB of a,b,c each iteration.
3. Apply rules: if c_bit==1 and both a,b have 0 -> +1; if c_bit==0 -> add number of 1s in a_bit and b_bit.
4. Shift a,b,c right and accumulate flips.

## Other Patterns

### Pattern 1

**Idea**

Bit-by-bit scan using LSB extraction (chosen primary).

**Pseudo Code**

```text
function minFlips(a, b, c)
    flips <- 0
    while a > 0 or b > 0 or c > 0
        abit <- a & 1
        bbit <- b & 1
        cbit <- c & 1
        if cbit == 1 and (abit | bbit) == 0
            flips <- flips + 1
        else if cbit == 0
            flips <- flips + (abit + bbit)
        a <- a >> 1
        b <- b >> 1
        c <- c >> 1
    return flips
```

### Pattern 2

**Idea**

Use bit masks and bit-count (popcount): flips = popcount((~c) & a) + popcount((~c) & b) + popcount(c & ~(a|b)).

**Pseudo Code**

```text
function minFlips_using_popcount(a, b, c)
    maxBits <- max(bit_length(a), bit_length(b), bit_length(c), 1)
    mask <- (1 << maxBits) - 1
    notc <- (~c) & mask
    flips <- popcount(notc & a) + popcount(notc & b) + popcount(c & ~(a | b))
    return flips
```
