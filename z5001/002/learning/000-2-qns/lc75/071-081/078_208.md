# Implement Trie (Prefix Tree)

## Difficulty
Medium

## Description
Design a trie (prefix tree) with insert, search and startsWith operations for lowercase English words. Implement methods: insert(word), search(word) -> bool, startsWith(prefix) -> bool.

## Examples

### Example 1

```text
Input:
insert("apple")
search("apple")
search("app")
startsWith("app")
insert("app")
search("app")
Output:
true
false
true
true
Explanation:
After inserting "apple", search("apple") is true, search("app") is false, startsWith("app") is true.
After inserting "app", search("app") is true.
```

## Constraints

```text
1 <= word.length, prefix.length <= 1000
word and prefix contain only lowercase English letters
At most 10^4 calls to insert, search and startsWith
```

---

## Idea
Use a root node with children (map or fixed array) and a boolean end flag; traverse/create nodes per character.

---

## Pseudo Code

```text
structure TrieNode
    children : map<char, TrieNode>   // or array[26] of TrieNode
    isEnd : boolean

function Trie()
    root = new TrieNode()

function insert(word)
    node = root
    for each ch in word
        if ch not in node.children
            node.children[ch] = new TrieNode()
        node = node.children[ch]
    node.isEnd = true

function search(word)
    node = root
    for each ch in word
        if ch not in node.children
            return false
        node = node.children[ch]
    return node.isEnd

function startsWith(prefix)
    node = root
    for each ch in prefix
        if ch not in node.children
            return false
        node = node.children[ch]
    return true
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(L) per operation where L = length of word/prefix |
| Space Complexity | O(N * A) where N = total inserted characters, A = alphabet factor (26 or map overhead) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | root:{} | insert("apple") create nodes a->p->p->l->e and mark e.isEnd=true | trie contains "apple" |
| 2    | root:{a->...} | search("apple") traverse a->p->p->l->e and check isEnd | true |
| 3    | same | search("app") traverse a->p->p and check isEnd (false) | false |
| 4    | same | startsWith("app") traverse a->p->p exists | true |
| 5    | same | insert("app") traverse a->p->p and set node.isEnd=true | "app" and "apple" stored |
| 6    | same | search("app") traverse a->p->p and check isEnd | true |

## Other Patterns

### Pattern 1

**Idea**
Store all words and all prefixes in hash sets for O(1) queries.

**Pseudo Code**

```text
function TrieHashSet()
    words = empty set
    prefixes = empty set

function insert(word)
    add word to words
    prefix = ""
    for each ch in word
        prefix = prefix + ch
        add prefix to prefixes

function search(word)
    return word in words

function startsWith(prefix)
    return prefix in prefixes
```

### Pattern 2

**Idea**
Use fixed-size array[26] children in nodes for lower memory and faster access.

**Pseudo Code**

```text
structure TrieNodeArray
    children : array[26] of TrieNode
    isEnd : boolean

function insert(word)
    node = root
    for each ch in word
        idx = ch - 'a'
        if node.children[idx] is null
            node.children[idx] = new TrieNodeArray()
        node = node.children[idx]
    node.isEnd = true
```

### Pattern 3

**Idea**
Use compressed trie (radix tree) to merge chains and save space.

**Pseudo Code**

```text
structure RadixNode
    label : string
    children : map<char, RadixNode>
    isEnd : boolean

function insert(word)
    node = root
    while word not empty
        find child with common prefix between child.label and word
        if no common prefix
            add new child with label = word and isEnd = true
            return
        split child if partial match
        advance node and shorten word accordingly
    set node.isEnd = true
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Trie (map children) | Node per char with hashmap children | O(L) | O(N * map overhead) | Yes |
| Trie (array children) | Node per char with array[26] children | O(L) | O(N * 26) | Yes (when alphabet small) |
| HashSet prefixes | Store all prefixes | O(L) insert, O(1) query | O(N * L) heavy | No (space heavy) |
| Compressed trie | Merge chains into labels | O(L) amortized complex | Better than trie for long chains | No (complex to implement)
