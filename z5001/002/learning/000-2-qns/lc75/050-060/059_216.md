# 059 Combination Sum III

## Difficulty
Medium

## Description
Find all unique combinations of k distinct numbers from 1 to 9 that add up to n. Each number may be used once in a combination. Return combinations in any order.

## Examples

### Example 1

```text
Input: k = 3, n = 7
Output: [[1,2,4]]
Explanation: Only combination of 3 numbers from 1..9 summing to 7 is [1,2,4].
```

### Example 2

```text
Input: k = 3, n = 9
Output: [[1,2,6],[1,3,5],[2,3,4]]
Explanation: All unique 3-number combos from 1..9 that sum to 9.
```

## Constraints

```text
1 <= k <= 9
1 <= n <= 60
Numbers allowed: 1..9 distinct
```

---

## Idea
Backtrack by choosing increasing numbers from 1..9, prune when sum exceeds n or remaining spots cannot be filled.

---

## Pseudo Code

```text
function combinationSum3(k,n)
    result = []
    path = []
    backtrack(start=1, remain=n, slots=k)
    return result

function backtrack(start, remain, slots)
    if remain == 0 and slots == 0
        add copy of path to result
        return
    if remain < 0 or slots == 0
        return
    for num from start to 9
        if num > remain
            break
        if num > 9 - (slots - 1) + 1 then break
        append num to path
        backtrack(num+1, remain - num, slots - 1)
        remove last element from path
```

---

## Complexity

| Metric           | Value                                  |
| ---------------- | -------------------------------------- |
| Time Complexity  | O(C(9,k) * k) (or O(2^9) worst-case)  |
| Space Complexity | O(k) recursion depth + output size     |

---

## Code Explanation

### Dry Run

| Step | State         | Operation                        | Result             |
| ---- | ------------- | -------------------------------- | ------------------ |
| 1    | path=[]       | backtrack(start=1,remain=7,3)    | iterate num=1      |
| 2    | path=[1]      | backtrack(start=2,remain=6,2)    | iterate num=2      |
| 3    | path=[1,2]    | backtrack(start=3,remain=4,1)    | iterate num=3..4   |
| 4    | path=[1,2,4]  | remain==0 and slots==0           | add [1,2,4] to res |
| 5    | path=[1,2]    | backtrack returns                 | continue loop      |
| 6    | path=[]       | explore other starts              | no other valid    |

## Other Patterns

### Pattern 1

**Idea**

Enumerate all subsets of 1..9 by bitmask and check size and sum.

**Pseudo Code**

```text
function combinationSum3_bitmask(k,n)
    result = []
    for mask from 1 to (1<<9)-1
        if popcount(mask) != k then continue
        sum = 0
        path = []
        for i from 0 to 8
            if (mask >> i) & 1 == 1
                sum += i+1
                append i+1 to path
        if sum == n
            add path to result
    return result
```

### Pattern 2

**Idea**

Generate combinations by recursive choose/unchoose with early bound checks using combinatorial limits.

**Pseudo Code**

```text
function combinationSum3_choose(k,n)
    result = []
    path = []
    generate(start=1,slots=k,remain=n)
    return result

function generate(start, slots, remain)
    if slots == 0
        if remain == 0 then add copy of path to result
        return
    for num from start to 9 - slots + 1
        if num > remain then break
        append num to path
        generate(num+1, slots-1, remain-num)
        remove last element from path
```

## Comparison

| Approach              | Idea                                    | Time                | Space            | Recommended |
| --------------------- | --------------------------------------- | ------------------- | ---------------- | ----------- |
| Backtracking (main)   | DFS with pruning                        | O(C(9,k)*k)         | O(k) + output    | Yes         |
| Bitmask enumeration   | Try all 2^9 subsets                     | O(2^9 * 9)          | O(k) + output    | No          |
| Recursive choose-only | Generate combinations with bounds       | O(C(9,k)*k)         | O(k) + output    | Yes         |
