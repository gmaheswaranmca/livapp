# Maximum Subsequence Score

## Difficulty
Hard

## Description
Given two integer arrays nums1 and nums2 of equal length n and an integer k, choose a subsequence of indices of length k to maximize the score defined as (sum of chosen nums1 values) * (minimum of chosen nums2 values). Return the maximum possible score.

## Examples

### Example 1

```text
Input: nums1 = [1,3,3,2], nums2 = [2,1,3,4], k = 3
Output: 12
Explanation: Choose indices [0,2,3] => sum(nums1)=1+3+2=6, min(nums2)=2 => 6*2=12
```

### Example 2

```text
Input: nums1 = [4,2,3,1,1], nums2 = [7,5,10,9,6], k = 1
Output: 30
Explanation: Choose index [2] => 3*10 = 30
```

## Constraints

```text
1 <= k <= n <= 10^5
nums1.length == nums2.length == n
0 <= nums1[i], nums2[i] <= 10^5
Answer fits in 64-bit signed integer
```

---

## Idea
Sort indices by nums2 descending, iterate considering each nums2 as the minimum and maintain the top-k largest nums1 using a min-heap to compute sum * current nums2.

---

## Pseudo Code

```text
function maxSubsequenceScore(nums1, nums2, k)
    n <- length(nums1)
    pairs <- empty list
    for i from 0 to n-1
        append (nums1[i], nums2[i]) to pairs
    sort pairs by second element descending

    minHeap <- empty min-heap
    sumNums1 <- 0
    best <- 0

    for each (val1, val2) in pairs
        push val1 into minHeap
        sumNums1 <- sumNums1 + val1
        if size(minHeap) > k
            removed <- pop minHeap (smallest)
            sumNums1 <- sumNums1 - removed
        if size(minHeap) == k
            score <- sumNums1 * val2
            if score > best
                best <- score
    return best
```

## Code Explanation

### Dry Run

| Step | Current pair (val1,val2) | Heap (min-heap) | sumNums1 | size | Computed score | best |
| ---- | ------------------------- | ---------------- | -------- | ---- | -------------- | ---- |
| 1    | (2,4)                     | [2]              | 2        | 1    | -              | 0    |
| 2    | (3,3)                     | [2,3]            | 5        | 2    | -              | 0    |
| 3    | (1,2)                     | [1,2,3]          | 6        | 3    | 6*2 = 12      | 12   |
| 4    | (3,1)                     | after push [1,2,3,3] -> pop 1 -> [2,3,3] | 8 | 3 | 8*1 = 8 | 12 |

1. Create pairs (nums1[i], nums2[i]) and sort by nums2 descending so current val2 is the minimum among chosen.
2. Maintain a min-heap of chosen nums1 values and their running sum.
3. Keep heap size ≤ k by popping smallest nums1; when size == k compute candidate score = sum * current nums2.
4. Track maximum score and return it.

## Other Patterns

### Pattern 1

**Idea**  
Sort by nums2 descending and maintain top-k nums1 with a min-heap.

**Pseudo Code**

```text
function maxSubsequenceScore(nums1, nums2, k)
    pairs <- zip(nums1, nums2)
    sort pairs by second desc
    minHeap, sum, best <- empty, 0, 0
    for (a,b) in pairs
        push a into minHeap
        sum <- sum + a
        if size(minHeap) > k
            sum <- sum - pop(minHeap)
        if size(minHeap) == k
            best <- max(best, sum * b)
    return best
```

### Pattern 2

**Idea**  
Iterate distinct nums2 values as threshold, collect indices with nums2 >= threshold and take top-k nums1 using selection/partial sort; compute score.

**Pseudo Code**

```text
function maxSubsequenceScore(nums1, nums2, k)
    uniqueVals <- unique(nums2) sorted descending
    best <- 0
    for val in uniqueVals
        candidates <- [nums1[i] for i where nums2[i] >= val]
        if length(candidates) < k continue
        topKsum <- sum of k largest in candidates (use nth_element / partial sort)
        best <- max(best, topKsum * val)
    return best
```

### Pattern 3

**Idea**  
Brute force combinations of k indices (only for very small n).

**Pseudo Code**

```text
function maxSubsequenceScore_bruteforce(nums1, nums2, k)
    best <- 0
    for each subset S of indices of size k
        sumA <- sum(nums1[i] for i in S)
        minB <- min(nums2[i] for i in S)
        best <- max(best, sumA * minB)
    return best
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Sort + Heap | Sort by nums2 desc, maintain min-heap of nums1 size k | O(n log n) | O(n) | Yes |

| Brute Force | Try all k-combinations | O(C(n,k) * k) | O(k) | No (only tiny n)
