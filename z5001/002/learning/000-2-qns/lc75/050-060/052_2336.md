# Smallest Number in Infinite Set

## Difficulty
Medium

## Description
Design a data structure that represents the infinite set of positive integers {1,2,3,...} and supports:
- popSmallest(): remove and return the smallest number in the set.
- addBack(num): add num back into the set if it was previously popped.

Implement efficiently so addBack and popSmallest operate in logarithmic or amortized constant time.

## Examples

### Example 1

```text
Input: 
["SmallestInfiniteSet","addBack","popSmallest","popSmallest","popSmallest","addBack","popSmallest"]
[[],[2],[],[],[],[2],[]]
Output:
[null,null,1,2,3,null,2]
Explanation:
SmallestInfiniteSet(); // set = {1,2,3,...}
addBack(2);           // 2 already present implicitly -> no change
popSmallest();        // returns 1
popSmallest();        // returns 2
popSmallest();        // returns 3
addBack(2);           // 2 was popped -> add back
popSmallest();        // returns 2
```

## Constraints

```text
1 <= num <= 1000 (typically small integers)
At most 1000 calls to popSmallest and addBack combined
Operations should be near O(log n) or amortized O(1)
```

---

## Idea
Maintain a min-heap of numbers that were added back and a hash-set to avoid duplicates; use a pointer "next" for the implicit infinite sequence.

---

## Pseudo Code

```text
function SmallestInfiniteSet()
    heap <- empty min-heap
    set <- empty hash-set
    next <- 1

function popSmallest()
    if heap is not empty
        val <- heap.pop()
        set.remove(val)
        return val
    val <- next
    next <- next + 1
    return val

function addBack(num)
    if num >= next
        return
    if num in set
        return
    heap.push(num)
    set.add(num)
```

---

## Complexity

| Metric           | Value                |
| ---------------- | -------------------- |
| Time Complexity  | popSmallest: O(log m) worst-case, O(1) if using next; addBack: O(log m) worst-case |
| Space Complexity | O(m) where m = size of heap/set (numbers added back) |

## Code Explanation

### Dry Run

| Step | State (heap, set, next) | Operation      | Result / Output |
| ---- | ----------------------- | -------------- | --------------- |
| 1    | ([], {}, 1)             | SmallestInfiniteSet() | init |
| 2    | ([], {}, 1)             | addBack(2)     | no-op (2 >= next) |
| 3    | ([], {}, 1)             | popSmallest()  | returns 1 -> state becomes ([], {}, 2) |
| 4    | ([], {}, 2)             | popSmallest()  | returns 2 -> state becomes ([], {}, 3) |
| 5    | ([], {}, 3)             | popSmallest()  | returns 3 -> state becomes ([], {}, 4) |

| 7    | ([2], {2}, 4)          | popSmallest()  | pop 2 -> returns 2 -> ([], {}, 4) |

## Other Patterns

### Pattern 1

**Idea**
Use a balanced BST (TreeSet) storing numbers that are currently present up to some high bound and a pointer for the unbounded tail.

**Pseudo Code**
```text
function SmallestInfiniteSet()
    tree <- empty ordered-set
    next <- 1

function popSmallest()
    if tree is not empty
        val <- tree.min()
        tree.remove(val)
        return val
    val <- next
    next <- next + 1
    return val

function addBack(num)
    if num >= next
        return
    tree.add(num)
```

### Pattern 2

**Idea**
Use a boolean array visited[1..MAX] and a pointer next; push addBack items into a min-heap only when they are less than next and not visited.

**Pseudo Code**
```text
function SmallestInfiniteSet(MAX)
    visited <- boolean array size MAX+1 initialized false
    heap <- empty min-heap
    next <- 1

function popSmallest()
    while next <= MAX and visited[next] == true
        next <- next + 1
    if heap is not empty and (next > MAX or heap.min() < next)
        val <- heap.pop()
        visited[val] <- false
        return val
    val <- next
    next <- next + 1
    return val

function addBack(num)
    if num >= next or visited[num] == false
        return
    if not in heap
        heap.push(num)
        visited[num] <- true
```

## Comparison

| Approach         | Idea                            | Time                       | Space     | Recommended |
| ---------------- | ------------------------------- | -------------------------- | --------- | ----------- |
| Heap + HashSet   | Min-heap for added-back + next  | pop/add: O(log m) worst    | O(m)      | Yes         |
| TreeSet (BST)    | Ordered set of available items  | pop/add: O(log m)          | O(m)      | No (simple but heavier) |
| Bool array+heap  | Fixed-size visited + heap       | pop/add: O(log m) + O(1)   | O(MAX)    | No (needs upper bound) |
