# Title
060 - Letter Combinations of a Phone Number

## Difficulty
Medium

## Description
Given a string containing digits from 2-9 inclusive, return all possible letter combinations that the number could represent using the phone keypad mapping. Return an empty list if input is empty.

## Examples

### Example 1

```text
Input: digits = "23"
Output: ["ad","ae","af","bd","be","bf","cd","ce","cf"]
Explanation: Digit '2' -> [a,b,c], Digit '3' -> [d,e,f]. All combinations of one letter from each digit.
```

### Example 2

```text
Input: digits = ""
Output: []
Explanation: Empty input yields no combinations.
```

## Constraints

```text
0 <= digits.length <= 4
digits[i] is a digit in the range ['2','9']
Total combinations <= 4^4 = 256
```

---

## Idea
Backtracking (DFS) building prefixes one digit at a time and collecting full-length strings.

---

## Pseudo Code

```text
function letterCombinations(digits)
    mapping = {
        '2': "abc", '3': "def", '4': "ghi",
        '5': "jkl", '6': "mno", '7': "pqrs",
        '8': "tuv", '9': "wxyz"
    }
    if digits == "" return []
    result = []
    function backtrack(index, path)
        if index == length(digits)
            append path to result
            return
        letters = mapping[digits[index]]
        for letter in letters
            backtrack(index + 1, path + letter)
    backtrack(0, "")
    return result
```

---

## Complexity

| Metric           | Value                     |
| ---------------- | ------------------------- |
| Time Complexity  | O(4^N * N)                |
| Space Complexity | O(N) (recursion) + O(4^N * N) output |

## Code Explanation

### Dry Run

| Step | State (prefix) | Operation                          | Result added |
| ---- | -------------- | ---------------------------------- | ------------ |
| 1    | "a"            | choose 'd' from digit '3'          | "ad"         |
| 2    | "a"            | choose 'e' from digit '3'          | "ae"         |
| 3    | "a"            | choose 'f' from digit '3'          | "af"         |
| 4    | "b"            | choose 'd' from digit '3'          | "bd"         |
| 5    | "b"            | choose 'e' from digit '3'          | "be"         |
| 6    | "b"            | choose 'f' from digit '3'          | "bf"         |
| 7    | "c"            | choose 'd' from digit '3'          | "cd"         |
| 8    | "c"            | choose 'e' from digit '3'          | "ce"         |
| 9    | "c"            | choose 'f' from digit '3'          | "cf"         |

1. Start with empty prefix.
2. For each letter mapped from the first digit extend prefix and recurse.
3. When prefix length equals digits length append to result.
4. Backtrack to explore remaining letters.

## Other Patterns

### Pattern 1

**Idea**
Iterative BFS-like expansion of prefixes for each digit.

**Pseudo Code**

```text
function letterCombinations(digits)
    mapping = {...}
    if digits == "" return []
    queue = [""]
    for digit in digits
        temp = []
        for prefix in queue
            for letter in mapping[digit]
                append prefix + letter to temp
        queue = temp
    return queue
```

### Pattern 2

**Idea**
Compute Cartesian product of letter lists and join each tuple.

**Pseudo Code**

```text
function letterCombinations(digits)
    mapping = {...}
    if digits == "" return []
    lists = [mapping[d] for d in digits]
    result = cartesian_product_join(lists)  # returns joined strings
    return result
```

## Comparison

| Approach     | Idea                                 | Time        | Space                        | Recommended |
| ------------ | ------------------------------------ | ----------- | ---------------------------- | ----------- |
| Backtracking | DFS building prefixes                | O(4^N * N)  | O(N) recursion + output      | Yes         |
| Iterative    | BFS-like prefix expansion            | O(4^N * N)  | O(4^N * N)                   | Yes         |
| Cartesian    | Cartesian product then join results  | O(4^N * N)  | O(4^N * N)                   | No (less explicit) |
