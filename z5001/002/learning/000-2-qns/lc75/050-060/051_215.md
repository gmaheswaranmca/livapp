# Kth Largest Element in an Array

## Difficulty
Medium

## Description
Find the k-th largest element in an unsorted array.

## Examples

### Example 1

```text
Input: nums = [3,2,1,5,6,4], k = 2
Output: 5
Explanation: The 2nd largest element is 5.
```

### Example 2

```text
Input: nums = [3,2,3,1,2,4,5,5,6], k = 4
Output: 4
Explanation: The 4th largest element is 4.
```

## Constraints

```text
1 <= k <= nums.length <= 10^5
-10^9 <= nums[i] <= 10^9
Time limits require O(n log k) or better for large arrays
```

---

## Idea
Maintain a min-heap of size k containing the k largest seen elements; the heap root is the k-th largest.

---

## Pseudo Code

```text
function findKthLargest(nums, k)
    create empty minHeap
    for each num in nums
        push num into minHeap
        if size of minHeap > k
            pop root from minHeap
    return root of minHeap
```

---

## Complexity

| Metric           | Value    |
| ---------------- | -------- |
| Time Complexity  | O(n log k) |
| Space Complexity | O(k)     |

---

## Code Explanation

### Dry Run

| Step | State (minHeap) | Operation                     | Result (minHeap) |
| ---- | ---------------- | ----------------------------- | ---------------- |
| 1    | []               | push 3                        | [3]             |
| 2    | [3]              | push 2                        | [2,3]           |
| 3    | [2,3]            | push 1                        | [1,3,2]         |
| 4    | [1,3,2]          | push 5 ; size>2 pop root 1    | [2,3,5] -> after pop [2,3,5] trimmed to k=2 -> actual [3,5] |

| Final| [5,6]            | return root                   | 5               |

## Other Patterns

### Pattern 1

**Idea**

Use Quickselect (partition-based selection) to find k-th largest in average O(n).

**Pseudo Code**

```text
function findKthLargest(nums, k)
    targetIndex = length(nums) - k
    return quickselect(nums, 0, length(nums)-1, targetIndex)

function quickselect(nums, left, right, targetIndex)
    if left == right
        return nums[left]
    pivotIndex = partition(nums, left, right)
    if pivotIndex == targetIndex
        return nums[pivotIndex]
    else if pivotIndex < targetIndex
        return quickselect(nums, pivotIndex+1, right, targetIndex)
    else
        return quickselect(nums, left, pivotIndex-1, targetIndex)

function partition(nums, left, right)
    choose pivot = nums[right]
    storeIndex = left
    for i from left to right-1
        if nums[i] < pivot
            swap nums[i] and nums[storeIndex]
            storeIndex = storeIndex + 1
    swap nums[storeIndex] and nums[right]
    return storeIndex
```

### Pattern 2

**Idea**

Sort array descending and take element at index k-1.

**Pseudo Code**

```text
function findKthLargest(nums, k)
    sort nums in descending order
    return nums[k-1]
```

## Comparison

| Approach   | Idea                            | Time         | Space  | Recommended |
| ---------- | ------------------------------- | ------------ | ------ | ----------- |
| Min-Heap   | Maintain min-heap of size k     | O(n log k)   | O(k)   | Yes         |
| Quickselect| Partition to target index       | O(n) average, O(n^2) worst | O(1)  | Yes         |
| Sort       | Full sort then index            | O(n log n)   | O(1) or O(n) | No          |
