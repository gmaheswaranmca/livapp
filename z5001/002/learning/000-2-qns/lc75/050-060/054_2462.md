# Total Cost to Hire K Workers

## Difficulty
Medium

## Description
Given an array costs of non-negative integers and an integer k, choose exactly k workers minimizing the total hiring cost. You may hire any worker; each worker can be hired at most once.

## Examples

### Example 1

```text
Input: costs=[17,12,10,2,7,2,11,20,8], k=3
Output: 11
Explanation: Select costs 2, 2, and 7 => 2+2+7 = 11
```

## Constraints

```text
1 <= k <= n == costs.length <= 10^5
0 <= costs[i] <= 10^9
```

---

## Idea
Use a min-heap of all costs and extract the smallest k elements.

---

## Pseudo Code

```text
function totalCostMinHeap(costs, k)
    if k <= 0 or costs is empty
        return 0
    create minHeap from costs
    total <- 0
    for i from 1 to k
        val <- pop minHeap
        total <- total + val
    return total
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n + k log n) |
| Space Complexity | O(n)  |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | heap=[2,2,7,8,11,10,12,20,17] after heapify | pop -> 2 | total=2 |
| 2    | heap after pop | pop -> 2 | total=4 |
| 3    | heap after pop | pop -> 7 | total=11 |

1. Build a min-heap from the costs array (heapify O(n)).
2. Pop the smallest element k times, accumulating the sum.
3. Return the accumulated sum.

## Other Patterns

### Pattern 1

**Idea**
Maintain a max-heap of size k with the k smallest seen so far.

**Pseudo Code**

```text
function totalCostMaxHeapSizeK(costs, k)
    if k <= 0 or costs is empty
        return 0
    create empty maxHeap
    for each cost in costs
        if size(maxHeap) < k
            push maxHeap cost
        else if cost < top(maxHeap)
            pop maxHeap
            push maxHeap cost
    total <- sum of elements in maxHeap
    return total
```

### Pattern 2

**Idea**
Use Quickselect to find k-th smallest, then sum all elements less than pivot and take remaining smallest up to k.

**Pseudo Code**

```text
function totalCostQuickselect(costs, k)
    if k <= 0 or costs is empty
        return 0
    kthValue <- quickselect(costs, k) // O(n) average
    countLess <- count of elements < kthValue
    sumLess <- sum of elements < kthValue
    remaining <- k - countLess
    collect elements equal to kthValue
    sumRemaining <- sum of first remaining occurrences
    return sumLess + sumRemaining
```

## Comparison

| Approach     | Idea                                  | Time             | Space | Recommended |
| ------------ | ------------------------------------- | ---------------- | ----- | ----------- |
| Min-Heap     | Heapify all and pop k times           | O(n + k log n)   | O(n)  | Yes         |
| Max-Heap(k)  | Keep k smallest in max-heap           | O(n log k)       | O(k)  | Yes (when k << n) |
| Quickselect  | Partition to find k-th smallest       | O(n) average     | O(1)  | Yes (when in-place optimal) |
| Sorting      | Sort and sum first k                   | O(n log n)       | O(1)/O(n) | No (slower) |
