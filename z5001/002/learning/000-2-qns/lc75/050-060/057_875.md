# Koko Eating Bananas

## Difficulty
Medium

## Description
Given piles of bananas and H hours, find the minimum integer eating speed K (bananas per hour) such that Koko can finish all piles within H hours. Each hour Koko chooses one pile and eats up to K bananas from it; if a pile has fewer than K bananas, she finishes that pile in that hour.

## Examples

### Example 1

```text
Input: piles = [3,6,7,11], h = 8
Output: 4
Explanation: With speed 4, hours needed = ceil(3/4)+ceil(6/4)+ceil(7/4)+ceil(11/4)=1+2+2+3=8.
```

## Constraints

```text
1 <= piles.length <= 10^4
1 <= piles[i] <= 10^9
1 <= h <= 10^9
Answer K is an integer in [1, max(piles)].
```

---

## Idea
Binary search on the eating speed (answer space) and test feasibility by summing required hours.

---

## Pseudo Code

```text
function minEatingSpeed(piles, h)
    low = 1
    high = max(piles)
    while low < high
        mid = (low + high) // 2
        if canFinish(piles, mid, h) then
            high = mid
        else
            low = mid + 1
    return low

function canFinish(piles, k, h)
    total = 0
    for p in piles
        total = total + (p + k - 1) // k
        if total > h then
            return false
    return true
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n log m) where n = len(piles), m = max(piles) |
| Space Complexity | O(1)   |

## Code Explanation

### Dry Run

| Step | State                         | Operation                            | Result                     |
| ---- | ----------------------------- | ------------------------------------ | -------------------------- |
| 1    | low=1, high=11                | mid=(1+11)//2=6                      | check hours with k=6       |
| 2    | total=6                       | hours = 1+1+2+2 = 6 <= 8             | high = 6                   |
| 3    | low=1, high=6                 | mid=(1+6)//2=3                       | check hours with k=3       |
| 4    | total=10                      | hours = 1+2+3+4 = 10 > 8             | low = 4                    |
| 5    | low=4, high=6                 | mid=(4+6)//2=5                       | check hours with k=5       |
| 6    | total=8                       | hours = 1+2+2+3 = 8 <= 8             | high = 5                   |
| 7    | low=4, high=5                 | mid=(4+5)//2=4                       | check hours with k=4       |
| 8    | total=8                       | hours = 1+2+2+3 = 8 <= 8             | high = 4                   |
| 9    | low=4, high=4                 | loop ends                            | return 4                   |

## Other Patterns

### Pattern 1

**Idea**
Brute force try all speeds from 1 to max(piles).

**Pseudo Code**

```text
function minEatingSpeedBrute(piles, h)
    maxp = max(piles)
    for k from 1 to maxp
        total = 0
        for p in piles
            total = total + (p + k - 1) // k
            if total > h then
                break
        if total <= h then
            return k
    return maxp
```

## Comparison

| Approach       | Idea                            | Time           | Space | Recommended |
| -------------- | ------------------------------- | -------------- | ----- | ----------- |
| Binary Search  | Binary search on speed + check  | O(n log m)     | O(1)  | Yes         |
| Brute Force    | Test every speed from 1..max    | O(n * m)       | O(1)  | No          |
