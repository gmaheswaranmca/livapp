# 055 Guess Number Higher or Lower

## Difficulty
Easy

## Description
Guess a hidden number between 1 and n using an API guess(num) that returns -1 if the hidden number is lower, 1 if higher, and 0 if correct. Return the correct number.

## Examples

### Example 1

```text
Input: n = 10, pick = 6
Output: 6
Explanation: guess(5) -> 1, guess(8) -> -1, guess(6) -> 0 so return 6.
```

## Constraints

```text
1 <= pick <= n <= 2^31 - 1
API: int guess(int num) returns {-1,0,1}
Expected deterministic solution with O(log n) time and O(1) space
```

---

## Idea
Use binary search on the range [1, n] and call the guess API to guide direction.

---

## Pseudo Code

```text
function guessNumber(n)
    low = 1
    high = n
    while low <= high
        mid = low + (high - low) // 2
        res = guess(mid)
        if res == 0 return mid
        if res < 0 high = mid - 1
        else low = mid + 1
    return -1
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log n) |
| Space Complexity | O(1) |

---

## Code Explanation

### Dry Run

| Step | State (low,high) | Operation         | Result                     |
| ---- | ----------------- | ----------------- | -------------------------- |
| 1    | (1,10)            | mid=5, res=guess(5) | res=1 => low=6             |
| 2    | (6,10)            | mid=8, res=guess(8) | res=-1 => high=7           |
| 3    | (6,7)             | mid=6, res=guess(6) | res=0 => return 6          |

## Other Patterns

### Pattern 1

**Idea**

Iterative binary search (primary).

**Pseudo Code**

```text
function guessNumber(n)
    low = 1
    high = n
    while low <= high
        mid = low + (high - low) // 2
        res = guess(mid)
        if res == 0 return mid
        if res < 0 high = mid - 1
        else low = mid + 1
    return -1
```

### Pattern 2

**Idea**

Recursive binary search.

**Pseudo Code**

```text
function guessNumberRec(low, high)
    if low > high return -1
    mid = low + (high - low) // 2
    res = guess(mid)
    if res == 0 return mid
    if res < 0 return guessNumberRec(low, mid - 1)
    return guessNumberRec(mid + 1, high)

function guessNumber(n)
    return guessNumberRec(1, n)
```

### Pattern 3

**Idea**

Linear search from 1 to n (brute force).

**Pseudo Code**

```text
function guessNumber(n)
    for num from 1 to n
        if guess(num) == 0 return num
    return -1
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Iterative Binary Search | Divide range by half using API | O(log n) | O(1) | Yes |
| Recursive Binary Search | Same as iterative but recursive | O(log n) | O(log n) (call stack) | No |
| Linear Search | Try every number sequentially | O(n) | O(1) | No |
