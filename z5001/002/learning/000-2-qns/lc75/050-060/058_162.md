# Find Peak Element

## Difficulty
Medium

## Description
Given an integer array nums, find any index i such that nums[i] is a peak element (nums[i] > nums[i-1] and nums[i] > nums[i+1]). Treat out-of-bounds neighbors as -∞. Return the index of any peak.

## Examples

### Example 1

```text
Input: [1,2,3,1]
Output: 2
Explanation: nums[2]=3 is a peak.
```

### Example 2

```text
Input: [1,2]
Output: 1
Explanation: nums[1]=2 is a peak (right neighbor is -∞).
```

## Constraints

```text
1 <= nums.length <= 1000
-2^31 <= nums[i] <= 2^31 - 1
nums[i] != nums[i+1] (no equal adjacent elements)
```

---

## Idea
Binary search on the slope: compare mid and mid+1 to decide search direction.

---

## Pseudo Code

```text
function findPeakElement(nums)
    n = length(nums)
    if n == 1
        return 0
    low = 0
    high = n - 1
    while low < high
        mid = floor((low + high) / 2)
        if nums[mid] > nums[mid + 1]
            high = mid
        else
            low = mid + 1
    return low
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(log n) |
| Space Complexity | O(1) |

---

## Code Explanation

### Dry Run

| Step | State (low,high) | mid | nums[mid] | nums[mid+1] | Operation | Result (new low,high) |
| ---- | ----------------- | ---- | --------- | ----------- | --------- | --------------------- |
| 1    | (0,3)             | 1    | 2         | 3           | nums[mid] < nums[mid+1] => go right | (2,3) |
| 2    | (2,3)             | 2    | 3         | 1           | nums[mid] > nums[mid+1] => go left  | (2,2) |
| 3    | (2,2)             | 2    | -         | -           | loop ends                        | return 2 |

1. Initialize low and high to array bounds.
2. Compute mid as floor((low+high)/2).
3. If slope is descending at mid (nums[mid] > nums[mid+1]) move left by high=mid.
4. Else slope ascending move right by low=mid+1.
5. When low==high return low (index of a peak).

## Other Patterns

### Pattern 1

**Idea**

Linear scan to find local maximum.

**Pseudo Code**

```text
function findPeakElement(nums)
    n = length(nums)
    for i from 0 to n-1
        left = -infinity if i==0 else nums[i-1]
        right = -infinity if i==n-1 else nums[i+1]
        if nums[i] > left and nums[i] > right
            return i
    return 0
```

### Pattern 2

**Idea**

Divide and conquer recursive binary search (similar to iterative but recursive).

**Pseudo Code**

```text
function findPeakElement(nums)
    return helper(nums, 0, length(nums)-1)

function helper(nums, low, high)
    if low == high
        return low
    mid = floor((low + high) / 2)
    if nums[mid] > nums[mid + 1]
        return helper(nums, low, mid)
    else
        return helper(nums, mid + 1, high)
```
