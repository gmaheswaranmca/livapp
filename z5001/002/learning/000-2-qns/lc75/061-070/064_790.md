# Domino and Tromino Tiling

## Difficulty
Medium

## Description
Count the number of ways to tile a 2 × n board using 2×1 dominoes and L-shaped trominoes (covering three squares). Return the count modulo 10^9+7.

## Examples

### Example 1

```text
Input: n = 3
Output: 5
Explanation: Five tilings exist for a 2x3 board.
```

### Example 2

```text
Input: n = 1
Output: 1
Explanation: Only one vertical domino.
```

## Constraints

```text
0 <= n <= 1000
Answer modulo 10^9+7
```

---

## Idea
Use DP with two states: full columns (f[i]) and one-cell-stub (g[i]) to derive linear recurrences.

---

## Pseudo Code

```text
function solve(n)
    MOD = 1000000007
    if n == 0 return 1
    f = array of size n+1 initialized 0   // f[i] = ways to fully tile 2xi
    g = array of size n+1 initialized 0   // g[i] = ways to tile up to column i with one cell extra (stub)
    f[0] = 1
    f[1] = 1
    g[0] = 0
    for i from 2 to n
        g[i] = (g[i-1] + f[i-2]) % MOD
        f[i] = (f[i-1] + f[i-2] + 2 * g[i-1]) % MOD
    return f[n]
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(n) or O(1) with rolling variables |

## Code Explanation

### Dry Run

| Step | i | f[i-2] | g[i-1] | g[i] = g[i-1]+f[i-2] | f[i] = f[i-1]+f[i-2]+2*g[i-1] |
| ---- | - | ------ | ------ | -------------------- | ----------------------------- |
| init | - | -      | -      | g[0]=0                | f[0]=1, f[1]=1                 |
| 2    | 2 | f[0]=1 | g[1]=0 | g[2]=0+1=1            | f[2]=f[1]+f[0]+2*0 = 1+1=2     |
| 3    | 3 | f[1]=1 | g[2]=1 | g[3]=1+1=2            | f[3]=f[2]+f[1]+2*1 = 2+1+2=5   |

1. Initialize base: empty board (f[0]=1), 2x1 (f[1]=1).
2. g[i] counts arrangements with one extra cell at column i; build from previous g and f.
3. f[i] uses previous full tilings, one vertical domino extension, and placements involving trominoes accounted via g.

## Other Patterns

### Pattern 1

**Idea**
Use prefix-sum recurrence: f[i] = f[i-1] + f[i-2] + 2 * sum_{k=0..i-3} f[k].

**Pseudo Code**

```text
function solve(n)
    MOD = 1000000007
    if n == 0 return 1
    f = array size n+1
    prefix = array size n+1
    f[0] = 1
    prefix[0] = 1
    if n >= 1 then f[1] = 1, prefix[1] = 2
    for i from 2 to n
        sum = prefix[i-3] if i-3 >= 0 else 0
        f[i] = (f[i-1] + f[i-2] + 2 * sum) % MOD
        prefix[i] = (prefix[i-1] + f[i]) % MOD
    return f[n]
```

### Pattern 2

**Idea**
Matrix exponentiation to compute linear recurrence in O(log n).

**Pseudo Code**

```text
function solve(n)
```

| Approach        | Idea                                              | Time    | Space   | Recommended |

| Two-state DP    | f[i], g[i] linear recurrence                      | O(n)    | O(1)/O(n) | Yes        |
