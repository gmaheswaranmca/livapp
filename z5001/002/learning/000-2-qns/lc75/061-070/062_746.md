# Min Cost Climbing Stairs

## Difficulty
Easy

## Description
Given an array cost where cost[i] is the cost of step i, you can climb either one or two steps. Return the minimum cost to reach the top of the floor (one step beyond the last index). You may start at step 0 or step 1.

## Examples

### Example 1

```text
Input: [10, 15, 20]
Output: 15
Explanation: Start at index 1 (cost 15), then climb one step to top. Total = 15.
```

### Example 2

```text
Input: [1,100,1,1,1,100,1,1,100,1]
Output: 6
Explanation: Optimal path picks minimal cumulative costs to reach the top = 6.
```

## Constraints

```text
2 <= cost.length <= 100000
0 <= cost[i] <= 10000
```

---

## Idea
Compute minimum cumulative cost to reach each step using bottom-up DP and optimize space to O(1).

---

## Pseudo Code

```text
function minCostClimbingStairs(cost)
    n = length(cost)
    if n == 0 return 0
    if n == 1 return cost[0]
    prev2 = cost[0]
    prev1 = cost[1]
    for i from 2 to n-1
        curr = cost[i] + min(prev1, prev2)
        prev2 = prev1
        prev1 = curr
    return min(prev1, prev2)
```

---

## Complexity

| Metric           | Value     |
| ---------------- | --------- |
| Time Complexity  | O(n)      |
| Space Complexity | O(1)      |

---

## Code Explanation

### Dry Run

| Step | State (i) | Operation                         | Result (prev2, prev1) |
| ---- | --------- | --------------------------------- | --------------------- |
| 1    | init      | prev2 = cost[0], prev1 = cost[1] | (10, 15)              |
| 2    | i = 2     | curr = cost[2] + min(15,10)=20+10 | curr=30 -> (15, 30)   |
| 3    | finish    | return min(prev1, prev2)         | min(30,15)=15         |

1. Initialize prev2 and prev1 as costs of first two steps.
2. Iterate from step 2 to last index, compute current minimal cumulative cost.
3. Slide the window (prev2 <- prev1, prev1 <- curr).
4. Answer is min(prev1, prev2) representing cheapest way to reach top from last two steps.

## Other Patterns

### Pattern 1

**Idea**
Bottom-up DP using an array storing dp[i] = min cost to reach step i.

**Pseudo Code**

```text
function minCostClimbingStairsDP(cost)
    n = length(cost)
    dp = array of size n
    dp[0] = cost[0]
    dp[1] = cost[1]
    for i from 2 to n-1
        dp[i] = cost[i] + min(dp[i-1], dp[i-2])
    return min(dp[n-1], dp[n-2])
```

### Pattern 2

**Idea**
Top-down recursion with memoization computing minimal cost to reach each step.

**Pseudo Code**

```text
function minCostClimbingStairsMemo(cost)
    n = length(cost)
    memo = array of size n initialized to -1
    function dfs(i)
        if i < 0 return 0
        if memo[i] != -1 return memo[i]
        if i == 0 return memo[0] = cost[0]
        if i == 1 return memo[1] = cost[1]
        memo[i] = cost[i] + min(dfs(i-1), dfs(i-2))
        return memo[i]
    result = min(dfs(n-1), dfs(n-2))
    return result
```
