# Delete Operation for Two Strings

## Difficulty
Medium

## Description
Given two strings word1 and word2, return the minimum number of delete operations required to make the two strings equal. You may delete characters from either string. The solution is based on computing the Longest Common Subsequence (LCS).

## Examples

### Example 1

```text
Input: "sea","eat"
Output: 2
Explanation: LCS = "ea" (length 2). Deletions = 3 + 3 - 2*2 = 2.
```

### Example 2

```text
Input: "leetcode","etco"
Output: 4
Explanation: LCS = "etco" (length 4). Deletions = 8 + 4 - 2*4 = 4.
```

## Constraints

```text
1 <= word1.length, word2.length <= 500
word1 and word2 consist of lowercase English letters.
```

---

## Idea
Compute LCS length via dynamic programming; answer = m + n - 2 * LCS.

---

## Pseudo Code

```text
function minDeletions(word1, word2)
    m := length(word1)
    n := length(word2)
    create dp array with dimensions (m+1) x (n+1) initialized to 0
    for i from 1 to m
        for j from 1 to n
            if word1[i-1] == word2[j-1]
                dp[i][j] := dp[i-1][j-1] + 1
            else
                dp[i][j] := max(dp[i-1][j], dp[i][j-1])
    lcs := dp[m][n]
    return m + n - 2 * lcs
```

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(m * n) |

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | Initialize dp 4x4 zeros for m=3,n=3 | init dp[0..3][0..3]=0 | dp rows: [0,0,0,0] x4 |
| 2 | Process i=1 ('s') vs "e","a","t" | no matches -> dp[1][1..3]=0 | dp[1]=[0,0,0,0] |
| 3 | Process i=2 ('e') | match at j=1 -> dp[2][1]=1; propagate -> dp[2]=[0,1,1,1] | dp[2]=[0,1,1,1] |
| 4 | Process i=3 ('a') | match at j=2 -> dp[3][2]=2; propagate -> dp[3]=[0,1,2,2] | dp[3]=[0,1,2,2] |
| 5 | Final | lcs = dp[3][3] = 2 | deletions = 3+3-2*2 = 2 |

## Other Patterns

### Pattern 1

**Idea**

Use 1D rolling DP to reduce space to O(n).

**Pseudo Code**

```text
function minDeletionsOptimized(word1, word2)
    m := length(word1)
    n := length(word2)
    create prev array of size (n+1) initialized to 0
    create curr array of size (n+1) initialized to 0
    for i from 1 to m
        for j from 1 to n
            if word1[i-1] == word2[j-1]
                curr[j] := prev[j-1] + 1
            else
                curr[j] := max(prev[j], curr[j-1])
        swap prev and curr
        reset curr to zeros if needed
    lcs := prev[n]
    return m + n - 2 * lcs
```

### Pattern 2

**Idea**

Top-down recursion with memoization computing LCS.

**Pseudo Code**

```text
function minDeletionsMemo(word1, word2)
    m := length(word1)
    n := length(word2)
    create memo dictionary
    function lcs(i, j)
        if i == m or j == n
            return 0
        if (i,j) in memo
            return memo[(i,j)]
        if word1[i] == word2[j]
            memo[(i,j)] := 1 + lcs(i+1, j+1)
        else
            memo[(i,j)] := max(lcs(i+1, j), lcs(i, j+1))
        return memo[(i,j)]
    result := lcs(0, 0)
    return m + n - 2 * result
```
