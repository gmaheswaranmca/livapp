# Unique Paths

## Difficulty
Medium

## Description
Count number of unique paths from top-left to bottom-right in an m x n grid when only moves right or down are allowed.

## Examples

### Example 1

```text
Input: m = 3, n = 7
Output: 28
Explanation: There are 28 distinct paths from top-left to bottom-right.
```

### Example 2

```text
Input: m = 1, n = 1
Output: 1
Explanation: Single cell, only one path (start = end).
```

## Constraints

```text
1 <= m, n <= 100
Result may exceed 32-bit integer; use 64-bit or big integer if required.
```

---

## Idea
Use dynamic programming: number of ways to reach a cell = sum of ways from top and left; optimize space with a 1D array of length n.

---

## Pseudo Code

```text
function uniquePaths(m, n)
    create array dp of length n
    for j from 0 to n-1
        dp[j] = 1
    for i from 1 to m-1
        for j from 1 to n-1
            dp[j] = dp[j] + dp[j-1]
    return dp[n-1]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(n) |

## Other Patterns

### Pattern 1

**Idea**
Use combinatorics: number of paths = C((m-1)+(n-1), m-1).

**Pseudo Code**

```text
function uniquePathsCombinatorial(m, n)
    k = min(m-1, n-1)
    numerator = 1
    denominator = 1
    for i from 1 to k
        numerator = numerator * (m + n - 1 - i)
        denominator = denominator * i
    return numerator / denominator
```

### Pattern 2

**Idea**
Recursive DFS with memoization (top-down DP).

**Pseudo Code**

```text
function uniquePathsMemo(m, n)
    create memo dictionary
    return dfs(0, 0, m, n, memo)

function dfs(i, j, m, n, memo)
    if i == m-1 and j == n-1
        return 1
    if i >= m or j >= n
        return 0
    if (i,j) in memo
        return memo[(i,j)]
    memo[(i,j)] = dfs(i+1, j, m, n, memo) + dfs(i, j+1, m, n, memo)
    return memo[(i,j)]
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| DP (1D) | Row-by-row cumulative sums using O(n) space | O(m*n) | O(n) | Yes |
| DP (2D) | Full table dp[i][j] = dp[i-1][j] + dp[i][j-1] | O(m*n) | O(m*n) | No (higher space) |
| Combinatorics | Compute binomial coefficient C(m+n-2, m-1) | O(min(m,n)) | O(1) | Yes (when overflow handled) |
| Recursion + Memo | Top-down memoization of subproblems | O(m*n) | O(m*n) | No (stack overhead) |
