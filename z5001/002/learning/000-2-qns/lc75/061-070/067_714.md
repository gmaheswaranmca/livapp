# Best Time to Buy and Sell Stock with Transaction Fee

## Difficulty
Medium

## Description
Given an array prices where prices[i] is the price of a given stock on day i and an integer fee representing a transaction fee, find the maximum profit you can achieve. You may complete as many transactions as you like, but you pay the transaction fee for each sale. You cannot hold more than one share at a time.

## Examples

### Example 1

```text
Input: prices = [1,3,2,8,4,9], fee = 2
Output: 8
Explanation: Buy at 1, sell at 8 => profit 8-1-2 = 5. Then buy at 4, sell at 9 => profit 9-4-2 = 3. Total = 8.
```

### Example 2

```text
Input: prices = [1,3,7,5,10,3], fee = 3
Output: 6
Explanation: Buy 1 sell 7 => 7-1-3 = 3. Buy 5 sell 10 => 10-5-3 = 2. Total = 5; better sequence yields 6.
```

## Constraints

```text
1 <= prices.length <= 10^5
0 <= prices[i] <= 10^5
0 <= fee <= 10^5
```

---

## Idea
Maintain two states: cash (not holding) and hold (holding), update each day: hold = max(hold, cash - price); cash = max(cash, hold + price - fee).

---

## Pseudo Code

```text
function maxProfitWithFee(prices, fee)
    if prices is empty then
        return 0
    end if
    cash = 0
    hold = -prices[0]
    for i from 1 to length(prices)-1
        prev_hold = hold
        hold = max(hold, cash - prices[i])
        cash = max(cash, prev_hold + prices[i] - fee)
    end for
    return cash
```

## Other Patterns

### Pattern 1

**Idea**

DP with arrays for clarity.

**Pseudo Code**

```text
function maxProfitDPArray(prices, fee)
    n = length(prices)
    if n == 0 then
        return 0
    end if
    cash = array of size n
    hold = array of size n
    cash[0] = 0
    hold[0] = -prices[0]
    for i from 1 to n-1
        hold[i] = max(hold[i-1], cash[i-1] - prices[i])
        cash[i] = max(cash[i-1], hold[i-1] + prices[i] - fee)
    end for
    return cash[n-1]
```

### Pattern 2

**Idea**

Top-down recursion with memoization on day and holding state.

**Pseudo Code**

```text
function maxProfitRec(prices, fee)
    memo = map()
    function dfs(i, holding)
        if i == length(prices) then
            return 0
        end if
        if (i,holding) in memo then
            return memo[(i,holding)]
        end if
        if holding == 0 then
            do_nothing = dfs(i+1, 0)
            buy = dfs(i+1, 1) - prices[i]
            ans = max(do_nothing, buy)
        else
            do_nothing = dfs(i+1, 1)
            sell = dfs(i+1, 0) + prices[i] - fee
            ans = max(do_nothing, sell)
        end if
        memo[(i,holding)] = ans
        return ans
    end function
    return dfs(0, 0)
```

### Pattern 3

**Idea**

Greedy compressing profitable spans using effective buy price (works as an alternative O(n) approach).

**Pseudo Code**

```text
function maxProfitGreedy(prices, fee)
    if prices is empty then
        return 0
    end if
    effective_buy = prices[0] + fee
    profit = 0
    for price in prices
        if price + fee < effective_buy then
            effective_buy = price + fee
        else if price > effective_buy then
            profit = profit + (price - effective_buy)
            effective_buy = price
        end if
    end for
    return profit
```

## Comparison

| Approach       | Idea                                 | Time | Space | Recommended |
| -------------- | ------------------------------------ | ---- | ----- | ----------- |
| State DP (O(1))| Two variables cash and hold          | O(n) | O(1)  | Yes         |

| Recursion+Memo | Top-down states (day,holding)        | O(n) | O(n)  | No          |
| Greedy         | Compress profitable spans with fee   | O(n) | O(1)  | Yes (alternative)
