# 070 Minimum Flips to Make a OR b Equal c

## Difficulty
Medium

## Description
Given three non-negative integers a, b, and c, return the minimum number of bit flips required in a and/or b so that (a OR b) equals c. A flip toggles a single bit in either a or b.

## Examples

### Example 1
```text
Input: a = 2, b = 6, c = 5
Output: 3
Explanation: Flip bit0 of a (0->1), flip bit1 of a (1->0), flip bit1 of b (1->0).
```

### Example 2
```text
Input: a = 4, b = 2, c = 7
Output: 1
Explanation: Flip bit0 of b (0->1) or bit0 of a (0->1).
```

## Constraints
```text
0 <= a, b, c <= 10^9
Result fits in 32-bit integer
Prefer O(number_of_bits) time and O(1) space
```

---

## Idea
Greedy bit-by-bit: for each bit i, compare ai, bi, ci and count minimal flips to make (ai OR bi) == ci.

---

## Pseudo Code
```text
function minFlips(a, b, c)
    flips <- 0
    i <- 0
    while a > 0 or b > 0 or c > 0
        ai <- a & 1
        bi <- b & 1
        ci <- c & 1
        if ci == 1
            if ai == 0 and bi == 0
                flips <- flips + 1
        else
            flips <- flips + (ai + bi)   // if ai or bi is 1, each needs flipping to 0
        a <- a >> 1
        b <- b >> 1
        c <- c >> 1
        i <- i + 1
    return flips
```

## Complexity

| Metric           | Value                                 |
| ---------------- | ------------------------------------- |
| Time Complexity  | O(B) where B = number of bits used (O(log max(a,b,c))) |
| Space Complexity | O(1)                                  |

## Code Explanation

### Dry Run

| Step | State (a,b,c) in binary | Operation | Result (flips so far) |
| ---- | ------------------------ | --------- | --------------------- |
| 1    | a=010, b=110, c=101; i=0 -> bits (0,0,1) | ci=1 and ai=bi=0 => +1 flip | 1 |
| 2    | i=1 -> bits (1,1,0) | ci=0 => flips += ai+bi = 2 | 3 |
| 3    | i=2 -> bits (0,1,1) | (ai|bi)=1 == ci => +0 | 3 |

1. Iterate bits from LSB to MSB until all numbers are zero.
2. When ci==1 and both ai,bi are 0, flip one bit (count +1).
3. When ci==0, flip every 1 in ai or bi to 0 (count ai+bi).
4. Sum flips and return.

## Other Patterns

### Pattern 1

**Idea**

Bit manipulation, count per-bit differences (chosen approach).

**Pseudo Code**

```text
function minFlips(a, b, c)
    flips <- 0
    while a > 0 or b > 0 or c > 0
        ai <- a & 1
        bi <- b & 1
        ci <- c & 1
        if ci == 1 and ai == 0 and bi == 0
            flips <- flips + 1
        else if ci == 0
            flips <- flips + (ai + bi)
        a <- a >> 1
        b <- b >> 1
        c <- c >> 1
    return flips
```

### Pattern 2

**Idea**

Brute-force BFS over flipping bits until (a|b)==c (exponential, only for tiny inputs).

**Pseudo Code**

```text
function minFlipsBrute(a, b, c)
    visited <- set()
    queue <- [(a,b,0)]
    while queue not empty
        x,y,dist <- dequeue
        if (x | y) == c
            return dist
        for each bit position i in [0..MAXBITS-1]
            nx <- x ^ (1 << i)
            if (nx,y) not in visited
                enqueue (nx,y,dist+1)
                visited.add((nx,y))
            ny <- y ^ (1 << i)
            if (x,ny) not in visited
                enqueue (x,ny,dist+1)
                visited.add((x,ny))
    return -1
```
