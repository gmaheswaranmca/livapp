# Longest Common Subsequence (LCS) — Length

## Difficulty
Medium

## Description
Given two strings s1 and s2, return the length of their longest common subsequence (not necessarily contiguous). Use a 2D dynamic programming table.

## Examples

### Example 1

```text
Input: s1 = "abcde", s2 = "ace"
Output: 3
Explanation: Common subsequence "ace" has length 3.
```

### Example 2

```text
Input: s1 = "abc", s2 = "abc"
Output: 3
Explanation: Entire string matches.
```

## Constraints

```text
0 <= len(s1), len(s2) <= 1000
Characters are ASCII or lowercase letters
Expected result fits in 32-bit integer
```

---

## Idea
Use a 2D DP table dp[i][j] = LCS length of prefixes s1[0..i-1] and s2[0..j-1].

---

## Pseudo Code

```text
function lcs_length(s1, s2)
    n = length(s1)
    m = length(s2)
    create dp matrix of size (n+1) x (m+1) filled with 0
    for i from 1 to n
        for j from 1 to m
            if s1[i-1] == s2[j-1]
                dp[i][j] = dp[i-1][j-1] + 1
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[n][m]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n * m) |
| Space Complexity | O(n * m) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1 | dp all zeros (6x4 for "abcde","ace") | initialize dp | dp[0..5][0..3] = 0 |
| 2 | i=1 (s1[0]='a'), j=1 (s2[0]='a') | match: dp[1][1]=dp[0][0]+1 | dp[1][1]=1 |
| 3 | i=1, j=2..3 | no matches: propagate max | dp[1][2]=1, dp[1][3]=1 |
| 4 | i=2..3 process 'b','c' vs s2 update | when s1[2]=='c' and s2[1]=='c' dp[3][2]=dp[2][1]+1=2 | partial dp rows updated |
| 5 | i=5 end | final dp[5][3] computed | return 3 |

## Other Patterns

### Pattern 1

**Idea**

Use two rolling rows to reduce space to O(min(n,m)).

**Pseudo Code**

```text
function lcs_length_optimized(s1, s2)
    if length(s1) < length(s2)
        swap s1 and s2
    n = length(s1)
    m = length(s2)
    create prev array of size m+1 filled 0
    create curr array of size m+1 filled 0
    for i from 1 to n
        for j from 1 to m
            if s1[i-1] == s2[j-1]
                curr[j] = prev[j-1] + 1
            else
                curr[j] = max(prev[j], curr[j-1])
        copy curr into prev (or swap references)
        reset curr to zeros if needed
    return prev[m]
```

### Pattern 2

**Idea**

Top-down recursion with memoization.

**Pseudo Code**

```text
function lcs_memo(s1, s2)
    n = length(s1)
    m = length(s2)
    create memo map
    function dfs(i, j)
        if i == n or j == m
            return 0
        if (i,j) in memo
            return memo[(i,j)]
        if s1[i] == s2[j]
            memo[(i,j)] = 1 + dfs(i+1, j+1)
        else
            memo[(i,j)] = max(dfs(i+1, j), dfs(i, j+1))
        return memo[(i,j)]
    return dfs(0, 0)
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| 2D DP table | Fill dp matrix for prefix pairs | O(n*m) | O(n*m) | Yes |
| Rolling rows | Keep only two rows (space optimized) | O(n*m) | O(min(n,m)) | Yes |
| Recursion + Memo | Top-down with memo table | O(n*m) | O(n*m) (stack + memo) | No (less iterative control) |
