# Edit Distance (LeetCode 72)

## Difficulty
Medium

## Description
Given two strings word1 and word2, return the minimum number of operations required to convert word1 to word2. Allowed operations: insert a character, delete a character, replace a character.

## Examples

### Example 1

```text
Input: word1 = "horse", word2 = "ros"
Output: 3
Explanation: Replace 'h' -> 'r', delete 'o', delete 'e' (one possible sequence).
```

### Example 2

```text
Input: word1 = "intention", word2 = "execution"
Output: 5
Explanation: One optimal sequence uses replace/insert/delete operations total 5.
```

## Constraints

```text
0 <= len(word1), len(word2) <= 500
word1 and word2 consist of lowercase/uppercase letters and/or digits
```

---

## Idea
Use dynamic programming where dp[i][j] = min operations to convert first i chars of word1 to first j chars of word2.

---

## Pseudo Code

```text
function editDistance(word1, word2)
    m = length(word1)
    n = length(word2)
    create dp matrix of size (m+1) x (n+1)
    for i from 0 to m
        dp[i][0] = i
    for j from 0 to n
        dp[0][j] = j
    for i from 1 to m
        for j from 1 to n
            if word1[i-1] == word2[j-1]
                dp[i][j] = dp[i-1][j-1]
            else
                dp[i][j] = 1 + min(dp[i-1][j],    // delete from word1
                                    dp[i][j-1],    // insert into word1
                                    dp[i-1][j-1])  // replace
    return dp[m][n]
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(m * n) |
| Space Complexity | O(m * n) |

---

## Code Explanation

### Dry Run

| Step | State | Operation | Result |
| ---- | ----- | --------- | ------ |
| 1    | Initialize dp (m=5,n=3) | set dp[i][0]=i, dp[0][j]=j | dp after init: [[0,1,2,3],[1,0,0,0],[2,0,0,0],[3,0,0,0],[4,0,0,0],[5,0,0,0]] |
| 2    | i=1,j=1 ('h' vs 'r') | chars differ -> 1 + min(dp[0][1],dp[1][0],dp[0][0]) | dp[1][1]=1 |
| 3    | i=2,j=2 ('o' vs 'o') | chars equal -> dp[2][2]=dp[1][1] | dp[2][2]=1 |
| 4    | i=3,j=1 ('r' vs 'r') | chars equal -> dp[3][1]=dp[2][0] | dp[3][1]=2 |
| 5    | Final | computed all cells | dp[5][3]=3 (answer) |

## Other Patterns

### Pattern 1

**Idea**  
Use a single-row (or two-row) DP to reduce space to O(min(m,n)).

**Pseudo Code**

```text
function editDistanceOptimized(word1, word2)
    if length(word1) < length(word2)
        swap(word1, word2)
    m = length(word1)
    n = length(word2)
    create prev array of size n+1
    for j from 0 to n
        prev[j] = j
    for i from 1 to m
        create cur array of size n+1
        cur[0] = i
        for j from 1 to n
            if word1[i-1] == word2[j-1]
                cur[j] = prev[j-1]
            else
                cur[j] = 1 + min(prev[j], cur[j-1], prev[j-1])
        prev = cur
    return prev[n]
```

### Pattern 2

**Idea**  
Top-down recursion with memoization.

**Pseudo Code**

```text
function editDistanceMemo(word1, word2)
    m = length(word1)
    n = length(word2)
    create memo map
    function dfs(i, j)
        if i == 0 return j
        if j == 0 return i
        if (i,j) in memo return memo[(i,j)]
        if word1[i-1] == word2[j-1]
            ans = dfs(i-1, j-1)
        else
            ans = 1 + min(dfs(i-1, j), dfs(i, j-1), dfs(i-1, j-1))
        memo[(i,j)] = ans
        return ans
    return dfs(m, n)
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Full DP | 2D DP matrix dp[m+1][n+1] | O(m*n) | O(m*n) | Yes |
| Optimized DP | 1D/2-row DP using previous row | O(m*n) | O(min(m,n)) | Yes (when memory-critical) |
| Recursion + Memo | Top-down memoized recursion | O(m*n) | O(m*n) | No (stack overhead) |
