# N-th Tribonacci Number

## Difficulty
Easy

## Description
Return the n-th Tribonacci number where T0 = 0, T1 = 1, T2 = 1 and Tn = Tn-1 + Tn-2 + Tn-3 for n >= 3.

## Examples

### Example 1

```text
Input: n = 4
Output: 4
Explanation: T0=0, T1=1, T2=1, T3=2, T4=4
```

### Example 2

```text
Input: n = 0
Output: 0
Explanation: Base case
```

### Example 3

```text
Input: n = 25
Output: 1389537
Explanation: Fits in 32-bit signed integer for n<=37
```

## Constraints

```text
0 <= n <= 37  (for 32-bit result)
Result fits in 32-bit int for n <= 37
For larger n use big integers or arbitrary-precision arithmetic
```

---

## Idea
Iteratively compute using three rolling variables to maintain last three Tribonacci values (constant space DP).

---

## Pseudo Code

```text
function tribonacci(n)
    if n == 0 return 0
    if n == 1 return 1
    if n == 2 return 1
    a = 0
    b = 1
    c = 1
    for i from 3 to n
        d = a + b + c
        a = b
        b = c
        c = d
    return c
```

---

## Complexity

| Metric           | Value  |
| ---------------- | ------ |
| Time Complexity  | O(n)   |
| Space Complexity | O(1)   |

---

## Code Explanation

### Dry Run

| Step | State (a,b,c) | Operation       | Result c |
| ---- | ------------- | --------------- | -------- |
| 1    | (0,1,1)       | start for n=4   | 1        |
| 2    | (0,1,1)       | i=3 -> d=2      | c=2      |
| 3    | (1,1,2)       | i=4 -> d=4      | c=4      |
| 4    | (1,2,4)       | end loop        | return 4 |

1. Handle base cases n=0,1,2 directly.
2. Initialize a=T0, b=T1, c=T2.
3. Iterate i from 3 to n computing d=a+b+c then shift a,b,c.
4. Return c which holds Tn.

## Other Patterns

### Pattern 1

**Idea**

Top-down recursion with memoization to avoid exponential recomputation.

**Pseudo Code**

```text
function tribonacci_memo(n)
    memo = map()
    function dfs(k)
        if k == 0 return 0
        if k == 1 return 1
        if k == 2 return 1
        if memo contains k return memo[k]
        memo[k] = dfs(k-1) + dfs(k-2) + dfs(k-3)
        return memo[k]
    return dfs(n)
```

### Pattern 2

**Idea**

Use matrix exponentiation to compute Tribonacci in O(log n) time.

**Pseudo Code**

```text
function tribonacci_matrix(n)
    if n == 0 return 0
    if n == 1 return 1
    if n == 2 return 1
    M = [[1,1,1],[1,0,0],[0,1,0]]
    R = matrix_power(M, n-2)
    // Tn = R[0][0]*T2 + R[0][1]*T1 + R[0][2]*T0
    return R[0][0]*1 + R[0][1]*1 + R[0][2]*0
```

## Comparison

| Approach                 | Idea                                    | Time      | Space    | Recommended |
| ------------------------ | --------------------------------------- | --------- | -------- | ----------- |
| Iterative DP (rolling)   | Maintain three variables and iterate    | O(n)      | O(1)     | Yes        |
| Recursion with memo      | Top-down cache of computed values       | O(n)      | O(n)     | No (simple) |
| Matrix exponentiation    | Use linear recurrence matrix pow        | O(log n)  | O(1)-O(log n) | No (when n large) |
