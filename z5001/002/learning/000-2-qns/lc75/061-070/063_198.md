# House Robber

## Difficulty
Medium

## Description
Given an array nums where nums[i] is the amount of money of the i-th house, determine the maximum amount of money you can rob without robbing two adjacent houses.

## Examples

### Example 1
```text
Input: [1,2,3,1]
Output: 4
Explanation: Rob houses 1 and 3 (1-based: houses 1 and 3) -> 1 + 3 = 4
```

### Example 2
```text
Input: [2,7,9,3,1]
Output: 12
Explanation: Rob houses 1, 3, and 5 -> 2 + 9 + 1 = 12
```

## Constraints
```text
1 <= nums.length <= 10^5
0 <= nums[i] <= 10^4
Answer fits in 32-bit signed integer range
```

---

## Idea
Maintain two values per index: max if current house is robbed (include) and max if current house is not robbed (exclude); update iteratively.

---

## Pseudo Code
```text
function solve(nums)
    if nums is empty
        return 0
    prevInclude = 0
    prevExclude = 0
    for each value in nums
        currInclude = prevExclude + value
        currExclude = max(prevInclude, prevExclude)
        prevInclude = currInclude
        prevExclude = currExclude
    return max(prevInclude, prevExclude)
```

| Metric           | Value   |
| ---------------- | ------- |
| Time Complexity  | O(n)    |
| Space Complexity | O(1)    |

## Other Patterns

### Pattern 1
**Idea**
Top-down recursion with memoization on index to decide rob or skip.

**Pseudo Code**
```text
function solve(nums)
    n = length of nums
    memo = array of size n initialized to -1
    return dfs(0, nums, memo)

function dfs(i, nums, memo)
    if i >= length of nums
        return 0
    if memo[i] != -1
        return memo[i]
    take = nums[i] + dfs(i+2, nums, memo)
    skip = dfs(i+1, nums, memo)
    memo[i] = max(take, skip)
    return memo[i]
```

### Pattern 2
**Idea**
Bottom-up DP using an array dp[i] = max money from first i houses.

**Pseudo Code**
```text
function solve(nums)
    if nums is empty
        return 0
    n = length of nums
    if n == 1
        return nums[0]
    dp = array of size n
    dp[0] = nums[0]
    dp[1] = max(nums[0], nums[1])
    for i from 2 to n-1
        dp[i] = max(dp[i-1], nums[i] + dp[i-2])
    return dp[n-1]
```

## Comparison

| Approach | Idea | Time | Space | Recommended |
| -------- | ---- | ---- | ----- | ----------- |
| Iterative include/exclude | Track include and exclude per house | O(n) | O(1) | Yes |
| Recursion + memo | Top-down choose/skip with memo | O(n) | O(n) | No (stack overhead) |
| Bottom-up DP array | Full dp array storing results | O(n) | O(n) | No (extra memory) |
