026	394	Decode String	Decode nested encoded string.	"3[a2[c]]"	"accaccacc"	Stack for nested patterns.

The above problem

Pseudo code is 

```text
function decodeString(s)
    countStack=emptyStack()
    stringStack=emptyStack()

    currentString=""
    currentNumber=0
    for each ch in s
        if isDigit(ch)
            currentNumber=currentNumber*10+(ch-'0')
        else if ch=='['
            push currentNumber into countStack
            push currentString into stringStack
            currentNumber=0
            currentString=""
        else if ch==']'
            repeatCount=pop countStack
            previousString=pop stringStack
            currentString=previousString+repeat(currentString,repeatCount)
        else
            currentString=currentString+ch
    return currentString
```
