# LC 88 - Merge Sorted Array

| Field      | Details            |
| ---------- | ------------------ |
| LC#        | 88                 |
| Title      | Merge Sorted Array |
| Difficulty | Easy               |
| Pattern    | Two Pointers       |

---

# Problem Description

You are given two integer arrays `nums1` and `nums2`, sorted in non-decreasing order.

* `nums1` has a length of `m + n`.
* The first `m` elements of `nums1` represent valid elements.
* The last `n` elements are `0`s and should be ignored.
* `nums2` contains `n` valid elements.

Merge `nums2` into `nums1` as one sorted array.

The final sorted array must be stored inside `nums1`.

---

# Example 1

### Input

```text
nums1 = [1,2,3,0,0,0]
m = 3

nums2 = [2,5,6]
n = 3
```

### Output

```text
[1,2,2,3,5,6]
```

### Explanation

```text
nums1 valid part = [1,2,3]
nums2            = [2,5,6]

Merge both sorted arrays:

1,2,3
2,5,6

Result:
1,2,2,3,5,6
```

### Input


```text

```

# Constraints

```text
0 <= m, n <= 200

1 <= m + n <= 200

-10^9 <= nums1[i], nums2[i] <= 10^9
```

---

# Key Observation

```text
nums1 already has extra space at the end.

If we start merging from the beginning,
elements of nums1 may get overwritten.

Therefore merge from the END.
```

---

# Best Pattern: Three Pointers From End

## Idea

Use:

```text
i = last valid element of nums1
j = last element of nums2
k = last position of nums1
```

Compare:

```text
nums1[i]
nums2[j]
```

Place the larger one at position `k`.

Move corresponding pointer backward.

---

# Dry Run

```text
nums1 = [1,2,3,0,0,0]
nums2 = [2,5,6]

i = 2 (3)
j = 2 (6)
k = 5
```

### Step 1

```text
3 vs 6

6 larger

nums1 = [1,2,3,0,0,6]

j--
k--
```

### Step 2

```text
3 vs 5

5 larger

nums1 = [1,2,3,0,5,6]

j--
k--
```

### Step 3

```text
3 vs 2

3 larger

nums1 = [1,2,3,3,5,6]

i--
k--
```

### Step 4

```text
2 vs 2

take nums2

nums1 = [1,2,2,3,5,6]

j--
k--
```

### Done

```text
Result = [1,2,2,3,5,6]
```

# Pseudo Code (Language Independent)

```text
FUNCTION merge(nums1, m, nums2, n)

    i = m - 1
    j = n - 1
    k = m + n - 1

    WHILE i >= 0 AND j >= 0

        IF nums1[i] > nums2[j]
            nums1[k] = nums1[i]
            i = i - 1
        ELSE
            nums1[k] = nums2[j]
            j = j - 1
        END IF

        k = k - 1

    END WHILE

    WHILE j >= 0
        nums1[k] = nums2[j]
        j = j - 1
        k = k - 1
    END WHILE

END FUNCTION
```

---

# Why Does This Work?

```text
Largest element must appear at the end.

Both arrays are already sorted.

Comparing the last elements always reveals
the next largest element.

Thus we fill nums1 from right to left.
```

---

# Time & Space Complexity

| Complexity | Value  |
| ---------- | ------ |
| Time       | O(m+n) |
| Space      | O(1)   |

Optimal solution.

# Explain the Code

```text
i = m-1
```

Points to last valid element of nums1.

```text
j = n-1
```

Points to last element of nums2.

```text
k = m+n-1
```

Points to last available position in nums1.

---

```text
WHILE i >=0 AND j >=0
```

Keep comparing until one array finishes.

---

```text
IF nums1[i] > nums2[j]
```

Larger element belongs at position k.

---

```text
nums1[k] = nums1[i]
```

Place larger element.

Move pointer backward.

---

```text
WHILE j >=0
```

If nums2 still has elements,
copy them.

No need to copy remaining nums1 elements because they are already in correct places.

# Other Pattern 1: Extra Array

## Idea

Create a third array.

Merge normally like Merge Sort.

Copy result back.

---

## Pseudo Code

```text
FUNCTION merge(nums1,m,nums2,n)

    temp = empty array

    i = 0
    j = 0

    WHILE i < m AND j < n

        IF nums1[i] <= nums2[j]
            ADD nums1[i] TO temp
            i++
        ELSE
            ADD nums2[j] TO temp
            j++
        END IF

    END WHILE

    ADD remaining elements

    COPY temp INTO nums1

END FUNCTION
```

### Complexity

```text
Time  : O(m+n)
Space : O(m+n)
```

---

# Other Pattern 2: Append + Sort

## Idea

```text
Copy nums2 into empty slots of nums1

Sort nums1
```

---

## Pseudo Code

```text
FUNCTION merge(nums1,m,nums2,n)

    FOR each element in nums2
        place in nums1
    END FOR

    SORT nums1

END FUNCTION
```

### Complexity

```text
Time  : O((m+n) log(m+n))
Space : Depends on sorting algorithm
```
