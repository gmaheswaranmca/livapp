# 27. Remove Element

Remove Element

## Problem Statement

Given an integer array `nums` and an integer `val`, remove all occurrences of `val` **in-place**.

The order of the remaining elements **may be changed**.

Return the number of elements in `nums` that are **not equal** to `val`.

After returning `k`, the first `k` elements of `nums` should contain all elements that are not equal to `val`.

---

## Description

You are given:

* An array `nums`
* A value `val`

You must:

1. Remove all occurrences of `val` **without using extra array space**.
2. Modify the existing array itself.
3. Return the count `k` of remaining elements.

Important:

* Elements after index `k-1` do **not** matter.
* The remaining elements can be in **any order**.

---

## Example 1

### Input

```text
nums = [3,2,2,3]
val = 3
```

### Process

Remove all `3`s.

```text
[3,2,2,3]
 ↓     ↓ remove

Remaining:
[2,2]
```

### Output

```text
k = 2
nums = [2,2,_,_]
```

`_` means any value; they are ignored.

---

## Example 2

### Input

```text
nums = [0,1,2,2,3,0,4,2]
val = 2
```

### Step-by-step

```text
Original:
[0,1,2,2,3,0,4,2]

Keep:
0 -> write at index 0

Keep:
1 -> write at index 1

Skip:
2

Skip:
2

Keep:

0 -> write at index 3

Keep:

```

Result:

```text
[0,1,3,0,4,_,_,_]

k = 5
```

# Pattern 1 (Most Common): Two Pointers - Forward Overwrite

This is the standard solution.

## Idea

Maintain:

* `read` -> scans every element.
* `write` -> points where the next valid element should be placed.

Whenever:

```text
nums[read] != val
```

copy:

```text
nums[write] = nums[read]
write++
```

---

Done

```text
k=2
```

# Pseudocode
```text
write = 0
read = 0
while read < n
    if nums[read] != val
        nums[write] = nums[read]
        write++
    read++

return write
```

```text
write = 0

for read from 0 to n-1

    if nums[read] != val

        nums[write] = nums[read]
        write++

return write
```

---

# Generic Template (Migrates to Any Language)

```text
function removeElement(nums, val):

    write = 0

    for each element x in nums:

        if x != val:

            nums[write] = x
            write++

    return write
```

# Code Explanation

Example code:

```python
def removeElement(nums, val):

    write = 0

    for read in range(len(nums)):

        if nums[read] != val:

            nums[write] = nums[read]
            write += 1

    return write
```

# Pattern 2: Opposite Ends Swapping

Useful because **order doesn't matter**.

This is another official-style solution.

---

## Idea

Maintain:

```text
left = 0
right = n
```

where:

```text
[left, right)
```

is the current valid range.

If:

```text
nums[left] == val
```

replace it with the last unchecked element:

```text
nums[left] = nums[right-1]
right--
```

Else:

```text
left++
```

---

## Example

```text
nums=[3,2,2,3]
val=3

left=0 right=4
```

`nums[0]=3`

Swap with last:

```text
[3,2,2,3]

nums[0]=nums[3]

right=3
```

Still:

```text
nums[0]=3
```

Again:

```text
nums[0]=nums[2]

[2,2,2,3]

right=2
```

Now:

```text
nums[0]=2

left++
left=1
```

Done.

```text
k=2
```

---

# Pseudocode

```text
left = 0
right = n

while left < right

    if nums[left] == val

        nums[left] = nums[right-1]
        right--

    else

        left++

return right
```

| Complexity | Value |
| ---------- | ----- |
| Time       | O(n)  |
| Space      | O(1)  |

# Pattern 3: Stable Compaction (General Filtering)

This is actually the generalized version of Pattern 1.

---

## Idea

Keep everything satisfying:

```text
condition(element)
```

For Remove Element:

```text
condition = (element != val)
```

---

## Pseudocode

```text
write = 0

for read from 0 to n-1

    if keep(nums[read])

        nums[write] = nums[read]
        write++

return write
```

---

This pattern is used in:

* Remove Element
* Move Zeroes
* Remove Duplicates from Sorted Array
* Filter array in-place
* Partition valid/invalid elements

---

# Comparison of Approaches

| Method            | Stable Order | Time | Space | Best Use          |
| ----------------- | ------------ | ---- | ----- | ----------------- |
| Forward Overwrite | Yes          | O(n) | O(1)  | Most interviews   |
| End Swapping      | No           | O(n) | O(1)  | Many deletions    |
| Stable Compaction | Yes          | O(n) | O(1)  | Generic filtering |

# Interview Takeaway

For **LeetCode 27**, the most expected answer is:

```text
Two Pointers

read -> scans array
write -> stores next valid position

If nums[read] != val:
    nums[write] = nums[read]
    write++
```

This "read/write pointer" pattern is one of the most important array techniques because the exact same idea reappears in problems like:

* Move Zeroes
* Remove Duplicates from Sorted Array
* Remove Duplicates from Sorted Array II
* Sort Colors
* Partition Array

These are often grouped under the **Two Pointers / Fast-Slow Pointer / Array Compaction** pattern.
