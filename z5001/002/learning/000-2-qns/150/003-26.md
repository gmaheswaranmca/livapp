# 26. Remove Duplicates from Sorted Array

**Difficulty:** Easy

## Problem Description

Given an integer array `nums` sorted in **non-decreasing order**, remove the duplicates **in-place** such that each unique element appears only once.

The relative order of the elements should be kept the same.

Since the array length cannot be changed in some languages, place the result in the first `k` positions of `nums`, where `k` is the number of unique elements.

Return `k`.

### Important Notes

* Modify the array **in-place**.
* Do **not** allocate another array for the answer.
* The first `k` elements should contain the unique values.
* Elements after `k` do not matter.

---

## Example 1

### Input

```text
nums = [1,1,2]
```

### Process

| Step                      | Read Pointer | Write Pointer | Array   |
| ------------------------- | ------------ | ------------- | ------- |
| Start                     | 1            | 0             | [1,1,2] |
| nums[1]=1 same as nums[0] | 1            | 0             | [1,1,2] |
| nums[2]=2 different       | 2            | 1             | [1,2,2] |

### Output

```text
k = 2
nums = [1,2,...]
```

Only first 2 elements matter.

# Constraints

```text
1 <= nums.length <= 3 * 10^4

-100 <= nums[i] <= 100

nums is sorted in non-decreasing order.
```

# Main Pattern: Slow and Fast Pointers

This is the standard and most optimal approach.

## Idea

Because the array is sorted:

```text
Duplicates are adjacent.
```

Keep:

* `slow` → points to last unique element.
* `fast` → scans the array.

If:

```text
nums[fast] != nums[slow]
```

we found a new unique number.

Move `slow` ahead and copy:

```text
slow++
nums[slow] = nums[fast]
```

# Pseudocode (Language Independent)

```text
function removeDuplicates(nums):

    if nums is empty:
        return 0

    slow = 0

    for fast from 1 to n-1:

        if nums[fast] != nums[slow]:

            slow = slow + 1

            nums[slow] = nums[fast]

    return slow + 1
```

---

# Complexity

| Metric      | Value |
| ----------- | ----- |
| Time        | O(n)  |
| Extra Space | O(1)  |

Because:

* Each element visited once.
* No extra array used.

# Code Explanation

Typical code:

```text
slow = 0

for fast = 1 to n-1:

    if nums[fast] != nums[slow]:

        slow++

        nums[slow] = nums[fast]

return slow + 1
```

### Why compare with `nums[slow]`?

`slow` always stores the index of the **last unique element**.

Example:

```text
nums = [1,1,2,2,3]

slow = 1

nums[slow] = 2
```

When:

```text
nums[fast] = 3
```

they differ:

```text
3 is a new unique value
```

Store it:

```text
slow++
nums[slow]=3
```

# Alternative Pattern 1: Count Unique Elements

Maintain:

```text
k = 1
```

If current element differs from previous:

```text
nums[k] = nums[i]

k++
```

### Pseudocode

```text
function removeDuplicates(nums):

    k = 1

    for i from 1 to n-1:

        if nums[i] != nums[i-1]:

            nums[k] = nums[i]

            k++

    return k
```

### Complexity

```text
Time : O(n)

Space: O(1)
```

### Difference

This is actually another way of writing the same slow-fast pointer solution.

---

# Alternative Pattern 2: Use Extra Set

### Idea

Store seen numbers in a set.

### Pseudocode

```text
set = {}

k = 0

for x in nums:

    if x not in set:

        set.add(x)

        nums[k] = x

        k++

return k
```

---

### Complexity

| Metric | Value |
| ------ | ----- |
| Time   | O(n)  |
| Space  | O(n)  |

### Drawback

Uses extra memory.

LeetCode asks:

```text
In-place with O(1) extra space
```

So this is not preferred.

---

# Alternative Pattern 3: Create New Array

### Pseudocode

```text
result = []

for x in nums:

    if result is empty OR x != last(result):

        append x

copy result back

return length(result)
```

---

### Complexity

```text
Time  : O(n)

Space : O(n)
```

Again:

❌ Not in-place.

# Comparison of All Approaches

| Approach             | Time | Space | In-place | Recommended |
| -------------------- | ---- | ----- | -------- | ----------- |
| Slow-Fast Pointers   | O(n) | O(1)  | Yes      | ⭐⭐⭐⭐⭐       |
| Unique Count Variant | O(n) | O(1)  | Yes      | ⭐⭐⭐⭐⭐       |
| Hash Set             | O(n) | O(n)  | No       | ⭐⭐          |
| New Array            | O(n) | O(n)  | No       | ⭐           |

# Pattern Recognition for Interviews

If you see:

* Sorted array
* Remove duplicates
* Keep relative order
* In-place modification
* O(1) extra space

Think immediately:

```text
Sorted Array
        ↓
Duplicates are adjacent
        ↓
Two Pointers
(slow = write pointer,
 fast = read pointer)
```

This **Slow-Fast Pointer / Read-Write Pointer** pattern is one of the most frequently used patterns in array interview problems.
