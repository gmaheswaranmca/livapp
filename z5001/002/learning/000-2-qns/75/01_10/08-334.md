# 334. Increasing Triplet Subsequence

Increasing Triplet Subsequence

## Problem Statement

Given an integer array `nums`, return:

```text
true
```

if there exists a triplet of indices:

```text
i < j < k
```

such that:

```text
nums[i] < nums[j] < nums[k]
```

Otherwise return:

```text
false
```

---

# Description

You need to determine whether there exists **three numbers** in increasing order while preserving their positions.

The indices must satisfy:

```text
i < j < k
```

and values:

```text
nums[i] < nums[j] < nums[k]
```

You do **not** need to return the triplet.

Only return:

```text
true or false
```

You do **not** need to store the whole subsequence.



# Approach 1 (Recommended)

## Greedy Tracking of Two Minimums

---

### Maintain

```text
first

second
```

Initially:

```text
first = +infinity

second = +infinity
```

---

For each number:

### Case 1

```text
num <= first
```

Update:

```text
first = num
```

---

### Case 2

```text
num <= second
```

Update:

```text
second = num
```

---

### Case 3

```text
num > second
```

Then:

```text
first < second < num
```

Return:

```text
true
```

---

# Pseudo Code

```text
function increasingTriplet(nums):
    first = +infinity
    second = +infinity
    for num in nums:
        if num <= first:
            first = num
        else if num <= second:
            second = num
        else:
            return true
    return false
```




This means:

```text

first < second
```


# Pattern Used

This is the expected solution.

---

### Idea

Keep:

```text
best first candidate

```

If third appears:

```text

```

---

### Generic Template

```text
first=INF
second=INF
for x:
    if x<=first:
        first=x
    else if x<=second:
        second=x
    else:
        found answer
```

---

This pattern appears in:

# Alternative Pattern 2 : Prefix Minimum + Suffix Maximum

---

### Observation

For index `j`:

Need:

```text
smaller on left

and

larger on right
```

---

Create:

```text
leftMin[i] = minimum before i
```

and

```text
rightMax[i] = maximum after i
```

---

If:

```text
leftMin[i] < nums[i] < rightMax[i]
```

Triplet exists.

---

## Pseudo Code

```text
leftMin[0]=nums[0]
for i:
    leftMin[i] = min(leftMin[i-1],nums[i])
rightMax[n-1]=nums[n-1]
for i backwards:
    rightMax[i] = max(rightMax[i+1],nums[i])
for i:
    if leftMin[i] < nums[i]  < rightMax[i]:
        return true
return false
```

---

### Complexity

```text
Time : O(n)

Space: O(n)
```

Easy to understand.

# Why the Greedy Solution Works

Suppose:

```text
first = 5

second = 8
```

Later:

```text
num=3
```

Replace:

```text
first=3
```

Smaller first is always better because:

```text
3 < 8
```

gives more opportunity for a future third number.

---

Similarly:

```text
second
```

is always kept as small as possible.

This maximizes the chance of:

```text
futureNum > second
```
