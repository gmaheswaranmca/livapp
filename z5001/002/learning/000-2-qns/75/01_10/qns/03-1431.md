# 1431. Kids With the Greatest Number of Candies

Kids With the Greatest Number of Candies

## Problem Statement

There are `n` kids, and the `i-th` kid has `candies[i]` candies.

You are given an integer array `candies` and an integer `extraCandies`.

For each kid, determine whether giving **all** the `extraCandies` to that kid would make them have the **greatest number of candies among all kids**.

Return a boolean array `result` of length `n`, where:

```text
result[i] = true
    if candies[i] + extraCandies >= maximum candies

otherwise
result[i] = false
```

---

# Description

For every child:

1. Give all `extraCandies` to that child.
2. Check if their new candy count is **at least** the current maximum candy count among all children.
3. Store:

```text
true  -> can become one of the greatest
false -> cannot become greatest
```

---


# Observation

Suppose:

```text
candies = [2,3,5,1,3]

extra = 3
```

Maximum candies:

```text
5
```

Now:

```text
2 + 3 = 5 -> true

3 + 3 = 6 -> true

5 + 3 = 8 -> true

1 + 3 = 4 -> false

3 + 3 = 6 -> true
```

Notice:

You **do not need to recalculate the maximum every time**.

Find:

```text
maxCandy = max(candies)
```

once.

This is the main optimization.

---

# Approach 1 (Recommended)

## Two Pass Traversal

### Pass 1

Find:

```text
maxCandy
```

---

### Pass 2

For each child:

```text
candies[i] + extraCandies >= maxCandy
```

If yes:

```text
result[i] = true
```

Else:

```text
false
```

---

# Pseudo Code

```text
function kidsWithCandies(candies, extraCandies):

    maxCandy = maximum element of candies

    result = empty list

    for candy in candies:

        if candy + extraCandies >= maxCandy:

            append true to result

        else:

            append false to result

    return result
```

# Pattern Used

## 1. Precompute Then Query ⭐⭐⭐⭐⭐

This is the classic pattern.

---

### Idea

Instead of:

```text
for every i:

    find maximum again
```

Do:

```text
maximum = compute once

reuse maximum
```

---

### Generic Template

```text
best = precompute(data)

for each item:

    answer based on best
```

---

This pattern appears in:

* Maximum element problems
* Prefix sums
* Running totals
* Min/Max preprocessing
* Frequency counting

---

# Alternative Pattern 2 : Brute Force

For every child:

Find maximum again.

---

## Pseudo Code

```text
for i from 0 to n-1:

    maxCandy = maximum(candies)

    if candies[i] + extra >= maxCandy:

        result[i] = true

    else:

        result[i] = false
```

---

### Complexity

Finding maximum:

```text
O(n)
```

inside loop:

```text
n times
```

Total:

```text
O(n²)
```

Not recommended.

---

# Alternative Pattern 3 : Threshold Transformation

Observe:

```text
candies[i] + extra >= maxCandy
```

Rearrange:

```text
candies[i] >= maxCandy - extra
```

So first compute:

```text
threshold = maxCandy - extra
```

Then:

```text
if candies[i] >= threshold

    true

else

    false
```

---

## Pseudo Code

```text
maxCandy = max(candies)

threshold = maxCandy - extraCandies

for candy in candies:

    if candy >= threshold:

        result.append(true)

    else:

        result.append(false)
```

---

### Complexity

```text
Time  : O(n)

Space : O(n)
```

Same complexity.

Some people find this version easier to reason about.

---

# Comparison of Approaches

| Approach                   |       Time |     Space | Recommended |
| -------------------------- | ---------: | --------: | ----------- |
| Precompute Maximum + Check |       O(n) |      O(n) | ⭐⭐⭐⭐⭐       |
| Threshold (`max-extra`)    |       O(n) |      O(n) | ⭐⭐⭐⭐        |
| Brute Force                |      O(n²) |      O(n) | ⭐           |
| Sort First                 | O(n log n) | O(1)/O(n) | ⭐⭐          |

# Interview Takeaway

This problem teaches a very common interview pattern:

```text
Precompute an aggregate value

↓

Reuse it for every query
```

For this problem:

```text
maxCandy = max(candies)

for each candy:

    candy + extra >= maxCandy
```

Template:

```text
best = maximum(array)

for x in array:

    answer = condition(x,best)
```

This **Precompute + Single Traversal** pattern is the expected optimal solution for **LeetCode 1431** and appears frequently in array interview questions.
