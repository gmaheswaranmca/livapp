# 1768. Merge Strings Alternately 
Difficulty: Easy

## Problem Statement
You are given two strings `word1` and `word2`. Merge the strings by adding letters in alternating order, starting with `word1`. If a string is longer than the other, append the additional letters onto the end of the merged string.

Return the *merged* string.

---

## Example 1
```text
Input: word1 = "abc", word2 = "pqr"
Output: "apbqcr"
Explanation: The merged string will be merged as so:
word1:  a   b   c
word2:    p   q   r
merged: a p b q c r
```

## Example 2
```text
Input: word1 = "ab", word2 = "pqrs"
Output: "apbqrs"
Explanation: Notice that as word2 is longer, "rs" is appended to the end.
word1:  a   b 
word2:    p   q   r   s
merged: a p b q   r   s
```

## Example 3
```text
Input: word1 = "abcd", word2 = "pq"
Output: "apbqcd"
Explanation: Notice that as word1 is longer, "cd" is appended to the end.
word1:  a   b   c   d
word2:    p   q 
merged: a p b q c   d
```

---

## Constraints:
```text
1 <= word1.length, word2.length <= 100
`word1` and `word2` consist of lowercase English letters.
```

---

# Solution

## Description

The goal is to combine two strings character by character:

* Take one character from `word1`
* Then one character from `word2`
* Continue alternating until one string ends
* Append the remaining characters from the longer string

---

# Approach 1 (Recommended) : Two Pointers

## Idea
```
Maintain:
i = index in word1
j = index in word2
answer = ""
While characters remain:
* Add `word1[i]` if possible
* Add `word2[j]` if possible
* Increment indices
```

---

## Pseudo Code
```text
function mergeAlternately(word1, word2):
    i = 0
    j = 0
    m = length(word1)
    n = length(word2)
    result = ""
    while i < m OR j < n:
        if i < m:
            result += word1[i]
            i++
        if j < n:
            result += word2[j]
            j++
    return result
```

---

## Dry Run
```
word1 = "ab", word2 = "pqrs"
m = length(word1) = 2
n = length(word2) = 4
---------------------------------------------
i   j   action: i<m -> result+=word1[i],
        j<n -> result+=word2[j]
---------------------------------------------
0   0   0<2T, result="a", 0<4T, result="ap" 
1   1   1<2T, result="apb", 1<4T, result="apbq"
2   2   2<2F, -, 2<4T, result="apbqr"
2   3   2<2F, -, 3<4T, result="apbqrs"
2   4   2<2F, -, 4<4F, -, stop
return "apbqrs"
---------------------------------------------
```

---

# Time and Space Complexity
```text
Time Complexity: O(n + m), n = len(word1), m = len(word2)
Space Complexity: O(n + m)
```

# Pattern Used

## 1. Two Pointers (Primary Pattern) ✅
This is the standard pattern.

### When to use
When:
* Traversing two arrays/strings simultaneously
* Merging sequences
* Comparing two sorted arrays
* Alternating elements

### Template

```text
i = 0
j = 0
while i < n OR j < m:
    if i < n:
        process(arr1[i])
        i++
    if j < m:
        process(arr2[j])
        j++
```

---

# Alternative Pattern 2 : Single Loop using Maximum Length
## Pseudo Code
```text
function mergeAlternately(word1, word2):
    result = ""
    maxLen = max(length(word1), length(word2))
    for k from 0 to maxLen-1:
        if k < length(word1):
            result += word1[k]
        if k < length(word2):
            result += word2[k]
    return result
```

---

# Alternative Pattern 3 : Queue Simulation
## Pseudo Code

```text
queue1 = characters of word1
queue2 = characters of word2

result = ""
while queue1 not empty OR queue2 not empty:
    if queue1 not empty:
        result += queue1.popFront()
    if queue2 not empty:
        result += queue2.popFront()
return result
```

# Comparison of Approaches

| Approach               |   Time | Extra Space | Recommended |
| ---------------------- | -----: | ----------: | ----------- |
| Two Pointers           | O(n+m) |       O(1)* | ⭐⭐⭐⭐⭐       |
| Single Loop (`maxLen`) | O(n+m) |       O(1)* | ⭐⭐⭐⭐        |
| Queue Simulation       | O(n+m) |      O(n+m) | ⭐⭐          |

*Ignoring the output string itself.
