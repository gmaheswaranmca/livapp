# 1071. Greatest Common Divisor of Strings

Greatest Common Divisor of Strings

## Problem Statement

For two strings `str1` and `str2`, we say that a string `x` **divides** a string `s` if and only if:

```text
s = x + x + x + ... + x
```

That is, `s` is made by concatenating one or more copies of `x`.

Given two strings `str1` and `str2`, return the **largest string** `x` that divides both strings.

If no such string exists, return an empty string `""`.

---

# Description

You need to find the **longest common repeating pattern** that can construct both strings completely.

Example:

```text
str1 = "ABCABCABC"
str2 = "ABCABC"
```

The repeating block is:

```text
ABC
```

because

```text
ABCABCABC = ABC × 3

ABCABC    = ABC × 2
```

So answer:

```text
"ABC"
```

# Why GCD of Lengths Works

Suppose:

```text
str1 = ABCABCABC

length = 9


str2 = ABCABC

length = 6
```

Their common repeating unit length must divide both:

```text
gcd(9,6)=3
```

Take:

```text
str1[0:3] = "ABC"
```

This is the answer.

# Approach 1 (Recommended)

## Concatenation Property + GCD of Lengths

This is the most elegant solution.

---

## Algorithm

### Step 1

Check:

```text
str1 + str2 == str2 + str1
```

If not:

```text
return ""
```

---

### Step 2

Find:

```text
g = gcd(len(str1), len(str2))
```

---

### Step 3

Return:

```text
str1[0:g]
```

---

# Pseudo Code

```text
function gcdOfStrings(str1, str2):

    if str1 + str2 != str2 + str1:
        return ""

    g = gcd(length(str1), length(str2))

    return substring(str1, 0, g)
```

---

# Euclidean GCD Pseudo Code

```text
function gcd(a,b):

    while b != 0:

        temp = a % b

        a = b

        b = temp

    return a
```

---

# Alternative Pattern 2 : Brute Force Candidate Checking

Try every possible divisor length from largest to smallest.

---

## Idea

Possible divisor lengths:

```text
minLen down to 1
```

Check:

```text
if len1 % k == 0
and len2 % k == 0
```

Take:

```text
candidate = str1[0:k]
```

Verify:

```text
candidate repeated == str1

candidate repeated == str2
```

---

## Pseudo Code

```text
function gcdOfStrings(str1,str2):

    limit = min(len(str1),len(str2))

    for k from limit down to 1:

        if len1 % k == 0 and len2 % k == 0:

            candidate = str1[0:k]

            if repeat(candidate,len1/k)==str1
            and repeat(candidate,len2/k)==str2:

                return candidate

    return ""
```

---

## Complexity

Worst case:

```text
O(min(n,m) * (n+m))
```

Much slower than GCD approach.

---

# Alternative Pattern 3 : Recursive String Reduction

Similar to Euclid's algorithm for integers.

---

## Idea

If:

```text
str1 starts with str2
```

Remove prefix:

```text
gcd(str1,str2)

=

gcd(str1.removePrefix(str2), str2)
```

Until:

```text
str2 == ""
```

---

## Pseudo Code

```text
function gcdString(a,b):

    if b == "":
        return a

    if a does not start with b:
        return ""

    return gcdString(removePrefix(a,b), b)
```

---

### Example

```text

remove ABC

ABC

ABC


remove ABC

"" and ABC

answer = ABC
```
