# 238. Product of Array Except Self

Product of Array Except Self

## Problem Statement

Given an integer array `nums`, return an array `answer` such that:

```text
answer[i] =
product of all elements of nums except nums[i]
```

### Important Constraint

You **cannot use division**.

Also, your algorithm should run in:

```text
Time  : O(n)

Extra Space : O(1)
```

*(The output array does not count as extra space.)*

---

# Description

For every index `i`, compute:

```text
nums = [a,b,c,d]

answer[0] = b*c*d

answer[1] = a*c*d

answer[2] = a*b*d

answer[3] = a*b*c
```

---

For index 2:

```text

```

For index 3:

```text

```

Answer:

```text
[24,12,8,6]
```

```text
2 <= nums.length <= 10^5

-30 <= nums[i] <= 30

The product of any prefix or suffix fits in 32-bit integer.
```

# Approach 1 (Optimal)

## Prefix Product + Suffix Product

---

### Idea

For every index:
```text
answer[i] = prefix[i] × suffix[i]
```

where

```text
prefix[i] = product before i 
suffix[i] = product after i
```

---

Example

```text
nums

1 2 3 4
```

Prefix:

```text
1 1 2 6
```

Meaning:

```text
prefix[0]=1

nothing before


prefix[1]=1

1


prefix[2]=2

1×2


prefix[3]=6

1×2×3
```

---

Suffix:

```text
24 12 4 1
```

Actually store:

```text
suffix before multiplication

24

12

4

1
```

---

Final:

```text
1×24 =24

1×12 =12

2×4  =8

6×1  =6
```

Answer:

```text
[24,12,8,6]
```

---

# Optimal Pseudo Code (O(1) Extra Space)

```text
function productExceptSelf(nums):
    n = length(nums)
    answer = array of size n
    answer[0]=1
    for i from 1 to n-1:
        answer[i] = answer[i-1] * nums[i-1]
    suffix=1
    for i from n-1 down to 0:
        answer[i] *= suffix
        suffix *= nums[i]
    return answer
```

# Code Explanation

## First Loop

```text
answer[i] = answer[i-1] × nums[i-1]
```

This stores:
```text
product of everything before i
```

---

Example

```text
nums
1 2 3 4

answer

```

---

## Second Loop

Maintain:
```text
suffix
```

which stores:
```text
product of elements after i
```

---

Then:
```text
answer[i] *= suffix
```

Now:
```text
prefix × suffix
```

which equals:
```text
product except self
```

# Pattern Used

## 1. Prefix + Suffix Products ⭐⭐⭐⭐⭐

This is one of the most important interview patterns.

---

### Formula

```text
answer[i] = product before i × product after i
```

---

### Generic Template

```text
prefix=1

for i:
    answer[i]=prefix
    prefix*=arr[i]
suffix=1
for i backwards:
    answer[i]*=suffix
    suffix*=arr[i]
```

---

Used in:

* Product Except Self
* Rain Water (prefix max/suffix max)
* Equilibrium Index
* Left Sum Right Sum
* Prefix Min/Max problems

---

# Alternative Pattern 2 : Prefix Array + Suffix Array

Create two arrays.

---

Example

```text
nums

1 2 3 4
```

Prefix:

```text
1 1 2 6
```

Suffix:

```text
24 12 4 1
```

---

Answer:

```text
prefix[i] × suffix[i]
```

---

## Pseudo Code

```text
prefix[0]=1
for i=1 to n-1:
    prefix[i] = prefix[i-1]*nums[i-1]
suffix[n-1]=1
for i=n-2 down to 0:
    suffix[i] = suffix[i+1]*nums[i+1]
for i:
    answer[i] = prefix[i]*suffix[i]
```

---

### Complexity

```text
Time : O(n)
Space: O(n)
```

Easy to understand.

---

# Alternative Pattern 3 : Division (Not Allowed)

Compute:

```text
totalProduct = all numbers multiplied
```

Then:

```text
answer[i] = totalProduct / nums[i]
```

---

Example

```text

answer

```

Result:


### Problem

```text

```

```text

```
Division by zero.

Also:

```text
Not allowed by problem.
```

# Alternative Pattern 4 : Brute Force
For every index:

Multiply all other elements.

---

## Pseudo Code

```text
for i:
    product=1
    for j:
        if i!=j:
            product*=nums[j]
    answer[i]=product
```

---

### Complexity

```text
Time O(n²)
```

Too slow.

# Why Prefix + Suffix Works

For:

```text
nums

1 2 3 4
```

At:

```text
i=2
```

Need:

```text
1×2×4
```

Split:

```text
(1×2)

×

(4)
```

Which is:

```text
prefix

×

suffix
```

This works for every position.

# Interview Takeaway

This problem is one of the most famous interview questions because it teaches:

```text
Left information

+

Right information

↓

Combine at current index
```

Template:

```text
answer[i]=prefix

update prefix


answer[i]*=suffix

update suffix
```

This **Prefix + Suffix Pattern** is the expected optimal solution for **LeetCode 238 – Product of Array Except Self**, and it frequently appears in many array interview problems involving cumulative information from both sides.
