# 1768. Merge Strings Alternately

Merge Strings Alternately

## Problem Statement

You are given two strings `word1` and `word2`.

Merge the strings by adding letters in alternating order, starting with `word1`. If one string is longer than the other, append the additional letters to the end of the merged string.

Return the merged string.

---

## Description

The goal is to combine two strings character by character:

* Take one character from `word1`
* Then one character from `word2`
* Continue alternating until one string ends
* Append the remaining characters from the longer string

---

## Example 1

### Input

```text
word1 = "abc"
word2 = "pqr"
```

### Output

```text

```

### Explanation

| ---- | --------- | ------ |
| 1    | a         | a      |

| 3    | b         | apb    |
| 4    | q         | apbq   |
| 5    | c         | apbqc  |
| 6    | r         | apbqcr |

```text

```

# Constraints

```text
1 <= word1.length, word2.length <= 100
word1 and word2 consist of lowercase English letters.
```

---

# Observation

Suppose:

```text
word1 = abcde
word2 = pqr
```

Indices:

```text
word1: a b c d e
       0 1 2 3 4

word2: p q r
       0 1 2
```

Take:

```text
a p b q c r d e
```

You keep two indices:

```text
i -> word1
j -> word2
```

Move them independently.

This is the **Two Pointers** pattern.

---

# Approach 1 (Recommended) : Two Pointers

## Idea

Maintain:

```text
i = index in word1
j = index in word2
answer = ""
```

While characters remain:

* Add `word1[i]` if possible
* Add `word2[j]` if possible
* Increment indices

---

## Pseudo Code

```text
function mergeAlternately(word1, word2):

    i = 0
    j = 0

    result = ""

    while i < length(word1) OR j < length(word2):

        if i < length(word1):
            result += word1[i]
            i++

        if j < length(word2):
            result += word2[j]
            j++

    return result
```

# Code Explanation

```text
while i < n OR j < m
```

Continue until both strings are exhausted.

---

```text
if i < n:
    result += word1[i]
    i++
```

If `word1` still has characters:

* append current character
* move pointer

---

```text
if j < m:
    result += word2[j]
    j++
```

Do the same for `word2`.

---

# Time and Space Complexity

### Time Complexity

```text
O(n + m)
```

where

```text
n = len(word1)
m = len(word2)
```

Each character is visited exactly once.

---

### Space Complexity

```text
O(n + m)
```

The output string stores all characters.

# Pattern Used

## 1. Two Pointers (Primary Pattern) ✅

This is the standard pattern.

### When to use

When:

* Traversing two arrays/strings simultaneously
* Merging sequences
* Comparing two sorted arrays
* Alternating elements

### Template

```text
i = 0
j = 0

while i < n OR j < m:

    if i < n:
        process(arr1[i])
        i++

    if j < m:
        process(arr2[j])
        j++
```

---

# Alternative Pattern 2 : Single Loop using Maximum Length

Instead of two independent loops:

Find:

```text
maxLen = max(len(word1), len(word2))
```

Iterate:

```text
for k from 0 to maxLen-1

    if k < len(word1):
        add word1[k]

    if k < len(word2):
        add word2[k]
```

---

## Pseudo Code

```text
function mergeAlternately(word1, word2):

    result = ""

    maxLen = max(length(word1), length(word2))

    for k from 0 to maxLen-1:

        if k < length(word1):
            result += word1[k]

        if k < length(word2):
            result += word2[k]

    return result
```

---

# Alternative Pattern 3 : Queue Simulation

Treat strings like queues.

Take:

```text
pop from word1
pop from word2
repeat
```

---

## Pseudo Code

```text
queue1 = characters of word1
queue2 = characters of word2

result = ""

while queue1 not empty OR queue2 not empty:

    if queue1 not empty:
        result += queue1.popFront()

    if queue2 not empty:
        result += queue2.popFront()

return result
```

# Comparison of Approaches

| Approach               |   Time | Extra Space | Recommended |
| ---------------------- | -----: | ----------: | ----------- |
| Two Pointers           | O(n+m) |       O(1)* | ⭐⭐⭐⭐⭐       |
| Single Loop (`maxLen`) | O(n+m) |       O(1)* | ⭐⭐⭐⭐        |
| Queue Simulation       | O(n+m) |      O(n+m) | ⭐⭐          |

*Ignoring the output string itself.

# Which Pattern Should You Remember for Interviews?

For this problem, remember:

```text
Two Strings + Alternate Traversal
            ↓
       Two Pointers
```

General template:

```text
i = 0
j = 0

while i < len(A) OR j < len(B):

    if i < len(A):
        use A[i]
        i++

    if j < len(B):
        use B[j]
        j++
```

This same template appears in many string/array merge problems in interview sets and the LeetCode 75 study plan.
