# 345. Reverse Vowels of a String

Reverse Vowels of a String

## Problem Statement

Given a string `s`, reverse **only** all the vowels in the string and return the resulting string.

The vowels are:

```text
a, e, i, o, u
A, E, I, O, U
```

All non-vowel characters must remain in their original positions.

---

# Description

You need to:

1. Find the vowels in the string.
2. Reverse their order.
3. Keep all other characters unchanged.

---

# Constraints

```text

```

# Observation

Suppose:

```text
s = "hello"
```

Indices:

```text
0 1 2 3 4

h e l l o
```

We want:

```text
h o l l e
```

Observe:

* First vowel from left → `e`
* First vowel from right → `o`

Swap them.

---

Then:

```text
left++
right--
```

Continue until they cross.

This naturally suggests:

# Two Pointers

One pointer from left.

One pointer from right.

---

# Approach 1 (Recommended)

## Two Pointers + Swap

---

### Idea

Use:

```text
left = 0

right = n-1
```

Move:

* `left` until vowel found.
* `right` until vowel found.
* Swap.
* Continue.

---

# Pseudo Code

```text
function reverseVowels(s):
    vowels = {a,e,i,o,u,A,E,I,O,U}
    arr = characters of s
    left = 0
    right = length(arr)-1
    while left < right:
        while left < right and arr[left] not vowel:
            left++
        while left < right and arr[right] not vowel:
            right--
        swap(arr[left], arr[right])
        left++
        right--
    return string(arr)
```

# Code Explanation

### Step 1

```text
left = 0

right = n-1
```

Start from both ends.

---

### Step 2

```text
while arr[left] not vowel:

    left++
```

Skip consonants.

Find first vowel.

---

### Step 3

```text
while arr[right] not vowel:

    right--
```

Skip consonants from right.

Find vowel.

---

### Step 4

```text
swap(arr[left], arr[right])
```

Reverse vowel positions.

---

### Step 5

```text
left++

right--
```

Move inward.

Repeat.

---

# Complexity Analysis

Let:

```text
n = length(s)
```

### Time Complexity

```text
O(n)
```

Each pointer moves at most `n` times.

---

### Space Complexity

```text
O(n)
```

Because strings are immutable in many languages, we convert to character array.

If mutable strings exist:

```text
O(1)
```

extra space.

# Pattern Used

## 1. Opposite Direction Two Pointers ⭐⭐⭐⭐⭐

This is the standard solution.

---

### Pattern

```text
left = 0

right = n-1


while left < right:

    move left

    move right

    swap

    left++

    right--
```

---

Used in:

* Reverse String
* Valid Palindrome
* Reverse Vowels
* Container With Most Water
* Two Sum II
* Palindrome Check

---

# Generic Template

```text
left=0

right=n-1

while left<right:

    while condition not met:

        left++


    while condition not met:

        right--


    swap

    left++

    right--
```

---

# Alternative Pattern 2 : Collect and Rewrite

### Step 1

Collect vowels.

```text
hello

vowels:

e o
```

Store:

```text
[e,o]
```

---

### Step 2

Reverse:

```text
[o,e]
```

---

### Step 3

Traverse original string.

Replace vowels one by one.

---

## Pseudo Code

```text
vowelsList=[]

for c in s:

    if vowel:

        add c


reverse(vowelsList)

index=0

for i in range(n):

    if s[i] is vowel:

        s[i]=vowelsList[index]

        index++
```

---

### Complexity

```text
Time : O(n)

Space: O(v)
```

where:

```text
v = number of vowels
```

---

# Alternative Pattern 3 : Stack

Push vowels onto stack.

---

Example

```text
hello

stack:

e
o
```

Top:

```text
o
```

---

Traverse again:

Replace vowels by popping:

```text
h o l l e
```

---

## Pseudo Code

```text
stack=[]

for c in s:

    if vowel:

        push c


for i:

    if vowel:

        s[i]=stack.pop()
```

---

### Complexity

```text
Time : O(n)

Space: O(v)
```

---

# Alternative Pattern 4 : Queue (Not Reverse Friendly)

Store vowels in queue.

But:

```text
e o
```

Queue gives:

```text
e then o
```

which preserves order.

We need:

```text
o then e
```

So queue is not suitable unless reversed.

# Why Two Pointers is Optimal

Suppose:

```text
hello

e ..... o
```

The first vowel from left should exchange with:

```text
first vowel from right
```

Similarly:

```text
second vowel from left

↓

second vowel from right
```

Exactly what two pointers do.

No extra storage needed.

# Interview Takeaway

This problem is one of the classic:

```text
Selective Reversal Problems
```

Pattern:

```text
Two Pointers

↓

Move left until target found

Move right until target found

↓

Swap

↓

Continue inward
```

Template:

```text
left=0

right=n-1

while left<right:

    advance left

    advance right

    swap
```

This **Opposite Direction Two Pointers Pattern** is the expected optimal solution for **LeetCode 345 – Reverse Vowels of a String** and is a foundational interview technique for strings and arrays.
