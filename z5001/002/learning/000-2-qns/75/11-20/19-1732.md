# 019. Find the Highest Altitude
* **LC #:** 1732
* **Difficulty:** Easy
* **Pattern:** Prefix Sum / Running Sum

## Title
**Find the Highest Altitude**

---

## Description

```text
There is a biker going on a road trip.
The road trip consists of `n+1` points at different altitudes. 
The biker starts the trip at altitude `0`.
You are given an integer array `gain` of length `n` where:
* `gain[i]` is the net gain in altitude between points `i` and `i+1`.
Return the highest altitude of a point.
```

```text
Note:
gain[i] means the change in altitude between two consecutive points.
Positive value → biker goes uphill.
Negative value → biker goes downhill.
Zero → altitude does not change.
```
---

## Examples

```text
Input: gain=[-5,1,5,0,-7]
Output: 1
Explanation:
Start altitude = 0
Altitude sequence:
0
0+(-5)=-5
-5+1=-4
-4+5=1
1+0=1
1+(-7)=-6
Highest altitude = 1
```

```text
Input: gain=[-4,-3,-2,-1,4,3,2]
Output: 0
Explanation:
Altitudes: 0,-4,-7,-9,-10,-6,-3,-1
Highest altitude is the starting altitude 0.
```

```text
Input: gain=[1,2,3]
Output: 6
Explanation:
Altitudes:0,1,3,6
Highest altitude = 6
```

---

## Constraints

```text
n==gain.length
1<=n<=100
-100<=gain[i]<=100
```

---

# Idea (One Line)
Keep a running altitude using prefix sum and track the maximum altitude seen so far.

---

# Pseudocode
```text
function largestAltitude(gain)
    altitude=0
    highest=0

    for each g in gain
        altitude=altitude+g
        highest=max(highest,altitude)
    return highest
```

---

# Complexity

```text
Time Complexity: O(n)
Single traversal of gain array.
Space Complexity: O(1)
```

# Code Explanation
```text
1. The biker starts at altitude 0.
2. altitude stores the current altitude.
3. highest stores the maximum altitude reached.
4. Traverse each gain value.
    5. Update:
    altitude=altitude+gain[i]
    6. Compare:
    highest=max(highest,altitude)
7. Continue until the end.
8. Return highest.
```

---

# Why Prefix Sum Works?
```text
Suppose:gain=[-5,1,5,0,-7]
Altitude at each point:
    altitude[0]=0
    altitude[1]=0+(-5)=-5
    altitude[2]=-5+1=-4
    altitude[3]=-4+5=1
    altitude[4]=1+0=1
    altitude[5]=1+(-7)=-6
In general:altitude=previousAltitude+gain[i]

This is exactly a running prefix sum.
```

# Alternative Pseudocode Using Explicit Prefix Array
```text
function largestAltitude(gain)
    n=length(gain)
    altitude[0]=0
    highest=0
    for i=0 to n-1
        altitude[i+1]=altitude[i]+gain[i]
        highest=max(highest,altitude[i+1])
    return highest
```

# Other Patterns
## Pattern 1 : Explicit Prefix Sum Array
### Idea
Build the altitude array explicitly and find its maximum.

### Pseudocode
```text
function largestAltitude(gain)
    n=length(gain)
    prefix[0]=0
    for i=0 to n-1
        prefix[i+1]=prefix[i]+gain[i]
    ans=prefix[0]
    for each x in prefix
        ans=max(ans,x)
    return ans
```

### Complexity
```text
Time: O(n)
Space: O(n)
```

---

## Pattern 2 : Functional Accumulation
### Idea
Accumulate prefix sums and track maximum simultaneously.

### Pseudocode
```text
function largestAltitude(gain)
    sum=0
    ans=0

    for each x in gain
        sum=sum+x
        if sum>ans
            ans=sum
    return ans
```

### Complexity
```text
Time: O(n)
Space: O(1)
```

---

## Pattern 3 : Brute Force
### Idea
For every position, recalculate altitude from the beginning.

### Pseudocode
```text
function largestAltitude(gain)
    ans=0
    for i=0 to length(gain)
        altitude=0
        for j=0 to i-1
            altitude=altitude+gain[j]
        ans=max(ans,altitude)
    return ans
```

### Complexity

```text
Time: O(n^2)
Space: O(1)
```
