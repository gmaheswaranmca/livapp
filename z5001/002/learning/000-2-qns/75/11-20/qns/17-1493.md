# 017. Longest Subarray of 1's After Deleting One Element
* **LC #:** 1493
* **Difficulty:** Medium
* **Pattern:** Sliding Window (Variable Size)

## Title
**Longest Subarray of 1's After Deleting One Element**

---

## Description
```text
Given a binary array `nums`, you should delete exactly one element from it.
Return the size of the longest non-empty subarray containing only `1`s in the resulting array.
If there is no such subarray, return `0`.
```
---

## Examples

```text
Input: nums=[1,1,0,1]
Output: 3
Explanation:
Delete the zero at index 2.
Original: [1,1,0,1]
After delete: [1,1,1]
Longest subarray of 1's = 3.
```

```text
Input: nums=[0,1,1,1,0,1,1,0,1]
Output: 5
Explanation:
Delete the zero at index 4.
After deletion: [0,1,1,1,1,1,0,1]
Longest consecutive 1's = 5.
```

```text
Input: nums=[1,1,1]
Output: 2
Explanation:
Exactly one element must be deleted.
Delete any one: [1,1]
Answer = 2.
```

---

## Constraints
```text
1<=nums.length<=10^5
nums[i] is either 0 or 1
```

---

# Idea (One Line)
Maintain a window containing at most one zero and delete that zero, so answer is `window_length-1`.

---

# Pseudocode
```text
function longestSubarray(nums)
    left=0
    zeros=0
    ans=0
    for right=0 to length(nums)-1
        if nums[right]==0
            zeros=zeros+1
        while zeros>1
            if nums[left]==0
                zeros=zeros-1
            left=left+1
        ans=max(ans,right-left)
    return ans
```

---

# Complexity
```text
Time Complexity: O(n)
Each element enters window once.
Each element leaves window once.
Space Complexity: O(1)
```

# Code Explanation
```text
1. left marks the start of the window.
2. right expands the window.
3. zeros stores how many zeros are inside current window.
4. If nums[right]==0,
   increment zeros.
5. Window can contain at most one zero.
6. If zeros>1,
   move left forward until zeros becomes 1.
7. The window length is:
   right-left+1
8. Since one element must be deleted,
   effective length becomes:
   right-left
9. Update answer using:
   ans=max(ans,right-left)
10. Continue until right reaches end.
```

---

# Why right-left Instead Of right-left+1 ?
```text
Suppose window: [1,1,0,1,1], Length=5
We must delete one element.
Delete zero: Remaining ones=4
Formula: 5-1=4
right-left+1-1=right-left
```

That is why:
```text
ans=max(ans,right-left)
```

# Other Patterns
## Pattern 1 : Prefix Consecutive Ones
### Idea
Store consecutive ones from left and right, then delete one element and combine both sides.

### Pseudocode
```text
function longestSubarray(nums)
    n=length(nums)
    left[0]=nums[0]
    for i=1 to n-1
        if nums[i]==1
            left[i]=left[i-1]+1
        else
            left[i]=0
    right[n-1]=nums[n-1]
    for i=n-2 downto 0
        if nums[i]==1
            right[i]=right[i+1]+1
        else
            right[i]=0
    ans=0
    for i=0 to n-1
        l=0
        r=0
        if i>0
            l=left[i-1]
        if i<n-1
            r=right[i+1]
        ans=max(ans,l+r)
    return ans
```

### Complexity
```text
Time: O(n)
Space: O(n)
```

---

## Pattern 2 : Count Total Ones
### Idea
Find positions of zeros and merge ones segments around one deleted zero.
### Pseudocode
```text
function longestSubarray(nums)
    find all zero positions
    for every zero
        merge ones on left and right
        update answer
    return answer
```

### Complexity
```text
Time: O(n)
Space: O(number_of_zeros)
```

# Template to Remember
```text
If problem says: "At most K bad elements" -> answer=right-left+1
If problem says:"Delete exactly one element" -> answer=right-left
Because one element is excluded from the window.
```
