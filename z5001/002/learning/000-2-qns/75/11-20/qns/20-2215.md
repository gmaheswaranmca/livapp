# 020. Find the Difference of Two Arrays

* **LC #:** 2215
* **Difficulty:** Easy
* **Pattern:** Hash Set / Set Difference

## Title

**Find the Difference of Two Arrays**

---

## Description
```text
Given two integer arrays `nums1` and `nums2`, return a list `answer` of size `2` where:
* `answer[0]` contains all distinct integers in `nums1` that are not present in `nums2`.
* `answer[1]` contains all distinct integers in `nums2` that are not present in `nums1`.
The integers in each list may be returned in any order.
```
---

## Examples

```text
Input: nums1=[1,2,3], nums2=[2,4,6]
Output: [[1,3],[4,6]]
Explanation:
Distinct nums1={1,2,3}
Distinct nums2={2,4,6}
nums1-nums2={1,3}
nums2-nums1={4,6}
```

```text
Input: nums1=[1,2,3,3], nums2=[1,1,2,2]
Output: [[3],[]]
Explanation:
Distinct nums1={1,2,3}
Distinct nums2={1,2}
nums1-nums2={3}
nums2-nums1={}
```

```text
Input: nums1=[1], nums2=[100]
Output: [[1],[100]]
```

---

## Constraints

```text
1 <= nums1.length, nums2.length <= 1000
-1000 <= nums1[i], nums2[i] <= 1000
```

---

# Idea (One Line)
Convert arrays into sets and compute set differences in both directions.

---

# Pseudocode
```text
function findDifference(nums1,nums2)
    set1 = createSet(nums1)
    set2 = createSet(nums2)
    answer1=emptyList()
    for each x in set1
        if x not in set2
            add x to answer1
    answer2=emptyList()

    for each x in set2
        if x not in set1
            add x to answer2
    return [answer1,answer2]
```

---

# Complexity
```text
Time Complexity: O(n + m)
Creating sets: O(n + m)
Finding differences: O(n + m)
Space Complexity: O(n + m)
```

where:
```text
n=length(nums1)
m=length(nums2)
```

# Code Explanation

```text
1. Convert nums1 into a set to remove duplicates.
2. Convert nums2 into a set to remove duplicates.
3. Traverse set1.
    4. If element does not exist in set2,
    add it to answer1.
5. Traverse set2.
    6. If element does not exist in set1,
    add it to answer2.
7. Return:
   [answer1, answer2]
```

---

# Why Use Set?

```text
Suppose: nums1 = [1,2,3,3], nums2 = [1,1,2,2]
Without set: 1 appears twice, 2 appears twice, 3 appears twice
After converting: set1 = {1,2,3}, set2 = {1,2}
Duplicates are removed automatically. Then: set1 - set2 = {3}, set2 - set1 = {}
```

# Other Patterns
## Pattern 1 : Boolean Array / Frequency Array
### Idea
Store existence of values in frequency arrays and compare presence.

### Pseudocode
```text
function findDifference(nums1,nums2)
    offset = 1000

    exist1[2001] = false
    exist2[2001] = false

    for each x in nums1
        exist1[x + offset] = true
    for each x in nums2
        exist2[x + offset] = true

    answer1 = emptyList()
    for i = 0 to 2000
        if exist1[i] == true and exist2[i] == false
            add i - offset to answer1
    answer2 = emptyList()
    for i = 0 to 2000
        if exist2[i] == true and exist1[i] == false
            add i - offset to answer2
    return [answer1, answer2]
```

### Complexity

```text
Time: O(n + m + range)
Space: O(range)
```

## Pattern 3 : Brute Force
### Idea
For every unique element in one array, scan the other array completely.

### Pseudocode
```text
function findDifference(nums1, nums2)
    answer1 = emptyList()
    for each unique x in nums1
        found = false
        for each y in nums2
            if x == y
                found=true
        if found == false
            add x to answer1
    repeat similarly for nums2
    return [answer1, answer2]
```

### Complexity

```text
Time: O(n*m)
Space: O(1)
```

# Template to Remember

```text
If problem asks: Find elements present in A but not in B
Then: A - B

If problem asks: Find elements present in both
Then: A ∩ B

If problem asks: Find all unique elements from both
Then: A ∪ B

If problem asks: Find elements exclusive to each
Then: (A - B, B - A)
```

# Key Observation

```text
This problem is not about array traversal.
It is actually:
Find: Unique(nums1) - Unique(nums2)
and  Unique(nums2) - Unique(nums1)

Hash Set supports:
    Insert : O(1)
    Search : O(1)
    Difference : O(n)

Hence Hash Set is the most natural and optimal solution.
```
