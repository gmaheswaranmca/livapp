# 014. LC #643 - Maximum Average Subarray I

| Field               | Value                                                                                                                                                                           |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LC#**             | 643                                                                                                                                                                             |
| **Title**           | Maximum Average Subarray I                                                                                                                                                      |
| **Difficulty**      | Easy                                                                                                                                                                            |
| **Description**     | Given an integer array `nums` consisting of `n` elements and an integer `k`, find a contiguous subarray of length `k` that has the maximum average value and return that value. |
| **Idea (One Line)** | Keep a fixed-size sliding window of size `k` and track the maximum window sum.                                                                                                  |

---

## Example 1

```text
Input: nums=[1,12,-5,-6,50,3], k=4
Output: 12.75
Explanation:
Window [1,12,-5,-6], sum=2, avg=0.5
Window [12,-5,-6,50], sum=51, avg=12.75
Window [-5,-6,50,3], sum=42, avg=10.5
Maximum average=51/4=12.75
```

---

## Example 2

```text
Input: nums=[5], k=1
Output: 5.0
Explanation:
Only one window exists.
Average=5/1=5.0
```

---

## Constraints

```text
1 <= k <= nums.length <= 10^5
-10^4 <= nums[i] <= 10^4
```

---

# Main Pattern

## Fixed Size Sliding Window

### Idea

```text
Compute first window sum of size k.
Slide window by removing left element and adding right element.
Track maximum sum.
```

---

# Formula

```text
windowSum=windowSum-nums[left]+nums[right]
average=maxSum/k
```

---

# Pseudo Code

```text
function findMaxAverage(nums,k)
    windowSum = 0
    for i = 0 to k-1
        windowSum = windowSum + nums[i]
    maxSum = windowSum
    for i = k to length(nums)-1
        windowSum = windowSum - nums[i-k]
        windowSum = windowSum + nums[i]
        maxSum = max(maxSum,windowSum)
    return maxSum/k
```

---

# Code Explanation

```text
1. Calculate sum of first k elements.
2. Store it as maxSum.
3. Move window one step to the right.
4. Remove nums[i-k] from windowSum.
5. Add nums[i] into windowSum.
6. Update maxSum=max(maxSum,windowSum).
7. Repeat until end of array.
8. Return maxSum/k.
```

---

# Complexity

| Operation | Complexity |
| --------- | ---------: |
| Time      |       O(n) |
| Space     |       O(1) |

Reason:

```text
Each element enters window once and leaves window once.
```

# Other Patterns

## Pattern 1 : Prefix Sum

### Idea

```text
Store prefix sums and calculate every window sum in O(1).
```

### Pseudo Code

```text
function findMaxAverage(nums,k)
    n = length(nums)
    prefix[0] = 0
    for i = 0 to n-1
        prefix[i+1] = prefix[i] + nums[i]
    maxSum = -infinity
    for i = 0 to n-k
        currSum = prefix[i+k] - prefix[i]
        maxSum = max(maxSum,currSum)
    return maxSum/k
```

---

## Pattern 2 : Brute Force

### Idea

```text
Calculate sum of every subarray of size k separately.
```

### Pseudo Code

```text
function findMaxAverage(nums,k)
    maxSum = -infinity
    for i = 0 to n-k
        currSum = 0
        for j = i to i+k-1
            currSum = currSum + nums[j]
        maxSum = max(maxSum,currSum)
    return maxSum/k
```

---

## Pattern 3 : Queue Based Sliding Window

### Idea

```text
Store k elements in queue and maintain running sum.
```

### Pseudo Code

```text
function findMaxAverage(nums,k)
    create queue
    sum = 0
    maxSum = -infinity
    for each num in nums
        push num
        sum = sum + num
        if size(queue) > k
            sum = sum - front(queue)
            pop front
        if size(queue) == k
            maxSum = max(maxSum,sum)
    return maxSum/k
```

# Comparison of Approaches

| Pattern              |   Time | Space | Recommended       |
| -------------------- | -----: | ----: | ----------------- |
| Fixed Sliding Window |   O(n) |  O(1) | ✅ Best            |
| Prefix Sum           |   O(n) |  O(n) | Good              |
| Queue Sliding Window |   O(n) |  O(k) | Good              |
| Brute Force          | O(n×k) |  O(1) | ❌ Not Recommended |

---

# Why Sliding Window is Best?

```text
Brute Force:
For every window, calculate sum again.
Time=O(n×k)

Sliding Window:
Reuse previous window sum.
newSum=oldSum-removed+added
Time=O(n)
Space=O(1)
```

---

# Interview Takeaway

```text
Pattern: Fixed Size Sliding Window

Step1: Compute first window sum.
Step2: Slide window.
Step3: windowSum=windowSum-nums[i-k]+nums[i]
Step4: Update maxSum.
Step5: Return maxSum/k.

Time=O(n)
Space=O(1)
```

This is one of the most important **Fixed Size Sliding Window** problems and serves as the foundation for many other sliding window interview questions.
