## 023. Equal Row and Column Pairs

| Item       | Value                     |
| ---------- | ------------------------- |
| LeetCode   | 2352                      |
| Difficulty | Medium                    |
| Pattern    | Hash Map + Matrix         |
| Tags       | Array, Matrix, Hash Table |

### Description
```text
Given an `n x n` integer matrix `grid`, 
return the number of pairs `(ri,cj)` 
such that row `ri` and column `cj` are equal.
A row and column pair is equal if:
    * They contain the same elements.
    * The elements appear in the same order.
```
---

### Example 1

```text
Input:
grid=[
[3,2,1],
[1,7,6],
[2,7,7]
]

Output:
1

Explanation:
Row0=[3,2,1]
Col0=[3,1,2] -> not equal

Row1=[1,7,6]
Col1=[2,7,7] -> not equal

Row2=[2,7,7]
Col1=[2,7,7] -> equal

Answer=1
```

---

### Example 2

```text
Input:
grid=[
[3,1,2,2],
[1,4,4,5],
[2,4,2,2],
[2,4,2,2]
]

Output:
3

Explanation:
Row2=[2,4,2,2] matches Col0? No
Row2=[2,4,2,2] matches Col2 Yes
Row3=[2,4,2,2] matches Col2 Yes
Row3=[2,4,2,2] matches Col3 Yes

Total=3
```

---

### Constraints

```text
n==grid.length
n==grid[i].length
1<=n<=200
1<=grid[i][j]<=100000
```

---

## Idea (One Line)
Store all rows in a hash map with frequencies, then build each column and add its matching row count.

## Pseudo Code
```text
function equalPairs(grid)
    n=length(grid)
    rowMap=emptyMap()
    for i=0 to n-1
        rowKey=tuple(grid[i])
        rowMap[rowKey]=rowMap.get(rowKey,0)+1
    count=0
    for col=0 to n-1
        colList=emptyList()
        for row=0 to n-1
            append grid[row][col] to colList
        colKey=tuple(colList)
        count=count+rowMap.get(colKey,0)
    return count
```

# Code Explanation
```text
1. Create a hash map rowMap to store all rows and their frequencies.
2. Traverse each row and convert it into a tuple/string key.
3. Increase its frequency in rowMap.
4. Traverse each column.
5. Build the column as a list.
6. Convert the column into the same key format.
7. If the key exists in rowMap, add its frequency to answer.
8. Return the total count.
```

# Other Patterns
## Pattern 1: Brute Force
### Idea
Compare every row with every column element by element.

### Pseudo Code
```text
function equalPairs(grid)
    n=length(grid)
    count=0
    for row=0 to n-1
        for col=0 to n-1
            same=true
            for k=0 to n-1
                if grid[row][k]!=grid[k][col]
                    same=false
                    break
            if same
                count=count+1
    return count
```

**Complexity**
```text
Time Complexity: O(n³)
Space Complexity: O(1)
```

---

## Pattern 2: Trie
### Idea
Insert all rows into Trie and search each column.

### Pseudo Code
```text
function equalPairs(grid)
    trie=createTrie()
    for each row in grid
        trie.insert(row)
    count=0
    for each column
        count=count+trie.search(column)
    return count
```

**Complexity**

```text
Time Complexity: O(n²)
Space Complexity: O(n²)
```

---

## Pattern 3: String Serialization
### Idea
Convert rows and columns into strings and count using hash map.

### Pseudo Code
```text
function equalPairs(grid)
    rowMap=emptyMap()
    for each row
        key=join(row,"#")
        rowMap[key]=rowMap.get(key,0)+1
    count=0
    for each column
        key=serializeColumn(column)
        count=count+rowMap.get(key,0)
    return count
```

**Complexity**

```text
Time Complexity: O(n²)
Space Complexity: O(n²)
```

# Pattern Comparison
| Pattern                     |  Time | Space | Interview Preference |
| --------------------------- | ----: | ----: | -------------------- |

| String Serialization + Hash | O(n²) | O(n²) | ✅ Very Common        |
| Trie                        | O(n²) | O(n²) | △ Rarely Asked       |

### Recommended
```text
Hash Rows + Columns
Reason:
1. Simple to implement.
2. Optimal O(n²) time.
3. Easy to explain in interviews.
```

```python
class Solution:
    def equalPairs(self, grid):
        n = len(grid)

        rowMap = {}
        for i in range(n):
            rowKey = tuple(grid[i])
            rowMap[rowKey] = rowMap.get(rowKey, 0) + 1

        count = 0
        for col in range(n):
            colList = []
            for row in range(n):
                colList.append(grid[row][col])
```

```csharp
public class Solution {
    public int EqualPairs(int[][] grid) {
        int n = grid.Length;
        Dictionary<string,int> rowMap = new Dictionary<string,int>();
        for(int i=0;i<n;i++) {
            string key = string.Join(",",grid[i]);
            if(rowMap.ContainsKey(key))
                rowMap[key]++;
            else
                rowMap[key]=1;
        }

        int count = 0;
        for(int col=0;col<n;col++) {
            List<int> column = new List<int>();
            for(int row=0;row<n;row++) {
                column.Add(grid[row][col]);
            }
            string key = string.Join(",",column);

            if(rowMap.ContainsKey(key))
                count += rowMap[key];
        }
        return count;
    }
}
```
