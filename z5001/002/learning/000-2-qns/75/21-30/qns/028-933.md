## 028. Number of Recent Calls
| Field       | Value                                                                     |
| ----------- | ------------------------------------------------------------------------- |
| LC #        | 933                                                                       |
| Title       | Number of Recent Calls                                                    |
| Difficulty  | Easy                                                                      |
| Category    | Queue, Sliding Window                                                     |
| Description | Count the number of requests that happened in the last 3000 milliseconds. |
| Idea        | Keep only timestamps in the range [t-3000,t] using a queue.               |

---

## Description
```text
Write a class `RecentCounter` that counts recent requests within a certain time frame.
Implement:
    RecentCounter()
        int ping(int t)
            Adds a new request at time t.
            Returns the number of requests that occurred in the inclusive range [t-3000,t].
**Note:**
    * Every call to `ping(t)` uses a strictly larger value of `t` than the previous call.
    * Requests are stored in increasing order of time.
```
---

## Example 1
```text
Input: 
["RecentCounter","ping","ping","ping","ping"], 
[[],[1],[100],[3001],[3002]]
Output: [null,1,2,3,3]
Explanation:
ping(1)
Range=[-2999,1]
Requests={1}
Count=1

ping(100)
Range=[-2900,100]
Requests={1,100}
Count=2

ping(3001)
Range=[1,3001]
Requests={1,100,3001}
Count=3

ping(3002)
Range=[2,3002]
Request 1 is outside range.
Requests={100,3001,3002}
Count=3
```

---

## Constraints
```text
1<=t<=10^9
Each call uses strictly increasing t.
At most 10^4 calls to ping().
```

---

## Idea (One Line)
```text
Store timestamps in a queue and remove timestamps smaller than t-3000.
```

## Pseudo Code
```text
class RecentCounter
    queue = emptyQueue()
    function ping(t)
        enqueue t into queue
        while queue not empty and front(queue) < t - 3000
            dequeue queue
        return size(queue)
```

---

## Complexity
| Operation |           Time | Space |
| --------- | -------------: | ----: |
| ping(t)   | O(1) amortized |  O(n) |

### Why O(1) Amortized?
```text
Each timestamp is inserted once.
Each timestamp is removed once.
Total enqueue=n
Total dequeue<=n
Therefore total operations=O(n)
Average per ping=O(1)
```

## Code Explanation
```text
1. Create an empty queue.
2. For every ping(t), insert t into queue.
3. The valid time window is [t-3000,t].
4. Remove all timestamps from front while front<t-3000.
5. Remaining timestamps belong to the valid range.
6. Return queue size.
7. Since each element is inserted once and removed once, amortized time is O(1).
```

# Other Patterns
## Pattern 1: Dynamic Array + Left Pointer
### Idea
```text
Store all timestamps in an array and move left pointer to first valid timestamp.
```

### Pseudo Code
```text
class RecentCounter
    arr = emptyList()
    left = 0
    function ping(t)
        append t to arr
        while arr[left] < t - 3000
            left = left + 1
        return length(arr) - left
```

### Complexity
|           Time | Space |
| -------------: | ----: |
| O(1) amortized |  O(n) |

---

## Pattern 2: Queue (Optimal)
### Idea
```text
Store only valid timestamps using queue.
```
### Pseudo Code
```text
class RecentCounter
    queue=emptyQueue()
    function ping(t)
        enqueue t into queue
        while queue not empty and front(queue)<t-3000
            dequeue queue
        return size(queue)
```

### Complexity
|           Time | Space |
| -------------: | ----: |
| O(1) amortized |  O(n) |

---

## Pattern 3: Binary Search on Array
### Idea
```text
Store all timestamps and binary search first timestamp>=t-3000.
```

### Pseudo Code
```text
class RecentCounter
    arr=emptyList()
    function ping(t)
        append t to arr
        left=lowerBound(arr,t-3000)
        return length(arr)-left
```

### Complexity
|     Time | Space |
| -------: | ----: |
| O(log n) |  O(n) |

---

## Comparison of Approaches
| Approach             | Main Idea                  |           Time | Space | Recommended |
| -------------------- | -------------------------- | -------------: | ----: | ----------- |
| Brute Force          | Scan all timestamps        |           O(n) |  O(n) | ❌ No        |
| Binary Search        | Search first valid index   |       O(log n) |  O(n) | ✓           |
| Array + Left Pointer | Sliding window indices     | O(1) amortized |  O(n) | ✓✓          |
| Queue                | Keep only valid timestamps | O(1) amortized |  O(n) | ✓✓ Best     |
