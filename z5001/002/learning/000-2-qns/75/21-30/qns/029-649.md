| Description | Predict which party will finally announce victory after senators ban opponents in rounds. |
| Idea        | Use two queues to store indices of Radiant and Dire senators and simulate rounds.         |

---

## Description
```text
In the world of Dota2, there are two parties:
    * `R` -> Radiant
    * `D` -> Dire
Each senator can:
    1. Ban one senator from the opposite party.
    2. Announce victory if only senators from the same party remain.
Given a string `senate`, predict which party will finally win.
Return: "Radiant" or "Dire"
```

---

## Example 1
```text
Input: senate="RD" 
Output: "Radiant"
Explanation:
Round 1:
R acts first and bans D.
Remaining:R
Radiant wins.
```

---

## Example 2
```text
Input:senate="RDD"
Output:"Dire"
Explanation:
Initial:
Index: 0 1 2
Value: R D D
R bans first D.
Remaining: R D
Now D bans R.
Remaining:D
Dire wins.
```

---

## Constraints
```text
1<=senate.length<=10^4
senate[i] is either 'R' or 'D'
```

---

## Idea (One Line)
```text
Store Radiant and Dire indices in separate queues; smaller index bans larger and re-enters next round with index+n.
```

---

## Optimal Pattern: Two Queues Simulation
### Pseudo Code
```text
class Solution
    function predictPartyVictory(senate)
        n=length(senate)
        radiant=emptyQueue()
        dire=emptyQueue()
        for i=0 to n-1
            if senate[i]=='R'
                enqueue i into radiant
            else
                enqueue i into dire
        while radiant not empty and dire not empty
            r=dequeue radiant
            d=dequeue dire
            if r<d
                enqueue r+n into radiant
            else
                enqueue d+n into dire
        if radiant empty
            return "Dire"
        return "Radiant"
```

---

## Complexity
| Operation | Complexity |
| --------- | ---------: |
| Time      |       O(n) |
| Space     |       O(n) |

### Why O(n)?
```text
Each senator is inserted and removed from queue a constant number of times.
Therefore total operations are O(n).
```

## Code Explanation
```text
1. Store positions of Radiant senators in one queue.
2. Store positions of Dire senators in another queue.
3. Remove front senators from both queues.
4. Smaller index acts first and bans the other.
5. Winner survives and joins next round by adding n to its index.
6. Continue until one queue becomes empty.
7. Remaining queue determines the winner.
```

# Other Patterns

### Idea

```text
Two queues store positions; earlier senator bans later senator and survives to next round.
```

### Pseudo Code


## Pattern 2: Circular Array Simulation
### Idea
```text
Simulate rounds using alive array and pending bans.
```

### Pseudo Code
```text
function predictPartyVictory(senate)
    alive=array of true
    banR=0
    banD=0
    while both parties alive
        traverse all senators
            if current is banned
                continue
            if senator=='R'
                if banR>0
                    alive[i]=false
                    banR=banR-1
                else
                    banD=banD+1
            else
                if banD>0
                    alive[i]=false
                    banD=banD-1
                else
                    banR=banR+1
    return winner
```

---

## Pattern 3: String Rebuilding Simulation
### Idea
```text
In every round remove banned senators and rebuild the string.
```

### Pseudo Code
```text
function predictPartyVictory(senate)
    while both parties exist
        nextRound=""
        simulate bans
        senate=nextRound
    return winner
```

| Approach            | Main Idea                     |  Time | Space | Recommended |
| ------------------- | ----------------------------- | ----: | ----: | ----------- |

| Circular Simulation | Alive + ban counters          | O(n²) |  O(n) | △           |

## Python
```python
from collections import deque

class Solution:
    def predictPartyVictory(self, senate: str) -> str:
        n = len(senate)
        radiant = deque()
        dire = deque()
        for i in range(n):
            if senate[i] == 'R':
                radiant.append(i)
            else:
                dire.append(i)
        while radiant and dire:
            r = radiant.popleft()
            d = dire.popleft()
            if r < d:
                radiant.append(r + n)
            else:
                dire.append(d + n)
        if not radiant:
            return "Dire"
        return "Radiant"
```

```go
func predictPartyVictory(senate string) string {
	n := len(senate)
	radiant := []int{}
	dire := []int{}
	for i := 0; i < n; i++ {
		if senate[i] == 'R' {
			radiant = append(radiant, i)
		} else {
			dire = append(dire, i)
		}
	}
	for len(radiant) > 0 && len(dire) > 0 {
		r := radiant[0]
		radiant = radiant[1:]
		d := dire[0]
		dire = dire[1:]
		if r < d {
			radiant = append(radiant, r+n)
		} else {
			dire = append(dire, d+n)
		}
	}
	if len(radiant) == 0 {
		return "Dire"
	}
	return "Radiant"
}
```
