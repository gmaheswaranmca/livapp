## 027. Online Stock Span

| Field       | Value                                                                                                          |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| LC #        | 901                                                                                                            |
| Title       | Online Stock Span                                                                                              |
| Difficulty  | Medium                                                                                                         |
| Category    | Stack, Monotonic Stack                                                                                         |
| Description | Design a class that collects daily stock prices and returns the span of the stock's price for the current day. |
| Idea        | Monotonic decreasing stack storing (price,span).                                                               |

---

## Description
```text
Design an algorithm that collects the daily prices of a stock and 
returns the **span** of the stock's price for the current day.

The span of the stock's price today is defined as:
    * The maximum number of consecutive days (starting from today and going backward)
    * For which the stock price was less than or equal to today's price.
Implement:
StockSpanner()
int next(int price)
Returns span of current stock price.
```

---

## Example 1

```text
Input:
["StockSpanner","next","next","next","next","next","next","next"]
[[],[100],[80],[60],[70],[60],[75],[85]]

Output:
[null,1,1,1,2,1,4,6]

Explanation:

next(100) -> 1
Span=[100]

next(80) -> 1
Only itself because 100>80

next(60) -> 1
Only itself because 80>60

next(70) -> 2
70>=60, so span=2

next(60) -> 1
Only itself

next(75) -> 4
75>=60,70,60

next(85) -> 6
85>=75,60,70,60,80
```

---

## Constraints
```text
1<=price<=10^5

At most 10^4 calls will be made to next().
```

---

## Idea (One Line)
```text
Maintain a monotonic decreasing stack of (price,span); merge spans while top price<=current price.
```


## Pseudo Code

```text
class StockSpanner
    stack=emptyStack()
    function next(price)
        span = 1
        while stack not empty and top(stack).price<=price
            span = span + top(stack).span
            pop stack
        push (price,span) into stack
        return span
```

---

## Complexity

| Operation         |           Time | Space |
| ----------------- | -------------: | ----: |
| next(price)       | O(1) amortized |  O(n) |
| Worst single call |           O(n) |  O(n) |

### Why O(1) Amortized?

```text
Each element is pushed once.

Each element is popped once.

Total push=n
Total pop<=n

Hence total operations=O(n)

Average per call=O(1)
```

## Visual Understanding

```text
Price : 100 80 60 70 60 75 85
Span  :  1  1  1  2  1  4  6


For 85:

85>=75 -> count 1
85>=60 -> count 2
85>=70 -> count 3
85>=60 -> count 4
85>=80 -> count 5
Stop at 100 because 100>85

Including today => 6
```

---

## Code Explanation

```text
1. Maintain stack of (price,span).
2. Stack remains decreasing by price.
3. For a new price:
   While stack top price<=current price:
       Add top span to current span.
       Pop top.
4. Push (current price,current span).
5. Return span.
6. Because spans are merged, we skip many previous elements at once.
7. Hence amortized complexity becomes O(1).
```

# Other Patterns
## Pattern 1: Brute Force
### Idea
```text
Traverse backwards until a greater element is found.
```

### Pseudo Code
```text
class StockSpanner
    prices=emptyList()
    function next(price)
        append price to prices
        span=1
        i=length(prices)-2
        while i>=0 and prices[i]<=price
            span=span+1
            i=i-1
        return span
```

### Complexity
|           Time | Space |
| -------------: | ----: |
| O(n) per query |  O(n) |

---

## Pattern 2: Previous Greater Element Index
### Idea
```text
Find previous greater element using monotonic stack and compute span=index-prevGreater.
```

### Pseudo Code
```text
class StockSpanner
    stack=emptyStack()
    index=-1
    function next(price)
        index=index+1
        while stack not empty and top(stack).price<=price
            pop stack
        if stack empty
            span=index+1
        else
            span=index-top(stack).index
        push (price,index) into stack
        return span
```

### Complexity
|           Time | Space |
| -------------: | ----: |
| O(1) amortized |  O(n) |

---

## Pattern 3: Span Compression (Official Optimized)
### Idea
```text
Store (price,span) and merge spans while popping.
```

### Pseudo Code
```text
class StockSpanner
    stack=emptyStack()
    function next(price)
        span=1
        while stack not empty and top(stack).price<=price
            span=span+top(stack).span
            pop stack
        push (price,span) into stack
        return span
```

### Complexity
|           Time | Space |
| -------------: | ----: |
| O(1) amortized |  O(n) |

## Comparison of Approaches
| Approach               | Main Idea                 |           Time | Space | Recommended |
| ---------------------- | ------------------------- | -------------: | ----: | ----------- |
| Brute Force            | Scan backwards            |           O(n) |  O(n) | ❌ No        |
| Previous Greater Index | Previous greater element  | O(1) amortized |  O(n) | ✓ Good      |
| Span Compression       | Store (price,span) pairs  | O(1) amortized |  O(n) | ✓✓ Best     |
| Array + Prefix Jump    | Jump using previous spans | O(1) amortized |  O(n) | Rare        |

## Python

```python
class StockSpanner:
    def __init__(self):
        self.stack = []  # (price, span)
    def next(self, price: int) -> int:
        span = 1
        while self.stack and self.stack[-1][0] <= price:
            span += self.stack.pop()[1]
        self.stack.append((price, span))
        return span
```

## Java

```java
import java.util.Stack;

class StockSpanner {
    private static class Pair {
        int price;
        int span;
        Pair(int price, int span) {
            this.price = price;
            this.span = span;
        }
    }
    private Stack<Pair> stack;
    public StockSpanner() {
        stack = new Stack<>();
    }
    public int next(int price) {
        int span = 1;
        while (!stack.isEmpty() && stack.peek().price <= price) {
            span += stack.pop().span;
        }
        stack.push(new Pair(price, span));
        return span;
    }
}
```

## C++

```cpp
#include <stack>
#include <utility>
using namespace std;

class StockSpanner {
private:
    stack<pair<int, int>> st; // {price, span}
public:
    StockSpanner() {}
    int next(int price) {
        int span = 1;
        while (!st.empty() && st.top().first <= price) {
            span += st.top().second;
            st.pop();
        }
        st.push({price, span});
        return span;
    }
};
```

## JavaScript

```javascript
class StockSpanner {
    constructor() {
        this.stack = []; // [price, span]
    }
    next(price) {
        let span = 1;
        while (
            this.stack.length > 0 &&
            this.stack[this.stack.length - 1][0] <= price
        ) {
            span += this.stack.pop()[1];
        }
        this.stack.push([price, span]);
        return span;
    }
}
```
