# 021. Unique Number of Occurrences
* **LC #:** 1207
* **Difficulty:** Easy
* **Pattern:** HashMap + HashSet

## Title
**Unique Number of Occurrences**

---

## Description
```text
Given an array of integers `arr`, return `true` 
if the number of occurrences of each value 
in the array is unique, otherwise return `false`.
In other words:
    * Count how many times each number appears.
    * All those frequencies must be different.
```

---

## Examples

```text
Input: arr=[1,2,2,1,1,3]
Output: true
Explanation: 1 appears 3 times, 2 appears 2 times, 3 appears 1 time
Frequencies={3,2,1}
All are unique.
```

```text
Input: arr=[1,2]
Output: false
Explanation: 1 appears 1 time, 2 appears 1 time
Frequencies={1,1}
Frequency 1 repeats.
Answer=false
```

```text
Input: arr=[-3,0,1,-3,1,1,1,-3,10,0]
Output: true
Explanation: -3 -> 3 times, 0  -> 2 times, 1  -> 4 times, 10 -> 1 time
Frequencies={3,2,4,1}
All are unique.
```

---

## Constraints
```text
1<=arr.length<=1000
-1000<=arr[i]<=1000
```

---

# Idea (One Line)
Count frequencies using HashMap and verify uniqueness of counts using HashSet.

---

# Pseudocode
```text
function uniqueOccurrences(arr)
    freq=emptyMap()
    for each num in arr
        if num not in freq
            freq[num]=0
        freq[num]=freq[num]+1
    seen=emptySet()
    for each count in freq.values()
        if count in seen
            return false
        add count to seen
    return true
```

---

# Complexity
```text
Time Complexity: O(n)
    Frequency counting: O(n)
    Checking uniqueness: O(n)
Space Complexity: O(n)
```

# Code Explanation

```text
1. Create a HashMap called freq.
2. Traverse the array.
3. Count how many times each number appears.
4. Create a HashSet called seen.
5. Traverse all frequency values.
6. If count already exists in seen,
   return false.
7. Otherwise insert count into seen.
8. If traversal completes,
   return true.
```

---

# Why HashSet Works?
```text
Suppose: freq={1:3,2:2,3:1}
Insert counts one by one:
    seen={}
    Insert 3 -> {3}
    Insert 2 -> {3,2}
    Insert 1 -> {3,2,1}
All insertions are unique.
```

```text
Suppose: freq={1:1,2:1}
seen={}
    Insert 1 -> {1}
    Insert 1 again
Already exists
Return false
```

# Other Patterns
## Pattern 1 : Compare Sizes of Sets
### Idea
If the number of unique values equals the number of unique frequencies, then occurrences are unique.

### Pseudocode
```text
function uniqueOccurrences(arr)
    freq=emptyMap()
    for each x in arr
        freq[x]=freq.get(x,0)+1
    counts=createSet(freq.values())
    return size(freq)==size(counts)
```

### Complexity
```text
Time: O(n)
Space: O(n)
```

---

## Pattern 2 : Frequency Array
### Idea
Use array indexing because values are bounded.

### Pseudocode
```text
function uniqueOccurrences(arr)
    offset=1000
    freq[2001]=0
    for each x in arr
        freq[x+offset]=freq[x+offset]+1
    seen=emptySet()
    for each count in freq
        if count>0
            if count in seen
                return false
            add count to seen
    return true
```

### Complexity
```text
Time: O(n)
Space: O(1)
```

Because range is fixed.

---

## Pattern 3 : Sorting Frequencies
### Idea
Sort all frequency counts and check adjacent duplicates.

### Pseudocode
```text
function uniqueOccurrences(arr)
    freq=emptyMap()
    for each x in arr
        freq[x]=freq.get(x,0)+1
    counts=list(freq.values())
    sort(counts)
    for i=1 to length(counts)-1
        if counts[i]==counts[i-1]
            return false
    return true
```

### Complexity
```text
Time: O(nlogn)
Space: O(n)
```

# Key Observation

```text
The problem is not asking: "Are numbers unique?"
It asks: "Are frequencies unique?"

Frequencies: {3,2,1}
The uniqueness check is performed on: frequency values
```

## Python
```python
def uniqueOccurrences(arr):
    freq = {}

    for num in arr:
        if num not in freq:
            freq[num] = 0
        freq[num] += 1

    seen = set()

    for count in freq.values():
        if count in seen:
            return False

        seen.add(count)

    return True
```

## C++
```cpp
#include <vector>
#include <unordered_map>
#include <unordered_set>
using namespace std;

bool uniqueOccurrences(vector<int>& arr) {
    unordered_map<int,int> freq;
    for(int num : arr) {
        freq[num]++;
    }

    unordered_set<int> seen;
    for(auto &p : freq) {
        int count = p.second;
        if(seen.count(count))
            return false;
        seen.insert(count);
    }

    return true;
}
```

## Java

```java
import java.util.*;

class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        Map<Integer,Integer> freq = new HashMap<>();
        for(int num : arr) {
            freq.put(num,freq.getOrDefault(num,0)+1);
        }

        Set<Integer> seen = new HashSet<>();
        for(int count : freq.values()) {
            if(seen.contains(count))
                return false;
            seen.add(count);
        }

        return true;
    }
}
```

```csharp
public class Solution
{
    public bool UniqueOccurrences(int[] arr)
    {
        Dictionary<int,int> freq = new Dictionary<int,int>();
        foreach(int num in arr)
        {
            if(!freq.ContainsKey(num))
                freq[num] = 0;
            freq[num]++;
        }

        HashSet<int> seen = new HashSet<int>();
        foreach(int count in freq.Values)
        {
            if(seen.Contains(count))
                return false;
            seen.Add(count);
        }
        return true;
    }
}
```
