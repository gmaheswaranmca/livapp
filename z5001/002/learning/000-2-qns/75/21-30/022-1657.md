# 022. Determine if Two Strings Are Close

* **LC #:** 1657
* **Difficulty:** Medium
* **Pattern:** HashMap Frequency + Character Set

## Title
**Determine if Two Strings Are Close**

---

## Description
```text
Two strings `word1` and `word2` are considered **close** 
if you can transform one string into the other 
using the following operations any number of times:
    1. Swap any two existing characters.
    2. Transform every occurrence of one existing character 
       into another existing character, and do the same in reverse.
Return `true` if `word1` and `word2` are close, 
otherwise return `false`.
```

---

## Important Observation
```text
Operation 2 means: a ↔ b
"abbccc" becomes "baaccc"
Characters can exchange their frequencies.
Therefore:
    Characters must be same.
    Frequencies may be rearranged.
```

---

## Examples

```text
Input: word1="abc", word2="bca"
Output: true
Explanation:
Operation 1 allows rearrangement.
Both have:
Characters={a,b,c}
Frequencies=[1,1,1]
```

```text
Input: word1="a", word2="aa"
Output: false
Explanation:
Lengths differ.
Transformation impossible.
```


```text
Input: word1="cabbba", word2="abbccc"
Output: true
Explanation:
word1:
a -> 2
b -> 3
c -> 1
word2:
a -> 1
b -> 2
c -> 3
Same characters.
Frequency multisets:
[1,2,3]
[1,2,3]
Therefore true.
```

---

```text
Input: word1="cabbba", word2="aabbss"
Output: false
Explanation:
Characters differ.
word1={a,b,c}
word2={a,b,s}
Transformation impossible.
```

---

## Constraints
```text
1<=word1.length,word2.length<=10^5
word1 and word2 contain lowercase English letters.
```

---

# Idea (One Line)
Two strings are close if they have the same character set and the same frequency multiset.

---

# Pseudocode
```text
function closeStrings(word1,word2)
    if length(word1) != length(word2)
        return false
    freq1[26] = 0
    freq2[26] = 0
    for each ch in word1
        index = ch - 'a'
        freq1[index] = freq1[index] + 1
    for each ch in word2
        index = ch - 'a'
        freq2[index] = freq2[index] + 1
    for i = 0 to 25
        if freq1[i] == 0 and freq2[i] > 0
            return false
        if freq1[i] > 0 and freq2[i] == 0
            return false
    sort(freq1)
    sort(freq2)
    return freq1 == freq2
```

```
function closeStrings(word1, word2)

    freq1=emptyMap()

        if ch not in freq2
            freq2[ch]=0
        freq2[ch]=freq2[ch]+1

        return false
    counts1=list(freq1.values())
    counts2=list(freq2.values())

    sort(counts1)
    sort(counts2)

    return counts1==counts2
```

# Code Explanation
```text
1. If lengths differ,
   return false.
2. Count frequencies of all 26 letters.
3. Verify that both strings use exactly the same characters.
4. If a character appears in one string but not the other,
   return false.
5. Sort both frequency arrays.
6. Compare sorted arrays.
7. If equal,
   return true.
8. Otherwise,
   return false.
```

---

# Why Sorting Frequencies Works?
```text
Operation 2 allows:
Swap character identities.

Example: a:5, b:2
can become a:2, b:5

Therefore: Exact character-frequency mapping is NOT important.
Only: Frequency multiset matters.

Example:
word1 a:1, b:3, c:2
word2 a:3, b:1, c:2
Frequencies: [1,3,2], [3,1,2]
Sort: [1,2,3], [1,2,3]
Hence transformable.
```

# Other Patterns
## Pattern 1 : HashMap + Sorting
### Idea
Store frequencies in HashMaps, compare key sets and sorted values.

### Pseudocode
```text
function closeStrings(word1,word2)
    map1=count(word1)
    map2=count(word2)

    if keys(map1)!=keys(map2)
        return false
    counts1=values(map1)
    counts2=values(map2)
    sort(counts1)
    sort(counts2)
    return counts1==counts2
```

### Complexity

```text
Time: O(n)
Space: O(26)
```

---

## Pattern 2 : Counter Comparison

### Idea
Compare character sets and compare sorted frequency lists.

### Pseudocode

```text
function closeStrings(word1,word2)
    freq1=count(word1)
    freq2=count(word2)
    return 
        set(keys(freq1))==set(keys(freq2))
            and
        sort(values(freq1))==sort(values(freq2))
```

### Complexity

```text
Time: O(n)
Space: O(26)
```

---

## Pattern 3 : Brute Force
### Idea
Try all frequency rearrangements.

### Pseudocode
```text
function closeStrings(word1,word2)
    generate all permutations of frequencies
    check whether word2 can be formed
    return result
```

### Complexity

```text
Time: Exponential
Space: Exponential
```

# Key Observations
```text
Condition 1:
Same character set
Example:
abc
abd
Not close.
Condition 2:
Same frequency multiset
Example:
a:1,b:2,c:3
and
a:3,b:1,c:2
Close.
Character ↔ Frequency mapping may change.
Character existence cannot change.
```

# Template to Remember

```text
If problem allows:
    Swap positions
        +
    Swap character identities
Then: Check
    1. Same set of characters.
    2. Same multiset of frequencies.
If both hold: Return true.
```

## Python
```python
def closeStrings(word1, word2):
    if len(word1) != len(word2):
        return False

    freq1 = {}
    freq2 = {}
    for ch in word1:
        if ch not in freq1:
            freq1[ch] = 0
        freq1[ch] += 1
    for ch in word2:
        if ch not in freq2:
            freq2[ch] = 0
        freq2[ch] += 1

    if set(freq1.keys()) != set(freq2.keys()):
        return False
    counts1 = sorted(freq1.values())
    counts2 = sorted(freq2.values())

    return counts1 == counts2
```


## C++

```cpp
#include <unordered_map>

using namespace std;

bool closeStrings(string word1, string word2) {
    if(word1.size() != word2.size())
        return false;

    unordered_map<char,int> freq1;
    unordered_map<char,int> freq2;
    for(char ch : word1)
        freq1[ch]++;
    for(char ch : word2)
        freq2[ch]++;

    for(auto &p : freq1) {
        if(freq2.count(p.first) == 0)
            return false;
    }
    for(auto &p : freq2) {
        if(freq1.count(p.first) == 0)
            return false;
    }

    vector<int> counts1, counts2;
    for(auto &p : freq1)
        counts1.push_back(p.second);
    for(auto &p : freq2)
        counts2.push_back(p.second);

    sort(counts1.begin(), counts1.end());
    sort(counts2.begin(), counts2.end());

    return counts1 == counts2;
}
```

## Java

```java
import java.util.*;

class Solution {
    public boolean closeStrings(String word1, String word2) {
        if(word1.length()!=word2.length())
            return false;

        HashMap<Character,Integer> freq1=new HashMap<>();
        HashMap<Character,Integer> freq2=new HashMap<>();

        for(char ch:word1.toCharArray())
            freq1.put(ch,freq1.getOrDefault(ch,0)+1);

        for(char ch:word2.toCharArray())
            freq2.put(ch,freq2.getOrDefault(ch,0)+1);

        if(!freq1.keySet().equals(freq2.keySet()))
            return false;

        ArrayList<Integer> counts1=new ArrayList<>(freq1.values());
        ArrayList<Integer> counts2=new ArrayList<>(freq2.values());

        Collections.sort(counts1);
        Collections.sort(counts2);

        return counts1.equals(counts2);
    }
}
```

## C#

```csharp
using System.Collections.Generic;
using System.Linq;

public class Solution
{
    public bool CloseStrings(string word1, string word2)
    {
        if(word1.Length!=word2.Length)
            return false;

        Dictionary<char,int> freq1=new Dictionary<char,int>();
        Dictionary<char,int> freq2=new Dictionary<char,int>();
        foreach(char ch in word1)
        {
            if(!freq1.ContainsKey(ch))
                freq1[ch]=0;
            freq1[ch]++;
        }
        foreach(char ch in word2)
        {
            if(!freq2.ContainsKey(ch))
                freq2[ch]=0;
            freq2[ch]++;
        }

        if(!freq1.Keys.ToHashSet().SetEquals(freq2.Keys))
            return false;

        var counts1=freq1.Values.OrderBy(x=>x).ToList();
        var counts2=freq2.Values.OrderBy(x=>x).ToList();

        return counts1.SequenceEqual(counts2);
    }
}
```

## Go
```go
import "sort"

func closeStrings(word1 string, word2 string) bool {
    if len(word1) != len(word2) {
        return false
    }

    freq1 := make(map[byte]int)
    freq2 := make(map[byte]int)
    for i := 0; i < len(word1); i++ {
        freq1[word1[i]]++
    }
    for i := 0; i < len(word2); i++ {
        freq2[word2[i]]++
    }

    for ch := range freq1 {
        if _, ok := freq2[ch]; !ok {
            return false
        }
    }

    for ch := range freq2 {
        if _, ok := freq1[ch]; !ok {
            return false
        }
    }

    counts1 := []int{}
    counts2 := []int{}
    for _, v := range freq1 {
        counts1 = append(counts1, v)
    }

    for _, v := range freq2 {
        counts2 = append(counts2, v)
    }

    sort.Ints(counts1)
    sort.Ints(counts2)
    for i := 0; i < len(counts1); i++ {
        if counts1[i] != counts2[i] {
            return false
        }
    }

    return true
}
```

```c
#include <stdbool.h>
#include <string.h>
#include <stdlib.h>

int compare(const void *a,const void *b)
{
    return (*(int*)a)-(*(int*)b);
}
bool closeStrings(char *word1,char *word2)
{
    if(strlen(word1)!=strlen(word2))
        return false;
    int freq1[26] = {0};
    int freq2[26] = {0};
    for(int i = 0;word1[i] != '\0';i++)
        freq1[word1[i] - 'a']++;
    for(int i = 0;word2[i] != '\0';i++)
        freq2[word2[i] - 'a']++;

    for(int i = 0;i < 26;i++)
    {
        if(freq1[i] == 0 && freq2[i] > 0)
            return false;
        if(freq1[i] > 0 && freq2[i] == 0)
            return false;
    }

    qsort(freq1,26,sizeof(int),compare);
    qsort(freq2,26,sizeof(int),compare);
    for(int i = 0;i < 26;i++)
    {
        if(freq1[i] != freq2[i])
            return false;
    }

    return true;
}
```

### Note for C

```text
C does not provide built-in HashMap.

For this problem, because only lowercase English letters exist,
an array of size 26 is preferred and considered the optimal C solution.

The HashMap approach shown in other languages is conceptually equivalent.
```
