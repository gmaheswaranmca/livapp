# 443. String Compression

String Compression

## Problem Statement

Given an array of characters `chars`, compress it **in-place** using the following rule:

* Consecutive repeating characters form a group.
* Write the character once.
* If the count is greater than `1`, write the count as separate digits.

Return the **new length** of the compressed array.

---

## Compression Rules

Suppose:

```text
["a","a","a"]
```

Compress to:

```text
["a","3"]
```

---

Suppose:

```text
["a"]
```

Compress to:

```text
["a"]
```

(No count written because count = 1)

---

Suppose:

```text
["a"] repeated 12 times
```

Compress to:

```text
["a","1","2"]
```

Notice:

```text
12

↓

'1'
'2'
```

The digits are stored separately.

# Approach 1 (Recommended)

## Read Pointer + Write Pointer

This is the standard in-place solution.

---

### Idea

Use:

```text
read
```

to scan groups.

Use:

```text
write
```

to write compressed result.

---

# Pseudo Code

```text
function compress(chars):

    read = 0

    write = 0


    while read < n:

        current = chars[read]

        count = 0


        while read < n

        and chars[read] == current:

            read++

            count++


        chars[write] = current

        write++


        if count > 1:

            digits = toString(count)

            for d in digits:

                chars[write] = d

                write++


    return write
```

# Pattern Used

## 1. Fast and Slow Pointer (Read / Write) ⭐⭐⭐⭐⭐

This is the most important pattern here.

---

### Template

```text
read scans input


write stores answer
```

---

Generic:

```text
read=0

write=0


while read<n:

    process group

    write result
```

---

Used in:

* String Compression
* Remove Duplicates
* Move Zeroes
* Remove Element
* Array Deduplication
* URL Encoding

# Alternative Pattern 2 : Group Start + Group End

Maintain:

```text
start

end
```

---

Example

```text
a a a b b c

S
E
```

Expand:

```text
while chars[end]==chars[start]

    end++
```

Count:

```text
end-start
```

Write compressed result.

Move:

```text
start=end
```

---

## Pseudo Code

```text
start=0

while start<n:

    end=start


    while end<n

    and chars[end]==chars[start]:

        end++


    count=end-start


    write compressed


    start=end
```

---

### Complexity

```text
Time : O(n)

Space: O(1)
```

Same idea.

---


# Alternative Pattern 5 : Run Length Encoding (RLE)

This problem is actually:

```text
Run Length Encoding
```

---

Example

```text

```

```text

```

---

General RLE Pseudo Code

```text
count=1

for i:

    if current==previous:

        count++

    else:

        output previous,count

        count=1
```

---

This is used in:

* PNG compression
* Fax encoding
* Bitmap compression
* Data compression systems
