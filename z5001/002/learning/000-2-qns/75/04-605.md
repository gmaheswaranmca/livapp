# 605. Can Place Flowers

Can Place Flowers

## Problem Statement

You have a flowerbed represented by an integer array `flowerbed`, where:

```text
0 -> empty plot
1 -> already planted flower
```

Flowers cannot be planted in adjacent plots.

Given an integer `n`, return:

```text
true  -> if n new flowers can be planted
false -> otherwise
```

---

# Description

You want to plant exactly `n` flowers.

A flower can be planted at index `i` only if:

```text
flowerbed[i] == 0

AND

left neighbor is empty or does not exist

AND

right neighbor is empty or does not exist
```

That means:

```text
flowerbed[i-1] != 1
flowerbed[i]   == 0
flowerbed[i+1] != 1
```

Boundary positions are handled specially:

* First index has no left neighbor.
* Last index has no right neighbor.

# Observation

Suppose:

```text
flowerbed = [1,0,0,0,1]

n = 1
```

Can we plant at:

```text
index 1 ?
```

No:

```text
1 0 0 0 1
↑

left neighbor is 1
```

---

Can we plant at:

```text
index 2 ?
```

```text

self  = 0

right = 0
```

Plant immediately:

```text

```

---

This gives an important insight:

> If a flower can be planted now,
> planting it immediately never hurts future choices.

This is a **Greedy Problem**.

# Approach 1 (Recommended)

## Greedy Placement

Traverse from left to right.

Whenever:

```text
left empty

current empty

right empty
```

Plant immediately.

Increase:

```text
count++
```

If:

```text
count >= n
```

Return:

```text
true
```

---

# Pseudo Code

```text
function canPlaceFlowers(flowerbed, n):

    count = 0

    for i from 0 to length(flowerbed)-1:

        leftEmpty =

            (i==0) OR flowerbed[i-1]==0

        rightEmpty =

            (i==last) OR flowerbed[i+1]==0


        if flowerbed[i]==0
        and leftEmpty
        and rightEmpty:

            flowerbed[i]=1

            count++

            if count >= n:

                return true


    return count >= n
```

# Pattern Used

## 1. Greedy Placement ⭐⭐⭐⭐⭐

This is the standard solution.

---

### Greedy Rule

```text
If a flower can be planted now,

plant it immediately.
```

Why?

Because planting at earliest available position:

* never blocks a better solution
* maximizes future space

---

### Generic Greedy Template

```text
for each position:

    if safe:

        choose it immediately
```

---

This pattern appears in:

* Interval Scheduling
* Jump Game
* Gas Station
* Cookie Assignment
* Activity Selection
* Flowerbed Placement

---

# Alternative Pattern 2 : Count Consecutive Zeros

Instead of modifying the array.

Count blocks of zeros.

Example:

```text
0 0 0 0 0
```

Length:

```text
5
```

Maximum flowers:

```text
(5+1)/2

=3
```

if boundaries are empty.

---

### Example

```text
flowerbed

0 0 0 1 0 0 0 0
```

Zero blocks:

```text
[0 0 0]

can place 2


[0 0 0 0]

can place 2
```

Total:

```text
4 flowers
```

---

## Pseudo Code

```text
count consecutive zeros

for every zero block:

    compute possible flowers

add to total

return total >= n
```

---

### Complexity

```text
Time : O(n)

Space: O(1)
```

More complicated than greedy.

---

# Alternative Pattern 3 : Brute Force Backtracking

Try:

```text
plant

or

don't plant
```

at every index.

---

## Pseudo Code

```text
function solve(index, remaining):

    if remaining==0:

        return true

    if index>=n:

        return false


    option1 = skip


    option2 =

       if safe:

           plant

           recurse


    return option1 OR option2
```

---

### Complexity

```text
O(2^n)
```

Very slow.

Used only for understanding.

---

# Why Greedy is Correct

Suppose:

```text
0 0 0 0
```

At first valid position:

```text
1 0 0 0
```

Remaining:

```text
1 0 1 0
```

Total:

```text
2 flowers
```

If you skip:

```text
0 1 0 0
```

Still:

```text
0 1 0 1
```

Total:

```text
2 flowers
```

Greedy never reduces the answer.

Hence:

```text
Always plant when possible.
```
