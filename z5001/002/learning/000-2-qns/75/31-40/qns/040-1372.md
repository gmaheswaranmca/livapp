## 040. Longest ZigZag Path in a Binary Tree

**Difficulty:** Medium

### Description

You are given the `root` of a binary tree.

A ZigZag path is defined as:

* Choose any node and a direction (left or right).
* If current direction is left, move to the left child.
* Then switch direction and move to the right child.
* Continue alternating directions until you cannot move further.

The length of a ZigZag path is the number of edges visited.

Return the length of the longest ZigZag path in the tree.

---

### Examples

```text
Input: root=[1,null,1,1,1,null,null,1,1,null,1]

            1
             \
              1
             / \
            1   1
           /     \
          1       1
           \
            1

Output: 3

Explanation:
One longest ZigZag path is:

1 -> right
1 -> left
1 -> right

Length=3
```

```text
Input: root=[1,1,1,null,1,null,null,1,1,null,1]

Output: 4
```

```text
Input: root=[1]

Output: 0
```

---

### Constraints

```text
Number of nodes is in the range [1,50000].
1<=Node.val<=100
```

---

## Idea (One Line)

Use DFS and keep track of previous direction and current ZigZag length.

---

## Pseudocode (DFS Tracking Direction)

```text
function longestZigZag(root)
    answer=0
    dfs(root.left,0,1)
    dfs(root.right,1,1)
    return answer

function dfs(node,direction,length)
    if node==null
        return
    answer=max(answer,length)
    if direction==0
        dfs(node.right,1,length+1)
        dfs(node.left,0,1)
    else
        dfs(node.left,0,length+1)
        dfs(node.right,1,1)
```

where

```text
direction=0 means previous move was left
direction=1 means previous move was right
```

---

## Complexity

```text
Time Complexity: O(n)
Space Complexity: O(h)

n=number of nodes
h=height of tree
```

### DFS Traversal

|                    Node | Previous Direction | Current Length | Answer |
| ----------------------: | ------------------ | -------------: | -----: |
|           1(root.right) | Right              |              1 |      1 |
|                 1(left) | Left               |              2 |      2 |
|            1(left.left) | Left again         |              1 |      2 |
|      1(left.left.right) | Right              |              2 |      2 |
|                1(right) | Right again        |              1 |      2 |
|          1(right.right) | Right              |              1 |      2 |
| Continue alternate path | Alternate          |              3 |      3 |

### Longest ZigZag

```text
root
 -> right
 -> left
 -> right

Length=3
```

```text
Return 3
```

---

## Code Explanation

```text
1. Start DFS from root.left with direction=left and length=1.
2. Start DFS from root.right with direction=right and length=1.
3. At every node update answer=max(answer,length).
4. If previous move was left, continue ZigZag by moving right with length+1.
5. Moving left again breaks ZigZag, restart length=1.
6. Similarly for previous right direction.
7. Continue DFS until null nodes.
8. Return answer.
```

# Other Patterns

## 1. Bottom-Up DFS DP

### Idea

For every node compute longest ZigZag ending with left and right move.

### Pseudocode

```text
function longestZigZag(root)
    answer=0

    dfs(root)

    return answer


function dfs(node)
    if node==null
        return (-1,-1)

    leftPair=dfs(node.left)
    rightPair=dfs(node.right)

    leftLength=leftPair.right+1
    rightLength=rightPair.left+1

    answer=max(answer,max(leftLength,rightLength))

    return (leftLength,rightLength)
```

---

## 2. BFS With Direction State

### Idea

Store node,direction,length in queue.

### Pseudocode

```text
function longestZigZag(root)
    queue=emptyQueue()

    enqueue(root.left,0,1)
    enqueue(root.right,1,1)

    answer=0

    while queue not empty
        node,direction,length=dequeue queue

        if node==null
            continue

        answer=max(answer,length)

        if direction==0
            enqueue(node.right,1,length+1)
            enqueue(node.left,0,1)
        else
            enqueue(node.left,0,length+1)
            enqueue(node.right,1,1)

    return answer
```

---

## 3. DFS Returning Pair

### Idea

Each DFS returns `(leftZigZag,rightZigZag)`.

### Pseudocode

```text
function longestZigZag(root)
    answer=0

    solve(root)

    return answer


function solve(node)
    if node==null
        return (-1,-1)

    left=solve(node.left)
    right=solve(node.right)

    leftLen=left[1]+1
    rightLen=right[0]+1

    answer=max(answer,max(leftLen,rightLen))

    return (leftLen,rightLen)
```

# Comparison of Approaches

| Approach               | Idea                             | Time | Space | Recommended |
| ---------------------- | -------------------------------- | ---: | ----: | ----------: |
| DFS Tracking Direction | Pass direction and length        | O(n) |  O(h) |       ⭐⭐⭐⭐⭐ |
| Bottom-Up DFS DP       | Return left/right ZigZag lengths | O(n) |  O(h) |       ⭐⭐⭐⭐⭐ |
| DFS Returning Pair     | Return two states                | O(n) |  O(h) |        ⭐⭐⭐⭐ |
| BFS With State         | Queue with direction,length      | O(n) |  O(w) |         ⭐⭐⭐ |

where

```text
n=number of nodes
h=height of tree
w=maximum width of tree
```

---

## Best Choice

```text
Interview: DFS Tracking Direction

Reason:
1. O(n) time complexity.
2. Simple recursive solution.
3. Naturally models alternating directions.
4. Easy to explain using direction and length.
5. Standard solution for LC 1372.
```
