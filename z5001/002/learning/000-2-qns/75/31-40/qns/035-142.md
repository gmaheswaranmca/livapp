## 035. Linked List Cycle II

**Difficulty:** Medium

### Description

Given the `head` of a linked list, return the node where the cycle begins. If there is no cycle, return `null`.

There is a cycle in a linked list if some node can be reached again by continuously following the `next` pointer.

Do not modify the linked list.

---

### Examples

```text
Input: head=[3,2,0,-4], pos=1
Output: node with value 2
Explanation:
The tail connects to the node at index 1.
The cycle starts at node having value 2.
```

```text
Input: head=[1,2], pos=0
Output: node with value 1
Explanation:
The tail connects to the first node itself.
The cycle starts at node having value 1.
```

```text
Input: head=[1], pos=-1
Output: null
Explanation:
There is no cycle in the linked list.
```

---

### Constraints

```text
Number of nodes in the list is in the range [0,10^4].
-10^5<=Node.val<=10^5
pos is -1 or a valid index in the linked list.
```

---

## Idea (One Line)

Detect the meeting point using Floyd's algorithm, then reset one pointer to head and move both one step to find the cycle start.

---

## Pseudocode (Floyd Cycle Detection + Reset Pointer)

```text
function detectCycle(head)
    slow=head
    fast=head

    while fast!=null and fast.next!=null
        slow=slow.next
        fast=fast.next.next

        if slow==fast
            entry=head

            while entry!=slow
                entry=entry.next
                slow=slow.next

            return entry

    return null
```

---

## Complexity

```text
Time Complexity: O(n)
Space Complexity: O(1)
```

---

## Dry Run

### Input

```text
head=[3,2,0,-4], pos=1
```

Structure:

```text
3 -> 2 -> 0 -> -4
     ^         |
     |_________|
```

### Phase 1: Find Meeting Point

| Iteration | slow | fast | Meet? |
| --------- | ---: | ---: | ----- |
| 0         |    3 |    3 | No    |
| 1         |    2 |    0 | No    |
| 2         |    0 |    2 | No    |
| 3         |   -4 |   -4 | Yes   |

Meeting point = -4

---

### Phase 2: Find Cycle Start

Reset:

```text
entry=head=3
slow=-4
```

| Step | entry | slow |
| ---- | ----: | ---: |
| 0    |     3 |   -4 |
| 1    |     2 |    2 |

Both meet at node `2`.

```text
Return node having value 2
```

---

## Why Resetting Works

Suppose:

```text
a=distance from head to cycle start
b=distance from cycle start to meeting point
c=remaining cycle length

slow travels=a+b
fast travels=a+b+k(b+c)

Since fast moves twice:

2(a+b)=a+b+k(b+c)

a=k(b+c)-b

a=(k-1)(b+c)+c
```

Therefore,

```text
Distance from head to cycle start=a
Distance from meeting point to cycle start=c

Moving both one step at a time,
they meet exactly at cycle start.
```

---

## Code Explanation

```text
1. Initialize slow=head and fast=head.
2. Move slow by one step and fast by two steps.
3. If slow and fast meet, a cycle exists.
4. Create entry pointer at head.
5. Move entry and slow one step at a time.
6. When they meet, that node is the cycle start.
7. Return the node.
8. If fast reaches null, return null.
```

# Other Patterns

## 1. HashSet

### Idea

Store visited nodes in a set. First repeated node is the cycle start.

### Pseudocode

```text
function detectCycle(head)
    visited=emptySet()

    current=head

    while current!=null
        if current in visited
            return current

        add current into visited
        current=current.next

    return null
```

---

## 2. Mark Visited Nodes

### Idea

Modify next pointer temporarily to mark visited nodes.

### Pseudocode

```text
function detectCycle(head)
    marker=new Node()

    current=head

    while current!=null
        if current.next==marker
            return current

        nextNode=current.next
        current.next=marker
        current=nextNode

    return null
```

---

## 3. Map Node To Index

### Idea

Store node with its first occurrence index.

### Pseudocode

```text
function detectCycle(head)
    visited=emptyMap()

    current=head
    index=0

    while current!=null
        if current in visited
            return current

        visited[current]=index

        current=current.next
        index=index+1

    return null
```

# Comparison of Approaches

| Approach              | Idea                               | Time | Space | Modify List | Recommended |
| --------------------- | ---------------------------------- | ---: | ----: | ----------: | ----------: |
| Floyd + Reset Pointer | Find meeting point and cycle start | O(n) |  O(1) |          No |       ⭐⭐⭐⭐⭐ |
| HashSet               | Store visited nodes                | O(n) |  O(n) |          No |        ⭐⭐⭐⭐ |
| Map Node To Index     | Store nodes with index             | O(n) |  O(n) |          No |         ⭐⭐⭐ |
| Mark Visited          | Modify next pointer                | O(n) |  O(1) |         Yes |          ⭐⭐ |

---

## Best Choice

```text
Interview: Floyd Cycle Detection + Reset Pointer

Reason:
1. O(n) time.
2. O(1) extra space.
3. Does not modify the linked list.
4. Elegant mathematical proof.
5. Standard solution for LC 142.
```
