## 038. Count Good Nodes in Binary Tree

**Difficulty:** Medium

### Description

Given a binary tree `root`, a node `X` in the tree is named **good** if in the path from root to `X` there are no nodes with a value greater than `X`.

Return the number of good nodes in the binary tree.

---

### Examples

```text
Input: root=[3,1,4,3,null,1,5]
Output: 4

Explanation:

        3
       / \
      1   4
     /   / \
    3   1   5

Good nodes are:
3(root)
3(left-left)
4
5

Count=4
```

```text
Input: root=[3,3,null,4,2]
Output: 3

Explanation:

      3
     /
    3
   / \
  4   2

Good nodes are:
3(root)
3
4

Count=3
```

```text
Input: root=[1]
Output: 1

Explanation:
The root is always a good node.
```

---

### Constraints

```text
Number of nodes is in the range [1,10^5].
-10^4<=Node.val<=10^4
```

---

## Idea (One Line)

Perform DFS while carrying the maximum value seen so far from root to current node.

---

## Pseudocode (DFS with Max-So-Far)

```text
function goodNodes(root)
    return dfs(root,-infinity)


function dfs(node,maxSoFar)
    if node==null
        return 0

    count=0

    if node.val>=maxSoFar
        count=1

    newMax=max(maxSoFar,node.val)

    leftCount=dfs(node.left,newMax)
    rightCount=dfs(node.right,newMax)

    return count+leftCount+rightCount
```

---

## Complexity

```text
Time Complexity: O(n)
Space Complexity: O(h)

n=number of nodes
h=height of tree

Worst case: O(n)
Balanced tree: O(logn)
```

## Code Explanation

```text
1. Start DFS from root with maxSoFar=-infinity.
2. If current node is null, return 0.
3. If node.val>=maxSoFar, count this node as good.
4. Update newMax=max(maxSoFar,node.val).
5. Recursively process left subtree using newMax.
6. Recursively process right subtree using newMax.
7. Return current count+left subtree count+right subtree count.
```

# Other Patterns

## 1. DFS Using Global Counter

### Idea

Use a global variable and update answer whenever a good node is found.

### Pseudocode

```text
function goodNodes(root)
    answer=0

    dfs(root,-infinity)

    return answer


function dfs(node,maxSoFar)
    if node==null
        return

    if node.val>=maxSoFar
        answer=answer+1

    newMax=max(maxSoFar,node.val)

    dfs(node.left,newMax)
    dfs(node.right,newMax)
```

---

## 2. Iterative DFS Using Stack

### Idea

Store `(node,maxSoFar)` in stack and process iteratively.

### Pseudocode

```text
function goodNodes(root)
    stack=emptyStack()

    push(root,-infinity) into stack

    count=0

    while stack not empty
        node,maxSoFar=pop stack

        if node==null
            continue

        if node.val>=maxSoFar
            count=count+1

        newMax=max(maxSoFar,node.val)

        push(node.right,newMax) into stack
        push(node.left,newMax) into stack

    return count
```

---

## 3. BFS Level Order

### Idea

Use queue storing `(node,maxSoFar)` while traversing level by level.

### Pseudocode

```text
function goodNodes(root)
    queue=emptyQueue()

    enqueue(root,-infinity) into queue

    count=0

    while queue not empty
        node,maxSoFar=dequeue queue

        if node.val>=maxSoFar
            count=count+1

        newMax=max(maxSoFar,node.val)

        if node.left!=null
            enqueue(node.left,newMax) into queue

        if node.right!=null
            enqueue(node.right,newMax) into queue

    return count
```

# Comparison of Approaches

| Approach           | Idea                      | Time | Space | Recommended |
| ------------------ | ------------------------- | ---: | ----: | ----------: |
| DFS Recursive      | Pass maxSoFar recursively | O(n) |  O(h) |       ⭐⭐⭐⭐⭐ |
| DFS Stack          | Store(node,maxSoFar)      | O(n) |  O(h) |        ⭐⭐⭐⭐ |
| BFS Queue          | Level order with maxSoFar | O(n) |  O(w) |         ⭐⭐⭐ |
| DFS Global Counter | Global answer variable    | O(n) |  O(h) |         ⭐⭐⭐ |

where

```text
n=number of nodes
h=height of tree
w=maximum width of tree
```

---

## Best Choice

```text
Interview: DFS Recursive

Reason:
1. Very intuitive.
2. Carries only one extra value maxSoFar.
3. O(n) time complexity.
4. Easy to write and explain.
5. Standard solution for LC 1448.
```
