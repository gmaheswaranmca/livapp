## 036. Maximum Depth of Binary Tree

**Difficulty:** Easy

### Description

Given the `root` of a binary tree, return its maximum depth.

A binary tree's maximum depth is the number of nodes along the longest path from the root node down to the farthest leaf node.

---

### Examples

```text
Input: root=[3,9,20,null,null,15,7]
Output: 3
Explanation:
        3
       / \
      9   20
         /  \
        15   7

Longest path has 3 nodes.
```

```text
Input: root=[1,null,2]
Output: 2
Explanation:
1
 \
  2

Longest path has 2 nodes.
```

```text
Input: root=[]
Output: 0
Explanation:
Empty tree has depth 0.
```

---

### Constraints

```text
Number of nodes is in the range [0,10^4].
-100<=Node.val<=100
```

---

## Idea (One Line)

Use DFS recursion and return `1+max(leftDepth,rightDepth)` for each node.

---

## Pseudocode (Recursive DFS)

```text
function maxDepth(root)
    if root==null
        return 0

    leftDepth=maxDepth(root.left)
    rightDepth=maxDepth(root.right)

    return 1+max(leftDepth,rightDepth)
```

---

## Complexity

```text
Time Complexity: O(n)
Space Complexity: O(h)

n=number of nodes
h=height of tree
Worst case: O(n)
Balanced tree: O(logn)
```

## Code Explanation

```text
1. If root is null, return 0.
2. Recursively find depth of left subtree.
3. Recursively find depth of right subtree.
4. Take maximum of both depths.
5. Add 1 for current node.
6. Return the result.
```

# Other Patterns

## 1. BFS Level Order Traversal

### Idea

Traverse level by level and count the number of levels.

### Pseudocode

```text
function maxDepth(root)
    if root==null
        return 0

    queue=emptyQueue()
    enqueue root into queue

    depth=0

    while queue not empty
        size=queue.size()

        for i=1 to size
            node=dequeue queue

            if node.left!=null
                enqueue node.left into queue

            if node.right!=null
                enqueue node.right into queue

        depth=depth+1

    return depth
```

---

## 2. DFS Using Explicit Stack

### Idea

Use stack to store node and its depth.

### Pseudocode

```text
function maxDepth(root)
    if root==null
        return 0

    stack=emptyStack()

    push(root,1) into stack

    answer=0

    while stack not empty
        node,depth=pop stack

        answer=max(answer,depth)

        if node.left!=null
            push(node.left,depth+1) into stack

        if node.right!=null
            push(node.right,depth+1) into stack

    return answer
```

---

## 3. DFS With Global Variable

### Idea

Traverse tree recursively and update maximum depth globally.

### Pseudocode

```text
function maxDepth(root)
    answer=0

    dfs(root,1)

    return answer


function dfs(node,depth)
    if node==null
        return

    answer=max(answer,depth)

    dfs(node.left,depth+1)
    dfs(node.right,depth+1)
```

# Comparison of Approaches

| Approach            | Idea                       | Time | Space | Recommended |
| ------------------- | -------------------------- | ---: | ----: | ----------: |
| Recursive DFS       | 1+max(left,right)          | O(n) |  O(h) |       ⭐⭐⭐⭐⭐ |
| BFS Level Order     | Count levels               | O(n) |  O(w) |        ⭐⭐⭐⭐ |
| DFS Stack           | Explicit stack             | O(n) |  O(h) |        ⭐⭐⭐⭐ |
| DFS Global Variable | Track max depth during DFS | O(n) |  O(h) |         ⭐⭐⭐ |

where

```text
h=height of tree
w=maximum width of tree
```

## Best Choice
