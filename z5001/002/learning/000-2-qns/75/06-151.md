# 151. Reverse Words in a String

Reverse Words in a String

## Problem Statement

Given an input string `s`, reverse the order of the words.

A **word** is defined as:

```text
A sequence of non-space characters.
```

The returned string should:

1. Contain words in reverse order.
2. Have exactly **one space** between words.
3. Have **no leading or trailing spaces**.

---

# Description

You are given a sentence that may contain:

* Multiple words
* Leading spaces
* Trailing spaces
* Multiple spaces between words

You need to:

1. Extract words.
2. Reverse their order.
3. Join them using a single space.

---

### Input


# Observation

Suppose:

```text
s = "the sky is blue"
```

Words are:

```text
["the","sky","is","blue"]
```

Reverse:

```text
["blue","is","sky","the"]
```

Join:

```text
"blue is sky the"
```

This naturally gives:

```text
Split

↓

Reverse

↓

Join
```

This is the easiest solution.

# Approach 1 (Recommended for Interviews)

## Split + Reverse + Join

---

### Algorithm

1. Split string into words.
2. Ignore extra spaces.
3. Reverse word list.
4. Join with single spaces.

---

# Pseudo Code

```text
function reverseWords(s):

    words = split s by spaces

    remove empty words


    reverse(words)


    return join(words, " ")
```

---

# Dry Run

Input:

```text
s = "  hello   world  "
```

---

### Split

```text
["", "", "hello", "", "", "world", "", ""]
```

---

### Remove empty strings

```text
["hello","world"]
```

---

### Reverse

```text
["world","hello"]
```

---

### Join

```text
"world hello"
```

Return:

```text
"world hello"
```

---

# Code Explanation

### Step 1

```text
words = split(s)
```

Extract words.

Ignore spaces.

---

### Step 2

```text
reverse(words)
```

Reverse order:

```text
A B C D

↓

D C B A
```

---

### Step 3

```text
join(words," ")
```

Join using one space:

```text
D C B A
```

becomes:

```text
"D C B A"
```

# Approach 2 (Optimal In-place Idea)

## Reverse Entire String Then Reverse Each Word

This is a famous interview technique.

---

### Example

Input:

```text
"the sky is blue"
```

Reverse whole string:

```text
"eulb si yks eht"
```

---

Reverse each word:

```text
blue is sky the
```

Done.

---

# Pseudo Code

```text
function reverseWords(s):

    trim spaces

    reverse entire string


    start = 0

    for each word:

        reverse characters of word


    clean extra spaces

    return s
```

---

# Dry Run

Original:

```text
the sky is blue
```

Reverse all:

```text
eulb si yks eht
```

---

Reverse words:

```text
blue is sky the
```

Answer:

```text
blue is sky the
```

---

### Complexity

```text
Time : O(n)

Space: O(1)
```

if mutable string available.

# Approach 3 : Stack of Words

Push words into stack.

---

Example

```text
the sky is blue
```

Push:

```text
the

sky

is

blue
```

Stack:

```text
top -> blue
```

Pop:

```text
blue

is

sky

the
```

Join:

```text
blue is sky the
```

---

## Pseudo Code

```text
stack=[]

for word in words:

    push(word)


result=""

while stack not empty:

    result += pop()
```

---

### Complexity

```text
Time : O(n)

Space: O(n)
```

# Approach 4 : Two Pointers Without Split

Parse words manually.

---

Idea:

Move:

```text
left -> start of word

right -> end of word
```

Extract:

```text
word
```

Store.

Reverse order at the end.

---

## Pseudo Code

```text
i=0

while i<n:

    skip spaces


    start=i


    while i<n and s[i]!=' ':

         i++


    word=s[start:i]


    add word
```

Reverse list afterwards.

---

### Complexity

```text
Time : O(n)

Space : O(n)
```

Useful when `split()` is unavailable.

---

# Approach 5 : Deque

Instead of:

```text
append at end
```

Insert each word at front.

---

Example

```text
the

deque=[the]


sky

deque=[sky,the]


is

deque=[is,sky,the]


blue

deque=[blue,is,sky,the]
```

Join:

```text
blue is sky the
```

---

## Pseudo Code

```text
deque=[]

for each word:

    pushFront(word)


return join(deque)
```

---

### Complexity

```text
Time : O(n)

Space : O(n)
```

# Why Reverse Whole String Works

Suppose:

```text
the sky is blue
```

Reverse characters:

```text
eulb si yks eht
```

Now every word itself is reversed.

Reverse each word:

```text
blue is sky the
```

The word order becomes reversed automatically.

# Interview Takeaway

There are **two important interview patterns** here:

### Pattern 1

```text
Split

↓

Reverse list

↓

Join
```

Simple and readable.

---

### Pattern 2

```text
Reverse entire string

↓

Reverse each word

↓

Remove extra spaces
```

This is the **in-place string reversal pattern**, a classic interview technique.

## Generic Templates

### Split-Reverse-Join

```text
words = split(s)

```

---

### In-place Reverse

```text
reverse(all)
```

For **LeetCode 151**, the expected interview solution is usually:

* **Split + Reverse + Join** for clarity.
* **Reverse Entire String + Reverse Each Word** when asked for **O(1) extra space**.
