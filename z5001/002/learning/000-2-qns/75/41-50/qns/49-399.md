## 049. LC# 399. Evaluate Division

**Difficulty:** Medium

### Description

You are given equations representing relationships between variables and their values.

For example:

* a / b = 2.0
* b / c = 3.0

You are also given queries. For each query `x / y`, return:

* The result if a path exists.
* `-1.0` if the relationship cannot be determined.

This problem is naturally modeled as a **weighted graph**:

* Edge a→b with weight=value
* Edge b→a with weight=1/value

---

### Example 1

```text
Input:
equations=[["a","b"],["b","c"]]
values=[2.0,3.0]
queries=[["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]

Output:
[6.0,0.5,-1.0,1.0,-1.0]

Explanation:
a/c=a/b*b/c=2*3=6
b/a=1/2=0.5
a/e=>e not present => -1
a/a=1
x/x=>x not present => -1
```

---

### Example 2

```text
Input:
equations=[["a","b"],["b","c"],["bc","cd"]]

queries=[["a","c"],["c","b"],["bc","cd"],["cd","bc"]]

```

## Idea (One Line)

Build a weighted graph and use DFS/BFS to find a path between source and destination while multiplying edge weights.

---

## Pseudocode (DFS)

```text
function calcEquation(equations,values,queries)
    graph=emptyMap()

    for i=0 to length(equations)-1
        a=equations[i][0]
        b=equations[i][1]
        val=values[i]

        graph[a].add(b,val)
        graph[b].add(a,1/val)

    ans=emptyList()

    for each query in queries
        src=query[0]
        dst=query[1]

        if src not in graph or dst not in graph
            add -1.0 to ans
            continue

        if src==dst
            add 1.0 to ans
            continue

        visited=emptySet()

        result=dfs(src,dst,1.0,visited,graph)

        add result to ans

    return ans


function dfs(node,target,product,visited,graph)

    if node==target
        return product

    add node to visited

    for each (next,weight) in graph[node]

        if next not in visited

            ans=dfs(next,target,product*weight,visited,graph)

            if ans!=-1.0
                return ans

    return -1.0
```

---

## Complexity

```text
Build Graph : O(E)
Each Query DFS : O(V+E)
Total : O(E+Q*(V+E))

Space : O(V+E)
```

where

```text
V = number of variables
E = number of equations
Q = number of queries
```

```text

```

| ---- | ------ | -----: | ------: |
| a    | b      |      2 |   1×2=2 |
| b    | c      |      3 |   2×3=6 |
| c    | target |      - |       6 |

```text

```

### Query : b/a

| Node | Next   | Weight |   Product |
| ---- | ------ | -----: | --------: |
| b    | a      |    0.5 | 1×0.5=0.5 |
| a    | target |      - |       0.5 |

Return:

```text
0.5
```

---

## Code Explanation

```text
1. Create graph as adjacency list.
2. For equation a/b=value:
   add a->b with value.
   add b->a with 1/value.
3. For every query:
   If source or destination missing, return -1.
4. If source==destination, return 1.
5. Run DFS from source to destination.
6. Multiply weights while traversing.
7. Once target is reached, return accumulated product.
8. If no path exists, return -1.
```

# Other Patterns

## Pattern 1 : BFS

### Idea

Use BFS and propagate multiplication values level by level.

### Pseudocode

```text
function bfs(src,dst,graph)

    queue=emptyQueue()
    visited=emptySet()

    enqueue(src,1.0)
    add src to visited

    while queue not empty

        node,val=dequeue()

        if node==dst
            return val

        for each (next,weight) in graph[node]

            if next not in visited

                enqueue(next,val*weight)
                add next to visited

    return -1.0
```

---

## Pattern 2 : Union Find With Weights

### Idea

Store parent and ratio to parent while unioning variables.

### Pseudocode

```text
function union(x,y,value)

    rootX,weightX=find(x)
    rootY,weightY=find(y)

    if rootX!=rootY

        parent[rootX]=rootY

        weight[rootX]=value*weightY/weightX


function find(x)

    if parent[x]==x
        return (x,1)

    root,w=find(parent[x])

    weight[x]=weight[x]*w

    parent[x]=root

    return (parent[x],weight[x])
```

## Pattern 3 : Floyd Warshall

### Idea

Precompute ratio between every pair of variables.

### Pseudocode

```text
for each equation a/b=value
    dist[a][b]=value
    dist[b][a]=1/value

for each k
    for each i
        for each j

            if i->k exists and k->j exists

                dist[i][j]=dist[i][k]*dist[k][j]
```

## Comparison of Patterns

| Pattern             | Build    | Query   | Space  | Best Use                   |
| ------------------- | -------- | ------- | ------ | -------------------------- |
| DFS                 | O(E)     | O(V+E)  | O(V+E) | Few queries                |
| BFS                 | O(E)     | O(V+E)  | O(V+E) | Few queries                |
| Union Find Weighted | O(Eα(V)) | O(α(V)) | O(V)   | Many queries               |
| Floyd Warshall      | O(V³)    | O(1)    | O(V²)  | Very many queries, small V |
