## 044. Search in a Binary Search Tree

**Difficulty:** Easy

### Description

You are given the `root` of a **Binary Search Tree (BST)** and an integer `val`.

Find the node in the BST whose value equals `val` and return the subtree rooted with that node.

If such a node does not exist, return `null`.

---

### Example 1

```text
Input:
root=[4,2,7,1,3]
val=2

        4
       / \
      2   7
     / \
    1   3

Output:
[2,1,3]

Explanation:
Start at 4.
2<4, so move to left child.
Found node 2.
Return subtree rooted at 2.

        2
       / \
      1   3
```

### Example 2

```text
Input:
root=[4,2,7,1,3]
val=5

Output:
null

Explanation:
5>4, move right to 7.
5<7, move left.
No node found.
Return null.
```

---

### Constraints

```text
The number of nodes in the tree is in the range [1,5000].
1<=Node.val<=10^7
root is a Binary Search Tree.
1<=val<=10^7
```

---

## Idea (One Liner)

**Use BST property: if val<node.val go left, if val>node.val go right, otherwise return the node.**

---

## Pseudocode (Iterative BST Search)

```text
function searchBST(root,val)
    current=root

    while current!=null
        if current.val==val
            return current

        if val<current.val
            current=current.left
        else
            current=current.right

    return null
```

---

## Complexity

```text
Time Complexity: O(h)
Space Complexity: O(1)
```

where:

```text
h=Height of the BST

Balanced BST -> O(logn)
Skewed BST -> O(n)
```

## Code Explanation

```text
1. Start from root node.
2. Compare val with current node value.
3. If equal, return current node.
4. If val is smaller, move to left subtree.
5. Otherwise move to right subtree.
6. Continue until node is found or current becomes null.
7. If current is null, return null.
```

# Other Patterns

## Pattern 1: Recursive BST Search

### Idea

**Use recursion and BST property to search in left or right subtree.**

### Pseudocode

```text
function searchBST(root,val)
    if root==null
        return null

    if root.val==val
        return root

    if val<root.val
        return searchBST(root.left,val)

    return searchBST(root.right,val)
```

---

## Pattern 2: DFS General Binary Tree Search

### Idea

**Ignore BST property and search every node using DFS.**

### Pseudocode

```text
function searchBST(root,val)
    if root==null
        return null

    if root.val==val
        return root

    leftResult=searchBST(root.left,val)

    if leftResult!=null
        return leftResult

    return searchBST(root.right,val)
```

---

## Pattern 3: BFS Level Order Search

### Idea

**Traverse tree level by level until the value is found.**

### Pseudocode

```text
function searchBST(root,val)
    if root==null
        return null

    queue=emptyQueue()

    enqueue root into queue

    while queue not empty
        node=dequeue queue

        if node.val==val
            return node

        if node.left!=null
            enqueue node.left into queue

        if node.right!=null
            enqueue node.right into queue

    return null
```

---

## Comparison of Patterns

| Pattern              | Uses BST Property | Traversal | Time | Space | Recommended |
| -------------------- | ----------------- | --------- | ---: | ----: | ----------- |
| Iterative BST Search | Yes               | Loop      | O(h) |  O(1) | ⭐⭐⭐⭐⭐       |
| Recursive BST Search | Yes               | DFS       | O(h) |  O(h) | ⭐⭐⭐⭐⭐       |
| DFS General Tree     | No                | DFS       | O(n) |  O(h) | ⭐⭐          |
| BFS Level Order      | No                | BFS       | O(n) |  O(n) | ⭐⭐          |

---

## Interview Preference

```text
1. Iterative BST Search is the most preferred because it uses O(1) extra space.
2. Recursive BST Search is shorter and elegant.
3. DFS and BFS ignoring BST property are not optimal for this problem.
4. The key observation is to use BST ordering:
   left subtree values<root.val
   right subtree values>root.val
```

---

## Key BST Search Rule

```text
if val==node.val
    return node

if val<node.val
    go left

if val>node.val
    go right
```

This rule is the foundation for many BST problems such as Search, Insert, Delete, Floor, Ceil, Lowest Common Ancestor, and Validate BST.
