## 046. Keys and Rooms

**Difficulty:** Medium

### Description

There are `n` rooms numbered from `0` to `n-1`.

Initially, all rooms are locked except room `0`. Your goal is to visit all rooms.

When you enter a room, you may find keys to other rooms. Each key has a number representing another room.

Given `rooms` where `rooms[i]` is a list of keys available in room `i`, return `true` if you can visit all rooms, otherwise return `false`.

---

### Examples

```text
Input: rooms=[[1],[2],[3],[]]
Output: true
Explanation:
Start from room 0.
Room 0 -> key 1
Room 1 -> key 2
Room 2 -> key 3
All rooms are visited.
```

```text
Input: rooms=[[1,3],[3,0,1],[2],[0]]
Output: false
Explanation:
Reachable rooms are 0,1,3.
Room 2 cannot be reached.
```

---

### Constraints

```text
n==rooms.length
2<=n<=1000
0<=rooms[i].length<=1000
1<=sum(rooms[i].length)<=3000
0<=rooms[i][j]<n
All keys in rooms[i] are unique.
```

---

## Idea (One Liner)

**Treat rooms as a graph and perform DFS/BFS from room 0 to mark reachable rooms.**

---

## Pseudocode (DFS)

```text
function canVisitAllRooms(rooms)
    n=length(rooms)
    visited=array(n,false)

    dfs(0,rooms,visited)

    for i=0 to n-1
        if visited[i]==false
            return false

    return true

function dfs(room,rooms,visited)
    visited[room]=true

    for each key in rooms[room]
        if visited[key]==false
            dfs(key,rooms,visited)
```

---

## Complexity

```text
Time Complexity: O(V+E)
V=number of rooms
E=total number of keys

Space Complexity: O(V)
Recursion stack may use O(V)
```

---

## Code Explanation

```text
1. Create visited array initialized with false.
2. Start DFS from room 0 because it is unlocked initially.
3. Mark current room as visited.
4. Traverse all keys present in current room.
5. If a room is not visited, recursively visit it.
6. After DFS finishes, check whether every room is visited.
7. If any room remains unvisited, return false.
8. Otherwise return true.
```

# Other Patterns

## Pattern 1: BFS Using Queue

### Idea (One Liner)

**Start from room 0 and explore rooms level by level using a queue.**

### Pseudocode

```text
function canVisitAllRooms(rooms)
    n=length(rooms)

    visited=array(n,false)
    queue=emptyQueue()

    enqueue 0 into queue
    visited[0]=true

    while queue not empty
        room=dequeue queue

        for each key in rooms[room]
            if visited[key]==false
                visited[key]=true
                enqueue key into queue

    for i=0 to n-1
        if visited[i]==false
            return false

    return true
```

## Pattern 2: Iterative DFS Using Stack

### Idea (One Liner)

**Use an explicit stack instead of recursion to simulate DFS traversal.**

### Pseudocode

```text
function canVisitAllRooms(rooms)
    n=length(rooms)

    visited=array(n,false)
    stack=emptyStack()

    push 0 into stack
    visited[0]=true

    while stack not empty
        room=pop stack

        for each key in rooms[room]
            if visited[key]==false
                visited[key]=true
                push key into stack

    for i=0 to n-1
        if visited[i]==false
            return false

    return true
```

---

## Pattern 3: Count Visited Rooms

### Idea (One Liner)

**Maintain a counter while traversing and stop early when all rooms are visited.**

### Pseudocode

```text
function canVisitAllRooms(rooms)
    n=length(rooms)

    visited=array(n,false)
    queue=emptyQueue()

    visited[0]=true
    count=1

    enqueue 0 into queue

    while queue not empty
        room=dequeue queue

        for each key in rooms[room]
            if visited[key]==false
                visited[key]=true
                count=count+1
                enqueue key into queue

    return count==n
```

## Comparison of Approaches

| Approach      | Traversal     | Extra Space | Recursive | Preferred                   |
| ------------- | ------------- | ----------- | --------- | --------------------------- |
| DFS Recursive | Depth First   | O(V)        | Yes       | ⭐ Most common in interviews |
| DFS Iterative | Depth First   | O(V)        | No        | Avoid recursion limits      |
| BFS Queue     | Breadth First | O(V)        | No        | Easy to understand          |
| Count Visited | BFS/DFS       | O(V)        | Optional  | Early stopping possible     |
