## 043. Find Largest Value in Each Tree Row

**Difficulty:** Medium

### Description

Given the `root` of a binary tree, return an array of the **largest value in each row** of the tree (0-indexed).

---

### Example 1

```text
Input: root=[1,3,2,5,3,null,9]

        1
       / \
      3   2
     / \   \
    5   3   9

Output: [1,3,9]

Explanation:
Level 0 -> [1] -> max=1
Level 1 -> [3,2] -> max=3
Level 2 -> [5,3,9] -> max=9

Answer=[1,3,9]
```

### Example 2

```text
Input: root=[1,2,3]
Output: [1,3]

Explanation:
Level 0 -> [1] -> max=1
Level 1 -> [2,3] -> max=3
```

---

### Constraints

```text
The number of nodes in the tree is in the range [0,10^4].
-2^31<=Node.val<=2^31-1
```

---

## Idea (One Liner)

**Traverse tree level by level using BFS and store the maximum value of each level.**

---

## Pseudocode (BFS Level Order)

```text
function largestValues(root)
    if root==null
        return []

    result=emptyList()
    queue=emptyQueue()

    enqueue root into queue

    while queue not empty
        size=queue.size()
        maxValue=-infinity

        for i=0 to size-1
            node=dequeue queue

            maxValue=max(maxValue,node.val)

            if node.left!=null
                enqueue node.left into queue

            if node.right!=null
                enqueue node.right into queue

        append maxValue into result

    return result
```

---

## Complexity

```text
Time Complexity: O(n)
Space Complexity: O(n)
```

where `n` is the number of nodes.

---

## Dry Run

Example:

```text
Input:

        1
       / \
      3   2
     / \   \
    5   3   9
```

### Level Wise Traversal

| Level | Queue Before | Nodes | Maximum | Result  |
| ----- | ------------ | ----- | ------: | ------- |
| 0     | [1]          | 1     |       1 | [1]     |
| 1     | [3,2]        | 3,2   |       3 | [1,3]   |
| 2     | [5,3,9]      | 5,3,9 |       9 | [1,3,9] |

---

### Detailed Iteration

| Level | Node | maxValue | Queue After Processing |
| ----: | ---: | -------: | ---------------------- |
|     0 |    1 |        1 | [3,2]                  |
|     1 |    3 |        3 | [2,5,3]                |
|     1 |    2 |        3 | [5,3,9]                |
|     2 |    5 |        5 | [3,9]                  |
|     2 |    3 |        5 | [9]                    |
|     2 |    9 |        9 | []                     |

---

### Final Result

```text
Level 0 -> Maximum=1
Level 1 -> Maximum=3
Level 2 -> Maximum=9

Answer=[1,3,9]
```

---

## Code Explanation

```text
1. If root is null, return empty list.
2. Create result list and queue.
3. Insert root into queue.
4. While queue is not empty, process one complete level.
5. Initialize maxValue=-infinity for the current level.
6. Remove every node of the level and update maxValue.
7. Insert left child into queue if it exists.
8. Insert right child into queue if it exists.
9. After completing the level, append maxValue into result.
10. Return result.
```

# Other Patterns

## Pattern 1: DFS With Level Maximum Array

### Idea

**Use DFS and store maximum value for every depth in an array.**

### Pseudocode

```text
function largestValues(root)
    result=emptyList()

    dfs(root,0,result)

    return result


function dfs(node,depth,result)
    if node==null
        return

    if depth==result.size()
        append node.val into result
    else
        result[depth]=max(result[depth],node.val)

    dfs(node.left,depth+1,result)
    dfs(node.right,depth+1,result)
```

---

## Pattern 2: DFS Using HashMap

### Idea

**Store level maximum values in HashMap where key=depth and value=maximum.**

### Pseudocode

```text
function largestValues(root)
    map=emptyMap()

    dfs(root,0,map)

    result=emptyList()

    for level=0 to map.size()-1
        append map[level] into result

    return result


function dfs(node,depth,map)
    if node==null
        return

    if depth not in map
        map[depth]=node.val
    else
        map[depth]=max(map[depth],node.val)

    dfs(node.left,depth+1,map)
    dfs(node.right,depth+1,map)
```

---

## Pattern 3: BFS Using Two Queues

### Idea

**Use separate queues for current level and next level, finding maximum at each level.**

### Pseudocode

```text
function largestValues(root)
    if root==null
        return []

    result=emptyList()

    currentQueue=emptyQueue()
    nextQueue=emptyQueue()

    enqueue root into currentQueue

    while currentQueue not empty
        maxValue=-infinity

        while currentQueue not empty
            node=dequeue currentQueue

            maxValue=max(maxValue,node.val)

            if node.left!=null
                enqueue node.left into nextQueue

            if node.right!=null
                enqueue node.right into nextQueue

        append maxValue into result

        swap currentQueue and nextQueue

    return result
```

---

## Comparison of Patterns

| Pattern                 | Traversal | Extra Structure | Time |  Space | Recommended |
| ----------------------- | --------- | --------------- | ---: | -----: | ----------- |
| BFS Level Order         | Queue     | Single Queue    | O(n) |   O(n) | ⭐⭐⭐⭐⭐       |
| DFS Level Maximum Array | Recursion | Array/List      | O(n) |   O(h) | ⭐⭐⭐⭐⭐       |
| DFS HashMap             | Recursion | HashMap         | O(n) | O(h+k) | ⭐⭐⭐         |
| BFS Two Queues          | Queue     | Two Queues      | O(n) |   O(n) | ⭐⭐⭐         |

where:

```text
n=Number of nodes
h=Height of tree
k=Number of levels
```

---

## Interview Preference

```text
1. BFS Level Order is the most common solution because the problem is level-based.
2. DFS with level maximum array is the most elegant recursive solution.
3. Both BFS and DFS run in O(n) time.
4. BFS is generally preferred in interviews for this problem.
```
