## 045. Delete Node in a BST

**Difficulty:** Medium

### Description

Given a root node reference of a Binary Search Tree (BST) and a key, delete the node with the given key in the BST.

Return the root reference of the BST after deletion.

The BST properties must remain valid after deletion.

---

### Example 1

```text
Input:
root=[5,3,6,2,4,null,7]
key=3

        5
       / \
      3   6
     / \   \
    2   4   7

Output:
[5,4,6,2,null,null,7]

Explanation:

Delete node 3.

Case: Node has two children.

1. Find inorder successor = 4.
2. Replace node 3 with 4.
3. Delete original node 4.

        5
       / \
      4   6
     /     \
    2       7
```

---

### Example 2

```text
Input:
root=[5,3,6,2,4,null,7]
key=0

Output:
[5,3,6,2,4,null,7]

Explanation:
0 is not present.
Return original tree.
```

---

### Example 3

```text
Input:
root=[]
key=0

Output:
[]
```

---

### Constraints

```text
The number of nodes in the tree is in the range [0,10^4].
-10^5<=Node.val<=10^5
Each node has a unique value.
root is a valid BST.
```

---

## Idea (One Liner)

**Search the node using BST property and handle deletion separately for 0 child, 1 child, and 2 children cases.**

---

## Cases to Remember

```text
Case 1: Leaf node
Delete directly.

Case 2: One child
Return the existing child.

Case 3: Two children
Find inorder successor(minimum in right subtree).
Copy successor value.
Delete successor node recursively.
```

---

## Pseudocode (Recursive Using Inorder Successor)

```text
function deleteNode(root,key)
    if root==null
        return null

    if key<root.val
        root.left=deleteNode(root.left,key)

    else if key>root.val
        root.right=deleteNode(root.right,key)

    else
        if root.left==null and root.right==null
            return null

        if root.left==null
            return root.right

        if root.right==null
            return root.left

        successor=findMin(root.right)

        root.val=successor.val

        root.right=deleteNode(root.right,successor.val)

    return root


function findMin(node)
    while node.left!=null
        node=node.left

    return node
```

---

## Complexity

```text
Time Complexity: O(h)
Space Complexity: O(h)
```

where

```text
h=Height of BST

Balanced BST -> O(logn)
Skewed BST -> O(n)
```

## Dry Run

Example:

```text
Input:

        5
       / \
      3   6
     / \   \
    2   4   7

key=3
```

---

### Step 1: Find Node

| Current | Condition | Move   |
| ------: | --------- | ------ |
|       5 | 3<5       | Left   |
|       3 | 3==3      | Delete |

---

### Step 2: Node Has Two Children

```text
        3
       / \
      2   4

Successor=min(right subtree)=4
```

Replace:

```text
3 -> 4

        4
       / \
      2   4
```

Delete original 4 from right subtree:

```text
        4
       /
      2
```

---

### Final Tree

```text
        5
       / \
      4   6
     /     \
    2       7
```

Output:

```text
[5,4,6,2,null,null,7]
```

---

## Code Explanation

```text
1. If root is null, return null.
2. If key<root.val, search in left subtree.
3. If key>root.val, search in right subtree.
4. Otherwise node is found.
5. If node has no children, return null.
6. If node has only right child, return right child.
7. If node has only left child, return left child.
8. If node has two children, find inorder successor.
9. Copy successor value to current node.
10. Delete successor from right subtree.
11. Return root.
```

# Other Patterns

## Pattern 1: Recursive Using Inorder Predecessor

### Idea

**Replace deleted node with maximum node from left subtree.**

### Pseudocode

```text
function deleteNode(root,key)
    if root==null
        return null

    if key<root.val
        root.left=deleteNode(root.left,key)

    else if key>root.val
        root.right=deleteNode(root.right,key)

    else
        if root.left==null
            return root.right

        if root.right==null
            return root.left

        predecessor=findMax(root.left)

        root.val=predecessor.val

        root.left=deleteNode(root.left,predecessor.val)

    return root


function findMax(node)
    while node.right!=null
        node=node.right

    return node
```

---

## Pattern 2: Iterative BST Deletion

### Idea

**Search node iteratively and adjust parent pointers after deletion.**

### Pseudocode

```text
function deleteNode(root,key)
    parent=null
    current=root

    while current!=null and current.val!=key
        parent=current

        if key<current.val
            current=current.left
        else
            current=current.right

    perform deletion according to number of children

    return root
```

---

## Pattern 3: Delete By Merging

### Idea

**Attach left subtree to leftmost node of right subtree and return right subtree.**

### Pseudocode

```text
function deleteNode(root,key)
    if root==null
        return null

    if key<root.val
        root.left=deleteNode(root.left,key)

    else if key>root.val
        root.right=deleteNode(root.right,key)

    else
        if root.left==null
            return root.right

        if root.right==null
            return root.left

        node=root.right

        while node.left!=null
            node=node.left

        node.left=root.left

        return root.right

    return root
```

## Comparison of Patterns

| Pattern                         | Replacement Node      | Time | Space | Recommended |
| ------------------------------- | --------------------- | ---: | ----: | ----------- |
| Recursive + Inorder Successor   | Min of right subtree  | O(h) |  O(h) | ⭐⭐⭐⭐⭐       |
| Recursive + Inorder Predecessor | Max of left subtree   | O(h) |  O(h) | ⭐⭐⭐⭐⭐       |
| Iterative Deletion              | Successor/Predecessor | O(h) |  O(1) | ⭐⭐⭐⭐        |
| Delete By Merging               | Merge subtrees        | O(h) |  O(h) | ⭐⭐⭐         |

---

## Interview Preference

```text
1. Recursive using Inorder Successor is the most common interview solution.
2. Inorder Predecessor solution is equally acceptable.
3. Iterative deletion is harder to code but uses O(1) extra space.
4. Always remember the three deletion cases:
   Zero child -> return null
   One child -> return existing child
   Two children -> replace with successor/predecessor and delete duplicate
```

---

## BST Delete Cheat Sheet

```text
Search:
key<root.val -> go left
key>root.val -> go right

Delete:
0 child -> null
1 child -> return child
2 children ->
    successor=min(right subtree)
    root.val=successor.val
    delete successor
```

This `Search -> Delete -> Successor/Predecessor` pattern is the standard solution used in BST deletion problems.
