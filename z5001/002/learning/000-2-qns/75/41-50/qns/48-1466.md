## 048. LC# 1466. Reorder Routes to Make All Paths Lead to the City Zero

**Difficulty:** Medium

### Description

There are `n` cities numbered from `0` to `n-1` and `n-1` roads such that there is only one path between any two cities.

The roads are directed. `connections[i]=[a,b]` means there is a road from city `a` to city `b`.

You need to reorder the minimum number of roads so that every city can reach city `0`.

Return the minimum number of edges that must be reversed.

---

### Examples

```text
Input:
n=6
connections=[[0,1],[1,3],[2,3],[4,0],[4,5]]

Output:
3

Explanation:
Reverse:
0->1 to 1->0
1->3 to 3->1
4->5 to 5->4

Now every city can reach city 0.
```

```text
Input:
n=5
connections=[[1,0],[1,2],[3,2],[3,4]]

Output:
2

Explanation:
Reverse:
1->2 to 2->1
3->4 to 4->3
```

---

### Constraints

```text
2<=n<=50000
connections.length==n-1
connections[i].length==2
0<=a,b<n
a!=b
The graph forms a tree.
```

---

## Idea (One Liner)

**Convert every directed edge into two undirected edges while storing direction information, then DFS from city 0 and count edges pointing away from city 0.**

---

## Key Observation

```text
Original edge: a->b

Store:
a->b with cost=1
b->a with cost=0

cost=1 means this edge must be reversed if we travel through it from city 0.
cost=0 means edge already points toward city 0.
```

---

## Pseudocode (DFS)

```text
function minReorder(n,connections)
    graph=array of n empty lists

    for each edge in connections
        from=edge[0]
        to=edge[1]

        add(to,1) into graph[from]
        add(from,0) into graph[to]

    visited=array(n,false)

    return dfs(0,graph,visited)

function dfs(city,graph,visited)
    visited[city]=true

    changes=0

    for each(neighbor,cost) in graph[city]
        if visited[neighbor]==false
            changes=changes+cost
            changes=changes+dfs(neighbor,graph,visited)

    return changes
```

## Code Explanation

```text
1. Create adjacency list.
2. For original edge a->b:
   store a->b with cost 1.
   store b->a with cost 0.
3. Start DFS from city 0.
4. Mark current city visited.
5. Traverse all neighbors.
6. If neighbor not visited:
   add cost to answer.
   continue DFS.
7. Sum all reversals required.
8. Return final answer.
```

# Other Patterns

## Pattern 1: BFS With Direction Tracking

### Idea (One Liner)

**Traverse from city 0 using queue and count outgoing edges that need reversal.**

### Pseudocode

```text
function minReorder(n,connections)
    graph=array of n empty lists

    for each edge in connections
        a=edge[0]
        b=edge[1]

        add(b,1) into graph[a]
        add(a,0) into graph[b]

    queue=emptyQueue()
    visited=array(n,false)

    enqueue 0 into queue
    visited[0]=true

    answer=0

    while queue not empty
        city=dequeue queue

        for each(neighbor,cost) in graph[city]
            if visited[neighbor]==false
                visited[neighbor]=true
                answer=answer+cost
                enqueue neighbor into queue

    return answer
```

## Pattern 2: DFS Using Parent Node

### Idea (One Liner)

**Avoid visited array by passing parent in DFS because graph is a tree.**

### Pseudocode

```text
function minReorder(n,connections)
    build graph

    return dfs(0,-1,graph)

function dfs(city,parent,graph)
    answer=0

    for each(neighbor,cost) in graph[city]
        if neighbor!=parent
            answer=answer+cost
            answer=answer+dfs(neighbor,city,graph)

    return answer
```

---

## Pattern 3: Iterative DFS Using Stack

### Idea (One Liner)

**Replace recursion with stack and count reversals during traversal.**

### Pseudocode

```text
function minReorder(n,connections)
    build graph

    stack=emptyStack()
    visited=array(n,false)

    push 0 into stack
    visited[0]=true

    answer=0

    while stack not empty
        city=pop stack

        for each(neighbor,cost) in graph[city]
            if visited[neighbor]==false
                visited[neighbor]=true
                answer=answer+cost
                push neighbor into stack

    return answer
```
