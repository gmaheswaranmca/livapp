## 041. Binary Tree Right Side View

**Difficulty:** Medium

### Description

Given the `root` of a binary tree, imagine yourself standing on the **right side** of it. Return the values of the nodes you can see ordered from top to bottom.

---

### Example 1

```text
Input: root=[1,2,3,null,5,null,4]
Output: [1,3,4]

Explanation:
Level 0 -> [1] -> rightmost=1
Level 1 -> [2,3] -> rightmost=3
Level 2 -> [5,4] -> rightmost=4

Answer=[1,3,4]
```

### Example 2

```text
Input: root=[1,2,3,4]
Output: [1,3,4]

Explanation:
Level 0 -> [1] -> rightmost=1
Level 1 -> [2,3] -> rightmost=3
Level 2 -> [4] -> rightmost=4
```

### Example 3

```text
Input: root=[]
Output: []
```

---

### Constraints

```text
The number of nodes in the tree is in the range [0,100].
-100<=Node.val<=100
```

---

## Idea (One Liner)

**Perform Level Order Traversal (BFS) and store the last node of each level.**

---

## Pseudocode (Level Order Traversal / BFS)

```text
function rightSideView(root)
    if root==null
        return []
    result=emptyList()
    queue=emptyQueue()
    enqueue root into queue
    while queue not empty
        size=queue.size()
        for i=0 to size-1
            node=dequeue queue
            if i==size-1
                append node.val into result
            if node.left!=null
                enqueue node.left into queue
            if node.right!=null
                enqueue node.right into queue
    return result
```

---

## Complexity

```text
Time Complexity: O(n)
Space Complexity: O(n)
```

where `n` is the number of nodes.

---

## Dry Run

Example:

```text
Input:
        1
       / \
      2   3
       \   \
        5   4
```

### Queue Traversal Table

| Level | Queue Before | Nodes Processed | Rightmost | Result  |
| ----- | ------------ | --------------- | --------- | ------- |
| 0     | [1]          | 1               | 1         | [1]     |
| 1     | [2,3]        | 2,3             | 3         | [1,3]   |
| 2     | [5,4]        | 5,4             | 4         | [1,3,4] |

---

### Detailed Iteration

| Step | Node |  i | size | i==size-1? | Action | Result  |
| ---- | ---: | -: | ---: | ---------- | ------ | ------- |
| 1    |    1 |  0 |    1 | Yes        | Add 1  | [1]     |
| 2    |    2 |  0 |    2 | No         | Skip   | [1]     |
| 3    |    3 |  1 |    2 | Yes        | Add 3  | [1,3]   |
| 4    |    5 |  0 |    2 | No         | Skip   | [1,3]   |
| 5    |    4 |  1 |    2 | Yes        | Add 4  | [1,3,4] |

---

## Code Explanation

```text
1. If root is null, return empty list.
2. Create result list and queue.
3. Insert root into queue.
4. While queue is not empty, get current level size.
5. Traverse all nodes of the current level.
6. When processing the last node of the level(i==size-1), add its value to result.
7. Push left child into queue if it exists.
8. Push right child into queue if it exists.
9. Continue until queue becomes empty.
10. Return result.
```

# Other Patterns

## Pattern 1: DFS Right First (Recommended DFS)

### Idea

**Visit Right subtree first. The first node visited at every depth becomes the answer.**

### Pseudocode

```text
function rightSideView(root)
    result=emptyList()

    dfs(root,0,result)

    return result


function dfs(node,depth,result)
    if node==null
        return

    if depth==result.size()
        append node.val into result

    dfs(node.right,depth+1,result)
    dfs(node.left,depth+1,result)
```

### Complexity

```text
Time Complexity: O(n)
Space Complexity: O(h)
```

where `h` is tree height.

---

## Pattern 2: BFS Right To Left

### Idea

**Traverse each level from right to left and take the first node.**

### Pseudocode

```text
function rightSideView(root)
    if root==null
        return []

    result=emptyList()
    queue=emptyQueue()

    enqueue root into queue

    while queue not empty
        size=queue.size()

        for i=0 to size-1
            node=dequeue queue

            if i==0
                append node.val into result

            if node.right!=null
                enqueue node.right into queue

            if node.left!=null
                enqueue node.left into queue

    return result
```

---

## Pattern 3: DFS Left First + Overwrite

### Idea

**Traverse Left then Right and keep updating value at the same depth. The last visited node becomes the rightmost node.**

### Pseudocode

```text
function rightSideView(root)
    result=emptyList()

    dfs(root,0,result)

    return result


function dfs(node,depth,result)
    if node==null
        return

    if depth==result.size()
        append node.val into result
    else
        result[depth]=node.val

    dfs(node.left,depth+1,result)
    dfs(node.right,depth+1,result)
```

---

## Comparison of Patterns

| Pattern                    | Traversal | Selection Rule      | Time | Space | Recommended |
| -------------------------- | --------- | ------------------- | ---: | ----: | ----------- |
| BFS Level Order            | Queue     | Last node of level  | O(n) |  O(n) | ⭐⭐⭐⭐⭐       |
| DFS Right First            | Recursion | First node at depth | O(n) |  O(h) | ⭐⭐⭐⭐⭐       |
| BFS Right→Left             | Queue     | First node of level | O(n) |  O(n) | ⭐⭐⭐⭐        |
| DFS Left First + Overwrite | Recursion | Overwrite at depth  | O(n) |  O(h) | ⭐⭐⭐         |

---

### Interview Preference

```text
1. BFS Level Order -> Most intuitive and easiest to explain.
2. DFS Right First -> Most elegant recursive solution.
3. Both BFS and DFS are accepted O(n) solutions in interviews.
```
