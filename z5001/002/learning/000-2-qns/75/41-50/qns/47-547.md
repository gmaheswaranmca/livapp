## 047. Number of Provinces

**Difficulty:** Medium

### Description

There are `n` cities. Some cities are directly connected, while some are not.

If city `a` is connected to city `b`, and city `b` is connected to city `c`, then city `a` is indirectly connected to city `c`.

A **province** is a group of directly or indirectly connected cities and no other cities outside the group.

You are given an `n x n` matrix `isConnected` where:

* `isConnected[i][j]=1` means city `i` and city `j` are directly connected.
* `isConnected[i][j]=0` means they are not directly connected.

Return the total number of provinces.

---

### Examples

```text
Input: isConnected=[[1,1,0],[1,1,0],[0,0,1]]
Output: 2
Explanation:
Cities 0 and 1 belong to the same province.
City 2 forms another province.
Hence total provinces=2.
```

```text
Input: isConnected=[[1,0,0],[0,1,0],[0,0,1]]
Output: 3
Explanation:
No cities are connected.
Each city forms an individual province.
```

---

### Constraints

```text
1<=n<=200
n==isConnected.length
n==isConnected[i].length
isConnected[i][j] is 0 or 1
isConnected[i][i]==1
isConnected[i][j]==isConnected[j][i]
```

---

## Idea (One Liner)

**Count connected components using DFS on the adjacency matrix.**

---

## Pseudocode (DFS)

```text
function findCircleNum(isConnected)
    n=length(isConnected)
    visited=array(n,false)
    provinces=0

    for city=0 to n-1
        if visited[city]==false
            provinces=provinces+1
            dfs(city,isConnected,visited,n)

    return provinces

function dfs(city,isConnected,visited,n)
    visited[city]=true

    for neighbor=0 to n-1
        if isConnected[city][neighbor]==1 and visited[neighbor]==false
            dfs(neighbor,isConnected,visited,n)
```

---

## Complexity

```text
Time Complexity: O(n^2)

Reason:
For each city, we scan all n neighbors from adjacency matrix.

Space Complexity: O(n)

Visited array: O(n)
Recursion stack: O(n)
```

| Step | City | Action                     | Provinces | Visited |
| ---: | ---: | -------------------------- | --------: | ------- |
|    1 |    0 | Not visited, provinces++   |         1 | [F,F,F] |
|    2 |    0 | DFS visit 0                |         1 | [T,F,F] |
|    3 | 0->1 | Connected, DFS visit 1     |         1 | [T,T,F] |
|    4 |    1 | Neighbor 0 already visited |         1 | [T,T,F] |
|    5 |    2 | Not visited, provinces++   |         2 | [T,T,F] |
|    6 |    2 | DFS visit 2                |         2 | [T,T,T] |

Final:

```text
visited=[T,T,T]
provinces=2

Return 2
```

---

## Code Explanation

```text
1. Create visited array of size n initialized to false.
2. Initialize provinces=0.
3. Traverse every city from 0 to n-1.
4. If a city is not visited, a new province is found.
5. Increment provinces.
6. Start DFS from that city.
7. DFS marks all directly and indirectly connected cities.
8. Continue until all cities are processed.
9. Return provinces.
```

# Other Patterns

## Pattern 1: BFS

### Idea (One Liner)

**Use queue to traverse all cities in one province level by level.**

### Pseudocode

```text
function findCircleNum(isConnected)
    n=length(isConnected)

    visited=array(n,false)
    provinces=0

    for city=0 to n-1
        if visited[city]==false
            provinces=provinces+1

            queue=emptyQueue()
            enqueue city into queue
            visited[city]=true

            while queue not empty
                current=dequeue queue

                for neighbor=0 to n-1
                    if isConnected[current][neighbor]==1 and visited[neighbor]==false
                        visited[neighbor]=true
                        enqueue neighbor into queue

    return provinces
```

## Pattern 2: Iterative DFS Using Stack

### Idea (One Liner)

**Replace recursion with an explicit stack.**

### Pseudocode

```text
function findCircleNum(isConnected)
    n=length(isConnected)

    visited=array(n,false)
    provinces=0

    for city=0 to n-1
        if visited[city]==false
            provinces=provinces+1

            stack=emptyStack()
            push city into stack

            while stack not empty
                current=pop stack

                if visited[current]==false
                    visited[current]=true

                    for neighbor=0 to n-1
                        if isConnected[current][neighbor]==1 and visited[neighbor]==false
                            push neighbor into stack

    return provinces
```

---

## Pattern 3: Union Find (Disjoint Set Union)

### Idea (One Liner)

**Merge connected cities into sets and count remaining parents.**

### Pseudocode

```text
function findCircleNum(isConnected)
    n=length(isConnected)

    parent=array(n)

    for i=0 to n-1
        parent[i]=i

    provinces=n

    for i=0 to n-1
        for j=i+1 to n-1
            if isConnected[i][j]==1
                if union(i,j,parent)
                    provinces=provinces-1

    return provinces

function find(x,parent)
    if parent[x]!=x
        parent[x]=find(parent[x],parent)
    return parent[x]

function union(a,b,parent)
    pa=find(a,parent)
    pb=find(b,parent)

    if pa==pb
        return false

    parent[pa]=pb
    return true
```

# Comparison of Approaches

| Approach      | Time       | Space | Recursive | Notes                         |
| ------------- | ---------- | ----- | --------- | ----------------------------- |
| DFS Recursive | O(n²)      | O(n)  | Yes       | ⭐ Most common                 |
| DFS Iterative | O(n²)      | O(n)  | No        | Avoid recursion depth         |
| BFS           | O(n²)      | O(n)  | No        | Easy traversal                |
| Union Find    | O(n²×α(n)) | O(n)  | No        | Good for dynamic connectivity |
