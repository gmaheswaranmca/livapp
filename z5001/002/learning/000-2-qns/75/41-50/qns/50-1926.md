## 050. Nearest Exit from Entrance in Maze

**Difficulty:** Medium

### Description

You are given an `m x n` maze represented by:

* `'.'` → Empty cell
* `'+'` → Wall

You are also given an entrance cell `[row,col]`.

Return the minimum number of steps required to reach the **nearest exit**.

An exit is:

* An empty cell on the border of the maze.
* The entrance itself is **NOT** considered an exit.

If no exit exists, return `-1`.

---

### Example 1

```text
Input:
maze=[
["+","+",".","+"],
[".",".",".","+"],
["+","+","+","."]]

entrance=[1,2]

Output:
1

Explanation:
From (1,2), move to (0,2).
(0,2) is on border and is not entrance.
Distance=1.
```

---

### Example 2

```text
Input:
maze=[
["+","+","+"],
[".",".","."],
["+","+","+"]]

entrance=[1,0]

Output:
2

Explanation:
(1,2) is the nearest exit.

Path:
(1,0)->(1,1)->(1,2)

Distance=2.
```

---

### Example 3

```text
Input:
maze=[
[".","+"]]

entrance=[0,0]

Output:
-1

Explanation:
Entrance is on border but cannot be counted as exit.
No other exit exists.
```

---

### Constraints

```text
m==maze.length
n==maze[i].length
1<=m,n<=100
maze[i][j] is '.' or '+'
entrance.length==2
0<=entranceRow<m
0<=entranceCol<n
entrance is always '.'
```

---

## Idea (One Line)

Use BFS from entrance because BFS always finds the shortest path in an unweighted grid.

---

## Pseudocode (BFS)

```text
function nearestExit(maze,entrance)

    rows=length(maze)
    cols=length(maze[0])

    queue=emptyQueue()

    enqueue(entranceRow,entranceCol,0)

    maze[entranceRow][entranceCol]='+'

    directions=[[-1,0],[1,0],[0,-1],[0,1]]

    while queue not empty

        r,c,steps=dequeue()

        for each (dr,dc) in directions

            nr=r+dr
            nc=c+dc

            if nr<0 or nr>=rows or nc<0 or nc>=cols
                continue

            if maze[nr][nc]=='+'
                continue

            if nr==0 or nr==rows-1 or nc==0 or nc==cols-1
                return steps+1

            enqueue(nr,nc,steps+1)

            maze[nr][nc]='+'

    return -1
```

---

## Complexity

```text
Time:O(m*n)

Space:O(m*n)
```

where

```text
m=number of rows
n=number of columns
```

### BFS Traversal

| Queue Before | Pop     | Neighbour   | Action     |
| ------------ | ------- | ----------- | ---------- |
| [(1,2,0)]    | (1,2,0) | (0,2)       | Exit found |
| -            | -       | Border cell | Return 1   |

| Step | Queue     | Current | Next Cell | Exit? |
| ---- | --------- | ------- | --------- | ----- |
| 0    | [(1,2,0)] | (1,2)   | (0,2)     | Yes   |
| 1    | Return    | -       | -         | 1     |

## Code Explanation

```text
1. Put entrance into queue with distance 0.
2. Mark entrance visited by changing '.' to '+'.
3. Pop one cell from queue.
4. Explore four directions:
   up=(-1,0)
   down=(1,0)
   left=(0,-1)
   right=(0,1)
5. Ignore cells outside maze.
6. Ignore walls and visited cells.
7. If neighbour is on border, return distance+1.
8. Otherwise push neighbour into queue.
9. Continue until queue becomes empty.
10. If no exit found, return -1.
```

---

# Why BFS?

```text
BFS explores nodes level by level.

Level 0 -> distance 0
Level 1 -> distance 1
Level 2 -> distance 2

First exit reached
=
Nearest exit.
```

This is exactly a **Shortest Path in Unweighted Graph** problem.

# Other Patterns

## Pattern 1 : BFS With Separate Visited Array

### Idea

Keep visited[][] instead of modifying maze.

### Pseudocode

```text
function bfsVisited(maze,entrance)

    visited=2D false array

    enqueue(entranceRow,entranceCol,0)

    visited[entranceRow][entranceCol]=true

    while queue not empty

        r,c,d=dequeue()

        for each direction

            nr=r+dr
            nc=c+dc

            if valid and not visited[nr][nc] and maze[nr][nc]=='.'

                if isBorder(nr,nc) and not entrance
                    return d+1

                visited[nr][nc]=true

                enqueue(nr,nc,d+1)

    return -1
```

---

## Pattern 2 : BFS Level Order

### Idea

Store only coordinates and increment distance after each level.

### Pseudocode

```text
function bfsLevel(maze,entrance)

    queue=emptyQueue()

    enqueue(entrance)

    steps=0

    while queue not empty

        size=queue.size()

        repeat size times

            r,c=dequeue()

            if isExit(r,c) and not entrance
                return steps

            explore neighbours

        steps=steps+1

    return -1
```

---

## Pattern 3 : DFS Backtracking

### Idea

Explore all paths recursively and keep minimum distance.

### Pseudocode

```text
function dfs(r,c,dist)

    if out of bounds
        return

    if wall
        return

    if isExit(r,c)
        answer=min(answer,dist)
        return

    mark visited

    dfs(r-1,c,dist+1)
    dfs(r+1,c,dist+1)
    dfs(r,c-1,dist+1)
    dfs(r,c+1,dist+1)

    unmark visited
```

# Pattern Comparison

| Pattern               |           Time |  Space | Shortest Path | Recommended |
| --------------------- | -------------: | -----: | ------------- | ----------- |
| BFS(In-place visited) |         O(m*n) | O(m*n) | Yes           | ⭐⭐⭐⭐⭐       |
| BFS(visited[][])      |         O(m*n) | O(m*n) | Yes           | ⭐⭐⭐⭐        |
| BFS(Level Order)      |         O(m*n) | O(m*n) | Yes           | ⭐⭐⭐⭐        |
| DFS Backtracking      |     O(4^(m*n)) | O(m*n) | No guarantee  | ❌           |
| Dijkstra              | O(m*nlog(m*n)) | O(m*n) | Yes           | Overkill    |
