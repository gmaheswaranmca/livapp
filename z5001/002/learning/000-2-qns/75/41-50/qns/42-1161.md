## 042. Maximum Level Sum of a Binary Tree

**Difficulty:** Medium

### Description

Given the `root` of a binary tree, the **level of its root is 1**, its children are level 2, and so on.

Return the **smallest level x** such that the sum of all the values of nodes at level `x` is maximum.

---

### Example 1

```text
Input: root=[1,7,0,7,-8,null,null]

        1
       / \
      7   0
     / \
    7  -8

Output: 2

Explanation:
Level 1 sum=1
Level 2 sum=7+0=7
Level 3 sum=7+(-8)=-1

Maximum sum is 7 at level 2.
```

### Example 2

```text
Input: root=[989,null,10250,98693,-89388,null,null,null,-32127]
Output: 2

Explanation:
Level 1 sum=989
Level 2 sum=10250
Level 3 sum=9305

Maximum sum occurs at level 2.
```

---

### Constraints

```text
The number of nodes in the tree is in the range [1,10^4].
-10^5<=Node.val<=10^5
```

---

## Idea (One Liner)

**Traverse tree level by level using BFS and keep track of the level having maximum sum.**

---

## Pseudocode (BFS Level Order)

```text
function maxLevelSum(root)
    queue=emptyQueue()
    enqueue root into queue

    level=1
    maxSum=-infinity
    answer=1

    while queue not empty
        size=queue.size()
        currentSum=0

        for i=0 to size-1
            node=dequeue queue

            currentSum=currentSum+node.val

            if node.left!=null
                enqueue node.left into queue

            if node.right!=null
                enqueue node.right into queue

        if currentSum>maxSum
            maxSum=currentSum
            answer=level

        level=level+1

    return answer
```

---

## Complexity

```text
Time Complexity: O(n)
Space Complexity: O(n)
```

where `n` is the number of nodes.

---

## Dry Run

Example:

```text
Input:

        1
       / \
      7   0
     / \
    7  -8
```

### Level Wise Traversal

| Level | Queue Before | Nodes | Level Sum | Max Sum | Answer |
| ----- | ------------ | ----- | --------: | ------: | -----: |
| 1     | [1]          | 1     |         1 |       1 |      1 |
| 2     | [7,0]        | 7,0   |         7 |       7 |      2 |
| 3     | [7,-8]       | 7,-8  |        -1 |       7 |      2 |

---

### Detailed Iteration

| Level | Node | currentSum | Queue After Processing |
| ----: | ---: | ---------: | ---------------------- |
|     1 |    1 |          1 | [7,0]                  |
|     2 |    7 |          7 | [0,7,-8]               |
|     2 |    0 |          7 | [7,-8]                 |
|     3 |    7 |          7 | [-8]                   |
|     3 |   -8 |         -1 | []                     |

---

### Final Result

```text
Level 1 -> Sum=1
Level 2 -> Sum=7
Level 3 -> Sum=-1

Maximum Sum=7
Answer=2
```

---

## Code Explanation

```text
1. Create a queue and insert root.
2. Initialize level=1.
3. Initialize maxSum=-infinity and answer=1.
4. While queue is not empty, process one complete level.
5. Calculate currentSum by adding all node values in the current level.
6. Insert left and right children into queue.
7. If currentSum>maxSum, update maxSum and answer.
8. Increment level after finishing the current level.
9. Continue until queue becomes empty.
10. Return answer.
```

# Other Patterns

## Pattern 1: DFS With Level Sums Array

### Idea

**Store the sum of every level using DFS traversal, then find the maximum.**

### Pseudocode

```text
function maxLevelSum(root)
    sums=emptyList()

    dfs(root,0,sums)

    maxSum=sums[0]
    answer=1

    for i=1 to sums.size()-1
        if sums[i]>maxSum
            maxSum=sums[i]
            answer=i+1

    return answer


function dfs(node,level,sums)
    if node==null
        return

    if level==sums.size()
        append 0 into sums

    sums[level]=sums[level]+node.val

    dfs(node.left,level+1,sums)
    dfs(node.right,level+1,sums)
```

---

## Pattern 2: DFS Using HashMap

### Idea

**Store level sums in a HashMap where key=level and value=sum of nodes at that level.**

### Pseudocode

```text
function maxLevelSum(root)
    map=emptyMap()

    dfs(root,1,map)

    maxSum=-infinity
    answer=1

    for each level in sortedKeys(map)
        if map[level]>maxSum
            maxSum=map[level]
            answer=level

    return answer


function dfs(node,level,map)
    if node==null
        return

    map[level]=map.get(level,0)+node.val

    dfs(node.left,level+1,map)
    dfs(node.right,level+1,map)
```

---

## Pattern 3: BFS Using Two Queues

### Idea

**Use one queue for current level and another queue for next level.**

### Pseudocode

```text
function maxLevelSum(root)
    currentQueue=emptyQueue()
    nextQueue=emptyQueue()

    enqueue root into currentQueue

    level=1
    maxSum=-infinity
    answer=1

    while currentQueue not empty
        currentSum=0

        while currentQueue not empty
            node=dequeue currentQueue

            currentSum=currentSum+node.val

            if node.left!=null
                enqueue node.left into nextQueue

            if node.right!=null
                enqueue node.right into nextQueue

        if currentSum>maxSum
            maxSum=currentSum
            answer=level

        swap currentQueue and nextQueue

        level=level+1

    return answer
```

## Comparison of Patterns

| Pattern         | Traversal | Extra Structure | Time |  Space | Recommended |
| --------------- | --------- | --------------- | ---: | -----: | ----------- |
| BFS Level Order | Queue     | Single Queue    | O(n) |   O(n) | ⭐⭐⭐⭐⭐       |
| DFS Level Sums  | Recursion | Array/List      | O(n) | O(h+k) | ⭐⭐⭐⭐⭐       |
| DFS HashMap     | Recursion | HashMap         | O(n) | O(h+k) | ⭐⭐⭐         |
| BFS Two Queues  | Queue     | Two Queues      | O(n) |   O(n) | ⭐⭐⭐         |

where:

```text
n = Number of nodes
h = Height of tree
k = Number of levels
```

---

## Interview Preference

```text
1. BFS Level Order -> Most common and easiest to explain.
2. DFS with Level Sums Array -> Elegant recursive solution.
3. BFS is generally the first choice because the problem is level-based.
4. Both BFS and DFS achieve O(n) time complexity.
```
