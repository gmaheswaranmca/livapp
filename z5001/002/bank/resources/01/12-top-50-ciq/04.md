*31. Explain the difference between pass by value and reference*  
- Pass by value: A copy of the variable is passed. Changes inside the function don’t affect the original variable  
- Pass by reference: The actual variable is passed. Changes inside the function affect the original variable  
- Java uses pass-by-value. For objects, the reference is passed by value, so object data can be changed, but the reference itself can't be reassigned  
- C++ supports both based on function signature

*32. What is memoization vs. tabulation*  
- Memoization: Top-down. Use recursion with caching to store computed subproblems  
- Tabulation: Bottom-up. Solve subproblems iteratively and store results in a table  
- Example: Fibonacci  
  - Memoization: fib(n) = fib(n-1) + fib(n-2) with cache  
  - Tabulation: Fill array from fib(0) to fib(n)

*33. Solve the knapsack problem*  
- 0/1 Knapsack: Given weights and values, maximize value for a given capacity  
- Use dynamic programming  
```python
def knapsack(wt, val, W):
    n = len(wt)
    dp = [[0]*(W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for w in range(W+1):
            if wt[i-1] <= w:
                  dp[i][w] = max(val[i-1]+dp[i-1][w-wt[i-1]], dp[i-1][w])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][W]
```

*34. Find duplicate numbers in an array*  
- Use a set to track seen elements  
```python
def find_duplicates(nums):
    seen = set()
    dupes = set()
    for num in nums:
        if num in seen:
            dupes.add(num)
        else:
            seen.add(num)
    return list(dupes)
```

*35. What are function closures in Python/JavaScript*  
- A closure is a function that remembers variables from its outer scope  
```python
def outer(x):
    def inner(y):
        return x + y
    return inner

add5 = outer(5)
print(add5(3))  # Output: 8
```

*36. How does garbage collection work in Java*  
- Java automatically reclaims memory using garbage collection  
- JVM detects unreachable objects and frees memory  
- Uses generational GC: Young, Old, and Permanent generations  
- Algorithms: Mark and Sweep, G1, CMS  
- You can request GC via System.gc(), but execution is not guaranteed

*37. What are lambda functions*  
- Anonymous functions used for short operations  
- Python: `lambda x: x + 2`  
- Java: Introduced in Java 8  
```java
List<Integer> list = Arrays.asList(1, 2, 3);
list.forEach(x -> System.out.println(x));
```

*38. Explain OOPs concepts: Inheritance, Polymorphism, Encapsulation, Abstraction*  
- Inheritance: One class can use properties of another  
- Polymorphism: One function behaves differently in different contexts  
- Encapsulation: Hide internal data, access via methods  
- Abstraction: Hide implementation details, expose interface

*39. What is multithreading vs. multiprocessing*  
- Multithreading: Multiple threads share memory in one process  
- Multiprocessing: Each process has its own memory space  
- Multithreading is lighter, but less isolated  
- Python: `threading`, `multiprocessing`  
- Java: Use `Thread` or `Runnable`

*40. Difference between process and thread*  
- Process: Independent, has its own memory  
- Thread: Runs in a process, shares memory with other threads  
- Threads are lighter and faster, but less safe due to shared state  
- Processes are more isolated but heavier to manage
