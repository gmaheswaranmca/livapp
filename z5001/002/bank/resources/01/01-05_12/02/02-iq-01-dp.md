*🔥 Dynamic Programming — Interview Questions with Answers 🧠💻*

*1️⃣ What is Dynamic Programming?*

Answer:
Dynamic Programming (DP) is a technique used to solve problems by breaking them into smaller subproblems and storing their results to avoid repeated computation.

Example:
In Fibonacci, instead of recalculating fib(3) multiple times, we store it once and reuse it.

*2️⃣ What are the key properties of DP?*

Answer:
1. Overlapping Subproblems
Same subproblems are solved multiple times.
Example: Fibonacci recursion repeats calculations.

2. Optimal Substructure
The final solution is built from optimal solutions of smaller problems.
Example: Shortest path problems.

*3️⃣ What is the difference between Recursion and Dynamic Programming?*

Answer:
Recursion solves problems by calling itself, but may recompute the same values many times.
Dynamic Programming improves recursion by storing results (memoization).

Example:
- Recursive Fibonacci → slow
- DP Fibonacci → efficient

*4️⃣ What is Memoization?*

Answer:
Memoization is a top-down DP approach where results of function calls are stored.

Example:
If fib(5) is calculated, store it so next time it's reused instead of recalculating.

*5️⃣ What is Tabulation?*

Answer:
Tabulation is a bottom-up approach where solutions are built step by step using iteration.

Example:
Start from fib(0), fib(1) → build up to fib(n).

*6️⃣ What is the difference between Memoization and Tabulation?*

Answer:
Memoization uses recursion and stores results, while tabulation uses iteration and builds solutions from base cases.

Example:
- Memoization → recursive + cache
- Tabulation → loop + table

*7️⃣ How do you identify a DP problem?*

Answer:
Look for:
- Repeated subproblems
- Optimization (min/max)
- Recursive structure

Example:
“Find minimum cost”, “maximum profit” → usually DP.

*8️⃣ What is DP state?*

Answer:
DP state represents a subproblem definition.

Example:
In climbing stairs →
dp = number of ways to reach step i[i]

*9️⃣ What is transition in DP?*

Answer:
Transition defines how current state depends on previous states.

Example:
dp = dp[i-1] + dp[i-2][i]

*🔟 What are common DP problems?*

Answer:
- Fibonacci
- Knapsack
- Longest Common Subsequence
- Coin Change
- Climbing Stairs

*1️⃣1️⃣ What is space optimization in DP?*

Answer:
Reducing memory usage by storing only necessary values.

Example:
Instead of storing entire array in Fibonacci, store only last two values.

*⭐ Bonus Interview Question*

Q: Is every recursive problem a DP problem?

Answer:
No. Only problems with overlapping subproblems and optimal substructure can be solved using DP.

*🎯 Interview Tip*

When solving DP:
1. Define state
2. Write recurrence relation
3. Identify base case
4. Choose memoization or tabulation
