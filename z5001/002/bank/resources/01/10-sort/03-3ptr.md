📌 *Three Pointers Technique!* 🧠🧵  

Used to solve complex problems efficiently on arrays & strings.

🔺 *1. Classic Three Pointer – Merge Two Sorted Arrays*  
*Use case:* Comparing & merging  
📌 *Example:* Merge two sorted arrays into one  
🧠 *Idea:*  
- Pointer A for array1  
- Pointer B for array2  
- Pointer C for merged array  
💡 Efficient merging in O(n + m) time

🔺 *2. Three Sum Problem*  
*Use case:* Finding triplets that meet a condition  
📌 *Example:* Find all triplets with sum = 0  
🧠 *Idea:*  
- Sort the array  
- Fix one pointer (i)  
- Use left & right pointers to find matching sum  
💡 Time: O(n²) vs O(n³) brute-force

🔺 *3. Dutch National Flag Algorithm*  
*Use case:* Sorting 0s, 1s, 2s  
📌 *Example:* Sort array of 0, 1, 2 in one pass  
🧠 *Idea:*  
- Low, Mid, High pointers  
- Swap based on value at mid  
💡 Time: O(n), Space: O(1)

🧠 *When to Use:*  
✅ Searching combinations  
✅ Partitioning arrays  
✅ Solving in-place  
✅ Optimizing nested loops
