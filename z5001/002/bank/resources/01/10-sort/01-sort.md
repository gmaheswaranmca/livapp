✅ *Sorting Algorithms!* 🔢🧠  

Here are 5 important sorting algorithms every programmer must know — with logic, time complexity, and pros/cons!

1️⃣ *Bubble Sort*  
*🧠 Logic:* Repeatedly compares adjacent elements and swaps if needed.  
*⏱️ Time:*  
• Best: O(n)  
• Avg/Worst: O(n²)  
*💡 Use:* For learning; not efficient for large data.

2️⃣ *Selection Sort*  
*🧠 Logic:* Finds the smallest element and places it at the beginning.  
*⏱️ Time:* O(n²) for all cases  
*💡 Use:* Easy to implement but slow for big lists.

3️⃣ *Insertion Sort*  
*🧠 Logic:* Takes elements one by one and inserts them into their correct position.  
*⏱️ Time:*  
• Best: O(n)  
• Avg/Worst: O(n²)  
*💡 Use:* Great for small or nearly sorted data.

4️⃣ *Merge Sort*  
*🧠 Logic:* Divide the array into halves, sort them, then merge.  
*⏱️ Time:* O(n log n)  
*💡 Use:* Fast and consistent; uses extra memory.

5️⃣ *Quick Sort*  
*🧠 Logic:* Select a pivot, partition the array, then sort partitions recursively.  
*⏱️ Time:*  
• Best/Avg: O(n log n)  
• Worst: O(n²)  
*💡 Use:* Very fast in practice; needs careful pivot choice.
