✅ *Coding Interview Cheat Sheet (Quick Revision)* 💡💻

🔹 *Big-O Complexity (Must Know!)*  
• Array Search – O(n)  
• Binary Search – O(log n)  
• HashMap Access – O(1)  
• Sorting (Merge/Quick) – O(n log n)  
• Nested Loops – O(n²)

🔹 *Data Structures to Master*  
• Arrays & Strings  
• Linked Lists (Singly, Doubly)  
• Stacks & Queues  
• Hash Tables  
• Trees (BST, Trie)  
• Graphs (Adjacency List/Matrix)  
• Heaps/Priority Queues

🔹 *Common Algorithm Patterns*  
• Two Pointers  
• Sliding Window  
• Fast & Slow Pointer  
• Binary Search  
• Recursion + Backtracking  
• Dynamic Programming  
• Graph Traversal (DFS/BFS)

🔹 *Tricky Concepts*  
• Bit Manipulation  
• Prefix Sum  
• Kadane’s Algorithm  
• Floyd’s Cycle Detection  
• Topological Sort  
• Union Find (Disjoint Set)

🔹 *Behavioral Quick Tips*  
• Use STAR method (Situation, Task, Action, Result)  
• Be honest about weaknesses  
• Practice common scenarios

🔹 *Interview Mindset*  
• Think out loud  
• Optimize step-by-step  
• Communicate clearly  
• Don’t panic — stay calm!
