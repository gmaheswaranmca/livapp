🔄 *Two Pointers Technique* 🧠🧩  

Used for solving problems on *arrays* or *strings*, especially when dealing with *sorted data*, *palindromes*, or *pairs*.

📌 *When to Use:*  
- Searching for pairs (e.g., sum = target)  
- Removing duplicates  
- Reversing strings/arrays  
- Checking for palindromes

✅ *Common Patterns:*  

1️⃣ *Start + End Pointer:*  
```python
arr = [1, 2, 3, 4, 5]
start, end = 0, len(arr) - 1

while start < end:
    # do something with arr[start] and arr[end]
    start += 1
    end -= 1
```

2️⃣ *Fast + Slow Pointer (Floyd's Cycle Detection):*  
```python
slow, fast = head, head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```
💡 Used in linked lists to detect cycles

🧠 *Why It’s Useful:*  
- Reduces time complexity from O(n²) to O(n)  
- Saves space (no extra arrays needed)  
- Easy to implement once you spot the pattern
