*🧠 1️⃣ Fibonacci (DP Optimized)*

*Problem:*
Find the nth Fibonacci number.

*Idea:*
Store previous results to avoid repeated calculations.

def fib(n):
    if n <= 1:
        return n

    dp = [0] * (n + 1)
    dp[1] = 1

    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]

    return dp[n]

👉 Time Complexity: O(n)
👉 Key Concept: 1D DP

*🧠 2️⃣ Climbing Stairs*

*Problem:*
You can take 1 or 2 steps. Find total ways to reach step n.

def climb_stairs(n):
    if n <= 2:
        return n

    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2

    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]

    return dp[n]

👉 Same pattern as Fibonacci

*🧠 3️⃣ Coin Change (Minimum Coins)*

*Problem:*
Find minimum coins needed to make a given amount.

def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0

    for i in range(1, amount + 1):
        for coin in coins:
            if i - coin >= 0:
                dp[i] = min(dp[i], dp[i - coin] + 1)

    return dp[amount] if dp[amount]!= float('inf') else -1

👉 Key Concept: Optimization DP

*🧠 4️⃣ Longest Common Subsequence (LCS)*

*Problem:*
Find longest common subsequence between two strings.

def lcs(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0]*(n+1) for _ in range(m+1)]

    for i in range(1, m+1):
        for j in range(1, n+1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = 1 + dp[i-1][j-1]
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[m][n]

👉 Key Concept: 2D DP

*🧠 5️⃣ 0/1 Knapsack*

*Problem:*
Maximize value within weight limit.

def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0]*(capacity+1) for _ in range(n+1)]

    for i in range(1, n+1):
        for w in range(capacity+1):
            if weights[i-1] <= w:
                dp[i][w] = max(
                    values[i-1] + dp[i-1][w-weights[i-1]],
                    dp[i-1][w]
                )
            else:
                dp[i][w] = dp[i-1][w]

    return dp[n][capacity]

👉 Key Concept: Decision DP

*⭐ Key Takeaway*

All DP problems follow:
1️⃣ Define state
2️⃣ Write transition
3️⃣ Initialize base case
4️⃣ Build solution
