*🚀 41. How do you implement BFS and DFS on a graph?*

Graphs can be traversed using:
*BFS (Breadth-First Search)*
*DFS (Depth-First Search)*

*🔹 BFS (Breadth-First Search)*
*Uses*: Queue
*Explores*: Level by level

*🔹 Python BFS*
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])

    while queue:
        node = queue.popleft()

        if node not in visited:
            print(node)
            visited.add(node)

            for neighbor in graph[node]:
                queue.append(neighbor)

*🔹 Complexity*
*Time*: O(V + E)
*Space*: O(V)
Where:
*V*: Vertices
*E*: Edges

*🔹 DFS (Depth-First Search)*
*Uses*: Stack or Recursion
*Explores*: Deeply before backtracking

*🔹 Python DFS*
def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()

    if node not in visited:
        print(node)
        visited.add(node)

        for neighbor in graph[node]:
            dfs(graph, neighbor, visited)

*🔹 BFS vs DFS*
*BFS*: Uses Queue, Shortest path, Level traversal
*DFS*: Uses Stack, Backtracking, Deep traversal

Graphs are among the most important DSA interview topics.

*🚀 42. How do you find the height or depth of a tree?*

*Height*: Longest path from root to leaf

*🔹 Recursive Solution*
def height(root):
    if not root:
        return 0

    left = height(root.left)
    right = height(root.right)

    return max(left, right) + 1

*🔹 Complexity*
*Time*: O(n)
*Space*: O(h)
Where:
*h*: tree height

*🔹 Interview Tip*
This question checks recursion fundamentals.

*🚀 43. How do you implement level-order traversal?*

Level-order traversal is BFS on tree.

*🔹 Example*
      1
     / \
    2 3
*Output*: 1 2 3

*🔹 Python Solution*
from collections import deque

def level_order(root):
    if not root:
        return []

    queue = deque([root])

    while queue:
        node = queue.popleft()
        print(node.val)

        if node.left:
            queue.append(node.left)

        if node.right:
            queue.append(node.right)

*🔹 Complexity*
*Time*: O(n)
*Space*: O(n)

*🔹 Uses*
✅ Tree serialization
✅ Shortest path
✅ Hierarchical processing

*🚀 44. How do you check if a binary tree is a BST?*

*BST Rule*: Left < Root < Right

*🔹 Efficient Approach*
Use range validation.

*🔹 Python Solution*
def is_bst(root, low=float('-inf'), high=float('inf')):
    if not root:
        return True

    if root.val <= low or root.val >= high:
        return False

    return (
        is_bst(root.left, low, root.val) and
        is_bst(root.right, root.val, high)
    )

*🔹 Complexity*
*Time*: O(n)
*Space*: O(h)

*🔹 Interview Tip*
Many candidates incorrectly check only immediate children.

*🚀 45. How do you implement preorder traversal iteratively?*

*Preorder*: Root → Left → Right

*🔹 Idea*
Use stack.

*🔹 Python Solution*
def preorder(root):
    if not root:
        return

    stack = [root]

    while stack:
        node = stack.pop()
        print(node.val)

        if node.right:
            stack.append(node.right)

        if node.left:
            stack.append(node.left)

*🔹 Complexity*
*Time*: O(n)
*Space*: O(n)

*🔹 Interview Tip*
Push right first so left is processed first.

*🚀 46. How do you implement postorder traversal iteratively?*

*Postorder*: Left → Right → Root

*🔹 Approach*
Use two stacks or one stack with tracking.

*🔹 Two Stack Solution*
def postorder(root):
    if not root:
        return

    stack1 = [root]
    stack2 = []

    while stack1:
        node = stack1.pop()
        stack2.append(node)

        if node.left:
            stack1.append(node.left)

        if node.right:
            stack1.append(node.right)

    while stack2:
        print(stack2.pop().val)

*🔹 Complexity*
*Time*: O(n)
*Space*: O(n)

*🔹 Interview Tip*
Iterative traversals are common in senior-level interviews.

*🚀 47. How do you find the lowest common ancestor (LCA)?*

*LCA*: Deepest common ancestor of two nodes

*🔹 Example*
      3
     / \
    5 1
*LCA of 5 and 1*: 3

*🔹 Recursive Solution*
def lca(root, p, q):
    if not root or root == p or root == q:
        return root

    left = lca(root.left, p, q)
    right = lca(root.right, p, q)

    if left and right:
        return root

    return left or right

*🔹 Complexity*
*Time*: O(n)
*Space*: O(h)

*🔹 Uses*
✅ File systems
✅ DOM trees
✅ Organizational hierarchies

*🚀 49. How do you detect a cycle in an undirected graph?*

Use DFS with parent tracking.

*🔹 Idea*
If visited neighbor is not parent: cycle exists

*🔹 Python Solution*
def has_cycle(graph, node, visited, parent):
    visited.add(node)

    for neighbor in graph[node]:
        if neighbor not in visited:
            if has_cycle(graph, neighbor, visited, node):
                return True
        elif neighbor!= parent:
            return True

    return False

*🔹 Complexity*
*Time*: O(V + E)
*Space*: O(V)

*🔹 Interview Tip*
Parent tracking is the key idea.

*🚀 50. How do you implement Dijkstra’s algorithm?*

Dijkstra finds shortest path from source for weighted graphs.

*🔹 Idea*
Use Min Heap and greedy approach.

*🔹 Python Solution*
import heapq

def dijkstra(graph, start):
    heap = [(0, start)]
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    while heap:
        current_dist, node = heapq.heappop(heap)

        for neighbor, weight in graph[node]:
            distance = current_dist + weight

            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(heap, (distance, neighbor))

    return distances

*🔹 Complexity*
*Time*: O((V + E) log V)
*Space*: O(V)

*🔹 Uses*
✅ GPS systems
✅ Network routing
✅ Maps
✅ Delivery optimization
