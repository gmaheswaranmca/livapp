*📦 Must-Know Data Structures for Coding Interviews*

✅ *1. Arrays & Lists*  
• Fixed/variable size collections  
• Easy access by index  
📌 *Q:* Reverse an array, two-sum, move zeros  

✅ *2. Strings*  
• Immutable sequences of characters  
• Often treated like arrays  
📌 *Q:* Longest palindrome, string compression  

✅ *3. Hashmaps (Dictionaries)*  
• Key-value storage, fast lookups  
📌 *Q:* Count frequencies, detect duplicates  

✅ *4. Stacks*  
• LIFO (Last In First Out)  
📌 *Q:* Valid parentheses, undo feature  

✅ *5. Queues*  
• FIFO (First In First Out)  
📌 *Q:* Implement with two stacks, sliding window max  

✅ *6. Linked Lists*  
• Nodes with next pointers  
📌 *Q:* Reverse list, detect cycle, merge two lists  

✅ *7. Trees (Binary, BST)*  
• Hierarchical structure, recursive nature  
📌 *Q:* DFS, BFS, height of tree, is BST  

✅ *8. Graphs*  
• Nodes + edges, used in maps/networks  
📌 *Q:* DFS, BFS, detect cycle, shortest path  

✅ *9. Heaps (Priority Queues)*  
• Used to get min/max efficiently  
📌 *Q:* K largest elements, median in stream  

✅ *10. Tries*  
• Tree structure for fast prefix search  
📌 *Q:* Auto-complete, word search
