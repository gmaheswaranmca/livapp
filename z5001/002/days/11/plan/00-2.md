## Final Learning Order

| Phase            | Problems                |
| ---------------- | ----------------------- |
| BST Basics       | 700 → 230 → 653         |
| BST Construction | 108 → 109 → 1008        |
| BST Ancestor     | 235                     |

This sequence takes you from **easy BST operations → BST construction → graph traversal → connected components → topological sorting → grid DFS/BFS** in a structured interview-preparation path.
