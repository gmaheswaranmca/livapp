## Phase-wise Learning Path

### Phase 1: Understand BST Property

1. 700 – Search in BST
2. 938 – Range Sum of BST
3. 530 – Minimum Absolute Difference in BST
4. 230 – Kth Smallest Element in BST

### Phase 2: BST Validation

5. 98 – Validate BST
6. 99 – Recover BST

### Phase 3: BST Updates

7. 701 – Insert into BST
8. 450 – Delete Node in BST
9. 669 – Trim BST

### Phase 4: BST Relationships

10. 235 – Lowest Common Ancestor
11. 285 – Inorder Successor

### Phase 5: BST Construction

12. 108 – Sorted Array → BST
13. 109 – Sorted List → BST
14. 1008 – Preorder → BST

### Phase 6: Advanced BST

15. 1382 – Balance BST
16. 173 – BST Iterator
17. 333 – Largest BST Subtree
