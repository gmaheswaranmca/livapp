These are good BST + Graph/Topo + DFS/BFS problems. Learn them in this order:

# Phase 1: Basic BST Traversal & Search

### 1. LeetCode 700 — Search in a Binary Search Tree

* Search a value in BST
* Learn BST property
* Difficulty: Easy

### 2. LeetCode 230 — Kth Smallest Element in a BST

* Inorder traversal of BST
* BST produces sorted order
* Difficulty: Medium

### 3. LeetCode 653 — Two Sum IV - Input is a BST

* BST + HashSet
* DFS traversal
* Difficulty: Easy

---

# Phase 2: BST Construction

### 4. LeetCode 108 — Convert Sorted Array to Binary Search Tree

* Build balanced BST
* Divide and conquer
* Difficulty: Easy

### 5. LeetCode 109 — Convert Sorted List to Binary Search Tree

* Linked List + BST
* Slow/Fast Pointer
* Difficulty: Medium

### 6. LeetCode 1008 — Construct BST from Preorder Traversal

* Recursive BST construction
* Bounds technique
* Difficulty: Medium

---

# Phase 3: BST Ancestor Problems

### 7. LeetCode 235 — Lowest Common Ancestor of a BST

* Use BST ordering property
* Difficulty: Easy

---

# Phase 4: BST Modification

### 8. LeetCode 701 — Insert into a Binary Search Tree

* BST insertion
* Difficulty: Medium

### 9. LeetCode 450 — Delete Node in a BST

* Three deletion cases
* Difficulty: Medium

---

# Phase 5: Graph Basics

### 10. LeetCode 997 — Find the Town Judge

* Indegree / Outdegree
* Graph fundamentals
* Difficulty: Easy

### 11. LeetCode 1791 — Find Center of Star Graph

* Simple graph observation
* Difficulty: Easy

### 12. LeetCode 1971 — Find if Path Exists in Graph

* DFS / BFS
* Graph traversal
* Difficulty: Easy

### 13. LeetCode 547 — Number of Provinces

* DFS
* BFS
* Union Find
* Difficulty: Medium

---

# Phase 6: Topological Sort

### 14. LeetCode 207 — Course Schedule

* Cycle Detection
* Topological Sort
* Difficulty: Medium

### 15. LeetCode 210 — Course Schedule II

* Topological Ordering
* Kahn's Algorithm
* Difficulty: Medium

### 16. LeetCode 310 — Minimum Height Trees

* Topological Sort
* Leaf Trimming
* Difficulty: Medium

---

# Phase 7: Grid Graphs

### 17. LeetCode 200 — Number of Islands

* DFS
* BFS
* Grid Traversal
* Connected Components
* Difficulty: Medium
