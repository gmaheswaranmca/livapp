# Network Flow – Easy-to-Understand Notes

## 1. What is Network Flow?

Network Flow is a graph problem where we need to **send something from a source to a destination through a network**.

The "something" can be:

* Water through pipes
* Data through computer networks
* Cars through roads
* Goods through transportation routes
* People through evacuation paths

---

## 2. Basic Components

Consider this graph:

```text
        10
   S --------> A
   |           |
  5|           |8
   |           |
   v           v
   B --------> T
        6
```

### Source (S)

Starting point.

```text
S = Source
```

### Sink (T)

Ending point.

```text
T = Sink
```

### Edge Capacity

Maximum amount that can flow through an edge.

Example:

```text
S → A = 10
```

means at most 10 units can travel.

---

## 3. Real-Life Example

Imagine water pipes.

```text
Tank
  |
  | 10 liters
  v
Junction
  |
  | 5 liters
  v
House
```

If a pipe supports only 5 liters, you cannot send 10 liters through it.

That pipe becomes a **bottleneck**.

---

# 4. Flow Rules

### Rule 1: Capacity Constraint

Flow cannot exceed capacity.

```text
Capacity = 10

Allowed:
Flow = 5
Flow = 8
Flow = 10

Not Allowed:
Flow = 11
```

---

### Rule 2: Flow Conservation

Except Source and Sink:

```text
Incoming Flow = Outgoing Flow
```

Example:

```text
    5
A -----> B
          |
          |5
          v
          C
```

B receives 5 and sends 5.

---

## 5. What is Maximum Flow?

Question:

> What is the maximum amount that can be sent from Source to Sink?

Example:

```text
S --10--> A --8--> T
```

Maximum flow:

```text
8
```

because edge A→T allows only 8.

---

## 6. Bottleneck Edge

Smallest capacity in a path.

Example:

```text
S --10--> A --4--> B --8--> T
```

Path capacities:

```text
10, 4, 8
```

Minimum = 4

So only 4 units can travel.

```text
Bottleneck = 4
```

---

## 7. Augmenting Path

A path from Source to Sink that can still carry flow.

Example:

```text
S → A → T
```

Capacity:

```text
10 and 8
```

Can carry:

```text
min(10,8)=8
```

This is an augmenting path.

---

## 8. Residual Graph

After sending flow, some capacity remains.

Example:

```text
S → A capacity 10

Send flow = 6
```

Remaining:

```text
10 - 6 = 4
```

Residual capacity:

```text
4
```

Residual graph helps us find more paths.

---

# 9. Maximum Flow Example

Graph:

```text
      10
S --------> A
|           |
|           |8
|           |
v           v
B --------> T
      5
```

Capacities:

```text
S→A = 10
S→B = 5
A→T = 8
B→T = 5
```

Path 1:

```text
S→A→T
```

Flow:

```text
min(10,8)=8
```

Path 2:

```text
S→B→T
```

Flow:

```text
min(5,5)=5
```

Total:

```text
8 + 5 = 13
```

Maximum Flow = 13

# 10. Famous Algorithms

## Ford-Fulkerson

Main idea:

```text
1. Find path Source→Sink
2. Send bottleneck flow
3. Update capacities
4. Repeat
```

Time Complexity:

```text
O(E × MaxFlow)
```

---

## Edmonds-Karp

Ford-Fulkerson using BFS.

Uses:

```text
BFS to find shortest augmenting path
```

Time:

```text
O(VE²)
```

Most common interview algorithm.

---

## Dinic's Algorithm

Faster version.

Uses:

* BFS
* Level Graph
* DFS

Complexity:

```text
O(V²E)
```

Very popular in competitive programming.

---

## Push Relabel

Used in large networks.

Complexity:

```text
O(V³)
```

---

# 11. Max Flow = Min Cut Theorem

One of the most important graph theorems.

It states:

> Maximum Flow = Minimum Cut

A cut divides graph into two parts:

```text
Source side
Sink side
```

The minimum capacity that disconnects source from sink equals maximum flow.

---

Example:

```text
S --5--> T
```

Maximum flow:

```text
5
```

Removing edge:

```text
capacity = 5
```

Minimum cut:

```text
5
```

Hence:

```text
Max Flow = Min Cut
```

## Interview Definition

> A Network Flow problem models the movement of some quantity through a directed graph where each edge has a capacity. The goal is typically to find the maximum amount that can be sent from a source node to a sink node while respecting capacity constraints and flow conservation rules.
