If a learner will do **only 5 BST problems**, the goal should be to cover the **core BST patterns**, so they can independently solve most other BST questions later.

| Order | Problem # | Title                            | Why This One?                                                                     |
| ----- | --------- | -------------------------------- | --------------------------------------------------------------------------------- |
| 1     | 700       | Search in a Binary Search Tree   | Understand the BST property (`left < root < right`). Foundation of everything.    |
| 2     | 230       | Kth Smallest Element in a BST    | Learn that inorder traversal of a BST gives sorted order. Very important insight. |
| 3     | 701       | Insert into a Binary Search Tree | Learn how BSTs are built and modified. Reinforces BST property.                   |
| 4     | 450       | Delete Node in a BST             | Covers the hardest fundamental BST operation (leaf, one child, two children).     |
| 5     | 235       | Lowest Common Ancestor of a BST  | Teaches how to exploit BST ordering instead of traversing the whole tree.         |

### Why these 5?

After these 5, students will know:

✅ BST Property
✅ Search
✅ Inorder Traversal Insight
✅ Insert
✅ Delete
✅ Ancestor Queries
✅ Recursive Tree Thinking

Then they can self-learn:

* 653 (Two Sum IV)
* 938 (Range Sum BST)
* 530 (Minimum Difference BST)
* 501 (Find Mode BST)
* 285 (Inorder Successor)
* 669 (Trim BST)

with relatively little difficulty.

### If you want 5 problems that also include BST Construction

Replace 235 with:

| Problem                                          | Reason                                           |
| ------------------------------------------------ | ------------------------------------------------ |
| 108 – Convert Sorted Array to Binary Search Tree | Teaches BST construction and divide-and-conquer. |

Then the sequence becomes:

**700 → 230 → 701 → 450 → 108**

This is the set I would use for a training batch because it covers:

* Search
* Traversal
* Insert
* Delete
* Construction

which are the five fundamental BST operations.
