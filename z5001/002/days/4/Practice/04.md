# Snowmelt Collection Between Mountain Peaks

(Equivalent to the classic **Trapping Rain Water** problem)

## Example

```text
Height = [4, 2, 0, 3, 2, 5]
```

Total trapped water = **9 units**

---

# Approach 1: Prefix/Suffix Arrays

## Idea

For every position:

```text
Water[i] =
MIN(Max Height on Left,
    Max Height on Right)
-
Current Height
```

---

## Step 1: Build LeftMax Array

```text
Height =  [4, 2, 0, 3, 2, 5]

LeftMax = [4, 4, 4, 4, 4, 5]
```

Explanation:

```text
Index 0 → max(4) = 4
Index 1 → max(4,2) = 4
Index 2 → max(4,2,0) = 4
Index 3 → max(4,2,0,3) = 4
Index 4 → max(...) = 4
Index 5 → max(...) = 5
```

---

## Step 2: Build RightMax Array

```text
RightMax = [5, 5, 5, 5, 5, 5]
```

Explanation:

```text
Index 5 → 5

Index 4 →
max(2,5)=5

Index 3 →
max(3,5)=5

and so on...
```

---

## Step 3: Calculate Water

| Index | Height | LeftMax | RightMax | Water |
| ----- | ------ | ------- | -------- | ----- |
| 0     | 4      | 4       | 5        | 0     |
| 1     | 2      | 4       | 5        | 2     |
| 2     | 0      | 4       | 5        | 4     |
| 3     | 3      | 4       | 5        | 1     |
| 4     | 2      | 4       | 5        | 2     |
| 5     | 5      | 5       | 5        | 0     |

Total:

```text
0 + 2 + 4 + 1 + 2 + 0 = 9
```

---

## Prefix/Suffix Pseudocode

```text
INPUT height[]

n ← length(height)

CREATE leftMax[n]
CREATE rightMax[n]

leftMax[0] ← height[0]

FOR i ← 1 TO n-1

    leftMax[i] ←
        MAX(leftMax[i-1], height[i])

rightMax[n-1] ← height[n-1]

FOR i ← n-2 DOWNTO 0

    rightMax[i] ←
        MAX(rightMax[i+1], height[i])

water ← 0

FOR i ← 0 TO n-1

    trapped ←
        MIN(leftMax[i], rightMax[i])
        - height[i]

    water ← water + trapped

PRINT water
```

### Complexity

```text
Time  : O(n)
Space : O(n)
```

# Approach 2: Two Pointers (Best)

## Core Observation

Water depends on:

```text
MIN(leftMax, rightMax)
```

If:

```text
leftMax < rightMax
```

Then left side decides water amount.

So we can safely process the left pointer.

Similarly:

```text
rightMax <= leftMax
```

Process the right pointer.

---

## Pseudocode

```text
INPUT height[]

left ← 0
right ← n-1

leftMax ← 0
rightMax ← 0

water ← 0

WHILE left < right

    IF height[left] < height[right]

        IF height[left] >= leftMax

            leftMax ← height[left]

        ELSE

            water ←
                water +
                (leftMax - height[left])

        left ← left + 1

    ELSE

        IF height[right] >= rightMax

            rightMax ← height[right]

        ELSE

            water ←
                water +
                (rightMax - height[right])

        right ← right - 1

PRINT water
```

# Two Pointer Walkthrough

Input:

```text
[4,2,0,3,2,5]
```

Initial:

```text
left = 0
right = 5

leftMax = 0
rightMax = 0

water = 0
```

---

### Iteration 1

```text
height[left] = 4
height[right] = 5

4 < 5
```

Update leftMax:

```text
leftMax = 4
```

Move:

```text

```

Water:

```text
0
```

---

### Iteration 2

```text
height[left] = 2
height[right] = 5

2 < 5
```

```text
water += leftMax - height[left]

water += 4 - 2

```

Move:

```text
left = 2
```

---

### Iteration 3

```text

0 < 5
```

```text

water = 6
```

Move:

```text
left = 3
```

---

### Iteration 4

```text
height[left] = 3
height[right] = 5

3 < 5
```

```text

water = 7
```

```text

```

# Why Two Pointers Works

At any moment:

```text
Water at position =
MIN(leftMax, rightMax)
-
height
```

When:

```text
leftMax < rightMax
```

The minimum boundary is definitely:

```text
leftMax
```

So water on the left side can already be calculated without knowing future values.

Similarly:

```text
rightMax <= leftMax
```

Water on the right side can be calculated immediately.

This removes the need for storing `leftMax[]` and `rightMax[]` arrays.

# Comparison

| Approach             | Time  | Space | Interview Preference |
| -------------------- | ----- | ----- | -------------------- |
| Brute Force          | O(n²) | O(1)  | ❌                    |
| Prefix/Suffix Arrays | O(n)  | O(n)  | ✅ Good               |
| Two Pointers         | O(n)  | O(1)  | ⭐ Best               |

### Pattern Recognition

When you hear:

* Water trapped between bars
* Rain water trapping
* Left boundary and right boundary
* Need O(1) extra space

Think:

```text
Two Pointers + Running LeftMax + Running RightMax
```

This is the standard optimal pattern used in interviews at companies like Amazon, Google, Meta, and Microsoft.
