## Recommended Learning Order

### Phase 1 (Mass Hiring)

1. Linear Search
2. First Occurrence
3. Last Occurrence
4. Count Occurrences
5. Binary Search
6. Search Insert Position

### Phase 2 (Product Companies)

7. Lower Bound
8. Upper Bound
9. First and Last Position
10. Floor and Ceil
11. Square Root
12. Peak Element
13. Rotated Sorted Array

### Phase 3 (Amazon / Microsoft / Google)

14. Single Element in Sorted Array
15. Infinite Sorted Array
16. Koko Eating Bananas
17. Allocate Pages
18. Aggressive Cows
19. Capacity To Ship Packages

### Phase 4 (Tier-1 Companies)

20. Median of Two Sorted Arrays
21. K-th Element of Two Sorted Arrays
22. Median in Matrix
23. K-th Smallest in Matrix
24. Find Peak Element II
25. Ternary Search Optimization Problems

This sequence covers almost every search-pattern question typically seen from TCS/Infosys level up to Amazon, Google, Microsoft, Meta, Adobe, Uber, Bloomberg, and quantitative trading firms.
