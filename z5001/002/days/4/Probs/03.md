# Problem 3: Ternary Search

## Question Title

Ternary Search in a Sorted Array

## Category

Searching

## Difficulty Level

Medium

## Time Complexity

* Best Case: O(1)
* Average Case: O(log₃ n)
* Worst Case: O(log₃ n)

## Space Complexity

* O(1)

## Problem Description

Given a sorted array of integers in ascending order and a target value K, find the index of K using the Ternary Search algorithm.

Ternary Search divides the search range into three parts using two middle positions and determines in which part the target may exist.

If the target exists in the array, print its index (0-based indexing). Otherwise, print -1.

---

## Input Format

* First line contains an integer N representing the number of elements.
* Second line contains N space-separated integers sorted in ascending order.
* Third line contains an integer K representing the target value.

---

## Output Format

Print the index of K if found; otherwise print -1.

---

## Constraints

* 1 ≤ N ≤ 10^5
* -10^9 ≤ Array[i] ≤ 10^9
* Array is sorted in ascending order.
* -10^9 ≤ K ≤ 10^9

---

## Sample Input

```text
9
10 20 30 40 50 60 70 80 90
70
```

## Sample Output

```text
6
```

---

## Explanation

The target value 70 is present at index 6.

Using Ternary Search:

* First Mid = 2 (30)
* Second Mid = 6 (70)

Target found at index 6.

## Additional Notes

* Ternary Search works only on sorted data.
* The search range is divided into three parts using two midpoints.
* Although theoretically O(log₃ n), Binary Search is usually preferred in practice because it performs fewer comparisons and has lower overhead.

### Ternary Search Midpoint Formula

```text
mid1 = left + (right - left) / 3
mid2 = right - (right - left) / 3
```

### Search Regions

```text
[left ... mid1-1]
[mid1+1 ... mid2-1]
[mid2+1 ... right]
```
