# Problem 10: Radix Sort

## Question Title

Sort an Array Using Radix Sort

## Category

Sorting

## Difficulty Level

Medium

## Time Complexity

* Best Case: O(d × (n + k))
* Average Case: O(d × (n + k))
* Worst Case: O(d × (n + k))

Where:

* n = Number of elements
* d = Number of digits in the largest element
* k = Base (10 for decimal numbers)

---

## Space Complexity

* O(n + k)

---

## Problem Description

Given an array of non-negative integers, sort the array in ascending order using the Radix Sort algorithm.

Radix Sort processes numbers digit by digit, starting from the least significant digit (LSD) and moving towards the most significant digit (MSD).

A stable sorting algorithm (typically Counting Sort) is used at each digit position.

Print the sorted array.

---

## Input Format

* First line contains an integer N representing the number of elements.
* Second line contains N space-separated non-negative integers.

---

## Output Format

Print the sorted array in ascending order separated by spaces.

---

## Constraints

* 1 ≤ N ≤ 10⁵
* 0 ≤ Array[i] ≤ 10⁹

---

## Sample Input

```text
8
170 45 75 90 802 24 2 66
```

## Sample Output

```text
2 24 45 66 75 90 170 802
```

---

## Explanation

Initial Array:

```text
170 45 75 90 802 24 2 66
```

### Pass 1 (Units Digit)

```text
170 90 802 2 24 45 75 66
```

### Pass 2 (Tens Digit)

```text
802 2 24 45 66 170 75 90
```

### Pass 3 (Hundreds Digit)

```text
2 24 45 66 75 90 170 802
```

Final sorted array:

```text
2 24 45 66 75 90 170 802
```

## Notes

### Radix Sort Workflow

```text
Input Array
↓
Sort by Units Digit
↓
Sort by Tens Digit
↓
Sort by Hundreds Digit
↓
...
↓
Sorted Array
```

### Characteristics

* Non-Comparison Sort
* Stable Sort
* Requires Extra Memory
* Efficient for Integers with Limited Digits
* Uses Counting Sort Internally

---

### Key Idea

```text
Sort by 1's Digit
↓
Sort by 10's Digit
↓
Sort by 100's Digit
↓
Continue Until Largest Digit Processed
```
