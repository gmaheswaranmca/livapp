# Problem 2: Binary Search

## Question Title

Binary Search in a Sorted Array

## Category

Searching

## Difficulty Level

Easy

## Time Complexity

* Best Case: O(1)
* Average Case: O(log n)
* Worst Case: O(log n)

## Space Complexity

* O(1)

## Problem Description

Given a sorted array of integers in ascending order and a target value K, find the index of K using Binary Search.

If the target exists in the array, print its index (0-based indexing). Otherwise, print -1.

The solution must utilize the Binary Search technique.

---

## Input Format

* First line contains an integer N representing the number of elements.
* Second line contains N space-separated integers sorted in ascending order.
* Third line contains an integer K representing the target value.

---

## Output Format

Print the index of K if found; otherwise print -1.

---

## Constraints

* 1 ≤ N ≤ 10^5
* -10^9 ≤ Array[i] ≤ 10^9
* Array is sorted in ascending order.
* -10^9 ≤ K ≤ 10^9

---

## Sample Input

```text
7
10 20 30 40 50 60 70
50
```

## Sample Output

```text
4
```

---

## Explanation

The target value 50 is found at index 4.

### Notes

* Binary Search works only when the array is sorted.
* At each step, the search space is reduced by half.
* This makes Binary Search significantly faster than Linear Search for large datasets.
