# Problem 9: Bucket Sort

## Question Title

Sort an Array Using Bucket Sort

## Category

Sorting

## Difficulty Level

Medium

## Time Complexity

* Best Case: O(n + k)
* Average Case: O(n + k)
* Worst Case: O(n²)

Where:

* n = Number of elements
* k = Number of buckets

## Space Complexity

* O(n + k)

---

## Problem Description

Given an array of non-negative integers, sort the array in ascending order using the Bucket Sort algorithm.

Bucket Sort distributes elements into multiple buckets based on a predefined range. Each bucket is sorted individually and then all buckets are combined to obtain the final sorted array.

Print the sorted array.

---

## Input Format

* First line contains an integer N representing the number of elements.
* Second line contains N space-separated non-negative integers.

---

## Output Format

Print the sorted array in ascending order separated by spaces.

---

## Constraints

* 1 ≤ N ≤ 10⁵
* 0 ≤ Array[i] ≤ 10⁵

---

## Sample Input

```text
8
29 25 3 49 9 37 21 43
```

## Sample Output

```text
3 9 21 25 29 37 43 49
```

---

## Explanation

Initial Array:

```text
29 25 3 49 9 37 21 43
```

Assume bucket ranges:

```text
Bucket 0 : 0 - 9
Bucket 1 : 10 - 19
Bucket 2 : 20 - 29
Bucket 3 : 30 - 39
Bucket 4 : 40 - 49
```

Elements distributed:

```text
Bucket 0 : 3 9
Bucket 1 :
Bucket 2 : 29 25 21
Bucket 3 : 37
Bucket 4 : 49 43
```

Sort each bucket:

```text
Bucket 0 : 3 9
Bucket 2 : 21 25 29
Bucket 3 : 37
Bucket 4 : 43 49
```

Merge buckets:

```text
3 9 21 25 29 37 43 49
```

## Notes

### Bucket Sort Workflow

```text
Input Array
↓
Create Buckets
↓
Distribute Elements
↓
Sort Individual Buckets
↓
Merge Buckets
↓
Sorted Array
```

---

### Example

```text
Input:
42 32 33 52 37 47 51

Buckets:

0-9   :
10-19 :
20-29 :
30-39 : 32 33 37
40-49 : 42 47
50-59 : 52 51
```

After sorting buckets:

```text
32 33 37
42 47
51 52
```

Final output:

```text
32 33 37 42 47 51 52
```

---

### Characteristics

* Distribution Sort
* Not Comparison Based
* Can achieve near O(n)
* Requires extra memory
* Works best when data is uniformly distributed

---

### Key Idea

```text
Distribute
↓
Sort Small Groups
↓
Combine
```

---

### Best Use Cases

```text
Uniformly Distributed Data
Floating Point Numbers
Large Data Sets
Range-Based Data
```

---

### Comparison with Merge Sort

| Feature      | Bucket Sort                   | Merge Sort      |
| ------------ | ----------------------------- | --------------- |
| Type         | Distribution Sort             | Comparison Sort |
| Best Case    | O(n+k)                        | O(n log n)      |
| Average Case | O(n+k)                        | O(n log n)      |
| Worst Case   | O(n²)                         | O(n log n)      |
| Extra Space  | O(n+k)                        | O(n)            |
| Stable       | Depends on bucket sort method | Yes             |
