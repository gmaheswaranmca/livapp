# Problem 1: Linear Search

## Question Title

Linear Search in an Array

## Category

Searching

## Difficulty Level

Easy

## Time Complexity

* Best Case: O(1)
* Average Case: O(n)
* Worst Case: O(n)

## Space Complexity

* O(1)

## Problem Description

Given an array of integers and a target value, find the index of the first occurrence of the target in the array.

If the target is present, print its index (0-based indexing). Otherwise, print -1.

You must use the Linear Search technique to solve the problem.

---

## Input Format

* First line contains an integer N representing the number of elements.
* Second line contains N space-separated integers.
* Third line contains an integer K representing the target value.

---

## Output Format

Print the index of the first occurrence of K.

If K is not found, print -1.

---

## Constraints

* 1 ≤ N ≤ 10^5
* -10^9 ≤ Array[i] ≤ 10^9
* -10^9 ≤ K ≤ 10^9

---

## Sample Input

```text
5
10 20 30 40 50
30
```

## Sample Output

```text
2
```

---

## Explanation

The target value 30 is present at index 2.
