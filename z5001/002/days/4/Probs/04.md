# Problem 4: Bubble Sort

## Question Title

Sort an Array Using Bubble Sort

## Category

Sorting

## Difficulty Level

Easy

## Time Complexity

* Best Case: O(n) (with swap optimization)
* Average Case: O(n²)
* Worst Case: O(n²)

## Space Complexity

* O(1)

---

## Problem Description

Given an array of integers, sort the array in ascending order using the Bubble Sort algorithm.

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each pass, the largest unsorted element moves to its correct position.

Print the sorted array.

---

## Input Format

* First line contains an integer N representing the number of elements.
* Second line contains N space-separated integers.

---

## Output Format

Print the elements of the sorted array in ascending order separated by spaces.

---

## Constraints

* 1 ≤ N ≤ 10^3
* -10^9 ≤ Array[i] ≤ 10^9

---

## Sample Input

```text
5
64 34 25 12 22
```

## Sample Output

```text
12 22 25 34 64
```

---

## Explanation

Initial Array:

```text
64 34 25 12 22
```

After Bubble Sort:

```text
12 22 25 34 64
```

## Notes

### Bubble Sort Process

```text
Pass 1:
64 34 25 12 22
↓
34 25 12 22 64

Pass 2:
34 25 12 22 64
↓
25 12 22 34 64

Pass 3:
25 12 22 34 64
↓
12 22 25 34 64
```

### Characteristics

* Stable Sort
* In-place Sort
* Easy to implement
* Inefficient for large datasets
* Frequently used for teaching sorting fundamentals
