# Question Title
Valid Anagram

# Categories
Strings, Hashing

# Time Complexity
O(n)

# Space Complexity
O(1)

# Difficulty Level
Easy

# Problem Description
Given two strings `s` and `t`, determine whether `t` is an anagram of `s`.

An anagram is a word or phrase formed by rearranging the characters of another word or phrase, using all the original characters exactly the same number of times.

Return `true` if `t` is an anagram of `s`; otherwise, return `false`.

# Sample Input
```
listen
silent
```

# Sample Output
```
true
```

# Input Format
- First line contains a string `s`.
- Second line contains a string `t`.

# Output Format
- Print `true` if the strings are anagrams.
- Otherwise, print `false`.

# Explanation
For:

```
s = "listen"
t = "silent"
```

Both strings contain the same characters:

```
l, i, s, t, e, n
```

with exactly the same frequency.

Therefore:

```
true
```

# Constraints
- 1 ≤ length of s, t ≤ 5 × 10^4
- `s` and `t` consist of lowercase English letters.
