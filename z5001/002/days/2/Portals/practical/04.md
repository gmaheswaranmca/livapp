# Question Title
Longest Substring Without Repeating Characters

# Categories
Strings, Sliding Window, Hashing

# Time Complexity
O(n)

# Space Complexity
O(min(n, m))

Where:
- `n` = length of the string
- `m` = size of the character set

# Difficulty Level
Medium

# Problem Description
Given a string `s`, find the length of the longest substring without repeating characters.

A substring is a contiguous sequence of characters within a string.

Return the maximum length of a substring that contains only unique characters.

# Sample Input
```
abcabcbb
```

# Sample Output
```
3
```

# Input Format
- A single line containing the string `s`.

# Output Format
- Print a single integer representing the length of the longest substring without repeating characters.

# Explanation
For:

```
abcabcbb
```

The longest substrings without repeating characters are:

```
abc
bca
cab
```

Each has length:

```
3
```

Therefore, the output is:

```
3
```

# Constraints
- 0 ≤ s.length ≤ 5 × 10^4
- `s` consists of English letters, digits, symbols, and spaces.
