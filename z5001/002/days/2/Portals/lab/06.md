# Question Title
Product of Array Except Self

# Categories
Arrays, Prefix Sum

# Time Complexity
O(n)

# Space Complexity
O(1)

Note: The output array is not counted as extra space.

# Difficulty Level
Medium

# Problem Description
Given an integer array `nums`, return an array `answer` such that:

```
answer[i]
```

is equal to the product of all elements of `nums` except `nums[i]`.

You must solve the problem without using the division operator and in `O(n)` time complexity.

# Sample Input
```
4
1 2 3 4
```

# Sample Output
```
24 12 8 6
```

# Input Format
- First line contains an integer `n`, representing the size of the array.
- Second line contains `n` space-separated integers representing the array elements.

# Output Format
- Print `n` space-separated integers where the `i-th` value represents the product of all elements except the current element.

# Explanation
For:

```
1 2 3 4
```

Output values are:

- For index 0: 2 × 3 × 4 = 24
- For index 1: 1 × 3 × 4 = 12
- For index 2: 1 × 2 × 4 = 8
- For index 3: 1 × 2 × 3 = 6

Therefore:

```
24 12 8 6
```

# Constraints
- 2 ≤ n ≤ 10^5
- -30 ≤ nums[i] ≤ 30
- The product of any prefix or suffix fits in a 32-bit integer.
