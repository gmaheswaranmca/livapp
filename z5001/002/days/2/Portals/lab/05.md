# Question Title
Contains Duplicate

# Categories
Arrays, Hashing

# Time Complexity
O(n)

# Space Complexity
O(n)

# Difficulty Level
Easy

# Problem Description
Given an integer array `nums`, return `true` if any value appears at least twice in the array, and return `false` if every element is distinct.

# Sample Input
```
5
1 2 3 1
```

# Sample Output
```
true
```

# Input Format
- First line contains an integer `n`, representing the size of the array.
- Second line contains `n` space-separated integers representing the array elements.

# Output Format
- Print `true` if the array contains at least one duplicate element.
- Otherwise, print `false`.

# Explanation
For:

```
1 2 3 1
```

The value `1` appears more than once.

Therefore, the array contains duplicate elements and the output is:

```
true
```

# Constraints
- 1 ≤ n ≤ 10^5
- -10^9 ≤ nums[i] ≤ 10^9
