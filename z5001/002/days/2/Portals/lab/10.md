# Question Title
Minimum Window Substring

# Categories
Strings, Sliding Window, Hashing

# Time Complexity
O(n + m)

Where:
- `n` = length of string `s`
- `m` = length of string `t`

# Space Complexity
O(k)

Where:
- `k` = number of distinct characters in `t`

# Difficulty Level
Hard

# Problem Description
Given two strings `s` and `t` of lengths `n` and `m` respectively, return the minimum window substring of `s` such that every character in `t` (including duplicates) is included in the window.

If there is no such substring, return an empty string `""`.

If multiple valid windows exist, return the one with the minimum length.

# Sample Input
```
ADOBECODEBANC
ABC
```

# Sample Output
```
BANC
```

# Input Format
- First line contains string `s`.
- Second line contains string `t`.

# Output Format
- Print the smallest substring of `s` that contains all characters of `t`.
- Print an empty string if no valid window exists.

# Explanation
Input:

```
s = ADOBECODEBANC
t = ABC
```

Possible valid windows include:

```
ADOBEC
CODEBAN
BANC
```

Among them:

```
BANC
```

is the shortest substring containing all characters:

```
A, B, C
```

Hence the output is:

```
BANC
```

# Constraints
- 1 ≤ s.length ≤ 10^5
- 1 ≤ t.length ≤ 10^5
- `s` and `t` consist of uppercase and lowercase English letters.
- Characters in `t` may appear multiple times.
