# Why?

Every runtime will support:

```javascript
await runtime.initialize()

await runtime.run(code,input)

await runtime.reset()
```

No UI component should know whether it's Python, R, C++, or JS.

# 2. RuntimeFactory.js

Path

```text
src/runtimes/RuntimeFactory.js
```

```javascript
import PyodideRuntime from "./python/PyodideRuntime";
import WebRRuntime from "./r/WebRRuntime";
import ClangRuntime from "./cpp/ClangRuntime";
import JSRuntime from "./javascript/JSRuntime";

export function createRuntime(language) {

    switch(language) {

        case "python":
            return new PyodideRuntime();

        case "r":
            return new WebRRuntime();

        case "cpp":
            return new ClangRuntime();

        case "javascript":
            return new JSRuntime();

        default:
            throw new Error(
                `Unsupported language: ${language}`
            );
    }

}
```

# 3. JSRuntime.js

Start with JavaScript because it requires no external package.

Path

```text
src/runtimes/javascript/JSRuntime.js
```

```javascript
import BaseRuntime from "../BaseRuntime";

export default class JSRuntime extends BaseRuntime {

    async initialize() {

        return true;

    }

    async run(code) {

        try {

            const logs = [];

            const originalLog = console.log;

            console.log = (...args) => {

                logs.push(
                    args.join(" ")
                );

            };

            eval(code);

            console.log = originalLog;

            return {

                success: true,

                output: logs.join("\n")

            };

        }
        catch(error) {

            return {

                success: false,

                output: error.message

            };

        }

    }

    async reset() {

        return true;

    }

}
```

# 4. Runtime Service

Create a singleton manager.

Path

```text
src/services/runtimeService.js
```

```javascript
import { createRuntime }
from "../runtimes/RuntimeFactory";

class RuntimeService {

    runtime = null;

    language = null;

    async getRuntime(language) {

        if(
            this.runtime &&
            this.language === language
        ) {
            return this.runtime;
        }

        this.runtime =
            createRuntime(language);

        this.language =
            language;

        await this.runtime.initialize();

        return this.runtime;
    }

}

export default new RuntimeService();
```

---

# Why RuntimeService?

Without it:

```text
Run
Run
Run
Run
```

would reload Pyodide/WebR every time.

With RuntimeService:

```text
Load once
Reuse forever
```

which is exactly how LeetCode works.
