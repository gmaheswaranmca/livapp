
# 5. Python stdin()

Pyodide supports stdin.

Inside

```text
PyodideRuntime.js
```

---

Before executing:

```javascript
const lines=input.split("\n");

let index=0;
```

---

Provide stdin:

```javascript
this.pyodide.setStdin({

stdin:()=>{

return lines[index++] || null;

}

});
```

---

Now this works:

```python
name=input()

print(name)
```

```text
John
```

```text
John
```

# 6. JS stdin()

Browser JS has no stdin.

Create helper:

```javascript
const stdin=input.split("\n");

let ptr=0;


const prompt=()=>{

}
```

User code:

```javascript
const a=parseInt(prompt())

const b=parseInt(prompt())

console.log(a+b)
```

# 8. Judge Service

Create:

```text
src/services/JudgeService.js
```

---

Basic version:

```javascript
export default class JudgeService{


static async judge(

runtime,

code,

testCases

){

let passed=0;


for(const tc of testCases){

const result=

await runtime.execute(

code,

tc.input

);


if(

result.output.trim()

===

tc.expected.trim()

){

passed++;

}

}


return{

passed,

total:testCases.length

}

}


}
```

---

Example

Test Cases:

```text
1 2

expected

3
```

```text
5 6

expected

11
```

---

User code:

```python
a,b=map(int,input().split())

print(a+b)
```

---

Result:

```javascript
{

passed:2,

total:2

}
```
