## Why not wait for all steps?

If I give you 40–50 steps now:

* You may change folder structures later.
* Runtime APIs may evolve.
* C++ WASM integration may require modifications.
* You may discover UI improvements while coding.

So designing everything upfront is less effective than:

```text
Design a stable architecture
        ↓
Implement a small piece
        ↓
Test
        ↓
Improve
        ↓
Move to next layer
```

This is also how:

* Meta Platforms engineers build React apps.
* Microsoft develops editor features.
* JupyterLite evolved over time.
