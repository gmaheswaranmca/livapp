### Phase 2 – Runtime Layer

Implement one runtime at a time:

1. JavaScript Runtime
2. Python Runtime (Pyodide)
3. R Runtime (WebR)
4. C++ Runtime (clang.wasm / xeus-cpp)

Each runtime will expose:

```javascript
init()

run(code)

restart()

destroy()
```

This common API is extremely important.
