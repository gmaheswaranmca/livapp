# Question Before We Start Coding Phase 2

There is **one architectural decision** I want to freeze first:

### Output and Test Cases Layout

#### Option A (Simple)

```text
Toolbar

Editor

Test Cases

Output
```

---

#### Option B (LeetCode Style) ⭐ Recommended

```text
Toolbar

Editor

-----------------

| Test Cases |

-----------------

| Output     |

-----------------
```

---

#### Option C (Resizable Bottom Panel) ⭐⭐⭐ My Recommendation

```text
Toolbar

Editor

-------------------------

Bottom Panel

Tabs:

[Test Cases]

[Output]

-------------------------
```

Like:

* LeetCode
* Visual Studio Code
* JupyterLite

where Output and Test Cases are tabs inside a resizable bottom panel.

**I recommend Option C**, because it is scalable and closely matches professional coding platforms.
