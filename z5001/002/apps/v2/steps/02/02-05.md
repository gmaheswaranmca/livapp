In this step, we will build:

```text
LanguageSelector.jsx
ThemeSelector.jsx
FontSelector.jsx
```

These components are intentionally **dumb UI components**:

* They receive values as props.
* They call callback functions.
* They do not contain business logic.

This makes them reusable and easy to test.

---

# 1. LanguageSelector.jsx

**File**

```text
src/components/editor/LanguageSelector.jsx
```

**Code**

```jsx
function LanguageSelector({

  language,

  setLanguage,

  languages,

}) {

  return (

    <select

      value={language}

      onChange={(e) =>

        setLanguage(e.target.value)

      }

      className="

      rounded-lg

      border

      border-gray-300

      px-4

      py-2

      bg-white

      "

    >

      {

        languages.map((lang) => (

          <option

            key={lang.value}

            value={lang.value}

          >

            {lang.label}

          </option>

        ))

      }

    </select>

  );

}

export default LanguageSelector;
```

```jsx
function FontSelector({

  fontSize,

  setFontSize,

  fonts,

}) {

  return (

    <select

      value={fontSize}

      onChange={(e) =>

        setFontSize(

          Number(

            e.target.value

          )

        )

      }

      className="

      rounded-lg

      border

      border-gray-300

      px-4

      py-2

      bg-white

      "

    >

      {

        fonts.map((size) => (

          <option

            key={size}

            value={size}

          >

            {size}px

          </option>

        ))

      }

    </select>

  );

}

export default FontSelector;
```

# Important Design Rule

These components:

```text
DO NOT

import Zustand

DO NOT

import Runtime

DO NOT

change templates

DO NOT

run code
```

They only:

```text
Display values

Raise events
```

This keeps the project clean.
