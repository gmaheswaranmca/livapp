# Step 1. Create the Project

Open terminal:

```bash
npm create vite@latest browser-code-runner
```

Choose:

```text
Framework : React
Variant   : JavaScript
```

Then:

```bash
cd browser-code-runner

npm install
```

---

# Step 2. Install Required Packages

Run:

```bash
npm install @monaco-editor/react

npm install react-icons

npm install react-router-dom

npm install zustand

npm install react-resizable-panels

npm install pyodide

npm install webr
```

---

# Step 3. Install Tailwind

```bash
npm install tailwindcss @tailwindcss/vite
```

---

# Step 4. Configure Vite

Open:

```text
vite.config.js
```

Replace with:

```javascript
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({

  plugins: [

    react(),

    tailwindcss(),

  ],

});
```

---

# Step 5. Configure CSS

Open:

```text
src/index.css
```

Replace with:

```css
@import "tailwindcss";
```

# Step 7. App.jsx

Create:

```jsx
import PlaygroundPage
from "./pages/PlaygroundPage";

function App(){

  return(

      <PlaygroundPage />

  );

}

export default App;
```

**Small correction**

In React JavaScript:

```javascript
import PlaygroundPage from "./pages/PlaygroundPage";
```

not Python style.

So final:

```jsx
import PlaygroundPage from "./pages/PlaygroundPage";

function App() {

  return <PlaygroundPage />;

}

export default App;
```

# Important Rule for the Entire Project

From now onwards:

```text
runtimes/

Contains ONLY language execution code


components/

Contains ONLY UI


services/

Contains managers and factories


store/

Contains application state
```

We will never violate this separation.

This is what keeps large projects maintainable.
