# Final Architecture

```text id="k’wini3"
Public GitHub Repo          # git branch(namned course_id 10001) url + practice/day1.json | assessment1.json ..., starter code, PDFs, sample tests
        ↓
React App
   ├── Fetch JSON files     # downloading content
   ├── IndexedDB cache      # caching locally
   ├── Monaco editor        # editor execution
   ├── Schedule handling    # deciding unlock schedule from checklist
   └── Problem solving UI   # submission UI

        ↓

Backend Services    
   ├── Auth Service         # login, JWT, refresh token, session/device validation | POST /auth/login, POST /auth/refresh, POST /auth/logout
   ├── Progress Tracking    # completed problems, day completion, scores, timings | POST /progress/update, GET  /progress/me
   └── Assessment Control   # assessment windows, preventing early access, submission timing, hidden testcase execution
```

As students can inspect JSON | URLs can be shared,
* Public: Assessment problem statements 
* Backend-only: Hidden testcases | Evaluation logic | Final scoring
* Your Infra Cost Will Be Very Low: GitHub serves static files | browser caches locally | backend does minimal work -> Excellent for training platforms.
* Your Current Design Is Actually Strong: Frontend-heavy architecture + Lightweight backend + Public content distribution + Secure assessment control
