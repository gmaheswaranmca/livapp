# Alternative — sys.settrace()

Very powerful for browser debuggers.

Example:

```python id="ibn7qc"
import sys

def trace(frame, event, arg):
    print(frame.f_lineno, event)
    return trace

sys.settrace(trace)

x = 10
y = 20
print(x + y)
```

This gives:

* line execution
* function calls
* returns
* exceptions

Perfect for educational debugger UI.

# Important Challenge

Pyodide execution is synchronous.

Meaning:

* execution blocks worker

So for debugging:
you need:

* async execution control
* pause/resume mechanism

This is advanced but achievable.
