# Your Architecture (Recommended)

## 1. Problems Stored as JSON

You can fetch problems:

```json
{
  "id": 101,
  "title": "Sum of Two Numbers",
  "statement": "Read two numbers...",
  "starter_code": "def solve():\n    pass",
  "hidden_code": "import sys",
  "test_cases": [
    {
      "input": "10 20",
      "output": "30"
    }
  ]
}
```

Then:

* store in IndexedDB
* cache offline
* preload batches

Good for:

* offline support
* fast reload
* low server cost

---

# 2. IndexedDB as Hidden File System

Exactly correct.

User should NEVER see:

* actual file system
* generated files
* hidden wrappers
* execution pipeline

You internally create:

```text
/problems/101/problem.json
/workspace/user_solution.py
/runtime/main.py
```

inside IndexedDB.

Libraries:

* Dexie.js
* localForage

Dexie is better for your case.

---

# 3. Build Final Executable Python File

This is the important part.

Suppose student writes:

```python
def add(a, b):
    return a + b
```

You generate internally:

```python
import sys

def add(a, b):
    return a + b

# hidden evaluator
print(add(10, 20))
```

or:

```python
import io
import sys

input_data = "10 20"
sys.stdin = io.StringIO(input_data)

# student code
...
```

Then pass FULL generated program to Pyodide.

This is exactly how coding platforms work.

# 5. IMPORTANT — Use Web Workers

DO NOT run Pyodide in main thread.

Otherwise:

* UI freezes
* typing lag
* browser hangs

Correct:

```text
Main UI Thread
    ↓
Web Worker
    ↓
Pyodide Runtime
```

Very important.

# 7. Hidden Wrapper Generator

This component is critical.

Example:

```js
function buildProgram(userCode, testInput) {
  return `
import sys
import io

sys.stdin = io.StringIO("""${testInput}""")

${userCode}

if __name__ == "__main__":
    solve()
`
}
```

# 8. Capture Output

In Pyodide:

```js
pyodide.setStdout({
  batched: (msg) => console.log(msg)
})
```

Capture:

* stdout
* stderr
* exceptions
* timeout

---

# 9. Timeout Protection

Very important.

Students can do:

```python
while True:
    pass
```

Need:

* worker termination
* execution timeout

Example:

```js
setTimeout(() => {
   worker.terminate()
}, 3000)
```

Then recreate worker.
