# What Should Stay Local

Store in IndexedDB:

```json id="mwrf44"
{
  "problem_id": 101,

  "status": "Solved",
  "last_run": "2026-05-21T10:20",
```

Also:

* draft code
* unsynced submissions
* execution history
* cached problems
* settings

# What Should Sync to Server

Do NOT sync everything.

Sync only:

```json id="6o3rxl"
{
  "user_id": 55,
  "problem_id": 101,
  "status": "Solved",
  "score": 100,
  "attempts": 4,
  "time_taken": 600,
  "last_submission": "...",
  "language": "python"
}
```

Optional:

* final accepted code
* analytics
* cheating detection
* progress reports

Avoid syncing:

* every keystroke
* editor cursor
* temporary code states

# Use Sync Queue

VERY important.

Local table:

```text id="ml6lm2"
sync_queue
   ├── id
   ├── operation
   ├── payload
   ├── retry_count
   └── status
```

When offline:

* queue operations

When online:

* flush queue

This makes system reliable.

# One Important Recommendation

Do NOT sync entire code files frequently.

Instead:

* sync only milestones
* accepted solutions
* periodic snapshots

Otherwise:

* bandwidth increases
* server storage explodes
* mobile performance degrades
