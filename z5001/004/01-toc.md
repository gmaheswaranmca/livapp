Python: Beyond Basics
Duration: 1 Full Day
Level: Intermediate / Fast-track

Course Description:
    This intensive hands-on course is designed for developers who are already comfortable with the basics of Python and want to explore its applied capabilities. The course focuses on essential built-in modules that enable Python to interact with the operating system and the network. Learners will create command-line tools using argparse, manage system-level operations with subprocess, and explore both multithreading and asynchronous programming with threading and asyncio. This course lays the groundwork for building real-world automation and network applications in Python.

Learning Objectives:
    By the end of the training, participants will be able to:
    Create powerful command-line utilities using argparse
    Execute and manage system commands using subprocess
    Build basic socket-based server applications
    Understand threading, concurrency, and thread synchronization using queues
    Grasp asynchronous programming fundamentals with asyncio
    Build event-driven programs using async def, await, and the event loop

Key Takeaways:
    Hands-on experience with real-world modules used in automation and networking
    Clarity on differences between threading and asyncio concurrency models
    Ability to build Python tools that interact with the system and network
    A strong foundation to transition into automation, DevOps, and network scripting roles

Target Audience (Who Should Attend):
    Software engineers and system administrators comfortable with basic Python
    Developers aiming to deepen their skills in scripting, automation, or network programming
    Professionals planning to move into roles involving DevOps or backend automation using Python

Skill Level:
    Intermediate / Fast-track

Pre-requisites:
    Participants should be comfortable with:
    Python language basics: data types, loops, functions, modules
    Some understanding of Object-Oriented Programming concepts (in any language)
    Working knowledge of basic terminal/command-line usage

Lab Setup Requirements:
    Latest version of Python 3.x installed: https://www.python.org/downloads/
    Preferred IDE: Visual Studio Code with Python extension: https://code.visualstudio.com/download
    Internet access to install required modules (via pip)
    Optional: Git installed for accessing example repositories

Course Agenda
    Session 1: Systems Interaction & CLI Utilities
        Introduction to command-line arguments
        Building command-line tools using argparse
        Using subprocess module
        Executing shell commands
        Capturing output and error streams
        Piping commands

    Session 2: Networking with Sockets
        Building a basic socket server
        Connecting via a simple client
        Understanding client starvation problems
        Resolving starvation using threading.Thread
        Synchronizing threads using queue.Queue

    Session 3: Async Programming with asyncio
        Introduction to asynchronous programming in Python
        Understanding async def, await, and the event loop
        Differences between threads and async IO
        Building an async network or I/O simulator with asyncio
        Closing discussion: when to use threading vs asyncio
