For teaching **socket programming**, chat is only one example. Many real-world applications use the same networking concepts and are often easier to relate to.

## 1. Echo Server ⭐ (Best First Example)

**Concept:** Server sends back exactly what the client sends.

```
Client ---- "Hello" ---->

Server

Client <--- "Hello" ----
```

Teaches:

* socket
* connect
* recv
* send

---

## 2. Calculator Server ⭐⭐⭐

Client sends

```
10 + 20
```

Server computes

```
30
```

Students learn that the server performs processing, not just forwarding data.

Example

```
Client
-------
Enter:
25 * 4

Server
-------
100
```

---

## 3. Time Server

Client connects.

Server replies

```
07-Jul-2026 02:30 PM
```

Then disconnects.

Similar to the classic TCP Daytime protocol.

---

## 4. Uppercase Converter

Client

```
python networking
```

Server

```
PYTHON NETWORKING
```

Shows request-response.

---

## 5. Reverse String Server

Client

```
abcdef
```

Server

```
fedcba
```

Simple but demonstrates processing.

## 6. File Transfer ⭐⭐⭐

Client

```

```

Server

```

```

Client saves the file.

Concepts:

* binary data
* chunks
* EOF
* recv loop

## 20. Mini HTTP Server ⭐⭐⭐⭐

Client (browser)

```
GET /
```

Server returns

```html
<html>
<h1>Hello</h1>
</html>
```

Students realize that a web browser is just another TCP client and that HTTP is an application-layer protocol built on sockets.

# Recommended Classroom Sequence (8-Hour Networking Module)

| Session | Example                      | Concept                                 |
| ------- | ---------------------------- | --------------------------------------- |
| 1       | Echo Server                  | Basic socket communication              |
| 2       | Calculator Server            | Request-response processing             |
| 3       | Time/Uppercase Server        | Different server behaviors              |
| 4       | Single-threaded Multi-client | Blocking problem                        |
| 5       | Threaded Server              | Concurrency                             |
| 6       | File Transfer                | Binary data and chunked I/O             |
| 7       | Broadcast Chat               | Shared clients and message distribution |
| 8       | Mini HTTP Server             | Real-world protocol built on TCP        |

This progression takes students from the fundamentals of sockets to a simple web server, while naturally introducing concepts like blocking, threading, binary transfers, and application protocols.
