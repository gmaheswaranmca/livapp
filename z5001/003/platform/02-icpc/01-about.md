**ICPC-style problems** are programming problems similar to those used in the **International Collegiate Programming Contest (ICPC)**, one of the world's most prestigious competitive programming contests.

They are different from typical coding interview questions.

---

# What Makes a Problem "ICPC Style"?

An ICPC-style problem usually requires:
✅ Strong algorithm knowledge
✅ Mathematical thinking
✅ Data structure mastery
✅ Problem-solving creativity
✅ Efficient implementation
✅ Handling large constraints

Not just coding.

---

# Typical Structure

A problem statement contains:

### Story

Sometimes a real-world scenario:

> A king wants to build roads...

> A robot moves on a grid...

> Students join university groups...

---

### Input

```text
5
1 2 3 4 5
```

---

### Output

```text
15
```

---

### Constraints

```text
1 ≤ N ≤ 100000
```

These constraints tell you what algorithm is expected.

---

# Example 1: Easy ICPC Problem

### Problem

Given N numbers, find maximum.

Input

```text
5
3 8 2 10 1
```

Output

```text
10
```

Complexity:

```text
O(N)
```

---

# Example 2: Typical ICPC Problem

### Problem


# Example of a Real ICPC-Style Thought Process

Problem:

```text
N = 100000
Find shortest path.
```

Thinking:

```text
Weighted graph?
    -> Dijkstra

Negative edges?
    -> Bellman Ford

DAG?
    -> Topological DP
```

The skill is identifying the algorithm quickly.

# Difference Between Interview Problems and ICPC Problems

| Interview             | ICPC                       |
| --------------------- | -------------------------- |
| Focus on coding       | Focus on algorithms        |
| 30-60 min             | 5-30 min                   |
| Usually one topic     | Multiple topics            |
| Small constraints     | Huge constraints           |
| Communication matters | Correctness + speed matter |

Example:

Interview:

```text
Reverse Linked List
```

ICPC:

```text
Given a tree with 200000 nodes,
support updates and path queries.
```

Requires:

* Tree Flattening
* Segment Tree
* LCA
