If your goal is to become strong enough for **ICPC Regionals** and eventually compete at a world-class level, you do **not** need 50 different resources.

You need **one roadmap + one practice site + one contest site**.

## Stage 1: Learn DSA Fundamentals

Since you are already studying Trees, Graphs, AVL, Trie, etc., continue with:

* Arrays
* Strings
* Sorting
* Binary Search
* Linked Lists
* Stack
* Queue
* Trees
* Graphs
* Greedy
* Dynamic Programming

A highly recommended free book is:

* [Competitive Programmer's Handbook (Antti Laaksonen)](https://cses.fi/book.pdf?utm_source=chatgpt.com) — covers competitive programming from basics to advanced topics. ([cses.fi][1])

---

## Stage 2: Follow a Structured Competitive Programming Curriculum

The best free roadmap today is:

* [USACO Guide](https://usaco.guide/?utm_source=chatgpt.com)

It provides:

* Topic-wise learning
* Theory
* Practice problems
* Difficulty progression
* Training from beginner to advanced levels ([usaco.guide][2])

---

## Stage 3: Practice Every Topic

The best practice site for learning algorithms systematically:

* [CSES Problem Set](https://cses.fi/problemset/?utm_source=chatgpt.com)

Many competitive programmers consider it one of the best collections of fundamental algorithmic problems. ([usaco.guide][3])

Suggested order:

1. Introductory Problems
2. Sorting and Searching
3. Dynamic Programming
4. Graph Algorithms
5. Range Queries
6. Tree Algorithms
7. String Algorithms
8. Geometry

---

## Stage 4: Learn Advanced Algorithms

For detailed explanations:

* [CP-Algorithms](https://cp-algorithms.com/?utm_source=chatgpt.com)

Use it whenever you encounter:

* Segment Trees
* Fenwick Trees
* DSU
* KMP
* Dijkstra
* Number Theory
* Network Flow

It is one of the most referenced resources in competitive programming. ([competitive-programming.cs.princeton.edu][4])

---

## Stage 5: Start Contesting

Practice weekly on:

* [Codeforces](https://codeforces.com/?utm_source=chatgpt.com)
* [AtCoder](https://atcoder.jp/?utm_source=chatgpt.com)
* [CodeChef](https://www.codechef.com/?utm_source=chatgpt.com)

AtCoder is excellent for learning standard algorithms, while Codeforces is the most popular competitive programming platform. ([Codeforces][5])

---

## Stage 6: Study ICPC-Specific Material

After reaching roughly Codeforces Expert level (~1600+ rating), begin:

* ICPC regional problem archives
* Kattis ICPC problems
* Team contest practice
* Contest strategy

ICPC problems often combine multiple topics in one solution. ([competitive-programming.cs.princeton.edu][4])

## A 12-Month ICPC Preparation Plan

| Months | Focus                                    |
| ------ | ---------------------------------------- |
| 1-2    | Arrays, Strings, Sorting, Binary Search  |
| 3-4    | Stack, Queue, Linked List, Heap, Hashing |
| 5-6    | Trees, BST, Trie, DSU                    |
| 7-8    | Graphs, BFS, DFS, Shortest Paths         |
| 9-10   | Dynamic Programming, Greedy              |
| 11     | Segment Tree, Fenwick Tree, Strings      |
| 12     | ICPC archives + contests                 |

For someone with your current DSA interests, I'd start immediately with:

1. Competitive Programmer's Handbook
2. CSES Problem Set
3. Codeforces contests

That combination alone can take a beginner to a very strong competitive programming level if practiced consistently for a year. ([cses.fi][1])
