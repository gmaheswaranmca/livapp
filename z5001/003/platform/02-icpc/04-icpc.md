### Milestones

| Milestone             | CSES Problems Solved | Approx. Codeforces Level |
| --------------------- | -------------------- | ------------------------ |
| Beginner              | 0–50                 | 800–1100                 |
| Basic CP              | 50–100               | 1100–1300                |
| Intermediate          | 100–150              | 1300–1500                |
| Strong Intermediate   | 150–220              | 1500–1700                |
| Advanced              | 220–300              | 1700–2000                |
| ICPC Regional Level   | 300–350              | 1900–2200                |
| World-Class Candidate | 350+                 | 2200+                    |

### After CSES

1. Codeforces Div2 A/B/C/D problems daily.
2. AtCoder ABC contests.
3. USACO Silver → Gold.
4. ICPC regional archives.
5. CodeChef Starters and Long Challenges.

A common path followed by many strong competitive programmers is:

**CSES → AtCoder ABC → Codeforces Div2 → USACO Gold → ICPC Regionals → ICPC World Finals level problems.**
