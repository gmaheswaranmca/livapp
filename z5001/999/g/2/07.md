# Quick Memory Tips

### Land

* Earth → **Bhoomi / Bhoomi / Dharti / Bhoomi**
* Tree → **Mara / Chettu / Ped / Maram**
* Flower → **Hoovu / Puvvu / Phool / Poovu**
* Forest → **Kaadu / Adavi / Jungle / Kaadu**

### Water

* River → **Nadi / Nadi / Nadi / Puzha**
* Sea → **Samudra / Samudram / Samundar / Kadal**
* Lake → **Kere / Cheruvu / Jheel / Thadakam**

### Sky

* Sun → **Soorya / Sooryudu / Sooraj / Sooryan**
* Moon → **Chandra / Chandrudu / Chaand / Chandran**
* Star → **Nakshatra / Nakshatram / Taara / Nakshathram**

### Weather

* Rain → **Male / Varsham / Baarish / Mazha**
* Wind → **Gaali / Gaali / Hawa / Kaattu**
* Rainbow → **Malebillu / Indradhanussu / Indradhanush / Mazhavillu**

# Important Notes

* **Bhoomi** (Earth) is the common word in Kannada, Telugu, and Malayalam, while Hindi commonly uses **Dharti** in everyday speech.
* Kannada **Kaadu** and Malayalam **Kaadu** both mean **forest**.
* Telugu **Chettu** (tree) and Malayalam **Maram** are among the most frequently used everyday words.
* Hindi **Bijli** can mean both **electricity** and **lightning**, depending on the context.
* Malayalam **Mazha** (rain) and **Mazhavillu** (rainbow) share the same root, making them easy to remember together.
