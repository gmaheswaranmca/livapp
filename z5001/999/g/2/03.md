# Quick Memory Tips

### Staple Foods

* Rice → **Akki / Biyyam / Chawal / Ari**
* Cooked Rice → **Anna / Annam / Pakka Chawal / Choru**
* Wheat → **Godhi / Godhuma / Gehun / Gothambu**

### Dairy

* Milk → **Haalu / Paalu / Doodh / Paal**
* Curd → **Mosaru / Perugu / Dahi / Thairu**
* Butter → **Benne / Venna / Makhan / Venna**
* Ghee → **Tuppa / Neyyi / Ghee / Ney**

### Drinks

* Water → **Neeru / Neellu / Paani / Vellam**
* Tea → **Chaha / Tea / Chai / Chaaya**
* Coffee → **Coffee / Coffee / Coffee / Kaapi**

### Common South Indian Foods

* Idli → **Idli** (all four languages)
* Dosa → **Dose / Dosa / Dosa / Dosa**
* Sambar → **Sambar** (all four languages)
* Rasam → **Saaru / Charu / Rasam / Rasam**

---

# Important Notes

* Kannada **Akki**, Telugu **Biyyam**, and Malayalam **Ari** refer to **raw rice**, while **Anna / Annam / Choru** refer to **cooked rice**.
* Telugu **Pachadi** can mean both **chutney** and certain types of **pickle**, depending on context.
* English food names such as **Bread, Cake, Biscuit, Noodles, Cheese, Ice Cream,** and **Chocolate** are widely used in all four languages.
