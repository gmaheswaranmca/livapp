# Quick Memory Tips

### Common Clothes

* Shirt → **Angi / Chokka / Kameez / Shirt**
* Pant → **Pant** (commonly used in all languages)
* Saree → **Seere / Cheera / Saree / Saree**
* Blouse → **Ravike / Ravika / Blouse / Blouse**

### Footwear

* Shoes → **Bootu / Bootlu / Joota / Shoes**
* Sandals → **Chappali / Cheppulu / Chappal / Cheruppu**

### Accessories

* Belt → **Belt**
* Tie → **Tie**
* Cap → **Topi / Topi / Topi / Thoppi**

### Fabric

* Cotton → **Hatti / Patti / Kapas / Panji**
* Silk → **Reshme / Pattu / Resham / Pattu**
* Wool → **Unne / Unni / Oon / Kambli Romam**

---

# Important Notes

* Many modern clothing terms (**T-Shirt, Jeans, Jacket, Sweater, Coat, Belt, Tie, Hoodie**) are borrowed directly from English across all four languages.
* Kannada **Seere** and Telugu **Cheera** both mean **saree**.
* Hindi **Joota** usually refers to a **shoe**, while **Chappal** refers to **slippers/sandals**.
* Malayalam **Cheruppu** is the common everyday word for **footwear**, especially sandals or slippers.
