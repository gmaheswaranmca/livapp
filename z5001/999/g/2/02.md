# Quick Memory Tips

### House

* House → **Mane / Illu / Ghar / Veedu**

### Rooms

* Room → **Kone / Gadi / Kamra / Muri**
* Kitchen → **Aduge Mane / Vantagadi / Rasoi / Adukkala**
* Bedroom → **Malagu Kone / Padaka Gadi / Sone Ka Kamra / Kidappu Muri**

### Entry

* Door → **Bagilu / Talupu / Darwaza / Vaathil**
* Window → **Kitaki / Kitiki / Khidki / Janal**
* Gate → **Baagilu / Gate / Gate / Gate**

### Furniture

* Bed → **Hasige / Mancham / Bistar / Kattil**
* Chair → **Kurchi / Kurchi / Kursi / Kasera**
* Cupboard → **Beeru / Beeruva / Almari / Alamara**

---

# Important Notes

* **Illu** (Telugu), **Mane** (Kannada), and **Veedu** (Malayalam) all correspond to Tamil **வீடு**.
* Many modern household words such as **Lift**, **Garage**, **Switch**, **Plug**, **Fan**, and **Balcony** are borrowed from English in all four languages.
* Malayalam **Janal** and Tamil **ஜன்னல்** are closely related.
