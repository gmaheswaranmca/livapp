# Quick Memory Tips

* **Family**

  * Father → Appa / Nanna / Pitaji / Achan
  * Mother → Amma / Amma / Maa / Amma
  * Brother → Anna / Annayya / Bhai / Chettan
  * Sister → Akka / Akka / Behen / Chechi

* **Children**

  * Son → Maga / Koduku / Beta / Makan
  * Daughter → Magalu / Koothuru / Beti / Makal

* **Common People**

  * Friend → Geleya / Snehitudu / Dost / Suhruth
  * Teacher → Shikshaka / Upadhyayudu / Adhyapak / Adhyapakan
  * Farmer → Raitha / Rythu / Kisaan / Karshakan

---

# Important Notes

* **Amma** is used in Kannada, Telugu, and Malayalam exactly like Tamil.
* **Appa** is common in Kannada, while Telugu commonly uses **Nanna**.
* Hindi **Aurat** is conversational for "woman," while **Mahila** is more formal.
* Malayalam commonly distinguishes older and younger siblings:

  * **Chettan** = elder brother
  * **Aniyan** = younger brother
  * **Chechi** = elder sister
  * **Aniyathi** = younger sister
