# Quick Memory Tips

### Head

* Head → **Tale / Tala / Sir / Thala**
* Hair → **Koodalu / Juttu / Baal / Mudi**
* Face → **Mukha / Mukham / Chehra / Mukham**

### Eyes & Face

* Eye → **Kannu / Kannu / Aankh / Kannu**
* Ear → **Kivi / Chevi / Kaan / Chevi**
* Nose → **Moogu / Mukku / Naak / Mookku**
* Mouth → **Baayi / Noru / Munh / Vaay**

### Arms & Hands

* Hand → **Kai / Cheyi / Haath / Kai**
* Finger → **Beralu / Velu / Ungli / Viral**
* Thumb → **Hebberalu / Botanavelu / Angootha / Peruviral**

### Legs

* Leg → **Kaalu / Kaalu / Pair / Kaal**
* Knee → **Monakaalu / Mokalu / Ghutna / Muttu**
* Foot → **Kaalu / Paadam / Paon / Paadam**

### Internal Body

* Heart → **Hrudaya / Gunde / Dil / Hridayam**
* Brain → **Medulu / Medadu / Dimaag / Thalachoru**
* Blood → **Rakta / Raktam / Khoon / Raktham**

---

# Important Notes

* **Kannu** means **eye** in Kannada, Telugu, and Malayalam, making it one of the easiest words to remember.
* **Kai** means **hand** in Kannada and Malayalam.
* Hindi **Dil** is the everyday word for **heart**, while **Hriday** is more formal.
* Telugu **Gunde** is the most common everyday word for **heart**.
