Below is a complete setup guide to create and run a **Spring Boot + MongoDB Employee CRUD API**.

---

# 1. Prerequisites

Install the following:

| Software                 | Version |
| ------------------------ | ------- |
| Java                     | 21      |
| Maven                    | 3.9+    |
| MongoDB Community Server | Latest  |
| VS Code / IntelliJ IDEA  | Latest  |
| Postman                  | Latest  |

---

# 6. Configure MongoDB

`src/main/resources/application.properties`

```properties

spring.data.mongodb.uri=mongodb://localhost:27017/employeedb
```

# 15. Ready to Connect React

Once the backend is running on `http://localhost:8080`, your React application can call:

* `GET http://localhost:8080/employees`
* `GET http://localhost:8080/employees/{id}`
* `POST http://localhost:8080/employees`
* `PUT http://localhost:8080/employees/{id}`
* `DELETE http://localhost:8080/employees/{id}`

This gives you a clean foundation for building a React CRUD application with forms, tables, edit, and delete functionality.
