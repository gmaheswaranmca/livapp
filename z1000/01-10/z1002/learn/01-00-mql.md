MongoDB (a NoSQL database) doesn’t use SQL, but it **does have its own “query language” and structured categories of operations**—very similar in purpose to SQL sublanguages like DDL, DML, DCL, and TCL.

Let’s map this clearly so you can relate MongoDB to SQL 👇

---

# 🧠 1. MongoDB Query Language (MQL)

MongoDB uses **MQL (MongoDB Query Language)** instead of SQL.

* JSON-like syntax (BSON internally)
* Works with documents instead of tables
* Executed via:

  * Shell (`mongosh`)
  * Drivers (Node.js, Python, etc.)

Example:

```js
db.users.find({ age: { $gt: 25 } })
```

---

# 🔁 2. Equivalent of SQL Sublanguages in MongoDB

## 📦 A. Data Definition (DDL Equivalent)

In SQL → CREATE, ALTER, DROP

In MongoDB:

* `db.createCollection()`
* `db.collection.drop()`
* Implicit collection creation (auto)

Example:

```js
db.createCollection("users")
db.users.drop()
```

👉 MongoDB is **schema-less**, so DDL is minimal compared to SQL.

---

## ✍️ B. Data Manipulation (DML Equivalent)

In SQL → INSERT, UPDATE, DELETE

In MongoDB:

### Insert

```js
db.users.insertOne({ name: "John", age: 25 })
```

### Update

```js
db.users.updateOne(
  { name: "John" },
  { $set: { age: 26 } }
)
```

### Delete

```js
db.users.deleteOne({ name: "John" })
```

---

## 🔍 C. Data Query (DQL Equivalent)

In SQL → SELECT

MongoDB:

```js
db.users.find({ age: { $gt: 20 } })
```

With projection:

```js
db.users.find({}, { name: 1, _id: 0 })
```

---

## 🔐 D. Data Control (DCL Equivalent)

In SQL → GRANT, REVOKE

MongoDB:

* `createUser`
* `grantRolesToUser`
* `revokeRolesFromUser`

Example:

```js
db.createUser({
  user: "admin",
  pwd: "1234",
  roles: ["readWrite"]
})
```

---

## 🔄 E. Transaction Control (TCL Equivalent)

In SQL → COMMIT, ROLLBACK

MongoDB (for replica sets):

```js
session.startTransaction()

// operations

session.commitTransaction()
session.abortTransaction()
```

---

# 🧩 3. Advanced Categories (MongoDB-Specific)

## 🔗 Aggregation Framework (VERY IMPORTANT)

Equivalent to:

* SQL GROUP BY
* JOIN
* HAVING

```js
db.orders.aggregate([
  { $match: { status: "completed" } },
  { $group: { _id: "$customerId", total: { $sum: "$amount" } } }
])
```

---

## 🔍 Indexing

Equivalent to SQL indexes

```js
db.users.createIndex({ email: 1 })
```

---

## 🔗 Relationships (instead of JOIN)

MongoDB uses:

### 1. Embedding

```json
{
  name: "John",
  orders: [{ item: "Book", price: 10 }]
}
```

### 2. Referencing

```json
{
  name: "John",
  orderIds: [101, 102]
}
```

# ⚖️ 4. Quick Mapping Table

| SQL Category | MongoDB Equivalent              |
| ------------ | ------------------------------- |
| DDL          | createCollection, drop          |
| DML          | insertOne, updateOne, deleteOne |
| DQL          | find                            |
| DCL          | createUser, roles               |
| TCL          | transactions (session)          |
| JOIN         | $lookup (aggregation)           |
| GROUP BY     | $group                          |

# 🚀 Final Understanding

Think like this:

👉 SQL = Table-based + strict schema
👉 MongoDB = Document-based + flexible schema

👉 SQL sublanguages → MongoDB **operation categories + MQL**
