# 🔹 1. String Functions

| Function  | Syntax                       | Example                          | Explanation                        |
| --------- | ---------------------------- | -------------------------------- | ---------------------------------- |
| UPPER     | `UPPER(str)`                 | `SELECT UPPER('john');`          | Converts text to uppercase         |
| LOWER     | `LOWER(str)`                 | `SELECT LOWER('JOHN');`          | Converts text to lowercase         |
| LENGTH    | `LENGTH(str)`                | `SELECT LENGTH('Hello');`        | Returns number of bytes/characters |
| CONCAT    | `CONCAT(str1, str2,...)`     | `SELECT CONCAT('John',' Doe');`  | Joins multiple strings             |
| SUBSTRING | `SUBSTRING(str, start, len)` | `SELECT SUBSTRING('Hello',1,3);` | Extracts part of string            |
| TRIM      | `TRIM(str)`                  | `SELECT TRIM('  hi  ');`         | Removes leading/trailing spaces    |
| REPLACE   | `REPLACE(str, old, new)`     | `SELECT REPLACE('abc','a','x');` | Replaces substring                 |
| INSTR     | `INSTR(str, substr)`         | `SELECT INSTR('Hello','e');`     | Returns position of substring      |
| LEFT      | `LEFT(str, n)`               | `SELECT LEFT('Hello',2);`        | First N characters                 |
| RIGHT     | `RIGHT(str, n)`              | `SELECT RIGHT('Hello',2);`       | Last N characters                  |

# 🔹 2. Numeric Functions

| Function | Syntax             | Example                      | Explanation                 |
| -------- | ------------------ | ---------------------------- | --------------------------- |
| ROUND    | `ROUND(num, d)`    | `SELECT ROUND(12.345,2);`    | Rounds number               |
| CEIL     | `CEIL(num)`        | `SELECT CEIL(10.2);`         | Rounds up                   |
| FLOOR    | `FLOOR(num)`       | `SELECT FLOOR(10.9);`        | Rounds down                 |
| ABS      | `ABS(num)`         | `SELECT ABS(-10);`           | Absolute value              |
| MOD      | `MOD(a,b)`         | `SELECT MOD(10,3);`          | Remainder                   |
| POWER    | `POWER(a,b)`       | `SELECT POWER(2,3);`         | Exponentiation              |
| SQRT     | `SQRT(num)`        | `SELECT SQRT(16);`           | Square root                 |
| RAND     | `RAND()`           | `SELECT RAND();`             | Random number (0–1)         |
| SIGN     | `SIGN(num)`        | `SELECT SIGN(-5);`           | Returns -1, 0, or 1         |
| TRUNCATE | `TRUNCATE(num, d)` | `SELECT TRUNCATE(12.345,2);` | Cuts decimals (no rounding) |

# 🔹 3. Date Functions

| Function    | Syntax                          | Example                                       | Explanation         |
| ----------- | ------------------------------- | --------------------------------------------- | ------------------- |
| NOW         | `NOW()`                         | `SELECT NOW();`                               | Current date & time |
| CURDATE     | `CURDATE()`                     | `SELECT CURDATE();`                           | Current date        |
| CURTIME     | `CURTIME()`                     | `SELECT CURTIME();`                           | Current time        |
| DATE        | `DATE(datetime)`                | `SELECT DATE(NOW());`                         | Extract date        |
| YEAR        | `YEAR(date)`                    | `SELECT YEAR('2025-01-01');`                  | Extract year        |
| MONTH       | `MONTH(date)`                   | `SELECT MONTH('2025-01-01');`                 | Extract month       |
| DAY         | `DAY(date)`                     | `SELECT DAY('2025-01-01');`                   | Extract day         |
| DATEDIFF    | `DATEDIFF(d1,d2)`               | `SELECT DATEDIFF('2026-01-01','2025-01-01');` | Difference in days  |
| ADDDATE     | `ADDDATE(date, INTERVAL n DAY)` | `SELECT ADDDATE(NOW(), INTERVAL 5 DAY);`      | Add days            |
| DATE_FORMAT | `DATE_FORMAT(date, format)`     | `SELECT DATE_FORMAT(NOW(),'%d-%m-%Y');`       | Format date         |

# 🔹 4. Aggregate Functions

| Function     | Syntax              | Example                                     | Explanation                |
| ------------ | ------------------- | ------------------------------------------- | -------------------------- |
| COUNT        | `COUNT(*)`          | `SELECT COUNT(*) FROM employees;`           | Number of rows             |
| SUM          | `SUM(col)`          | `SELECT SUM(salary) FROM employees;`        | Total sum                  |
| AVG          | `AVG(col)`          | `SELECT AVG(salary) FROM employees;`        | Average value              |
| MAX          | `MAX(col)`          | `SELECT MAX(salary) FROM employees;`        | Highest value              |
| MIN          | `MIN(col)`          | `SELECT MIN(salary) FROM employees;`        | Lowest value               |
| GROUP_CONCAT | `GROUP_CONCAT(col)` | `SELECT GROUP_CONCAT(name) FROM employees;` | Combine values into string |

# 🔹 5. NULL Handling Functions

| Function | Syntax                | Example                           | Explanation           |
| -------- | --------------------- | --------------------------------- | --------------------- |
| IFNULL   | `IFNULL(val, alt)`    | `SELECT IFNULL(NULL,'N/A');`      | Replace NULL          |
| COALESCE | `COALESCE(v1,v2,...)` | `SELECT COALESCE(NULL,NULL,'A');` | First non-null value  |
| NULLIF   | `NULLIF(a,b)`         | `SELECT NULLIF(5,5);`             | Returns NULL if equal |

# 🔹 6. Conditional Functions

| Function | Syntax              | Example                                                                    | Explanation         |
| -------- | ------------------- | -------------------------------------------------------------------------- | ------------------- |
| IF       | `IF(cond, t, f)`    | `SELECT IF(10>5,'Yes','No');`                                              | Conditional logic   |
| CASE     | `CASE WHEN ... END` | `SELECT CASE WHEN salary>50000 THEN 'High' ELSE 'Low' END FROM employees;` | Multiple conditions |

# 🔹 Real-World Combined Example 🔥

```sql
SELECT 
    name,
    UPPER(name) AS upper_name,
    ROUND(salary) AS rounded_salary,
    DATEDIFF(CURDATE(), join_date) AS days_worked,
    IFNULL(email, 'N/A') AS email_status
FROM employees;
```

👉 Uses:

* String function
* Numeric function
* Date function
* NULL handling
