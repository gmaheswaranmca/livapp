# 💰 Redis Cloud Pricing Overview

## 🟢 1. Free Tier (Best for learning / dev)

* Cost: **$0**
* Memory: ~30 MB
* Use case: small testing apps, demos
* No HA, limited connections ([Redis][1])

👉 Good for: students, POCs, small trainers’ apps

---

## 🟡 2. Essentials Plan (Entry paid tier)

* Cost:

  * **~$0.007/hour (~$5/month minimum)** ([Redis][2])
* Memory: 250 MB → 100 GB
* Type: Shared infrastructure
* Features:

  * Basic SLA (~99.99%)
  * Auth, encryption, RBAC

👉 Good for:

* Small production apps
* Your Trainer + Auth service (low traffic)

---

## 🔵 3. Pro Plan (Production-grade)

* Cost:

  * **~$0.014/hour**
  * **Minimum ~$200/month** ([Redis][2])
* Dedicated infrastructure
* Features:

  * Multi-region (Active-Active)
  * Auto-scaling
  * High SLA (99.999%)

👉 Good for:

* Real production systems
* Microservices + API Gateway + rate limiting

---

## 🔴 4. Real-world Cost Examples

Typical monthly cost (industry estimates):

| Usage      | Cost             |                  |
| ---------- | ---------------- | ---------------- |
| 1 GB RAM   | $50–80/month     |                  |
| 10 GB RAM  | $500–800/month   |                  |
| 100 GB RAM | $4000–6000/month | ([OneUptime][3]) |

👉 Key insight:

* **Redis pricing scales with RAM + throughput**
* Not CPU, not storage → **memory = money**

---

## ⚙️ How Pricing is Calculated

Redis Cloud charges based on:

* **Memory (RAM used)** → biggest factor
* **Throughput (ops/sec)**
* **Replication (HA, multi-region)**
* **Shard count (cluster size)** ([Redis][4])

---

## 📉 Hidden Costs You Should Know

* Multi-region = **2x cost**
* HA replicas = **double memory cost**
* Data transfer (cross-region) may be extra ([Amazon Web Services, Inc.][5])
* Cost increases quickly as usage grows ([G2][6])

# 🔥 Alternative (Cost Optimization Tip)

Instead of Redis Cloud:

### 🟢 Cheapest Option

* Self-host Redis on:

  * AWS EC2 / Lightsail
  * Docker (you already use)

👉 Cost:

* ₹500–₹1500/month for small instance

### 🔵 Managed Alternatives

* AWS ElastiCache (slightly cheaper at scale)
* Upstash (pay-per-request model)
