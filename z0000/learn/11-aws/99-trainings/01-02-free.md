# 📱 Will AWS ask mobile number & ID?

When creating an account on Amazon Web Services, AWS typically requires:

## ✅ 1. Mobile Number (Mandatory)

* OTP verification (SMS or call)
* Used for:

  * Account security
  * Fraud detection

👉 **Important:**

* You cannot reuse the same phone number too many times
* After a few accounts → AWS may block it

---

## 🪪 2. Identity Details (Basic, not KYC)

AWS may ask:

* Name
* Address
* Country

👉 Usually:

* No Aadhaar / PAN upload initially
* But details must look realistic (not fake patterns)

---

## 💳 3. Credit/Debit Card (Mandatory)

* Even for Free Tier
* Used for:

  * Verification
  * Backup billing

👉 Indian cards work (Visa/Mastercard preferred)

---

## 🚨 4. Fraud Detection System (Very Important)

AWS tracks patterns like:

* Same phone number reused
* Same IP creating many accounts
* Same card used repeatedly
* Similar names/emails

👉 If detected:

* Account creation fails ❌
* Accounts may get suspended ❌
